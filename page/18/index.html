1932年01月10日

发表于 2021-01-10 更新于 2021-04-05 分类于 局部抗战(1931-1937)

  • 1932年1月10日讯：中共 中央 军委下达攻打赣州令，以红三军团和红四军担任攻城和打援任务。

  • 1932年1月10日讯：驻天津日兵三名，夜闯入居民李振亭宅，欲轮奸李妻，李夫妇抗拒，被日兵用刺刀将李削断三指。

  • 1932年1月10日讯：锦西一带义勇军六、七、八等大队以东北民众自卫义勇军名义，与东北军前线下级军官联合发表绝命宣言，表示誓死抗日，“无所悔恨”。

  • 1932年1月10日讯：日本“八云”舰由旅顺开赴青岛。

  • 1932年1月10日《申报》：北平息，青年舍身抗日团请张学良发给皮衣及赴热河护照，并送卫戍部果品四十包，慰劳锦州伤兵。（9日专电）

  • 1932年1月10日《申报》：北平息，沟帮子站一部房屋及附近民宅，皆为日军焚毁，住户逃避已空。迟行者多遭杀害，榆关以东电话电报线杆，被割断者甚多，话报线仍不通。（9日专电）

  • 1932年1月10日《申报》：哈尔滨息，张景惠令匪军王殿忠部改成警备第一旅，驻黑垣。（9日专电）

  • 1932年1月10日讯：福建各团体代表团9日在上海青年会招待沪各团体及各报新闻记者，报告日人在福州挑衅情形及省府媚外辱国等经过。是日赴南京请愿，要求国民党中央就福州事件向日使提出严重抗议，限令日舰即日离开福建，保证此后日水兵不随意登陆，并否认福建省政府承认日本所提之五项无 …

  • 1932年1月10日《申报》：哈尔滨息，张景惠昨晨2时由江省垣回哈后，午后4时，召集会议，宣布1月1日起，兼领江省最高政权。3日起，正式就任江省省长，江省事权，委吉祥代理，并任日人顾问村田懿磨。（9日专电）

  • 1932年1月10日讯：上海各大学抗日救国联合会在南市公共体育场召开赴京请愿被难同学杨同恒追悼会，与会者数千人。会后在南京路抬杨棺示威游行，至百老汇路，被公共租界探捕驱散。

  • 1932年1月10日《申报》：北平息，日军攻陷盘山后，28夜我义勇军复向阵地袭击，日军不支溃退，当获日方野战炮7门，陆炮4门，炮弹千余发。因义勇军无能发炮者，遂电锦调讲武堂炮兵科学生四人前往，即以日炮克服盘山，终以弹药耗尽，日军得逞。（9日专电）

  • 1932年1月10日《申报》：天津息，北宁路前所站东南15里之南海头，9日晨7时开到日舰飞穴号一艘，有陆战队500名登岸，并卸下军火甚多。（9日专电）

  • 1932年1月10日讯：北平绥靖公署主任张学良在平招待新闻记者，表示拥护统一，安定北方。

  • 1932年1月10日《申报》：北平息，北宁路车务处长英人巴克，昨随101次客车，由榆关东行，过绥中，日军阻止。该员向日军交涉，日军怒，竟连批其颊。该员随客车退回榆关。（9日专电）

  • 1932年1月10日讯：军政部、参谋本部及训练总监部合组军事整理会议，由军政部长召集，商讨全国各部队整理事宜。

  • 1932年1月10日讯：日关东军第八师团古贺骑兵联队和松尾辎重部队在锦西、锦州间遭我辽西义勇军郑桂林部伏击，被全部歼灭，古贺被击毙。

  • 1932年1月9日讯：上海市政府密电行政院，请下令制止该市成立中国军人救国会组织。

  • 1932年1月9日《申报》：北平息，辽省府秘书长黄剑秋谈，2日晚因日军迫锦，将省府迁址据锦县十数里之杨新村金厂堡。当晚我公安队与日主力军在白骨河激战，毙敌航空及步兵大尉各一，死日兵无算。3日拂晓，日军取包围策略，装甲轻便汽车六七十辆，由左翼袭来，骑兵七八百名由铁路南急进，主力有甲车两…

  • 1932年1月9日《申报》：哈尔滨息，6日晨8时，马占山由海伦至松浦镇，日人百武中佐、林官崎两少佐、驹井顾问等往晤。午后2时，马至哈与张景惠谈，闻仍促马回龙江省垣，主持军政，但马已否允诺，及何日返龙江未悉。（8日专电）

  • 1932年1月9日《申报》：天津息，日武装兵60名，分成10余小组，8日下午2时在中日交界巡行示威，嗣拟入华界，在东南城角被警阻止，悻悻折回。（8日专电）

  • 1932年1月9日讯：国民政府令免教育部政务次长陈布雷本职，任命段锡朋为教育部政务次长；在教育部部长朱家骅未到任以前，由段锡朋暂行代理部务。

  • 1932年1月9日《申报》：北平息，前所日军1600余名，今晨10时，搭榆关东开材料车开绥中，今晨东行之101次客车，旅客均受日军威吓。日军再东新庄检查时，有警察29人，均被囚一室。（8日专电）

  • 1932年1月9日讯：张发奎第四军到达柳州，27日到桂林，2月1日全部集中全州。

  • 1932年1月9日《申报》：北平息，热河我原驻军第5旅，与退往朝阳一带之张树森骑兵旅及义勇军，合计七八万人，日如来攻，颇可应战。（8日专电）

  • 1932年1月9日《申报》：北平息，榆关电，日嘉村旅团7日由锦朝线开10余列车，向上齐台义县前进，图占北票，进攻热河。我骑兵第3旅张树森部，共四团，集中北票一带。日军以飞机掷弹、机枪扫射，及大炮轰击对其猛攻，致进退维谷。现张部正死力抵抗，伤亡甚众，死尸枕藉，恐将全部牺牲。（8日专电）

  • 1932年1月9日《申报》：东京讯，日人对于美国最近照会态度，因政友会内阁之是否留任，尤在未定之天，故今夕尤觉难于确悉。惟外部发言人声称，日本准备重行辨明其在满行动，不能适用非战公约与九国公约，日政府并拟发一新宣言，重申日本再满无领土之野心。（8日国民社电）

  • 1932年1月9日讯：外交部照会日使重光葵，中国政府对日本在东北组织的伪政权机关和设立之伪交通委员会概不承认。

  • 1932年1月9日讯：日军骑兵第27联队联队长古贺传太郎率所部90余人在锦西以西扫荡时，在江家屯附近遭到以刘纯启（绰号亮山）为首的锦西抗日义勇军和锦西民众武装2000余人的包围，激战中，古贺联队长等40多人当场毙命。

1932年01月08日

发表于 2021-01-08 更新于 2021-04-05 分类于 局部抗战(1931-1937)

  • 1932年1月8日讯：美国政府援《九国公约》照会中日两国政府，声称：“凡中日两国政府或其代表所订立之任何条约或协定，足以损及美国或其人民在华条约上之权利，或损及中国主权独立或领土及行政之完整，或违反国际上关于中国的政策，即通常所谓‘门户开放’政策者，美国政府均无意承认。”

  • 1932年1月8日讯：北平国立七院校教职员因积欠薪金五个月，派代表赴京索薪。北平中学教职员亦派代表赴北平市府索薪。

  • 1932年1月8日讯：杭州中等以上学校学生抗日救国联合会请愿团代表47人向国民政府、行政院及外交部请愿，要求即日出兵收复失地，实行革命外交，宣布对日方针，惩办张学良，保护民众救国运动。

  • 1932年1月8日讯：南京金陵大学学生500余人赴行政院请愿，要求政府即日宣布对日外交方针，以实力援助东北将领，无结果。9日全体罢课，决定促汪、蒋、胡入京。

  • 1932年1月8日讯：上海总工会电国民政府，要求出兵收复失地，宣布对日方针。按：上海总工会系由上海市南、北两总工会合并而成。

  • 1932年1月8日讯：国民政府令免中央大学校长朱家骅本职，任命桂崇基为中央大学校长。

  • 1932年1月8日《申报》：北平息，黄显声今晚到平，即谒张学良报告日军前进及我方损失情形。（7日专电）

  • 1932年1月8日讯：国民政府令：所有对于电报及新闻施行检查之事一律取消。

  • 1932年1月8日《申报》：北平息，此次日军犯锦，我方死伤千余，暴尸原野，无人掩埋。于凤至等组织华北妇女救国会，商妥红十字会，即派队出关掩埋，经费由该会担住。（7日专电）

  • 1932年1月8日《申报》：纽约讯，《纽约时报》今日华盛顿访电称，列强对日，现将用单独交涉之形式，以世界外交压力加诸日本。此种交涉将切实声明列强在华之条约权利，并声明满洲乃中国整个的一部分，列强此举似欲由可能的各方面进行谈判，至获有满洲问题之永久解决法而后已云。（7日路透社电）

  • 1932年1月8日讯：外交部声明，否认1905年中日密约，谓“我国自始即否认其事，嗣后亦屡经驳斥，早成死案，有案可稽”。

  • 1932年1月6日讯：国联“满洲调查团”委员名单已确定，有英国李顿、法国克劳德、美国麦考益、德国希尼、意大利马柯迪，李顿为团长。21日，该团正式成立。

  • 1932年1月6日讯：湖南学生抗日救国会在长沙举行抗日救国大会，到50余校约二万人。大会通过全国一致团结抗日、请发给各校学生枪 支、全国总动员出发东北等决议案。
