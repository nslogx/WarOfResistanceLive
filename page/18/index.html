1932年12月17日

发表于 2021-12-17 更新于 2022-03-11 分类于 局部抗战(1931-1937)

  • 1932年12月17日讯：太原一师、成中等校学生千余人，为一师开除学生事赴省府请愿，被军警镇压，伤14人。

  • 1932年12月17日讯：刘湘、刘文辉两军激战竟日，双方伤亡甚重，刘湘到荣县指挥，潘文华师到乐山对岸之笋子山，田颂尧师到仁寿清水镇，刘文辉部退井研、乐山、仁寿。

  • 1932年12月17日讯：刘茂恩、胡宗南、萧之楚、范石生等四师奉命入陕“剿共”。是日，刘、萧两师已过陕西鄠县以西。

  • 1932年12月17日讯：红四方面军徐向前部由陕西城固南进，越大巴山，先头部队于18日进入四川通江县境。蒋介石电令田颂尧派兵于川北堵截。田部分两路出动，刘汉雄率三团开广元；李炜如率四团开通江、南江。刘存厚亦派一旅防边。

  • 1932年12月17日讯：辽宁日参事官成泽直亮同指挥官山岸等率日伪军自凤城孙家店进入岫岩境。18日，辽南抗日义勇军司令刘景文发动岫岩关门山战斗，活捉成泽直亮。

  • 1932年12月17日《申报》：北平息，义勇军穆文明部千余人，14日夜猛攻伪奉山路青堆子车站，与伪警及日宪兵约百人激战半小时，占领该车站。伪警死伤17名，车站被焚毁。日甲车赶由沟帮子往援，与义勇军激战四小时，义勇军向胡家窝棚引退。（16日专电）

  • 1932年12月17日《申报》：北平息，日政府欲使伪满洲国在事实上独立，所取大政策如下：1）日军负责以全力消灭东北义勇军及反满洲国军队；2）使“满洲国”编成国防军十个师团，由日人操纵。军费由“满洲国”发行第一至第三等建国公债，每年至少一亿元，全数由日本收买，军器由日贷之，或由辽宁兵工厂存品发给，再偿还之。（16日专电）

  • 1932年12月17日《申报》：北平息，前在中东线失败之救国军七千余，拟拥戴濮炳珊，联络东路邓文、才鸿猷、南廷芳等，再图总攻，救国军士兵誓死抗日到底。（16日专电）

  • 1932年12月17日《申报》：北平息，苏炳文电平报告，15日抵莫斯科，拟在俄京（指莫斯科）勾留一周，俟领到出境护照先到德国，再转日内瓦。苏部退入俄境四千余，一部已抵大黑河，一部已绕道离开东北，大部均投马占山，继续抗日。（16日专电）

  • 1932年12月17日讯：宋庆龄、蔡元培、杨杏佛、黎照寰、林语堂等在沪发起组织中国民权保障同盟，宣言称该同盟之目的：一、为国内政治犯之释放与非法的拘禁、酷刑及杀戮之废除而奋斗，本同盟愿首先致力于大多数无名与不为社会注意之狱囚；二、予国内政治犯以法律及其他之援助，并调查监狱状况，刊布关于国内压迫民权之事实，以唤起社会之公意；三、协助为结社集会自由、言论自由、出版自由诸民权努力之一切奋斗。是日，以筹委会名义代电蒋介石、宋子文、于学忠要求即日释放在平被非法拘禁之学校师生许德珩等。

1932年12月16日

发表于 2021-12-16 更新于 2022-03-11 分类于 局部抗战(1931-1937)

  • 1932年12月16日讯：山西省立一师因校方开除学生杜连秀等五人，向教育厅请愿无结果，是日联合女师等七校发动驱逐教育厅长冀贡泉运动，沿街遍贴驱冀标语。

  • 1932年12月16日讯：红十六军孔荷宠部第七、九两师由赣万载入鄂东。

  • 1932年12月16日讯：国民党南京市党部呈请中央撤刘湘职，并通电全国共起制止刘湘用兵。

  • 1932年12月16日讯：江苏中等学校教职员联合会临时代表大会决议赴教育部请愿发清积欠省校经费四个月。

  • 1932年12月16日讯：李济深再电蒋介石坚辞训练总监职。军事委员会、国民政府、蒋介石先后慰留。

  • 1932年12月16日讯：国民党三中全会首次大会，蒋介石主席，决议组织特种外交委员会，推戴季陶、宋子文、于右任、孙科、顾孟馀、王正廷、朱培德、朱家骅、伍朝枢为委员，并指定外交部部长、次长参加，由宋子文召集。

  • 1932年12月16日讯：蒋介石邀梁漱溟咨询对改进社会及农村建设等问题。梁曾于15日在中央大学农学院讲“村治问题”。

  • 1932年12月16日《申报》：北平息，热边开鲁朝阳等县，近日发现日人收买之蒙匪，扰乱地方，已有数名被捕，供出扰乱热境阴谋。热境以外蒙匪，均在打通路通辽钱家居一带，由日人供给枪械粮饷。日人计划，拟明春开始攻热河。（15日专电）

  • 1932年12月16日《申报》：北平息，王德林部迭与敌军激战且多肉搏，受伤者众，因无医乏药，均以木贼草药为解之方。随处露宿，饮雪卧冰以树皮为窝铺。（15日专电）

  • #抗战影像#“一·二八事变”中，一队日本海军陆战队员在占领一座吴淞口中国守军炮台后高声欢呼。

  • 1932年12月16日《申报》：北平息，辽西义勇军王理锋部之天下好率队千余骑，在康平彰武边境等防地。据本月三日，有日军三百名，督饬伪民团五六百人，自康平来袭，激战约一昼夜。伪民团不支溃退，日逆伤亡甚众，向康平方面退却。（15日专电）

  • 1932年12月16日《申报》：北平息，东边自卫军22路28路，均在安图抚松濛江一带活动。前得唐聚五秘令，佯装与日方妥协暂定条件，为接济我方大洋十万元，军衣四万套，嗣即派藤田少将等九人，来我军点名。义勇军窥其毫无诚意，即将该九人扣押，日军数次来袭，均被击退，现已改树自卫军旗帜，与敌抗拒到底。（15日专电）

  • 1932年12月16日《申报》：南京息，伍朝枢谈，中俄复交，为我国外交上之新开展，转移国际目光，打开沉静局面，大体言之，自属有益而应做之事，国际的影响如何，此时尚不能预测。须知东北失地，非恃中俄邦交之恢复，即能驱出日军，观察一股国民之意识，如美总统之改选与中俄之复交，欢舞之忱，一若外交成功，即可高枕无忧，岂非大谬。（15日准点）

  • 1932年12月16日讯：全国各界救国团体联合会电请第十九路军出关杀敌，收复失地。

  • 1932年12月16日讯：东北义勇军电三中全会，要求集全国力量抗日。

1932年12月15日

发表于 2021-12-15 更新于 2022-03-11 分类于 局部抗战(1931-1937)

  • 1932年12月15日讯：国联特别委员会通过英、法、捷克、西班牙、瑞士五国起草委员会之决议草案，其要点为：一、以李顿调查团报告书为调解的基础；二、重行确定3月11日之决议案；三、提议以十九国特委会为调解委员会，而辅以中日代表；四、宜请美、苏参加调解工作。但草案既未规定制成最后报告书的期限，更无阻止日本侵略办法，为日本预留狡辩余地。17日，国联中国代表团发表宣言，陈述中国政府不能接受十九国特委会决议草案并要求加以修改。日本拒绝接受。

  • 1932年12月15日讯：陈济棠召集粤党政要员讨论时局，决议力促三中全会实现“防止独裁再起”，“联合肃清共患”、“切实长期抗日”三要案，并提议分权共治及扩充西南政务委员会各部会组织案。

  • 1932年12月15日讯：全国内政会议历时六日，共开大会七次，是日下午闭幕。通过“地方自治”、“整理土地”、“确定地方卫生制度”、“改良礼俗”、“执行调查统计工作”等议案400余件，审议建议案200余件，并发表宣言。

  • 1932年12月15日讯：国民党四届三中全会在南京开幕，到执监委百人，阎锡山、胡汉民、汪精卫、冯玉祥、张学良、李济深、程潜、陈济棠、李宗仁、白崇禧等均不出席。于右任主席。下午预备会议，推蒋介石、孙科、于右任、顾孟馀、丁惟汾、戴季陶、居正为主席团。

  • 1932年12月15日讯：东北义勇军第二军团李纯华部运弹部队西进突破南满铁路，试验爆破器械，颠覆日军军列一列。次日拂晓，日军炮击东西蒋官屯及附近村庄进行示威报复。

  • 1932年12月15日《申报》：天津息，法租界30号路大公报馆后门13日晚9时有人投一弹，无损伤，似系锄奸团所为。13日下午2时，天祥市场四楼扶梯发现纸裹炸弹，未爆，发当由法工部局取走。（14日专电）

  • 1932年12月15日《申报》：北平息，日军第八师团一万余，近集中伪丰山线，拟一举“消灭”义勇军郑桂林部，7日郑部派少数部下，进攻前卫，与日军接触。郑部全体将士万余，9日起分在前卫、前所、绥中等处，与日军激战，至今未分胜负。（14日专电）

  • #抗战影像#“一·二八事变”期间，一支被派遣到上海的法属印度支那殖民地部队，正在前往上海法租界。

  • 1932年12月15日《申报》：北平息，救国军孙震甲部，8日夜袭击大石桥，9日晨将该处围绕，一部绕道前所，与铁血军相遇，夹击该地敌军。敌后退，前所被我占领，嗣恐敌榆关大队来援，退向防地。毙敌数十，获枪40余，铁盔10余顶，军需品无算，我方亦有伤亡，损失机枪及步枪若干。（14日专电）

  • 1932年12月15日《申报》：北平息，日机11日飞至朝阳县南岭一带侦察半小时而飞去。朝阳县境发现蒙匪，系受日方贿买，意在寻衅。驻军持镇静，未生冲突，日方近在各县收买蒙匪、流氓及地痞，附丛者多。汤玉麟已严密防范，开鲁县附近安静，日方屡次寻衅，我均置之不理。（14日专电）

1932年12月14日

发表于 2021-12-14 更新于 2022-03-11 分类于 局部抗战(1931-1937)

  • 1932年12月14日讯：据《大公报》讯：伪满实行鸦片公卖，鸦片专卖公署及分署已分别成立，开始营业。

  • 1932年12月14日讯：新加坡华侨开设之华商、和丰和华侨三家银行合组华侨银行，在国内设上海、厦门、香港三分行。控制东南亚许多地方华侨的信贷和汇兑业务。

  • 1932年12月14日讯：东北抗日各军代表刘丕光、王子耀等12人以日本伪造东北人民请求独立函件3000余件寄日内瓦，特电国联大会，称自九一八事变以后，东三省人民先后牺牲于日人之手者，已达5.8万余人，“东三省3000万人民誓死不承认满洲国，务希大会予以正义公平之裁判”。

  • 1932年12月14日讯：辽吉黑热义勇军后援会向国民党三中全会建议武力抗日，收复东北失地。

  • 1932年12月14日讯：东北民众自卫军军官学校教育长苗可秀率学生大队和自卫军大刀队在凤城和龙王庙之间伏击歼灭日伪军百余名。

  • 1932年12月14日讯：江苏淮阴点心业200余家罢市，反对政府启征营业税。17日，经商会会长劝导，各代表答应秋冬两季缴税40元，并于次日复业。

  • 1932年12月14日讯：行政院代院长宋子文就中苏复交事发表谈话称：“两民族间自由往来之途径，已清除一切阻碍，深信定能于实现远东和平上大有助力。”南京《新京日报》著文称“中俄复交与反 共判若两事”。

  • 1932年12月14日讯：蒋介石在南京各界迎蒋大会上演说，声称：“欲民族复兴，须从民族固有之精神，即恢复礼义廉耻作起。”

  • 1932年12月14日《申报》：北平息，关东军司令官武藤，因黑省苏炳文部退却，现调往黑茂木旅团开回锦州，企图向锦西义勇军总攻，并将日军驻在地点，向锦朝支路推进，为初步计划。（13日专电）

  • 1932年12月14日《申报》：北平息，救国军苏华轩部，10日晨在锦州与日方战斗，因日机猛烈轰炸，全部退至北镇整理，待机反攻。（13日专电）

  • #抗战影像#“一·二八事变”期间，刚刚抵达上海执行保护使馆和侨民任务的一支意大利陆军部队，正在接受意大利侨民的欢迎。

  • 1932年12月14日《申报》：北平息，王德林7日电到平称，3日夜大雪，平地积雪没胫，日军五千，飞机二十余架，甲车数列，向我军迫近。我军沉着应战，经9小时苦战，因日军甲车及飞机轰炸过猛，我军少有伤亡，暂退一面坡固守，调加生力军反攻。（13日专电）

  • 1932年12月14日《申报》：北平息，榆关东门外日军第五联队，撤往王家屯，在前所车站驻防，人数约八百余。日军第五联队长谷仪，12日午返锦县，现驻榆关日军共四百余，车站仍有驻防日兵。秦皇岛日兵母舰一艘及驱逐舰朝颜号，日前撤回营口旅顺。（13日专电）

1932年12月13日

发表于 2021-12-13 更新于 2022-03-11 分类于 局部抗战(1931-1937)

  • 1932年12月13日讯：废止内战大同盟会代表林康侯等赴京，向国民党三中全会请愿制止内战。

  • 1932年12月13日讯：河北省商会代表电国民党三中全会及财政部，请求取消营业税新税率。31日，财政部批示已咨行冀省府转饬核议。

  • 1932年12月13日讯：陕省干旱日烈，灾民400万，死亡逃徙日有增加，灾情严重，各县灾民代表是日在西安开紧急会议，决推郭子兴等赴南京向国民党三中全会请愿：一、履行二中全会决议案，速发陕灾公债800万元；二、豁免灾区粮赋及一切苛捐杂税；三、所有驻军一律由中央直发饷糈，以免同归于尽。

  • 1932年12月13日讯：外交部长罗文幹发表中苏复交宣言，并公布中苏换文。

  • #国家公祭日# 我有所念人，隔在远远乡。我有所感事，结在深深肠。乡远去不得，无日不瞻望。肠深解不得，无夕不思量。况此残灯夜，独宿在空堂。秋天殊未晓，风雨正苍苍。不学头陀法，前心安可忘。

  • 1932年12月13日《申报》：北平息，马占山在嫩江附近，所部骑步兵万余，正集中整顿，将与濮炳珊邓文才鸿猷各部联络反攻。（12日专电）

  • #抗战影像#“一·二八事变”期间，一队日本陆军士兵在攻下一处据点后高声欢呼，其中也有武装日本侨民。

  • 1932年12月13日《申报》：北平息，苏炳文赴欧，拟在德意法各国略勾留，再转南洋一带，向我侨民报告日人侵略东北真相，下月底到平。（12日专电）

  • 1932年12月13日《申报》：哈尔滨息，据日人方面消息，义勇军占据哈尔滨西北约百里之明水镇，驻安达之“满洲国”军已奉命前往夺回该地。（12日路透社电）
