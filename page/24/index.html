1932年11月01日

发表于 2021-11-01 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1932年11月1日讯：沪回教代表因上海北新书局发行《小猪八戒》一书，侮辱回教，在京向中央请愿，要求惩办编辑人员，封闭北新书局。

  • 1932年11月1日讯：在沪被捕与陈独秀案有关之共产党人李荣生、苏正海、饶志陆、陈善甫、纪维方、刘志福、吴俊臣、刘阿芳、陈王氏（即帅孟奇）、吴陈氏、朱彩弟（即朱镜如）11人，由沪市公安局押解南京交江苏高等法院，寄押江宁地方法院候审。

  • 1932年11月1日讯：　张群在京向川省各军驻京代表详询川局情形及各军现状后，即与戴季陶、石青阳、顾孟馀等会商解决川事办法。2日乘轮赴汉向蒋介石报告。

  • 1932年11月1日讯：刘湘部继10月31日进驻荣昌、合江之后，是日又占隆昌。杨森部进驻安岳。

  • 1932年11月1日讯：国民政府参谋本部国防设计委员会成立。由军事委员会委员长蒋介石兼任委员长，由秘书长翁文灏、副秘书长钱昌照负实际责任。主要任务是从事军事、国防、财经、文教、工矿、交通、农林等方面的调查，写出专题报告，供蒋介石等作决策时参考。

  • 1932年11月1日讯：行政院会议决议：一、慰留鄂省府主席夏斗寅；二、电令川、康军及达赖停止军事行动。

  • 1932年11月1日《申报》：东京讯，今日探悉东三省日军当道现派代表赴满洲里，与苏炳文谈判释放日俘事。查现尚未释之日俘，计一百七十名皆系男性。至于妇孺一百十人，则已由满洲里俄领事向苏接洽，送入俄境矣。（31日路透社电）

  • 1932年11月1日《申报》：北平息，义勇军再占虹螺岘为根据地，向锦县城进攻，日本以飞机大炮轰击义勇军，锦县城外10余里之村庄民房，轰毁殆尽。义勇军正分途向锦县城进攻中，连日均有激战，日方已由兴城调军五百名往援，大战即在目前。（31日专电）

  • #抗战影像#两名日军正在乘坐橡皮筏渡河。

  • 1932年11月1日《申报》：北平息，月初日军以五个师团、飞机百余架，猛攻通化，肆意轰炸，唐聚五部弹绝势孤，尽弃通化恒仁等16县，退守安图抚松蒙江，待机反攻。13日，唐率第一旅长高伯翔部五千余人，往横道河子督战，因日炮猛烈，我弹不济退却。高旅长阵亡，唐仍奋勇指挥，在苏土崖等处，击落日机7架，日兵死400余名，血战三昼夜，日方派马龙骧到部劝降，许予百万日金，唐将马监押，激励士兵，誓死相拼，唐左目受创。（31日专电）

  • 1932年11月1日《申报》：北平息，苏炳文自海拉尔电平云，据濮炳珊29日电称，克山之敌，27日倾巢而来，在鳌龙沟与我步兵二团骑兵四团，及卫队营激战亘日，毙敌甚多，珊由由腰兴屯率队开到，将敌击退。拟29日解决贝子府之敌，该敌28日向我西兴屯阵地猛攻，经我步三团及骑二团迎头痛击，毙敌甚多。我骑二团亦伤亡20余名，刻令步兵严守阵地。步骑一团向敌迂回，期一举歼灭之。自珊部与敌接仗以来，敌人受打击，颓丧已极，马主席联络妥协，请电各方勿信日人伪宣称。（31日专电）

  • 1932年11月1日讯：东兴县城之敌指挥优势兵力，对巴彦游击队发动猛烈反扑，游击队伤亡50余人，余部突围，突围中赵尚志左眼受重伤，视力丧失，眼下颧部留下了三个新月型伤痕。

1932年10月31日

发表于 2021-10-31 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1932年10月：蒋介石以豫鄂皖三省“剿总”总司令名义发布训令，颁发《匪区内各省农村金融紧急救济条例》，决定在豫、鄂、皖、赣四省农民银行成立之前，先在“剿总”内部设立农村金融救济处，负责监督农村金融“救济事务”。

  • 1932年10月31日讯：教育部通令各省、市，免收入关求学青年学费。

  • 1932年10月31日讯：闽北红一、五军团会同进占黎川东南之红三军团逼南丰。

  • 1932年10月31日讯：马占山军与苏炳文军配合进攻齐齐哈尔。

  • 1932年10月31日讯：国联中国代表颜惠庆、顾维钧、郭泰祺致电外交部长罗文幹，请转达山东韩、刘及四川二刘立即停止内争，以免日方利用，而利外交进行。

  • 1932年10月31日讯：宋庆龄向国民党中央提议设立特种委员会，专理“政治犯”事件。

  • 1932年10月31日讯：戴季陶在中央纪念周会上报告治川办法：治标，根据民国十七年（1928）11月国民政府发表之治川纲要10条；治本，根据民国十一年（1922）9月孙中山致川各将领之电令，以废除内战、振兴实业两点为原则。

  • 1932年10月31日《申报》：北平息，吉救国军王德林电平称，宁古塔已完全占领，刻正包围宁安，不日即可攻下，盼速接洽棉衣。（30日专电）

  • 1932年10月31日《申报》：北平息，救国军第四军团总指挥就震东电平称，16日率第一军刘桂堂部约千余人，在通辽附近水里圈阁家园子利里屯一带，与日军激战，双方死亡均众。我方又向开鲁调来马队五百余，炮手队一队，约百余人，大炮四尊。21日晨，突有日军约二千人，向我攻击，我部张旅出迎，接触至午，日军完全破我包围，午后四时，敌夺路而逃。毙敌百余，俘虏43名，马74匹，枪械弹药无算。（30日专电）

  • 1932年10月31日《申报》：北平息，辽吉黑民众后援会会长，接前方电称，顷据段席珍、姜纪昌26日电称，顷据张文祥来部报称，伊于上月20日抵北镇，23日、25日、28日三日，率五千自卫军，与敌肉搏血战，攻下北镇全城。计是役毙敌官兵20余名，生擒敌兵四名，侦探二名，获步枪40余枝，子弹数千发，钢板载重汽车两辆，我军共伤亡70余名。（29日专电）

  • #抗战影像#一队侵占我东北的日本关东军正在滑雪行军。

  • 1932年10月31日《申报》：山海关息，锦州西北附近一带义勇军，有五六千名，现已联络完毕，企图日内进攻锦州县城。驻锦州日军日来戒备极严，并对出入锦城行人，严加检查。26日早拂晓有一部义勇军，与日军接触，枪声不绝，炮声隆隆。至早10时，义勇军撤去，城门始开，日军击死无辜人民十余名，现住民惶恐异常。27日早，由东来榆日军少将高级参谋一员，30日早车去天津。（30日专电）

  • 1932年10月31日《申报》：北平息，救国军董荣久部一万一千余名，26日分三路向锦州猛攻。第一旅李世朋部第二支队侯璧峰部三千余名，攻锦州西门。第一旅王永良部及第四支队展国枢部二千余名，攻北门。第三旅曹振国部及第一支队李荣禄第二支队宫仲九部五千余名，攻东门及东站等处。27日晨，自卫军星九鼎路雨田率部四千余名增援，与日军展开血战，双方均伤亡颇众。敌机10余架，轮番轰炸，坦克车装甲汽车等，皆向救国军猛攻。28日晨，敌方由石山站开来甲车一列，及援军三千余名，救国军虽腹背受敌但力战不退。29日晚北门被王永良部攻破，并占伪丰山路车站。李世朋、侯璧峰率部绕北门援助，总攻锦城、室师团司令部，已令全军向北门集中，大虎山沟帮子一带，日军现已大批开到，向我军迎击，董亲督师，誓死攻袭，决不后退。（30日专电）

  • 1932年10月31日讯：蒋介石电令财政部转饬各海关扣留入川军火，并令军政部停发运输护照。

1932年10月30日

发表于 2021-10-30 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1932年10月30日讯：日本关东军司令部由沈阳移长春，另设特务机关于沈阳，以板垣征四郎少将为特务机关长。

  • 1932年10月30日讯：军政部奉蒋介石电谕，以陶峙岳升任第八师师长。

  • 1932年10月30日讯：全国各界救国团体联合会在沪成立。主席团主席张军光致开会辞称：“本会成立后之唯一任务，便是切切实实的为救国而抗日。”

  • 1932年10月30日讯：废止内战大同盟会北平分会成立，胡适任临时主席。胡致开会辞，称该会为“中国之生命线”。

  • 1932年10月30日《申报》：北平息，距洮南城六十里外，时有义勇军与日军接触，16日晚洮河水陡涨，日军二百余抢堵，因水势过猛，将堤冲溃，抢险日军险遭灭顶，遭难村落，有20余处，房屋皆被冲毁。（29日专电）

  • 1932年10月30日《申报》：北平息，冯占海率部万余人向长春推进，联络该部前往长春附近工作队伍，大举进攻长春，已抵海拉哈果宝山石庙一带，距长春约二百余里。（29日专电）

  • #抗战影像#“一·二八事变”中，在上海的日本侨民正在欢迎一支侵沪日军部队进入上海市区。

  • 1932年10月30日《申报》：北平息，苏炳文27日由海拉尔来电云，濮炳珊24日率步兵进至泰安镇迄西腰兴屯西端，猝然与炮二门步骑联合三百余名之敌人相遇，激战甚烈，毙敌三十余名，敌退走。翌日复来，经我痛击，毙敌10余名，狼狈逃窜。以巴贝子府为据点，该蒙人亲敌拒我，容纳日军，否则可将该敌完全歼灭矣。此两日得敌机枪、骑枪及军需品甚多，一两日即将该敌完全解决，长驱直进，我藏旅在富海附近，何旅向寗年挺进，李振华旅已将联络，会攻寗年，军心民气，异常振奋。（29日专电）

  • 1932年10月30日《申报》：齐齐哈尔息，张殿九军之一部，约五百名，突出现于齐齐哈尔城外嫩江之对岸，准备渡河进逼齐齐哈尔，日军再西面外旧机场列炮，于27日下午四时，开始向张军炮轰。（29日电通电）

  • 1932年10月30日讯：朴炳珊所部收复克山县城，但在进军齐齐哈尔时，在克山西南八贝子府被一团日军骑兵阻击十余日无法前行。

  • 1932年10月30日讯：国民党南京市党部呈中央党部，请依法严办陈独秀，不准保释；并通电全国，称蔡元培、杨杏佛等请保释陈“系徇情庇护，为反 动张目”。

1932年10月29日

  • 1932年10月29日讯：甘肃省府政务会议决议预征1933年田赋。

  • 1932年10月29日讯：江都反“清赋”运动领导人葛广兴、陈友善、罗才良、杨德昌、刘玉山、卜登云六人经江苏省府委员、省保安处长李明扬等亲自审讯，是日被杀害。

  • 1932年10月29日讯：立法院通过《国际海上人命安全公约》。

  • 1932年10月29日《申报》：北平息，义勇军占据义县城后，即向七里河子进攻，日机向该处爆炸，战事激烈，日列车26日驰往七里河子东站，以重炮掩护日军作战，义勇军死守喇嘛寺，日军将民间村庄，全行轰毁，战事迄今未停止。（28日专电）

  • 1932年10月29日《申报》：山海关息，25日日军骑兵二百余名，步兵一团飞机五架，开往千金寨南边，进击辽东义勇军。总指挥黄宇宙亲率卫队与之接触，黄部凭山以守，虽经一昼夜，日军所有飞机大炮俱失效用，最后黄部卒将日军击退，死伤未明，黄部得马七匹，步枪48杆。（28日华联社电）

  • #抗战影像#三名在屋顶上的日军，机枪手正手持大正十一年式轻机枪瞄准目标。

  • 1932年10月29日《申报》：北平息，苏炳文昨电平称，日本松本师团前26日午，派爆炸机数架，到海拉尔抛掷重磅炸弹，散放松本师团长署名传单，声言将派攻城重炮，大股军队，多架爆炸机，实行粉碎札蓝屯博克图海拉尔满洲里等处，不成灰烬不罢等语。查上列各地，均非战斗区域，竟有此等残暴宣传，其毒辣阴狠，足以危害中外商民生命财产，视屠杀如儿戏，非特有损日本军队之价值，实亦大伤国际人道之信条。（28日专电）

  • 1932年10月29日《申报》：齐齐哈尔息，本日上午10时，由齐齐哈尔出发之801号列车，行至五家站，忽有义勇军三百名，从50米之近处，猛袭松本某大队五中队横泽特务曹长以下23名所乘之客车，并跳入车内，欲击杀下士官兵。双方互以手榴弹及其他，大举格斗，义勇军未能达到目的。遭难列车，上午11时折还齐齐哈尔，日军战死兵四名，重伤八名，轻伤无名。（27日电通社电）

  • 1932年10月29日讯：赵尚志率领的巴彦游击队在“绿林好”部队配合下，不到半小时即袭取了东兴县城。

  • 1932年10月29日讯：刘文辉致电中央表示愿将所部悉交刘湘，不愿延长内战。

  • 1932年10月28日讯：蒋介石自汉口抵长沙，部署“剿匪”。

  • 1932年10月28日讯：闽省府委员因财政困难向国民政府总辞职。

  • 1932年10月28日讯：蒋介石之代表张钫、刘峙之代表刘耀扬，在济南与韩复榘商鲁事，张转达蒋意：令韩部包围掖县、莱阳等县之军队后撤，以便让刘珍年部离鲁。韩表示服从。

  • 1932年10月28日《申报》：天津息，孟昭炎有电到津后，顷据前线归来某君谈，义县附近，自11日发生战事，国民救国军孟昭炎等部及其他友军，12日迫近县城猛攻，前传之13日克复，当系指敢死队混入城内活动，此后连日剧战，至15日遂克义县。闻国民救国军19日由北票等处开到大批援队，自晨四时至晚九时，肃清残敌。同时，在锦朝线上蔡台七里河子间掘毁路轨，割倒电线杆，以牵制驻锦敌军，在此十数日间，救国军似有屡进率退模样。（27日日联社电）

  • 1932年10月28日《申报》：北平息，救国军董荣久部，25日全军一万一千余名，分三路向锦州猛攻，第一旅李世明部，及第二支队侯璧峰部三千余名攻锦西门。第三旅曹振国部及第一支队李荣禄部，第三支队宫仲元部五千余名，进攻东门及车站等处，第二旅王永良部，及第四支队展国枢部三千余名，攻北门。26日晨10时许，仍与日军肉搏中，双方伤亡颇众。自卫军邢九鼎路雨田，率部四千余名，11时增援。董部副官长关廷购办大批棉衣，今晚运赴前方应用。（27日专电）

  • 1932年10月28日《申报》：北平息，苏炳文自海拉尔电平云，濮炳珊15日在拜泉誓师，当即整军向泰安镇进发。因乌眼河泛滥，道路泥泞，乃架设军桥。17日以骑兵集团挺进，占领傲龙沟，并破坏铁路电信。我官兵奋勇杀敌，是役毙敌数十名，得火车两列，军用战利品无算。19日夜主力全部渡河，20日拂晓开始攻击，即日占领泰安镇。是役毙敌四十余名，获坦克车两辆，械弹无算。同晚克山之敌数百名在甲车野炮掩护之下，向我逆袭。我官兵奋不顾身，激战七小时，卒被击退。敌人伤亡枕籍，我方亦有少数伤亡。现我军已遮断齐克路，日内可完全解决，然后直攻龙江，规复国土可待。（27日专电）
