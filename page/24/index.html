1932年01月03日

发表于 2021-01-03 更新于 2021-04-27 分类于 局部抗战(1931-1937)

  • 1932年1月3日讯：福州日侨水户参雄夫妇，晚9时在日俱乐部宿舍暴毙，日居留民谓系华人所为。4日，日舰圆岛陆战队100余人在福州登陆，并由马江运来水兵80余人，声言保侨。5日，福建省府议决限晚8时起36小时内缉到凶手。

  • 1932年1月3日讯：全国医师联合会电国民政府，请迅速以实力援助东北抗日将领马占山。

  • 1932年1月3日讯：东北民众反日救国会电国民党中央和国民政府，声称：“我东北民众固犹为国家之民众也，未知政府负责诸公，尚有无有效办法解救此种危急。

  • 1932年1月3日讯：东北军前线下级军官署名发表第二次联合宣言，声明：“东北为中国之东北，非东北人之东北。故言抵抗，必须全国以整个力量赴之。”

  • 1932年1月3日讯：国民政府令：免国民政府文官长王树翰、代理文官长叶楚伧本职，特任魏怀为国民政府文官长；准免国民政府参军长贺耀组本职，遗职由吕超继任。

  • 1932年1月3日讯：何成濬、李鸣钟、徐源泉、夏斗寅等21将领电行政院，请对日速定大计，下令动员抗日。

  • 1932年1月3日讯：锦州地区的中国军队由山海关撤退到关内，通辽一带的骑兵第三旅撤向热河。日军第20师团占领锦州。

  • 1932年1月3日《申报》：福州息，2日下午，西公园开反日宣传游艺会，日领及圆岛舰长与东瀛校长，便服扯毁反日标语，被民众拥入市局，经军警保护，日方传两长有微伤。（3日专电）

  • 1932年1月3日讯：日军西进，占领辽宁连山，黄显声率警备队退兴城。4日日军占葫芦岛。5日陷绥中。6日下午到万家屯，距山海关仅九公里。

1932年01月01日

发表于 2021-01-01 更新于 2021-04-27 分类于 局部抗战(1931-1937)

  • 1932年1月1日：陈绍宽宣誓就任中国海军部部长，陈季良受任海军部政务次长，仍兼第一舰队司令。海军部总务司司长李世甲兼代常务次长。

  • 1932年1月1日讯：香港《破产条例》、《竞博税条例》公布施行。

  • 1932年1月1日讯：张景惠在关东军高级参谋板垣征四郎指使下在哈尔滨发表所谓《独立宣言》，宣布黑龙江省和东省特别区“独立”。

  • 1932年1月1日讯：张发奎第四军在广西南宁举行北上援助黑龙江马占山将军抗日誓师大会。3日，第四军第十二师分批由南宁出发，取道邕柳公路北上。

  • 1932年1月1日讯：日机轰炸锦州，投弹20余枚，军民伤亡七人。辽宁省政府出锦州移至滦州，驻锦州东北军全部撤至关内，沟帮子失陷。

  • 1932年1月1日讯：中国驻国联代表胡世泽会见国联理事会主席白里安，请国联采取手段，制止日军扩大侵华行动。次日，白里安电各国政府，询问对日军攻占锦州之态度。

  • 1932年1月1日《申报》：北平息，沈讯，营口盐款先后被日方提二百七十余万。（31日专电）

  • 1932年1月1日《申报》：北平息，锦州电，30晨，日军分三路猛攻胡家窝堡我军。我步兵第19旅主力，由中山号铁甲车掩护下，上午进退六次，阵地几经易手，战死三百余名，日军伤亡亦众。我左翼得义勇军助力，死守高平一阵线。俾与牛庄城联络，我八角台阵地，为日军炮骑联队冲破。我19旅23团副金大成，…

  • 1932年1月1日《申报》：北平息，日军炮骑联队千余人，昨日拂晓，猛攻我打通线归马山骑六旅，历三小时。经我还击，日军不支，退平康，同时日飞机三架掷火弹，我营房被焚一部。（31日专电）

  • 1932年1月1日《申报》：北平息，今晨打虎山东北，发现日骑兵，猛扑打虎山，经我军击退，毙日兵二十余，获马枪廿余支。（31日专电）

  • 1932年1月1日《申报》：天津息，沈讯，日军下总攻令后，各处站甚烈，伤亡亦多，。昨起将新由朝鲜调来之混成旅参加作战，向沟帮子进攻，其先锋部队过白旗堡时，与黄显声部警队激战，我兵器较逊，警士死伤达百五十余名。日骑兵昨下午四时侧击羊圈子、石山站间之三家子，激战二小时，敌未深入（31日专电）

  • 1932年1月1日《申报》：天津息，日军部讯，日飞机30午由营口飞向沟帮子，在盘山失事慎，飞机全毁，驾驶员副岛、冈山两名烧死。（31日专电）

  • 1932年1月1日讯：外交部长陈友仁发表对东省问题宣言，略谓：“本政府最急之任务即在于消灭战祸，并保主权，誓本此旨努力奋斗。前日政府已命令张学良固守锦州，积极抵抗，今后仍坚持此旨，决不稍变。即不幸而挫败，非所计也。”

  • 1932年1月1日《申报》：天津息，外人消息，营沟全线30无战事，惟盘山胡家窝铺中日两军，损失甚大，日铁甲车在白旗堡绕阳河开，被华军炮毁。30晚羊圈子有枪声，是否系日军袭来，未判明。（31日专电）

  • 1932年1月1日《申报》：天津息，30日晚，在羊圈子发生战事，已证明系日别动队与我19旅孙德荃部接触，约一小时后败退，更有一部日军，利用胡匪，向女儿河前进，意在扰乱我锦州后路。（31日专电）

  • 1932年1月1日《申报》：天津息，日军31午占领沟帮子，已证实，羊圈子大凌河，31午至晚，仍在争夺战中。（31日专电）

1931年12月31日

发表于 2020-12-31 更新于 2021-04-27 分类于 局部抗战(1931-1937)

  • 1931年：东亚毛呢纺织公司在天津成立，资本23万元，宋棐卿联合山东韩复榘创办。宋任董事长兼总经理。

  • 1931年：九一八事变后，中国民商抵制日货风潮剧烈，日本对华输入减少。据《申报》统计，本年9月比上年9月减少34.7％，10月减少59.7％，11月减少68％，12月减少63.8％。

  • 1931年：据《中国经济年鉴》载：本年钢产量1.5万吨，锰3.185万吨，钨矿砂6550吨，金12.85万两，煤2724.4673万吨，焦炭61.3863万吨，石油25.9632万桶，铜413吨，铅矿5996吨，锌矿1.4618万吨，锑矿1.1755万吨。

  • 1931年12月31日讯：胡汉民、孙科、冯玉祥、李济深、李烈钧、居正、程潜、唐生智、黄绍竑、张发奎、刘芦隐等24人联名在《申报》刊登《为发起筹备邓演达同志追悼会启事》，称“中国国民党第二届中央执行委员邓演达同志努力于国民革命，艰苦卓绝，任劳任怨，始终为实现三民主义而奋斗” …

  • 1931年12月31日《申报》：北平息，日军续增重兵来华，志在取锦，而锦为东北最后堡垒，关系全国安危，中央已急令锦州当局，严密防守。张之参谋长荣臻，已赴锦，对防守军事已有通盘计划。（30日专电）

  • 1931年12月31日《申报》：天津息，秦皇岛29晨到日舰5艘，30晨陆战队上岸示威，有开往山海关模样。日军火300余箱，内装炸弹炮弹枪弹，30晨5时半，挂北宁路15次车运赴山海关（30日专电）

  • 1931年12月31日《申报》：北平息，大沟之役，毙敌170余，掳10余，获枪10余支。我方因缺乏空军，死伤惨重。（30日专电）

  • 1931年12月31日《申报》：北平息，日军昨晚以铁甲车两列，坦克车三辆，由多门指挥，进攻胡家窝堡，与我义勇军及甲车队混战一夜。我军因炮火贫弱不敌，30晨5时退出胡家窝堡，集中沟帮子。（30日专电）

  • 1931年12月31日《申报》：北平息，日机昨在盘山站掷重弹数十枚，站落11，毁路房一间，余落城内。县政府炸毁，民房毁甚多，死伤人民无数。营沟支线已无中国军队。（30日专电）

  • 1931年12月31日《申报》：北平息，30晨沟帮子开炮声甚清晰，沟帮子情形混乱。（30日专电）

  • 1931年12月31日讯：国民政府致电国联，报告日军进攻锦州，情势越趋严重，请速采有效措施，制止日军进攻。同日，致电日本政府提出抗议，声明日军攻锦所造成的严重后果，日政府须负完全责任。

  • 1931年12月31日《申报》：北平息，日机今在打虎山掷弹四枚，日骑兵二三百人，进至打虎山。我军退至沟帮子，沟帮子居民悉数迁出。（30日专电）

  • 1931年12月31日讯：东北军下级军官在锦州前线发表联合宣言，谓日军攻锦，血战五日，东北军死伤枕藉，“自一中全会开会之后，三次转电中央，请发弹药接济，无一应者，是中央抗日能力，仅于一纸电文，数张标语”。东北将士，决心为东北而死，“望南方同胞，弗徒以空言作抵抗”。

  • 1931年12月31日《申报》：南京息，中央社平电，日军占盘山后，复于30晨7时，由盘山向沟帮子前进，同时日海军复派军舰，载运陆战队由旅顺开赴山海关，使我军腹背受敌，我驻锦军队，因之有一部分向后移动，以资抵御。（30日专电）

  • 1931年12月31日《申报》：北平息，今晚得悉张学良谕令锦州及附近军队撤回关内，以免日军当道借口扩大其军事行动于华北，盖鉴于天津之集结大批日军也。撤兵事已开始，闻辽宁省政府仍在锦州，仅留少数兵士以资保护，主队则完全撤退。（29日路透社电）

  • 1931年12月31日《申报》：天津息，驻大虎山东北军19旅孙德荃部，29晚开沟帮子。原驻沟帮子军队，29晚有6列车开锦州，铁甲车司令部，29晚由沟帮子移锦州，炮兵13团29晚由锦州乘5列车撤走，第12旅张廷枢部，29晚开始西移，在锦州各机关重要人员，亦多入关，锦州不致再有战事。（30日专电）

  • 1931年12月31日讯：新任外交部长陈友仁对记者谈，锦州驻军退入关内一事，过渡政府不负责任，应由张学良负责，因过渡政府迭令张学良坚守锦州。新政府成立后，亦必赓续此旨。
