1932年06月04日

发表于 2021-06-04 更新于 2021-07-19 分类于 局部抗战(1931-1937)

  • 1932年6月4日讯：总税务司梅乐和训令东北各关税务司，谓关款关系内外债基金甚巨，各税务司应遵照关税行政完整原则，严拒其他方面提拨税款或扰乱税务独立行政与事权独立。

  • 1932年6月4日讯：航空署增派航空第五队赴汉，第七队赴赣，“协剿”红军。

  • 1932年6月4日讯：军委会统一各师编制，军为军政部直辖单位，军长不兼师长，全国共48个军，96个师。

  • 1932年6月4日讯：国民政府令：派黄乃枢为邮政总局局长，派杨建平为邮政储金汇业总局局长。

  • 1932年6月4日讯：财政部长宋子文电汪精卫、蒋介石辞财政部长职。5日，汪复电慰留。

  • 1932年6月4日讯：在中共磐石中心县委和省委特派员杨 林的主持下，一支对外号称“满洲工农反日义勇军第一军第4纵队”，对内称为“磐石工农反日义勇军”的抗日队伍正式成立。队伍下设3个小分队，共30余人。中心县委组织部部长张振国任总队长。

  • 1932年6月4日《申报》：齐齐哈尔息，顷接急电，马占山系之邵平山，率部下千余，包围道达（译音）县城，日平山旅团与飞机队，昨午后向该方面出动，以飞机开始炸击马部。（3日电通社电）

  • #抗战影像#伪满洲国陆军辎重部队，使用马匹驮运装备。

  • 1932年6月4日《申报》：北平息，伪国编国防军16团，班长以上军官，由日人充任。（2日专电）

  • 1932年6月4日《申报》：蚌埠息，驻蚌航空第一队102号达格拉斯机，3日晨飞往光山轰炸“共匪”。9时许回蚌，机上所余35磅炸弹一枚脱系，落于繁闹之太平街上，炸死市民22人，伤41人。各界大愤，警备司令部将肇祸分队长赵敬贤看管，伤者送医院，死者招尸亲属认领。（3日专电）

  • 1932年6月4日讯：中日停战共同委员会讨论日军完全撤退问题，日方委员冈崎表示，沙泾港驻日军仅事巡逻护侨；吴淞纱厂、同文书院、丰田纱厂仅各驻少数宪兵，且战前亦有陆战队驻入。中方委员俞鸿钧驳斥，指出市政府自可负责护侨，毋须由日军越俎代谋；未闻同文书院等处以前有陆战队驻入。声明日军之驻各地不撤，有违协定，遂无结果而散。

1932年06月03日

发表于 2021-06-03 更新于 2021-07-19 分类于 局部抗战(1931-1937)

  • 1932年6月3日讯：上海《申报》、《新闻报》和《时事新报》三报馆工潮工人先后复工。《时事新报》问题仍未解决。

  • 1932年6月3日讯：驻蚌航空队飞机自光山轰炸红军后返回，在蚌落下炸弹一枚，炸死市民22人，伤41人。

  • 1932年6月3日讯：何应钦派飞机多架轰炸湘鄂赣苏区龙港。

  • 1932年6月3日讯：济南市商会议决，通电响应沪废止内战大同盟主张。

  • 1932年6月3日讯：日本首相斋藤发表对伪满新政策。对伪满洲国决先承认独立；日本对满依然遵守门户开放、机会均等之原则；并谓如不获谅解，不惜退出国联。

  • 1932年6月3日讯：国联调查团赴柳条湖九一八事变现场考察。

  • 1932年6月3日讯：战区视察团视察宝山、吴淞、江湾各处，孙科、顾祝同均前往。

  • 1932年6月3日讯：徐州房山下发现古墓，尸长丈余未腐，并掘出瓦瓶、瓦瓮、水盂三种，考古学家谓为汉代陶器。

  • 1932年6月3日讯：日平贺旅团占海伦，马占山部向通北方向撤退。

  • 1932年6月3日讯：国民政府任命周浑元为陆军第五师师长。

  • 1932年6月3日《申报》：北平息，兴城日军向围城之三路义勇军，放毒气炮（弹），我敢死队死亡甚多，卒被敢死队破城，日军三百余，仅5人生还。（2日专电）

  • #抗战影像#侵占我东北之日本于“九一八”事变爆发两周年之际，发行的宣传画，营造满日友善相处的假象，利用人口数量和贸易数字增长来美化其侵略本质。

  • 1932年6月3日《申报》：哈尔滨息，安达县31日晚为马占山部骑兵千余攻占，伪黑省长程志远，请日机前往轰炸。日机数架，1日自黑垣飞往。（2日专电）

  • 1932年6月3日《申报》：香港息，蔡廷锴弟朝锴来粤，与陈济棠商派兵夹击闽匪，蒋光鼐日内亦回粤。一行，港福建商会已筹备欢迎，陈济棠决仍派黄任寰、黄延桢两师，入闽协剿。（2日专电）

  • 1932年6月3日讯：行政院决议：一、指定吴铁城为邮政经济制度研究委员会主席；二、任命驻瑞典兼挪威公使诸昌年兼驻芬兰公使；三、任命刘和鼎为陆军第五十六师师长，毛炳文为陆军第八师师长。

1932年06月02日

  • 1932年6月2日讯：国民政府派张钫为河南全省清乡督办。

  • 1932年6月2日讯：陈诚、刘建绪部进犯红军湘赣边根据地鹅塘。

  • 1932年6月2日《申报》：哈尔滨息，李海青军31日遭日军平松、人见两支队，及空军（原文如此，当时日军兵种应该是陆军航空队）夹击，向对青山退却。程志远令丰乐镇之新黑军追击。（1日专电）

  • #抗战影像#溥仪以伪满洲国“皇帝” 身份出访日本时，前往参拜靖国神社。

1932年06月01日

发表于 2021-06-01 更新于 2021-07-19 分类于 局部抗战(1931-1937)

  • 1932年6月1日讯：韩复榘派第二十师师长孙桐萱为鲁北剿匪总指挥，民政厅长李树春为副总指挥。2日，韩在济南召集各军开剿匪会议。3日，孙、李赴鲁北指挥剿匪。

  • 1932年6月1日讯：江苏教育厅明令禁止小学校教职员罢教索薪，以“防止借口索薪，暗图掀动教潮”。

  • 1932年6月1日讯：国民政府令撤销第十九路军卫戍司令部，派蒋光鼐为驻闽“绥靖”公署主任。

  • 1932年6月1日讯：汉口20余商会向鄂总商会请愿，因水灾后营业无法维持，请减轻全市房租。

  • 1932年6月1日讯：北平大学工学院学生为驱逐压迫反帝学生运动的校长沈尹默和院长程干云，于本日举行罢课。中国共产主义青年团河北省委发表《援助工学院罢课宣言》，对驱程斗争表示援助与支持。

  • 1932年6月1日讯：中央公务员惩戒委员会成立，居正等11人在司法院就职，该会通告本日起实行惩戒职务。

  • 1932年6月1日讯：上海《申报》、《新闻报》、《时事新报》等报馆工人，为援助《时事新报》被迫离馆之工人，一致举行大罢工。

  • 1932年6月1日讯：川、鄂军总攻鄂西红军，刘湘增兵一团、飞机一架，出川助战。

  • 1932年6月1日讯：5月份东北关税受伪满压迫，未解中央，外交部向日提出抗议。

  • 1932年6月1日讯：马占山在海伦附近三门谢家接见由国联调查团团长李顿密派的美国记者海米斯和一名瑞士记者。马对其陈述日本制造伪满及江桥抗战情况，表示“唯一心愿就是把日寇打走，消灭伪组织——满洲国，收复我东北三省同胞安居乐业的国土”。

  • 1932年6月1日讯：河北省反帝国主义大同盟第一次全省代表大会在北平召开，该会宗旨为加紧反对帝国主义，进行与扩大民族革命战争，“打倒帝国主义走狗——国民党政府”，“建立民众自己的政权”，“争取中华民族的独立与解放”。

  • 1932年6月1日讯：敌28旅团占领海伦，控制了呼海铁路，第27旅团结束肇东地区的扫荡作战，从安达站转向克山，并令15旅团天野所部向墨尔根方向前进，准备墨尔根、黑河地区的作战。

  • 1932年6月1日《申报》：北平息，吉自卫军占阿城，破坏道路桥梁，日机往侦察。（31日专电）

  • 1932年6月1日《申报》：北平息，辽东义勇军保持原阵地，近接管十二县行政，于芷山军奉日令往剿，在新宾激战五昼夜。于芷山军耗子弹近万发，大败。于行踪不明，其两夫人已离省城，因部下纷纷反正，恐权险。（31日专电）

  • #抗战影像#伪满洲国“皇帝”溥仪曾经使用过的几座“龙椅”。

  • 1932年6月1日《申报》：沈阳息，日本平松部，今日清晨向海伦之马占山军，开始猛烈之炮击，海伦势将攻（沦）陷。（31日电通社电）

  • 1932年6月1日《申报》：哈尔滨息，30日午前7时，日本飞机队飞机数架袭海伦上空，猛烈投掷炸弹，致海伦全市顿成火海，焚毁极重。29日夜深更，由海伦出发沿呼海路南下之马占山军约骑兵三千名，及吴松林所部，30日行抵中途，闻海伦大火，折回扑救，终日未熄。（31日专电）

  • 1932年6月1日讯：颜惠庆将日军进攻北满详情报告国联，请从速履行12月10日保证日军退入铁路沿线之国联行政院决议。

1932年05月31日

发表于 2021-05-31 更新于 2021-07-19 分类于 局部抗战(1931-1937)

  • 1932年5月：清华大学自3月份起，庚款即停付，学生组织经费维护委员会，反对停付美庚款，几经交涉，才由财政部借垫100万元作为维持费。

  • 1932年5月下旬：中华苏维埃共和国临时中央政府电全国邮务罢工工人，希望“本着无产阶级的坚决精神并防止黄色领袖出卖罢工，以与敌人作坚决的斗争直至最后的胜利”。

  • 1932年5月31日讯：行政院决议，特派蒋光鼐为驻闽绥靖公署主任；决设邮政经济制度研究委员会，聘陈公博、吴铁城、林实等为该委员会委员。

  • 1932年5月31日讯：马占山部骑兵千余攻入安达县境，6月1日占领安达县城。

  • 1932年5月31日讯：南京、济南市商会分别致电上海全国商联会等，响应废止内战大同盟，京商会派濮仰山等三人参加，济银行公会已函沪商联会等加入。

  • 1932年5月31日讯：吴铁城赴京向蒋介石、汪精卫等人报告日军撤退经过及请示善后。同日，吴对记者谈，沪战区善后，农业区如吴淞、江湾、大场、庙行等地由政府及地方协力救济为主，工商业区如闸北一带应以恢复和平秩序及进行防疫为主。

  • 1932年5月31日讯：侵沪日陆军除宪兵外全撤，第九师团长植田返日。虹口越界筑路周围地区尚留海军陆战队未撤。

  • 1932年5月31日《申报》：哈尔滨息，闻哈尔滨西面复有激战，初以为马占山军在该处失利后，不致得有战事，不意日军今复在哈尔滨西约18里处遇劲敌。日飞机12架由天空轰炸反满军，敌（原文如此，应该指反满军）死伤颇多，但仍坚守阵地。（30日路透社电）

  • #抗战影像#伪满洲国发行的系列明信片，主题为“哈尔滨的夜色”。

  • 1932年5月31日《申报》：哈尔滨息，哈绥线客货车，30日仍抵返一面坡。29日自一面坡开出试通绥芬河客车，中途被阻折回。东铁俄局长要求熙洽之护路军护行车，派重兵分驻各站，并表示在旅客生命财产未得保障、及路方利益无丝毫损失前，不开行哈绥通车。（30日专电）

  • 1932年5月31日《申报》：大连息，来连中之调查团一行，今晨九时二十分，由大连复往沈阳。一行于中途鞍山下车，拟视察鞍山制铁所。（30日电通社电）

  • 1932年5月31日讯：我宪兵两连到沪维持治安，日方认为违反停战协定，双方发生争执，沪停战共同委员会为此举行会议调解。日方代表冈崎认此举为敌对行动。中方代表俞鸿钧驳复，称宪兵到沪并无敌对行为，系我主权，日方不能干涉。最后经共同委员会主席克宁翰转圜，中方答应以后军队调动须通知该委员会。
