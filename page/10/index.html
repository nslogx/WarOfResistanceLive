1932年11月27日

发表于 2021-11-27 更新于 2022-01-11 分类于 局部抗战(1931-1937)

  • 1932年11月27日讯：南开之豫灾民第一列车抵明光，在泰安被扣之第二列车经劝阻折回天津。

  • 1932年11月27日讯：太原山西大学等校学生因要求生活费，爆发学潮。全市师范、初中学生因官费取消，生活困难，连日向山西省府教育厅请愿，要求恢复官费制或酌予津贴。

  • 1932年11月27日讯：蒋介石通令各县驻军尊重县长地位，凡团长以下各长官，对县长如有凌辱行为，由各该师长负责论罪。

  • 1932年11月27日讯：李济深、黄绍竑电邀粤中委陈济棠、李宗仁、白崇禧、黄旭初、余汉谋、邓家彦等出席三中全会。

  • 1932年11月27日《申报》：沈阳息，本月24日，日空军（注：应为陆军航空队）飞机两架，参加作战。在沈阳郊外，被我义勇军用步、机枪击落，河内大尉等在机上中弹，飞机发动机部亦被破毁，两架均落在沈阳郊外，司机当场毙命。（26日华联社电）

  • 1932年11月27日《申报》：北平息，23日救国军苏华轩部第一总队长方海洪、第二总队长王老虎，率部四千余人，进攻锦州。双方接触五小时，王部大刀队肉搏冲锋，日军溃退入城。我军阵亡士兵十八，伤三十二，毙敌十余，伤无算。获大枪九枝，及其他战利品甚多。当日军入城时，王部便衣队乘机混入，城内百余埋伏内应，方、王两部已约定继续攻锦，里应外合，即将有进展。（26日专电）

  • #抗战影像#一支关东军中队正准备登上火车，向昂昂溪方向出动，执行所谓“讨伐”义勇军的作战行动。

  • 1932年11月27日《申报》：北平息，苏炳文21日致其父电称，自誓师以来，迭次激战，敌人陆空并举，武器虽优，而我军将士勇猛，前赴后继，大寒敌胆。库勒站一役，毙敌高级军官一名，伤亡敌官兵四五百人，生遁者仅二百余人。儿决以身许国，奋斗到底，现在中外人士，交相称许，国际空气甚好。只求与国有利，成败非所计及，日方全权代表，飞赴俄境，屡电求和，亦足见对我军之重视，与关系之重要矣。平寓蒙某某二公之照拂，可以维持生活。儿为民族荣辱而争，为东北存亡而奋斗，捐躯殉职，甘之如饴，国人贤明，必不令家族有冻馁之忧也。此间经济物质，极感缺乏，官兵三月余不得一饷，而士气民心，甚为旺盛，诚所谓置之死地而后生云。（26日专电）

  • 1932年11月27日《申报》：北平息，江省日军，松本师团所属某中队，14日奉紧急救援命令，在疾赴拜泉途中，遇义勇军约50余名，于拜泉附近某村中，义勇军将枪械藏起。着普通破旧衣服，日军遂在该村宿营，夜深人静，义勇军突起以刀戮之，日军约百余人，伤亡俱尽，逃者仅十余人。（26日专电）

  • 1932年11月27日讯：国民政府通电各省、市，中央党部和国民政府定12月1日同时迁回南京。29日，国民政府公布12月1日迁回南京令。

1932年11月26日

发表于 2021-11-26 更新于 2022-01-11 分类于 局部抗战(1931-1937)

  • 1932年11月26日讯：河南灾民四五千人乘专车由北平赴南京，是日在泰安被扣留。

  • 1932年11月26日讯：教育部通令全国高、初中下学期起取消学分制，取消选科制，不设党义科。

  • 1932年11月26日讯：江、浙两省渔业团体再电宋子文，要求豁免重征渔税。

  • 1932年11月26日讯：刘珍年部梁立柱旅开抵浙江温州，骑兵团调驻安徽滁州。

  • 1932年11月26日讯：刘湘令各军全线停止进攻，静候中央命令。

  • 1932年11月26日讯：东北在平难民数逾10万，是日张学良等邀请平、津党、政、军、绅、商、学各界举行茶会，讨论筹款赈济办法及筹设难民工厂等事宜。

  • 1932年11月26日《申报》：北平息，日人拟恢复东三省兵工厂，明春三月中旬，开始工作，定名奉天造兵所株式会社。由关东军司令部直辖，资本八千万元，伪政府及日方各投资本四千万，已定吉川中佐为厂长，用工人1500名，出品除枪弹炮弹外，每月可出轻机枪150至200挺，七五生（注：指75毫米）炮3-6门，装甲汽车10-20辆，轻型坦克3-7辆，汽车40-70辆，并可自制枪炮。期扑灭义勇军实力，该厂机械，一经修改，可制造毒瓦斯及其他新式兵器。日方决定促成昭和制钢所，即将实现。资本定2300万，为日本预定在东亚之大钢厂，在军事上极关重要。（25日专电）

  • 1932年11月26日《申报》：山海关息，热河抗日军何民魂部刘甲山师24日晚10时，攻克瞻榆，获敌铁甲车一辆，击毙敌兵甚多，现正沿四洮路向昂昂溪推进。（25日华联社电）

  • #抗战影像#“一·二八事变”中，日本海军陆战队员和武装日侨（胳膊缠白毛巾者）在上海街头追捕一名被怀疑是抗日分子的中国人。

  • 1932年11月26日《申报》：北平息，义勇军三江好部，17日夜率部四千余，占领下九台车站，现正与日军激战中。（25日专电）

  • 1932年11月26日《申报》：北平息，黑河电，马占山离雅鲁后，经嫩江上游到讷河，指挥各路军事，第二步军事计划准备中，日方因苏炳文态度坚决，调三个师团开始集合。（25日专电）

  • 1932年11月26日《申报》：北平息，日军三百余名，附有野 炮10余门，日前由安东开抵锦县。该队10月间曾在安奉线，与救国军接战，锦县日飞机场刻仅有飞机两架，余均调往中东、沈海各线。意似对北满，苏炳文张殿九等部有大举进攻准备。（25日专电）

  • 1932年11月26日讯：中共满洲省委派化名张贯一的杨靖宇来磐石接替杨佐青工作。杨靖宇把义勇军改编成为“中国工农红军第三十二军南满游击队”，通称磐石游击队，从桦甸蜂蜜顶子拉回磐石红石砬子根据地，下设3个大队。孟洁民任总队长，初向辰任政委，王兆兰任副总队长。

1932年11月25日

发表于 2021-11-25 更新于 2022-01-11 分类于 局部抗战(1931-1937)

  • 1932年11月25日讯：宋哲元以察省财政困难，办事棘手，电蒋介石辞察省主席职。26日，蒋复电慰留。

  • 1932年11月25日讯：江西九江商会以洋米倾销，农村经济破产，特函全国商会联合会转请中央对洋米进口从重征税，以保护我国农业。

  • 1932年11月25日讯：吉林抗日救国军总司令王德林致电国联并通电全国，反对国联调查团报告书，声明不承认伪满，誓死抵抗。

  • 1932年11月25日讯：上海社会局发表一二八事变损失统计，总数达1.9亿余元。

  • 1932年11月25日讯：北平各团体决议反对故宫古物迁至洛阳，电请中央取消原议，如无效果，迁移时各团体民众定在神武门前设法阻止。

  • 1932年11月25日讯：立法院通过《中华民国红十字会管理条例》和《商品检验法》。

  • 1932年11月25日讯：鄂豫皖“剿匪”总部制定对所占苏区新设县治建置大纲14条，凡新设县治，其应隶属之省区、县治所在地及疆域，悉由总部规定，县长亦由总部任命。是日通令三省遵行。

  • 1932年11月25日《申报》：北平息，王德林电平称，苇河围攻四日，敌气已馁，即可解决。刻派李秀云旅长在苇指挥，职率劲旅五千，越过苇河进攻珠河。刻与一面坡日军激战中，据吴副司令电称，在吉林附近攻击日军，颇为得力。阿什哈打亦为我军占领，刻我军取游击方式，扰害日军。（24日专电）

  • #抗战影像#”一·二八事变”中，一队日本陆军炮兵正操作大正四年式150毫米重型榴弹炮，准备轰击中国守军阵地。

  • 1932年11月25日《申报》：北平息，义勇军耿继周部谢振国支队二千余名，20日晚全部占领打通路之伊胡塔及巴胡塔站，并派王德全率部千名，向彰武进行，行至章古台站，与日甲车及日军激战数时，我方获掳颇众。21日晚占领江坨子，刻仍向彰武推进。（24日专电）

  • 1932年11月25日《申报》：东京讯，“满洲国”正式宣布成立后，一再派亲善团至日，现复有学童及童子军各一队抵此。童子军共41人，今日由首相斋藤接见。同时“满洲国”商业团寓日12日，与日政府机关及商业团体交换意见，以期增进理解，及从事日“满”经济合作后，已于今日启程返长春。（24日路透社电）

  • 1932年11月25日讯：行政院代院长宋子文、外交部长罗文幹向各国驻华公使声明，否认中日直接交涉之说，并称日方造谣已司空见惯。

1932年11月24日

发表于 2021-11-24 更新于 2022-01-11 分类于 局部抗战(1931-1937)

  • 1932年11月24日讯：吉林抗日救国军王德林部进攻黑省珠河（今珠河县），与一面坡日军激战。

  • 1932年11月24日讯：日阁议决定，任命武藤信义为驻伪满大使。

  • 1932年11月24日讯：天津裕元纱厂工人因要求发放制服被开除四人，是晨开始罢工，又被开除12人，工人被迫复工。

  • 1932年11月24日讯：北平大学代理校长徐诵明电教育部辞职。

  • 1932年11月24日讯：翁文灏就任教育部长，但不辞地质调查所长职。

  • 1932年11月24日讯：皖省旅京同乡电国民政府反对米照捐。同日，宋子文电皖省政府，粮食照费商民不得抗缴，如有赴京请愿，定予申斥。

  • 1932年11月24日讯：南京农、工、商、学、妇各团体联名电请国联对日有效制裁，谓对于日本若仍持宽容态度，不予迅速有效制裁，则世界和平基础从此即破坏无余。

  • 1932年11月24日讯：刘文辉、邓锡侯、田颂尧在成都再度协商息争，谓川战发生，皆刘湘所操纵，今后当制止其野心，一切请命中央，谋川局善后。同日，刘湘分电潘文华、王缵绪、唐式遵、穆瀛洲等各督所部分路西进，期于月底攻下成都，完成统一。

  • 1932年11月24日《申报》：北平息，义勇军百余人，前日在北宁路青堆子，掘毁路轨十余丈，图颠覆伪奉山路车。适日军守备队乘甲车梭巡，至此开炮，与义勇军激战。义勇军遂向双台子撤退，伪奉山路车误点四小时，始到榆关，榆关谣言甚炽。（23日专电）

  • 1932年11月24日《申报》：北平息，前几日日机八架飞拜泉轰炸，投弹30余枚，东大营已成一片焦土，且散放传单。令民众将濮（炳珊）扣押之日军下枝少佐联络员，护送海伦或省垣，不准再供给濮部粮物，否则飞机多架，再来轰炸该地街市等恐吓语。（23日专电）

  • 1932年11月24日《申报》：天津息，关外青纱帐倒后，义勇军大部隐于深山，刻各江河封冻，活动较夏便利。日逆甚忧虑，在辽河鸭绿江松花江等江各要镇赶筑土垒，以防义勇军袭击。（23日专电）

  • #抗战影像#“一·二八事变”中，在上海街头一处工事的日本海军陆战队员，中间沙袋上架着一挺日制大正11年式轻机枪。

  • 1932年11月24日《申报》：北平息，苏炳文21日电平称，马主席前由讷河到雅鲁县，已与职及张副司令香阁会面，对黑省军事步骤完全商妥。马主席刻已离县返回讷河，职亦返抵海防。（23日专电）

  • 1932年11月24日《申报》：东京讯，据日内瓦来电，“满洲国”代表丁士源被拒绝入瑞士国境，后经矢田公使周旋，瑞士政府遂登许可入境，已于今晨11时由巴黎出发，晚9时抵日内瓦。（12日日联社电）

  • 1932年11月24日《申报》：东京讯，据日外交界讯，国联一般空气于日本逐渐不利，十九国大会之开幕又迫在眼前。日外部处此状态之下，愈觉有与国联冲突之危险，为缓和目前之危机，日外部除一方训令日内瓦各代表加紧抓作各大国恳其援助外，仍是脱不了虚声恫吓手段，以脱退国联而组织东洋联盟，而中日问题范围属东洋，应在东洋联盟解决等，并宣布要求俄国参加东洋联盟，以牵制英法意各国，企图挽救其喘死之运命。（23日华联社电）

1932年11月23日

  • 1932年11月23日讯：抗日军李海青部收复吉省长岭、瞻榆（今通榆）等县。

  • 1932年11月23日讯：松江《松报》因登载调查仇货新闻，被国民党县党部以“故违法令，鼓动风潮”罪勒令停刊。

  • 1932年11月23日讯：刘珍年部第二旅约6000余人，由烟台分乘五轮，开往温州。

  • 1932年11月23日讯：上海市拥护国联盟约会发表告全国商人书，勉全国商人御侮救亡，提出五事勉商界共同进行：一、拥护国联盟约；二、保持领土完整；三、实施经济封锁；四、援助东北义勇军；五、制裁破坏盟约及世界和平之野心国家。

  • 1932年11月23日讯：国民党中央政治会议通过建设陪都西京、行都洛阳案，交行政院、军委会妥议办法进行，并通过保留行都中央党部及国民政府现有地址等案。

  • 1932年11月23日讯：国民政府为息川事，重申民国十七年整理川政之命令，交行政院详定实施办法，并令川军各将领暨行政专员“引咎互让，立止干戈”，依院决办法实行。

  • 1932年11月23日《申报》：北平息，日军令伪国强迫各县增兵，大县增四千，中县三千，小县二千，准备再东北成立10个师，由日军官训练三个月，预备进犯热河用。（22日专电）

  • 1932年11月23日《申报》：北平息，日军再满洲作战，使逆军在前线，日兵在后督战。伪军以与苏炳文宫长海袍泽关系，不肯拼战，日兵在后严重压迫，后退即以机枪扫射，伪军被日军击毙者，比战死者多。日对大部义勇军进攻，对小部义勇军实行分散，意图义勇军潜伏各村人民不能安居，纷逃关内，日人可享有其土地权，其计阴毒。（22日专电）

  • 1932年11月23日《申报》：沈阳息，辽东义勇军六十八人被捕于安东县，分禁两处。昨夜11时半，同时破狱脱出，日军警接讯，即时派警查询情形。仅见监房被冲破，并不能发现任何踪迹。日方疑为守监华人被义勇军收买内应，将华人巡捕在日宪兵队询讯中，又恐义勇军乘机攻日侨，守备队派兵守各关隘云。（22日专电）
