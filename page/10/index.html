1932年05月04日

  • 1932年5月4日讯：马占山召开全体将领会议，决定联合黑、吉两省抗日义勇军进攻哈尔滨。

  • 1932年5月4日讯：中华民国拒毒会通电全国各拒毒团体，请响应高友唐弹劾刘瑞恒案。

  • 1932年5月4日讯：国民政府任命刘通为福建省政府委员兼民政厅长；任命邓家彦、傅汝霖为立法院立法委员；国立中央大学校长任鸿隽未到校以前，派该校法学院长刘光华代理校务。

  • 1932年5月4日讯：北京大学纪念“五四”，各教授发表悲壮演说，下午集合游行，被警阻止。同日，广州学生召开五四运动纪念会，通电反对签订上海丧权协定。

  • 1932年5月4日讯：　江西清乡会在南昌开幕，何应钦训词宣称：“改良政治，发展交通，组织民众，为剿赤根本工作。”

  • 1932年5月4日讯：颜惠庆向国联报告日本阻挠顾维钧与国联调查团各委员合作，顾之寓所侦察密布，且有侵入室内情事，并阻挠顾与人谈话及发电。

  • 1932年5月4日《申报》：停战会议我方首席代表外次（长）郭泰祺氏，于昨日上午九时二十分，接见民众团体代表时，被某团体代表用铜元茶杯等掷伤头部，致左颊流血甚多。嗣经法捕房得讯，立派探捕前往弹压，并拘去十一人。各团体会代表殷芝龄、李次山被捕后，即经郭氏派员保释。其余仍在押，……

  • 1932年5月4日《申报》：奉天息，据由沈海线山城镇之警察队所发致沈阳警察署电报，谓日本警察队，在方清台子与大刀会激战，日本警察死伤15名，旋警察队占领东方高山，将数千之大刀会包围。（3日电通社电）

  • 1932年5月4日《申报》：北平息，日对北满计划，用全部军力对付李杜、丁超，大部军队已开依兰，用政治手腕缓和马占山，屡派代表见马，均被拒绝。（3日专电）

  • 1932年5月4日讯：国联调查团第一次报告书全文在南京发表，遵国联决议述东北实际情况，关于东三省军事情形由日本军事当局供给；并称恢复和平安全办法尚待考量。

1932年05月03日

发表于 2021-05-03 更新于 2021-06-19 分类于 局部抗战(1931-1937)

  • 1932年5月3日讯：自九一八以来，各地禁止现金出口，本日财政部通电各省市“一律取消禁令”。

  • 1932年5月3日讯：中华民国拒毒会函汪精卫称，除江、浙、鲁三省外，其余各省均次第实行鸦片公卖，外传中央酝酿公卖复活，请宣布禁烟政策及制止各省实

  • 1932年5月3日讯：吉林自卫军冯占海部克复宾县。

  • 1932年5月3日讯：全国邮务工会通令各地分会反对邮资加价。同日，全国商会联合会分电国民政府行政院、立法院、监察院、交通部，反对邮资加价。

  • 1932年5月3日讯：国民政府任命郎官普为黑龙江省政府委员兼财政厅长，韩立如为黑龙江省政府委员兼民政厅长，周维泰为黑龙江省政府委员兼实业厅长，邹邦杰为黑龙江省政府委员兼教育厅长。

  • 1932年5月3日讯：沪日军闯入租界新闸路乌镇路桥附近，刺伤华人七名。是日上海市政府致函公共租界工部局提出抗议，要求严重交涉，并饬属保护居住租界内之华人，不再发生同样事件。

  • 1932年5月3日讯：蔡元培电汪精卫称，牛兰案“政府应令法庭公开审判，并许自聘律师辩护”。汪精卫4日复电称：“牛兰案一切手续，均依照刑事诉讼法办理，与尊电相同。”

  • 1932年5月3日讯：于右任在上海各报发表《对孙哲生谈话之献疑》，反对孙科所谈“国民党中央不能领导全国，信用完全失掉，主张筹备实施宪政”之说，认为国民党还在“革命”时期中，不能放弃“训政”，否则即是“革命之危机”。

  • 1932年5月3日讯：国联调查团抵长春，五委员访溥仪。

  • 1932年5月3日讯：行政院会议，外长罗文幹报告沪停战会议经过及日撤兵后接收被占区域计划。

  • 1932年5月3日《申报》：日内瓦讯，国联秘书处已接到李顿调查团由沈阳发来之初步报告书，其中多述满洲军事情形，不日将在沈阳与日内瓦同时发表。（2日路透社电）

  • #抗战影像#伪满洲国时期，某女子学校毕业生合影照片

  • 1932年5月3日《申报》：北平息，丁超、李杜电平，连日在新甸黑口等处，与敌舰接触，击沉敌舰6（注：原文如此，可能为无装甲防护的内河汽艇或汽船），拖船4，毁1。敌损失重，依林站马旅刘旅与敌站，双方损失重，我军守五虎林一带，今晨我军占珠河，截敌归路。（2日专电）

  • 1932年5月3日讯：粤西南政务委员会决议，裁撤海军总部，改隶第一集团军管辖；陈策任第一集团军高等顾问。同日，陈济棠准备以武力接收粤海军。

  • 1932年5月3日《申报》：哈尔滨息，昨晨有袭击队在中东铁路东段乌吉密河附近炸毁路轨，致村井旅团之一部队乘以开回哈尔滨之火车，因以被阻，敌兵（注：日方角度）利用铁路两面之茂林，伏于其中，以机关枪及迫击炮猛轰被阻之兵车，激战24小时，日兵率将敌击败，敌向北退，日兵死伤30人。（2日路透社电）

  • 1932年5月3日讯：广东省政府改组，林翼中任主席，林云陔任广州市长。

  • 1932年5月3日讯：上海中日停战会议中国代表郭泰祺在寓所接见上海各救国团体代表，应众要求宣读停战协定草案。学生激于爱国义愤，用铜元、茶杯掷伤郭之左额。汪精卫对此发表谈话，主张痛惩，并电令上海市长吴铁城迅即查明殴伤郭的凶徒，“递解归案，严加讯办”。

1932年05月02日

发表于 2021-05-02 更新于 2021-06-19 分类于 局部抗战(1931-1937)

  • 1932年5月2日讯：红军第三军团彭德怀部占领湖南汝城。13日又被敌王东原第十五师攻占。

  • 1932年5月2日讯：上海市民联合会通电发起举行全国各团体救国会议，讨论救亡大计。

  • 1932年5月2日讯：陈济棠在广州召开滇、黔、湘、桂、闽、赣等八省军事反 共会议。

  • 1932年5月2日讯：国民党中央政治会议通过《惩治贪官污吏办法》，于最高法院设惩治贪官污吏专庭，以最高法院院长为庭长，监察院及行政院代表参加组织之。

  • 1932年5月2日讯：日军在通河地区遭我自卫军反击，发生猛烈战斗，但我军部队薄弱，未能驱逐日军，日军随即增兵通河，并意图继续向下游攻击

  • 1932年5月2日讯：我军集中所有炮兵猛攻珠河车站，此时，周边民众以及红枪会组织纷纷来援，数量多达万人，赤膊与敌进行肉搏，我主攻部队顺势突入敌据点，占领珠河车站。

  • 1932年5月2日《申报》：哈尔滨息，国联调查团定一日晚离辽，到长考察，留二日，三日赴吉，亦留二日，五日晚可抵哈。（1日专电）

  • 1932年5月2日《申报》：哈尔滨息，30日早救国军与日军，在东线磨刀石站激战三小时，日军以装甲车猛攻，救国军退却。（1日专电）

  • 1932年5月2日《申报》：电通社1日东京讯，日乘爆弹事件机会，在上海设立中立地带之意见，愈益渐成问题。若依现在之状态，上海为国际阴谋之中心点，由不能除去内外在沪人民不安着想，日中央军部对停战交涉成立调印后，在圆桌会议中，当迫求中政府之责任，且力主有效且切之提案，使之实现。

  • 1932年5月2日讯：上海各团体救国联合会急电蒋介石、汪精卫及罗文幹反对日本提出所谓南市、浦东永远不驻华军之要求。

  • 1932年5月2日讯：军事小组委员会开会，英军事参赞桑布尔对苏州河南及浦东方面我军驻防问题提出折衷新方案，即于会议录中由我方声明浦东本无驻军，苏州河南龙华、莘庄一带我方虽有驻军，但与日方相约各不前进，双方不得有敌对行动。中日代表一致接受。

  • 1932年4月：东铁护路军总司令丁超、吉林自卫军总司令李杜电致国联调查团，陈述东省日军之暴行，表示自卫军抗日决心。
