1932年08月02日

发表于 2021-08-02 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年8月2日讯：上海全市电报工人为要求改善待遇实行罢工，当晚经劝告复工，局方允每人加工资二元，分期实行。

  • 1932年8月2日讯：国民政府任命高桂滋为陆军第八十四师师长。

  • 1932年8月2日讯：财政部电令各海关增加丝织等类货品进口税率，即日实行。

  • 1932年8月2日讯：财政部通令各省、市财政厅、局限制田赋附捐，不得逾越地价l％，附加总额尤不得超过正税。其已经超过者，应即切实核减；未超过者，非迫不得已时，不得率请加征。

  • 1932年8月2日讯：前第八十八师独立旅旅长王赓，在淞沪抗战中被拘，经严密侦察确无通敌嫌疑，本日以擅离戒严地点之罪，判处徒刑二年六个月。

  • 1932年8月2日讯：晨，辽南抗日义勇军袭击海城，猛攻营口，切断南满路；辽西义勇军郑桂林部占领葫芦岛。日步兵第二十九联队及靖安游击队自沈阳出发，3日晨到达海城。

  • 1932年8月2日讯：行政院接西藏达赖电，表示对康、藏纠纷愿和平解决，盼政府适当处置。是日行政院致电达赖、刘文辉详询对此事意见。

  • 1932年8月2日讯：粤空军将领黄光锐、丁纪徐等由广州赶回韶关，组织第六航空国防队，决心以空军全力向红军总攻击。

  • 1932年8月2日讯：荷使杜培克赴外交部欧美司洽商退还荷兰庚款事，双方意见甚接近。

  • 1932年8月2日《申报》：北平息，记者以日传马占山阵亡，特向黑省驻平代表探询。据称，马仍在绥楞督师，健康无恙。连日黑河均有电报到平，足证日方所传别有作用，绝非事实云。（1日中央社电）

  • 1932年8月2日《申报》：长春息，今晨三时，约30名之义勇军袭击长春飞机场，但为日本警备队击退，该军之本队系在长春东方之国祖子，集有二千左右，今日有袭击长春之形势，日满当局，现甚戒备。（1日电通社电）

  • #抗战影像#伪满洲国早期的国务院。原为吉长道尹公署，曾为溥仪执政府临时所在地。伪满参议府、法制局亦曾在此办公。

  • 1932年8月2日《申报》：锦州息，今晨5时，约50名之义勇军袭击锦州绥中之间之兴城。俄人警察6名应战，结果死2名，2名负伤，1名生命危险，损害较大。日本锦西守备队接此急报，立即向该方面出动。（1日电通社电）

  • 1932年8月2日《申报》：沈阳息，期于8月1日袭击满铁沿线之义勇军，31日晨起，由各方面向辽阳进攻，至是晚9时半，辽阳全城，被三千义勇军完全包围。10时起，以迫击炮向辽阳附属地，开始攻击，日军与之交战中，又首山堡亦完全被义勇军包围。（31日电通社电）

  • 1932年8月2日《申报》：国民政府财政困难，曾由外部照会英、美、意三国，商请将各该国庚款，自本年3月起，至明年2月止，缓付一年，三国近均复照表示同意。

1932年08月01日

发表于 2021-08-01 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年8月1日讯：香港《妇女杂志》创刊。

  • 1932年8月1日讯：上海商务印书馆1月间被日机炸毁停业，是日总馆恢复营业，仍推王云五为总经理。

  • 1932年8月1日讯：广西银行总行在桂林成立，资本800万元，实收521万，官商合办。

  • 1932年8月1日讯：国民政府任命谷良民为陆军第二十二师师长；曹福林为陆军第二十九师师长；乔立志为陆军第七十四师师长；展书堂为陆军第八十一师师长。

  • 1932年8月1日讯：南京市“血魂锄奸团”成立，宣言称有团员数百，分布全市，其任务在调查事实，锄灭奸商。

  • 1932年8月1日讯：为防共产党人举行“八一”纪念，上海市政府下令断绝交通，禁止一切集会、结社、游行。北平亦戒严。

  • 1932年8月1日讯：粤军李振球第一纵队占领信丰城。

  • 1932年8月1日讯：闽“绥靖”公署在漳州召开漳、泉、龙、汀四属“绥靖”会议，研究“剿灭”红军计划。蔡廷锴主席，出席者第十九路军师长沈光汉、区寿年、张贞及毛维寿、黄强，并龙溪、海澄等14县县长。第十九路军其他高级军官列席。

  • 1932年8月1日讯：国民党中央以近时各地新成立之团体常对于政治“作不负责任之批评或攻讦”，特规定嗣后各团体发布文电，须有会长或主席署名，以重责任，除通令各级党部转饬遵照外，并函知行政院。

  • 1932年8月1日讯：南京各界民众团体为日军侵热开代表大会，讨论应付方策，决定致电国联调查团及国联，报告“暴日侵热”真相，请强力制裁，以伸公理；并致电张学良及华北各将领，请率军抵抗，援助义勇军收复失地。

  • 1932年8月1日《申报》：哈尔滨息，据日方消息，日将田中部下会同“满洲国”军队，在海伦北四十里之刘家店（译音）附近，击溃马占山部下八百人。日人称，此股为马部下精锐，阵亡250人，伤350人，丧马150匹。日方续称，马军继续退走，田中部下获车百辆，闻马占山因此番失利，颇抱悲观，已将军权交与张某，中东路西段现已通车，但火车延迟14小时至20小时，水尚未退，雨亦未止。（31日路透电）

  • #抗战影像#伪满洲国初期，新京特别市公署。

  • 1932年8月1日《申报》：北平息，日人各界盛传马占山阵亡消息，但众不之信，盖此间今仍与东北义勇军通电，而未接有此项凶耗也。华员谓此乃日人之宣称，盖日人近亦作此谣言，未几知马仍健在也。（31日路透电）

  • 1932年8月1日《申报》：山海关息，打通路义勇军击溃日军，占领通辽，伪路车顷通彰武，彰武附近仍在激战中。（31日专电）

  • 1932年8月1日讯：张学良电京报告热河情形，称：“日方已开始军事行动，形势渐趋严重，榆关亦告紧急。”

1932年07月31日

发表于 2021-07-31 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年7月：国民政府以“言论反 动，毁谤党 国”的罪名，下令禁止《生活》周刊在河南、湖北、江西、安徽等省邮递。

  • 1932年7月下旬：冯占海吉林抗日义勇军袭击并占领榆树城，该城伪军、伪保安队数百人起义。

  • 1932年7月下旬：军政部为封锁苏区消息，订定《匪区邮电扣留办法》，咨请交通部令各省依照办理，并将设在苏区之邮务分局暂行撤退。交通部通令实行。

  • 1932年7月下旬：湖南省政府聘胡庶华担任湖南大学校长。

  • 1932年7月31日讯：华侨救国经济委员会公推该会副主席何永贞赴津调查义勇军抗日状况。何表示侨胞素爱祖国，对抗日军民当有充分之接济。

  • 1932年7月31日讯：“津沽民众救国会”致函国民政府，要求转饬张学良率部援热，并函请国联调查团主持正义，制止日军在热河的军事行动。

  • 1932年7月31日讯：平、津43个团体请愿代表团代表80余人，在平向张学良请愿，提出下最大决心，收复失地等六项要求。

  • 1932年7月31日讯：马占山军在罗圈甸子遭日军八个联队近万人设伏围困，是日，马率部从北山口突围，受阻，转东南山口，乘黑冲出包围。

  • 1932年7月31日《申报》：南京息，中委潘云超继朱霁青主任担任东北国民救国军后方事务，30日由津抵京，定31日夜赴沪，与各抗日团体接洽援助事宜。闻将在沪设立办事处，以利进行，此间一般爱国青年，自朱霁青到京后，纷纷投效国民救国军，30日又有40余人乘津浦车北上，加入抗日工作。（30日专电）

  • 1932年7月31日《申报》：南京息，东北义勇军司令朱霁青，在京领有大批军火，由津浦路乘车北上，转往关外。（30日专电）

  • #抗战影像#伪满洲国宣传画，宣扬所谓王道建国。

  • 1932年7月31日《申报》：哈尔滨息，29日下午1时左右，由宁古塔出发之高桥大尉等9名，行到梅林河与牡丹江合流之上游二千米远之处，突被四五十名之义勇军袭击。经交战后，高桥大尉阵亡，内田中尉以下五名负伤。（30日电通社电）

  • 1932年7月31日《申报》：北平息，哈电，马占山部连日在绥鄂尼尔吉河上游一带，与日军转战，因积雨泥泞，日军用骑兵活动，马部以森林为掩护，往来游击，日军吉冈部有被诱失利说。（30日专电）

  • 1932年7月31日讯：北平政委会连日会议军政防务，是日闭幕，发表宣言称：长期御侮，应以改善内政为根本之图，各省当局“应亲身巡视，或派员调查地方应兴应革事宜，克期实施”；恢复失地，巩固国防，为全国军人之专责，华北军人“更应遵照中央命令，同心努力，共谋捍卫”。

1932年07月30日

发表于 2021-07-30 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年7月30日讯：广州连日大雨，今晨全市被淹，塌屋数十间，溺毙98人，伤53人，无家可归者甚多。

  • 1932年7月30日讯：上海日商对“血魂锄奸团”之行动恐惧万状，特开会议定应付办法五项；一、催领事从速交涉；二、组织便衣侦察队侦察该团行踪；三、将存货廉价赶快出售；四、请日军保护；五、急电日本国内各埠暂停装货来沪。

  • 1932年7月30日讯：沈阳伪公安局长张凤岐因筹划起义被日军惨杀，株连数十人，该局督察长杨某被割舌而死。

  • 1932年7月30日讯：“国民自救会”在沪成立，发起人为褚慧僧、褚文绮、李永祥等。该会宗旨为抵制日货，提倡国货救国。

  • 1932年7月30日讯：第十届奥运会在美国洛杉矶举行，中国代表队临时拼凑而成，刘长春执国旗，总代表沈嗣良及代表宋君复、刘雪松、申国权、托平共六人。刘长春百米预赛成绩11秒左右，排名第五，被淘汰；200米成绩21秒9，列第四。

  • 1932年7月30日讯：天津各团体救国联合会、国难救济会、市商会、各大学教授抗日会等38团体200余人，在银行公会宴请张学良、韩复榘、傅作义等，呼吁各将领下最大决心，收复失地。

  • 1932年7月30日讯：豫鄂皖三省“剿匪”总部颁布命令，凡红军师、旅、团、营、连长“率部来归”者，提升一级，并赏师10万，旅三万，团一万，营5000，连1500元；个人“自首来归”者，保留原阶级，听候录用，不究既往。

  • 1932年7月30日讯：国民政府令：公布《县长任用法》；任命孙桐萱为陆军第二十师师长。

  • 1932年7月30日讯：财政部长宋子文发表声明，因日本违背国际协定，掠夺东北税收，决定暂停拨付日本庚子赔款3.3万镑。

  • 1932年7月30日《申报》：天津息，驻津日领已令警署设立邮递代办处，凡日侨寄东北邮件，由代办处收两倍邮费，每日集交中国邮局贴票寄大连，再由大连日邮局贴伪国邮票寄出，自28日起实行。（29日专电）

  • #抗战影像#侵占我东北之日本制作的宣传画，号召所谓防赤化。

  • 1932年7月30日《申报》：沈阳息，本年5月16日有沈阳警局长张凤池图杀本庄而推翻“满洲国”为日宪兵发觉，拘获多人，此事当时不许各报登载，今日始驰禁。（29日路透社电）

  • 1932年7月30日《申报》：沈阳息，几成为第二中村事件而集中视听之石本事件，由日军守备队与汤玉麟代表祁子锋迭次谈判释放，祁向义勇军交涉之结果，石本遂于昨日释放，本日可由锦州归沈阳。（29日电通社电）

  • 1932年7月30日讯：立法院会议通过中政会交议之海关征收附加税，并增加进口税之种类及税率案。附加税按关税税率征收5％，以一年为期。附税、进口税两项年可增收2000万元。
