1932年10月17日

发表于 2021-10-17 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月17日讯：第十九路军奉命“围剿”红军，是日该军第六十师占福建龙岩，第四十九师占坎市。

  • 1932年10月17日讯：上海市长吴铁城密电行政院，称捕陈独秀事先曾与租界当局“特别交涉”，并“协同捕房侦察”达月余之久。

  • 1932年10月17日讯：下午5时，外交委员会开秘密会，讨论《国联调查团报告书》，由罗文幹报告赴汉与蒋磋商经过，讨论至7时始散。

  • 1932年10月17日《申报》：沈阳息，派往吉林之日本武装移民五百，于14日午后到达目的地，15日上午起即开始工作，建设宿舍，制造农具，酿造酱油等，俟解水期，开始耕种。（16日电通电）

  • #抗战影像# 地处闸北的一条街道，因日本飞机轰炸上海引起大火而成为废墟，有两名日军士兵在那儿站岗￼

  • 1932年10月17日《申报》：北平息，进攻伊通义勇军，被日军包围数日，势极危险。驻双阳河之援军王玉东部，12日夜开到，内外夹击，日军13日拂晓溃退，伊通之围遂解。获敌械百余枝，毙日军五十余名，王玉东派人与王德林部商联络。（16日专电）

  • #抗战影像#“一·二八事变”中，正在逃离家园躲避战火的中国难民。

  • 1932年10月17日《申报》：沈阳息，包围东边道义勇军根据地通化桓仁，（日军）一齐开始攻击之服部某联队主力，高波某联队主力，阁谷某联队，西安游击队之北方及中央部队大木某联队主力，山冈某联队及仓林某联队之南京部队，于昨夜中在由通化桓仁之二里地点，形成包围圈。义勇军总司令唐聚五则于通化南门外日本领事分馆前设立总司令部，决死守舍命抵抗。日军服部某联队长于今晨下总攻击令，对义勇军形成包围之日军与满军及日飞机队联络，空陆相呼应，自今晨以来，对义勇军根据地之通化桓仁，开始猛烈之总攻击，各处皆有激战。（16日电通电）

  • 1932年10月17日《申报》：北平息，义勇军耿继周部谢振国，13日率部千五百余名，由锦东攻打虎山车站，与日军七百余名激战数小时。日军用机枪重炮向我射击，旋第五支队杨春桦部继至，两部取包围形势猛攻。日军退新立屯，我军占领打虎山车站，毙敌百余名，获机枪二挺，山炮一门，步枪七十余枝。我方死五伤七，现正集合军队，耿部10日大部分向锦州朝阳推进，攻朝阳。一部绕经彰武，转袭新民，耿亲赴前方指挥。（16日专电）

  • 1932年10月17日讯：杨森、李家钰、罗泽洲部在顺庆附近与刘文辉连日激战。刘湘集中兵力于荣昌、遂宁一带，准备武装调停川战。

1932年10月16日

发表于 2021-10-16 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月16日讯：晚，戴季陶宴川军各驻京代表冷杰生等20余人，劝告息争。

  • 1932年10月16日讯：全国各地邮工抗日殉难烈士追悼大会在沪举行，陆京士主祭，中央及沪各界代表均参加。

  • 1932年10月16日讯：山东日照县共产党率领农民、雇工千余人在北乡于家村、安家岭，西乡山子河、牟家小庄子，南乡平家村等处暴动，鲁陆海军同时出动镇慑。

  • 1932年10月16日讯：吉林抗日义勇军冯占海部围攻吉林市，在小白山、温德河子与日伪军激战一昼夜始退。

  • 1932年10月16日讯：上海救国团体联合会常务理事熊希龄等致电国民政府及中央党部，建议将党务经费移充东北义勇军饷械之用。

  • 1932年10月16日讯：国联中国代表颜惠庆、顾维钧、郭泰祺电外交部，谓鲁、川内战，国际对华舆论恶劣，影响中日问题者至大，望政府力予制止。

  • 1932年10月16日讯：废止内战大同盟四川分会在重庆成立。

  • 1932年10月16日讯：马占山与苏炳文在扎兰屯举行会议，决分兵三路攻打齐齐哈尔，终因敌强我弱未能实现。

  • 1932年10月16日《申报》：南京息，今日下午此间接天津消息，昨晨日机炮轰热河之南岭，华北人士对于日军此举是否为示威性质，抑系大举之先升，意见不一。另有消息，谓日军事当局已调兵六旅（注：旅团），准备大举攻击热河东边之义勇军。（15日路透社电）

  • #抗战影像#东北义勇军骑兵正奔赴前线。

  • 1932年10月16日《申报》：北平息，救国军董荣久部占领女儿河车站后，日军屡以飞机轰炸，并时遣伪军扰乱。13日黄昏，敌方甲车一列，由锦州开来，并有日、鲜步骑炮联队二千余名，由坦克车掩护，向救国军猛袭。我军由王永良指挥大刀队迎击，乘夜冲杀，砍伤敌众。14日午，敌不支，全军向锦州撤退。（15日专电）

  • 1932年10月16日《申报》：山海关息，朱霁青亲督国民救国军马子丹、孟晤炎、李海峙等部，攻击义县城，与日军步骑炮兵，约700余人交绥，战斗极猛烈。救国军袭敌前路，并潜入城内扰乱，乃退却。双方互有伤亡，仍在相持中，闻日军此次再锦朝线增厚兵力，全在防阻朱部，并由驻锦铃木旅团长，躬亲指挥云。（15日华联社电）

  • 1932年10月16日讯：冯占海部未跟随主力一起行动的邓乃柏和张纯玺部攻占扶余县城，阵亡30余人，协同作战的红枪会亦阵亡30余人，邓乃柏和张纯玺部在扶余县城夺取大量物资，并在营救的船工帮助下渡过松花江，继续西行，此后除在乾安地区遭汉奸武装袭击外，基本安全地越过四洮铁路，进入草原。

1932年10月15日

发表于 2021-10-15 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月15日讯：国民政府准国联行政院代表颜惠庆辞职，特派顾维钧继任。

  • 1932年10月15日讯：驻满洲里苏联领事应日政府之请，致文苏炳文，请求释放被俘之日侨移居俄境。22日苏炳文照会苏领事，允其所请，决照日领署所开名单予以释放。

  • 1932年10月15日讯：济南地方法院公审郑继成刺张宗昌案，律师谓郑非预谋杀人，应请减刑。19日，该案判决，以预谋杀人罪判郑有期徒刑七年。

  • #抗战影像# 一二八淞沪抗战中：一位中国士兵（图左）正在审问一名中国人，后者坦白说接受了日本人的贿赂，以便在闸北纵火。他随后被那位士兵所处决。￼

  • 1932年10月15日讯：蒋介石电新编第二十三师师长罗泽洲顾全川局，竭力避免冲突。

  • 1932年10月15日讯：由于谢立功、费侠告密，陈独秀在沪被市公安局会同公共租界捕房逮捕。同时被捕者有谢少山、王武（即宋逢春）、王兆群（即罗世凡）、张次南（即彭述之）、濮一凡、王晓春、梁有光、王之平、何阿方、王剑堂共11人。

  • 1932年10月15日《申报》：北平息，义勇军郑桂林部自进攻绥中兴城两县城后，所部仍布置附近一带，近日驻绥重鱼石附近郑部，时与前卫日军冲突，双方各有伤亡。（14日专电）

  • 1932年10月15日《申报》：哈尔滨息，据日军在与义勇军交战时所遭之死伤报告观之，义勇军现用榴弹炮与野 战炮，且发炮甚能命中。10月9日、10日富拉尔基附近战斗中，日军自称死11人、伤234人，日军受6寸（注：6英寸，为152毫米）、三寸（注：76.2毫米）野 战炮与机关炮猛而有效之轰击云。众信如义勇军弹药充足，则定可获更大胜利。（13日路透社电）

  • #抗战影像#在侵略我东北的作战中，一个日军炮兵小组正在检查一门可能是撤除了防盾的明治三八式野战炮。

  • 1932年10月15日《申报》：北平息，救国军张鸣五部与陆雨田部联络，双十节由胡家窝棚出发，再度攻锦。12日午克大凌河，并占领车站，伪奉山路交通断绝。13日晨克双阳甸车站，刻距锦仅40里，驻锦日军恐慌，应战大败，死伤百余，有逃走模样。（14日专电）

  • 1932年10月15日《申报》：山海关息，义勇军在义县西50余里之刘龙台结合，与在义县集中之日军歩骑炮约五百余人。在头道河子一带，发生剧战。日炮火猛烈，焚民房甚多，义勇军抄日军后路，日军乃退却，互有伤亡20余名。（14日专电）

  • 1932年10月15日讯：吉林救国军冯占海部主力在穿越四洮铁路时。遭到日军铁甲车隔绝，路东部分遭日军追击，大部溃散，冯占海与部队失去联系，后在百姓帮助下改装成木工，穿过封锁线，重新收容散兵，约2万余人。

  • 1932年10月14日讯：牛兰夫妇移押南京第一模范监狱，执行无期徒刑。

  • 1932年10月14日讯：周恩来、朱德签发《工农红军一方面军战役计划》。又称《建（宁）黎（川）泰（宁）战役计划》。

  • 1932年10月14日讯：外交部长罗文幹飞汉口，征询蒋介石对《国联调查团报告书》之意见。罗在汉对记者称：“国人于此时研究报告书外，尤应留意国际情势及日人态度。”

  • 1932年10月14日《申报》：北平息，日人派员改组东北兵工厂，内分5部：1）制造飞机部；2）毒瓦斯部，将由大连日人毒瓦斯制造厂机械运沈改装；3）枪炮制造及修理部；4）子弹制造厂；5）火药制造厂。必要时将设无线电机械工厂。（13日专电）

  • 1932年10月14日《申报》：北平息，热边蒙古自治军包善一部八千余人，佟连升部约一千余人，黄海山部约一千五百余人，包殿卿部约一千余人，去年“九·一八事变”后，一致抗日，绝不受日人利用。惟日方最近，除增加正式军队外，又在通辽征兵一千余，并在各处招有蒙军四千余人，经日军指挥，目下正在钱家店、通辽、仁发等处集合。更在当地征发大车数百辆，积极动作，日机连日向热边侦察，不时散发传单，鼓吹满蒙联合独立。（13日专电）

  • 1932年10月14日《申报》：北平息，义勇军宣称队女队员苏秀贞、王毓秀、马淑娴等赴义县一带，宣称抗日工作。义县民众激昂，加入义勇军者甚踊跃。日军派侦探间谍，寻捕该女宣传员，并派飞机散传单，谓此项女宣传员，系女马贼，不得信其妖言等语。（13日专电）

  • #抗战影像#在马家寨准备出发“讨伐”我抗日义勇军的日本关东军士兵。

  • 1932年10月14日《申报》：沈阳息，九月杪（注：月末的意思）左右在满洲西北失踪之日本载客飞机一架，兹悉该机乃九月二十七日由哈尔滨飞往满洲里。当日降落满洲里飞行场时，即为义勇军包围，驾机者见势不佳，即复飞起，但所载之二日客已离机，致落敌（注：原文如此，指义勇军）手。该机希图飞回哈尔滨，旋在中东路西段某车站附近被迫降落。机中之人即将机损毁，继图逃亡，而卒为义勇军所俘。有少佐一员，上尉一员，已遭枪毙，余两人被押往海拉尔。（12日路透社电）

  • 1932年10月14日《申报》：山海关息，辽东义勇军中韩联合军总司令李棱然，率第二路司令孙冠美五千余人，在海龙之北朝阳镇附近，与日军于12日夜11时接触。日军约二千左右，用轰炸机投掷炸弹，并用迫击炮轰击。孙部仅有手 枪及手榴弹，战至5时，孙部佯退至海龙附近，突起伏兵二千余人，均以大刀冒枪林弹雨冲入日军砍杀。敌不支，狼狈败走，孙部捡得步枪四百余枝，日军官兵死伤三百余人，孙部亦损失数百人。（13日华联社电）

  • 1932年10月14日讯：国民党第一集团军特别党部通电指摘《国联调查团报告书》，称报告书“无一非破坏我主权独立，干涉我自由，而为迁就强权欺压弱国之乖谬论调”；“所谓国联调查团者，不啻强国雇用之巡捕，徒为虎作伥，而不能为弱国主持公道”。
