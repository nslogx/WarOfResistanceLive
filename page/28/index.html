1932年04月01日

发表于 2021-04-01 更新于 2021-08-14 分类于 局部抗战(1931-1937)

  • 1932年4月1日讯：卫国阵亡将士遗族抚育会正式成立，选举许世英、史量才、朱庆澜、王晓籁、虞洽卿等41人为执行委员。

  • 1932年4月1日讯：北平大学校长沈尹默及各学院院长以经费困难，向教育部总辞职。

  • 1932年4月1日讯：军政部电赣“绥靖”公署，允月拨50万元充反 共军费。

  • 1932年4月1日讯：第十军军长徐源泉率第四十一、四十四、四十八师，分别从湖北孝感、天门、沙洋出发，三路进攻天门瓦庙红军贺龙等部。

  • 1932年4月1日讯：外交部抗议日政府嗾使伪满强接海关，截留盐税。

  • 1932年4月1日讯：三民主义力行社特务处（亦称复兴社特务处）在南京成立。戴笠任处长，设一室二科，唐纵任书记室书记，郑介民任侦察科科长，邱开基任执行科科长。后增设交通科，梁干乔任科长。编制145人。

  • 1932年4月1日讯：国民政府将意见书交国联调查团李顿，内容分：一、中日甲午前后之国交；二、中日历年之悬案；三、东北铁道之关系；四、辽案突发之真相；五、上海事变之经过；六、和议谈判之进行；七、我国政府之意见。

  • 1932年4月1日讯：蔡廷锴在京对蒋介石谈，上海系中国领土，日军撤退，应以撤回本国为合理，若撤兵时间不确定，则停战会议之效力等于零。

  • 1932年4月1日讯：马占山派少将参议韩述彭以视察为名赴拜泉、海伦一带，密嘱其到后捏报部队不稳消息，今日遂以拜泉、克山驻军军心不稳，亲去镇慑为由，离开龙江，前往拜泉，其部下步骑各一营以牧马为名，先期离开龙江。

  • 1932年4月1日讯：英使蓝普森邀中日代表及各使举行茶会，向中日双方调停沪战。外交次长郭泰祺表示日军最后撤兵期必须明白规定。日方仍坚持须视以后情形而定。

  • 1932年4月1日《申报》：北平息，十三路义勇军27日在绥中附近松树岭，与日军百余名，携山炮二门机枪四挺接触。激战通宵，日军死营长（原文如此，因为大队长）一名，伤亡甚众。28日日军援兵80余名开到，并携山炮多门，我军因子弹不给，退六家子村一带，待机反攻。（31日专电）

  • #抗战影像#侵占我东北的日本关东军在一次作战后，俘虏了一批义勇军战士（也可能是抗日的胡匪）并缴获了其武器。

  • 1932年4月1日《申报》：北平息，日军定一日协同马占山、张海鹏、熙洽等部攻农安自卫军，熙部及吉林铁路守备队充右翼，日军清水及黑石两部与奉天守备队野|炮队充正面，张海鹏部充左翼，马占山部充北方部队。（31日专电）

  • 1932年4月1日《申报》：南京息，国联调查团定一日晚九时，乘怡和公司隆和轮赴汉，并定一日下午四时，再与我当局会晤，交换意见。（31日专电）

  • 1932年4月1日讯：国民政府急电沪停战会议中国代表郭泰祺，详示对日军撤退问题之方针，对撤退时间及暂驻区域均作规定。

1932年03月31日

发表于 2021-03-31 更新于 2021-08-14 分类于 局部抗战(1931-1937)

  • 1932年3月:天津大公报社是月代收天津各界捐款10.4万余元慰劳第十九路军及救济上海难胞。

  • 1932年3月:伪满国务院通令伪民政部转知各中小学校：“着暂用四书、《孝经》讲授，以崇礼教。”

  • 1932年3月31日讯：国民政府令湖北陆、空军联合进攻洪湖贺龙红三军，以徐源泉任指挥。

  • 1932年3月31日讯：国民党中央政治会议决议：任吴忠信为安徽省政府主席，陈调元专任安徽省“绥靖”主任。

  • 1932年3月31日讯：蔡廷锴电劝粤方陈济棠等将领，为抵抗暴日，“国内诸公虽有杀父之仇，都可捐弃”。

  • 1932年3月31日讯：南京新闻界发表《敬告国联调查团书》，揭露日本自九一八至“一二八”之暴行，表示“中国无论如何，决不以尺土寸地让人”，“东三省一日不收回，在华日军一日不撤退，中国人民则一日不停止其抵抗暴日之行动，任何牺牲，在所不惜”。

  • 1932年3月31日讯：中日停战会议通过第二项原则，日军撤至1月28日前之原防；但撤兵日期，日方以须视秩序能否恢复为辞，不作肯定。

  • 1932年3月31日《申报》：北平息，榆关电，日人闻调查团将北上，关东军司令部发出命令，将伪奉山路附近及各站驻军，均暂撤至南满铁道附近附属地，俟调查团调查后，再恢复防地。（30日专电）

  • 1932年3月31日《申报》：北平息，自卫军克农安，熙洽所部及日军败退，城内日人全部逃出避难，长春震动，沈阳亦恐慌。（30日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，守候在上海某处街垒后的日本海军陆战队员。

  • 1932年3月31日《申报》：哈尔滨息，丁李来哈代表王之佑被软禁，丁李不肯妥协，惟邢占清部因胁诱，将单独投降与熙洽。王德林之救国军，因日军再吉敦路增援，已率众折回使日韩侨限于恐慌，日方谋增兵往攻。（30日专电）

  • 1932年3月31日《申报》：南京息，顾维钧以沪停战会，因日方故意拖延，迄无结果，实违国联大会决议案，29日晚30日晨，两晤调查团主席委员李顿爵士，商谈良久，闻李表示，决促进沪会成功，至我国代表参加调查团，系遵国联决议，当不致有何问题。（30日专电）

  • 1932年3月31日讯：日机一架飞江阴侦察。沪前线日军数百人向我纪王庙附近之北渡场及陶泥巷两处进攻，被我军击退。

  • 1932年3月30日《申报》：北平息，吉自卫军李海声部围攻农安后，熙洽部千五百名，及日军千名，正抗战中，日飞行队今晨飞农安。（廿九日专电）

  • 1932年3月30日讯：国民政府令准贵州省政府主席毛光翔辞职。
