1932年08月27日

发表于 2021-08-27 更新于 2021-09-11 分类于 局部抗战(1931-1937)

  • 1932年8月27日讯：国民政府任命蒋伏生为陆军第八十三师师长。

  • 1932年8月27日讯：陈诚部占领江西宜黄。红军向广昌、宁都、东韶方面撤退。

  • 1932年8月27日讯：日本公使馆代办矢野到南京，就锄奸团警告奸商事向外交部提出抗议。

  • 1932年8月27日讯：山西省商会以晋税奇重，商况艰窘，无力担负，特向省政府请求豁免所得税，如不允许，即拒绝缴纳营业税。

  • 1932年8月27日讯：上海虹口各人民团体以日浪人在虹口路一带横行，本月10日日军又在扬州路等处刺伤华人多名，特开紧急会议，议决推派代表向市政府请愿，要求制止日浪人在虹口一带活动，并赔偿损失。

  • 1932年8月27日讯：日本制定《从国际关系角度看时局处理方针》，令关东军暂停向热河进攻。

  • 1932年8月27日《申报》：北平息，第四路义勇军常秀山部马队四千余，及步兵万余人，迭在东丰沙河镇一带，与于芷山逆部激战，于部损失极重。（26日专电）

  • 1932年8月27日《申报》：山海关息，郑桂林部义勇军，25日夜向前所车站袭击，与日军互战4小时，日军不支，山海关守备队派兵80余名往援，义勇军始退。是夜炮声隆隆，榆关城内听闻不断，至拂晓始息，晨往援日军回榆。（26日专电）

  • #抗战影像#在东北山林中打击日本侵略者的义勇军战士们。

  • 1932年8月27日《申报》：北平息，义勇军在义县车站，埋地雷三枚。24日夜，日军用车一列，满载军需品，经该处中地雷，炸毁军用车一辆，机车一辆，毙日兵九。轨道炸断十余段，损失甚重，锦朝车25日起停开。（26日专电）

  • 1932年8月27日《申报》：山海关息，开鲁县24日有日机4架在北门外投弹30余枚，并用机关枪向下扫射，损害甚重。该县驻有热骑兵旅，当时力持镇定，如日军逼近，必竭力抵抗，旅长崔新五已将被炸事实，电告各方。（26日专电）

  • 1932年8月27日讯：废止内战大同盟会在上海开全国代表大会，到各省、市代表449人，宣布大同盟会正式成立，推吴鼎昌、王晓籁、朱学范等57人为常委，马相伯、段祺瑞、胡适等15人为名誉委员。28日闭会，宣言称该会“誓期消弭内战，共御外侮”。

1932年08月26日

发表于 2021-08-26 更新于 2021-09-11 分类于 局部抗战(1931-1937)

  • 1932年8月26日讯：晋省虎疫（霍乱）猖獗，蔓延28县，死一万余人。

  • 1932年8月26日讯：北平东郊农民700余人向市政府请愿，反对“公益捐”。

  • 1932年8月26日讯：教育部决定，各大学经费自8月份起先发五成。

  • 1932年8月26日《申报》：山海关息，南满铁总裁林博太郎莅职后，视察沿线各地，16日夜车过鞍山南返，义勇军往袭击，被逃脱，抵辽后谓人，满洲之不安，殊出人意外。（25日华联社电）

  • 1932年8月26日《申报》：北平息，据热河最近消息，日前侵热之日军，现仍盘踞热河边境内20里之南岭镇，其兵力仅有铁甲火车3列，及兵士350人。闻汤玉麟部下已夺回口北营子，自星期二晨起，未有战事，但有义勇军一队，现攻击日军后路，及其由南岭至锦州之交通线，又义勇军千余，进攻朝阳寺，恶战3小时，日军以重炮轰击，故义勇军昨已退走。闻日军乘铁甲火车一列，驰往朝阳寺援应，日机飞至口北营子与北票侦察，并放机关枪向两处射击。（25日路透社电）

  • 1932年8月26日，“宁海”号巡洋舰从日本驶抵上海交付，为当时中国海军最先进的军舰，后于9月1日举行升旗入役仪式，被编入中国海军第一舰队。

  • #抗战影像#一名身着冬装的日本关东军士兵。

  • 1932年8月26日《申报》：北平息，受日方收买久在热边骚扰之蒙匪，多为土木特左旗、土木特右旗及阿拉沁右旗壮丁。近不甘日人利用，集合八千余人，枪 支齐全，为日方供给，全部反正，向热当局投诚，愿任抗日前驱。（25日专电）

  • 1932年8月26日讯：行政院会议决议：侨务委员会委员兼常委曾仲鸣辞职照准，任命梁宇皋为侨委委员兼常委。30日，国民政府明令发表。

1932年08月25日

发表于 2021-08-25 更新于 2021-09-11 分类于 局部抗战(1931-1937)

  • 1932年8月25日讯：北平军事整理委员会举行常会，决议：一、张学良请辞委员职慰留；二、北平军整会改称北平军事训练委员会。

  • 1932年8月25日讯：罗家伦请辞中大校长任命。26日，行政院决议慰留。

  • 1932年8月25日讯：郝梦龄第五十四师“围剿”鄂豫皖红四方面军，是日占罗田，红军转移英山。

  • 1932年8月25日讯：上海抵制日货运动发生三星期以来，截至目前，在沪堆积日货达9000万元之巨，是日驻沪日陆战队司令杉坂下令组织陆战队特别警备队，从事防遏一切抗日抵货运动。

  • 1932年8月25日讯：日外务大臣内田在国会发表侵华演说，宣称日政府准备立即承认伪满洲国，并谓日对华军事行动，并不违反《九国公约》与《非战公约》。继称日新外交政策在确立远东门罗主义。

  • 1932年8月25日讯：国民党中常会开会，汪精卫主席，决议行政院长由宋子文代理。

  • 1932年8月25日讯：中华苏维埃共和国临时中央政府为牛兰夫妇被判无期徒刑发表宣言，向国民政府提出抗议，号召“全世界全中国民众一致起来，坚决反对献媚帝国主义的南京国民党政府对于牛兰及其同案妇人之判决，立即释放牛兰及其同案妇人”。

  • 1932年8月25日《申报》：北平息，图什业图王府忽发现义勇军千余名，一部进洮南城内，将公安局武器取去，日方因青纱帐起，迭被袭击，力谋应付方法。（24日专电）

  • 1932年8月25日《申报》：北平息，攻沈义勇军仍聚集郊外，到处袭击，日军紧守城门，苏家屯浑河被义勇军攻陷，安奉路仍不通，沈阳戒备甚严。（24日专电）

  • #抗战影像#在东北前线坚持抗击日本侵略者的义勇军战士。

  • 1932年8月25日《申报》：北平息，23日锦朝线大窑沟义勇军与日军激战，日铁甲车三列集中朝阳寺，该地约日兵500余，锦州驻日军约5千名，又热军董福亭旅，仍扼守口北营子。日铁甲车三列，兵三百余，仍据南岭，占领破庙子三宝营子之日军，23日撤回南岭。今晨起，热边无战事。（24日专电）

  • 1932年8月25日《申报》：北平息，义县及锦朝支线日军，因后方义勇军牵制，未敢前进。前锋仍在南岭子破庙子一带，与董福亭旅相持中。（24日专电）

  • 1932年8月25日讯：宋庆龄、蔡元培因牛兰夫妇被判无期徒刑，特向国民党中央请求予以特赦。居正至中央党部访汪精卫、叶楚伧等会商解决办法，汪称能否给予特赦，应由司法当局考虑。

1932年08月24日

发表于 2021-08-24 更新于 2021-09-11 分类于 局部抗战(1931-1937)

  • 1932年8月24日讯：山西省水灾，遍及56县。

  • 1932年8月24日讯：张群辞军委会北平分会委员，蒋介石致电慰留。

  • 1932年8月24日讯：锦朝线日军在南岭一带与热军董福亭旅相持中。日机五架晨飞朝阳、赤峰侦察。

  • 1932年8月24日《申报》：山海关息，锦朝路火车不通，义县以北被义勇军截成数段，义勇军刻向义县进攻，将日军包围，战事剧烈。23日，日飞机10余架飞往助战，热边形势缓和，双方相持中。（23日专电）

  • #抗战影像#热河战事期间，一队日军正在使用步兵炮向中国热河守军部队轰击。

  • 1932年8月24日《申报》：南京息，外部对日侵热河，除电知颜惠庆向国联提出报告外，23日已向日方提出严重抗议。（23日专电）

  • 1932年8月24日《申报》：北平息，汤玉麟23日电孟照田汤佐辅云，日方铁甲车已实行开至南岭破庙子地方，与我军突行开火，意图前进。我方已饬前线将士誓死坚守口北营子地方，并饬工兵运去炸毁铁桥工具，一面由张顾问督饬民团抵抗，朝阳附近义勇军均与我军合作，士气大振，余续电告。（23日专电）

  • 1932年8月24日讯：国民党中央政治会议通过《中美公断条约》。条约规定签字国间一切纠纷，应交公断，不得诉诸武力。26日，立法院通过。9月24日，国民政府批准《中美公断条约》。12月15日，驻美代办严鹤龄在华盛顿与美国政府正式换文，条约即日生效。

1932年08月23日

发表于 2021-08-23 更新于 2021-09-11 分类于 局部抗战(1931-1937)

  • 1932年8月23日讯：晋南永济县黄河决口。

  • 1932年8月23日讯：东北义勇军进袭铁岭。义勇军郭景珊等部进攻抚顺。

  • 1932年8月23日讯：为赈济东北难胞，上海各慈善团体赈济东北难民联合会是日在沪成立，推史量才、王晓籁、郑洪年等七人为委员。

  • 1932年8月23日讯：沪银界推张嘉璈、卢润泉、胡笔江三代表会见宋子文，要求缓征纸币税。

  • 1932年8月23日讯：北平政委会例会，张学良请辞委员职，决议慰留。

  • 1932年8月23日讯：蒋介石以第二师第八团团长杨少初，第十师营长郭罳、石泽乾，第八十三师连长李肇中，在“剿共”战争中“临阵退缩”，令就地枪决。

  • 1932年8月23日讯：行政院会议决议：一、任罗家伦为中央大学校长；二、管理中英庚款会董事程振钧病故，简派李四光补任；三、准甘察青宣慰使贺耀组辞职。

  • 1932年8月23日《申报》：北平息，日军占南岭后，各地民众纷组民军，朝阳设民军总司令部，援助军队抗日，义勇军葛文华部在七里河子、泥河子，进扰日军后方，欲收服义县断日军后路，迄昨夜我军民及义勇军，联合一致，正与日军混战，日军不支，向锦州求援。锦州有兵车一列，载兵500余，往援南岭日军，热当局致电驻守建平赵国增旅，向朝阳增援。（22日专电）

  • #抗战影像#在一次战斗结束后，日军发现受伤后还有生命迹象的义勇军战士，残忍地用刺刀将其刺死。

  • 1932年8月23日《申报》：南京息，关于最近日军改行侵热事，据汪于中常会会谈话会后语人，中央及外部，已接到北平电报，关于日军发动及热军抵抗情形，有所报告。大致与报载相同，中央对此，已抱定宗旨，如日军前进，当然加以抵抗，已电汤玉麟，令其本守土之责，坚决抵抗，勿稍迟疑。（22日专电）

  • 1932年8月23日《申报》：南京息，今夜接官电，日铁甲火车现正进攻热河，已推至南岭，该处驻军已退至口北营子，拟炸毁铁路桥，以阻日军续进。（22日路透社电）

  • 1932年8月23日讯：外交部就日军侵热事令蒋作宾公使向日提严重抗议，要求从速停止军事行动；并声明因此事件所引起之一切纠纷应归日方负责。
