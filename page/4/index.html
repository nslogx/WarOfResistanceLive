1932年07月17日

发表于 2021-07-17 更新于 2021-08-01 分类于 局部抗战(1931-1937)

  • 1932年7月17日讯：天津《益世报》创始人杜竹轩因心脏病突发逝世。

  • 1932年7月17日讯：闽省红军占华安。

  • 1932年7月17日讯：国民党中央政治会议通过整理产区盐税暂行税率，是日公布。原轻税地区税率均有增高，最高者增税1.45元。原有税率最低者仅0.3元，增后为一元。原有最高者为5.5元，增后为六元。

  • 1932年7月17日讯：江苏省援助东北义勇军、反对上海停战协定民众大会在上海共和剧院开会，被上海公安局侦悉，派警包围，捕去94人，并搜出各种革命文告、刊物、证章、密码本等。其中88人于21日解送淞沪警备司令部，28日审讯。29日解往南京。

  • 1932年7月17日讯：鄂省组织“剿共义勇队”，本日公布章程，县设总队，区设大队。凡15岁至45岁之男丁均编入。

  • 1932年7月17日讯：蒋介石决定对鄂、豫、皖三省红军“清剿”计划，分三步进行：先鄂，次皖，再豫。

  • 1932年7月17日讯：第五军军长张治中再次请辞军、师长各兼职，并请升王敬久为第八十七师师长；所遗第五军军长职，请派员接任或撤销，“以节糜费”。9月7日，国民政府令准张治中辞职，任命王敬久为第八十七师师长。

  • 1932年7月17日讯：日军借口关东军联络员石本权四郎在热河境内被义勇军扣押，铁甲车二列向朝阳寺进犯，我军阻拦，即被开枪射击。次日，日机五架飞朝阳轰炸，投弹30余枚，步兵第三十一联队一部占朝阳寺。

  • 1932年7月17日讯：日本陆战队200余人自上海停战协定中所规定之D区（东自沙泾港起，沿淞沪铁路至横浜桥止；北自沙泾港起，沿新市路至奚家桥止；西自奚家桥起，沿水电路至八字桥止；南自八字桥起，沿日本公墓循横浜河至横浜桥止）撤退，上海撤兵区域接管委员会及市公安局、保安队前往接收。

  • 1932年7月17日《申报》：北平息，长春电，俄军舰抵富锦，驻桦川依兰日军避免冲突，8日退出。（16日专电）

  • #抗战影像#伪满洲国时期，伪宫廷的菜谱。

  • 1932年7月17日《申报》：大连息，16日上午记事解禁。关东厅警察探悉，韩人决死队从上海到大连，将乘5月26日国际调查团来连之际，加以暗杀，以陷日本于国际的危地，即暗中戒备。于调查团到连之二日前，即5月24日晨，在大连市乃木町鲜人船员某之住宅，检举决死队员柳相根（25岁）及崔兴植（21岁）两名，得以防祸未然。此事前禁各报刊载，今日始行解禁，此二犯人，均属于以上海为根据地之韩国假政府爱国青年团，与1月8日樱田门不祥事件，及上海虹口公园爆弹事件有关。检举之际，搜得大响手 枪一支，及巧装于水筒内之炸弹一枚，与上海炸案所用炸弹相同。（16日电通社电）

  • 1932年7月17日《申报》：北平息，吉敦路拉法站附近六家子、五家子等处义勇军，与日军激战，日军死12名，伤7名。由拉法站输送收容死伤之列车，9日晨至六道河子，被义勇军用手榴弹袭击，列车及铁道被炸毁数处，运输停顿。（16日专电）

  • 1932年7月17日讯：牛兰夫妇经宋庆龄、蔡元培、杨杏佛具保，出狱移南京鼓楼医院就医，法院派警前往看守。

1932年07月16日

发表于 2021-07-16 更新于 2021-08-01 分类于 局部抗战(1931-1937)

  • 1932年7月16日讯：财政部发表6月份海关贸易额入超4000余万元，日货进口骤升至第一位。

  • 1932年7月16日讯：国民政府任命马鸿逵为陆军第三十五师师长。

  • 1932年7月16日讯：北江方面粤军改编为两个纵队：第一纵队攻南康，以余汉谋为总指挥；第二纵队攻信丰，以香翰屏为总指挥，限期克复信丰、南康。

  • 1932年7月16日讯：第十九路军军长蔡廷锴在福建漳州开军事会议，动员“剿匪”，其第六十、第七十八两师除留一团守漳州外，其余全部限三日内向闽西前方推进。

  • 1932年7月16日讯：蒋介石在汉口再度召集湖北各县长训话，令其效法曾国藩、左宗棠，并分赠手编之《曾左语录》一册。

  • 1932年7月16日《申报》广告：胜利公司纪念忠勇卫国之19路军爱国歌曲唱片。

  • 1932年7月16日《申报》：哈尔滨息，榆树近郊之“满洲国”马队二百人哗变，城内“满洲国”军队均被缴械。叛军突向日军攻击，但据日方报告，华军卒被击散，阵亡及就擒者五六十人，日军死五人伤十人。（15日路透社电）

  • #抗战影像#伪满洲国时期，新京大同广场（今长春市人民广场）上的顺天安民塔，光复后被拆除。

  • 1932年7月16日《申报》：齐齐哈尔息，战死之远矢忠大尉，系鹿儿岛县人，去年12月，嫩江之役，左肩受创甚重，仍跃入敌之堑壕，素有猛勇之称云。（15日电通社电）

  • 1932年7月16日《申报》：齐齐哈尔息，本月12日夜李海青统率边防军第9旅及由红枪会编成之部队，共约数千，猛袭齐克线拉哈尔，守备该地之日本远矢部队，仅以XX名（原文未具体透露，可能为几十）之寡兵，于小园江援兵未到以前，努力防战，死守拉哈尔，与黑龙江满洲军协力奋战。李部卒余30余名，其他四散。此次激战之结果，远矢大尉小林二等各战死，负伤6名，非战斗员中各长谷川满铁社员等，亦负伤，其他详情不明。（15日电通社电）

  • 1932年7月16日讯：何应钦致电陈济棠、李宗仁、蔡廷锴、何键，商定“剿匪”军事计划，即以粤军主力由粤北向赣南推进；湘、桂军由湘、赣边东下；闽军由武平、长汀、上杭向瑞金、石城进攻；赣军则自永丰、南丰之北向宁都、广昌以袭红军后方。五省动员总兵力约在30万人以上，对中央苏区之宁都、瑞金、石城、广昌、会昌、寻邬、雩都、兴国、汀州、宁化、上杭、武平等县形成大包围圈。

1932年07月15日

发表于 2021-07-15 更新于 2021-08-01 分类于 局部抗战(1931-1937)

  • 1932年7月15日讯：浙江嘉兴、桐乡交界之濮院镇贫苦农民结队向米行抢米；同日，镇海人民因田赋附加超过正税一倍多，举行抗捐运动。

  • 1932年7月15日讯：沈阳邮局被伪满劫夺，邮务长巴立地被迫办理交代，副邮务长刘耀庭脱险到北平。20日，邮政总局负责人对远东社记者称：东北邮政乃东北交通经济之主要命脉，决不能任人劫夺，必要时决将东北邮政全部封锁，亦所不惜。

  • 1932年7月15日讯：上海国际电台致电交通部，以该部与美国马凯公司密订无线电报务等合同，“实足危害我国甫经自主之国际通讯事业”，请立予撤销合同。

  • 1932年7月15日讯：全国高等教育问题讨论会在沪举行，到各地代表67人，交通大学校长黎照寰报告筹备经过，沪江大学校长刘湛恩致欢迎词。大会连开三日，通过增进高等教育效能、大学教学问题、普及体育、提高专任教员薪额等提案24件。17日会议闭幕。

  • 1932年7月15日讯：外交、财政两部决封锁东北海关，由各关代征东北入口税。

  • 1932年7月15日讯：中共苏区中央局发表《告前线红军战士书》，号召粉碎敌人第四次“围剿”，提出红一方面军要“迅速地夺取赣江流域中心城市，来实现江西首先胜利”。

  • 1932年7月15日讯：左路军司令何成濬、副司令徐源泉率部十余万人向鄂洪湖根据地红三军贺龙部发动总攻。

  • 1932年7月15日讯：国联调查团团长李顿偕秘书哈斯离日来华。17日顾维钧过津赴青岛迎候。19日，国联调查团抵青岛，次日抵北平。

  • 1932年7月15日讯：牛兰夫妇绝食消息传至欧洲后，欧洲各界异常愤怒。是日，巴黎劳动界、文化界向中国公使馆示威，柏林大学教授联名质问南京国民政府，英国独立劳动党领袖舍克司登亦向南京提严重抗议，要求释放牛兰夫妇。

  • 1932年7月15日讯：宋庆龄、蔡元培、杨杏佛决再为牛兰夫妇作保，并要求依《危害民国紧急治罪法施行条例》第一条规定，将牛兰夫妇移沪高等法院分院受理。保状由陈瑛、斐斯两律师夜车赴南京呈递。

  • 1932年7月15日《申报》：哈尔滨息，华人韩凤苍（译音）近为宾县军事当局拘获，供认为南京政府秘密工作员，兹已在傅家甸处决。闻韩曾在当地军界中作反“满洲国”宣传。（14日路透社电）

  • #抗战影像#伪满洲国时期伪皇宫缉熙楼，为“皇帝”溥仪和“皇后”婉容、庆贵人谭玉龄居住的寝宫。

  • 1932年7月15日《申报》：哈尔滨息，驻扎哈尔滨以南榆树县城南之伪国军250余名，12日午后4时，突起兵变。对于日军，为猛烈之奇袭，虽被川桥支队击退，击毙40余名，并有多数负伤。然日军以事出不意，亦战死7名，负伤10余名。（14日电通社电）

  • 1932年7月15日《申报》：北平息，日军在黑增加兵力，大部集中呼海齐克两路，我军离铁路线，利用野战，9日在林甸炮击日军。日军阵亡少将官佐，当进至安达站，日军急调驻昂昂溪大部援应。我无后援暂退，恐最近将有剧战。马占山曾一度到绥，布置防御工事。（14日专电）

  • 1932年7月15日讯：国民党南京市执委会决议，请国民党中央函国民政府转令司法机关，对牛兰夫妇“应依法办理，不得瞻徇”。

  • 1932年7月15日讯：宋子文、何应钦、刘瑞恒等飞赴汉口，与蒋介石商洽“剿匪”经费，并报告“剿匪”计划。

1932年07月14日

发表于 2021-07-14 更新于 2021-08-01 分类于 局部抗战(1931-1937)

  • 1932年7月14日讯：据《大公报》讯：杭县四乡及海宁、德清各县乡镇，最近发生老妪抢米，少则三四百人，多则千余人。抢米风潮扩大至湖属一带。

  • 1932年7月14日讯：福州全市商民反对省政府以暴力强征房铺捐而罢市。市警察第一署署长施泰桢率警劝令开店，被众围殴重伤。

  • 1932年7月14日讯：蒋介石电令张学良从速处理热河问题，务请从速派队星夜驰进，以免受制于倭。

  • 1932年7月14日讯：蒋介石手谕湖北各县长：一、应厉行本党政纲对内政策；二、严格清查户口；三、全民军事化。

  • 1932年7月14日讯：蒋介石颁发《告匪区民众书》及《悬赏招抚胁从民众命令》四道，凡属胁从，一律优待，并悬重赏劝红军来归。

  • 1932年7月14日《申报》：北平息，辽西义勇军第一军于百恩等电告，桑林青堆子两端，毙敌甚众，望各方援助。（13日专电）

  • #抗战影像#伪满洲国时期，位于新京（长春）市上海路30号的日本总领事馆，后来被拆除。

  • 1932年7月14日《申报》：北平息，依兰有日机一架，日军舰四艘，全县日兵二百余。通河日军舰二艘，日兵230余。木兰有日舰一艘，滨江有日机13架，每日在空中示威。夜放探海灯，江岸日舰七艘，道外日军二百余，南岗百余。文化协会五十余，日领馆内三百余，日军舰上二百余，哈埠四周二百余，全哈共计日军千余名。（13日专电）

  • 1932年7月14日《申报》：北平息，吉林讯，李杜部有12旅，连日由马在周冯占海率领，三路攻敌，马攻至中东路磨刀路，冯逼近哈埠。（13日专电）

  • 1932年7月14日讯：国联调查团再晤日外相内田，内田表明日本不能放弃其固定政策，永远不能承认将东三省归还中国，并声称：“日本欲先等满洲地位稳定后，再与满洲国商订条约，同时承认满洲国。”

1932年07月13日

发表于 2021-07-13 更新于 2021-08-01 分类于 局部抗战(1931-1937)

  • 1932年7月13日讯：东北军第九旅旅长何柱国就任临永警备司令，辖临榆、昌黎、抚宁、卢龙、迁安五县。

  • 1932年7月13日讯：豫、鄂、皖三省党政委员会成立，蒋介石兼任委员长，并派定委员九人：张难先、仇鳌、彭介石、萧萱、洪陆东、贺衷寒、张群、杨永泰、耿伯钊。张难先为监察处主任；洪陆东为党务指导处主任；张群为政务指导处主任。

  • 1932年7月13日《申报》：北平息，沈讯，沈南北边门外挖战壕，昼夜巡守，防义勇军袭击。举行私产收没调查，城内调查注册被收没者三千余户。凡来平者，均被收没。沈伪市署总务处长邵伸系民党，因日人利用毕，特拘禁之。哈公安局长高齐栋，招宴日岛本中佐致辞。日认为有侮辱日军语，当场拘捕。哈中小学7日一律罢课，推李某代表，向叛逆交涉，叛徒在东京设代表公署。（12日专电）

  • 1932年7月13日《申报》：北平息，马占山所部，在林甸与日骑兵联队相持，本人在庆城附近指挥。（12日专电）

  • #抗战影像#伪满洲国“皇宫”内的勤民殿，“皇帝”溥仪用来举行仪式和大典的正殿。

  • 1932年7月13日《申报》：哈尔滨息，闻日军现已占据横道河子，查该处前为“满洲国”军所据守，后被中国义勇军逐出。（11日路透电）

  • 1932年7月13日《申报》：北平息，驻临江徐达三部8日夜由下马蹬分股渡江，以平壤为进攻目的地，长白李奎五正准备出动中。（12日专电）

  • 1932年7月13日讯：宋庆龄、杨杏佛在沪发表声明，谓“前因牛兰夫妇绝食十日，本人等出于人道观念，并基于与关系当局事前之谅解，故愿以个人资格保释，俾到沪就医，经努力两日，未达目的，同时司法部长罗文幹因此呈辞，现本人等不愿再出为牛兰等作保，希望罗氏即可打消辞意”。18日，罗文幹、郑天锡打消辞意，到部视事。
