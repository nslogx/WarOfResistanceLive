1932年04月05日

发表于 2021-04-05 更新于 2021-04-21 分类于 局部抗战(1931-1937)

  • 1932年4月5日讯：教育部长朱家骅赴平，将晤蒋梦麟、任鸿隽等，商平、津教费维持办法。7日朱抵平，表示平、津教款自3月份起可发五成。

  • 1932年4月5日讯：东三省邮务员工通电，反对伪满接收辽宁邮政管理局，宣布不受乱命，并停止东三省一切邮务。

  • 1932年4月5日讯：江海关二五附税库券基金保管委员会奉令改组为国债基金管理委员会。是日该会正式成立，选举总税务司梅乐和、王晓籁、李铭、虞洽卿、谢韬甫五人为常务委员。

  • 1932年4月5日讯：夏斗寅电军政部，请辞第二十一路军总指挥、第十三军军长及武汉警备司令各军职。

  • 1932年4月5日讯：国民政府任命吴忠信、罗良鉴、何其巩、叶元龙、程振钧、光昇、江彤侯、张鼎勋、吴叔仁为安徽省政府委员，吴忠信兼省府主席，罗、何、叶、程分别兼任民政、财政、教育、建设各厅厅长；任命贺耀组为参谋本部参谋次长；派胡世泽为出席国际禁烟顾问委员会第十五届常会代表。

  • 1932年4月5日讯：伪满洲国外交部电外交部拒绝顾维钧随国联调查团入境。

  • 1932年4月5日讯：中共中央发表《为以民族的革命战争反对帝国主义进攻苏联与瓜分中国告民众书》。

  • 1932年4月5日讯：国难会议沪会员张耀曾、黄炎培等66人电国民政府，陈述不到洛赴会理由，称政府既定国难会议以御侮、救灾、绥靖为限制，“则实施宪政之案，又无提出会议余地，与其徒劳往返，无补艰危，不如谢绝征车”。

  • 1932年4月5日讯：沪市府通缉闸北维持会长胡立夫、副会长汪度、警务处长常玉清。

  • 1932年4月5日《申报》：南京息，行政院据军部呈，各地义勇军睛赴国难，热忱深堪嘉许，然国防武力，有国防军为主体，继战事必须召集补充，亦须由政府统筹办理，决无自行组军之理。特训令各部会，嗣后一切义勇军及类似之组织，一律禁止，以重法令，而维秩序。（4日专电）

  • 1932年4月5日《申报》：东京讯，众料陆相荒木明日将请政府核准将第八与第十师团之尚未调出者，从4月中旬起遣往东三省，以替回日军占据沈阳后调往东省之朝鲜师团。（4日路透电）

  • #抗战影像#伪满洲国特修科学生的照片，他们在参加伪满洲国军后被授予中尉军衔。

  • 1932年4月5日《申报》：北平息，沈讯，沈阳时有日人及日军随时随地向当地居民发问“你是哪国人？”如答“是中国人”，即痛击。如答“满洲人”日人便谓你是好百姓。日人为防调查团，来各处收买汉奸，侦察居民行动。赵欣伯被派为招待调查团委员长。（4日专电）

  • 1932年4月5日《申报》：东京讯，闻日本两大商家三井与三菱，已得日政府之核准，将以债欵日金二千万元借与（伪）满洲国，此项借欵既无利息，又无担保品，仅五年内归还。此为三井与三菱向日政府请准在东三省投资之第一结果，闻其他重要商家现亦考虑同样资助东三省（伪）新政府事。（4日路透电）

  • 1932年4月5日讯：日代表植田发表声明，声称日军来华目的，在保护侨民及商务上权益，决无永占中国领土企图，撤退须视地方情形自主，不得限定撤退日期。同日，前线日军仍继续增援修筑工事。

1932年04月04日

发表于 2021-04-04 更新于 2021-04-21 分类于 局部抗战(1931-1937)

  • 1932年4月4日讯：伪满洲国向日本财阀三菱、三井无息、无担保品借款2000万日元。

  • 1932年4月4日讯：天津高等商业学校雪耻救国基金储蓄会及天津电报局机器房同人，响应救国飞机捐款，捐257元交大公报社保存，作将来购机之用。

  • 1932年4月4日讯：上海公安局破获公共租界戈登路701号共产党机关，逮捕金味园、谢铭远、柳青及陈仙曦等四人，并搜去大批文件。5日又捕女共产党员一人，均解送江苏高等法院第二分院。

  • 1932年4月4日讯：潮州旅沪同乡会电军政部反对屈辱条件，称中日停战会议不得有妨害中国领土完整、行政独立之条件。

  • 1932年4月4日讯：行政院训令各部、会，“嗣后一切义勇军及类似之组织，一律禁止”。

  • 1932年4月4日讯：国联调查团抵汉口，次日赴武昌视察，分别接见各界代表。

  • 1932年4月4日讯：汪精卫在沪发表谈话，声称：“国难会议会员为政府所聘任，并不是由人民选举，讨论国家大事是有限制的（按：以御侮、救灾、绥靖为范围），政府绝无以任何责任使所聘任的人负担的道理。”又称：“训政到宪政，须经过时间与条件”，政府的决心是把训政时期缩短，使宪政早日实现。

  • 1932年4月4日讯：中日停战会议在沪续开，日方提议要中国代表说明苏州河以南及浦东等处驻兵情形。中方据理反驳。日方坚持撤兵时间不能先行决定，当由日方自定。谈判无结果。

  • 1932年4月4日《申报》：哈尔滨息，于琛澂军1日晨得日军协助，反攻方正，自卫军同时得援，在高力帽子激战击退于军，现于部退宾县修整。（3日专电）

  • #抗战影像# 侵占我东北之日寇绘制的伪满洲国要图。

  • 1932年4月4日《申报》：哈尔滨息，伪满洲国调马占山军二团开扶余断义勇军归路。（3日专电）

  • 1932年4月4日《申报》：哈尔滨息，日熙军2日早6时向农安总攻，激战一昼夜，日军以重炮10余门，飞机8架，上下环攻，军队增至2万人。义勇军虽在包围中，仍死命抗拒，2日战事双方无胜负，3日早5时仍开火。（3日专电）

  • 1932年4月4日讯：郭泰祺电国民政府，因停战会议进行困难，坚辞外交次长及中日停战会议代表职。5日，政府复电慰留，郭打消辞意。

  • 1932年4月4日讯：汪精卫晨接见郭泰祺商外交事，并将政府最后意旨训示后返京。临行发表谈话，否认国难会议之召集有将和战责任诿诸国民之意。

  • 1932年4月3日讯：南京中央大学校长任鸿隽以经费困难，再次向教育部辞职。

  • 1932年4月3日讯：上海各团体救国联合会召开紧急代表大会，通过促日撤兵宣言，称上海300万民众誓死反对有条件撤兵，任何外交当局如敢冒天下之大不韪，承认日本有条件撤兵，即一致认为出卖中华民国的主权与领土的国贼，以最严厉的方法对付之。大会并警告郭泰祺不得接受任何条件，否则“ …

  • 1932年4月3日讯：天津电报局同人首倡救国飞机基金，将月捐354元送《大公报》保存，并通电全国各电报局同人速起进行。

  • 1932年4月3日讯：日本驻吉林总领事馆磐石警察分署警察松尾峰雄等率12名伪保卫团员在磐东二道岗东北岔（今公所屯一带）逮捕反日群众9人。在中共磐东区委的领导下，展开了夺回被捕人员的斗争，期间，伪军连长龙介天率部下80余人哗变，杀死日警和翻译等3人。史称“三道岗事件”。

  • 1932年4月3日《申报》：哈尔滨息，日机爱国号31日至方正投弹，为自卫军击落，司机即毙。31日午后，自卫军反攻得手，在方正南伊漠通，击溃熙洽军，冯占海宫长海两部，取包抄势，仍在激战中，于琛澂电熙洽乞援。（2日专电）

  • 1932年4月3日《申报》：依兰息，1日自卫军右路追击溃敌，至宾州以东夹板站，逆军投诚三千余名，缴械三千余枝，获迫击炮三门，汽车七辆，于逆及李文炳只身逃走。（2日专电）

  • 1932年4月3日《申报》：东京讯，报载长春消息，日军与（伪）满洲国军攻袭农安八小时后，已于今日午后二时入城，守军自卫军已作强固抵抗后，向西北败退，（伪）满洲国军乃由张海鹏统带。（2日路透社电）

  • #抗战影像#侵占我东北的日本关东军士兵，正用雪橇杆支撑三八式步枪瞄准射击。

  • 1932年4月3日《申报》：哈尔滨息，日机7架31日午向农安城内投百余弹，城内大火，房屋市街已完全损毁，义勇军仍守城抵抗。日机俟由哈开去之天野长谷两旅团到后，2日总攻，匪首庄稼人率众三千加入农安义勇军中，日方颇以为虑。又及，张海鹏部骑兵四千，31日调至农安，协同熙洽军进击义勇军。（1日专电）

  • 1932年4月3日《申报》：大美晚报云，美飞行家肖特中尉，2月23日，在苏州天空与日飞机交战殒命后，今其母伊理萨伯·肖特夫人，与其胞兄爱特门·肖特乘搭孚脱总统轮船来沪，本月19日即可抵沪。肖特灵柩现尚停于万国殡仪馆，迨其母到沪后，再行殡葬，至肖特夫人等来沪后，将为中政府上宾。

  • 1932年4月3日讯：日机40架飞沪示威。

  • 1932年4月2日讯：日伪军总攻吉林农安。3日，李海青自卫军弃农安退扶余。

  • 1932年4月2日讯：张发奎部由醴陵出发入赣“剿匪”。

  • 1932年4月2日讯：上海《时事新报》馆资方为增加收入，强迫工人代印《大晚报》，工人以未得报界工会命令，拒绝承担。资方诬陷工人“煽动罢工”，将全体工人驱逐出馆，封锁大门，又擅自拘捕工人马德仁等八人，事件遂扩大。《申报》、《新闻报》、《时报》等全体工人均发表宣言，支持《时事新报》工人斗争

  • 1932年4月2日讯：西康省防军司令格桑泽仁在康叛逆行动，经蒙藏委员会向行政院请示处理。是日，行政院电令刘文辉勒令格桑泽仁自行取消西康省防军司令及建省委员会委员长等职，听候查办。

  • 1932年4月2日讯：国民政府任命洪中为军政部兵工署署长，原兼署长陈仪免职。

  • 1932年4月2日讯：国民党中执委复电粤中委萧佛成等3月24日电，说明此次上海停战谈判是根据国联决议确定停止敌对行为及撤退日军办法，不涉任何政治问题，表示中央对日方针，“具长期抵抗决心，以不丧权辱国为主旨”。

  • 1932年4月2日讯：国民党中央政治会议举行临时会议，讨论外交问题，集中讨论如何应付僵持之中日停战会议。

  • 1932年4月2日讯：上海各团体救国联合会派代表见外交次长郭泰祺，要求对日军撤退地点及时间勿迁就。

  • 1932年4月2日讯：日方代表陆军参谋长田代皖一郎在军事小组委员会上讨论撤兵地点时，节外生枝，询问我国军队在苏州河以南与南市、浦东等处之防务情形，我方以此事与停战会议无关，严词拒绝。

  • 1932年4月2日《申报》：天津息，石安全去年11月辞职，率同志出关，组织义勇军，奋勇杀寇。嗣被推为义勇军第13路总司令，近在绥中，与寇激战十余昼夜，被流弹击伤腰部，昨送入北平德国医院。（1日专电）

  • #抗战影像#侵占我东北的日本关东军，向检阅其的军官行持枪礼。

  • 1932年4月2日讯：浙江建设厅丝绸救济会决议：一、请国民政府规定茧价；二、旧存丝茧设法推销及补偿损失；三、增加人造丝原料及织物进口税；四、劝民众勿买叶养蚕；五、电国民政府设法代为烘茧，并组织丝绸救济会。
