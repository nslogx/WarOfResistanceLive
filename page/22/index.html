1932年04月15日

发表于 2021-04-15 更新于 2021-07-29 分类于 局部抗战(1931-1937)

  • 1932年4月15日讯：《台湾新民报》改周刊为日刊。

  • 1932年4月15日讯：广州脑膜炎流行。

  • 1932年4月15日讯：广东省政府财政厅布告，以频年军事支出浩繁，致财政支绌，不可名状，拟提前于16日发行国防公债3000万元。

  • 1932年4月15日讯：国难会议会员蒋梦麟等返平。据北平某会员谈：“国难会无拘束政府力量，无法实行，此次集合如许所谓知识阶级于一堂，不能寻出一解决国难切实办法，可见解决国难，决非此百余人聚坐空谈所能解决。”

  • 1932年4月15日讯：国民政府令：《惩治绑匪条例》、《惩治土豪劣绅条例》、《暂行特种刑事诬告治罪法》、《贩运人口出国治罪条例》，均着废止。

  • 1932年4月15日讯：上海各民众团体救国联合会通电全国，谴责国民政府承认划闸北、吴淞、引翔、江湾诸要区为敌军占据之地，自甘居于战败国之地位，表示“对此甘心屈辱之谬妄外交，誓死反对”。

  • 1932年4月15日讯：中华苏维埃共和国临时中央政府主席毛泽东发布《对日战争宣言》。宣言号召全国人民用民族革命战争，驱逐日本帝国主义出中国；并首先推翻国民党反 动统治。

  • 1932年4月15日讯：国民政府主席林森在沪访孙科，敦促进京共赴国难。林称：孙科对外意见与中央一致。

  • 1932年4月15日讯：汪精卫到陵园访蒋介石，商谈目前外交问题。

  • 1932年4月15日讯：上午国联调查团在北平先后接见东北各法团民众代表、北平各文化机关及学术团体代表、北平各大学教授代表。12时接见平、津新闻记者。

  • 1932年4月15日讯：外交部次长郭泰祺入京报告沪中日停战会议经过。

  • 1932年4月15日《申报》：哈尔滨息，救国军11日晚沿铁路退农安，日军进至天宝山。（13日专电）

  • #抗战影像#昭和7年（1932年）4月15日，伪满洲重工业开发株式会社发行的500日圆股票。

  • 1932年4月15日《申报》：东京讯，昨在哈尔滨附近失事之火车，今仍未查明为何人暗算，据报载哈尔滨消息，日军官一员，今晨奉命驾飞机飞抵火车失事之地，调查该案。（14日路透社电）

  • 1932年4月15日《申报》：依兰息，7日日重爆机（轰炸机）8架，投重（型）炸弹燃烧弹，一日四次，轰炸街市、镇署及电台，损害甚重。电台幸未过受重创，业于12日修复，照常通信，10及11两日，日机两架又来依兰轰炸。（13日专电）

  • 1932年4月15日讯：中共中央发表《中华苏维埃共和国临时中央政府宣布对日战争宣言》。表明对日宣战，号召“以民族革命战争，驱逐日本帝国主义出中国”，同时派遣以杨靖宇为首的一批干部深入东北，组建抗日义勇军。

1932年04月14日

发表于 2021-04-14 更新于 2021-07-29 分类于 局部抗战(1931-1937)

  • 1932年4月14日讯：红军攻占湖北蕲春，县长王道中被俘，黄梅队长胡佐民被击毙。

  • 1932年4月14日讯：晋绥军事委员会在太原成立，阎锡山兼委员长，徐永昌、傅作义、张荫梧、楚溪春等11人为委员。

  • 1932年4月14日讯：国民党中常会决定蒋介石为中国童子军总会正会长，戴季陶、何应钦为副会长。

  • 1932年4月14日讯：蒋光鼐晨抵京，向国民党中央报告沪中日停战会议经过情形，并请示一切。

  • 1932年4月14日讯：国联调查团上午10时在北京饭店接见在平满蒙王公代表。11时接见日代表。李顿等至外交档案处阅1905年铁路条约。下午4时调查团至顺承王府与原东北军政官吏举行第三次谈话会，商谈吉、黑及中东路问题。

  • 1932年4月14日讯：刘纪文辞广州市长职。

  • 1932年4月14日讯：蒋介石在南京军校邀中大、金大及金陵女大三校长讨论教育经费问题，各校长请蒋转请政府特别救济，蒋允设法。

  • 1932年4月14日讯：外长罗文幹以日方节外生枝，上海停战谈判无从进行，于晚8时往铁部晋见汪精卫，对沪事有极重要之接洽。

  • 1932年4月14日《申报》：哈尔滨息，救国军项团11日晚7时半入一面坡，商民悬国旗欢迎，熙洽军向乌吉密退却，其警备第一旅夏任谋团反正，投入第一路救国军。（13日专电）

  • 1932年4月14日《申报》：哈尔滨息，10日晚，距农安50华里高台子三道岗，发现救国义勇军六千名，有攻入农安之势，驻长春熙洽军一旅，11日午往攻。出现高台子之救国义勇军仍属攻农安之李青山率领，近在扶余整顿后，复来攻。（13日专电）

  • 1932年4月14日《申报》：哈尔滨息，王德林率救国军五千，退集中俄边境西大堡，其军队中赶编炮骑兵。并补充机关枪，在哈绥线之救国第二路军，中多知识分子及党员，有人曾于车中听见兵士互称为同志，对人对地方均极有纪律。（13日专电）

  • 1932年4月14日讯：沪中日停战会议军事小组会续开，日方仍提浦东、苏州河南我军不驻兵问题。无结果，小组会展延。

1932年04月13日

发表于 2021-04-13 更新于 2021-07-29 分类于 局部抗战(1931-1937)

  • 1932年4月13日讯：上海各团体电国联，反对英使蓝普森所提折衷办法。

  • 1932年4月13日讯：上海市民联合会等百余团体发表宣言，主张中西纳税人互相合作，研究解决今后租界之联防。

  • 1932年4月13日讯：上海各民众团体联合会成立，共有34个团体参加，推举各大学学生抗日救国会等15个团体为执行委员，主张暴日未撤退在华海陆空军以前，反对任何谈判；誓死反对中日问题进行局部解决；反对依赖国联。

  • 1932年4月13日讯：国民政府特派孔祥熙为考察各国实业特使。

  • 1932年4月13日讯：交通部订定招商局整理计划，取清年终双薪，革除分局包办制度，减裁职员。

  • 1932年4月13日讯：日兵车一列在哈尔滨郊区出轨，死伤百余人。

  • 1932年4月13日《申报》：北平息，秦皇岛电，本庄到锦，北宁路干支线，日军将另行配置，依田旅团留驻锦州以西，另以第十师团驻锦州以东，第二十师团一旅调回朝阳，伪路局力图恢复锦朝支线，俾作军政经济侵略之运用。（12日专电）

  • 1932年4月13日讯：国联调查团与原东北军政官吏举行第二次谈话会，并接见荣臻、王以哲询问沈变经过。

  • #抗战影像#几张伪满洲国宣传画

  • 1932年4月13日《申报》：北平息，此间华人得悉马占山已逃往俄国，初据东北消息，马已逃往大黑河，今传马因部下将士多起抗满伪政府，知大势已去，故乃潜入俄境，以图自保。（12日路透电）

  • 1932年4月13日《申报》：北平息，调查团与原任东北高级官吏，为交换意见，今日下午四时，在顺承王府开第一次会，调查团全体出席，华方张学良、万福麟、荣臻、米春霖、顾维钧等出席，详谈东北问题，七时散会，定13日开第二次谈话会，仍在顺承王府，日代表吉田亦参加。（12日专电）

  • 1932年4月13日讯：沪中日停战会议暂停，郭泰祺已通告各关系国。郭语记者，大会须俟国联解释日本撤兵时期再开。

  • 1932年4月12日讯：国难会议闭幕，通过请政府克日将张学良撤职查办，所部军队着军委会妥为处理，以便收复东北失地等案，并发出四电：一、慰勉颜惠庆；二、嘉慰华侨捐款救国；三、嘉慰上海民众；四、勖勉全国将士。会议闭幕，发出宣言称：“中国在此严重局面之下，非集中全国才力，共作长 …

  • 1932年4月12日《申报》：太仓11日专电云，日兵在岳王市勒令居民，供给鸡蛋牛肉及用品并迫各商店开市，改悬太阳旗，居民多避，日兵在市搜索，该处小麦，尽被日军作马料，田收已无望。

  • 1932年4月11日讯：河北省民生银行总行在天津成立。

  • 1932年4月11日讯：上海公共租界纳税华人会本年第一次代表大会召开，选出工部局华董虞洽卿等五人，华委六人及该会执行委员27人。

  • 1932年4月11日讯：国难会议决议，宪政未实施前提前设民意机关，定名为国民代表会。

  • 1932年4月11日讯：国难会议电请国联调查团主持公道，“望根据事实，为正确之报告，使日本强暴情形，得以明白昭著于世界，受正义与公理之裁判”。

  • 1932年4月11日讯：沪中日停战会议延期。军事小组晨赴引翔港视察，下午开会，讨论浦东及苏州河南之我军驻防问题，我方代表黄强以此系中国主权问题，拒绝讨论。
