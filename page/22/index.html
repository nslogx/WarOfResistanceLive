1932年05月17日

发表于 2021-05-17 更新于 2021-08-30 分类于 局部抗战(1931-1937)

  • 1932年5月17日讯：豫南颍河决口，西华、商水等县被淹。

  • 1932年5月17日讯：红军李明瑞部再次占领汝城。

  • 1932年5月17日讯：日军第10师团顺松花江而下，一举突入守备空虚的我指挥部所在地依兰，我军在依兰以西三块石的小股部队做坚决抵抗，依兰部队始得仓皇撤退，所有存储的被服、粮秣、武器弹药和修械所，全部为敌所获。

  • 1932年5月17日讯：萧之楚赴鄂省应城，代徐源泉指挥“剿匪”。

  • 1932年5月17日讯：何应钦在南昌发表谈话，声称：“上年剿匪，调集大军十数万，围剿经年，收效甚微，原因虽多，而我军不注重精神教育实为主因。今后剿匪部队须注意军人精神教育，除去畏匪心理，则战必胜，攻必克。”

  • 1932年5月17日讯：蒋伯诚等奉蒋介石之命赴济南与鲁省主席韩复榘商妥，今后鲁省国税交还中央，鲁军费由财政部拨发。

  • 1932年5月17日讯：陈济棠在西南政务委员会上提议讨伐陈策，委陈章甫为琼崖剿匪司令，拨六个团归其指挥，另派“广金”、“坚如”等舰水陆并进。

  • 1932年5月17日讯：沈阳县长谢桐森与伪满洲国官吏五名及其他人员十余名，谋推翻伪满政府，事泄被捕。

  • 1932年5月17日讯：日军翻译官、朝鲜人金枳率伪警多人往临榆县东八里之乐善堡村，围困、搜查保安团所，抢夺枪 支、弹药，捕去该所人员四人。

  • 1932年5月17日讯：行政院决议，派王伯群视察川、滇、黔军政。

  • 1932年5月17日《申报》：秦皇岛息，沈讯，义勇军司令李文良，13日晚率部六百余人，进袭本溪湖煤矿，行至距矿约20里地方，与驻该处之日守备队，发生冲突，激战三小时，义勇军以援不继，恐被包抄，遂向濮县退却，拟与该处民团联合，再行进攻。（15日专电）

  • #抗战影像#伪满洲图书株式会社发行的国民高等学校及女子国民高等学校使用的满语版本几何课本上册。

  • 1932年5月17日《申报》：哈尔滨息，自卫军宫长海部二千余人，进逼哈东一带，当与伪国警备军第二旅第四团，发生激战。哈市闻炮声，商民极不安，伪国军因失利，改取守势，迄15日晨止，尚在相持中。东铁安达站等处义勇军，集结三千余人，13日起，沿线东进。14日日军派飞机多架侦察，并调十四师团某联队，前往协击。（15日专电）

  • 1932年5月17日《申报》：北平息，驻榆日军确有行动计划，图占榆关车站，并肃清榆境内义勇军，何柱国决以不屈精神，镇静态度，尽守土责，驻秦皇岛日军声明，该处绝对无事，益澄榆关紧张，为预定计划。（16日专电）

  • 1932年5月17日讯：伪满洲国当局阻止国联调查团与马占山会晤。伪外交总长谢介石声言，“如与马占山会晤，不负保护责任”。

  • 1932年5月17日讯：驻沪大场日军自晨7时起分批撤退，至下午1时半撤尽，由江苏保安队进驻接收。

1932年05月16日

发表于 2021-05-16 更新于 2021-08-30 分类于 局部抗战(1931-1937)

  • 1932年5月16日讯：汉口银团召开紧急会议，商讨鄂绥署“剿匪”借款事，允增至50万元。

  • 1932年5月16日讯：11日，河北省国民拒毒会主席曹鸿翥曾电张学良，请通令查禁鸦片公卖，并严惩主办人员。本日张学良复电谓“烟土变售，曾未前闻”。

  • 1932年5月16日讯：国民党西南执行部及西南政委会召开联席会议，讨论榆关问题等。

  • 1932年5月16日讯：马占山部才鸿猷旅在松浦镇与日军交火，焚毁呼海路局大楼和日军军需库。

  • 1932年5月16日讯：蒋介石中央军校演讲《革命哲学的重要》（后定题为《自述研究革命哲学经过的阶段》），提出要御外侮，救中国，第一就要恢复我们固有的民族精神，尤其是“知难行易”的哲学，为其“攘外必先安内”的国策寻找理论拫据。

  • 1932年5月16日讯：国民党中央政治会议决议：一、关于行政院呈送市、县参议会组织法及议员选举法各草案修正如下：1.市参议会议员应全体由市公民选举；2.市参议会议员任期规定为一年，县参议会议员任期为二年；二、覃振请辞司法院副院长职，慰留；三、特派刘守中赴绥远、察哈尔调查实业事宜。

  • 1932年5月16日讯：日本政府派驻巴西大使有吉抵南京，请求会见汪精卫。17日，汪在官舍会见有吉，汪除对日首相犬养毅被刺死表示悼惜外，并谓：“中日关系密切，邦交上不应有似亲善而非亲善之现象，应使两国间相互得到满足，不受若何损害，达到真正的共存共荣之亲善邦交。”

  • 1932年5月16日讯：闸北苏州河北、京沪路南、浙江路西、广肇路东周围约七里之地区日军撤退，我方警察大队及北平保安队入驻接收。

  • 1932年5月16日《申报》：南京息，汪蒋等各要人，以榆关日军挑衅，形势益趋紧张，藏军内犯，边患未已，特于15日共同协商，研究应付方略。对于东北西南两部整个国防问题，通盘计划，闻已有相当决定。（15日专电）

  • #抗战影像#侵占我东北黑河瑷珲的关东军某部大久保队，一名叫樱井清的军人，写给日本静冈市海野安子的军用明信片。

  • 1932年5月16日《申报》：北平息，榆关日军14日在九门口石门寨等要隘侦察，并派便衣探，密布榆站，侦察各次客车，我方军警加严防范，清查户口，榆市面恐慌，居民纷迁唐山。（15日专电）

  • 1932年5月16日《申报》：北平息，马占山12日自黑河发出通电，誓死长期抗日，并饬所属文武官吏，竭力赞助，以达救国就种目的，并请全国竭力御侮。（15日专电）

  • 1932年5月16日讯：中日上海停战协定中、日文副本经文字修改后，由我方代表郭泰祺与日方代表重光葵等签字。双方文字经修改者各两点，中文本为：“战斗行为”改为“敌对行为”；“地点”改为“地方”。日文本为：“当分の间”改为“暂时”；“附近”改为“邻接”。

1932年05月15日

发表于 2021-05-15 更新于 2021-08-30 分类于 局部抗战(1931-1937)

  • 1932年5月15日讯：伪满洲中央银行开始营业。

  • 1932年5月15日讯：红军占领安徽霍丘。

  • 1932年5月15日讯：李宗仁、白崇禧在邕召开“剿匪”会议，决派第四集团三分之一兵力两万余赴闽、赣“剿匪”。

  • 1932年5月15日讯：日本海、陆军人发动“五一五”事件，首相犬养毅被枪击身亡。翌日，国民政府、汪精卫、罗文幹分别电唁。

  • 1932年5月15日讯：天津商民救国会电国联行政院，请制裁日军对我东北三省的暴行，并电请国民政府速定大计，以武力收复失地。

  • 1932年5月15日讯：西康总商会、教育会等于6日电驻京代表马泽昭，请转恳中央迅颁明令讨伐达赖，并接济飞机、高射炮械弹、无线电等军用品运康。马接电后于本月呈蒋介石、汪精卫，陈述军事情形，恳予照准。

  • 1932年5月15日讯：陈策在琼崖宣布成立海军行营，通电反对陈济棠强迫改编海军。

  • 1932年5月15日讯：北平市妇女救国同盟会开执委会议，建议国民党中央妇女科在最短期召集全国妇女代表大会，并请速定妇女救国运动方针。

  • 1932年5月15日讯：北平师范大学学生会电请教育部发表易培基、张乃燕、经亨颐三人中择一长校，三人之外，任何人均不欢迎，并绝对拒李建勋长校。

  • 1932年5月15日讯：津浦、北宁、平汉、平绥、胶济、道清、正太、陇海八铁路工会，在天津津浦路工会举行正式联席大会，讨论工会组织及工人待遇等问题。

  • 1932年5月15日讯：马占山黑河誓师出征。发布《告绅商书》、《告农民书》，通电南京中央党部、国民政府，誓言长期抗日御侮。

  • 1932年5月15日《申报》：哈尔滨息，广濑今日乘飞机赴方正，亲自指挥昨日开始对反满军之总攻势。反满军共有将士四千，由李杜统率，以依兰为根据地。（14日专电）

  • #抗战影像#伪满洲国明信片，主题是“哈尔滨的夜色”。

  • 1932年5月15日《申报》：山海关息，9日后，榆日军行动虽稍缓和，但伪国境警察仍极活动，成纠纷之重心。昨日下午1时，长城外临榆县属境第一区乐善堡，有榆日军宪兵队翻译、鲜人金某，率同伪国国境监视警察十余人，全副武装，强将该堡第15乡团分驻所占据。缴去枪弹、国旗、团旗、团丁、服装、电话箱什具，掳去乡团排长、团丁、书记等。临瑜县府报，当与榆日宪兵队部交涉，日方答系满洲国事件，彼不能干涉，以致交涉无结果。（14日专电）

  • 1932年5月15日《申报》：哈尔滨息，昨日反“满洲国”军队，侦悉乌吉密河日军暂离防地，突向车站及商埠地袭击，站内电报及电话机线，先被毁坏，车站及附近两小桥，后亦被焚，反“满洲国”军队，对于日军行动，似颇明了。（13日路透社电）

1932年05月14日

  • 1932年5月14日讯：国民政府公布《民事诉讼法施行法》、《实业部全国度量衡局组织条例》。

  • 1932年5月14日讯：河北省教育厅通令各院校切实防范共产党。

  • 1932年5月14日讯：鄂清乡促进会开第二次全体大会，决以善后公债150万元、市政公债150万元，摊销绅富，为“剿共”经费。盐税附加决请每月拨20万元。

  • 1932年5月14日讯：行政院决议：一、组织淞沪战区善后筹备委员会，派宋子文、黄绍竑、陈公博、顾祝同、吴铁城、王晓籁、史量才、虞洽卿等为委员，指定宋子文为主席；二、刘瑞恒辞禁烟委员会委员长职，慰留。

  • 1932年5月14日讯：据《大公报》讯：日本驻沪陆军全部撤退后，即专以海军陆战队及宪兵驻沪，其数为陆战队2500名，宪兵100名。此数较事件发生前之800名约增二倍。

  • 1932年5月14日《申报》：北平息，马占山上月17日续电调查团，揭破日人阴谋，并宣布日人强迫签字之呼海路黑省银号复业借欵合同，中日合办航空运输合同二件，极关重要，原文甚长。（13日专电）

  • #抗战影像#可能正在训练中的一个伪满洲国陆军分队，近处的机枪手正在操作日制大正三年式6.5毫米重机枪。

  • 1932年5月14日《申报》：北平息，昨日军四百余，由前所站徒步开往九门口外20余里马营子村，声称防义勇军活动，九门口石门寨两处驻第九旅一团，车站附近日侨商百余，均佩红色臂章。（13日专电）

  • 1932年5月14日《申报》：北平息，日人在榆关设大和大东两旅馆，专收汉奸及日鲜浪人，南关日宪兵队部，门外慢布电网，门内堆丈余高沙袋，上设机枪。日兵在榆实力四五百人，榆当局对日兵挑衅，应付办法，已磋商妥协，调城内警察编为特务警察队，维南关治安，队长陈宝，已正式服务。因南关与日人接近，避误会。（12日专电）

  • 1932年5月14日讯：上海停战共同委员会日方委员原田函撤兵区域接管委员会称：大场日军定17日下午1时撤退，所有接管事宜，盼先向该地守备队长接洽。

  • 1932年5月13日讯：国民政府任命徐庭瑶为陆军第四师师长，李建勋为国立北平师范大学校长。

  • 1932年5月13日讯：李宗仁、白崇禧函萧佛成，谓“两粤辅车相依，存亡与共，合则足以救国，离则两败俱伤，桂今后对时局方针，决在西南政委会领导下，以粤之主张为主张”。

  • 1932年5月13日讯：淞沪抗日各军、第十九路军总部及淞沪警备司令部移驻苏州。

  • 1932年5月13日讯：上海特区市民联合会发表宣言，反对丧权辱国之上海停战协定，指出该协定之丧权“直为《辛丑条约》以后所无”。

  • 1932年5月13日讯：日外务大臣芳泽邀英、美、法、意四国驻日各大使集议，促开圆桌会议及提议改上海为国际自由市，四周不得驻中国军队的荒谬主张。外交次长郭泰祺就此事在电话中对记者发表谈话予以驳斥，称圆桌会议不能开，自由市更谈不到。

  • 1932年5月13日《申报》：北平息，上村中佐所部日军，在绥中西狮子炮台，被2千名义勇军袭击，受创甚巨。又日军杉村部在八道沟，被400名义勇军击溃。（12日专电）

  • 1932年5月13日《申报》：北平息，哈尔滨11日电，马占山近以25000名之兵力，分布于齐克路沿线，逐步向龙江省垣推进，10日在该路支线塔哈站附近，与日军一队相遇，发生战事，结果日军大败，伤亡过半，余悉溃退，又马定15日前总攻黑垣，飞机场已筑竣。10日派机3架飞黑垣掷弹，轰炸城内，伪国机关人员及居民，极感恐慌，日军多门师团长，已增派某旅团全部，开往协防。（12日中央社电）

  • 1932年5月13日《申报》：上海日本驻军已奉命撤退，14师团开赴东北，志在用武力迫犯我东省，而第9师团则调退日本金泽，已在开拔中。

  • 1932年5月13日讯：日侨在沪日商俱乐部秘密集会阻挠日军撤退，决以全沪日侨名义致电首相、陆军大臣、海军大臣及政友、民政两党总裁，称“此次出兵侵沪，其结果对我仍毫无权利，则此次作战之损失，其代价将向谁取”；“外务省限侵沪军队于一个月内退尽，旅沪全体日侨必反对之”；“如不乘此战胜余威，向支那政府要求在上海设立自由市，则以后将永无机会可得，我旅沪侨胞亦将永无扩大居住区域之可能”。
