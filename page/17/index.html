1932年10月23日

发表于 2021-10-23 更新于 2022-01-11 分类于 局部抗战(1931-1937)

  • 1932年10月23日讯：中央红军在福建邵武与周志群第四旅发生战斗后，歼敌一个团，是日经麻沙入建阳。

  • 1932年10月23日讯：广州宣布戒严，清查户口，以“清除”共产党。

  • 1932年10月23日讯：蔡元培、杨杏佛、柳亚子、林语堂、潘光旦等致电南京中央党部、国民政府请释陈独秀，内称：“顾其反对暴动政策，斥红军为土匪，遂遭共党除名，实与欧美各立宪国议会中之共产党议员无异，伏望矜惜耆旧，爱惜人才，特宽两观之诛，开其自新之路。”

  • 1932年10月23日讯：刘珍年派代表杨力川谒何应钦，报告刘军遵令驻扎掖、莱等县情形，并请示解决鲁事办法。

  • 1932年10月23日讯：夏斗寅恐因病久旷职守，再呈蒋介石请辞鄂省府主席职，蒋派杨永泰问病并慰留。

  • 1932年10月23日讯：刘湘、田颂尧、邓锡侯、刘存厚各派代表同谒蒋介石报告川况，蒋再电令四川各将领立即息争，各守原防，听候中央处理。

  • 1932年10月23日讯：磐石工农反日义勇军建立总队，下设四个大队，每个大队30人，有长枪75支，短枪65支。对外用“五洋”匪号名义相号召。孟洁民任总队长，钟仿服任副总队长，张振国任政委，王耿任政治部主任，满汉生任参谋长。

  • 1932年10月23日《申报》：北平息，马占山有电到平云，濮炳珊14日在拜泉就职，所部向泰安镇集中，拟与宋喜和旅联络向省垣进攻，我部15日出动，士气甚状，省垣敌逆极感恐慌。（22日专电）

  • 1932年10月23日《申报》：山海关息，热河抗日军何民魂部李赐如率义勇军三千人，21日克复义县附近之阜新。现正会同攻破义县之李海峰张鸣五等均，向锦州方面之残敌进袭。（22日华联社电）

  • #抗战影像#“一·二八事变”中日本海军航空队飞机航拍下对吴淞口中国守军炮台轰炸的瞬间。

  • 1932年10月23日《申报》：北平息，救国军董荣久部第二旅长王永良，率部三千余人，19日攻连山，与日军八百余激战。22日日军机枪大炮威胁，并援军屡至，我军颇受损失，暂退原防。董前遣第三旅长曹振国，在擦崖口外大障山子一带，组织义勇军一千五百余名，22日由曹旅长率领全军，向锦州附近某地出发，候董点阅，听命进攻。（22日专电）

  • 1932年10月23日《申报》：北平息，义勇军第27路司令李宝连，37路司令杜成栋，共派军千余人，21日晨由阜新会合，加入义县城内义勇军作战。日甲车连日以大炮轰击，义县城内民房，完全被毁。义勇军正奋勇向义县车站猛扑中，双方死亡甚多，日机时向各处掷弹，战事极烈。（22日专电）

  • 1932年10月23日讯：四川善后督办第二十一军军长刘湘通电斥责刘文辉反复无常，好乱称兵，誓与友军左右提携，全力制止。

1932年10月22日

发表于 2021-10-22 更新于 2022-01-11 分类于 局部抗战(1931-1937)

  • 1932年10月22日讯：江苏江都县政府因清查田赋逮捕乡民50余人，是晨审讯时，乡民数千人持械入城，冲进县府，捣毁什物，焚烧卷宗。县长从后门逃跑，军警赶到，又捕200余人。23日，乡民要求渡河进城，被军警阻拦，枪 杀七人。省府令各县暂停清查田赋。

  • 1932年10月22日讯：江苏全省商联会以美麦倾销，国产粮价低落，农商交困，决议电请中央将第二次续贷美麦45万吨一案停止进行，以慰民望。

  • 1932年10月22日讯：立法院通过《行政诉讼法》。

  • 1932年10月22日讯：西康各喇嘛庙联名电请中央制止川战，令刘湘撤销战备，令刘文辉集中兵力，收复边疆，以固国防。

  • 1932年10月22日讯：马占山率少量骑兵由讷河经甘南到达扎兰屯，众人拟推举马占山为抗战领导，马占山以身体原因婉拒，拟由满洲里赴苏，为苏方拒绝，未能入境。

  • 1932年10月22日《申报》：北平息，义勇军第16路祖耀时部约千六百余名，有机枪三十余挺，迫击炮十余门，坦克车三辆。近由同江往义州、宽甸、复盖等处出动，扰乱日军后路，该军有前东北兵工厂技师某国人二名。（21日专电）

  • 1932年10月22日《申报》：北平息，今晨日甲车一列，由南岭开来，驶至义县车站处，以大炮轰击义县城，人民死亡甚众，房屋多被毁。义勇军仍奋战中，同时口北营子与南岭间之三宝营子，停日军甲车一列，不时示威。（21日专电）

  • 1932年10月22日《申报》：哈尔滨息，闻冯玉祥部下军队两旅已由哈尔加（音译）抵满蒙边界之呼伦贝尔，欲加入哈尔滨西面之反满军。（21日路透社电）

  • 1932年10月22日《申报》：齐齐哈尔息，对“满洲国”忽枢反旗之濮炳珊破坏齐克线线路达16处之多。19日复在克山，射杀满铁社员岩本定造，同时岩濑恒二，亦受重伤。又为濮炳删军指导将校之下枝少佐，最近消息不明，日军对此事非常重视。（21日电通社电）

  • #抗战影像#一名身穿昭五式军服的日本陆军军医。

  • 1932年10月22日《申报》：齐齐哈尔息，濮炳珊军之指导将校下枝少佐消息不明，日军今日对濮炳珊军发出如下之最后通牒“速护送下枝少佐至海伦，不然则将拜泉化为灰烬”。（21日路透社电）

  • 1932年10月22日《申报》：北平息，热河来电报告，通辽现有日军二百余名，康平法库两县，归义勇军占领。洮南一带，仍由张海鹏部驻防，各处有少数日军维持铁道。（21日专电）

  • 1932年10月22日讯：刘湘接受邓锡侯等百余人之请，领衔电呈中央，表示采纳“治川纲领”，召集遂宁会议，以解决四川积年纠纷。

1932年10月21日

  • 1932年10月21日讯：《主张与批评》半月刊在上海创刊，王造时主编，仅出三期即被当局禁止而停刊。

  • 1932年10月21日讯：热河抗日军何民魂部攻克阜新。

  • 1932年10月21日讯：中华苏维埃共和国临时中央政府执行委员会为粉碎敌人大举进攻，发行第二期革命战争公债120万元。

  • 1932年10月21日讯：江苏各县鲜猪同业推派代表40余人组请愿团赴省及京请愿，反对苛征猪只营业税。26日，财部电复该业临时代表联合会，称已令饬该省财政厅迅即查明制止拦征过路猪税。

  • 1932年10月21日讯：交通部长陈铭枢电行政院宋子文代院长坚请辞职。

  • 1932年10月21日讯：天津全市电车、电灯工人因提出要求改善待遇等七项条件，公司延不答复，是日起总罢工，市各民众团体予以支援。30日，天津社会局劝电车、电灯工人复工被拒绝。11月5日，于学忠奉张学良命实行强制调停，勒令工人代表承认“仲裁”条件，次日工人复工。

  • 1932年10月21日讯：江西公会常务理事李烈钧等通电反对《国联调查团报告书》，主张“亟宜调遣大批军队出关，协同原在东三省之义勇军积极与日军抵抗，收复失地”。

  • 1932年10月21日讯：“时轮金刚法会”在故宫太和殿开坛，班禅率喇嘛僧众诵经，段祺瑞、吴佩孚、朱庆澜、孙传芳、王揖唐等均入坛参礼。各界参加者数万人。

  • 1932年10月21日讯：“磐石工农反日义勇军”在常占匪部中哗变，独立出来的部队暂时转移到桦甸县蜜蜂顶子（今桦甸市北部）一带进行休整改编。

  • 1932年10月21日《申报》：北平息，救国团体联合会熊希龄等，电中央国府及华侨，请求援助义勇军。（20日专电）

  • #抗战影像#“一·二八事变”中，三名日本海军陆战队员正在街垒后向中国军队开枪射击。

  • 1932年10月21日《申报》：北平息，救国军董荣之部占领女儿河车站后，日机十余架每日盘旋轰炸，并时派队扰乱，或机枪大炮威胁。该地民众要求救国军暂退，该军19日晨退至附近某地。该部第二旅长王永良，率部三千余名，进袭连山车站，19日拂晓与日军八百余在连山激战。（20日专电）

  • 1932年10月21日讯：汪精卫决定赴德国就医，行政院各部、会长集沪与汪话别。22日，汪及家属、秘书等七人离沪赴欧。

  • 1932年10月21日《申报》：北平息，马占山部宋喜和旅，进至齐克线泰安镇以西至杨家屯铁道一段破坏，所部伏于路行。晚八时日兵列车驶来，至破坏处，即脱轨。宋部即加以猛袭，敌大溃退，至拉哈站。宋部继续追击，将该站包围。马派徐海亭往援，宋旅毙敌数十余名，俘三十二名，获大小枪百余枝，子弹十余万粒，给养及军需品一车。（20日专电）

  • #抗战影像#一二八淞沪抗战中激战后的闸北景象：火车北站附近和宝山路对面一处被毁街区的场景，显示死人尸体、被毁房屋、沙袋掩体和被打断了的电报、电话线

  • 1932年10月21日讯：韩复榘因军政部调处胶东问题为刘珍年划五县为防地，特电林森、宋子文、蒋介石等请辞鲁省主席职。宋复电慰留。蒋介石、张学良亦电劝“打销辞意”。

  • 1932年10月21日讯：朴炳珊暂编第一旅攻占泰安镇（今依安县城），歼灭日军守备部队中队长以下数十人，活捉伪克山公安局二分局局长薛昌信，缴获步枪四十六枝、子弹三千余发、军服多件及其它军用物资。

  • 1932年10月21日讯：四川各师、旅长等90余人联名电中央请免刘文辉职，交付惩戒。邓锡侯、刘湘、田颂尧、杨森等部公推刘湘为川康“绥靖”总司令，田颂尧为副。

  • 1932年10月20日《申报》：北平息，日军12日开来三个师团，分三路攻东边道义勇军。第一路进攻临江，已与义勇军齐达三部接触。第二路由朝鲜新义州取道安东，直攻桓仁，义勇军第四路司令李春光率部直抄安东日军后路，伪警备司令李穆山及日军两个联队正与义勇军交战中。第三路日军一师团直攻营盘，与义勇军李春润部血战一昼夜。李部退营盘尚百花岛山谷，诱日军深入，当击毙日军二百余名。（19日专电）

  • 1932年10月19日《申报》：沈阳息，日关东军司令部今日令金璧东与其妹川岛芳子，由黑垣赴满洲里，求见苏炳文，恳求以政治手段解决黑省之反正。金兄妹乃清室某亲王之子，自辛亥革命后，专为日军部担任军事侦察。（18日华联社电）

  • #“利济”舰起义# 1932年10月19日凌晨2时许，停泊在富锦附近江面的伪满洲国海军江防舰队“利济”号炮舰发动抗日反满起义。舰长范杰领导起义官兵将舰上2名日籍海军人员击毙投入江中，继而直驶同江。因为担心伪满洲国江防舰队与日军追击，“利济”舰实力难敌，起义官兵将舰上火炮、机枪拆卸上岸，弃舰登陆投奔李杜自卫军路永才部，被整编为自卫军海军筹备处。“利济”舰后被伪满洲国江防舰队拖回，重新入列。但“利济”舰起义在“建国”不久的伪满洲国引起巨大轰动，打击了伪满政权。 舰长范杰与起义官兵在1933年日军大扫荡时被迫同抗日武装一同退入苏联境内，一度滞留西伯利亚，后由苏联方面送至新疆塔城回国。由于他们坚持要归建东北海军作战，不愿留在新疆军阀盛世才处效力，范杰率部秘密化装离境，重新穿越苏联，取道海参崴乘船抵达上海。再由上海辗转到达青岛向当时的中国海军第三舰队（前身是东北海军）司令部报到，后来参加了保卫长江马当要塞等作战行动，大部分在战斗中殉国。 范杰等东北海军爱国官兵为了追寻自己中国海军的身份，履行海军卫国御敌的职责，途径万里的归队行动，在中国海军抗战史上留下了充满传奇色彩的一页。

  • #参战装备#伪满洲国“利济”号炮舰：1932年2月15日，“利济”号随同东北海军江防舰队投靠日军，舰队在同年5月28日更名为“满洲国海军江防舰队”。因为投敌前该舰武备已拆卸无存，日方提供武器对其重新武装，改为1门日制76毫米主炮（日本海军称为“八厘炮”，是当时日本海军江川炮舰的标准主炮）和1挺日式6.5毫米重机枪。该舰在改装后主要负责护卫装运日伪步兵的船只沿松花江航行巡弋，威慑沿岸的义勇军抗日武装。使得舰上有民族血气的官兵倍感羞耻和愤恨，最终爆发了“利济”号起义事件。

  • 1932年10月19日《申报》：东京讯，（日本）外务省接苏俄传来消息称，苏炳文将军共拘禁日侨二百四十名，现确悉死者仅有三人，但余人之生死，未能查明云。日政府因自苏炳文将军反正后，满洲里一带之大局情形，茫无所知，故已命伯力日领事署派员就近调查。闻苏俄当局已请苏炳文将军释放所拘日侨，而许彼等至苏俄境内平安地点。现信死者三人中，内有不知姓氏之美人一名。（18日路透社电）
