1932年06月21日

发表于 2021-06-21 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年6月21日讯：江苏省商联会呈行政院，请严厉制止苏省财政厅兴办特种营业税。

  • 1932年6月21日讯：豫、鲁、苏、皖边界商丘、睢县、宁陵、永城、曹县、夏邑、虞城、柘城、单县、亳县、鹿邑、考城等15县为“剿匪”清乡，在商丘召开15县联防会议，议决于7月1日正式成立15县联防委员会。

  • 1932年6月21日讯：蒋介石任命曹浩森为鄂、豫、皖三省“剿匪”总部参谋长。

  • 1932年6月21日讯：上海市商会呈请行政院免征淞沪国税，庶战区得稍苏息。同日，上海市政府布告减免战区捐税。

  • 1932年6月21日《申报》：沈阳息，今晨一时，义勇军包围攻击满铁沿线汤岗子站，将电报电话线全部切断，断绝与外部之联络，并继续包围攻击日本铁道守备队分遣队兵舍。复以一部袭击收容日本伤兵之玉泉馆，伤病兵即以身边武器起而应战。然已死伤数名，日本守备队现与辽阳、鞍山开到之应援队合力进攻，目下在交战中。（20日电通电）

  • #抗战影像#伪满洲国时期，生活在东北的朝鲜族儿童。

  • 1932年6月21日《申报》：锦州息，本日上午，老北风率部约600名，突然袭击泰安城，并在城内放火，火势甚炽。打虎山之日本守备队田中部队，闻讯驰往，现正与激战中。（19日电通社电）

  • 1932年6月21日《申报》：哈尔滨息，哈长线三姓屯红旗头屯，19日发现吉义勇军一队，与日军战一时许，向双城退去。19日义勇军与日军中村部队激战于双城东官所，双方战线长20余里，吉义勇军扼苏家窝铺、赵家铺子、狼窝海旺窝棚，竭力应战。嗣日军以飞机投弹，重炮轰射，占长岭子高地，义勇军遂向三道沟方面退却。（20日专电）

  • 1932年6月21日讯：上海停战共同委员会开会，俞鸿钧促日军速撤。日方委员冈崎答允最短期内撤退。

1932年06月20日

发表于 2021-06-20 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年6月20日讯：陕西举行泾惠渠落成放水典礼，中央派吴敬恒、褚民谊参加。

  • 1932年6月20日讯：北平市小学教员会召开执委会，议决：一、21日全体执委往访宋子文，面索协款；二、推葛济欧、吕流长二人为代表，持呈文于日内赴绥靖公署，要求张学良从速筹拨补助费。

  • 1932年6月20日讯：中央大学教授、学生举行经费独立运动联席会议，决定：一、以下周为本校经费独立运动周；二、推定代表赴国府请愿；三、电慰任鸿隽并促从速南下长校。21日，中央大学经费独立运动委员会教授和学生代表九人，赴行政院请愿，因汪精卫在平未返，无结果。

  • 1932年6月20日讯：上海各大学学生抗日救国联合会决议反对教育部停办劳动大学。

  • 1932年6月20日讯：兰州中等以上各学校教职员罢教事，经甘肃省政府主席邵力子调解，并发给一个月欠薪，各教职员即日复课。

  • 1932年6月20日讯：许世英电行政院请辞赈委会委员长职。

  • 1932年6月20日讯：陈济棠在国民党西南执行部纪念周报告粤海军历年走私漏税，为政治污点，又不能“剿匪”，故奉令将其改组。

  • 1932年6月20日讯：蒋作宾奉召赴庐山谒蒋介石。

  • 1932年6月20日讯：沪日陆战队声明，沪西丰田纱厂、同文书院、吴淞路华丰纱厂、平凉路公大纱厂四处日军必须长期驻防，决不撤退；第四暂驻区剩余日军亦暂不撤。

  • 1932年6月20日《申报》：哈尔滨息，黑义勇军徐子鹤部拟攻黑垣，现所部出动于齐克璐泰安镇附近，向省城活动，日军宇都部17日在呼兰河北与黑义勇军激战。义勇军退却，日军平贺部队渡过通肯河，向拜泉攻进，义勇军集结拜泉南方扼守。（19日专电）

  • #抗战影像#伪满洲国时期，在东北一处白俄生活区，正在举行东正教婚礼。

  • 1932年6月20日《申报》：哈尔滨息，宫长海义勇军，分两支取双城阿城县，16日已有向两县猛攻之势，双城魏县电哈乞援，日军兵车一列开往。16日晨宫长海、冯占海军已薄近双城，距城只10余里，情形紧张。（17日专电）

  • 1932年6月20日《申报》：沈阳息，今日上午8时，沈安线本溪湖北九里之牛心台，突被数百自卫军所袭击。牛心台车站被包围，站员及警官等努力防御对战，致警官死一站员伤一。及接警报，即由本溪湖之警官队前往征讨，目下正在对峙奋战中。（19日电通社电）

  • 1932年6月20日讯：财长宋子文发表宣言，对伪满强夺东北关税事予以指斥，略称：日政府假借伪满洲国名义干涉东三省海关行政，哈尔滨、牛庄、安东三处海关解交总税务司之税款，分别于3月28日、4月16日和4月19日被迫停止解出，并扩充其侵占行为于大连，构成直接违犯国际条约。

1932年06月19日

发表于 2021-06-19 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年6月19日讯：河南渑池县降雹两小时，被打死者200余人，有400村庄房屋、田禾、树木尽毁。

  • 1932年6月19日讯：上海青年会会员抗日救国会电告全国同胞，反对鸦片公卖。

  • 1932年6月19日讯：由黄郛、张嘉璈等发起之“新中国建设学会”在上海成立。

  • 1932年6月19日讯：国民党中委马超俊抵沪，发表调解粤事经过，称经数次调解结果，“陈策决顾全国运民命，不予抵抗，如粤方定欲攻琼，则愿退让，是非请国人评判”。

  • 1932年6月19日讯：第八十三师蒋伏生部和第十师李默庵部奉军委会令由浙调鄂“剿共”。23日，第八十三师全部抵武汉。

  • 1932年6月19日讯：鄂省民政厅长朱怀冰自庐山电鄂，声称：“庐山会议结果，对肃清赤匪整个方案有缜密之讨论与决定，决以政治力量随剿匪军事向前进展，使匪区收复后不致再陷匪手。”

  • 1932年6月19日《申报》：哈尔滨息，最近马占山将队伍渐次迂回通北方面，经海伦移南，拟在呼海铁路沿线各地，散布兵力，随时图扰袭击呼海路。若成功，则图侵入哈埠，故在呼海路绥化北约15里之四方台，集有约近四千名之马占山军大部队。但马军之主力则仍在克山北安镇方面，故其计划似有渐次向东移动之势。（18日电通电）

  • #抗战影像#伪满洲国发行的明信片，照片为牡丹江市满洲兴业银行前的街头景象。

  • 1932年6月19日《申报》：北平息，沈东大刀会蜂起，声势浩大，13日占营盘山城子等地，营盘以东路轨拆去20余里。沈海路车停，日军14日载（靖安）游击队五百，开抚顺千金寨布放。（18日专电）

  • 1932年6月19日《申报》：山海关息，辽东义勇军纷由辽阳抚顺方面向沈阳移动，沈阳东南驻军于芷山部一连被缴械。义勇军一部千余进逼沈垣，与靖安游击队剧战，村民迁避入城，沈阳形势紧张。（18日专电）

  • 1932年6月19日讯：汪精卫、宋子文、罗文幹、顾维钧等在北平会见国联调查团交换意见。20日继续会晤，调查团对东北义勇军及抑制日货问题颇注意。22日，汪、罗离开北平返京。

1932年06月18日

发表于 2021-06-18 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年6月18日讯：伪满秉承日人意志攫夺东北关税，是日伪财长熙洽发表声明，声称“先将大连以外满洲海关之全部税收，停止汇往南京政府”，“若总税务司及南京政府依旧采取反抗态度，则断然处置”，准备掌握大连及其他海关税收之全部。

  • 1932年6月18日讯：上海市商会召开代表大会，发表三项宣言：一、本年工作应注重于废止内战及提倡国货；二、反对上海设置自由市；三、反对鸦片公卖。

  • 1932年6月18日讯：上海劳动大学学生发表护校宣言，望全国同胞共起积极援助。

  • 1932年6月18日讯：国民政府重颁禁烟令，略称：政府曾先后颁布各种禁烟法令，并三令五申表示禁绝，“诚恐偏远省分，日久玩生，奉行不力，或诿卸职责于地方特殊情形，未能革除净尽，致隳前功”，“嗣后各地方长官对于实行烟禁，务各遵照现行法规，切实实行，毋得阳奉阴违，视为具文”。

  • 1932年6月18日讯：阿城伪军陈德才警备第9旅乘机发起对自卫军攻击，自卫军各部被分割各村独立作战，且给养将尽，处于崩溃状态。

  • 1932年6月18日讯：中共中央为反对帝国主义、国民党对红军的第四次“围剿”发表《告民众书》，号召“全中国的工农兵以及一切劳苦民众，团结一致，粉碎帝国主义、国民党的四次‘围剿’，争取中国革命的新胜利”。

  • 1932年6月18日《申报》：哈尔滨息，据日方消息，马占山筹备抗日已久，现率大军，由拜泉南进，期收复日军与“满洲国”军队所占领各地。“黑省主席”程志远，已令望奎一带“满洲国”军队“扑灭”攻军。此项命令，未免过于乐观，能否实现，甚属疑问，但闻马之军队纪律严肃，军械充实，如他日获胜，诚不足使人惊异。程志远谅自知抗马非易，故为激发士卒计，允将一切“战利品”分公，日人称，马有钞票三卡车，但系何项钞票，及总数若干，均未悉。中东路东段，仍时被袭击，距恢复原状尚早。最近成高子被劫，死华人两名，伤十人，内有俄人二名。（17日路透社电）

  • #抗战影像#伪满洲国时期，一户农家的全家福照片。

  • 1932年6月18日《申报》：北平息，熙洽部连长陈荫棠，联络各连，将团长囚执，相率反正。，当时收编各地义勇军三千余人。并接纳红枪会首于作圣、伍芳发各部，已达三千余人，在敦化南方迭与日军接触，屡毁吉敦路，现正与王德林部联络，在吉东一带活动，声势浩大。（17日专电）

  • 1932年6月18日《申报》：山海关息，沈海路义勇军与于芷山部激战后，已退却。锦日军部派大批飞机掩护步炮队进攻连山以北义勇军，连日在范家屯陈家屯有猛烈战事。辽西各路义勇军将策应声援。（17日专电）

  • 1932年6月18日讯：汪精卫、宋子文、罗文幹、顾维钧、王树翰、曾仲鸣、刘宗杰等自京同飞北平，往访国联调查团，并与张学良协议对日交涉方针。

1932年06月17日

发表于 2021-06-17 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年6月17日讯：伪满中央银行成立，荣厚为总裁，日人山成乔六为副总裁。

  • 1932年6月17日讯：伪满国务院通令东北各省对爱国青年、国民党员，一律以扰乱治安罪驱逐出境，如不出境，“即处死刑”，并取缔各法团自由开会。

  • 1932年6月17日讯：韩复榘通电取消刘桂堂山东警备军名义，略谓：“刘桂堂自投诚以后，编为山东警备军……乃狼子野心，反复无常，又纠党叛变，并敢驱逐县长，勒缴团枪，逆迹昭彰，殊堪发指”，“所有前编山东警备军名义即行取消。”

  • 1932年6月17日讯：广东陈济棠部梁公福团在唐家湾与陈策部四舰发生激战。四舰败退澳门。唐绍仪以梁部在中山港作战，愤而辞去西南政委会委员及中山县长兼职。

  • 1932年6月17日讯：汪精卫由京赴沪，敦劝宋子文、陈铭枢复职，并访孙科，沟通政见。

  • 1932年6月17日讯：上海撤兵区域接管委员会接管公共租界以北、淞沪铁路及北河南路以东、沙泾港河以西区域。

  • 1932年6月17日讯：外交部就日本议会承认伪满洲国事发表宣言，略称：“东省伪组织，完全为日本政府以武力所造成……中国政府断不能承认”，“中国政府除以最严厉之国法处置该伪组织外，对于日本在东省之前后非法行为，始终认为武力侵略之一贯。”

  • 1932年6月17日讯：行政院就日本议会承认伪满洲国事发表对外宣言，略谓：“此次日本政府竟抛弃最后之面具，明目张胆承认伪国，此种行为不独对于中国为最显豁之侵袭，抑且将《国联盟约》及《九国公约》完全撕毁”，“中国国民为自卫计……对于日本政府此种行为，决定不惜任何牺牲，坚决反对。”

  • 1932年6月17日讯：料甸子地区的红枪会、大刀会与自卫军中路军发生冲突，珠河、延寿等地的红枪会等也赶来对自卫军进行内外夹击。

  • 1932年6月17日《申报》：哈尔滨息，日军宇都宫部进至黑省克东，夹击黑义勇军。12日午海伦北镇黑义勇军千名，与日军战数小时退却，海伦东六头井子为黑义勇军攻入，日军往援，黑义勇军退走。（14日专电）

  • #抗战影像#伪满洲国时期，在东北某白俄生活区，一对新婚的白俄夫妇。

  • 1932年6月17日《申报》：哈尔滨息，宫长海一部军队二千名，集结阿城南。杨子斌部三千余，集结其西南18里正红旗屯，互为联络。新吉军由日军协助，准备往击。冯占海率大部军队，由阿城转双城北策应宫部。双城附近韩家窝棚亦有义勇军四百人集结。哈绥线九节泡方面集有红枪会三千人，与义勇军联络。（16日专电）

  • 1932年6月17日《申报》：哈尔滨息，日军14日午后侵讷河，马占山军千名退嫩江附近。拜泉人心恐慌，现由朴大同旅开往维持。（16日专电）

  • 1932年6月17日讯：鄂、豫、皖、赣、湘五省民政建设会议在庐山开幕。五省将领、省主席及民政、建设厅长均出席，讨论决定五省“剿匪”全盘计划，对红军取大包围方式，以政治、建设配合军事，为根本的“清除”，并着重讨论“各省剿共部队之分配联络办法”及“进剿方略”、饷糈筹措等。蒋介石在会上发表演说，并分别对各省军事长官表示：“剿匪须硬干、快干、实干”，“必须早日将匪类肃清，然后始能充实力量对外”。19日会议闭幕。
