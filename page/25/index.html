1932年10月29日

发表于 2021-10-29 更新于 2022-02-25 分类于 局部抗战(1931-1937)

  • 1932年10月29日讯：蒋伯诚到济南与韩复榘磋商解决鲁事途径，决定韩复榘先撤至潍河以西，11月8日以前撤完，然后再调刘部离鲁。烟台、龙口暂归东北海军驻防，俾刘由两处他调。中央派蒋伯诚、熊斌、高凌百监视双方撤兵。

  • 1932年10月29日讯：广东揭阳遍地皆蝗，晚稻被害。

  • 1932年10月29日讯：兰州教育界以9、10两月未领到薪金，是日起罢教索薪。

  • 1932年10月29日讯：甘肃省府政务会议决议预征1933年田赋。

  • 1932年10月29日讯：江都反“清赋”运动领导人葛广兴、陈友善、罗才良、杨德昌、刘玉山、卜登云六人经江苏省府委员、省保安处长李明扬等亲自审讯，是日被杀害。

  • 1932年10月29日讯：红一方面军总部发表文告，指出国民党军已将四次“围剿”的重心移到江西，号召军民保卫苏区。

  • 1932年10月29日讯：立法院通过《国际海上人命安全公约》。

  • 1932年10月29日《申报》：北平息，义勇军占据义县城后，即向七里河子进攻，日机向该处爆炸，战事激烈，日列车26日驰往七里河子东站，以重炮掩护日军作战，义勇军死守喇嘛寺，日军将民间村庄，全行轰毁，战事迄今未停止。（28日专电）

  • 1932年10月29日《申报》：山海关息，25日日军骑兵二百余名，步兵一团飞机五架，开往千金寨南边，进击辽东义勇军。总指挥黄宇宙亲率卫队与之接触，黄部凭山以守，虽经一昼夜，日军所有飞机大炮俱失效用，最后黄部卒将日军击退，死伤未明，黄部得马七匹，步枪48杆。（28日华联社电）

  • #抗战影像#三名在屋顶上的日军，机枪手正手持大正十一年式轻机枪瞄准目标。

  • 1932年10月29日《申报》：北平息，苏炳文昨电平称，日本松本师团前26日午，派爆炸机数架，到海拉尔抛掷重磅炸弹，散放松本师团长署名传单，声言将派攻城重炮，大股军队，多架爆炸机，实行粉碎札蓝屯博克图海拉尔满洲里等处，不成灰烬不罢等语。查上列各地，均非战斗区域，竟有此等残暴宣传，其毒辣阴狠，足以危害中外商民生命财产，视屠杀如儿戏，非特有损日本军队之价值，实亦大伤国际人道之信条。（28日专电）

  • 1932年10月29日《申报》：齐齐哈尔息，本日上午10时，由齐齐哈尔出发之801号列车，行至五家站，忽有义勇军三百名，从50米之近处，猛袭松本某大队五中队横泽特务曹长以下23名所乘之客车，并跳入车内，欲击杀下士官兵。双方互以手榴弹及其他，大举格斗，义勇军未能达到目的。遭难列车，上午11时折还齐齐哈尔，日军战死兵四名，重伤八名，轻伤无名。（27日电通社电）

  • 1932年10月29日讯：赵尚志率领的巴彦游击队在“绿林好”部队配合下，不到半小时即袭取了东兴县城。

  • 1932年10月29日讯：刘文辉致电中央表示愿将所部悉交刘湘，不愿延长内战。

1932年10月28日

发表于 2021-10-28 更新于 2022-02-25 分类于 局部抗战(1931-1937)

  • 1932年10月28日讯：《大公报》发表题为《营救陈独秀》之短评，称：“如果用哀恳式的乞怜，感情式的缓颊，在法律以外去营救他，倒反转辱没了这位有骨头有意识的老革命家”；蔡元培们致中央电内“矜惜耆旧，爱怜人才”的话，是“多此一举”。

  • 1932年10月28日讯：李宗仁、白崇禧在广西南宁召开桂系党、政、军要员会议，讨论两广经济提携合作问题。

  • 1932年10月28日讯：蒋介石自汉口抵长沙，部署“剿匪”。

  • 1932年10月28日讯：闽省府委员因财政困难向国民政府总辞职。

  • 1932年10月28日讯：蒋介石之代表张钫、刘峙之代表刘耀扬，在济南与韩复榘商鲁事，张转达蒋意：令韩部包围掖县、莱阳等县之军队后撤，以便让刘珍年部离鲁。韩表示服从。

  • 1932年10月28日《申报》：天津息，孟昭炎有电到津后，顷据前线归来某君谈，义县附近，自11日发生战事，国民救国军孟昭炎等部及其他友军，12日迫近县城猛攻，前传之13日克复，当系指敢死队混入城内活动，此后连日剧战，至15日遂克义县。闻国民救国军19日由北票等处开到大批援队，自晨四时至晚九时，肃清残敌。同时，在锦朝线上蔡台七里河子间掘毁路轨，割倒电线杆，以牵制驻锦敌军，在此十数日间，救国军似有屡进率退模样。（27日日联社电）

  • #抗战影像#日军一名副射手正在为日制八九式掷弹筒装弹，正射手调教角度准备发射。

  • 1932年10月28日《申报》：北平息，救国军董荣久部，25日全军一万一千余名，分三路向锦州猛攻，第一旅李世明部，及第二支队侯璧峰部三千余名攻锦西门。第三旅曹振国部及第一支队李荣禄部，第三支队宫仲元部五千余名，进攻东门及车站等处，第二旅王永良部，及第四支队展国枢部三千余名，攻北门。26日晨10时许，仍与日军肉搏中，双方伤亡颇众。自卫军邢九鼎路雨田，率部四千余名，11时增援。董部副官长关廷购办大批棉衣，今晚运赴前方应用。（27日专电）

  • 1932年10月28日《申报》：北平息，苏炳文自海拉尔电平云，濮炳珊15日在拜泉誓师，当即整军向泰安镇进发。因乌眼河泛滥，道路泥泞，乃架设军桥。17日以骑兵集团挺进，占领傲龙沟，并破坏铁路电信。我官兵奋勇杀敌，是役毙敌数十名，得火车两列，军用战利品无算。19日夜主力全部渡河，20日拂晓开始攻击，即日占领泰安镇。是役毙敌四十余名，获坦克车两辆，械弹无算。同晚克山之敌数百名在甲车野炮掩护之下，向我逆袭。我官兵奋不顾身，激战七小时，卒被击退。敌人伤亡枕籍，我方亦有少数伤亡。现我军已遮断齐克路，日内可完全解决，然后直攻龙江，规复国土可待。（27日专电）

  • 1932年10月28日讯：川北联军推杨森为前敌总指挥，进攻简阳。30日，罗泽洲、李家钰等部联军占安岳，向资中、内江推进。

1932年10月27日

  • 1932年10月27日讯：国民政府令派萧吉珊为宣慰华侨专员。

  • 1932年10月27日讯：何成濬乘飞机视察樊城，指挥所部“追剿”红四方面军。

  • 1932年10月27日《申报》：北平息，吉江救国军第一军许常振旅，20日攻通河，与敌激战四小时，毙敌五名，获步枪五枝，子弹八百二十粒。（26日专电）

  • #抗战影像#日军爬上一列缴获的东北军装甲列车。

  • 1932年10月27日《申报》：北平息，马占山23日电称，徐海亭宋善和两旅，猛攻拉哈站，日军凭坚固工事扼守。18、19日敌军飞机4架，向拉哈站外我军防地投弹轰炸，马抵某地视防，指挥部队，向齐克线西进。拉哈站仍派主力包围攻击，我右翼军濮司令部业将克山攻下。义勇军南廷芳部，18日将北安镇占领，除另调主力军直向省垣挺进外，一面搜索敌军残余，肃清中路云。（26日专电）

  • 1932年10月27日《申报》：北平息，日前日军第廿九联队约三千余人，偕同靖安游击队（伪军）四千余人，分三路向通化进攻，在通化南廿余里某处，与唐聚五部李春润大刀队接触，李部旋退却，将敌一部诱进包围，李部伏地佯作受伤。迨敌迫近，群起反攻，敌死伤甚众，伪靖安队反正者极多，余均溃散，获军械甚多。（26日专电）

  • 1932年10月27日讯：国民党中常会决定，12月15日召开三中全会。

  • 1932年10月26日讯：华北回民护教团因南华文艺社登载侮辱回教之文字，派代表马文清等四人赴京请愿，要求查封该社，将主编人曾仲鸣撤职治罪，并将撰稿人娄子匡逮捕法办。27日，马等到京。

  • 1932年10月26日讯：中共临时中央任命周恩来兼任红一方面军总政治委员。

  • #抗战影像# 一二八淞沪抗战中，一架刚向火车北站扔下炸弹，使其起火并炸死楼内一些狙击手的日本飞机

  • 1932年10月26日讯：中央限韩复榘28日前撤兵，是日韩电请展缓，俟海军接防烟台、龙口，再撤潍西。

  • 1932年10月26日讯：蒋介石派张钫赴济南调解鲁事。

  • 1932年10月26日讯：国民政府派李世中为议订中巴（西）友好通商航海条约全权代表。

  • 1932年10月26日讯：刘文辉退出成都，邓锡侯部入城维持秩序。潘文华部占江津。

  • 1932年10月26日讯：国民党中央政治会议决议，交通部长陈铭枢辞职照准，内政部长兼代交通部长黄绍竑呈辞兼职照准，任朱家骅为交通部长，翁文灏为教育部长。28日，国民政府明令发表。

  • 1932年10月26日《申报》：北平息，吉救国军冯占海部约五百余，20日进攻长春，与伪警卫军在兴龙山战数小时，伪军溃退。该部已将该处完全占领，获军需品甚众，该部稍事整顿后，即向长春进攻。（25日专电）

  • 1932年10月26日《申报》：北平息，日军昨又增派一师团到辽东，用飞机及重炮，与唐聚五部激战。唐部伤亡二千余人，日方死伤之数不详。此次战事较去岁龙江之役尤烈。（25日路透社电）

  • #抗战影像#伪装的友善——侵华日军摆出一副与中国儿童友善相处的模样。

  • 1932年10月26日《申报》：北平息，东北救国军思路孟昭田电称，所部分三路，12日总攻义县及西门车站，并于后方袭取朝阳寺车站，战三昼夜，15日晨敌溃散，我军同时克服各处。戮敌不计，获械百枝，机枪二挺，近日敌同伪军终日以大炮飞机轰炸，现我军出城，掘壕死抗，正危险万急中。（25日专电）

  • 1932年10月26日《申报》：北平息，榆关来人谈，十三站北宝阳楼附近义勇军，与日人时冲突。21日晨张鸣五部将宝阳楼占领，正迫击时，后路突被截断，嗣有义勇军二百余来援，始解围。双方死亡颇重，日死40余，我方死排长刘忠武、兵士20余，伤10余，现经费极困难。（25日华联社电）

  • 1932年10月26日讯：国民政府对《国联调查团报告书》意见由外交部电达国联中国代表，凡妨害主权、领土完整者明白表示不接受，凡无害主权、领土者原则接受。

1932年10月25日

发表于 2021-10-25 更新于 2022-02-25 分类于 局部抗战(1931-1937)

  • 1932年10月25日讯：正太路由法移交国民政府，是日在石家庄举行接收典礼，由山西省府齐厚之参加接收。

  • 1932年10月25日讯：国民党江苏常熟县党部以《民众日报》等八家报刊“违反出版法”，勒令停刊。

  • 1932年10月25日讯：陈独秀、彭述之移押江宁地方法院看守所。移押前何应钦在军政部秘密“传询”陈，陈答称与鄂赣等省暴动行动“毫无关系”；抗日问题“仍须联俄方为有利”。何请求写字，陈写“三军可夺帅也，匹夫不可夺志也”。

  • 1932年10月25日讯：行政院决议：河北省政府委员兼民政厅长王玉科、兼财政厅长姚宏 、兼实业厅长何玉芳均免本兼各职，任魏鉴、鲁穆庭、史靖寰为河北省政府委员，魏鉴兼民政厅长，鲁穆庭兼财政厅长，史靖寰兼实业厅长。28日，国民政府明令发表。

  • 1932年10月25日《申报》：北平息，义勇军耿继周部约2千余人，17日分路进攻新民县城，与日军五百余名激战，我分四路进攻，第一路张子安率领，由城东长沟沿，第二路何冀臣由城南八里堡，第三四两路李升久由城西北两面白旗堡等地，五路奋战二小时，将南门攻入，将发电处破坏，电灯均灭，秩序紊乱，混战二小时。日军向城外逃走，我军即占领，毙敌30余名，获机枪二挺，步枪二十余枝。我军阵亡十余、伤数名。19日晨日军由沈调来飞机数架，向我猛烈轰炸扫射。我军迎战，因弹药不足，向城外撤退集合，拟不日再行总攻。（24日专电）

  • 1932年10月25日《申报》：北平息，自黑省马占山、苏炳文联络后，图进展辽东，唐聚五部已归复20县失地。其他各地义勇军，均在苦战中，日方虽增兵，但均疲于奔命。洮热线日军部队，已调往南北，参加攻击马、唐各军。该线极空虚，日方乃在通辽钱家店一带，收买蒙匪两千余名，改易日装，开往洮南线驻守，防义勇军暗袭。（24日专电）

  • 1932年10月25日《申报》：北平息，义勇军前敌指挥刘振邦部，第三路游记司令宫仲九，22日晨，率部三千余名抵锦西附近，与日军七百余名激战。日军用机枪大炮向义勇军猛攻，我军拼命冲杀。及12时，日军某大尉，率日鲜军及伪国军队五百余名增援，并有装甲汽车掩护及飞机10余架掷弹轰炸，宫亲身指挥，迄未后退。（24日专电）

  • 1932年10月25日讯：国民政府令张学良全权调处鲁事。同日，刘珍年电呈中央，请将该师调离鲁境。
