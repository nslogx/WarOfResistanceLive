1932年04月29日

发表于 2021-04-29 更新于 2021-08-27 分类于 局部抗战(1931-1937)

  • 1932年4月29日讯：山东济南公安局将上月逮捕之共产党人袁兰荣等46人解送“军法会审委员会”裁判。

  • 1932年4月29日讯：萧佛成、陈济棠、李宗仁联电闽省方声涛、刘和鼎、张贞、卢兴邦、陈国辉等，请派兵夹击共产党军。

  • 1932年4月29日讯：驻沪日军在虹口公园庆祝“天长节”，举行阅兵式。韩国独立党员尹奉吉掷弹，上海派遣军司令官白川、公使重光、师团长植田、舰队司令官野村、总领事村井、日居留民会长河端均受伤。尹奉吉当场被捕。晚，外长罗文幹按国际惯例电重光慰问。

  • 1932年4月29日讯：粤赣闽三省“剿匪”总司令何应钦赴赣部署三省“剿共”事宜，5月1日抵南昌。

  • 1932年4月29日讯：粤空军总司令张惠长由宁电粤辞空军总司令职。陈济棠手令空军参谋长黄光锐代理粤空军总司令，任张惠长为第一集团军高等顾问。

  • 1932年4月29日讯：留京国民党中委举行谈话会，选任邵元冲为考试院副院长，送洛阳中央执行委员会核行。

  • 1932年4月29日讯：鄂省府议决：呈请行政院抚恤李汉俊、詹大悲；拟发之短期公债改发“剿匪”及市政公债各150万元。

  • 1932年4月29日讯：日军在南天门码头登陆，随即增加兵力，以一部前出至下游通河，登陆并占领通河。

  • 1932年4月29日讯：国民党中央政治会议开谈话会，讨论召集国民代表会方案，各委员认为国民代表会名称须更改，10月10日召集嫌迫促。

  • 1932年4月29日讯：冯占海在高丽帽子集合部队讲话，做攻击宾县准备，因目标暴露，遭日机轰炸，伤亡二三百人。

  • 1932年4月29日讯：国联特委会开秘密会，决定按照3月11日大会决议案草具报告。

  • 1932年4月29日讯：我东北自卫军第26旅邢占清部、第5旅李辅亭部、第4旅李华堂部、骑兵第6旅刘化南部围攻珠海县城，并分兵向县城周围车站发动猛烈攻击。

  • 1932年4月29日《申报》：北平息，外讯，义勇军克通化，占各机关，断绝外间交通，日侨及领馆人员被扣县政府。（28日专电）

  • #抗战英烈#韩籍义士尹奉吉——尹奉吉在投弹后当场被日军捕获，任凭日本宪兵严刑拷打，他只说行刺完全由他一人承担。1932年12月19日上午7点40分，尹奉吉在日本石川县金泽日本陆军基地英勇就义，年仅24岁。1945年日本战败投降后，尹奉吉义士的遗骨被迎回韩国，安放于首尔孝昌公园三一庙。现在上海虹口公园（今称鲁迅公园）、日本金泽均立有尹奉吉义士纪念碑。鲁迅公园里有一座“梅亭”，以纪念尹奉吉（号梅轩）。每年4月29日即事件发生之日，在尹奉吉的故乡，韩国忠清南道礼山郡都要举行梅轩文化节。

  • #抗战英烈#韩籍义士尹奉吉——1932年4月29日11:30，“天长节”大会现场进入高潮，全场日本人高唱国歌并奏响礼炮。正当第三声礼炮时，尹奉吉冲出人群将装有炸弹的水壶便当盒精准地抛上了主席台。巨响过后，河端贞次（日本驻沪居留民团行政委员长，三友实业社放火杀人案幕后主谋之一）当场丧命；白川义则（日军上海派遣军司令官）重伤，苟延残喘至5月26日毙命于上海；野村吉三郎（日本海军第三舰队司令）被炸瞎一眼；植田谦吉（日本陆军第九师团长）、重光葵（日本驻华公使）均被炸断一足；村井仓松（日本驻上海总领事）负伤。

  • #抗战英烈#韩籍义士尹奉吉——1932年4月29日上午10时整，“天长节”祝捷大会开始，检阅台上有白川义则（大将）、植田谦吉（中将），重光葵（日本驻华公使）、河端（日本驻上海总领事）等人 ，以及美、英、法等国驻沪领事。白川义则、河端等发表完祝辞。

  • 1932年4月29日《申报》：哈尔滨息，开河下游载日兵之浅水汽艇，27日在哈东老山头，为义勇军袭击，沉一艘，溺死日兵四十。江防舰利济、江清、利绥，各载日军百余下驶依兰。舰上海员，均于中途乘监视不备，泅水逃逸，日军在哈觅去白俄技术人员数百补充。（28日专电）

  • #抗战英烈#韩籍义士尹奉吉——1932年4月29日8时，尹奉吉顺利进入虹口公园庆祝日本天皇寿辰“天长节”会场，他身穿西服，肩挎水壶，手提日式便当盒，两者内均藏有烈性炸弹。

  • 1932年4月29日讯：驻京日领馆举行庆祝日皇“天长节”，外交次长徐谟、亚洲司长沈觐鼎、警备司令谷正伦及各机关代表均前往祝贺。

1932年04月28日

  • 1932年4月28日讯：行政院决议将国难会议决议案分送各部、会施行。

  • 1932年4月28日讯：国民政府令准免侨务委员会委员兼常务委员林柏生本兼各职；中华民国驻英国特命全权公使施肇基因病辞职照准。

  • 1932年4月28日讯：日军村井支队占黑省珠河东南之海林。

  • 1932年4月28日讯：马占山通电声明：“黑龙江从未与日人订有条约。如有伪造占山名义，或任何人出面订立之契约，概不承认，均属无效。”

  • 1932年4月28日讯：宋子文以伪满将东北盐余担保向日本银行借债，特呈请国民政府通知国联，在中日事件未解决前，伪国对外借款，中国政府不负偿还责任。

  • 1932年4月28日讯：国联调查团起草第一次报告书，将于5月1日提交国联。

  • 1932年4月28日讯：国联特委会召开不公开会议，主席希孟报告修正上海停战决议案草案经过。国联秘书厅接日本代表团通知，内称日本已接受英使蓝普森折衷案，拒绝再参加十九国特委会讨论。

  • 1932年4月28日讯：沪中日停战会议在英总领事馆举行非正式会议，通过英使蓝普森所提之折衷办法。

  • 1932年4月28日《申报》：北平息，沈阳来人谈，日唆使鲜人抢夺我田产。辽阳海城二县，被鲜人强夺民田二万余亩，富户时被诬以排日，收没财产。（27日专电）

  • 1932年4月28日《申报》：北平息，义勇军第14路司令那景春，率众五百余人，25日攻沈小西边门，与日警宪队激战良久，日警宪伤亡多名，义勇军死三伤八。后日援军至，不支而退，烧敌粮秣草垛数座。（27日专电）

  • 1932年4月28日《申报》：哈尔滨息，黑军骑兵八百余，25日出现于齐克路拉哈朋，黑垣大恐慌，日军天野旅团出城布放。（27日专电）

  • 1932年4月28日《申报》：北平息，秦皇岛26日下午电，沈阳确息，当地领馆界25晚6时得讯，马占山部队抵距长春30里地带，伪都极度震惊。（27日专电）

  • 1932年4月28日讯：冯占海部主力以游击方法，诱敌至蚂蚁河之线，潜派宫旅蔡营绕道至敌人后方宾县之高丽帽子，劫取其弹药及大部分军需品。击毙伪军看守士兵及日本准尉三人，劫获子弹六十万发，野炮弹一千四百发，迫击炮八门，炮弹四千发，我军士气大振。

  • 1932年4月28日讯：蒋梦麟自平赴京向教、财两部接洽平、津教费。

  • 1932年4月28日讯：内蒙王公联席会议，决接受章嘉宣化内蒙佛教，但请中央另委熟悉内蒙政情人员领导政治。

1932年04月26日

发表于 2021-04-26 更新于 2021-08-27 分类于 局部抗战(1931-1937)

  • 1932年4月26日讯：冀、晋、察、绥诸省以财政奇绌，定5月1日实行鸦片公卖，以充军费。

  • 1932年4月26日讯：日军三个混成旅开吉东总攻义军，义军已于25日克中东路西之兰西城。

  • 1932年4月26日讯：湖北“绥靖”公署划京山、天门、潜江、应城、沔阳、汉川、钟祥、宜城等八县为“特别剿匪区”，行政、公安均归徐源泉指挥。

  • 1932年4月26日讯：国民政府派刘绍先代理陆军第四十三师师长；任命林秉周为海军陆战队第二独立旅旅长。

  • 1932年4月26日讯：湖北省府会议议决劝销善后短期公债300万元，充“剿共”经费。

  • 1932年4月26日讯：国民党西南执行部、政委会联席会议决：一、唤起西南民众监督政府勿与日妥协；二、由一、四集团派劲旅于最短期内肃清赣、闽“匪”共，并电中央饬邻省友军“会剿”；三、陈济棠、李宗仁表示，在抗日“剿匪”事件未告段落前，暂不就中央所委新职，由陈、李将此情形报告中央。

  • #抗战影像#1932年4月26日，韩籍义士尹奉吉进入虹口公园实地考察，为日本“天长节”庆祝会上的刺杀行动作准备。当晚，尹奉吉在自己的住所给父母、妻子和两个儿子写下了遗书。

  • 1932年4月26日讯：蒋光鼐到京谒蒋介石等报告前方情况，并商洽关于日军撤退交涉之应付事宜。

  • 1932年4月26日《申报》：北平息，开鲁附近热河第九路义勇军联合各部约八九千人，进攻通辽，日羽山支队及独立守备队步兵第七十联队开通辽。（25日专电）

  • 1932年4月26日《申报》：延吉息，此间总领事接电谓，昨日下午四时，延吉冷水泉子日警察分署，被义勇军围攻，激战甚烈，总领事即派警官队前往救援。（25日日联社电）

  • #抗战影像#1932年4月26日上午10点，在上海法租界霞飞路宝康里27号，韩籍义士尹奉吉，左手握手榴弹，右手持手 枪，胸前挂着誓词，在韩国独立运动旗帜下宣誓加入“韩人爱国团”，并接受韩国临时流亡政府代总统金九委派，准备在几天后于虹口公园日本“天长节”庆祝会上，刺杀参会的日本军政界高级官员。

  • 1932年4月26日《申报》：北平息，自卫军二千名昨晨占石头城子，当地与长春电报断绝。（25日专电）

  • 1932年4月26日讯：日军第10师团33旅团在哈尔滨登船，顺松花江而下，向南天门码头冯占海部一个营发起攻击。
