1932年10月07日

发表于 2021-10-07 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月7日讯：凤城双庙子村长李春光和民团长陈友天、王寿山等组织辽东抗日军，共700人。

  • 1932年10月7日讯：三省“剿匪”总部公布《剿匪区内各省农村土地处理条例》，规定土地引起之纠纷“一律以发还原主确定其所有权为原则”。

  • 1932年10月7日讯：国联大会开会，中国代表胡世泽发言，主张除医药及科学用途外，完全禁售鸦片。

  • 1932年10月7日讯：冯玉祥自泰安北上易地休养，临行前在济南车站发表书面谈话称：“抗日问题，予仍主张以武力收复失地。惟有抵抗方是中国唯一出路。”

  • 1932年10月7日讯：邹鲁由香港回广州，与唐绍仪、陈济棠商对《国联调查团报告书》应表示之意见，邹主根据胡汉民评论，唐主暴露日本历来阴谋，陈则称结论绝对不能接受。

  • 1932年10月7日讯：宋子文偕褚民谊乘机飞沪征求汪精卫对《国联调查团报告书》意见，并促汪入京主持中枢。

  • 1932年10月7日《申报》：东京讯，日军自占领东三省以来，日人就为虎作伥，积极夺取我东三省土地，傀儡一系不敢有异议。官有地已不收代价，而农民土地亦等于白白奉送。兹举一例，最近日军计划在沟帮子建造飞机场，所需民地要三千亩，而每亩则仅以六角之代价作为收买。如此三千亩之土地，则仅以洋1800元，而入于日人之手，其他东三省民众处日逆之淫威下，以无代价强迫先出土地者，亦不胜枚举。（华联社6日电）

  • 1932年10月7日《申报》：北平息，伪奉山路车昨到榆关，误点十一小时，旅客仅十余人。据谈，沟帮子、锦州均发现义勇军，客车夜晚不开行，天明经过锦州车站时，闻有枪炮声不绝，车站停日甲车一列。（6日专电）

  • 1932年10月7日《申报》：北平息，9月20日，义勇军司令于百恩、张海涛率部六千名，围攻北镇县沟帮子八道壕站等处，与日军及伪警激战。22日，将北镇县城占领，23日，日机及大部步炮兵来援，我军徇民众之情，退守防区。29日，日机五百名携重炮十数门，机枪数十挺，以飞机6架，协同伪公安局长单孟庭、伪大队长何某，及伪警四百余名，向于部攻击。义勇军佯退，绣日军入山内大举包围，敌溃不成军。伪公安局长及大队长均被义勇军大刀队斩杀，获敌大小枪七十余枝，子弹三千余粒，毙日军伪警一百五十余名。（6日专电）

  • #抗战影像#侵占我东北的日军第39混成旅团，正在从新民火车站出发。

  • 1932年10月7日《申报》：北平息，攻沈义勇军退守千金寨、南台、浑河后，因补充实力未积极动作，五日晨三时许，义勇军三百余人突击浑河堡，向商埠地进攻，与日军伪警相遇，在沈阳郊外激战甚剧，战况不明。（6日专电）

  • 1932年10月7日《申报》：北平息，救国军董荣久、赵宝琦等二日占领沟帮子、羊圈子、大凌河等处后，5日拂晓，董率部及三十路穆华南部，由沟帮子一带再向锦州反攻，在锦东二十里之双羊店，与日军及伪军展开激战。日军以装甲汽车掩护步、骑、炮队猛攻，董率部绕至敌军后方，穆部为左翼，赵袭右方。阎延山、黄展雄、孟凤山、颜硕衡等率领余部，及民团各部，诱敌进退，四方布置完善后，向敌包围猛攻，激战数小时。锦州室师团司令部得报后，即遣该师团主力军增援，并用飞机10余架向我掷弹轰炸，坦克车等掩护，我军拼死抵抗，刻在敌炮火中奋战。（6日专电）

  • 1932年10月7日讯：日军200余人坐30只橡皮艇强行渡江，突破我军防线，随后增兵至500余人，张玉珽旅长急调第二旅步兵第一团高峻岭部增援，毙伤敌50余人，我军伤亡80余人

1932年10月06日

发表于 2021-10-06 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月6日讯：军政部代表李钺、范毓璜抵济南，转赴胶东前线调查，并监督韩、刘两军实行停战。

  • 1932年10月6日讯：全国民食会议在南京开幕，到浙、闽、粤、湘、鄂、赣、皖、沪等省、市代表16人。7日，开第二次会议，通过确定国外食粮进口税则，成立省、县、区食粮管理委员会等案。12日闭幕。

  • 1932年10月6日《申报》：北平息，闻东北义勇军二千人，10月2日攻击绥中，该处由日兵二百，抵抗甚力，但卒败走。义勇军乃入绥中城。未几，日军援兵开至猛力反攻，义勇军因弹药不济，遂弃城而去。闻义勇军曾射落日机两架，并重创日兵。（5日路透社电）

  • 1932年10月6日《申报》：天津息，日军再沈阳组织“正义团”，专门负责收买义勇军首领。（4日华联社电）

  • #抗战影像#一名辽西义勇军战士埋伏在稻草堆中，瞄准敌人准备射击。

  • 1932年10月6日《申报》：北平息，苏炳文抵海拉尔指挥军事，所部集中博克图等处，一部骑兵有嫩江下流渡河，抄至卜奎后路，攻黑垣部队达离城南方十里地点，俟隙进攻，黑垣日兵仅千余，极恐慌，刻沿齐克路南进，与苏部队联合，围攻黑垣，日内当有激战。（5日专电）

  • 1932年10月6日《申报》：北平息，王德林所属义勇军骑兵一营、炮兵一营、工兵三营，上月29日向吉林进攻至近郊地方，与日军接触，激战一昼夜，日军溃退。获大枪三十余枝，伤亡日军90余名，刻已进抵龙潭山附近。吴义成部步兵一旅机枪连两连，30日由防地越延吉进袭龙井村。由龙井村至上山峰间之小火车铁轨50余里拆毁，并将图门江铁桥炸断。嗣由么刘两团协助，向一面坡推进与敌激战两日，刻仍在相持中，始吉行部同时亦向前推进，已将头道沟二道沟三道沟占领，俘获日兵两大队，计九百余名（注：原文如此，存疑）。王德林刻正亲率所部猛攻延吉，该地日军迭被挫伤，敌气已馁，日内决刻克复。（5日专电）

  • 1932年10月6日讯：中华苏维埃共和国临时中央政府通电反对《国联调查团报告书》，指斥调查团出卖中国以取好日本，号召全国民众武装起来，以革命的民族战争来撕碎报告书，驱逐日本及一切帝国主义出中国，以求得中华民族完全的解放和独立。

1932年10月05日

发表于 2021-10-05 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月5日讯：国联中国代表团发表宣言，对《国联调查团报告书》表示遗憾，但称中国对报告书中之建议，愿加以慎重之考虑。

  • 1932年10月5日讯：何应钦电川军将领刘湘等息争御侮。7日，刘湘电复何应钦陈述川省情况，遵令制止一切纠纷，并请示今后处置办法。

  • 1932年10月5日讯：韩复榘致电蒋介石，历数刘珍年“纵兵殃民”罪状。鲁省府委张苇村赴京向中央请示制止韩、刘冲突之有效办法。

  • 1932年10月5日讯：国民党中央政治会议决议，加推朱家骅、居正、陈果夫、叶楚伧、何应钦、贺耀组、黄慕松、朱培德为外交委员会委员，推定汪精卫、宋子文、罗文幹、朱培德、顾孟馀等为常委。

  • 1932年10月5日《申报》：北平息，义勇军第16路邓铁梅部千余人，4路耿继周部骑兵千五百名，及王鹏达部五百人，9月30日，会攻沈垣。在距西南二十里浑河浦，与敌军五百余人激战一昼夜，毙敌30余名。义勇军向南部推进，将南满路苏家屯站全部破坏，义勇军第1军区彭振国，率第一路王显庭部千余，郑桂林部千余，耿继周部六百余，并他部共五千余名，业将锦西恢复，刻向锦州推进，即将有激战。9月30日，耿继周部第一师张润亭部，在距锦州60里某处，与日军激战一昼夜，日军退却，获军需品甚多。（4日专电）

  • 1932年10月5日《申报》：北平息，热退伍军官孙英杰，在蒙边一带，与当地乡绅保甲及旧日部属联络，约三万余众，组织乡国军，以游击方式威胁进犯热境日军。（4日专电）

  • #抗战影像#“一·二八淞沪抗战”期间，一支活跃在前线救护伤员的中国红十字救护队。

  • 1932年10月5日《申报》：齐齐哈尔息，据由海拉尔归抵此间之华人谈，护路军司令苏炳文于1日发出树立东北政府之声明，自任东北军总司令，任命张殿九为副司令。目下海拉尔由苏炳文军约二千与张殿九军严重警备。（4日电通社电）

  • 1932年10月5日《申报》：北平息，救国军六十路季司令率部二千，二日猛攻绥中，日驻军三百余名溃退。救国军占绥中，敌伤亡甚众，并击落敌机二架，以弹尽援绝，暂退出。（4日专电）

  • #抗战影像# 锦州的中国军队兵营鸟瞰：驻扎在这个军营里的卫戍部队在日军逼近锦州后被张学良将军撤走

  • 1932年10月5日讯：国民党中央政治会议讨论《国联调查团报告书》，以案关重要，决先交外交委员会详加研究，签注意见，再行集议。

1932年10月04日

发表于 2021-10-04 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1932年10月4日讯：《社会新闻》（三日刊）在上海出版。

  • 1932年10月4日讯：北平小学教员因对经费解决办法不满意，经全体大会决议赴市府请愿。10日，北平市府向银行借款五万元发放教费。12日，市长周大文答应拨给十万元（中央协款五万、银行借款五万）充作小学教职员维持费，并商定17日复课。

  • 1932年10月4日讯：行政院会议讨论《国联调查团报告书》，以事关重要，决将该报告书分发各部、会长审阅。晚7时，由宋子文汇集意见。

  • 1932年10月4日讯：鄂省府决议，以吴国桢继任汉口市长。

  • 1932年10月4日讯：行政院决议，在颜惠庆出席国联会议期间，驻美公使职务由施肇基代理。

  • 1932年10月4日讯：中国博爱会等15团体致电国民政府，内称：“调查团报告书无异国际共管，求救不如自救，求人不如求己，速与日本经济绝交，出兵讨伐叛逆。”

  • 1932年10月4日讯：全国民众救国团体联合会通电全国，称调查团报告书“显系抑弱扶强”，表示“依赖国联，极端错误”，要求一致猛醒，誓死抵抗，全力自救。

  • 1932年10月4日讯：胡汉民对《国联调查团报告书》发表意见，谓此书决不必要，调查团草此报告，为自毁立场。应否认有所谓满洲政府之存在，及所谓满洲国境之存在。东北问题之最终解决，不在国联，不在公约，而在我国人民最后之自决。

  • 1932年10月4日《申报》：北平息，义勇军张鸣五部五千余人，上月25日在锦县西北五十里之孟家屯子一带，与日军二百余名，激战约五小时，日军溃退。我军获军需品甚多，俘日军三十余名。（3日专电）

  • 1932年10月4日《申报》：北平息，辽北义勇军第三军总指挥高文斌，率部二万余人北上，23日克服辽阳窝棚八面城。该地为四洮路要塞，杀日兵三十余人，得枪百十枝。辽阳窝棚为沈北大道，现辽北完全收复。（3日电通社电）

  • #抗战影像#1932年，一支行进中的东北军部队。

  • 1932年10月4日《申报》：北平息，东北学生军李克夷部，联合哈绥线义勇军万余人，围攻吉北苇沙河日军。日军23日由哈派甲车一列往援。过乌吉密站，被义勇军埋藏地雷炸毁，敌死百七十余人，被俘十四人，获机枪四架，炮一尊。（3日专电）

  • 1932年10月4日《申报》：北平息，救国军总司令董荣久，率部九千余名，围攻沟帮子。30日起，与日鲜军及伪军五千余名，肉搏已三日。敌屡用飞机大炮轰炸。二日晨10时，沟帮子室内商民，反应救国军。第卅路穆化南部三千余名来援，敌向东撤退，我军占沟帮子，商民皆悬国旗欢迎庆祝，董部略息仍前进。（3日专电）

  • 1932年10月4日讯：孙科向报界发表对《国联调查团报告书》意见，认为报告书能认清“九一八”责任，并说明日本造成伪国，该团“能辨是非，明公道”。又谓关于解决东北方案及建议，“日本实获益较多”，“自治实现，东北无异名存实亡”。

  • 1932年10月3日讯：陈国辉部经第六十一师包围后，派代表到泉州向蔡廷锴请降，以不杀陈为条件。8日，蔡廷锴称陈部已大致解决，零星溃散者即可肃清。

  • 1932年10月3日讯：何应钦、顾孟馀在京召集川军代表，商议消弭川争办法。何、顾发言，望“一切纠纷均应诉之中央，听候中央处理解决，不得擅自用兵”。各代表表示接受，转电各将领知照。

  • 1932年10月3日讯：胡适在平对“路透社”记者称：彼对《国联调查团报告书》感觉满意，认为颇属公允，对报告书中所列解决中日问题之十项原则亦表同意。

  • 1932年10月3日讯：日军一部由齐齐哈尔以北渡江，遭东北民众救国军第一旅旅长张玉珽率富拉尔基步兵第一团一营击退，敌弃尸十二具。

  • 1932年10月3日《申报》：北平息，义勇军耿继周部千余人上月25日，在浑河浦附近，与日五百余名激战数小时，日军退沈阳。我军占领浑河浦，毙敌30余名，获步枪20余枝，炮1门，我方死五伤二，耿部准备向沈阳推进。（2日专电）

  • 1932年10月3日《申报》：北平息，锦绥义勇军张鸣五部一团，27日晨进攻锦州，日军死守，遂转攻女儿河车站，守站日军仅百余，被击溃，将车站占领，获军需品甚多，并夺获小米五十余麻包。该部与王显庭部联络后，共万余人，刻分散距锦城周围三四十里各处驻扎。锦城已成瓮中鳖，即可攻下。义勇军郑桂林部五百余人，上月30日攻绥中，战事颇烈，双方死亡甚重，已围攻三日，刻尚对峙。该部另分一部进攻兴城，亦在激战中。（2日专电）
