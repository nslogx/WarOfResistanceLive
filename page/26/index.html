1932年11月05日

发表于 2021-11-05 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1932年11月5日讯：东北民众抗日义勇军第十四路齐福臣部，袭击南满路十家堡车站，打死日军五人，焚毁车站。

  • 1932年11月5日讯：国民党广州市党部致电中央，请严办陈独秀，并称蔡元培等袒陈，“贻祸党 国，应予警告”。

  • 1932年11月5日讯：刘珍年电军政部报告，称掖、莱、栖三县情况仍未稍变，鲁东各地韩复榘军尚未撤退。

  • 1932年11月5日讯：沪市府将上海粮食委员会电转呈行政院，请停止续借美麦，免粮价更落。7日，湖南商会电中央反对续借美麦。8日，宋子文对记者发表谈话称：“即或政府不购美麦，而厂商亦必同美国或加拿大订购，此为事实所必需，与米价跌落毫无关系。”9日，北平商会电请中央反对续借美麦。

  • 1932年11月5日《申报》：北平息，苏炳文电平云，我军第一二两旅一万六七余人，1日晨分由朱家坎腰库勒一带，向富拉尔基推进，与敌中山支队千余人接触。激战至午，敌退车站附近，我左翼骑兵支队，已抵海拉屯，与兴安驻军联络妥协，嫩江西岸之敌，已被我包围。（4日专电）

  • 1932年11月5日《申报》：北平息，义勇军石殿卿部七百余人，1日晨围攻朝阳寺日军，劫取日军给养。日军猝不及防，军用品为石部夺获甚多。日军赶由义县调甲车一列往援，义勇军始退。现义勇军集中锦朝路者，有石殿卿部二千，李宝连部三千，刘春起部三千，杜成栋部三千余，孙权东部二千余，合各地民团等，均达三万人以上。（4日专电）

  • #抗战影像#“一·二八事变中”，一支增援侵略上海作战的日本陆军部队，刚刚在码头下船，正在列队开赴战场。

  • 1932年11月5日《申报》：北平息，辽东义勇军某军团总指挥部，近被日伪军攻击，战况激烈。前在横道河子激战三日，敌机40余架轰炸，被我击落几架，敌死二百余名，我军死百余名。（4日专电）

  • 1932年11月5日《申报》：北平息，唐聚五部共十万余人所属实力最厚者为十九路司令王凤阁部，共六万余人，据守柳河南磐石一带。日军总攻以来，于芷山逆部，派兵三团靖安游击队两队，共三千余人，分两路向王部进攻。一路出朝阳镇袭击辉南，一路由海龙县攻金川，双方血战五日，伤亡俱众。王部团长阵亡一名，王率部堵击沈海路进攻之日军，历经数次战斗，日军多被包围击溃。沈海全路迄未通车，王部所储粮秣足够所部军用以备长期抵抗。（4日专电）

  • 1932年11月5日讯：敌27旅团旅团长以骑兵联队为先导，从克山南下攻打驻守拜泉的朴炳珊和邓文的抗日部队。

1932年11月03日

发表于 2021-11-04 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1932年11月3日讯：香港邮政总署首次试行空邮服务。

  • 1932年11月3日讯：常熟《民众日报》等八家报刊前因未依法登记，且登淫秽新闻被封，国民党江苏省党部不许该八家报刊复刊，亦不准改名出版，是日函省府饬县严办。

  • 1932年11月3日讯：刘文辉划地与邓锡侯，正式让出遂宁、潼南、安岳、乐至四县，并将陈鸿文部仍归邓指挥。

  • 1932年11月3日讯：刘文辉为缓和各方围攻局势，与邓锡侯、田颂尧、杨森、李家钰、罗泽洲等在成都商定弭战办法，将温江、崇庆、华阳（今并入双流县）、简阳、乐至、潼南、安岳七县划为邓锡侯防区，金堂、新都、彭县、成都四县划为田颂尧防区，顺庆（今南充）、遂宁、蓬溪等七县划为杨森、李家钰、罗泽洲防区，意在保留川南富庶区域。

  • 1932年11月3日讯：四川联军猛攻泸州，刘文辉以10万人防守，双方发生激战。

  • 1932年11月3日讯：蒋介石电令赣、鄂、皖各军限12月15日前彻底肃清红军，“逾期以纵匪论”。

  • 1932年11月3日讯：外交部电催法政府履行《中法越南专约》。

  • 1932年11月3日讯：蚌埠盐业职工反对政府垄断盐业，是日举行罢工，游行示威，要求撤销北盐公共营业处，维持民食。12日，蚌埠盐商公推杨剑伯等三人到京，向盐务署请愿，要求撤销该营业处。

  • 1932年11月3日讯：红一、三、五军团攻占黎川。建（宁）黎（川）泰（宁）战役结束。

  • 1932年11月3日讯：刘湘压迫泸州、内江边境，刘文辉电国民政府及蒋介石，请阻刘湘进兵，称旬日以来，一让顺庆，再让遂宁、潼南，三让江津、永川，四让大足、安岳、乐至、合江诸县，将士愤慨，咸愿粉身，而刘湘仍督所部积极猛攻。表示决再退让，并提出治川三方案：一、军民大政奉还中央；二、遵照中央编遣方案施行编遣；三、由中央明令改组省政府。

  • 1932年11月3日讯：韩复榘电何应钦报告撤防令已下，俟海军接防烟台，第三路军即开始撤退。

  • 1932年11月3日讯：东满特委在审查延吉县委秘书宋老头期间，抓获两名日本宪兵队的翻译，经审讯，供出宋老头是日本宪兵队派回来的密探。县委对宋老头进行了严刑拷打，宋老头被迫承认自己是“民生团”，并且供出了20多名“同伙”。此后，东满特委将打击范围扩大，酿成了持续3年的“民生团事件“，造成重大损失。

  • 1932年11月3日《申报》：天津息，安东讯，辽东民众自卫军司令林振青，因作战失利，极感悲愤，宁死不屈，廿三日晚在缉安自杀，闻者无不叹息。（2日华联社电）

  • 1932年11月3日《申报》：北平息，广东各县救国会筹欵七万元，接济义勇军，已汇马占山、苏炳文、冯占海、李海青、唐聚五、王德林各部。（2日专电）

  • 1932年11月3日《申报》：沈阳息，今晨零时，大刀会约二千人，分为二队，一队袭凤凰县城，一队袭凤凰车站，军警及公安队，与之交战。激战至今晨五时，日本守备队中，三枝（注：为姓氏）军曹负伤，公安队员二名死亡。（2日电通社电）

  • #抗战影像#一队侵占我东北的日本关东军士兵在冰天雪地里吃饭。

  • 1932年11月3日《申报》：山海关息，热河抗日军何民魂部李海峰师，自30日会合孟昭炎、马子丹等部，占领义县后，复于一日拂晓，分兵攻克朝阳寺，日军一部因李师将锦朝路炸毁截断归路，退朝阳寺山中，经李包围，现仍在激战中。（2日华联社电）

  • 1932年11月3日《申报》：哈尔滨息，今日日人报纸消息谓克山西三十里之泰安镇，10月20日有反满军二千人出现，围攻该城，日兵坚守10日待援。30日晨日军生力军兵两队来援，辅以飞机在泰安镇北攻击义勇军，迫之退走。守城日兵无多，颇有死伤，司令林上尉阵亡，日兵死伤各14人，南满铁路职员4人不知下落，传说东北反满军领袖李杜已于10月13日抵伯力云。（1日路透社电）

  • 1932年11月3日《申报》：北平息，日军九月中旬，在抚顺焚烧枪 杀极惨。据调查被焚各村及死亡人数，计大东洲死16名，小东洲死5名，千金堡死3名，平顶山死2500人，栗子沟二人，四家子一人，下洼子三人。（2日专电）

1932年11月04日

发表于 2021-11-04 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1932年11月4日《申报》：北平息，兰州电，兰州各界决为东北义勇军赶制棉衣万套，15日前可运出，并派代表赴平，为慰劳专员。（3日专电）

  • 1932年11月4日《申报》：北平息，救国军苏华轩部，上月31日，率部1700余名，进袭打虎山锦州一带，在锦州附近，与日军六、七百名，激战两小时。日方有新式武器及飞机三架助战，结果，义勇军阵亡六名，伤十一名，获手 枪三支，子弹三箱，日方伤亡甚众。（3日专电）

  • #插播#1904年日俄战争期间，在我辽东地区作战的一队日本陆军士兵于战斗间隙，正在吃饭。

  • 1932年11月4日《申报》：北平息，日甲车一日夜以巨炮向义县城外幸庄，轰击义勇军。义勇军联合民团共三千余人应战，激战三小时，义勇军退。敌死11人，伤甚众，义勇军亦颇有损失，刻正联合各部义勇军，再猛攻义县。义县车站已毁，锦朝路车停开。（2日专电）

  • 1932年11月4日《申报》：北平息，救国军孙全东部，肉搏长久，占领该地。旋敌由大虎山开来甲车一列，载兵百余，山炮二门，机枪四挺，另飞机二架猛攻。孙部弹药不充退却，毙敌大尉一、士兵五十余，军需品无算。26日台安县伪县长邓冠军，率公安队二百余，及日骑兵40余，山炮二门，赴台安县任。行抵黑山八里台子刘家窝铺附近，被孙部傅九江团包围，激战一昼夜，敌退。毙敌十余名，内有伪县政府科长，获枪六枝。28日夜，孙部刘汇川团潜至县街东小桥子附近开枪，敌全力应战。刘团更以大部队暗袭车站，焚敌给养车数辆，迨敌知觉，刘团遂退向某地集合。（3日专电）

  • 1932年11月4日讯：朴炳珊一部在八贝子府与日军对峙，一部迂回占领讷河镇，意图进占克东。此时，留守拜泉的黑龙江抗日军副司令刘宏萱（后被处决）叛变，扣留前方急需的三千套棉服装，暗地勾结日军参谋下芝少佐，准备日军由克山、明水、海伦来犯时作内应。

1932年11月02日

  • 1932年11月2日讯：陈济棠召余汉谋、香瀚屏、缪培南、李汉魂会商，决定联络在赣中央军分三路进攻江西遂川红军。

  • 1932年11月2日讯：国民党中央政治会议讨论解决川省纠纷案，议决重申国民政府十七年11月7日命令，并交行政院详定实施办法，制成方案，报告该会议。

  • 1932年11月2日讯：国民党中央政治会议决议：准上海市政府发行复兴市政府公债600万元。12日，立法院通过该项公债条例。

  • 1932年11月2日讯：豫鄂皖三省“剿匪”总部在汉口召集七省公路会议，蒋介石之代表曹浩森及国联所派修路专家敖京基、特赖贡尼、巴勒加、蒲德利、伯利参加。会议拟定修筑京黔、京沪、京陕、汴粤、京川、洛韶、京鲁、沪桂、海郑、株祁、京闽11条干线。10日闭幕，蒋介石到会训话宣称：“剿匪”根本办法是“发展交通，组织民众”。

  • 1932年11月2日讯：川籍旅沪中委杨庶堪等50余人拟具解决川事办法，推谢无量、黄胜祥携节略到京，交石青阳提交中政会讨论。

  • 1932年11月2日讯：蒋介石委朱绍良为湘、鄂、赣三省边区“剿匪”总指挥。

  • 1932年11月2日讯：何应钦电令韩复榘、刘珍年撤兵原防，并致电沈鸿烈，在第二十一师未到达前接防烟台、龙口。

  • 1932年11月2日《申报》：沈阳息，据濮阳特务机关处接电二十日以来，断绝消息之泰安，系被约四千之濮炳珊军包围。至28日止，已激战数次，日方战死中队长一名，特务曹长一名、兵士11名。（1日电通社电）

  • 1932年11月2日《申报》：北平息，辽吉黑民众后援会军息，接前方卅日电云，顷据交通界消息，及郑桂林报告称，廿九日拂晓，日军由兴城开坦克车三辆，驰往九门台山道河子等地，对郑部重重压迫，郑部因日方炮火猛烈，乃向小石山退却，避免正面冲突。并由另一部与日坦克车周旋，引入已枯之高粱地中，四面放火焚烧，日坦克车陷于火窑中，仅一辆逃走，其余两辆烧毁，死日兵十余名，高粱地被烧十余里，兴城车站可见火头等语，特闻。（1日专电）

  • #抗战影像#日本陆军军校毕业生正在排队领取毕业证书。

  • 1932年11月2日《申报》：北平息，耿继周部三千余人，28日与董荣久部联合，会攻锦州，与日军千余激战数小时后，日军开来甲车数辆援军七百余迎击，及日机数架掷弹，并以机枪扫射。被我击落二架，毙敌无数，我方阵亡营长一、官兵三十余，刻仍激战中。（1日专电）

  • 1932年11月2日《申报》：北平息，辽吉黑民众后援会军息，接前方电报云，兹据哈尔滨专员来电称，本（注：原文如此，疑为误，应为上）月27日早8时，救国军袭击宁安 ，当与日军激战4小时，毙敌20余名，后因日机轰炸，救国军为避免损失计，遂退伏附近山林。至下午4时，王德林部二千名，携带迫击炮及机关枪，又进迫该地，致使日军陷于苦战状态。嗣经日军圆边部队及赤河之警备队及飞机多架来援，王部乃退。是役毙敌40余名，生获负伤日军一名，子弹数千发，枪 支38枝等语，特闻。（1日专电）

  • 1932年11月2日讯：中共满洲省委派遣杨靖宇以省委代表的身份到吉海铁路沿线磐石，海龙巡视，指导工作，整顿抗日武装，并将这一决定向中央作了报告。

  • 1932年11月1日讯：在沪被捕与陈独秀案有关之共产党人李荣生、苏正海、饶志陆、陈善甫、纪维方、刘志福、吴俊臣、刘阿芳、陈王氏（即帅孟奇）、吴陈氏、朱彩弟（即朱镜如）11人，由沪市公安局押解南京交江苏高等法院，寄押江宁地方法院候审。

  • 1932年11月1日讯：　张群在京向川省各军驻京代表详询川局情形及各军现状后，即与戴季陶、石青阳、顾孟馀等会商解决川事办法。2日乘轮赴汉向蒋介石报告。

  • 1932年11月1日讯：刘湘部继10月31日进驻荣昌、合江之后，是日又占隆昌。杨森部进驻安岳。

  • 1932年11月1日讯：国民政府参谋本部国防设计委员会成立。由军事委员会委员长蒋介石兼任委员长，由秘书长翁文灏、副秘书长钱昌照负实际责任。主要任务是从事军事、国防、财经、文教、工矿、交通、农林等方面的调查，写出专题报告，供蒋介石等作决策时参考。
