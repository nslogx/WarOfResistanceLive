1932年04月23日

发表于 2021-04-23 更新于 2021-08-26 分类于 局部抗战(1931-1937)

  • 1932年4月23日讯：行政院讨论筹设各省、市、县民意机关问题，决定先在京、沪、平、津、穗、汉等大城市筹设参议会。

  • 1932年4月23日讯：沪日军一部撤退回国，太田少佐率海军陆战队第七大队离沪。重炮大队亦开吴淞，从张华浜登轮回国。

  • 1932年4月23日讯：第十九路军参谋长黄强入京，向蒋介石报告上海中日停战会议经过。

  • 1932年4月23日讯：蒋光鼐抵苏州视察防务。同日，汪精卫、罗文幹、陈铭枢由京抵昆山转前线视察。

  • 1932年4月23日讯：立法院通过兵役法原则，规定年满18岁至40岁男子，均有服兵役义务。

  • 1932年4月23日讯：杨虎城电呈国民政府，报告陕西36个县降黑霜，恳办赈以资救济。

  • 1932年4月23日《申报》：北平息，伪教育部拟接办东北冯庸两大学，创办费定四十万，东大改满洲大学，冯大改大同大学。委赵欣伯为满洲大学校长，谢介石为大同大学校长，已着手筹备。（22日专电）

  • 1932年4月23日《申报》：哈尔滨息，旧吉军再一面坡附近拆断路轨，故中东路东段之车务，完全停顿。闻昨日旧吉军与满洲国军在一面坡附近激战，旧吉军死百余名，伤多名，日当局已派大批援军驰往一面坡。（22日路透社电）

  • #抗战影像#日本管制下伪满洲国教育，学生正在接受日本相扑训练。

  • 1932年4月23日《申报》：北平息，日东北义勇军第19路驻九间房后，19日派便衣队伏打虎山，削断电线并破坏铁路六七段，在柳河沟附近，与日军激战一昼夜，日军损失甚重。（22日专电）

  • 1932年4月23日《申报》：美国飞行家肖特义士遗骸，公葬日期，经旌表委员会决定于明日举行，同时并开追悼会，市民联合会，昨通告全市，一律下半旗致哀，并参加执绋。

  • 1932年4月23日：国联调查团赴驻沈阳日本总领事署会见代理领事森岛守人，征询九一八事变前后东北情况。

1932年04月22日

发表于 2021-04-22 更新于 2021-08-26 分类于 局部抗战(1931-1937)

  • 1932年4月22日讯：红军攻克福建海澄、石码，23日克同安，25日克漳浦，27日克云霄，至月底，长汀等九县全被占领。

  • 1932年4月22日讯：逮捕向忠发的主办、上海警备部督察员王斌在沪法租界维尔蒙路被人开枪打死。

  • 1932年4月22日讯：何成濬由信阳抵汉口。何谈：在信阳与刘峙商定两事：一、由刘镇华派一师接防襄樊、光化；二、会剿鄂东“匪共”。

  • 1932年4月22日讯：伪满发表日人驹井德藏任伪国务院总务长官，坂谷喜一任财政部总务司长，大桥忠一任外交部总务司长，三谷清任奉天省警务厅长。

  • 1932年4月22日据《申报》讯：邮资加价办法业经邮政总局电令各省于5月1日实行，辽、吉、黑三省情形特殊，暂照旧例，俟东北失地收复后再行加价。22日，立法院讨论邮资加价案，以此案既未经中政会讨论，又未经本院审议，行政院实无权独自决定实行日期，决定推陈长衡起草质问书，送行政院转饬交通部立即停止执行。

  • 1932年4月22日讯：军事委员会开会讨论改进全国军队编制问题，拟定将全国军制实行划一，仍以师为单位，每师改为二旅四团，每连改为135人，全师暂定一万人。

  • 1932年4月22日《申报》：北平息，日军部拟在绥中榆关间，筹建伪国国防要塞炮台，已密派工兵及技术人员，勘测计划，并勒令各县，凡藏自卫枪|支者，悉数交出，否则以通匪论罪。（20日专电）

  • #抗战影像#侵占我东北的日本关东军铃木旅团司令部门前，照片居中者为旅团长铃木宗作，他参与了“九·一八事变”、全面侵华战争以及太平洋战争，1945年4月19日毙命于莱特岛附近的海面上。

  • #抗战英烈#辽中义勇军 曹广大、胡忠厚等烈士 1932年4月22日《申报》刊文：北平息，辽西铁血义勇军迭挫日军后，声言攻沈，日恐慌，4月2日，调军三千，与该军激战于沙岭台，日军毙四十余，伤数十名，义勇军仅伤一名。 辽阳辽中义勇军，希于日军侵沪时大举，不料汉奸勾通日军，调于芷山军四千，王殿甲军三千，公安警察三千，将义勇军包围猛攻。激战二日，毙敌六七十名，伤九十余，义勇军冲破重围，潜伏各村，死八伤二，被俘58名，尽为日军枪决。 中有首领曹广大、胡忠厚，于绑赴法场时，沿街大声演讲，谓此次日强占东北，请同胞速觉悟，我土地财产生命，尽屈日人，我们将永当亡国奴了，可恨抗日目的未达，深望同胞起来，逐帝国主义日本。讲毕，慷慨就义，市人均掩面痛哭，咒骂日本及汉奸。曹广大妻不忍偷生，更不愿为日人奴隶，于汉奸上门来抓前自尽身亡。刻该团领袖王全一，整军经武，誓为牺牲者报仇。（21日专电）配图为1931年冬天被俘的义勇军

  • 1932年4月22日《申报》：哈尔滨息，今晚接讯，距一面坡东二十里之苇沙河已为自卫军于鏖战后占据，满洲国军现向一面坡退走。（21日路透社电）

  • 1932年4月22日讯：美使詹森回沪，与英使蓝普森同邀郭泰祺交换续开上海停战会议意见。
