1932年02月28日

发表于 2021-02-28 更新于 2021-05-03 分类于 局部抗战(1931-1937)

  • #一二八淞沪抗战#1932年2月29日讯：日军主力完成集结和作战部署，总攻时间定在3月1日。海军分别在26日，28日轰炸了我吴淞和狮子林炮台以做准备。

  • 1932年2月：海外华侨汇款慰劳第十九路军抗日。菲律宾华侨救国会、国难后援会等汇款44.318万元。11日，檀香山国难救济会汇沪10万元。13日，孙科收到各地及海外华侨捐款10万元。20日，旧金山华侨募美金100万元。其他如缅甸、加拿大、越南、美洲等各地华侨均多次汇款到沪，总数达17.25万元。

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，上海守军吴淞要塞一处炮台遭日本海军舰炮轰击后被毁。

  • 1932年2月28日讯：上海各团体救国联合会召开上海抗日血战周月纪念大会，追悼抗日阵亡将士，并请第十九路军、第五军代表报告作战情形。大会分别电国民政府和国联。致国民政府电要求当轴诸公速与民众一致下决心，出实力，以增援沪战，并速令张学良提兵出关，收复失地。

  • 1932年2月28日《申报》：依兰息，马占山到沈会议时，日方以消灭苑崇谷旅为主要条件，苑旅抗日救国，颇得军心。马虽允日，决难实行。（27日专电）

  • 1932年2月28日讯：日机又袭击杭州。

  • #一二八空战#1932年2月29日下午1时，3架日军飞机进犯笕桥机场，先投弹3枚，随后飞至乔司备用机场投弹2枚，再至七堡投弹8枚。笕桥地面高炮部队发炮还击，击中日军第41号机。该机最终坠入萧山地区，飞行人员殒命。

  • 1932年2月28日讯：日援军第十四师团1.4万人到上海。

  • 1932年2月28日《申报》：哈尔滨息，大批日军已开抵此间，日军事当局现急欲沿中东路东段运兵，以攻该处屯集之旧吉军。闻该军人数共约二万名，中东路局俄员拒绝日本由该路运兵，但闻日当局无论该局准否，必欲运之。（27日路透电）

  • 1932年2月28日讯：蔡廷锴以沪商罢市御侮一月，影响贫民生计，是日特函上海市商会劝告开市。

  • 1932年2月28日《申报》：美国福特威资消息，著名美国女飞行家威廉士夫人愿携其夫服务于中国空军，以拒日军。（26日路透社电）

  • 1932年2月28日讯：冯玉祥函汪精卫辞内政部长职，略称：“际此国难紧急之时，诚恐以一身之微，负繁巨之位，设有贻误，个人之负咎犹其小事，其如国家何。”

  • 1932年2月28日《申报》：昨日，闸北方面日军，自晨至晚，全用大炮飞机，向天通庵路、中兴路、青云路、公兴路等处轰炸。掷弹结果，发生大火数处，竟日未熄。入晚7时起，天通庵路方面日军，利用少数兵士，不时向我军偷袭，均被我军用机关枪击退，敌飞机于下午4时许，被我军击遁，炮轰至下午6时许平息。

  • 1932年2月28日讯：英美法公使各奉本国政府命令调停上海战事，要求中日双方于3月3日国联召集大会讨论中日问题前停止战争。英使蓝普森到京，偕法使韦礼敦晤罗文幹、陈铭枢，商讨双方停战办法，希望中日双方撤兵。罗文幹答中国可接受，但须中日同时撤退；如日方欲保持最后通牒之条件，则绝对不能接受。

  • 1932年2月28日《申报》：敌军自向庙行江湾等处，总攻以来，集中火力，连战两日，屡战屡北，其主力军队，实已疲乏不堪。一面向其政府乞援，一面恃以飞机，扰我各地。及至昨日，该处已无剧烈战事。时有稀疏之枪炮声，聒人耳鼓而已。但其14师团已有六千余人，于昨日运到，今日尚有续到，大约敌俟援军到..

  • 1932年2月28日讯：中国外交代表顾维钧等应英海军司令凯来之请，与日海军司令野村及犬养首相私人代表松冈在英舰“康特号”上会晤，商定停战办法，要点为：双方同时撤兵；撤退区域由中国继续行使警察行政权；中国军队退真如，日本军队退公共租界及越界筑路地段，完竣后，中国军队退南翔， …

  • 1932年2月28日讯：天津中等以上学校学生抗日救国会决议：一、派代表组织请愿团赴平，请张学良出兵东北讨伐伪国；二、联络其他团体筹备组织各界救国联合会；三、电国民党中央下令出兵东北讨伐伪国。

  • 1932年2月28日讯：汪精卫电告陈济棠、李宗仁，已令财政部月拨粤、桂入赣“剿共”部队补助费50万元。

  • 1932年2月28日讯：上海各团体救国联合会等11个团体，为庆祝第十九路军抗日胜利周月纪念发出启事，定28日至3月5日举行庆祝第十九路军抗日胜利纪念周，并于3月5日召集全上海市民庆祝大会。

1932年02月29日

发表于 2021-02-28 更新于 2021-05-03 分类于 局部抗战(1931-1937)

  • 1932年2月29日讯：国联满洲事变调查团抵东京。

  • 1932年2月29日讯：北平协和医校救护队由队长万福思率领，赴沪参加救护工作。

  • 1932年2月29日讯：“全满建国促进运动联合大会”在沈阳召开，选出11名代表赴旅顺迎接溥仪就任伪职。

  • 1932年2月29日讯：上海市地方维持会电北方同胞，请勿售敌货以肥身家。

  • 1932年2月29日讯：何成濬电财政部，以鄂省中央协款积欠五个月，请先拨50万元济急。

  • 1932年2月29日讯：日驻沪总领事村井函市府声称：“3月2日以后，不得不企图将苏州、嘉兴、上海间供给贵国军队使用之铁道线路及军用列车破坏。”沪市府函复日领，表示“倘贵国军队仍复攻击，我军自不得不采取相当自卫办法，因此发生之一切责任，应由贵国负之”，并将此事函知各国领事， …

  • 1932年2月29日讯：沪公安局调查，全上海2月份人口，较“一二八”战前减少81万。

  • 1932年2月29日讯：第十九路军发表《告全国民众书》，称我国对日“应谋长期之拒抗，以待国际之变化，及敌国自身之崩溃。毋以目前军事之胜利，期侥幸之成功，毋惧战祸之延长，生苟安之妄念……日本一日不罢兵，外交一日不胜利，则我国一日不停止武力拒抗”。

  • 1932年2月29日讯：日军侵沪司令官三易其人，由陆军大将白川义则替代植田谦吉。是日白川偕厚东笃太郎之第十一师团先遣兵团抵沪。

  • 1932年2月29日讯：日军全线发动总攻，庙行、江湾方面由植田指挥，闸北方面由日海军陆战队司令植松指挥。八字桥、天通庵站、西宝兴路、虬江路各口，日军3000余频频冲锋，均被沈光汉第六十师击退。

  • 1932年2月29日晨，江湾红十字会第十五伤兵医院被日军纵火焚烧，综计该院房屋、器械、药品等损失，约二万余元。

  • 1932年2月29日《申报》：杭州息，日飞机3架28日晨7时飞笕桥，侦察半小时即飞去。（28日专电）

1932年02月27日

发表于 2021-02-27 更新于 2021-05-03 分类于 局部抗战(1931-1937)

  • 1932年2月27日讯：天津济安自来水厂工人，因要求改善待遇，全体罢工。28日，工人又将电线割断，水源断绝。

  • 1932年2月27日讯：国难会议添聘张元济等30人为会员。

  • 1932年2月27日讯：上海市绸缎印花业同业公会发表宣言，主张房租减半，以纾商困，并将应付租金作为军饷，援助抗日军。

  • 1932年2月27日讯：卫国阵亡将士遗族抚育会在沪召开筹备成立大会，推定朱庆澜等15人为临时执委。当场认捐基金万余元。

  • 1932年2月27日讯：孙科、陈友仁电林森并转国民党中央，说明未出席二中全会原因，称：“适值淞沪抗日战事紧张之际，科等正从事于国际宣传，留沪接洽，较为便利而有益，故全会开会，恕未克出席。”

  • 上海市普陀区真南路的由来：真南路的修建，与十九路军总指挥部的地理位置有着密切关系。当时十九路军临时军部设于真如镇，前线总指挥部则在南翔镇。之后，张治中率领第五军抵达南翔镇，可见南翔具有重要的军事地位。因此，保证两地之间的交通顺畅，就有了十分重要的战略意义。在战前中国方面就开始……

  • 1932年2月27日《申报》：苏州息，26日晨9时，敌机一侦察车站，下午4时，又5架在昆山掷弹，继来苏，掷弹五枚爆炸，死一人、伤一人，我炮击未中。（26日专电）

  • 1932年2月27日讯：驻沪国民党中委再电张学良促迅下决心，即率全军，直趋东省，“执事补过图功，全在此举”。

  • 1932年2月27日《申报》：吴淞要塞方面，敌舰于前日曾有数次，向我开炮攻击，昨日上午，敌舰10余艘，均停泊三夹水外，并未开炮，惟至下午涨潮时，有3舰向我轮流开炮，潮落时，即行停止。蕰藻浜方面之侯家木桥纪家桥一带，敌军于昨日上午，向我阵地进攻，同时并有敌机6架掷弹助战，我军固守无变动。

  • 1932年2月27日讯：上海南市救火会汽车司机胡阿毛，被日兵强迫开车运送军火，由日兵押解。驶至黄浦江边时，胡激于爱国热忱，开足马力，将车开入江中，壮烈牺牲。

  • 1932年2月27日讯：税警团旅长王赓擅自离队，未报得第十九路总指挥及蔡军长许可，即赴上海法租界，旋又乘便往美国领事馆访友，行经礼查饭店附近，被日本警察拘捕，后经美国领事馆具保释放。此前，王赓参与十九路军作战会议，对十九路军布防情况颇多了解。

  • #抗战影像# 1932年“一·二八淞沪抗战”期间遭到日机轰炸后的上海虹桥机场，可见其间弹痕累累。

  • 1932年2月27日《申报》：闸北天通庵八字桥一带，日来战事，较为沉寂，前夜吾方集中炮火，向敌猛攻，敌军凭壕顽抗，双方激战甚烈。至昨日拂晓，敌始不支而退，我军除将前哨线移进外，并不穷追，至下午5时，敌又反攻，但人数不多，仅用大炮轰射，我方亦以重炮还击，双方激战约一小时，敌因进攻失利，…

  • 1932年2月27日讯：日混成第二十四旅团补充兵员407人到达上海。次日又有第九师团补充兵员518人到上海。

  • 1932年2月27日《申报》：昨日庙行及江湾方面，双方无甚重大接触，仅有大炮互轰，我军所发炮弹，多中敌军后方。敌方则仍用巨额大炮，惟庙行前里许一带田地，经敌军两日夜炮击后，已无一片净土。炮弹所炸窟洞，恰似蜂巢。我军阵线仍完整无变动，江湾我军前线，在距跑马厅二百码处，江湾车站及江湾镇，…

  • 1932年2月27日讯：沪战全线沉寂，敌机不时飞昆山、苏州一带侦察。前线我军伤亡日多，援军上官云相第四十七师只调两营到黄渡作工事。第十九路军因后援无望，是日有退守罗店、刘家行、大场、真如、龙华一线之议，但由于官兵愤激，誓与阵地共存亡，最后决定仍在原线固守，以待中央来援。

  • 1932年2月27日《申报》：昨日静安寺路126号大沪跳舞厅，将全日营业收入之欵大洋514元，小账大洋10元零4角，小洋24角及该厅衣帽间大洋3元5角，小洋60角，如数送至上海银行公会转交前线，慰劳抗日将士，为各舞厅之首倡。

1932年02月26日

发表于 2021-02-26 更新于 2021-05-03 分类于 局部抗战(1931-1937)

  • 1932年2月26日讯：鄂“绥靖”公署指定“剿匪”五区指挥官：何成濬任总指挥兼鄂南区指挥官，夏斗寅为鄂东区指挥官，袁彬为鄂西区指挥官，徐源泉为鄂中区指挥官，范石生为鄂北区指挥官。总预备队为第四十四师朱怀冰，相机协“剿”。

  • 1932年2月26日讯：国民党天津市党部发出通电，声讨张景惠在东北组织伪国。

  • 1932年2月26日讯：宋子文在沪与银行界商妥，减轻公债利息，延期还本，将每月内债所还本息1800万元减为每月拨还880万元，余900万元发行救国公债。

  • 1932年2月26日讯：汪精卫、何应钦电第十九路军将领蒋光鼐、蔡廷锴、戴戟及第五军军长张治中等，要求“查明所有阵亡将士姓名、等级，造册具报，当照章从优议恤，以彰忠烈”。

  • 1932年2月26日讯：英、美、法、意四国驻日大使分别通知日外相芳泽，要求如日军增援赴沪，不得在租界登陆，“否则华军炮轰码头，势将危及租界”。

  • 1932年2月26日《申报》：东京讯，白川大将今日就新职之前，曾觐见日皇，白川所就何职，东京秘不公布，大约乃上海日军总司令职。盖该地日军不久将有一师团之多也，白川为最高军事参议之一，曾参加日俄战争，1911年在西伯利亚统带第11师团，1925-1927年统带关东军，1927-1929年曾任陆相（25日路透社电）

  • 1932年2月26日《申报》：驻沪日本总领事村井仓松，鉴于领署左近，时有流弹落下，为避免危险起见，昨已将领署所有重要文卷书册，运送兵舰，并将重要部分及办公人员移往兵舰办公。

  • 1932年2月26日《申报》：今晨二时消息，日援军昨日下午开到后，即全部加入江湾方面前线作战，昨日下午6时，敌同江湾庙行等处取猛烈攻势，以坦克车数十辆掩护冲锋，并以重炮猛轰我阵地。我军俟其冲近，即与之肉搏应战。未几，我军佯败，诱敌至江湾镇与庙行镇间之小场庙地方，我军即采取大包围形势。…

  • 1932年2月26日讯：下午2时许，日舰炮轰浙江平湖乍浦口岸，陆战队图登岸未逞。

  • 1932年2月26日讯：十九路军函电请援，军政部通令各部：“第十九路军有三师十六团，无须援兵，尽可支持，各军将士非得军政部命令而自由行动者，虽意出爱国，亦须受抗命处分。”当时驻苏州的上官云相师，驻浙江的戴岳旅，驻江北的梁冠英部均按兵不动。

  • 1932年2月26日讯：李济深、陈公博奉命抵平请张学良赴洛出席国民党四届二中全会。

  • #一二八空战#1932年2月26日下午，日本海军又派出舰攻机6架、战斗机6架编队前往轰炸乔司机场。驻扎乔司机场的中国空军飞机接到黄秉衡署长命令，已经分别飞往南京与蚌埠，未遭到损失。
