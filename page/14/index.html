1932年06月06日

发表于 2021-06-06 更新于 2021-08-11 分类于 局部抗战(1931-1937)

  • 1932年6月6日讯：蒋介石、汪精卫及其他政府要员在南京会商，决计分别复电慰留宋子文、陈铭枢，劝“以国家大局为重，继续负责维持”。7日晚，汪精卫、顾孟馀、邵元冲、叶楚伧、黄绍竑、褚民谊等，赴沪挽留宋子文、陈铭枢。

  • 1932年6月6日讯：南京中央大学全体教授因索教费无着，全体罢教。

  • 1932年6月6日讯：中国征信所在上海创立，由上海各大银行共同创办，以收集调查各工商企业生产经营情况，为金融界放款提供信息。

  • 1932年6月6日讯：苏、沪、锡各团体代表到京请愿挽留第十九路军，褚民谊和陈仪分别代表行政院和军政部予以接见，均表示该军开闽“剿匪”，系整个军事计划，似难变更。

  • 1932年6月6日讯：汉口商会决议赞成沪废止内战大同盟，11日电沪全国商联会等响应，并主张各军、师长以至诚发表消灭内战意见，请中央彻底革新政治。

  • 1932年6月6日讯：鄂省清乡会以5日宋子文否决提取盐税为“剿匪”军费，本日呈财政部声称决自即日起直接提用盐税，否则即援赣例，请中央直接发放，或援湘、豫例，增加盐税附加。

  • 1932年6月6日讯：蒋介石在南京中央军校讲演《中国的立国精神》。

  • 1932年6月6日《申报》：北平息，上月30日，日军赴八百坡孟家窝一带，31日赴祖家罗屯一带，勒缴民枪，为保护日韩人圈夺民田产，刻各地村庄，联合抵御。（5日专电）

  • 1932年6月6日《申报》：北平息，盘山县公安局长张恒任，被日军枪 杀，于芷山一部缴械。（5日专电）

  • #抗战影像#日式装备的伪满洲国陆军部队。

  • 1932年6月6日《申报》：哈尔滨息，海伦数日前为日军占据，今反满军或反正之满洲国军之助，取道青冈。日军飞机屡次猛轰无效，昨日该军且进攻安达、青冈间横街（译音）之日防兵，后因日援军驰至，乃止攻。（5日路透社电）

  • 1932年6月6日《申报》：蚌埠息，军政部航空署军医科长陆心九、军务科员袁立人，5日由京抵蚌，调查飞机遗落炸弹案肇祸原因、死亡人数，以便赔偿抚恤。商会委员项允臣、孙元甫要求以后飞机携带危险物，不准飞行市空，对被炸死及受伤者从重抚恤，肇事分队长赵敬贤，经航空第一队长担保，由警备司令部开释。（5日专电）

  • 1932年6月6日讯：国民党中央政治会议讨论对苏复交问题，决定第一步缔结互不侵犯条约，第二步复交。

1932年06月05日

发表于 2021-06-05 更新于 2021-08-11 分类于 局部抗战(1931-1937)

  • 1932年6月5日讯：经学家廖平在四川井研县病逝。

  • 1932年6月5日讯：国联调查团晚9时由东北回到北平，张学良、于学忠等前往车站迎接。李顿对记者发表书面谈话，声称：“调查团第二步工作，即望利用中国政府与日本政府有一种诚意，用此种诚意来谋一种解决方法。”

  • 1932年6月5日讯：宋子文电何成濬，表示鄂省“剿匪”经费将“提前支给”。

  • 1932年6月5日讯：吉林自卫军冯占海部攻入阿城。

  • 1932年6月5日讯：何应钦电令何键断绝赣西苏区交通，禁止运米、盐、银钱，禁止邮电。

  • 1932年6月5日《申报》：哈尔滨息，二日阿城南白城子五间房有激战，旧吉军与日军混战甚烈，日机数架午刻飞往投弹。旧吉军约三千人，在死抗中。二日早，驻哈日军中村部队开往阿城援应。驻一面坡村井旅团，亦派大队驰往夹击。二日午后2时20分，自哈开河什河兵车三列，载日军骑兵大队前往剿击。二日午后5时，此地闻讯，旧吉军已向双城拉林仓方面退却，日军正在进击中。（4日专电）

  • 1932年6月5日讯：中共临时中央发出《致各苏区的军事训令》，通报国民党第四次“围剿”之兵力部署，指令各地红军反围剿任务。

  • 1932年6月5日讯：陈铭枢电国民政府、行政院和军委会，请辞交通部长及军委会委员职。

  • #抗战影像#侵占我东北之日本制作的宣扬伪满洲国满族与日本百姓友善相处的宣传画。

  • 1932年6月5日《申报》：哈尔滨息，二日晨，呼海路日军开始总攻击，空军（原文如此，应为陆军航空队）掷弹，黑军不支，向通北退却。日军二日晚渡泥河，夜间有入海伦说。（4日专电）

  • 1932年6月5日《申报》：东京讯，外务省照会李顿调查团，谓日本愿欢迎调查团中国陪员顾维钧博士之莅日，惟须声明赴日非为调查，外务省言调查团乃受命仅调查满洲与中国之情形云。（4日路透社电）

  • 1932年6月5日讯：冯占海部在宾县召开军事会议，部队改称吉林抗日救国军，冯占海任总指挥，宫长海任副总指挥兼前敌总指挥，李文光任参谋长。

  • 1932年6月5日《申报》：哈尔滨息，二日阿城南白城子五间房有激战，旧吉军与日军混战甚烈，日机数架午刻飞往投弹。旧吉军约三千人，在死抗中。二日早，驻哈日军中村部队开往阿城援应。驻一面坡村井旅团，亦派大队驰往夹击。二日午后2时20分，自哈开河什河兵车三列，载日军骑兵大队前往剿击。二日午后5时，此地闻讯，旧吉军已向双城拉林仓方面退却，日军正在进击中。（4日专电）

1932年06月04日

发表于 2021-06-04 更新于 2021-08-11 分类于 局部抗战(1931-1937)

  • 1932年6月4日讯：总税务司梅乐和训令东北各关税务司，谓关款关系内外债基金甚巨，各税务司应遵照关税行政完整原则，严拒其他方面提拨税款或扰乱税务独立行政与事权独立。

  • 1932年6月4日讯：航空署增派航空第五队赴汉，第七队赴赣，“协剿”红军。

  • 1932年6月4日讯：军委会统一各师编制，军为军政部直辖单位，军长不兼师长，全国共48个军，96个师。

  • 1932年6月4日讯：国民政府令：派黄乃枢为邮政总局局长，派杨建平为邮政储金汇业总局局长。

  • 1932年6月4日讯：财政部长宋子文电汪精卫、蒋介石辞财政部长职。5日，汪复电慰留。

  • 1932年6月4日讯：在中共磐石中心县委和省委特派员杨 林的主持下，一支对外号称“满洲工农反日义勇军第一军第4纵队”，对内称为“磐石工农反日义勇军”的抗日队伍正式成立。队伍下设3个小分队，共30余人。中心县委组织部部长张振国任总队长。

  • 1932年6月4日《申报》：齐齐哈尔息，顷接急电，马占山系之邵平山，率部下千余，包围道达（译音）县城，日平山旅团与飞机队，昨午后向该方面出动，以飞机开始炸击马部。（3日电通社电）

  • #抗战影像#伪满洲国陆军辎重部队，使用马匹驮运装备。

  • 1932年6月4日《申报》：北平息，伪国编国防军16团，班长以上军官，由日人充任。（2日专电）

  • 1932年6月4日《申报》：蚌埠息，驻蚌航空第一队102号达格拉斯机，3日晨飞往光山轰炸“共匪”。9时许回蚌，机上所余35磅炸弹一枚脱系，落于繁闹之太平街上，炸死市民22人，伤41人。各界大愤，警备司令部将肇祸分队长赵敬贤看管，伤者送医院，死者招尸亲属认领。（3日专电）

  • 1932年6月4日讯：中日停战共同委员会讨论日军完全撤退问题，日方委员冈崎表示，沙泾港驻日军仅事巡逻护侨；吴淞纱厂、同文书院、丰田纱厂仅各驻少数宪兵，且战前亦有陆战队驻入。中方委员俞鸿钧驳斥，指出市政府自可负责护侨，毋须由日军越俎代谋；未闻同文书院等处以前有陆战队驻入。声明日军之驻各地不撤，有违协定，遂无结果而散。

  • 1932年6月3日讯：驻蚌航空队飞机自光山轰炸红军后返回，在蚌落下炸弹一枚，炸死市民22人，伤41人。

  • 1932年6月3日讯：济南市商会议决，通电响应沪废止内战大同盟主张。

  • 1932年6月3日讯：日本首相斋藤发表对伪满新政策。对伪满洲国决先承认独立；日本对满依然遵守门户开放、机会均等之原则；并谓如不获谅解，不惜退出国联。

  • 1932年6月3日讯：日平贺旅团占海伦，马占山部向通北方向撤退。
