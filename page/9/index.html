1932年12月03日

发表于 2021-12-03 更新于 2022-01-12 分类于 局部抗战(1931-1937)

  • 1932年12月3日讯：据《大公报》讯：日伪在东北实行“五家连坐法”、“良民证”制度，并在铁路沿线设瞭望台，窥视义勇军行动。

  • 1932年12月3日讯：陈诚部周至柔第十四师陷江西金溪。红军向大、小竹枫林、资溪转移，主力仍在硝石、黎川及南丰间。

  • 1932年12月3日讯：朱绍良在鄂绥署召开鄂南“清剿”会议，决定“剿匪”新方案。9日，湘鄂赣边区“剿匪”总指挥部在咸宁成立，以朱为总指挥。10日，朱赴鄂南“督剿”红军。

  • 1932年12月3日讯：华侨委员会通过《侨民教育实施纲要》。

  • 1932年12月3日讯：蒋介石电日内瓦颜惠庆等三代表，郑重声明否认中日直接交涉，称“中正绝未主张直接交涉”，深信国联必能“为中日问题谋公平适当之解决”。

  • 1932年12月3日讯：外交委员会在京开会，讨论应付国联大会步骤，并训令日内瓦中国代表团据以进行。

  • 1932年12月3日《申报》：北平息，何柱国连日赴各地检阅军队，日军无特殊动作，各外报记者已抵榆关。（2日专电）

  • 1932年12月3日《申报》：北平息，黑省西路战事，于卅日晨开始接触，苏炳文部最前头部队张殿九、张玉挺两旅，在腰库勒与日军平贺旅团部队开火，双方激战甚烈。昨晨平接到海拉尔来电报告，前方战事自31日迄1日晚未止。苏炳文亲赴前方督师，马占山部队近由讷河移到西路，马已到兴安岭，将与苏炳文联络抵抗日军。（2日专电）

  • #抗战影像#一队身着昭五式军服的日本陆军士兵正在野外用军用饭盒加热食物。

  • 1932年12月3日《申报》：北平息，某方接札蓝屯电谓，日军开始总攻击后，以大军向札蓝屯压迫。因天气酷寒，日军动作迟缓，迭遭不利，连日正在激战中。上月29日日军茂田部队与我张玉挺旅，在腰库勒一带激战。日军死亡遍野，我军亦有不小伤亡。日机四架，向碾子山轰炸，被我军击落一架，飞机被焚，驾驶员跌毙。（2日专电）

  • 1932年12月3日《申报》：东京讯，东京高等女子学校校长会议中，决议将东京市官办民办女学生三万五千人武装起来，由军部派退伍军官加以严格之军事训练。闻陆军省甚赞同此举，已允拨步枪35000枝，及手 枪、防毒面具与各种卫生材料，从明春起开始训练。日本妇女已被迫抛弃针线生活，而从事于黩武主义之所日夜梦想之侵略战争云。（华联社3日电）

  • 1932年12月3日讯：顾维钧致函国联驳复日代表松冈洋右11月21日在国联行政院会议上的演说和日对李顿调查团报告书之意见书，略称：日方之意见书与言论，无一处可变更李顿调查团所证实满洲时局中之最重要事实及调查团依此事而得之结论。九一八事变乃日本大陆政策所促成，东三省现状之维持与承认，中国绝不能接受，“满洲国”必须解散，损失必须赔偿，日军之撤退必须尽早实行，中国问题之解决，应不违背《国联盟约》、《非战公约》及《九国公约》。

1932年12月02日

发表于 2021-12-02 更新于 2022-01-12 分类于 局部抗战(1931-1937)

  • 1932年12月2日讯：实业部发表10月份各海关调查报告，内称各国对华贸易，以前以美国第一，英国第二，日本第三；最近则以日货独旺，已居英、美之上，尤以棉纱、布匹为大宗。

  • 1932年12月2日讯：河北唐山粮食街余祥号经理刘国昌因贩卖仇货，被锄奸团掷炸弹炸伤。

  • 1932年12月2日讯：蒋介石增派卫立煌部两个师入赣“剿匪”。

  • 1932年12月2日《申报》：北平息，苏炳文前拘留之日侨妇孺300余人，已释放回国，现有二百余人，拘于海拉尔。上月松木师团抵龙江后，派飞机5架飞海拉尔，准备轰炸。苏炳文命部下将日侨推出，缚至军部附近各地，日机途中得讯，到海拉尔后，因见日侨中有日领事武官多人，未投弹飞回，近日日机只轰炸接近前线各车站。（1日专电）

  • 1932年12月2日《申报》：北平息，沈阳讯，日军近派华人及日人多名，皆着华服四处侦查。义勇军工作人员，连日被捕甚多，捕后即交奉天日宪兵队部，严刑毒打，并以煤油及冷水灌鼻，强迫招认后，活埋于该队部东侧院内。本年内被埋者已达三百余人，埋后上灌石灰酸水，以灭痕迹。有张铭信者辽宁一工高中毕业，不肯下坑，日宪兵以刀砍落其肩，推于坑内，其状至惨，张母因子惨死疯狂。（1日专电）

  • #抗战影像#一队关东军在雪地中利用伪装斗篷匍匐前进。

  • 1932年12月2日《申报》：华东社云，据东北国民救国军指挥总监部驻沪通讯处发表，东北国民救国军第一路第二支队长张子安，在辽西六十三屯作战殉国，详情如后。第二支队原驻黑山县城，于11月14日，在小白旗堡作战，以乏援退原防。19日在义利窝堡与敌交战数小时，缴获机关枪一架。23日在黑山与敌遇，张子安及营长张雨田、连长孙连生，当即率部迎敌。敌以重炮，我以刀枪；敌以物质，我以精神，冲锋肉搏，杀敌数十名，卒以寡不敌众，被围于六十三屯，以一千之孤军，对三千之敌众。激战两昼夜，阵亡七十余名，损失机枪两架，步枪三十余枝，而敌方亦毙命日兵24名，伪警16名。张子安、孙连生两人，负伤后犹奋不顾身，裹伤再战，争先指挥杀敌，卒遭炮火击中，壮烈殉国。残部现已退还原防，并由袁玉衡代理支队长，方从事整理，准备再战。按张子安为辽宁新民县人，曾在东北军警各界服务，忠实努力，“九·一八”以后，即从事抗日工作，任东北国民救国军第一路金子明部之第二支队长，屡立奇功。现年仅24岁，家有60岁之老母，弱妻幼子，身后极为萧条。

  • 1932年12月2日《申报》：北平息，苏炳文29日电称，士气甚壮，日飞机队近沿铁路线轰炸，死伤无辜居民，已电日内瓦宣布，揭穿日军之暴行。（1日专电）

  • 1932年12月2日讯：第二十五军军长王家烈率部自贵阳退守黔西，待何知重援军到后再战，该军副军长犹国才率第二师于上月25日进驻贵阳，欢迎毛光翔回省主持一切。是日，毛光翔电京，攻击王家烈祸省殃民，为保犹国才继长黔政。

1932年12月01日

发表于 2021-12-01 更新于 2022-01-12 分类于 局部抗战(1931-1937)

  • 1932年12月1日讯：天津电气工人罢工斗争结束，市府允代公司发给工人罢工期间工资。

  • 1932年12月1日讯：韩复榘严令济南罢课各学校限2日一律复课，违者解散，另招新生；如再发现标语，公安分局长须监禁三年；捕获贴标语者，赏洋200元。2日，济南罢课各校除高中外均复课。

  • 1932年12月1日讯：东北民众救国军李杜部张殿九旅与日军在碾子山激战后退扎兰屯，日军占碾子山。3日，日军又占扎兰屯，李杜率部自海拉尔退满洲里。

  • 1932年12月1日讯：翁文灏因母丧电国民政府恳辞教育部长职。

  • 1932年12月1日讯：蒋介石制定派员查禁十省种烟办法九条，分电苏、浙、皖、鄂、湘、豫、赣、闽、陕、甘十省主席遵行，规定以上各省先行禁种，如有包庇或玩忽者严办。7日，再电十省，严令禁烟。

  • 1932年12月1日讯：陈诚由南昌赴临川，就抚河“剿匪”总指挥职。

  • 1932年12月1日讯：刘湘联军在隆昌会议决定分三路逼成都：杨森、李家钰部取道资阳，王缵绪师取道仁寿，唐式遵、潘文华两师取道乐山。是日，前锋过简阳西进。

  • 1932年12月1日讯：国民党中常会通过中外影片标准。国产影片应鼓励其制造者之标准为“阐扬总理的遗教及本党主义、政纲政策者”等17项；所需外国影片之标准为“不违背本党主义而有利于本党宣传者”等12项。

  • 1932年12月1日讯：国民党中央党部、国民政府自洛阳迁回南京，是日分别举行回京典礼。国民政府主席林森抵南京。

  • 1932年12月1日《申报》：北平息，辽南台安向为义勇军活动中心，县城西北角有清真寺，曾被日军炮毁。日军利用该地，改建飞机场，四周建筑兵营。近已开始运料，堆积如山，日军并将该县城四周树木伐倒，预备架设电网。飞机场占地1800亩，界内居民均被逐出，张某因抗命被枪 杀。日方拟明春由沈修筑铁路，直达台安。（30日专电）

  • 1932年12月1日《申报》：齐齐哈尔息，日军侦察机两架，由浜田大尉及片冈军曹驾驶，28日上午10时，由哈尔滨来齐齐哈尔途中，上午11时在安达附近断绝消息。日军大行搜查之结果，发现两架飞机降落与安达车站之前后两处。浜田大尉即被救，昨晚乘车抵齐齐哈尔，然片冈及通讯员田中所乘之飞机破毁，两人下落不明。（30日日联社电）

  • #抗战影像#日本美化侵略中国的宣称画，描写中国儿童写下欢迎日军的标语。

  • 1932年12月1日《申报》：北平息，盘山县警察局伪警28名，日前被日军逮捕，用铁丝穿两腕，在商平镇用机枪击毙纵火焚尸。倭军主持之东五民族同盟会，联络员裴东阁，在盘山收降土匪280人。日军伪称检阅该部诱至城外河南沙滩上开机枪扫射，伪军大部被击毙，逃者无几。（30日专电）

  • 1932年12月1日《申报》：北平息，苏炳文28日电平，今午日方轰炸机6架，飞至扎兰屯西巴里木车站，投掷重磅炸弹数十枚，车站及护路军营舍被炸，并伤亡东铁职工居民数名。该站电线亦被炸毁数段，现正修理，须两日方能通车。（30日专电）

  • 1932年12月1日讯：南满游击队在郭家店枪决了民愤极大的反 动地主、土匪头子于宽，缴获长短枪20余支，游击队声威大震。其后再到石虎沟整顿，提高全队指战员的思想素质。整顿后，杨靖宇即离磐石去海龙巡视工作，去组建“中国工农红军第37军海龙游击队”。

  • 1932年12月1日讯：巴拿马国会通过禁止华侨移民入境法案。

  • 1932年12月1日讯：国联十九国特别委员会决定6日召集国联大会特别会议，中日问题移交大会。颜惠庆申请速定解决中日问题期限案被否决。

  • 1932年11月30日《申报》：北平息，辽吉黑民众后援会军息，据开鲁第四军团刘总指挥报称，22日派沈副旅长明盛，带队绕攻五松嘎瞎，及杜其营子等寨，已完全占领，获日枪马及俘虏甚多。潘团长及郑支队长，与敌苦战九小时，敌不支向唐家窑得拉苏营子一带溃逃，尽力追击，已不成军。击毙伪团长一员，连长三员，日兵30余名，从逆蒙兵150余名，获枪马无算，我军伤亡20余名。（29日专电）

  • 1932年11月30日《申报》：北平息，辽东来人谈，救国军唐聚五战略关系，率部退守濛江，再图进展。其副司令张宗周及第一旅长高百翔两部实力犹存，士兵在八千名以上，秘密联络各方，准备反攻，规复辽东失地。前传高百翔阵亡不确，高仍在金川计划指挥，凤城一带，为义勇军邓铁梅部占据，声势浩大，日方极注目。（29日专电）

  • 1932年11月30日讯：苏文炳用专车将谢珂、金奎壁两参谋长及总部官兵撤退至博克图，决定率残部2000余人撤回海拉尔，并安排一列装石列车做断后处置。
