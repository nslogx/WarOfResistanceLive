1932年03月16日

发表于 2021-03-16 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年3月16日讯：北平民众团体救国联合会成立。

  • 1932年3月16日讯：广东第一集团军余汉谋等以全体将士名义通电讨共，声称“非抗日无以救亡，非剿共无以抗日”。

  • 1932年3月16日讯：重庆各界122个团体，向第二十一军军部请愿，请刘湘出兵救国。

  • 1932年3月16日讯：北平大学教授抗日会电促各省军事长官积极抗日，万勿妥协。

  • 1932年3月16日讯：日机第五次飞杭州侦察。

  • 1932年3月16日讯：日舰载第十四师团工兵及军械到沪，次日又有师团直属部队到沪。

  • 1932年3月16日讯：李顿调查团委员分访英、美、法、意、德五国在沪公使、代办及海军司令，咨询上海事变之事实，并在旅寓华懋饭店接见各国领事搜集调查材料。

  • 1932年3月16日《申报》：哈尔滨息，东铁监事张恕，吉长官署参议李桂林，奉熙洽命，以友人关系，再赴珠河晤丁超、李杜，定14日前往，丁李来电允一见熙洽。（14日专电）

  • 1932年3月16日《申报》：北平息，外讯，伪满叛党决采金本位制，并着手编制大同二年度预岁出，总额概算为一亿二千万元，拟发公债与大借欵。（15日专电）

  • #抗战影像# “伪装的亲善“——1932年“一·二八淞沪抗战”期间，日本为了掩盖和美化侵略，拍摄的日本陆军士兵与中国儿童在一起的照片。

  • 1932年3月16日《申报》：东京讯，满洲国成立后，曾发表请求各国承认之通电，东京正在观察国际间之反响，对于苏俄态度尤为注意，长春方面蓄意将前南京所委派之中东路华董撤职，另行改委，故众料苏俄于此，即可表现态度。（15日路透电）

  • 1932年3月16日《申报》：北平息，榆关电，关外义勇军连日极活跃，大举破坏伪丰山路，连山附近铁路已被拆毁数段，14日辽宁至榆关火车不通。（15日专电）

  • 1932年3月16日讯：国民政府特任蒋中正兼参谋本部参谋总长，原任朱培德辞职照准；特任朱培德为军事委员会办公厅主任；任命吴奇伟为陆军第九十师师长。

1932年03月15日

发表于 2021-03-15 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年3月15日讯：3月11日天津《大公报》之《军事周刊》第七期因载《枯树又萌芽》讽刺画，讽刺日本发动侵略战争，日领向天津市府抗议，是日市府将该刊查禁。

  • 1932年3月15日讯：广州公安局军械库被人掷弹炸毁。

  • 1932年3月15日讯：伪满洲国决定将长春改为“新京”。

  • 1932年3月15日讯：山东省政府主席兼第三路总指挥韩复榘电国民政府、行政院请辞本兼各职，推荐省府委员兼民政厅长李树春继任主席，师长孙桐萱、曹福林择一任总指挥。

  • 1932年3月15日讯：上海律师吴迈前曾赴上海公安局要求保释中学生联合会学生，与该局发生冲突，竟被扣押，是日被解送南京卫戍司令部。16日，上海各界人民团体纷纷开会，通电要求释放吴迈。

  • 1932年3月15日讯：粤政务会议议决发行国防公债3000万元，作要塞设备用。

  • 1932年3月15日讯：汪精卫、朱培德、陈铭枢、李济深、王柏龄等赴昆山前线劳军。

  • 1932年3月15日讯：吴佩孚通电全国国民，申述救国大计，主张“动员全国之兵，以谋抵御，从速化除一切党派意见，与全国人才共图建设”。

  • 1932年3月15日讯：据《大公报》讯：日方在前线实力分配：正式陆战队5000人，由近卫师团改编之陆战队1.5万人，第十二师团1.5万人，第九师团战时编制2.5万人，第十一师团、第十四师团战时编制四万人，飞机200架，轻重炮350门。

  • 1932年3月15日讯：日机飞苏州、昆山侦察并扫射。

  • 1932年3月15日《申报》：哈尔滨息，黑河驻防黑军队第3旅，11日早树自卫军旗，反马占山。据黑河沿边六县抗马，丁超率大部队退密山宝清屯驻，待机就地筹饷抗熙洽。日第二师团拟调大队开宝清击丁超军，敦化战事12日晚停，王德林率救国军退往蛟河。（14日专电）

  • 1932年3月15日《申报》：北平息，外讯，伪国交通政策，决遵守中日间缔结之修筑满蒙五铁路条约，完成汽车站，统辖邮电各机关，并编订教科书，删除爱国材料，通令各校以日语为必修科。伪外长通电日英美等38国，要求承认，并向日政府要求开始外交关系。（14日专电）

  • 1932年3月15日《申报》：东京讯，参谋部副大臣，今晨觐见日皇，众信系请日皇核准撤回上海金泽师团与一混成旅团事，撤回此项军队之命令，明日可望发表。（14日路透电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，几名日本海军陆战队员用担架抬着一名受伤的同伴。

  • 1932年3月15日《申报》：国联调查团，昨已抵沪，在此间约有一星期之勾留，并将往闸北、吴淞、江湾等战区视察。闻日本军事当局，希图掩饰团员耳目起见，已于最近两日中，命闸北等处之驻军暂为隐藏撤退，并利用汉奸，在各处要隘屋顶，悬挂中华国旗，以示无占领我土地之野心。又将北区及虹口一带与华…

  • 1932年3月15日《申报》：国联辽案调查团，昨已由日抵沪，上海日军，近虽宣称和平，而援兵仍继续开来，惟为掩人耳目，不使扩大战区痕迹，为委员团所知，赶将已到吴淞口外陆军，乘委员团未到之先，运到上海，一面又将浦江大队日舰，暂时开往他处。

  • 1932年3月15日讯：国联调查团访宋子文、顾维钧、吴铁城，顾开茶会招待，吴设晚宴。李顿招待中外记者，表示调查团对上海之停战十分关心，如果列强同意，准备参加和议谈判。

1932年03月14日

发表于 2021-03-14 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年3月14日讯：天津市商民救国会成立。

  • 1932年3月14日讯：国民党中央政治会议准朱培德辞参谋总长职，遗缺由蒋介石兼，3月18日蒋就任。

  • 1932年3月14日讯：国民政府派蒋光鼐为中日上海停战会议军事代表。

  • 1932年3月14日讯：英、美、法、意四国参赞代表四国驻华公使赴闸北、江湾、大场、浏河等日占领区域视察。

  • 1932年3月14日讯：晚，国联调查团包括英、美、法、意、德五国委员及随员专家等一行，由李顿率领自日本乘轮到沪，顾维钧、吴铁城、郭泰祺等往迎。

  • 1932年3月14日讯：日上海派遣军司令官白川鉴于上海形势逐渐平静，是日下令第十一师团、混成第二十四旅团回国。19、21日，混成第二十四旅团分两批离沪。第十一师团亦正集中待运中。

  • 1932年3月14日《申报》：哈尔滨息，丁超率自卫军2千人，11日夜进占哈绥线高岭子，向一面坡开进。今日哈日领访东铁当局，续请拨车运兵，往击自卫军。郭恩霖携进击自卫军计划，今来哈召集于琛澂、李文炳、刘实麟会议。（12日专电）

  • 1932年3月14日《申报》：哈尔滨息，马占山发表公报称，忠于新政府之军队已击败大黑河变兵。变兵逃往爱珲，大黑河之日侨，除工人被杀外，余皆无恙。马占山为恢复治安计，已由海伦派骑兵赴大黑河，并有步兵一支队，分乘二十卡车前往。（13日路透电）

  • 1932年3月14日《申报》：哈尔滨息，江省军民联络反马救国团，声势甚大，黑河齐齐哈尔兵变，攻击马占山。各地驻军，多已反正，现马占山被日人监视，逼令下命缴各旅械，全军反抗，将有重大变化。（13日专电）

  • 1932年3月14日讯：中日停战第一次非正式会议在驻沪英领署举行，外交部次长郭泰祺、日使重光葵及英、美、法、意四国公使出席。日方提议设中立区，由中国警察在外人指挥之下警卫地方治安；并涉及1月28日吴铁城对日领复文所允四项要求。我方以越出国联大会决议案之精神，拒绝讨论。后经 …

1932年03月13日

发表于 2021-03-13 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年3月13日讯：东北义勇军晚11时占领大虎山。

  • 1932年3月13日讯：北平各大学教授抗日救国会成立，通过简章，选出邱昌渭等11人为理事。

  • 1932年3月13日讯：中国电影家协会在上海成立。

  • 1932年3月13日讯：国民党中执会电复留沪中委江（3日）电，谓收复东北，应由国府迅筹办法，以实力恢复中华民国领土主权之完整。

  • 1932年3月13日讯：沪社会局公布，自沪战以来，上海住户、商店、工厂、房屋四项损失在14亿元以上。

  • 1932年3月13日讯：蒋介石在南京接见路透社记者，表示对沪军事决不诿卸责任，“中国愿意和平解决争端，但若日本不停止侵略行为，则中国准备奋斗到底”；并称“日方正在筹备军事行动，如日军实行攻击，华军决计力抗，其责任当在日方”。

  • 1932年3月13日《申报》：南京息，外交界接莫斯科电称，苏联政府已正式宣布，否认满洲伪国。又称，日本利用白俄，骚扰苏联沿海州，意在要挟苏联承认日方在东省非法权利，但苏联决不示弱。（11日专电）

  • 1932年3月13日《申报》：哈尔滨息，自卫军一部，10日晚绕至哈西非山屯，与于琛澂军激战1小时退，双城救国军10日攻敦化，与长春开到之日援军激战。（11日专电）

  • 1932年3月13日《申报》：莫斯科讯，据苏联通信社，黑龙江上苏俄境内海兰泡消息，3月10日午后5时，中国境内萨哈连地方（在黑龙江口右岸，与海兰泡隔江相峙）驻防军队，见满洲新政府旗帜出现，愤激不平，因而哗变。起事之初，炮声隆隆，机关枪不绝于耳，闻有子弹飞越黑龙江而达海兰泡。据闻满政府军队…

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，在江湾镇附近的日军八九式中型坦克初期型。

  • 1932年3月13日《申报》：日飞机日来时飞过松江，向沪杭各处侦察，昨日（11）下午1时许，又飞过松江，至三十号桥附近，见有少数中国军队在此巡逻，即向下放枪一二响，旋即他去。松人本如惊弓之鸟，闻此枪声，又甚不安，惟外间所传，日机又飞至松江城内，实弹扫射，人民均避居屋中等说，则绝无其云。

  • 1932年3月13日《申报》：东京讯，日本切欲尽快清理沪案，兹又有一明证，闻当局已决议将二月二日特编之第三舰队，在沪重加编制，而减去数舰，然后即将解除该舰队动员。又广崎师团与某师团余兵之将遣往满洲者，除师团本部外，每师团仅有兵一旅团，故并非增加援满兵力，仅欲代替朝鲜师团之二旅团耳。…

  • 1932年3月13日讯：日军在南翔、嘉定间筑汽车路，在嘉定设司令部。朱家桥敌军数百，时出时没，焚杀甚惨。陆渡桥增兵千余。

1932年03月12日

发表于 2021-03-12 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年3月12日讯：日机又扰杭州及松江，机关枪扫射伤人。13日，杭州市政府函驻沪日总领事馆及驻杭日领米内山庸夫提出抗议，此后如再发生同样入侵情事，“本府为保护全市民众及各国侨民起见，当为合理之御击”。

  • 1932年3月12日讯：北平各界500余人在中山公园举行孙中山逝世七周年纪念，有人上台演说，反对一党专政，会场秩序大乱，王化一等六人被捕。

  • 1932年3月12日讯：朱德以中华苏维埃共和国中央革命军事委员会主席身份发布命令，重编红一、红三、红五军团。一军团，林彪为总指挥，聂荣臻为政委。三军团，彭德怀为总指挥，滕代远为政委。五军团，季振同为总指挥，萧劲光为政委。

  • 1932年3月12日讯：蔡廷锴对记者谈，和战关键“不在我方，而在日方之是否觉悟，能否放弃其侵略政策”。又称：“万一和平破裂，日方向我进攻，我决继续抵抗，但存一兵一卒，亦必奋斗到底。”

  • 1932年3月12日讯：颜惠庆通知国联大会，表示中国接受中日停战决议案。

  • 1932年3月12日讯：日本内阁会议决定《处理满蒙问题方针纲要》，谬称满蒙“可以脱离中国本部政权而独立”；满蒙治安“由帝国担任”；“将满蒙地区作为帝国对俄对华的国防第一线”，为达到这一目的，“应增加帝国陆军驻满洲的兵力”和“进行必要的海军设施”。

  • 1932年3月12日《申报》：杭州息，11日午2时半，日机一架，飞杭侦察全市，并在空开放机枪，我还击十分钟，敌不支向沪杭线逸去，敌弹伤车夫小孩各一人。（11日专电）

  • 1932年3月12日《申报》：北平息，日本坂西中将来平有所活动，昨谒吴佩孚被拒绝，吴谓以在野之身，外宾一概不见，坂怅然去。（11日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，部分参与侵略上海作战的日本海军陆战队军官合影。

  • 1932年3月12日《申报》：北平息，外讯，长春发表奉天省长臧式毅、吉省长熙洽、黑省长马占山，伪国拟9月以前完成全满各地自治市，缩小省府权限，使该三奸专任部长，哈埠仍设特别区。

  • 1932年3月12日《申报》：三友实业社愿助前敌军士内衣裤九百套，业于前日附函车送上海律师公会，代为支配分送前方。该会查得后方伤兵医院，医愈伤兵，因天气将暖，缺乏此种内衣，故于昨日提出内衣裤若干套，并将食品等送往中国红十字第20伤兵医院，慰问各伤兵。

  • 1932年3月12日讯：国民政府发表宣言，否认东北伪组织，声明“在日本军队非法占领东三省期间，所有该处政治组织，中国政府始终认为叛乱机关，同时并认为日本政府之变相的附属机关，对于其一切非法行为，绝对不能承认，并应由日本政府负其全责”。
