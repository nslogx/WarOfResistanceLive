1932年01月06日

发表于 2021-01-06 更新于 2021-09-02 分类于 局部抗战(1931-1937)

  • 1932年1月6日讯：张学良邀孙殿英、李服膺、商震、徐永昌等及在北平各将领协商华北军政问题。

  • 1932年1月6日讯：国民政府令：刘峙已特派为驻豫绥靖主任，所有从前任命兼充之讨逆军第二路总指挥、讨逆军第二军团总指挥、“剿赤”军南路集团军总司令官各名义，均即予撤销。

  • 1932年1月6日讯：国民政府令免京沪卫戍司令长官陈铭枢、南京市市长魏道明、上海市市长张群本职；特任蒋光鼐为京沪卫戍司令长官，任命马超俊为南京市市长，吴铁城为上海市市长。

  • 1932年1月6日讯：上海各大学学生抗日救国联合会发表告全国同胞书、致国民政府电，提出三点要求，限政府三日内实行，即：一、退出国联；二、出兵收复失地，并令北方将士不接受张学良不抵抗命令，自动抗日；三、枪毙丧权辱国的长官张学良。同时致电张学良称：“执事以东北最高军事长官，未 …

  • 1932年1月6日讯：国联“满洲调查团”委员名单已确定，有英国李顿、法国克劳德、美国麦考益、德国希尼、意大利马柯迪，李顿为团长。21日，该团正式成立。

  • 1932年1月6日讯：湖南学生抗日救国会在长沙举行抗日救国大会，到50余校约二万人。大会通过全国一致团结抗日、请发给各校学生枪 支、全国总动员出发东北等决议案。

  • 1932年1月6日讯：南京中央大学学生赴外交部请愿，要求政府出兵东北收复失地。

  • 1932年1月6日讯：日军骑兵第27联队90余人在联队长古贺传太郎率领下抵达锦西县城。由于县长张国栋的卖国投敌行为，导致日军兵不血刃便占领了锦西县。

  • 1932年1月6日讯：马占山由海伦赴哈尔滨与张景惠接洽，在马占山同意下，张景惠次日在齐齐哈尔就任伪黑龙江省省长。

  • 1932年1月6日《申报》：北平息，日军室师团中岛支队一部，今午抵榆关东炮台，日军到站欢迎，又日军因北宁路沿途桥梁路轨，破坏甚重，西进极缓，榆关以东我军，尚有一小部分，仍在奋斗。（6日专电）

  • 1932年1月6日《申报》：交通界讯，到锦州日军，5日6日向锦朝支路出动，6日有战事，闻我义勇军与敌抗拒。（6日专电）

  • 1932年1月6日《申报》：天津息，日飞机二架，六日侦察二十分，飞回秦皇岛。下午三时，又来两架，环飞数周而去，均未掷弹。该处商民多闭门他迁，人心恐慌。（6日专电）

  • 1932年1月6日讯：中国驻国联代表胡世泽访国联代理秘书长爱文诺，请制止日军继续向山海关进袭。

1932年01月05日

发表于 2021-01-05 更新于 2021-09-02 分类于 局部抗战(1931-1937)

  • 1932年1月5日讯：美国国务卿史汀生与英、法驻美大使讨论满洲问题，表示三国对于满洲事变，彼此携手办理。

  • 1932年1月5日讯：张学良在北平召集财政整委会议，讨论冀、晋、察、绥四省财政问题。会议认为：四省每月收入约数为500万元，中央协款百万元，但照六一折发，尚积欠两三月，实际每月收入仅400万元，而军、财支出每月700万元，不敷达300万元。各军若感不敷，可自动裁缩。

  • 1932年1月5日讯：行政院副院长陈铭枢以“政府虽告成立，而我重要领袖，犹天各一方，未能荟萃，致使党政最高指导机关，提挈无人”，电促蒋介石、汪精卫、胡汉民入京，团结御侮。

  • 1932年1月5日讯:行政院长孙科招待新闻界，告以新政府内政、外交、财政等大政方针。

  • 1932年1月5日讯：伪吉林剿匪军司令兼东省铁路护路军司令于琛澂在日军授意下，利用吉林省军械厂储存的武器弹药为基础，编制了5个旅的兵力，由舒兰经榆树大举向北推进。

  • 1932年1月5日《申报》：东京讯，日新闻消息，昨晨美领署人员张白兰为沈阳日兵殴打，稍受伤。张白兰因事往哈尔滨，当其赴车站时，因言语误会，与日兵冲突，日兵欧之，张受伤不重，仍登车赴哈。沈阳美总领事迈尔士旋向日总领事口头抗议，日总领事已谕令调查此事原委。（4日路透社电）

  • 1932年1月5日《申报》：北平息，日军铁甲车及兵车三列，5日抵绥中，定六日向山海关进展，秦皇岛日军500余名，五日到山海关，在车站高悬太阳旗，声明欢迎日军。日第二外遣舰队司令官津田，通告榆关何柱国，谓该舰队到秦皇岛榆关，目的为保护守备队，倘不加害日军，该军对锦州撤退部队，决无攻击意，…

  • 1932年1月5日讯北平绥靖主任张学良通电报告锦州失守经过，略谓：“日方兵力增厚，武器精良，在在皆远胜于我，自其发动以后，竟以飞机、坦克车及大口径炮分路猛攻。我军奋勇应敌，激战十昼夜之久，前仆后继，死伤蔽野。卒以兵力过疲，损失过重，无术继续坚持，致于江日失守锦县。”

1932年01月03日

发表于 2021-01-03 更新于 2021-09-02 分类于 局部抗战(1931-1937)

  • 1932年1月3日讯：福州日侨水户参雄夫妇，晚9时在日俱乐部宿舍暴毙，日居留民谓系华人所为。4日，日舰圆岛陆战队100余人在福州登陆，并由马江运来水兵80余人，声言保侨。5日，福建省府议决限晚8时起36小时内缉到凶手。

  • 1932年1月3日讯：全国医师联合会电国民政府，请迅速以实力援助东北抗日将领马占山。

  • 1932年1月3日讯：东北民众反日救国会电国民党中央和国民政府，声称：“我东北民众固犹为国家之民众也，未知政府负责诸公，尚有无有效办法解救此种危急。

  • 1932年1月3日讯：东北军前线下级军官署名发表第二次联合宣言，声明：“东北为中国之东北，非东北人之东北。故言抵抗，必须全国以整个力量赴之。”

  • 1932年1月3日讯：国民政府令：免国民政府文官长王树翰、代理文官长叶楚伧本职，特任魏怀为国民政府文官长；准免国民政府参军长贺耀组本职，遗职由吕超继任。

  • 1932年1月3日讯：何成濬、李鸣钟、徐源泉、夏斗寅等21将领电行政院，请对日速定大计，下令动员抗日。

  • 1932年1月3日讯：锦州地区的中国军队由山海关撤退到关内，通辽一带的骑兵第三旅撤向热河。日军第20师团占领锦州。

  • 1932年1月3日《申报》：福州息，2日下午，西公园开反日宣传游艺会，日领及圆岛舰长与东瀛校长，便服扯毁反日标语，被民众拥入市局，经军警保护，日方传两长有微伤。（3日专电）

  • 1932年1月3日讯：日军西进，占领辽宁连山，黄显声率警备队退兴城。4日日军占葫芦岛。5日陷绥中。6日下午到万家屯，距山海关仅九公里。
