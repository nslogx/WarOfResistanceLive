1933年02月18日

发表于 2022-02-18 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1933年2月18日讯：中国参加美国芝加哥博览会征品展览会在上海开幕。

  • 1933年2月18日讯：伪满“讨伐热河作战军”总司令部发表进犯热河声明，宣布成立讨热军总司令部，任张景惠为总司令，张海鹏为前敌总指挥，统率数万大军，与日军协同作战。

  • 1933年2月18日讯：日陆军省召开紧急军事参议官会议，菱刈、铃木、本庄繁等出席，由陆相荒木报告国联处理中日纠纷情况，并详细说明侵热军事计划。会议决定要求政府断然退出国联。

  • 1933年2月18日讯：北平学生抗日救国联合会成立，由北京大学、中国学院、法政大学等24校参加。

  • 1933年2月18日讯：国学泰斗章太炎、马相伯联名宣言，以无可辩驳的历史事实说明东北与热河同属中国领土，且热河与满洲无关。“热河在明时，本朵颜等三卫之地。朵颜种类，即古之山戎，汉之乌桓、唐之奚，与契丹种类甚近，而与满洲各类相远。其后清人夺取其地，本非满洲人之旧居，至于今日，则热河所有汉人几四百万，而满人无几，更不得谓热河为满洲人所应有”。

  • 1933年2月18日讯：外交部为十九国特委会通过《国际联盟特别大会关于中日争议报告书》发表谈话，表示对报告书“大体上自可满意。国人如不欲吹毛求疵者，则当不致有人欲拒绝此项报告书者”。

  • 1933年2月18日讯：张学良、张作相、汤玉麟、万福麟、冯占海等27将领自承德发抗日通电，谓：“时至今日，我实忍无可忍，惟有武力自卫，舍身奋斗，以为救亡图存之计”，表示“但有一兵一卒，亦必再接再厉”，要求全国声援。

  • 1933年2月18日讯：热河省府主席汤玉麟与承德各界设午宴欢迎宋子文、张学良等一行。宋致词称：“本人代表中央政府，敢向诸位担保，吾人决不放弃东北，吾人决不放弃热河，纵令敌方占我首都，亦无人肯作城下之盟。”张学良勉大家誓守热河，雪九一八之耻。汤致答词表示决心与日周旋。宴后，宋、张联电驻国联代表团，要求向国联和世界各国声明中国政府和人民决心抵抗日寇侵略。

  • 1933年2月18日讯：张学良同时下令将第4军团万福麟部第53军6个师，第5军团汤玉麟部第55军1个师又4个旅，第6军团张作相部第41军共3个旅以及第63军、挺进军等共约10万人编为两个集团军，直接担任热河省的防守任务，但各部队调防尚未完成，日军已开始进攻。

  • 1933年2月18日讯：张学良以北平军分会名义将华北现有驻军编为8个军团和1个预备军团。第1军团于学忠部防守津塘地区，第2军团商震部防守滦东地区，第3军团宋哲元部防守冀北地区，第7军团傅作义部防守察东地区，第8军团杨杰部和预备军团集结于北平附近。

  • 1933年2月18日《申报》：北平息，日军近派间谍多名，秘密赴北票三家子凌南县，侦探我军情，均扮成乡农模样，已有数名被驻军捕获。日军再朝阳寺增加甲车两列，时向南岭开炮，我驻军张营已严防。（17日专电）

  • 1933年2月18日《申报》：莫斯科讯，两月前随苏炳文将军退入俄境之抗日军队，经俄当道收容于多木斯克后，刻经中俄两政府商定，于今日起开始运送回国。兵士先行开拔，由西伯利亚铁路运送至吉亚的加，然后入新疆境，苏将军既各军官与眷属等，则因此道险恶，将俟兵士回国事务办毕后，取道欧洲返国，此间现信苏将军大约将照收容协定，再留三星期，然后去俄。至于所有收容及运输等费，将由中政府照付，俄员正在核算中。（17日国民社电）

  • 1933年2月18日《申报》：北平息，前榆关战役受伤之连长赵璧，在卫戍医院医治，经军分会升为营长，刻伤愈，今晨率同出院官兵百余赴前方继续杀敌。（17日专电）

  • #抗战影像#1933年2月下旬，进犯赤峰的日军进入敖汉旗四家子老虎山，当地维持会强迫老百姓“欢迎”日军到来。

  • 1933年2月18日《申报》：北平息，秦皇岛电，昨夜10时，日由万家屯调集骑兵三百余，坦克5辆，掩护其步队约500余，向九门口东方长岭子进攻，激战甚烈。我某部奋勇抵抗，同时义勇军由白帽山袭攻日军后路，双方激战约6小时。迄今晨4时，日军退却，刻正在李家堡待援，我军已联合义勇军，即向李家堡反攻，石河无战事。榆关每日下午4时闭城门，日机昨飞我后方侦查。（17日专电）

  • 1933年2月18日《申报》：北平息，汤玉麟电汤佐辅称，日方已通牒前方崔旅，声称如不撤退，决即实行三次总攻开鲁，由通辽调到日军，约千余，已运抵打虎山，张海鹏15日晚赴通辽，参加会商攻热计划，由打虎山至开鲁道台营子均掘战壕，周架电线，汤佐辅今奉召返热。（17日专电）

  • 1933年2月18日讯：张学良与万福麟、宋哲元等20多名将领发出通电，说：“时至今日，我实忍无可忍，惟有武力自卫，舍身奋斗，以为救亡图存之计。”

1933年02月17日

发表于 2022-02-17 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1933年2月17日讯：上海至海参崴航班恢复。

  • 1933年2月17日讯：上海公共租界英商自来水公司因任意增加水费，遭市民反对，13日起连续割断水管多处，引起汽缸爆裂，酿成人命事件。是日，上海房产公会大会决议拒付水费，以示抗议，并于翌日派代表向上海市政府请愿。3月1日，上海沪东区市民组拒绝断水会。

  • 1933年2月17日讯：英国著名文学家、世界反帝大同盟名誉主席萧伯纳游历远东，是日到达上海，宋庆龄等往吴淞口迎接，并设午宴招待，鲁迅、蔡元培、杨杏佛、林语堂以及美籍记者史沫特莱、伊罗生等人作陪。南京市长石瑛邀萧伯纳到京，被拒绝。当日，萧伯纳乘轮北上

  • 1933年2月17日讯：日驻华使馆通告北平、天津、张家口等地日侨，限两周内回国，违即强迫遣送。此前，驻津日领曾两次下令撤侨，因日侨反对日军侵华，回国者寥寥。

  • 1933年2月17日讯：宋子文、张学良、张作相、朱庆澜、黄炎培、杜重远、穆藕初等及东北民众抗日救国会所属宣传大队由平到承德。

  • 1933年2月17日讯：日关东军司令官武藤以侵热准备就绪，是日下令第六师团以主力于2月23日从打通路沿线出发，经开鲁、绥东、阜新，接着向天山、下洼、朝阳一线进攻，然后再向赤峰及林西、多伦方面作战。又以较强一部于2月23日从朝阳寺附近出发，从北票铁道方面开始经朝阳、建平向赤峰方面进攻；令第八师团一部2月23日开始行动，迅速占领北票，并统一指挥在该方面作战的第六师团。主力成二路纵队，于2月27日从北票及绥中附近出发，尽快向建昌附近至其以南一线挺进，不失时机地以一部确保界岭口、冷口、喜峰口等长城要隘，掩护军主力侧翼，尔后以主力占领承德及古北口；混成第三十三旅团主力按随时可出动的态势作好整备；飞行队以一部协助第六师团，主力协助第八师团作战。

  • 1933年2月17日讯：为配合关东军侵攻热河，伪满政权组成了“讨热军”司令部，伪军政部总长张景惠为总司令，张海鹏为前敌总指挥，军事顾问有多田骏、佐佐木到一等人，总数约1万人。此后，又陆续将伪军程国瑞、李寿山、刘桂堂、李际春等部，投入了热河及长城作战。

  • 1933年2月17日讯：宋子文等与张学良至热河视察部队。宋子文先后在北平和承德发表演讲，说：“热河为中国完整之一部，与苏、粤各省无异，热河被攻，即同于南京被攻。如日军来攻，则将举全国之力量以与其周旋。日本已占我东北，但任何进一步之进攻，即将予以抵抗”

  • 1933年2月17日《申报》：北平息，承德电，北票日关东军谍报队，近在各地招募工人一百余名，修理锦朝线铁路，并有日军收买汉奸多名，深夜开枪。汤玉麟已派参议邵次峰前往北票，与日方交涉。岭南第一区药王庙，发现日军第8师团部队三百名，并有炮兵第49联队，将掩护步兵，向岭南推进。（15日专电）

  • 1933年2月17日《申报》：北平息，前方来人谈，何柱国连日至各旅、团，对官兵演说，抗日责任。各将官兵士均极奋发，均愿以铁血与暴日周旋到底。（16日专电）

  • #抗战影像#1933年初，日军占领榆关后，日方称之为“榆关事变”，在天下第一关南侧为战死的日本官兵竖立了纪念碑，实属日军侵略的罪证。

  • 1933年2月17日《申报》：临榆息，九门口日军向我挑衅，15日午至16日午又续发步枪百余响，经我警戒兵发枪还击始至。（16日专电）

  • 1933年2月17日《申报》：临榆息，沈讯，日军在积极部署颁发总攻热河之命令，14日驻锦第八师团之步兵第31联队所属两大队，装车两列，开往义县方面。炮兵第8联队装车一列，开往通辽方面。伪军李芳亭部约四百余人，装车一列，开赴通辽。又讯，驻江省松木第14师团平贺旅团，已由洮昂路南下通辽。在中东路驶满间之服部14混成旅团及高波骑兵一旅团，准备南下中。（16日专电）

  • 1933年2月17日讯：武藤下达了“进攻热河的作战命令”，规定于2月23日开始，分热北和热南两个地域展开作战。同时下令编成进攻热河部队，主要有：第6 、第8 师团，混成第14、第33旅团，骑兵第4 旅团，以及飞行、铁道、通信、兵站等部队。

  • 1933年2月17日讯：十九国特委会于14日修正通过《国际联盟特别大会关于中日争议报告书》，是日全文公布。内容与李顿报告书大体一致，虽载明不能承认九一八后日本在中国东北之军事行动为自卫手段，对日本所操纵的伪满“不能认为自动及真实之独立运动”，却仍以李顿报告书中十项原则作为解决中日争议的建议，亦即承认日本在满洲之利益，满洲自治，以国际合作促进中国之建设（即国际共管）等等。18日，孙科对记者发表谈话，认为报告书内容均甚公正，可表示满意，但“国联若不能以经济绝交制裁违背盟约之日本，则此项报告书，亦系一纸空文”。

1933年02月16日

发表于 2022-02-16 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1933年2月16日讯：西陲宣化使班禅额尔德尼抵绥远百灵庙，对蒙古王公谈称：“中华五族，宜化除畛域，一致抗日。”并派安钦活佛返京，取道印度入藏，与达赖商班禅回藏事。

  • 1933年2月16日讯：上海三友实业社总厂工人，因厂方不遵上海劳资仲裁委员会关于开工问题的调解和江苏高等法院勒令开工的判决，数千工人无以为生，是日推代表樊臻涌等40余人到京向国民党中央党部请愿。

  • 1933年2月16日讯：实业部江浙区渔业改进委员会在上海成立，实业部长陈公博兼任主席委员，林康侯、方椒伯、杜月笙等任委员。4月，该会开征渔业建设费，遭渔商强烈反对。11月21日，陈公博以经费不敷，无余资从事渔业改进，呈请行政院停办。计划中之闽粤、鲁冀两渔业改进委员会亦未成立。

  • 1933年2月16日讯：国民党中政会议决修订反省院组织办法，反省院仍隶属于司法行政部，院长不由高等法院院长兼任，而就中央执行委员会所交付之人员任用之。

  • 1933年2月16日讯：日军以九门口两次被义军攻入，为扫除侵略热河的牵制，调步骑800余在九门口外进攻义军郑桂林、王慎庐等部。

  • 1933年2月16日《申报》：北平息，日军今日在连山县城锦县绥中一带村屯，征集车辆驮子等交通器具，备战地运输用。同时在朝阳、兴城、绥中、凌南、凌源一带，用飞机散传单，威胁村民迁移。现该地居民，恐慌万状，纷纷逃避，啼哭之声，惨不忍闻。义勇军近来在日军后方活动极力，凌南凌源朝阳绥中一带，交通孔道，多被义勇军封锁。（15日专电）

  • 1933年2月16日《申报》：南京息，15日外电传来消息，称日军已定本月27日开始总攻热河云云。官方对此，认为系日本在国联外交失败后之一种企图，并不惊奇。且据东京电传，自此项消息传出后，日金融界顿呈极度不安之现象，东京大阪等处之证券交易均已关闭，足见此项消息，在日本已发生恶劣的影响。我国上下对日军犯热，早在意料之中，并已一致决心抵抗，故日军如实际进犯，中央决严令守土将士誓死抵御，不失寸土。（15日中央社电）

  • #抗战影像#日本陆军军乐队正在吹奏军乐。

  • 1933年2月16日《申报》：北平息，绥中西方之马甸日军，被义勇军包围击退，义勇军昨午夜占领马甸，获日军械甚多，今晨向绥中车站进攻，日在绥中调来大队炮兵，预备迎击。（15日专电）

  • 1933年2月16日《申报》：北平息，据此间之日兵高级官员称，日方现准备再最短时间内向中国提出哀的美敦书（注：最后通牒的旧译）三件，内容系要求中国政府撤退热河所有之军队。但中国当局恐不能接受此种要求，日兵之军队至迟在本月27日即将入热，预期3月1日左右开始大规模之战事。因3月1日为“满洲国”第一周年纪念日也，该哀的美敦书三件，其一将由“满洲国”政府交热省主席汤玉麟，其二由关东军总司令武藤至张学良，其三则为东京政府至中国政府者，内容大致相同，皆谓热河为“满洲国”之一部分，故中国军队须全部由该地撤退云。（15日路透社电）

  • 1933年2月16日讯：黄炎培、穆藕初、朱庆澜、熊希龄、杜重远等发起组织东北热河后援协进会，本日在平成立。宋子文、张学良莅会发表演说。会议通过章程草案和工作计划大纲。称该会主要工作和目的为：一、集中民众抗日力量；二、使民众力量与抗日军队力量相结合；三、唤起国际的同情与援助。推选朱庆澜、丁文江、胡适、王克敏、熊希龄、周作民等45人为理事，会长朱庆澜、副会长周作民。决议通电全国人民 报告该会之成立，要求全国一致起来援助前方军需；并通电全国军政官兵请一致团结御侮。会后商定朱庆澜等翌日随宋子文赴热河视察，推动汤玉麟抗战。

1933年02月15日

发表于 2022-02-15 更新于 2022-02-23 分类于 局部抗战(1931-1937)

  • 1933年2月15日讯：广州市海珠桥落成。此桥于1929年由美国马克敦公司以银103.2万两承建。

  • 1933年2月15日讯：国民党中政会通过戴季陶等提议，设立建国奖学委员会，其条例规定：设总裁三人，考试院长为当然总裁，余二人由国府简派；奖学金来源为中央拨款、政府机关补助、社会团体或私人捐助。

  • 1933年2月15日讯：日关东军司令官为伪满“建国”一周年布告民众，宣称“建国期年，从来秕政，概行革除，日满国交，益加敦厚”；扶植伪满系“义之不容看过，情之不可坐视”。

  • 1933年2月14日讯：浙江镇海农民与城镇居民二三千人举行元宵赛会，因遭警察阻止，起而暴动，将公安局捣毁。翌日，县府紧急会议决定严禁迎赛集会，城厢戒严，并拘捕群众七人。

  • 1933年2月14日讯：日大藏省认可“满铁”增资3.6亿元，资本金达8亿元；新增资金充本年后新建事业经费。

  • 1933年2月14日讯：东北民众救国军苏炳文部入苏官兵2500余名由第十五旅旅长郑润成等率领，于是日、翌日及18日分三批由苏联鄂木斯克运送回国，27日抵新疆塔城，3月下旬陆续到迪化。

  • 1933年2月14日讯：段祺瑞在沪与日驻华公使有吉明会晤，要求日本缓和侵热军事。有吉表示侵热不能中止，对平、津可不积极行动。
