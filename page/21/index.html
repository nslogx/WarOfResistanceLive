1932年05月12日

发表于 2021-05-12 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年5月12日讯：上海明星影片公司摄制反映第十九路军与第五军抗日作战事迹影片《四达通》（意译星石）在沪公演。

  • 1932年5月12日讯：上海工部局在沪西一带越界筑路，上海市政府向工部局提严重抗议。

  • 1932年5月12日讯：鄂豫皖红军发起潢（川）光（山）战役，至16日共歼国民党军近万人。至此，鄂豫皖苏区迅速扩大，“东起淠河，西迄平汉路，北达潢川、固始，南至黄梅、广济，总面积达四万余平方米，人口三百五十余万，拥有黄安、商城、英山、罗田、霍邱五座县城”，跨越26个县的区域。主力红军4.5万余人，地方武装20余万人。

  • 1932年5月12日讯：粤军李汉魂到仁化，率陈汉光、陈章甫两旅会同湘军围攻汝城红军彭德怀部。13日，第十五师王东原部陷汝城，陈汉光、陈章甫两旅亦先后到达，粤、湘军联络会“剿”桂东。

  • 1932年5月12日讯：军委会改革陆军编制，通令各师按新编制每师改编为二旅四团，前定之甲、乙、丙各种师制一律取消。

  • 1932年5月12日讯：马占山自黑河向各报界发出文电，表示“誓死长期抗日”，“并请全国竭诚御侮”。

  • 1932年5月12日讯：粤西南政务委员会训令第一集团军称：“本会议决，反对中央所签丧权辱国停战协定，仰饬属一体严重反对，并筹拟进行抗日。”

  • 1932年5月12日《申报》：北平息，通辽义勇军首领天下好，4月24日夜，选精锐400，联络一二路义勇军，进击日军司令部，毙日兵5，司令部捣毁。25日日军由大通河调兵600，携机枪数十挺，大炮十余门，并由四洮调军400，飞机5架，两路夹击中埋伏大败。毙26，内日军官8，伤30余。义勇军死伤25，民众6。（11日专电）

  • #抗战影像#伪满洲国明信片，主题是“哈尔滨的夜色”。

  • 1932年5月12日《申报》：北平息，4月28日，日武装警260名，由山城子犯通化，与16路义勇军孙秀岩部，在城西开战，同时总司令唐聚五自桓仁，11路司令王桐轩自平顶山，派队应援，三面围击，经15小时，毙日兵20余，缴步枪百二十八枝，子弹二万余粒，轻机枪三挺，我仅伤亡三十余。（11日专电）

  • 1932年5月12日《申报》：北平息，榆关电，关东军驻津日军部派少佐参谋见何柱国，谓对前要求自由攻击义勇军，已不坚持，但要求在九门口以内，如发现义勇军，应由中国取缔。九门口以外，由日方取缔。何请转告关东军，日军不可越过绥中县境，以免引起误会。（11日专电）

  • 1932年5月12日讯：上海停战共同委员会委员俞鸿钧、温应星与日方委员冈崎、原田、伊藤会商闸北日军撤退日期，日方允本月16日将闸北铁路区域内之日军撤退；并声明一个月内，日陆军全数撤离上海。

1932年05月11日

  • 1932年5月11日讯：何应钦电汪精卫、朱家骅，请督饬全国各校注重体育，提倡尚武，严禁女学生束胸、缠足、高履。

  • 1932年5月11日讯：陕西省赈务会为陕省70县灾情惨重，致函华北各慈善团体，吁请赈济。

  • 1932年5月11日讯：　陈济棠委邓龙光为第一集团军海军舰队司令，是日邓接收海军总部。

  • 1932年5月11日讯：国民政府特派颜惠庆为参加法国故大总统杜美尔丧葬典礼专使；任命郭泰祺为驻英国特命全权公使。

  • 1932年5月11日讯：陈济棠电汪精卫，表示“此后惟有遵命努力于剿共，完成革命，以副先生之期望”。

  • 1932年5月11日讯：上海市政府商请撤兵区域接管委员会转请停战共同委员会向日方交涉，即日将闸北、吴淞、江湾等处日军迅速撤退，以便早日接管。

  • 1932年5月11日《申报》：北平息，马占山在通河击沉日舰一艘，日方损失颇巨，马并电调查团，决贯彻抗日初志。（10日专电）

  • 1932年5月11日《申报》：天津息，张学良7日运步枪弹万发，及迫击炮机关枪等多数兵器赴山海关。又于9日命炮兵独立第7旅，由北苑调防。同时在顺成王府，开军事会议，结果决定命令各部，如日军来攻，决立即抵抗，勿使寸土有失（10日电通社电）

  • #抗战影像#伪满洲国时期，南满洲四平街火车站（四平街驿）旧貌。

  • 1932年5月11日《申报》：北平息，马占山电平称，通河之役，日军除焚掠外，并将通河县长、公安局长、商会长一齐拉入兵舰监禁。路遇难民妇孺，皆札毙。有某姓全家41口，均被烧杀。在菜窖避难百姓，均堵窖口杀尽，凶惨已极。调查团东来，近在咫尺，日军惨横，肆无忌惮，凶顽可见云。（10日专电）

  • 1932年5月11日《申报》：北平息，马占山今有电到平称，日军利用我哈江防舰队，东犯通河，入城焚掠街市粮食，勒缴警团枪械，马部7日夜半乘敌装载登船之际，突包围痛剿，毙敌无算，获械甚多，正追击中。（10日专电）

  • 1932年5月11日讯：日陆军中央部命令上海派遣军司令部及第九师团等部队回国。第十四师团最后一批撤离上海，从吴淞港登轮去大连。

1932年05月10日

  • 1932年5月10日讯：西北科学考察团回到北平，带回采集品42箱，团长袁复礼报告在新疆、蒙古考察经过。按：该团系于1928年5月10日由北平出发。

  • 1932年5月10日讯：行政院决议：一、海军部长陈绍宽呈请辞职，决议慰留；二、派殷汝耕、温应星、郭德华、韩德勤、朱锡百为上海撤兵区域接管委员会委员。

  • 1932年5月10日讯：国民政府令：准免吴铁城兼侨务委员会委员长职，任命陈树人为侨务委员会委员，并指定为委员长。

  • 1932年5月10日讯：王陵基由汉飞宁，向蒋介石汇报鄂西“剿匪”情形，并请示“方略”。范绍增电刘湘，催川军速东下“剿匪”。

  • 1932年5月10日讯：鄂绥署主任何成濬发表救灾“剿匪”谈话，声称“救灾较剿匪尤为重要”，但“救灾须与剿匪同时并进”。

  • 1932年5月10日讯：交通部长陈铭枢赴沪晤孙科，陈述汪（精卫）、蒋（介石）两氏对孙所提抗日救国纲领之意见，孙称：本人所提之抗日救国纲领完全根据汪精卫来沪晤谈时之谈话意见。

  • 1932年5月10日讯：上海各团体救国联合会致函郭泰祺，质问其先后言行不符，竟签丧权辱国之协定。

  • 1932年5月10日讯：罗店日军步兵一营、过山炮队一连于中午12时半撤退，狮子林、杨行、大场、真如线迤西已无日军。

  • 1932年5月10日讯：冯占海部迫近哈尔滨近郊后，着手侦察部署，等待其他两路大军的到来，会攻哈尔滨

  • 1932年5月10日《申报》：北平息，榆关日军要求在榆关内80里内，自由剿灭义勇军，请何柱国签字，何已拒绝。谓榆关内80里，乃该军防区，如日军欲在此区内剿匪，须先得华军长官签字，否则危急华民生命财产，日须负责。日军尚未答复，榆关每晚8时起戒严，翌晨6时解严，入夜常有枪声，系日人希图扰乱地方诡计。（9日专电）

  • 1932年5月10日《申报》：北平息，救国军大刀会8日占柳河，且图突袭日军之警官队，使之陷于孤立无援之状。该地日侨均迁避北山城子，柳河通化间联络被截断。（9日电通社电）

  • #抗战影像#正在接受检阅的伪满洲国陆军部队。

  • 1932年5月10日《申报》：哈尔滨息，据前敌消息，日军于“满洲国”军于上周失利后，现又前进，闻从阿什河进抵哈尔滨之华军，已与日军接战，现向后退却。料哈埠之紧张，已稍松动，松花江日军已得生力军援助，亦向前推进。闻依兰方面，复被日军占据，刻向佳木斯进发其地距依兰约70里。闻日军司令为便利北满作战起见，拟在依兰设立飞机根据地。（9日路透社电）

  • 1932年5月10日《申报》：日军第一期撤退程序，定昨日下午1时前，将浏河、嘉定、南翔三处日军，完全撤退。罗店则定今日下午1时前，作最后撤退。昨日我方接管委员会，已开始进行接管事宜。

  • 1932年5月10日讯：李宗仁、白崇禧电汪精卫，称：“承示东北事件仍以交涉与抵抗并行，绝不因此而松懈……仁、禧当益奋勉，整饬所部，以为后盾。”

1932年05月09日

发表于 2021-05-09 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年5月9日讯：国民党海外党务委员会正式成立，任胡仲维等六人为总干事。

  • 1932年5月9日讯：中华苏维埃临时中央政府发出《反对国民党出卖淞沪的协定》通电，否认此项屈辱协定，号召群众进行民族战争来保卫中国的主权独立与领土完整。

  • 　1932年5月9日讯：国联调查团由长春抵哈尔滨。

  • 1932年5月9日讯：沪市商会电行政院，称：“历来外交恶例，往往于正式约文而外，另附议事录、声明书等类，丧权辱国，贻害无穷”，要求明白宣示此案除公布文件外，绝无其他秘密附录。10日，汪精卫复电，声称上海停战撤兵协定“无其他秘密文件或接受任何秘密条件”。

  • 1932年5月9日讯：国民党中央党部留京办事处举行“五九”国耻纪念会，汪精卫作报告：一、训政时期中央民意机关用国民参政会的名义，不用国民代表会名义；二、《淞沪停战协定》完全为停战撤兵，无政治性质；东北问题并不因此而停止交涉，今后外交仍抱一面交涉、一面抵抗之态度。

  • 1932年5月9日讯：是日为袁世凯签订“二十一条”国耻日，北平学生300余人上街游行，高呼“打倒国民党”、“打倒统治阶级”等口号，至市党部，将匾额卸下击碎，将党旗撕毁，并散发传单，下署“反帝大同盟”字样。南京、长沙、汉口、安庆、天津、镇江等地均举行“五九”国耻纪念会。

  • 1932年5月9日讯：萧佛成、唐绍仪、邹鲁、邓泽如、陈济棠、李宗仁等发出佳电，反对签订上海停战协定，认为该协定与袁世凯签订“二十一条”同为秘密卖国。

  • 1932年5月9日《申报》：哈尔滨息，今日此间得日人消息，马占山自海兰泡对面大石河运到飞机7架，设飞机场于克山铁路之班塔门（译音），将以此为轰炸齐齐哈尔之根据地。昨晨有反满洲国之军队5百名攻击海林。激战后，被迫退走，当交战之际，另有反满军队攻击中东路东段乌吉密河，而占据之。（8日路透社电）

  • #抗战影像#1931年11月26日，越狱后又再次落入日本关东军魔爪的几名东北义勇军战士。

  • 1932年5月9日《申报》：哈尔滨息，今晨得讯，反满洲国之军队昨在方正附近，与日军恶战终日，胜负未详。日军生力军昨已抵哈，闻一面坡以西五十基洛米突周径内之所有桥梁，皆已被毁。有数处路轨被拆，各长五百米突以上。（7日路透社电）

  • 1932年5月9日《申报》：中日停战协定签字后，日来进口日货，势如潮涌。兹据海关进口房某职员云，此项日货，以棉花居多，余系杂货。近一周内三井洋行一家约纳税银十万之多，据闻现在沪东西各日纱厂，已完全开工，该项棉花大都供给各日纱厂所需用。

  • 1932年5月9日讯：国民党中央政治会议议决：任命居正为司法院院长、覃振为司法院副院长，准伍朝枢辞司法院院长职；任命邵元冲为立法院副院长、叶楚伧为立法院秘书长；任命钮永建为考试院副院长；任命张继、伍朝枢为国民政府委员。并议决：在上海暂设临时市参议会；核准邮资加价办法，国内信件加一分，明信片加半分，挂号信件加二分。

  • 1932年5月9日《申报》：日军业已自各地陆续撤退，我方接管警察八百名，亦已于昨晚开至安亭及前线，听候调遣。而路局方面，亦已着手进行修理铁路等，并定于今晨派秘书丁振亨赴苏，向19路军接洽通车问题。

1932年05月08日

发表于 2021-05-08 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年5月8日讯：上海光华大学文学院长王造时发表《对于训政与宪政的意见》一文，驳斥汪精卫、于右任等人不同意结束训政的言论。指出“像国民党近几年来的干法，对外丧权辱国，对内压迫人民……到了万不得已的时候，推翻国民党的政权，也未始不是拥护中华民国之一法”。

  • 1932年5月8日讯：红军第三军团彭德怀部占领湖南桂东。

  • 1932年5月8日讯：苏家埠战役结束。红四方面军3月21日发起苏家埠战役，是日苏家埠、韩摆渡之守军全部投降。该战役历时48天，歼敌三万余，俘皖西“剿匪”总指挥厉式鼎及旅长五名，团长11名及以下官兵两万余人。

  • 1932年5月8日讯：川军师长王陵基、范绍增与何成濬、徐源泉、夏斗寅等商定，由川军派十二个团在鄂西“剿共”。

  • 1932年5月8日讯：何应钦电汪精卫、蒋介石称：在赣“剿匪”交通不便，请中央迅拨巨款，兴筑公路及铁路。

  • 1932年5月8日讯：平、津、济邮务工作会代表在天津开联席会议，决议：于6月12日在北平召开华北邮工联席会；反对邮资加价；平、津、济邮务工会共发宣言，反对上海丧权辱国停战协定。

  • 1932年5月8日讯：国联调查团访伪满交通总长丁鉴修，提出25项有关铁道之质询。旋赴伪立法院，听取伪院长赵欣伯说明参加“新国家”之动机及伪立法院组织之内容。

  • 1932年5月8日讯：上海各团体救国联合会电国联，“坚决否认中日停战协定，因其足以破坏中国领土、行政之完整”。

  • 1932年5月8日讯：国民党广州市党部通电反对上海停战协定，列举协定五大缺点：一、不提东北；二、淞沪被占领土不得驻兵与《辛丑条约》天津50里内不得驻兵相同；三、规定日军驻地模糊；四、无我军保护淞沪路明文；五、共同委员会无强制日人履约权。

  • 1932年5月8日讯：浏河、嘉定、南翔前线日军陆续撤退，9日撤尽，南京警察厅长吴思豫派干警500名前往接收。

  • #抗战影像#伪满洲国国境警察队，也称伪满洲国靖线警察队，正在接受其长官检阅。

  • 1932年5月8日《申报》：北平息，日关东军奉命决以全力消灭东北义勇军，连日运往绥中大批军需品子弹，日机迭飞各要隘，侦查义勇军根据地，并威胁各地驻军，不得与义勇军通声气，各驻军均不理。（7日专电）
