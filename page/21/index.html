1932年05月20日

发表于 2021-05-20 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年5月20日讯：章太炎、景耀月等组织之中国学会在北平成立。

  • 1932年5月20日讯：韩复榘在曲阜第二师范学校捕获共产党及嫌疑学生24人。

  • 1932年5月20日讯：财政部申令川、鄂、赣、湘四省现金出口，切实弛禁。

  • 1932年5月20日讯：北平邮务工会邮务职工会召开谈话会，决议为响应沪会所提救邮方案电呈交通部采纳施行。

  • 1932年5月20日讯：北平邮务工会邮务职工会召开谈话会，决议为响应沪会所提救邮方案电呈交通部采纳施行。

  • 1932年5月20日讯：沪邮务工会因所提归并汇业局、维持旧邮资、停止邮航津贴、改善邮务管理四项要求，为交通部批驳，本日开会决议采取直接行动。

  • 1932年5月20日讯：国联调查团长李顿请苏联政府签证护照，准团员由中东路取道西伯利亚铁路至海兰泡渡江至黑河访马占山。苏外交部门以严守不干涉政策拒绝。

  • 1932年5月20日讯：上官云相自浔乘飞机到京，向蒋介石报告在赣“剿共”情况。

  • 1932年5月20日讯：上海停战共同委员会日方委员冈崎正式通知中方委员俞鸿钧、温应星，决定于本月23日上午11时将杨行、狮子林炮台、炮台湾营房以及三官塘火药库方面之日军完全撤退。

  • 1932年5月20日《申报》：北平息，伪警组织，设总队一，内分三小队，下又分五分队。大队计二百人，中有日鲜十之九，华人约四十人。总队长为日人松山，分队长皆日鲜人，华人最高仅充班长。（19日专电）

  • 1932年5月20日《申报》：秦皇岛息，路透社今日得报官场消息，驻山海关之何柱国旅长，曾因日人无故炮击山海关，提出抗议。但日人迄未说明其炮击之理由，山海关现尚宁静。（19日路透社电）山海关息，榆关今日无事，沈变后临榆县党务工作，无形中限于停顿中。17日有徒手日兵擅入党部内，搜去宣传品一束。（19日专电）

  • #抗战影像#伪满洲国明信片，主题是“哈尔滨的夜色”。

  • 1932年5月20日《申报》：南京息，据可靠方面消息，马占山之抗日军事行动，极称顺利，日军曾数度被窘。马现得华侨赠送飞机数架，参加作战，龙江之兵工厂已迁移黑河。闻马最近购置军械颇多，尚待证实。然马于未反正时，确由日方取得军械，马之军队约四万人，步炮骑兵俱全，尚有飞机一队，野 炮二十尊。文马之军队军容甚整，军械充足，且得民团及义勇军赞助，人数渐增。（19日路透社电）

  • 1932年5月20日讯：自卫军中路军在后援尽失的情况下决定仍前往哈尔滨，进抵阿城，料甸子地区，并于总司令部和先期到达的冯占海部完成联络，遂在此集结等待左路军的到来。

  • 1932年5月20日《申报》：接管委员会，昨晨派员赴江湾，接收江湾淞沪铁路以西之区域，该处日军共二百余人，于昨晨11时一刻，完全撤退，双方于11时零5分交替。我方5区5所长戴鸿恩，于昨晨率警，会同平保安队前往，午时已布置就署。消防保安两组，亦即恢复，并实行清查户口，教育局亦派员前往接收各学校。此外我方又派员于昨晨接管彭浦，并于昨晨10时，日方在北站交还俘虏。

  • 1932年5月20日讯：沪撤兵区域接管委员会召集有关各方举行联席会议，会商接管闸北铁路以北区域办法。

  • 1932年5月20日讯：《再生》月刊在北平创刊。张君劢、张东荪、罗隆基等创办。宣传“国家社会主义”，中国国家社会党成立后为其机关刊。

  • 1932年5月20日讯：河南鹿邑、柘城两县春荒，粮食告竭，死亡枕藉，惨不忍睹，鹿邑县设人市五处，幼女不值10元，幼童仅易1000文，孩提婴儿抛弃遍地。

1932年05月19日

发表于 2021-05-19 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年5月19日讯：鄂省政府再颁现金出口禁令。

  • 1932年5月19日讯：国有七铁路（缺正太路代表）工会联席会议通过反对伪满洲国、收复失地等案。会议否认按月征收铁路员工所得捐充实财政案。20日又决议组织全国铁路工会联合会。

  • 1932年5月19日讯：国民政府令：一、豫陕晋边区绥靖督办公署撤销，派刘镇华为鄂豫陕边区“剿匪”督办，派徐源泉为湖北全省清乡督办；二、任命李松山为陆军第五十七师师长。

  • 1932年5月19日讯：行政院会议，陈铭枢、陈公博相继报告在沪与孙科接洽情形；决议设立全国水利委员会。

  • 1932年5月19日讯：考试院副院长钮永建对《申报》记者发表关于考试问题的谈话，称：“俟国难问题解决，当厉行考试制度，拔取真才。”

  • 1932年5月19日讯：马占山旧部柴鸿猷率部向克山进攻，与日军激战一天多，予敌较大打击。

  • 1932年5月19日讯：江湾日军于上午11时许完全撤退，由我方自北平调沪之保安队第三中队接防。彭浦、庙行亦均由我方派警进驻。江湾日军撤退区域，仅余瓦砾。

  • 1932年5月19日《申报》：北平息，榆关电，驻榆日守备队松下，今下午访问何柱国谈二小时。内容如下：1）以前误会设法接触；2）盼报纸对榆事勿扩大；3）长城内如伪警与我警冲突时，双方解除武装，再交涉；4）长城外属关东军，如发生事件，驻榆守备队不负责；5）榆关治安中日双方共同维持。（18日专电）

  • #抗战影像#日本大石田合同运送株式会社在伪满洲国发行的股票。

  • 1932年5月19日《申报》：哈尔滨息，日广濑师团，今晨八时占领松花江下流之依兰，该团司令部即移入城内。（18日路电通社电）

  • 1932年5月19日《申报》：东京讯，李杜军队为沿松花江而下之日军所迫，决定放弃依兰，而向东省与西比利亚边界附近之富锦退走。昨晨退出时，将日侨35名杀死，中村旅团入城后，发现被杀日侨之尸身。日本军事当道，以为日军之占据此城，乃一重要胜利。（18日路透社电）

  • 1932年5月19日讯：中华民国国难救济会通电全国，否认上海停战协定，略称：“协定第二条规定我国军队在常态恢复未决定办法以前，暂驻现在地位，等于设定暂时不驻军队之区域”；“协定未经立法院议决，在我现行国法上未具备有效条件，不得认为已生效力，我国家殊无受其拘束之理由。”

1932年05月18日

发表于 2021-05-18 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年5月18日讯：西兰（西安—兰州）线正式开航。

  • 1932年5月18日讯：浙江安吉县雷雨、飓风、冰雹交加，房屋倒坍无数，屋顶盖瓦吹飞尽殆，拱宸门大石桥亦被折断。

  • 1932年5月18日讯：北平师大学生自治会代表袁永清等，在鼓楼饭店招待新闻界，报告拒绝李建勋，请改任该校同学所拟想之校长。

  • 1932年5月18日讯：何键在衡阳召开上校以上军官会议，布置“剿匪”。

  • 1932年5月18日讯：国民政府任命李默庵为陆军第十师师长，戴民权为陆军第四十五师师长，岳盛宣为陆军第四十六师师长，张贞为陆军第四十九师师长。

  • 1932年5月18日讯：粤空军两队长刘植炎、周柏成通电反对粤空军改编，决然引退。

  • 1932年5月18日讯：胡汉民调停粤海军风潮，主张设江防及海防两司令，由陈策任海防司令兼琼崖特区委员及陆战队司令。江防司令由陈荐人。陈济棠表示接受胡之调停，拟令南路军队中止开拔。

  • 1932年5月18日讯：华侨联合会发表宣言，反对鸦片公卖，要求“制裁一切纵毒敛财之不肖官吏，扑灭一切教唆怂恿主张公卖之无耻民贼，以树民众自决之先声，而挽国族沦亡于一发”。

  • 1932年5月18日讯：国民政府令：《民事诉讼法》定自本年5月20日起施行。

  • 1932年5月18日《申报》：南京息，军息，距海伦南二百里，有日军大部向海伦义勇军进攻，义勇军正与马占山部取得联络，待援中。外传海伦失守不确。（17日中央社电）

  • 1932年5月18日讯：李杜和丁超率领自卫军总部撤至勃利县城，在此发生分歧，李杜前往梨树镇，而丁超转向宝清，从此分道扬镳。

  • 1932年5月18日《申报》：哈尔滨息，松花江之通河日军，前被迫退让，现闻得生力军援助，已复占通河，惟房屋已多被摧毁。昨晚反满军攻击松浦（译音）嗣因哈尔滨派兵往援，故反满军复退走。（16日路透社电）

  • #抗战影像#日本在侵华时期颁发的（伪）满洲国建国功劳章证书。

  • 1932年5月18日《申报》：北平息，第四路义勇军桂林部，1日在鲍庄子，与日军三百余接触，毙敌七十余，获步枪二十余，子弹万余粒。十日在四方台，与日步骑炮联队三百余激战，敌败；旋增援四百余反攻，复溃，损失甚重。11日晚再马家营，与日军七百余冲突，敌死伤过半，余溃散，获机枪三，步枪五十余，子弹万余粒，日旗一，伪国旗三，马刀四十余把，我死伤四十余。13日午，在高岭站，与日联队六百余激战，毙敌百余，获洋马十，战刀二十把，步马枪十余支，子弹千余粒。（17日专电）

  • 1932年5月18日《申报》：东京讯，据哈尔滨访电称，“满洲国”当局与李顿调查团已因马占山问题，发生冲突。调查团拟往晤马，询其意见并采取渠所能供给之任何证据，而“满洲国”当局则反对调查团前往晤马，访电又称，“满洲国”当局指顾维钧博士作政治活动，扬言拟加逮捕。（17日路透社电）

  • 1932年5月18日《申报》头版：援助东北义勇军募捐启事。

1932年05月17日

发表于 2021-05-17 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年5月17日讯：豫南颍河决口，西华、商水等县被淹。

  • 1932年5月17日讯：红军李明瑞部再次占领汝城。

  • 1932年5月17日讯：日军第10师团顺松花江而下，一举突入守备空虚的我指挥部所在地依兰，我军在依兰以西三块石的小股部队做坚决抵抗，依兰部队始得仓皇撤退，所有存储的被服、粮秣、武器弹药和修械所，全部为敌所获。

  • 1932年5月17日讯：萧之楚赴鄂省应城，代徐源泉指挥“剿匪”。

  • 1932年5月17日讯：何应钦在南昌发表谈话，声称：“上年剿匪，调集大军十数万，围剿经年，收效甚微，原因虽多，而我军不注重精神教育实为主因。今后剿匪部队须注意军人精神教育，除去畏匪心理，则战必胜，攻必克。”

  • 1932年5月17日讯：蒋伯诚等奉蒋介石之命赴济南与鲁省主席韩复榘商妥，今后鲁省国税交还中央，鲁军费由财政部拨发。

  • 1932年5月17日讯：陈济棠在西南政务委员会上提议讨伐陈策，委陈章甫为琼崖剿匪司令，拨六个团归其指挥，另派“广金”、“坚如”等舰水陆并进。

  • 1932年5月17日讯：沈阳县长谢桐森与伪满洲国官吏五名及其他人员十余名，谋推翻伪满政府，事泄被捕。

  • 1932年5月17日讯：日军翻译官、朝鲜人金枳率伪警多人往临榆县东八里之乐善堡村，围困、搜查保安团所，抢夺枪 支、弹药，捕去该所人员四人。

  • 1932年5月17日讯：行政院决议，派王伯群视察川、滇、黔军政。

  • 1932年5月17日《申报》：秦皇岛息，沈讯，义勇军司令李文良，13日晚率部六百余人，进袭本溪湖煤矿，行至距矿约20里地方，与驻该处之日守备队，发生冲突，激战三小时，义勇军以援不继，恐被包抄，遂向濮县退却，拟与该处民团联合，再行进攻。（15日专电）

  • #抗战影像#伪满洲图书株式会社发行的国民高等学校及女子国民高等学校使用的满语版本几何课本上册。

  • 1932年5月17日《申报》：哈尔滨息，自卫军宫长海部二千余人，进逼哈东一带，当与伪国警备军第二旅第四团，发生激战。哈市闻炮声，商民极不安，伪国军因失利，改取守势，迄15日晨止，尚在相持中。东铁安达站等处义勇军，集结三千余人，13日起，沿线东进。14日日军派飞机多架侦察，并调十四师团某联队，前往协击。（15日专电）

  • 1932年5月17日《申报》：北平息，驻榆日军确有行动计划，图占榆关车站，并肃清榆境内义勇军，何柱国决以不屈精神，镇静态度，尽守土责，驻秦皇岛日军声明，该处绝对无事，益澄榆关紧张，为预定计划。（16日专电）

  • 1932年5月17日讯：伪满洲国当局阻止国联调查团与马占山会晤。伪外交总长谢介石声言，“如与马占山会晤，不负保护责任”。

  • 1932年5月17日讯：驻沪大场日军自晨7时起分批撤退，至下午1时半撤尽，由江苏保安队进驻接收。

1932年05月16日

  • 1932年5月16日讯：国民党西南执行部及西南政委会召开联席会议，讨论榆关问题等。

  • 1932年5月16日讯：马占山部才鸿猷旅在松浦镇与日军交火，焚毁呼海路局大楼和日军军需库。

  • 1932年5月16日讯：蒋介石中央军校演讲《革命哲学的重要》（后定题为《自述研究革命哲学经过的阶段》），提出要御外侮，救中国，第一就要恢复我们固有的民族精神，尤其是“知难行易”的哲学，为其“攘外必先安内”的国策寻找理论拫据。

  • 1932年5月16日讯：国民党中央政治会议决议：一、关于行政院呈送市、县参议会组织法及议员选举法各草案修正如下：1.市参议会议员应全体由市公民选举；2.市参议会议员任期规定为一年，县参议会议员任期为二年；二、覃振请辞司法院副院长职，慰留；三、特派刘守中赴绥远、察哈尔调查实业事宜。
