1931年12月17日

发表于 2020-12-17 更新于 2021-03-25 分类于 局部抗战(1931-1937)

  • 1931年12月17日讯：张发奎因粤府及第四集团军总司令李宗仁不批准其率部北上援黑，呈请辞去军职，略谓日军“横侵我国，辽吉沦亡，黑垣继陷，中国养兵数百万，无敢言战，坐以待亡，宁非自杀”，并声明虽一再请缨援黑，而出发无期，“再四思维，惟有辞去本兼各职，俾得以国民资格赴难东北”。

  • 1931年12月17日讯：粤国民党中央委员孙科、伍朝枢、陈友仁等14人由沪抵达南京，孙谈此次入京任务在筹备召集四届一中全会，以实现在沪和会之各种决议。

  • 1931年12月17日讯：国民党第四届中央监察委员会召集在京各监委开会，推定林森、蔡元培、张静江、张继、邵力子为临时常委。

  • 1931年12月17日讯：国民党中常会第六次会议决议：一、撤销江西省党政委员会，改组江西省党部，派熊式辉、王冠英、陈剑翛等七人为江西省党务整理委员；二、派陈铭枢、邵力子、吴铁城指导上海党务。

  • 1931年12月17日讯：南京、上海、北平、江苏、安徽等各地抗日救国赴京示威团学生共万余人在南京举行总示威，包围国民党中央党部。党部紧闭大门，学生愤而将悬于大门口党徽砸毁。下午，示威团学生千余因《中央日报》不真实报道学生抗日活动，将报社捣毁。国民党政府出动大批军警镇压，在 …

  • 1931年12月17日《申报》：北平息，哈电，张学良计划付马占山现款45万，15日由中交两行交付。（16日专电）

  • 1931年12月17日《申报》：天津息，据日方消息，本庄繁因蒋下野，华北恐有变动，已急电陆军省，请向满洲增兵两师团，向天津增兵半个师团，提出16日阁议，请求通过。（16日专电）

  • 1931年12月17日《申报》：北平息，熙洽派伪吉黑枢运局长魏宗莲来哈，由张景惠协助提取滨江盐仓存欵60万，商会反对无效，因熙以停止运盐至哈恫吓。（16日专电）

  • 1931年12月17日讯：中国政府照会国联理事，报告日军最近不断制造严重事件，请国联密切关注。

  • 1931年12月17日《申报》：北平息，吉永衡官银号发现伪造哈币，传系日方所为，意在破坏东北金融，为将来把持之地。（16日专电）

  • 1931年12月17日讯：广州学生两万余人前往广州“国民政府”请愿，要求出兵抗日，收复东北失地，请粤中委立即北上与宁方组织统一政府，并要求明令准许学生自由参加救国运动。

  • 1931年12月17日《申报》：哈尔滨息，熙洽令长春县长赵汝栋，与长春日领交涉万宝山案，就地解决。赵知事重，称病不面。（16日专电）

  • 1931年12月17日讯：日关东军司令本庄令独立守备队司令森连指挥所部及混成第三十九旅团、骑兵第二联队进攻昌图、法库；命令第二师团长多门进攻辽中、牛庄、田庄台等地，为进攻辽西作准备。

  • 1931年12月17日《申报》：哈尔滨息，马占山向人谈，当余兵败至蘑菇溪时，有十二、三龄小学生3人，分肩牛肉百斤，向余欢迎，谓来劳军。问欵从何来，答以读书月费积得，谓不惧家中谴责耶。答慰劳战士，人同此心，谴责亦不悔。解囊酬20元，强而后受。俟师至河套，此三生复负肉至，谓酬不敢受，特用以购肉，希得将军饱餐杀敌。余闻之泪下，国人如此相许，余又怎敢相负。

  • 1931年12月17日《申报》：北平息，16午，日机二架，在四洮路飞通辽城，掷弹数枚，一小时后又来日机五架，向城中掷弹25枚，并放机枪。城中居民恐慌，纷向四乡逃走。（16日电）

  • 1931年12月17日《申报》：里加讯，苏俄外交委员会今日发表苏俄对满洲问题添堵之大概，提出可注意之建议，以为应召集远东圆桌会议，以解决远东一般问题。并表示苏俄愿意参加此种会议之意，俟芳泽由法返日道出莫斯科时，苏俄将以此建议请其注意。（16日路透社电）

  • 1931年12月17日讯：日本阁议决定派一混成旅团赴满洲，两大队赴天津；满洲军费增加176万元，天津军费增加40万元。同日，日陆军省发表声明，声称“关东军全部兵力（包括朝鲜旅团）不足以维持满洲之治安，保持帝国臣民生命财产之安固”，决定再由第五师团抽调一混成旅团赴满洲。

  • 1931年12月17日《申报》头版上海昌明电器公司白金怀炉广告：本公司为抵制日货制造一种白金怀炉，玲珑精巧，携带极便，每日用油费洋一分……尤为应时佳品，爱国同胞幸速选购。

1931年12月14日

发表于 2020-12-14 更新于 2021-03-25 分类于 局部抗战(1931-1937)

  • 1931年12月14日讯：日本政府向国联致文抗议中国政府参加抗日宣传，略谓：中国政府教育部曾令大中小学讲授日本侵华史；政府令国民党组织领导抗日会；政府令抗日会筹款五万元援助马占山，此款由扣留之日货拍卖拨充。

  • 1931年12月14日讯：上海各校学生二万余人决定进京示威请愿，要求政府立即动员全国进行抗日，蔡元培电沪各大学校长劝阻无效。是日，示威团首批代表500人乘车离沪赴京。

  • 1931年12月14日讯：济南市学生请愿团在南京举行示威游行，行抵外交部，拟向顾维钧质问，因顾未到部，遂在部长办公楼上及部内各室墙壁上大书“反对秘密外交”等标语。

  • 1931年12月14日讯：特种教育委员会委员长蔡元培在国民政府总理纪念周报告该会任务，谓国难时期学生之爱国运动决不能荒废学业，荒废学业其害“几与丧失领土相等”；为集思广益解决国难时期教育上之种种特殊问题，故设立本委员会，待将来国难会成立后，本会即可取消。

  • 1931年12月14日讯：陈铭枢由南京抵沪与孙科晤谈蒋介石下野及粤中委进京等问题，陈当晚返京复命。孙科电胡汉民及粤各中委从速来沪。

1931年12月13日

发表于 2020-12-13 更新于 2021-03-25 分类于 局部抗战(1931-1937)

  • 1931年12月13日讯：中华苏维埃共和国中央执行委员会非常会议通过《处理反革命案件和建立司法机关的暂行程序》，同日，以第六号训令颁布。

  • 1931年12月13日讯：日本政友会总裁犬养毅组织新内阁，主要成员为：外务大臣芳泽谦吉、内务大臣中桥德五郎、大藏大臣高桥是清、陆军大臣荒木贞夫、海军大臣大角岑生、司法大臣铃木喜三郎。前陆军大臣南次郎及前海军大臣安保清种任军事参议官。14日，荒木声称，今后对华仍将继续执行前任南次郎政策。

  • 1931年12月13日讯：中华林学会在南京举行年会，决议：请实业部迅予成立林垦署；请政府颁布森林法及狩猎法；请政府明文规定各省林业经费至少应占省支预算的百分之五；建议导淮委员会于淮河流域建造大规模之水源涵养林。

  • 1931年12月13日讯：上海暨南大学校长郑洪年发表谈话，认为学生爱国运动“系总理恢复民族固有精神之遗训”，无可非议。

  • 1931年12月13日讯：上海民众反日救国联合会召开全市市民大会，决议：反对锦州设立中立区；反对共管天津；反对中立国调查团赴满调查；民众自动武装起来对日宣战；否认国联对满洲问题决议案。

  • 1931年12月13日《申报》：北平息，打虎山电，洮南治安归张海鹏部下团长李树田维持。市内警宪，均归其节制。张海鹏在洮散传单诋毁万福麟父子，但日人对张，仍派军多名，分驻蒙边督办公署，及漫铁公所，监视其行动。（12日专电）

  • 1931年12月13日《申报》：天津息，日兵近在山海关，积极作军事准备，最近四天内，由津开往武装士兵50余名，军火四百余箱。由秦皇岛运往军火三百余箱，武装士兵80余名。12午又有日兵三百二十名，军火百余箱，由津搭轮赴秦皇岛。（12日专电）

  • 1931年12月13日《申报》：北平息，马占山昨自海伦电平报告，齐克路平靖，日军未积极进攻，本人正与省府委员整理政务，本人日内赴齐克路视察。（12日专电）

  • 1931年12月13日《申报》：北平息，锦州电，驻新日军用现洋二万收买匪首老提子野郎二名，及蒙匪首战北小辫二名，所属股匪，约千七百余名，编为国民自卫军。人马粮秣，日需八百元，迫由当地人民供给。新民辽宁各处日人，制脚镣甚多，用途不详。（12日专电）

  • 1931年12月13日《申报》：北平息，本庄派关东司令干部人员廿一人至哈，名为哈尔滨军事联络员，实则监视张景惠。近张复媚日，将本庄派来人员皆留居公署。每得电令，皆交日人先阅，并同议如何答复。故日军虽未进兵哈埠，哈埠早在暴日掌中矣。（12日专电）

  • 1931年12月13日《申报》：沈阳息，闻新民屯附近之日兵已拆毁该处中国电报局。所有机器皆已拆去，该局已废。资新民屯电局为收发国内外电报之站，而不受日人检查。今此局既废，则沈阳电报必须由沈阳日本邮局或日人现所管理之中国电局发出，故各电皆将受日人检查。（12日路透社电）

  • 1931年12月13日《申报》：北平息，白旗堡站长，电北宁局长称，101次车由该站开行后，突来土匪8名，将住站工人衣服行李财物等件，抢劫一空。全体工人，冒险工作，衣食全无，极不安，请设法接济，否则无法工作云。该局已设法接济。（12日专电）
