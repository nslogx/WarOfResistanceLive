1932年05月26日

发表于 2021-05-26 更新于 2021-07-25 分类于 局部抗战(1931-1937)

  • 1932年5月26日讯：教育部以部令公布《中小学生毕业会考暂行规定》，凡13条，并修正《中小学条例及毕业证书规程》。

  • 1932年5月26日讯：西康民众代表五人向行政院请愿，要求派重兵戡平藏乱。

  • 1932年5月26日讯：何应钦派刘建绪、余汉谋、陈诚分任赣、粤、闽三省“剿匪”指挥。

  • 1932年5月26日讯：邮政工潮和解成立。邮政罢工经中央特派专员陈公博、吴铁城召集各界领袖虞洽卿、王晓籁、杜月笙等及上海邮务工会、上海邮务职工会代表陆京工、朱学范共17人举行会议，签订调解方案如下：一、由地方各界接受邮工所建议之原则，转向政府请愿；二、组织邮政经济制度研究委员会，研究巩固邮政基础方案实施办法，转请政府核夺施行；三、邮工代表允即午复工。罢工委员会发复工通告。下午1时沪邮工复工，其他各地邮工相继复工。

  • 1932年5月26日讯：日本上海派遣军司令白川义则于4月29被炸伤后，是日死亡。其职务暂由第九师团长植田代行。

  • 1932年5月26日讯：日本斋藤内阁成立。暗杀犬养毅案责任者陆相荒木贞夫留任原职。

  • 1932年5月26日讯：国联调查团由沈阳到达大连，往访“满铁”总公司，听取有关地方设施及铁路问题之说明；并与由北平来大连之英国公使蓝普森会见。

  • 1932年5月26日讯：郭泰祺昨晚到南京，是日分谒蒋介石、汪精卫、罗文幹，报告上海停战协定签字。

  • 1932年5月26日《申报》：南京息，马占山部焦、吴两团电京称，奉命协同丁李各军攻哈之际，日军绕我后方，进犯通河，大肆荼毒。我团闻悉，率部回援，分布郊外，于夜间乘敌炮载登航之时，突起包围痛击，毙敌无算，夺获械弹甚多，刻正追击中。（25日中央社电）

  • 1932年5月26日《申报》：哈尔滨息，本庄到哈后，战事突紧张，23日晚起，哈西北方炮声极密。今晨道外完全闭市，由伪警及日逆各军检查行人，少壮华民被诬为义勇军便衣队，多遭捕杀。（25日专电）

  • #抗战影像#伪满洲国陆军装备的奥斯丁式轮式装甲车 1:35模型彩绘图。

  • 1932年5月26日《申报》：哈尔滨息，马占山及丁超李杜各部，沿呼海东铁两线，向哈急进。日机今晨飞兴隆镇等处侦察，被马部战斗机追击逃归。对青山安达站间路道，全被自卫军拆毁，哈西北方战事刻尚未息。（25日专电）

  • 1932年5月26日《申报》：各国组织之共同监视撤兵委员会，暨国府组织之撤兵区域接管会，连日接收被日军侵占区域以来，进行迅速顺利。至昨日已成最后接收之一日，计吴淞镇宝山县及吴淞要塞炮台、兵舍、三官堂、药库等五处，俱已接收完毕。其余吴淞江湾引翔及闸北与租界毗连地带四处，按照停战协定附件第一项，为日军撤退中之暂驻地段。但据日方宣称，亦允于6月2日完全撤尽。届期谅必可完全接收被占数月之沪嘉淞宝，自此可告一结束矣。

  • 1932年5月26日讯：沪撤退区域接管委员会召集会议，讨论恢复日军暂驻区域（包括引翔区、殷行区、江湾区、吴淞区、虹镇区暂时驻扎仍未撤退之部分）市行政权事宜，决定28日起次第实行。

1932年05月25日

发表于 2021-05-25 更新于 2021-07-25 分类于 局部抗战(1931-1937)

  • 1932年5月25日讯：驻齐齐哈尔马占山部旅长程志远投敌，进攻呼海路沿线马军，是日，日军占领呼兰，马占山部北退。

  • 1932年5月25日讯：长沙学生抗日救国会定于26日总检查仇货，将已登记贴花之仇货一律封存。何键为此查封学生抗日救国会，宣布戒严令，各校禁止学生外出。29日，长沙各校学生代表开紧急会议，要求省政府于6月1日前启封学生抗日救国会。

  • 1932年5月25日讯：南京各校抗日会举行慰劳抗日将士大会，第十九路军及第五军连长以上军官百余人，各校代表百人出席。

  • 1932年5月25日讯：蒋介石电蚌埠第四师师长徐庭瑶，蚌埠及皖北所有鸦片税收机关一律禁止。又电陈调元、吴忠信、徐庭瑶，皖北盐斤附加，自26日起一律取消。

  • 1932年5月25日讯：胡汉民在香港发表谈话，谓“自十七年来，均为军阀之治，而非党治，今欲救国，必先救党”。

  • 1932年5月25日讯：萧佛成电促第十九路军军长蔡廷锴即动员所部入闽“剿匪”。

  • 1932年5月25日讯：下午5时，吴铁城、杜月笙邀各界领袖及邮工代表集议解决邮潮。

  • 1932年5月25日讯：杨杏佛致书国民党中央政治会议，指责“政府屡言大赦政治犯，至今口惠而实不至”，要求将牛兰释放。

  • 1932年5月25日讯：上海邮务工会、上海邮务职工会罢工委员会通告，非得本会命令，一律不准复工。

  • 1932年5月25日讯：行政院长汪精卫电各省、市政府，谓“沪邮务员工关于要求邮工待遇者，均经交部酌予容纳。关于归并储汇局及停止航空邮运经费，关系国家行政及交通建设事业，自应从长计议，非该部所能解决”；“如已实行罢工，应限令二十四小时内复工，逾限一律开革”。

  • 1932年5月25日讯：北平保安队接收吴淞，炮台、兵舍及火药库同时被接收，炮六尊被日军运走。宝山县城亦于上午11时半由宝山县长孙熙文偕江苏省警接收。

  • 1932年5月25日《申报》：日内瓦讯，今日此间忽起一惊人谣言，据称，辽案调查团拟将满洲置于国际联盟管理之下，五调查员委员将一切辽案因果，加以相当考虑后，认为解决目前僵局，唯有将其置于国联管辖。该调查团九月间送出之最后报告内，将详论此事。至其计划内容，据称，拟设一行政委员会，以张学良为领袖，由英法中日或再加二三国代表为委员。此委员会将对于国际联盟负责云云。惟此次谣言，在日内瓦方面尚未能证实。询问国联秘书厅要人，均称完全不知此事。（23日国民社电）

  • #抗战影像#伪满洲国发行的明信片，主题为“哈尔滨的夜色”。 几位粉丝帮忙确认明信片中建筑物为秋林公司，感谢！

  • 1932年5月25日《申报》：北平息，本城消息，马占山昨有通电到平，原电如下：日军前曾一度侵入通河，经我军焦团长景彬、吴团长凌汉,率部痛击败退。日军自受创后，又由哈增调大批援军，水陆俱进，焦吴两部迎击，激战十余小时，双方肉搏，卒以敌方炮火甚烈，我军不支退出。是役毙敌少佐一员，大尉四员，中尉二，士兵约七十余人。我军阵亡步兵五团上校团长吴凌汉一员，中校团附张兴华一员，少校队长二员，上尉分队长六员，伤亡兵士百余名。我军大部现正退集离城十余里之三站，积极整理，准备反攻。（24日专电）

  • 1932年5月25日《申报》：侵沪日军，逾已络绎奉命撤退，留沪日军，且已不足半数。日政府前曾命驻沪日军，于一月内完全撤退，当经本月十日，共同委员会日方委员正式通知该会全体委员、并我方委员，并表示撤退日期，或可不逾一月。兹据正式消息，日方已决定于6月2日止，将驻沪日军，完全撤退。上述撤退地点，所有停战会议小组委员会决定之闸北、殷行、引翔、吴淞四处暂驻地点，亦属包括在内。下月3日起，日方只有少数陆战队留沪，可完全恢复1月28日以前原状云。

  • 1932年5月25日讯：宋子文由沪返京，向中央报告淞沪战区善后会讨论经过，并接洽筹划财政办法。

  • 1932年5月25日讯：全国商会联合会、沪市商会、沪银行业同业公会、沪钱业同业公会发起组织“废止内战大同盟”，发表通电，声称：“鉴于内忧外患之严重，特发起废止内战大同盟会，以期安内对外”，并制定章程十条。沪银行界吴鼎昌、张嘉璈、陈光甫等18人电平、津、汉、宁、穗等各地名人征求加入。

  • 1932年5月24日讯：交通部招待新闻界，次长俞飞鹏声称：“工会对此次沪邮罢工应负责任。中央早已取消工会组织……不知何来邮务总工会之名目”；邮工“干涉国家行政制度，不能允许，所谓巩固邮基方案，根本不能提出，在此国难期中罢工，尤为绝大错误”。

  • 1932年5月24日讯：下午3时，国民党中常会讨论沪邮工潮事，决定交民运会依据《工会法》分别处理。

  • 1932年5月24日讯：行政院决议：邮政总局局长钱春祺免职，听候查办，任命黄乃枢为邮政总局局长。

  • 1932年5月24日讯：杨行、狮子林炮台日军于正午12时撤尽，由江苏保安队接收。

  • 1932年5月24日《申报》：哈尔滨息，今日哈埠闻枪炮之声，甚为清晰。因昨夜开始在呼海路附件之战事，今仍在进行中。反满军力攻“满洲国”之军，双方迄今尚未分胜负，距哈埠西约60里亦有战事，战区难民线纷拥入哈。距哈埠西15里之中东铁路，今日为反满军拆毁一段。中东铁路东段仍有不清消息传来，反满军在1386公里处轰击货车，重伤铁路华雇员一人，又匪众曾袭击铁路货栈数次。据日人所办俄文报纸载称，黑龙江当局出示，生擒马占山将军者赏十万元，得其尸者赏半数。（23日路透社电）

  • #抗战影像#“一二·八”事变中死去的两名中国军人，被安置在同一口棺材内。

  • 1932年5月24日讯：敌第14师团28旅团从呼兰出发，向马占山部队海伦攻击前进。第27旅团则从哈尔滨出发，在肇东一带扫荡作战。

  • 1932年5月24日《申报》：汉城讯，此间今日接讯，非正式军二千五百名协同匪队进攻珲春，情势危急。该处（伪）满洲国军队闻风退走，故日韩侨均已逃避朝鲜境。朝鲜总司令林氏现游于（伪）满洲，闻此警耗，赶回汉城，今夜可到，闻边界卫队已有奉命开往乱区者。（23日电路透社电）

  • 1932年5月24日《申报》：沈阳息，本庄关东军司令官，22日晚9时20分，由沈阳出发，乘火车往哈尔滨，指挥作战。（23日电通社电）

  • 1932年5月24日讯：上海各民众团体联合会通电全国，对否决弹劾汪精卫案提出：一、应由各团体环请立法院切实声明关于上海中日停战协定全部无效；二、应由各团体环请监察院继续提出弹劾，责成汪精卫引咎自劾，否则应处以法律相当惩戒。
