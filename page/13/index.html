1932年03月18日

发表于 2021-03-18 更新于 2021-05-17 分类于 局部抗战(1931-1937)

  • 1932年3月18日讯：沈阳城内工业区大火，延烧400余家。

  • 1932年3月18日讯：上午，国联调查团接见日外相之代表松冈洋右及海军第三舰队司令野村。晚，赴上海市商会邀宴，主席王晓籁演说，对日人突然用兵占据满洲事详为批驳。李顿答词声明：“在国联公断以前，必尽量容纳双方意见，务使中国不因信赖国联反而吃亏。”

  • 1932年3月18日讯：福建省工农兵苏维埃第一次代表大会在汀州开幕，21日闭幕。大会通过土地问题、劳动问题、财经问题、苏维埃建设问题等决议案。通电拥护中华苏维埃中央政府对日作战的决议。宣告成立福建省苏维埃政府，选举张鼎丞、张思垣、范乐春、郭滴人、李六如、罗明、谭震林、罗炳 …

  • 1932年3月18日讯：北平纪念“三一八”惨案市民大会，因军警阻挠未开成。

  • 1932年3月18日讯：北平日军百余名荷枪实弹，并携大炮，经东长安街出地安门，游行示威。

  • 1932年3月18日讯：锦西义勇军800余名占领连山。

  • 1932年3月18日讯：北平市商会发表《告平津商胞书》，称“妻子且不保，何爱于金钱；尸骨且无托，何忧乎生计”，要求商胞宁死勿购日货。

  • 1932年3月18日《申报》：东京讯，据长春消息反对满洲新政府之大军，昨晚攻击距哈尔滨西南百里之伯都纳而占据之，攻军曾利用重炮队作战。伯都纳又名新城，为松花江右岸繁盛之商业中心点，自满洲各地军队起抗新政府后，此城之陷落，最关重要。（17日路透电）

  • #抗战影像#1932年3月18日，在“一·二八事变“庙行镇战斗中负伤的日军被运回日本东京。

  • 1932年3月18日《申报》：北平息，黑龙江各军反马空气浓厚，省内暴动有扩大势，马与臧倾轧甚烈，伪阁将改造，东北民众组织救国军，一路沿北宁线，一路向石门寨方面出动。（17日专电）

  • 1932年3月18日《申报》：北平息，本庄因辽西义勇军大举动员，急电前调赴黑吉日军连开新民集中。沈四郊义勇军颇活跃，拟向城内攻击，驻沈日军仅两个联队，义勇军拟乘势分三路攻沈。人数共数万，一路由锦县袭新民，二路由沟帮子袭营口，三路出彰武法库康平，分路前进，关外所悬伪国旗…

  • 1932年3月18日讯：国联秘书长德鲁蒙分函中日代表，请双方向国联特别委员会报告对决议案实行程度及准备采取之步骤。

  • 1932年3月18日讯：鄂省立各校代表400余人，齐集省府请愿拨发教费。

1932年03月17日

发表于 2021-03-17 更新于 2021-05-17 分类于 局部抗战(1931-1937)

  • 1932年3月17日讯：伪满洲国在长春设中央银行，溥伟任总裁。

  • 1932年3月17日讯：上海糖业同业公会因糖类新税则较原有税率陡增一倍，电宋子文请暂缓执行。4月2日，财政部批复不准。

  • 1932年3月17日讯：陈济棠发表告第一集团军将士书，声称：一、此次“剿匪”系下大决心，非达到成功，誓不回师；二、“剿匪”与抗日同样重要；三、“剿匪”是打倒赤俄的间接侵略。

  • 1932年3月17日讯：吴铁城答拜国联调查团，称“日本允撤兵至租界内，停战会议在调查团离沪前可开成”。午，上海报界宴请国联调查团，《申报》馆经理史量才致词，声述日人压迫中国舆论情形，请调查团维护公理与和平。晚，应顾维钧邀宴，顾演说希望调查团对中国人民对中日关系的愤慨表示，作进一步研究。

  • 1932年3月17日讯：行政院会议决议：一、简派胡世泽、谢东发为第十六届国际劳工大会中国代表，并拟指定胡为第一代表（19日国民政府明令发表）；二、请任命程天放为国立浙江大学校长；三、中央大学每月经费16万元，自2月份起，一并暂由财政部拨发。

  • 1932年3月17日讯：东北各法团自北平电沪国联调查团，声述暴日侵略蹂躏东北真相，表示爱护乡土决心，请主持公道，使东北问题早日得公平合理解决。

  • 1932年3月17日《申报》：北平息，外人电，伪国用人不分国籍，各机关正式官吏人选，无论日人鲜人，一律录用。伪外长谢介石日内将有通牒致国府溥仪弟溥杰今午抵长春，反吉军再乌珠河设步哨线，同宝附近亦有反吉军三千五百名。（16日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，日本海军陆战队某中队重机枪组在其指挥官太田大尉率领下在前线作战，机枪手操作的是大正三年式6.5毫米重机枪。

  • 1932年3月17日《申报》：前晚19路军驻沪办事处前方来电如下：1）敌军数百人向太仓前进，未久即退去；2）法参赞何伯玛上校，到前线参观。昆山16日电云，法参赞与铣晨10时许到昆，由总部派副官陪住常熟太仓一带视察，意参赞亦将到处。

  • 1932年3月17日《申报》：北平息，外讯，伪满叛党决将长春改名为新京，满洲里日侨66名，今赴哈避难，锦州日守备队，13、14日与义勇军激战，首山堡西北方之王树屯义勇军亦与日军接触，日军受创甚重。（16日专电）

  • 1932年3月17日讯：据外交界消息：上海事件连日经各方斡旋，中日双方代表会晤结果似较前进步，但日方仍坚持我国不能驻兵上海。外部已训令我方代表，略谓“日方如有和平诚意，则谈判不妨开始，惟须坚持立即停战，及日军无条件全部撤退至1月28日以前原防”。

1932年03月16日

发表于 2021-03-16 更新于 2021-05-17 分类于 局部抗战(1931-1937)

  • 1932年3月16日讯：北平民众团体救国联合会成立。

  • 1932年3月16日讯：广东第一集团军余汉谋等以全体将士名义通电讨共，声称“非抗日无以救亡，非剿共无以抗日”。

  • 1932年3月16日讯：重庆各界122个团体，向第二十一军军部请愿，请刘湘出兵救国。

  • 1932年3月16日讯：北平大学教授抗日会电促各省军事长官积极抗日，万勿妥协。

  • 1932年3月16日讯：日机第五次飞杭州侦察。

  • 1932年3月16日讯：日舰载第十四师团工兵及军械到沪，次日又有师团直属部队到沪。

  • 1932年3月16日讯：李顿调查团委员分访英、美、法、意、德五国在沪公使、代办及海军司令，咨询上海事变之事实，并在旅寓华懋饭店接见各国领事搜集调查材料。

  • 1932年3月16日《申报》：哈尔滨息，东铁监事张恕，吉长官署参议李桂林，奉熙洽命，以友人关系，再赴珠河晤丁超、李杜，定14日前往，丁李来电允一见熙洽。（14日专电）

  • 1932年3月16日《申报》：北平息，外讯，伪满叛党决采金本位制，并着手编制大同二年度预岁出，总额概算为一亿二千万元，拟发公债与大借欵。（15日专电）

  • #抗战影像# “伪装的亲善“——1932年“一·二八淞沪抗战”期间，日本为了掩盖和美化侵略，拍摄的日本陆军士兵与中国儿童在一起的照片。

  • 1932年3月16日《申报》：东京讯，满洲国成立后，曾发表请求各国承认之通电，东京正在观察国际间之反响，对于苏俄态度尤为注意，长春方面蓄意将前南京所委派之中东路华董撤职，另行改委，故众料苏俄于此，即可表现态度。（15日路透电）

  • 1932年3月16日《申报》：北平息，榆关电，关外义勇军连日极活跃，大举破坏伪丰山路，连山附近铁路已被拆毁数段，14日辽宁至榆关火车不通。（15日专电）

  • 1932年3月16日讯：国民政府特任蒋中正兼参谋本部参谋总长，原任朱培德辞职照准；特任朱培德为军事委员会办公厅主任；任命吴奇伟为陆军第九十师师长。

1932年03月15日

发表于 2021-03-15 更新于 2021-05-17 分类于 局部抗战(1931-1937)

  • 1932年3月15日讯：3月11日天津《大公报》之《军事周刊》第七期因载《枯树又萌芽》讽刺画，讽刺日本发动侵略战争，日领向天津市府抗议，是日市府将该刊查禁。

  • 1932年3月15日讯：广州公安局军械库被人掷弹炸毁。

  • 1932年3月15日讯：伪满洲国决定将长春改为“新京”。

  • 1932年3月15日讯：山东省政府主席兼第三路总指挥韩复榘电国民政府、行政院请辞本兼各职，推荐省府委员兼民政厅长李树春继任主席，师长孙桐萱、曹福林择一任总指挥。

  • 1932年3月15日讯：上海律师吴迈前曾赴上海公安局要求保释中学生联合会学生，与该局发生冲突，竟被扣押，是日被解送南京卫戍司令部。16日，上海各界人民团体纷纷开会，通电要求释放吴迈。

  • 1932年3月15日讯：粤政务会议议决发行国防公债3000万元，作要塞设备用。

  • 1932年3月15日讯：汪精卫、朱培德、陈铭枢、李济深、王柏龄等赴昆山前线劳军。

  • 1932年3月15日讯：吴佩孚通电全国国民，申述救国大计，主张“动员全国之兵，以谋抵御，从速化除一切党派意见，与全国人才共图建设”。

  • 1932年3月15日讯：据《大公报》讯：日方在前线实力分配：正式陆战队5000人，由近卫师团改编之陆战队1.5万人，第十二师团1.5万人，第九师团战时编制2.5万人，第十一师团、第十四师团战时编制四万人，飞机200架，轻重炮350门。

  • 1932年3月15日讯：日机飞苏州、昆山侦察并扫射。

  • 1932年3月15日《申报》：哈尔滨息，黑河驻防黑军队第3旅，11日早树自卫军旗，反马占山。据黑河沿边六县抗马，丁超率大部队退密山宝清屯驻，待机就地筹饷抗熙洽。日第二师团拟调大队开宝清击丁超军，敦化战事12日晚停，王德林率救国军退往蛟河。（14日专电）

  • 1932年3月15日《申报》：北平息，外讯，伪国交通政策，决遵守中日间缔结之修筑满蒙五铁路条约，完成汽车站，统辖邮电各机关，并编订教科书，删除爱国材料，通令各校以日语为必修科。伪外长通电日英美等38国，要求承认，并向日政府要求开始外交关系。（14日专电）

  • 1932年3月15日《申报》：东京讯，参谋部副大臣，今晨觐见日皇，众信系请日皇核准撤回上海金泽师团与一混成旅团事，撤回此项军队之命令，明日可望发表。（14日路透电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，几名日本海军陆战队员用担架抬着一名受伤的同伴。

  • 1932年3月15日《申报》：国联调查团，昨已抵沪，在此间约有一星期之勾留，并将往闸北、吴淞、江湾等战区视察。闻日本军事当局，希图掩饰团员耳目起见，已于最近两日中，命闸北等处之驻军暂为隐藏撤退，并利用汉奸，在各处要隘屋顶，悬挂中华国旗，以示无占领我土地之野心。又将北区及虹口一带与华…

  • 1932年3月15日《申报》：国联辽案调查团，昨已由日抵沪，上海日军，近虽宣称和平，而援兵仍继续开来，惟为掩人耳目，不使扩大战区痕迹，为委员团所知，赶将已到吴淞口外陆军，乘委员团未到之先，运到上海，一面又将浦江大队日舰，暂时开往他处。

  • 1932年3月15日讯：国联调查团访宋子文、顾维钧、吴铁城，顾开茶会招待，吴设晚宴。李顿招待中外记者，表示调查团对上海之停战十分关心，如果列强同意，准备参加和议谈判。
