1932年11月13日

发表于 2021-11-13 更新于 2022-01-13 分类于 局部抗战(1931-1937)

  • 1932年11月13日讯：苏炳文正式宣布拒绝与日人进行和平谈判，并否认谣传愿与日本在苏联境内进行和平谈判之消息，称“未与日人有任何接洽”，日人提议和平谈判，“决不给以答复”。

  • 1932年11月13日讯：红军徐向前部自鄂、豫、陕交界之南化塘地区西移，是日在漫川关突围入陕境。15日到达离商县50余里之杨家斜。

  • 1932年11月13日讯：蒋介石以第十师第二十八旅旅长刘戡在鄂“剿共有功”，着调升第八十三师师长。

  • 1932年11月13日《申报》：北平息，外讯，齐克路附近日满军与救国军仍激战中，最烈者为泰安镇，拉哈站以北宁年可闻炮声，富拉尔基昂昂溪仍在包围，日满军已派飞机援军解围，日内战事即爆发。（12日专电）

  • 1932年11月13日《申报》：北平息，吉林救国军王德林，8日电平称，5日率部三千抵达高岭子，与郑指挥会商，6日晨猛攻高岭子。日军虽有机枪护守，但敌仅数百，6日午退却。我军将敌机枪夺获，敌大溃，俘虏百余人，当即枪决，获军需品甚多。刻在整饬部队，向苇河推进中。（12日专电）

  • 1932年11月13日《申报》：北平息，苏炳文军近在中东线富拉尔基，与日军相持。苏本人驻在海拉尔，张殿九驻扎兰屯，总部参谋长谢珂，在扎兰屯指挥军事。义勇军李海青部在江桥附件，活动甚力，东路马占山部徐子鹤宋喜和部两旅，已在平宽甸集中，准备向拉哈站进攻，马占山似在拜泉方面。（12日专电）

  • #抗战影像#“一·二八事变”中，一队日本陆军士兵匍匐在地面上准备向中国守军防线发起进攻。注意近处日军持有类似“肉弹三勇士”使用的那种爆破筒。

  • 1932年11月13日《申报》：哈尔滨息，10日对太河原支队之攻击，顽强对抗，卒被日军占领之后腰库勒。日军入城后，调查之结果，知系由苏炳文部下黑龙江省第二旅及红枪会二千所扼守。检查捕获品，始知彼等有（日制大正）三年式（重）机关枪，其他最新式武器。其阵地之壁脚，筑有纵深各三米之外壕，城璧施有角面堡式防御，盖筑造极坚固之阵地。因此日军损失巨大，致战死20名，负伤50名。（12日电通社电）

  • 1932年11月13日《申报》：北平息，辽吉黑民众后援会军息，兹据通讯员孙德建报告称，1）我军于本月5日早5时，克复大孤山。此役伪军司令李寿山中弹负伤后吞金而死。原因在后方日军压迫过甚，前方攻击甚烈，退却不能，投降不得，而伪军家眷，又被日军看守，已置李寿山于死地。故我军乘胜追击，伪军及日军大败，因而携械来降者，约有三团之众。击死伪军及日军三百余人，俘虏日军57名，获敌机关枪两架，步枪三百余枝。2）现在我军兵士棉衣已着，惟以该处天气突寒，时已降雪，手足为之冻脱者，数见不鲜，状极可怜。（12日专电）

  • 1932年11月13日讯：交通部发现招商局总经理兼董事长李国杰与交通部次长、招商局监督陈孚木以招商局栈房、码头等财产向美商中国营业公司押借3000万元，是为非法，是日，上海市政府奉行政院代院长宋子文手谕，将李暂行扣押。李将向交通部招商局监督处呈文及陈孚木9月3日批复指令发表。

  • 1932年11月12日讯：伪满监察院长于冲汉在大连病死，以罗振玉继任伪监察院长。

  • 1932年11月12日讯：湘鄂西省苏维埃主席崔琪在湖南洞庭湖区游击战争中牺牲，是日在长沙悬首示众。

  • 1932年11月12日讯：韩复榘军总部参谋长刘书香及第二十九师师长曹福林，指挥所部分返原防。13日，韩军全撤潍西。

  • 1932年11月12日讯：“剿匪”总部电令豫、鄂、皖各省，限本月内肃清各该省红军。

  • 1932年11月12日讯：国民政府新建之中央广播电台在南京开幕，并正式播音。

  • 1932年11月12日《申报》：天津息，救国军邓铁梅部千余，一日夜12时，在安奉路凤城高丽沙间施行破袭工作，焚毁桥梁，割断电线，拆毁路轨。同时一部潜入城内扰乱并袭击铁路地带，战甚烈，我军与敌逆方面互有伤亡。二日晨两时，我军稍退。迄7日凤城附近仍被我包围，敌逆日夜戒备，日侨纷掘地洞避难。（11日华联社电）

  • 1932年11月12日《申报》：北平息，哈讯，日军因苏炳文不与妥协，决调大军向扎兰屯宁年克山进攻，欲以武力威胁苏屈服。日军第14师团之一部五千余人，已向龙江集中，开往富拉尔基，同时苏部亦在宁年集中，严阵以待，大战即将开始。（11日专电）

  • 1932年11月12日《申报》：长春息，据日关东军公告，10月中对义勇军作战28回，日军死59人，重伤93人。（11日华联社电）

  • #抗战影像#日本开拓团移民在掠夺我东北的所谓“千振乡”土地上犁地耕种。

  • 1932年11月12日《申报》：北平息，救国军南廷芳，在拉哈站北四十里地点，与日军黑田部队激战10余小时。日军本川来援，黑田部撤退，南（廷芳）部与本川部部相搏10余小时，旋有日机助战，南军暂退，刻两军仍在拉哈北相持中。（11日专电）

  • 1932年11月12日《申报》：齐齐哈尔息，苏炳文及张殿九对日军态度颇强硬，由满洲里海拉尔方面，陆续运兵至富拉尔基前线。日驻富拉尔基军及冈原部队，茂木骑兵部队，今晨开始攻击苏（炳文）军集结地点。（11日日联社电）

  • 1932年11月12日讯：国民党中央在南京举行孙中山诞辰纪念大会。各地机关、学校奉令不放假，不开民众大会，仅由国民党党部召集各界代表举行纪念会。

  • 1932年11月11日讯：外交部长罗文幹代表国民政府电贺罗斯福当选美总统。

  • 1932年11月11日《申报》：北平息，义勇军连日袭击锦县城，日军及伪警在城内抗守，自7日后，均有激战，日军以巨炮轰击锦县城外村庄，锦县城内民团响应义勇军，数度放火焚烧，各处已陷混乱。（10日专电）

  • 1932年11月11日《申报》：北平息，辽吉黑民众后援会军息，顷据哈尔滨专员8日电称，苏炳文部一二两旅约一万人，沿泌淋河上游向契子山腰库勒等处推进，包围富拉尔基，当在哲奴岗腰库勒，与敌中山支队二千余相遇，激战一昼夜。敌伤亡70余名，苏部伤亡20余名，敌向蘑菇溪退却，苏部尾追，并向富拉尔基推进等语。（10日专电）

  • 1932年11月11日《申报》：哈尔滨息，马占山部在兴安岭与苏炳文军已联成一气，马部分但海拉尔以西苏部分担海拉尔以东，富拉尔基拉哈等地为张殿九军防地。义勇军联络完成，给日本以莫大打击，日军计谋中之苏炳文妥协已成空梦。（9日华联社电）

  • 1932年11月11日《申报》：北平息，四洮车已不通，日军虽全部集中北满，以义勇军四出，大有疲于奔命应付不暇之势。（10日专电）

  • #抗战影像#一名关东军炊事兵正在为雪地中的关东军士兵分发食物。

  • 1932年11月11日《申报》：北平息，义勇军李赐如部李海峰部，7日晚占领班吉塔，距锦州仅30里，稍补充即开始攻锦。（10日专电）

  • 1932年11月11日《申报》：北平息，交通界息，1）朝阳寺南岭北票一带，连日大雪，日军不耐严寒，已失防御能力，义勇军开始大活跃，义县日军已被包围，激战甚力，日军死伤极多。2）义勇军连日袭击锦县，日军及伪警在城内扼守，城外村庄，城内民团，时起响应，曾数度放火焚烧各处，锦县已陷于混乱状态。（10日专电）

  • 1932年11月11日讯：义勇军第二军团总指挥李纯华率领31人，押运救国会和后援会援助的迫击炮、机关枪及弹药一批由北平运至沧县歧口装船，冒险偷渡渤海运往东北。（后于30日在邓铁梅部控制的枣儿沟成功登陆。）
