1932年10月19日

发表于 2021-10-19 更新于 2022-02-25 分类于 局部抗战(1931-1937)

  • 1932年10月19日讯：晚，陈独秀、彭述之解往南京。20日到京，在军政部军法司拘押。

  • 1932年10月19日讯：国民党中央政治会议通过监督地方财政暂行法原则五项、调节民食意见九项，交行政院办理。

  • 1932年10月19日讯：国民政府公布《统计法》。

  • 1932年10月19日讯：四川旅京同乡会电川人速集合各地民团武装制止川战，继之罢市、罢工，最后抗捐、抗税，绝彼财源，促其自毙。

  • 1932年10月19日讯：国民政府及蒋介石再电刘湘武力制止川乱，刘遵命准备。

  • 1932年10月19日讯：胶东13县代表李玉洲等通电，谓五年来刘珍年在胶东勒捐巨款共达五六千万元。

  • 1932年10月19日讯：何应钦电令韩复榘、刘珍年限期撤驻原防，听候中央处置。同日，何电令刘珍年，该师暂驻福山、掖县、莱阳、栖霞、牟平五县及龙口，严饬军纪，维持治安，关于地方民政、财政，完全由省政府主持，毋稍干涉，以明权限。次日，刘接受命令，所部暂驻掖县、莱阳等五县。

  • 1932年10月19日《申报》：北平息，马占山部东路军7日下总攻击令后，西路苏炳文部，亦同时进攻，对黑省垣取大包围攻势。日军恐后路截断，将兵力向齐哈间移动，省城内日军，仅留二百余人。日军平松旅团，移至昂昂溪，义勇军李海青部，16日早再向昂昂溪进攻，因日军戒备甚严，旋自动撤退。（18日专电）

  • 1932年10月19日《申报》：大连息，沈阳市政公署向南满铁公司借欵二百万元，以自来水收益为抵押。闻条件已商妥，日内可交欵云。（18日华联社电）

  • 1932年10月19日《申报》：沈阳息，日关东军司令部今日令金璧东与其妹川岛芳子，由黑垣赴满洲里，求见苏炳文，恳求以政治手段解决黑省之反正。金兄妹乃清室某亲王之子，自辛亥革命后，专为日军部担任军事侦察。（18日华联社电）

  • #“利济”舰起义# 1932年10月19日凌晨2时许，停泊在富锦附近江面的伪满洲国海军江防舰队“利济”号炮舰发动抗日反满起义。舰长范杰领导起义官兵将舰上2名日籍海军人员击毙投入江中，继而直驶同江。因为担心伪满洲国江防舰队与日军追击，“利济”舰实力难敌，起义官兵将舰上火炮、机枪拆卸上岸，弃舰登陆投奔李杜自卫军路永才部，被整编为自卫军海军筹备处。“利济”舰后被伪满洲国江防舰队拖回，重新入列。但“利济”舰起义在“建国”不久的伪满洲国引起巨大轰动，打击了伪满政权。 舰长范杰与起义官兵在1933年日军大扫荡时被迫同抗日武装一同退入苏联境内，一度滞留西伯利亚，后由苏联方面送至新疆塔城回国。由于他们坚持要归建东北海军作战，不愿留在新疆军阀盛世才处效力，范杰率部秘密化装离境，重新穿越苏联，取道海参崴乘船抵达上海。再由上海辗转到达青岛向当时的中国海军第三舰队（前身是东北海军）司令部报到，后来参加了保卫长江马当要塞等作战行动，大部分在战斗中殉国。 范杰等东北海军爱国官兵为了追寻自己中国海军的身份，履行海军卫国御敌的职责，途径万里的归队行动，在中国海军抗战史上留下了充满传奇色彩的一页。

  • #参战装备#伪满洲国“利济”号炮舰：1932年2月15日，“利济”号随同东北海军江防舰队投靠日军，舰队在同年5月28日更名为“满洲国海军江防舰队”。因为投敌前该舰武备已拆卸无存，日方提供武器对其重新武装，改为1门日制76毫米主炮（日本海军称为“八厘炮”，是当时日本海军江川炮舰的标准主炮）和1挺日式6.5毫米重机枪。该舰在改装后主要负责护卫装运日伪步兵的船只沿松花江航行巡弋，威慑沿岸的义勇军抗日武装。使得舰上有民族血气的官兵倍感羞耻和愤恨，最终爆发了“利济”号起义事件。

  • 1932年10月19日《申报》：东京讯，（日本）外务省接苏俄传来消息称，苏炳文将军共拘禁日侨二百四十名，现确悉死者仅有三人，但余人之生死，未能查明云。日政府因自苏炳文将军反正后，满洲里一带之大局情形，茫无所知，故已命伯力日领事署派员就近调查。闻苏俄当局已请苏炳文将军释放所拘日侨，而许彼等至苏俄境内平安地点。现信死者三人中，内有不知姓氏之美人一名。（18日路透社电）

  • 1932年10月19日讯：辽宁民众自卫军唐聚五部遭到日本关东军和伪满洲国军夹击，其内部亦有叛军出现，部队处于崩溃状态，唐聚五只身化装入关，其所辖自卫军，一部约3000余人郭景珊率领下化整为零退入热河，其余大部溃散。

1932年10月18日

发表于 2021-10-18 更新于 2022-02-25 分类于 局部抗战(1931-1937)

  • 1932年10月18日讯：广西右江革命根据地创始人之一、右江独立师师长韦拔群在东兰西山遭叛徒杀害。

  • 1932年10月18日讯：红军占领江西黎川、福建建宁。

  • 1932年10月18日讯：行政院决议，派颜惠庆、顾维钧、郭泰祺为国联特别大会代表，颜任首席代表。

  • 1932年10月18日讯：蒋介石拟具鲁战解决办法，由行政院分电韩复榘、刘珍年切实遵行，内容为：指定莱阳、牟平、烟台等五县为刘军驻地，所有政权交还鲁省政府，刘部让出之其他防地，交“民团”负责守备；韩部须退出潍县以西。

  • 1932年10月18日讯：国民党西南执行部、政委会分电鲁省韩复榘、刘珍年及四川刘湘、刘文辉，劝各消除成见，克日息争，协力御侮，以救危亡。

  • 1932年10月18日讯：刘湘部全线出动，派王缵绪、唐式遵、潘文华三师长分任川东各路指挥。北路指挥王缵绪协助李家钰、罗泽洲攻顺庆、遂宁，中路指挥唐式遵攻永川、江津。双方伤亡甚众。

  • 1932年10月18日《申报》：北平息，黑军濮炳珊旅已加入齐克线作战，马部宋和青团克复泰安镇，前线正向黑省垣推进。马占山由南路转赴拜泉督师，义勇军李海青南廷芳两部，潜伏省垣活动，卜奎伪警备司令张文柱，宣布戒严，昼夜检查户口，人心恐慌。（17日专电）

  • 1932年10月18日《申报》：北平息，辽东义勇军占14县，全力约4万，本部设通化，唐聚五任总司令。设兵工厂、军需厂、军官学校、造币厂等，在政治上财政上，可辖两省，又与韩国独立军5千人组织中韩联合军。（17日专电）

  • #参战装备#东北海军“利济”号炮舰：原为浅水民用轮船，1897年竣工于远东地区，建造商等情况不详。1920年4月，吉黑江防筹备处从中东铁路局拨借得到，当时名为“第六号巡船”，后更名为“利济”。最初排水量250吨，长40.32米，宽7.92米，吃水0.9米，航速15节，采用明轮驱动。主甲板上，舰体中部设置有驾驶室、机舱棚，单烟囱，单桅杆。军舰前部安装了1门旧款哈乞开斯5管机关炮，舰体中部安装有2挺重机枪。该舰后被编入吉黑江防舰队，负责东北边境主要河流的巡防和捕盗。1922年，北京政府连同该舰将吉黑江防舰队让给了东三省军阀张作霖。

  • 1932年10月18日《申报》：东京讯，沈阳又一无线电称，日军司令部已发哀的美敦书（最后通牒的旧译）致苏炳文，如不交出所拘日俘，则日军将采取非常手段云。查苏于9月27日反正后，拘获日人多名，闻共有200名左右，大都平民。日军哀的美敦书闻已送达，苏答称，准备与日当道谈判。苏部下现据有自齐齐哈尔至满洲里间约长260里之一带区域。（17日路透社电）

  • 1932年10月18日《申报》：北平息，日本陆军参事官今晚发表文告，解释日前日飞机轰炸海拉尔事。谓苏炳文现拘留日本载客飞机一架，作种种之诿词，不肯交还，且苏炳文似图将该机修理之后，作为军用。日本陆军得中东铁路之谅解后，派轰炸机三架，于10月15日清晨7时30分自齐齐哈尔出发，旋于10时30分飞抵海拉尔，抛掷炸弹一小时半之久，而专以被拘之飞机为目的云。（17日路透社电）

  • 1932年10月18日拂晓，伪满洲国海军江防舰队“利济”号浅水炮舰负责执行拖带3艘木船从富锦前往同江任务。由于同江地区陆上有义勇军抗日武装，早就对投身敌伪卖国不满的“利济”舰长范杰连同舰上爱国水兵，准备于次日发动起义。

1932年10月17日

发表于 2021-10-17 更新于 2022-02-25 分类于 局部抗战(1931-1937)

  • 1932年10月17日讯：第十九路军奉命“围剿”红军，是日该军第六十师占福建龙岩，第四十九师占坎市。

  • 1932年10月17日讯：上海市长吴铁城密电行政院，称捕陈独秀事先曾与租界当局“特别交涉”，并“协同捕房侦察”达月余之久。

  • 1932年10月17日讯：下午5时，外交委员会开秘密会，讨论《国联调查团报告书》，由罗文幹报告赴汉与蒋磋商经过，讨论至7时始散。

  • 1932年10月17日《申报》：沈阳息，派往吉林之日本武装移民五百，于14日午后到达目的地，15日上午起即开始工作，建设宿舍，制造农具，酿造酱油等，俟解水期，开始耕种。（16日电通电）

  • #抗战影像# 地处闸北的一条街道，因日本飞机轰炸上海引起大火而成为废墟，有两名日军士兵在那儿站岗￼

  • 1932年10月17日《申报》：北平息，进攻伊通义勇军，被日军包围数日，势极危险。驻双阳河之援军王玉东部，12日夜开到，内外夹击，日军13日拂晓溃退，伊通之围遂解。获敌械百余枝，毙日军五十余名，王玉东派人与王德林部商联络。（16日专电）

  • #抗战影像#“一·二八事变”中，正在逃离家园躲避战火的中国难民。

  • 1932年10月17日《申报》：沈阳息，包围东边道义勇军根据地通化桓仁，（日军）一齐开始攻击之服部某联队主力，高波某联队主力，阁谷某联队，西安游击队之北方及中央部队大木某联队主力，山冈某联队及仓林某联队之南京部队，于昨夜中在由通化桓仁之二里地点，形成包围圈。义勇军总司令唐聚五则于通化南门外日本领事分馆前设立总司令部，决死守舍命抵抗。日军服部某联队长于今晨下总攻击令，对义勇军形成包围之日军与满军及日飞机队联络，空陆相呼应，自今晨以来，对义勇军根据地之通化桓仁，开始猛烈之总攻击，各处皆有激战。（16日电通电）

  • 1932年10月17日《申报》：北平息，义勇军耿继周部谢振国，13日率部千五百余名，由锦东攻打虎山车站，与日军七百余名激战数小时。日军用机枪重炮向我射击，旋第五支队杨春桦部继至，两部取包围形势猛攻。日军退新立屯，我军占领打虎山车站，毙敌百余名，获机枪二挺，山炮一门，步枪七十余枝。我方死五伤七，现正集合军队，耿部10日大部分向锦州朝阳推进，攻朝阳。一部绕经彰武，转袭新民，耿亲赴前方指挥。（16日专电）

  • 1932年10月17日讯：杨森、李家钰、罗泽洲部在顺庆附近与刘文辉连日激战。刘湘集中兵力于荣昌、遂宁一带，准备武装调停川战。

  • 1932年10月16日讯：吉林抗日义勇军冯占海部围攻吉林市，在小白山、温德河子与日伪军激战一昼夜始退。

  • 1932年10月16日讯：上海救国团体联合会常务理事熊希龄等致电国民政府及中央党部，建议将党务经费移充东北义勇军饷械之用。

  • 1932年10月16日讯：国联中国代表颜惠庆、顾维钧、郭泰祺电外交部，谓鲁、川内战，国际对华舆论恶劣，影响中日问题者至大，望政府力予制止。

  • 1932年10月16日讯：马占山与苏炳文在扎兰屯举行会议，决分兵三路攻打齐齐哈尔，终因敌强我弱未能实现。

  • 1932年10月16日《申报》：南京息，今日下午此间接天津消息，昨晨日机炮轰热河之南岭，华北人士对于日军此举是否为示威性质，抑系大举之先升，意见不一。另有消息，谓日军事当局已调兵六旅（注：旅团），准备大举攻击热河东边之义勇军。（15日路透社电）

  • #抗战影像#东北义勇军骑兵正奔赴前线。

  • 1932年10月16日《申报》：北平息，救国军董荣久部占领女儿河车站后，日军屡以飞机轰炸，并时遣伪军扰乱。13日黄昏，敌方甲车一列，由锦州开来，并有日、鲜步骑炮联队二千余名，由坦克车掩护，向救国军猛袭。我军由王永良指挥大刀队迎击，乘夜冲杀，砍伤敌众。14日午，敌不支，全军向锦州撤退。（15日专电）

  • 1932年10月16日《申报》：山海关息，朱霁青亲督国民救国军马子丹、孟晤炎、李海峙等部，攻击义县城，与日军步骑炮兵，约700余人交绥，战斗极猛烈。救国军袭敌前路，并潜入城内扰乱，乃退却。双方互有伤亡，仍在相持中，闻日军此次再锦朝线增厚兵力，全在防阻朱部，并由驻锦铃木旅团长，躬亲指挥云。（15日华联社电）

  • 1932年10月16日讯：冯占海部未跟随主力一起行动的邓乃柏和张纯玺部攻占扶余县城，阵亡30余人，协同作战的红枪会亦阵亡30余人，邓乃柏和张纯玺部在扶余县城夺取大量物资，并在营救的船工帮助下渡过松花江，继续西行，此后除在乾安地区遭汉奸武装袭击外，基本安全地越过四洮铁路，进入草原。
