1933年02月07日

发表于 2022-02-07 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1933年2月7日讯：河北定县平民教育促进会发动农民举行游行示威，反对日本帝国主义侵略华北，参加人数达7000左右。

  • 1933年2月7日讯：立法院聘戴季陶、覃振、伍朝枢、王世杰为宪法起草委员会顾问。10日，立法院会议通过宪法起草委员会组织条例。3月初，又加聘胡适、张君劢为顾问。

  • 1933年2月7日讯：日军1000人纠合伪满军千余，由辽宁新立屯出发进犯热河阜新。

  • 1933年2月7日讯：川陕苏维埃政府在四川通江建立，张国焘任主席。

  • 1933年2月7日讯：湘鄂赣省苏维埃政府发第四号训令，提出“争取江西和邻近数省首先胜利”，训令“各级政府应以百分之百的精神，为成立新的红六军团而动员而努力”。

  • 1933年2月7日讯：蒋介石电令第二军军长蒋鼎文，将该军由湖北宜昌调往江西“剿共”。

  • 1933年2月7日《申报》：临榆息，绥中方面续到兵车多列，兵力在侦查中，榆关刻无续到敌部队，伪奉山客车今不通，榆城日军传有白俄军人掺杂其间，绥中以东情况未悉。（6日专电）

  • 1933年2月7日《申报》：北平息，义勇军郑桂林部自一日起，每夜向九门口敌军猛攻，前晚彻夜作战。昨战暂停，昨晚七时起仍继续作战，逆军张子清部被郑部包围，在李家堡以东已开始接触。（6日专电）

  • #抗战影像#1933年长城抗战期间，一架日军水上飞机正飞临长城上空进行军事侦察，可能是从秦皇岛水域停靠的日军水上飞机母舰上起飞。

  • 1933年2月7日《申报》：北平息，日人委叛逆张海鹏为热河军务督办，兼攻热第一路总指挥。（6日专电）

  • 1933年2月7日《申报》：北平息，义勇军在李家堡进攻甚力，日军第一警备队向万家屯高岭退却，同时医用又向兴城连山进攻甚烈，日急将锦西第八师团冈本支队赶向兴城增援外，昨复将秦皇岛海面日舰两艘调至葫芦岛，第二外遣舰队将全开葫芦岛，以策应各方。（6日专电）

  • 1933年2月7日讯：四川善后督办刘湘召杨森、李家钰、罗泽洲等在渝开军事会议，决定增调刘湘部十个团、杨森部四个团赴川北，由田颂尧指挥堵截红四方面军，并电复西南政务会同意加入西南国防委员会。

1933年02月06日

发表于 2022-02-06 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • 1933年2月6日讯：伪满国务院通过《商租办法》，确认日本军民在东北享有居住、往来和拥有土地的一切权利。

  • 1933年2月6日讯：犹国才到达南京，向国民党中央报告黔省内战经过，并要求相当名义。

  • 1933年2月6日讯：贵州省府主席、第二十五军军长王家烈电西南政务会，同意加入西南国防委员会。7日，西南政务会推王为西南国防委员会委员。

  • 1933年2月6日讯：行政院及中央古物保管委员会将北平故宫古物首批2118箱启运南京。天安门至西车站一带戒严，并将北平市民众保存故宫古物协会主席周肇祥逮捕，至22日古物在浦口起卸时始予释放。

  • 1933年2月6日讯：锦西日军沿小凌河推进，凌南、凌源等地形势紧张。

  • 1933年2月6日讯：南昌各界“协剿会”为“剿匪”急需，作出征借本市房铺租一个月，征收商店特别捐三个月，以及摊派店员每人一元捐等决定。

  • 1933年2月6日《申报》：北平息，郑桂林部伤兵九名到平，谈该部一日三次总攻九门口日军，二日夜向九门口小山城总攻，激战甚烈。三日早，郑率部攻兴绥先头部队，与伪军张子清不接触，伤兵由九门口抬至石门寨，转乘柳江火车换北宁路车来平。（5日专电）

  • 1933年2月6日《申报》：热河息，5日午此间市面纷传，日机将来承德侦察，驻军司令部即在沿城高处，预装高射炮，严密防范，结果未见踪迹。南方某救国宣传团，连夜放映国难电影，观众逾万，团员演讲时，群众大受感动，狂呼打到日本帝国主义口号，抗日空气浓厚异常。（5日中央社电，图文无关）

  • #抗战影像#山海关沦陷后，日军第8师团继续攻占在山海关以北的长城要隘石门寨，图为第8师团所属日本部队官兵在石门寨附近的合影。

  • 1933年2月6日《申报》：临榆息，4日，九门口方面义勇军与敌有激战，榆关敌百余名往援，5日在相持中，晨有伤兵二十余到榆。（5日专电）

  • 1933年2月6日《申报》：北平息，汤玉麟电平，据称，日军三宅骑兵第八联队一部七百余人，携迫击炮四尊，大炮十门，3日开抵绥中，与北票逆军李际春联合，将大举进攻朝阳。金教寺义勇军耿继周部，仍与三坚正部混战中，闻日方将先实行第三路攻热计划，由朝阳进攻南岭，并以李际春为攻热司令，实行以华治华之阴谋云。（5日中央社电）

  • 1933年2月6日讯：蒋介石在南昌召见湖北绥靖主任何成濬、第四十四师师长萧之楚、第十四师师长周至柔、新编第三十七师师长郭炳生、总部参议马青苑等商“剿匪”军事。

1933年02月05日

发表于 2022-02-05 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • #抗战影像#1932年“一·二八事变”期间，上海公共租界区万国商团下属白俄义勇队正在列队行进，接受工部局官员的检阅。

  • 1933年2月5日讯：交通部宣布“一二八”战役中，航业直接损失421.5万余元。

  • 1933年2月5日讯：前外交部长陈友仁由意大利返国抵沪，翌日对中外记者称：“以前所主张之对日绝交等意见仍未变更”；“依赖国联，终必失败。”13日，又对路透社记者称：“对日局部抵抗，决不能有何成功。”

  • 1933年2月5日讯：张学良电蒋介石，报告“热边风云日益紧急，大有一触即发之势”，“原有军队实属不敷分配”，要求蒋“筹定大计”。蒋批复以“北方军事已全权托付吾兄”推诿，并表示他对这场战争的态度说：“吾人处此忧患，横逆之来，惟有尽其心力而为之，只求此心无愧，并以扩然大公示众，则成败存亡，听之而已。”

  • 1933年2月5日《申报》：北平息，敌连日指挥张海鹏部骑兵及蒙匪，在开鲁阜新前方与我义勇军李海青、刘桂堂等部激战甚烈，伪军及蒙匪因无斗志，且乏训练，伤亡颇多。（4日专电，图文无关）

  • 1933年2月5日《申报》：东京讯，锦州日人消息称，近八月内，中国义勇军屡攻九门口，今晨复作第五次之攻击，希图包围驻该处之少数日防兵，激战三小时而退。（4日路透社电）

  • #抗战影像#长城抗战中，抵御日军入侵的中国军人正守护在长城沿线，义勇进行曲中”起来不愿做奴隶的人们，把我们的血肉铸成我们新的长城”正是对长城抗战真实的写照。

  • 1933年2月5日《申报》：北平息，我军占据九门口东方之鸡冠岭后，即与义勇军某部联合夹击九门口李家堡之敌，敌不支，向万家屯退却。昨九门口外无战事，石门寨方面亦甚沉寂，石河前线敌骑兵一度偷渡沙河寨桥，被我步哨察觉，用机枪扫射击退。（4日专电）

  • 1933年2月5日《申报》：临榆息，日军第八、第十、第十四师团余部似已由日鲜境内开抵沈阳，向锦绥榆方面配备，伪奉山路3日期停止全路客车。供该前项军运，榆关方面日再增兵说，据本日息，确有其事。3日并有一小部队百余人先头到榆，驻城内县立小学。（4日专电）

  • 1933年2月5日讯：国联十九国特委会向日本提三项办法，听其自择其一：一、接受十九国特委会决议草案及说明书，可依照日方对说明书所提出之修正案说明应保留各点；二、由十九国特委会起草报告书，日本不予阻挠，由国联负采取任何行动之责；三、日本可以十九国特委会拒绝日本提案为理由，与国联决裂。日方拖延未作答复。

1933年02月04日

发表于 2022-02-04 更新于 2022-02-28 分类于 局部抗战(1931-1937)

  • #抗战影像#1932年“一·二八事变”前的上海跑马场（解放后改为人民广场）。

  • 1933年2月4日讯：《自由言论》半月刊在沪创刊，王造时主编。在创刊号上，发表王自撰的《安内必先攘外》一文，痛论非对外抗战，不足以安内，非停止内战，不足以救亡。该刊出至本年12月，遭国民党当局以“言论荒谬”的罪名查封。

  • 1933年2月4日讯：中共苏区中央局机关报《斗争》在江西瑞金创刊，由中共苏区中央局党报委员会编辑，旬刊，由《战斗》和《党的建设》合并而成。至1934年9月30日停刊。

  • 1933年2月4日讯：西陲宣化使班禅额尔德尼谒国民政府主席林森，请示宣化方针。7日，班禅离京北上，往青、康等地宣慰。

  • 1933年2月4日讯：红四方面军进占川北通江、南江、巴中后，成立川陕省临时革命委员会及各级地方革命政权，发动群众打土豪、分田地，四川军阀极其恐慌。是日，刘湘、田颂尧分电国民政府，告以决调45000兵力“围剿”红军。

  • 1933年2月4日讯：日驻华使馆情报部主任须磨由沪到京，分访英使蓝普森及外长罗文幹，提出将榆关事件作为地方事件就地解决，声言“否则恐再起误会，势如燎原，更难遏止”。罗答以“时至今日断无局部解决之理”。

  • 1933年2月4日《申报》：北平息，义勇军汪元年师与耿继周部会师，克复大黑山。1月28日进占留龙台三宝营子，毙伪军30余名，日本督导员逃窜无踪。义勇军独立团邵荫樊、梁朝顶、张信出师穿心店，刻在某地与李旅会师，向锦县进展。热边民众因义勇军声势日大，各牌联庄会，均愿援助。（3日专电，图文无关）

  • #抗战影像#长城抗战期间，一名西北军军官驻守在长城之上，斜跨驳壳枪，肩背大刀，目光注视着日寇来犯的方向。大刀在长城抗战中成为代表中国抗日军民顽强不屈、奋勇杀敌的精神象征。

  • 1933年2月4日《申报》：北平息，攻榆关阵亡之日兵，遗尸二百余具，昨经日副官菱田，由南海沿装日轮返大连，运回本国。（3日专电）

  • 1933年2月4日《申报》：北平息，3日晨日机5架向九门口附近轰炸，计九门口落7枚炸弹，均在山地爆炸，我方无损失。口外郑桂林部，3日与日军激战，敌以坦克车掩护攻击，郑部均伏大红山一带，日军已下总攻击令，郑亲在某地指挥，石门寨3日午发现日机两架低飞侦察。（3日专电）

  • 1933年2月4日讯：日机连日轰炸开鲁，掷弹200余枚，民众伤亡惨重。

  • #抗战影像# 日军轰炸之后的山海关：日军士兵驾车驶过一条被毁街道的废墟
