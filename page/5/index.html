1932年03月23日

发表于 2021-03-23 更新于 2021-04-12 分类于 局部抗战(1931-1937)

  • 1932年3月23日讯：台湾总督府设糖业实验所。

  • 1932年3月23日讯：徐州实验小学13岁学生吴书骥，捐款50元慰劳第十九路军。当日蔡廷锴等复电致谢。

  • 1932年3月23日讯：胡适、丁文江、翁文灏、傅斯年等电国联秘书长，揭露日本操纵伪满洲国之阴谋，略称：“凡参加此项组织者均为性质可疑之以前官僚与军阀，受恫吓与贿赂之胁迫，成为日人之傀儡”，“以日方之傀儡视作中国人民之代表，不仅为一种损害，且为侮辱。”

  • 1932年3月23日讯：中日停战正式会议因日司令白川不出席，改期举行。

  • 1932年3月23日《申报》：北平息，马占山甘心助逆，将出发各地演说伪国理想，冀安人心，并对军队连发欠饷。（22日专电）

  • 1932年3月23日《申报》：哈尔滨息，东铁哈绥线帽儿山今晨为自卫军攻占，熙洽军缴械者二连，余溃散。午刻日飞机一架往侦察，自卫军顷分为数十支队，专在哈绥线及哈东进出。海林站牡丹江站间，20日晚王德林军与日军发生激战二时，宁古塔日军往增援，王军退却，丁超到延寿县指挥军事。（21日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，占据了一处上海街头的日本陆军士兵。

  • 1932年3月23日《申报》：沪某报云，有某西人住江湾路公共游泳池附近，报告捕房，谓寓所近旁，有华人八九人之残骸，其尸身据称曾为日人所焚化。迨捕房派高级巡官往查，果见白骨无数，并得切实证据，证明诸人被焚前，其双手曾为铁丝所缚。至该西人寓所，虽悬挂外国旗，仍为日军用作机关枪阵地，且曾…

  • 1932年3月23日《申报》：十九路总指挥蒋光鼐，及淞沪警备司令戴戟，前奉政府命令，来沪公干。现蒋已公毕，于昨日由杭转京，遣返遣返。戴戟因患吐血，为势颇剧，一时未能成行，且须入医院疗养，报载蒋充停战会议代表，查非事实云。

  • 1932年3月23日讯：颜惠庆就日本扣留东北关税事，通知国联提出抗议，谓日军在东三省强留关税及委派日顾问，并要求嗣后关税应交东省傀儡政府，中国绝对不能认为合法。国联虽有决议案，但日本吞并东三省之工作已将完成。

1932年03月22日

发表于 2021-03-22 更新于 2021-04-12 分类于 局部抗战(1931-1937)

  • 1932年3月22日讯：梅兰芳在北平义演得洋3900余元，汇沪作伤兵医药费。

  • 1932年3月22日讯：铁道部电令平绥、北宁各路局，拒绝军事机关提取路款。

  • 1932年3月22日讯：上海各界就上海停战会议发表宣言，反对签订丧权辱国条约。

  • 1932年3月22日讯：何香凝通电全国同胞，略称：“此次日祸中国，为我国数千年来最惨痛之事，中日停战会议，我方如先签订丧权辱国之条件，我民众当一致反对，万难承认。”

  • 1932年3月22日讯：杭州市教育会通电反对与日签订辱国条约，郑重宣言：“在此敌兵压境之秋，如不思积极抵抗，甘为城下之盟，签订辱国条约者，本会认为民族之叛徒，誓不承认。”

  • 1932年3月22日讯：张发奎亲赴南京谒行政院长汪精卫，请示第四军抵醴陵后进止，决定该军仍向南昌涂家埠前进。

  • 1932年3月22日讯：国民党中央统计处发布东北损失概计，其中官方财产178.5364亿余元。

  • 1932年3月22日《申报》：北平息，热河组就之义勇军已有11路。第1路孟希尧，2千余人，在凌源朝阳等县。2路孙瀵章，8百余人。3路李惊涛，9百余人，在平泉凌源等县。4路张其祥，6百人，在朝阳县，已出发至义县附近。5路温秀然，3500余人，在阜新开鲁等县。6路汪元平，4、5百人。7路李福千，2、3千人，…

  • 1932年3月22日《申报》：北平息，溥仪派人四处召集匪徒，成立禁卫军，日方限彼等扩展军部，不允发给枪|支，表示将来只能以红缨枪等为武器。（21日专电）

  • 1932年3月22日《申报》：北平息，榆关电，东北义勇军某路司令李华楷，率众三百余人，17日晨向绥中县日军进攻，双方均有伤亡。因弹药不济，退入山中。（21日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，蔡廷锴将军正亲临炮兵阵地观察敌情，边上炮手正在操作一门沪造克式75毫米山炮。

  • 1932年3月22日《申报》：哈尔滨息，哈绥线下城子站，19日晚为王德林救国军攻占，熙洽军退却待援，救国军占穆棱为根据，分兵向磨刀石方面推进，救国军与日军18日激战，日飞机四架投弹，救国军退穆棱。（20日专电）

  • 1932年3月22日《申报》：苏州21日专电云，21日，七坞口到日舰11艘，居民逃光，日兵未登陆，杨|林口亦到日舰数艘，满载日兵。21日晨，日机三架飞苏侦察一小时，浒浦亦到日机二。

  • 1932年3月22日讯：行政院会议决议：一、改组鄂省政府，以夏斗寅为鄂省政府主席；二、国难会议改于4月7日举行。

  • 1932年3月21日讯：西南政委会决议委任刘纪文为广州市长。28日刘到任。

  • 1932年3月21日讯：湖北民众驱何救省团到南京向国民党中央及国民政府请愿，列举何成濬荒淫暴虐、倒行逆施、任意搜括诸罪状，请迅予撤惩，以肃国纪。

  • 1932年3月21日讯：日机第九次飞杭州侦察，常熟亦有日机侦察。

  • 1932年3月21日讯：国联调查团在沪视察真如、闸北、江湾、吴淞等战区。

  • 1932年3月21日讯：下午4时至6时，中日代表及各使第三次非正式中日停战会议在英驻沪领署举行，议定停战三原则：一、中国军队暂留驻原防；二、日本军队撤退至1月28日前之原防；三、由参加各友邦代表在内之共同委员会证明第一及第二两项之实行。

  • 1932年3月21日讯：孔祥熙据金融界人士言及日机轰城由于在城驻军所致，特电蒋介石，“此后驻军筑垒，拟请饬令前方务必远离城市，避免敌人目标”，以保东南精华。

  • 1932年3月21日《申报》：北平息，关外第四路义勇军，日前已占黑山县城，现向打通路一带进袭，该路路轨一部被拆断，绥中日军只一部在车站，余陆续运沈，榆关安宁。（20日专电）

  • 1932年3月21日《申报》：哈尔滨息，昨夜与今晨丁超军队，又两次攻击此间正南60里之石头河子。丁军已连攻三次，故此间日当道现拟派兵援助该处防兵。同时中东路东段一带，现亦续需日军，路局虽允运输日兵，但车辆缺乏，暂时不能照办。（20日路透电）

  • 1932年3月21日《申报》：哈尔滨息，中东路东段之形势，益见恶化，阿什河附近之伊士凡斯柯伐耶分站，昨为非正规之军队所攻，掳去铁路职员二十人。今日阿什河监督电告路局，谓其所管区内之第四第五段路轨，因无工人不能修理，故渠不能负行车之责，闻丁超李杜莫德惠所有之地产，将为哈尔滨市议会拍卖。…

  • 1932年3月21日讯：国民党中央政治会议讨论外交问题。外交部长罗文幹报告沪停战会议谈判经过，及目前应付方针，决仍照原定方针相机进行。

  • 1932年3月20日讯：台湾艺术研究会在日本东京成立。

  • 1932年3月20日讯：中国左翼新闻记者联盟在上海成立，联盟斗争纲领强调“争取言论出版的绝对自由”，反对“一切束缚压制新闻文化之发展的法令”，使新闻事业“成为鼓动大众、组织大众之武器”。

  • 1932年3月20日讯：济南市公安局是日晚开始大肆搜捕共产党人，至22日，先后从第一乡村师范、女子师范、正谊中学等处捕去60人。

  • 1932年3月20日讯：东北义勇军拆去打通路绥中以东铁轨七八里，与日军开火。第四路支队占黑山县城。

  • 1932年3月20日讯：日机第八次飞杭州。昆山、青阳港及沪租界、南市均有日机侦察。

  • 1932年3月20日讯：国民党中央统计处发布，沪变损失达15.64亿元以上，受直接损害人民逾81万，其中死亡6080人，伤2000人，失踪1.04万人。

  • 1932年3月20日讯：中国青年救国会就中日和议发表宣言称：“如日本果具和平之诚意，则我国应本四项原则谈判：一、日本须无条件撤兵；二、不承认设置中立区、和平区或扩充租界；三、淞沪战区内一切损失须由日本赔偿；四、东北案件必须与沪案同时解决。”

  • 1932年3月20日《申报》：哈尔滨息，16日日军相蔻联队与救国军刘振邦部激战于宁古塔，双方死伤甚重，该地反日空气甚浓，东铁允拨车四列，运日军村井旅团赴珠河击丁超。日军恐与俄发生冲突，调兵赴哈满线事未决定，但令马占山派兵往，马则无兵可派。又伪国阁员均反对马，内阁或改组，日军将派一联队去…

  • 1932年3月20日《申报》：北平息，沈讯，10日伪国成立第一日，沈海路警察保安队二百余人被救国军缴械，公安局11分局全部亦缴械。溥仪抵春时，有吉林老八旗人自称前清旧臣，手执黄纸长方旗，上书大清宣统皇帝陛下，下书吉林八旗旧臣等字。见溥仪即跪地下，叩头如捣蒜。（19日专电）

  • 1932年3月20日《申报》：南京息，军委会组织，决分四厅。第一厅长蒋自兼，副林蔚文，职司军事计划；第二厅长李济深，副周亚卫，司训练事宜；第三厅长何应钦，副陈仪，司军令事宜；第四厅长朱培德，副未定，司总务及不属一二三厅之事宜，职员均由训练、军政、参谋三部调用。（19日专电）

  • 1932年3月20日讯：上海各团体救国联合会召集紧急理事会议，各团体代表50余人出席，讨论应付上海外交问题，议决：一、反对丧权辱国条件；二、通电全国一致主张，反对日兵未撤退以前开始任何谈判；三、通电国联及国联调查团，绝对不承认丧权辱国条约之签订。
