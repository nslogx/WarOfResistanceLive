1932年07月20日

发表于 2021-07-20 更新于 2021-08-10 分类于 局部抗战(1931-1937)

  • 1932年7月20日讯：天津商民救国会致电热河省主席汤玉麟请对攻热日军妥加防御，矢志抵抗。

  • 1932年7月20日讯：上海各民众团体救国联合会以日军“袭热河，攻榆关，窥平津”致电国民政府，质问“有无收复失地准备”，并称“诸公秉持国政，败坏于前，岂仍因循坐误，使敌寇纵骑关内，以沦我华北，涂炭全国”。

  • 1932年7月20日讯：废止内战大同盟在沪举行第八次筹备会议，秘书处报告截止是日加入发起之团体203个，个人493名。代表大会展期至8月27日在上海举行。

  • 1932年7月20日讯：中华苏维埃共和国临时中央政府自瑞金用无线电向南京政府发出抗议，要求释放牛兰夫妇，愿以释放苏区所有西方教士为交换条件，并表示牛兰为中国革命之友，愿为牛兰夫妇辩护。

  • 1932年7月20日讯：教育部呈行政院整顿各大学办法数项：一、确定经费；二、裁并各大学重复院系；三、规定延聘教授标准；四、严格限制招收及甄别学生；五、慎重任命校长。

  • 1932年7月20日讯：日军“鉴于当前内外诸般情势，不宜立即对于热河方面进行武力解决”，是日退出热河朝阳寺。

  • 1932年7月20日讯：国民党中央制定《保障言论自由法》，凡12条，其中规定“宣传共产主义或谋破坏团体之刊物没收”。

  • 1932年7月20日《申报》：哈尔滨息，伪国所铸新币，目下暂由“中央银行”运送二百万元于哈尔滨，以为流通北满之用，至于流通北满市场之旧纸币，其换算率，定为金币纸百元，换新铸币百二十五元。（19日电通社电）

  • 1932年7月20日《申报》：东京讯，日军出动热河之部队已在前线开火，形势顿形重大。（14日路透社电）

  • #抗战影像#伪满洲国时期，三个女学生的合影照片。

  • 1932年7月20日《申报》：锦州息，17日被义勇军捕去之满铁联络员石本权四郎，本日由在北票之热河军宪兵队，电锦州日军司令部，谓关于石本之踪迹，当于三四日中，由义勇军取去，交与日本，惟日军对此电，不肯置信。（19日电通社电）

  • 1932年7月20日《申报》：北平息，某方面据报日本决向东北增兵四个师团，进取热河，近两日嘉村旅团已向义县集中，并传已在朝阳镇，与我军冲突，张学良此次已下抵抗之决心，确有相当准备。（19日专电）

  • 1932年7月20日讯：国民政府任命沈光汉为陆军第六十师师长，毛维寿为陆军第六十一师师长，区寿年为陆军第七十八师师长。

1932年07月19日

发表于 2021-07-19 更新于 2021-08-10 分类于 局部抗战(1931-1937)

  • 1932年7月19日据《大公报》讯：浙西农民今春茧汛失败，无以自给，杭县、海宁、乌镇、菱湖、练市、德清、吴兴、桐乡等地饥民纷纷聚众抢米。

  • 1932年7月19日讯：浙江余姚运盐船200余艘要求酌加运费，遭资方拒绝，船工联合绍兴帆船业大罢工，盐运停工。

  • 1932年7月19日讯：热河省主席汤玉麟派代表与日方交涉，说明石本被掳，与正规军无关，完全是偶发事件。日军要求七天内找到石本，驻朝阳第一〇九旅旅长董福亭亲赴锦州向日方道歉，否则继续采取军事行动。

  • 1932年7月19日讯：第四军军长张发奎辞军长职，拟出洋游历。

  • 1932年7月19日《申报》：沈阳息，军部方面所推荐拟为满铁总裁之预备陆军大将吉田氏，今日下午三时二十分由大连来沈，当往关东军司令部访问本庄司令，会谈达一小时。（18日电通社电）

  • #抗战影像#伪满洲国“皇宫”中专用的合金餐具。

  • 1932年7月19日《申报》：北平息，于芷山派逆部三千，窥辑安，唐聚五派队应战，伪军四百人被缴械收编，二百余溃散。（18日专电）

  • 1932年7月19日讯：粤军以全力向信丰红军进犯，以缪培南师任前锋，黄光锐亲率飞机队出发掩护。

1932年07月18日

发表于 2021-07-18 更新于 2021-08-10 分类于 局部抗战(1931-1937)

  • 1932年7月18日讯：江苏第一监狱奉令办理大赦。在押920人，大赦出狱者35人。

  • 1932年7月18日讯：红军贺龙部二次占领湖北潜江城。

  • 1932年7月18日讯：下午2时，日机五架轰炸朝阳，炸死居民20余人。

  • 1932年7月18日《申报》：北平息，张海鹏通令部下，积极招募军队，但应募者无几。张乃令所部将黑山北镇等县村庄各村长带到，迫令代为招募，限十日内一律交齐，否则枪决。村长返村，以张复如此横暴，如不与之抗，决难逃生。已集民团千余人，准备与张逆决战，不料事机不密，被张逆部包围，焚烧民宅。各村民团已星夜往援，义勇军亦派三百往援，正激战中。（17日专电）

  • #抗战影像#伪满洲国时期新京特别市公署，伪满文教部、国都建设局亦在此办公。

  • 1932年7月18日《申报》：北平息，农安来人谈，日军于12日在通辽西之玉粮堡一带，与义勇军接触，战极烈，农安扶余等地义勇军，已达万二千余人。（17日专电）

  • 1932年7月18日《申报》：北平息，哈电，自卫军八千余，积极向斐克图进攻，日机连日往掷弹。13日晨经自卫军用慢枪击落一架，机师被俘，现哈埠形势极紧张，日侨多准备退出。（17日专电）

  • 1932年7月18日讯：何应钦到沪，对记者谈“剿匪”军事，声称“剿匪”军约60万人，约半年可告一段落，“剿匪”全部经费原支2000余万元，今减至1300万元，非常困难。

1932年07月17日

发表于 2021-07-17 更新于 2021-08-10 分类于 局部抗战(1931-1937)

  • 1932年7月17日讯：天津《益世报》创始人杜竹轩因心脏病突发逝世。

  • 1932年7月17日讯：闽省红军占华安。

  • 1932年7月17日讯：国民党中央政治会议通过整理产区盐税暂行税率，是日公布。原轻税地区税率均有增高，最高者增税1.45元。原有税率最低者仅0.3元，增后为一元。原有最高者为5.5元，增后为六元。

  • 1932年7月17日讯：江苏省援助东北义勇军、反对上海停战协定民众大会在上海共和剧院开会，被上海公安局侦悉，派警包围，捕去94人，并搜出各种革命文告、刊物、证章、密码本等。其中88人于21日解送淞沪警备司令部，28日审讯。29日解往南京。

  • 1932年7月17日讯：鄂省组织“剿共义勇队”，本日公布章程，县设总队，区设大队。凡15岁至45岁之男丁均编入。

  • 1932年7月17日讯：蒋介石决定对鄂、豫、皖三省红军“清剿”计划，分三步进行：先鄂，次皖，再豫。

  • 1932年7月17日讯：第五军军长张治中再次请辞军、师长各兼职，并请升王敬久为第八十七师师长；所遗第五军军长职，请派员接任或撤销，“以节糜费”。9月7日，国民政府令准张治中辞职，任命王敬久为第八十七师师长。

  • 1932年7月17日讯：日军借口关东军联络员石本权四郎在热河境内被义勇军扣押，铁甲车二列向朝阳寺进犯，我军阻拦，即被开枪射击。次日，日机五架飞朝阳轰炸，投弹30余枚，步兵第三十一联队一部占朝阳寺。

  • 1932年7月17日讯：日本陆战队200余人自上海停战协定中所规定之D区（东自沙泾港起，沿淞沪铁路至横浜桥止；北自沙泾港起，沿新市路至奚家桥止；西自奚家桥起，沿水电路至八字桥止；南自八字桥起，沿日本公墓循横浜河至横浜桥止）撤退，上海撤兵区域接管委员会及市公安局、保安队前往接收。

  • 1932年7月17日《申报》：北平息，长春电，俄军舰抵富锦，驻桦川依兰日军避免冲突，8日退出。（16日专电）

  • #抗战影像#伪满洲国时期，伪宫廷的菜谱。

  • 1932年7月17日《申报》：大连息，16日上午记事解禁。关东厅警察探悉，韩人决死队从上海到大连，将乘5月26日国际调查团来连之际，加以暗杀，以陷日本于国际的危地，即暗中戒备。于调查团到连之二日前，即5月24日晨，在大连市乃木町鲜人船员某之住宅，检举决死队员柳相根（25岁）及崔兴植（21岁）两名，得以防祸未然。此事前禁各报刊载，今日始行解禁，此二犯人，均属于以上海为根据地之韩国假政府爱国青年团，与1月8日樱田门不祥事件，及上海虹口公园爆弹事件有关。检举之际，搜得大响手 枪一支，及巧装于水筒内之炸弹一枚，与上海炸案所用炸弹相同。（16日电通社电）

  • 1932年7月17日《申报》：北平息，吉敦路拉法站附近六家子、五家子等处义勇军，与日军激战，日军死12名，伤7名。由拉法站输送收容死伤之列车，9日晨至六道河子，被义勇军用手榴弹袭击，列车及铁道被炸毁数处，运输停顿。（16日专电）

  • 1932年7月17日讯：牛兰夫妇经宋庆龄、蔡元培、杨杏佛具保，出狱移南京鼓楼医院就医，法院派警前往看守。

1932年07月16日

发表于 2021-07-16 更新于 2021-08-10 分类于 局部抗战(1931-1937)

  • 1932年7月16日讯：财政部发表6月份海关贸易额入超4000余万元，日货进口骤升至第一位。

  • 1932年7月16日讯：国民政府任命马鸿逵为陆军第三十五师师长。

  • 1932年7月16日讯：北江方面粤军改编为两个纵队：第一纵队攻南康，以余汉谋为总指挥；第二纵队攻信丰，以香翰屏为总指挥，限期克复信丰、南康。

  • 1932年7月16日讯：第十九路军军长蔡廷锴在福建漳州开军事会议，动员“剿匪”，其第六十、第七十八两师除留一团守漳州外，其余全部限三日内向闽西前方推进。

  • 1932年7月16日讯：蒋介石在汉口再度召集湖北各县长训话，令其效法曾国藩、左宗棠，并分赠手编之《曾左语录》一册。

  • 1932年7月16日《申报》广告：胜利公司纪念忠勇卫国之19路军爱国歌曲唱片。

  • 1932年7月16日《申报》：哈尔滨息，榆树近郊之“满洲国”马队二百人哗变，城内“满洲国”军队均被缴械。叛军突向日军攻击，但据日方报告，华军卒被击散，阵亡及就擒者五六十人，日军死五人伤十人。（15日路透社电）

  • #抗战影像#伪满洲国时期，新京大同广场（今长春市人民广场）上的顺天安民塔，光复后被拆除。

  • 1932年7月16日《申报》：齐齐哈尔息，战死之远矢忠大尉，系鹿儿岛县人，去年12月，嫩江之役，左肩受创甚重，仍跃入敌之堑壕，素有猛勇之称云。（15日电通社电）

  • 1932年7月16日《申报》：齐齐哈尔息，本月12日夜李海青统率边防军第9旅及由红枪会编成之部队，共约数千，猛袭齐克线拉哈尔，守备该地之日本远矢部队，仅以XX名（原文未具体透露，可能为几十）之寡兵，于小园江援兵未到以前，努力防战，死守拉哈尔，与黑龙江满洲军协力奋战。李部卒余30余名，其他四散。此次激战之结果，远矢大尉小林二等各战死，负伤6名，非战斗员中各长谷川满铁社员等，亦负伤，其他详情不明。（15日电通社电）

  • 1932年7月16日讯：何应钦致电陈济棠、李宗仁、蔡廷锴、何键，商定“剿匪”军事计划，即以粤军主力由粤北向赣南推进；湘、桂军由湘、赣边东下；闽军由武平、长汀、上杭向瑞金、石城进攻；赣军则自永丰、南丰之北向宁都、广昌以袭红军后方。五省动员总兵力约在30万人以上，对中央苏区之宁都、瑞金、石城、广昌、会昌、寻邬、雩都、兴国、汀州、宁化、上杭、武平等县形成大包围圈。
