1932年06月16日

发表于 2021-06-16 更新于 2021-07-05 分类于 局部抗战(1931-1937)

  • 1932年6月16日讯：在和任救国军前方司令部参谋长的胡泽民等共产党员取得联系后，在了解情况后，周保中接受王德林的邀请，来到吉林救国军前方总指挥部工作。一面建立党团支部，在士兵中秘密发展党团员作为骨干，一面积极开展抗日救国的宣传工作。

  • 1932年6月16日《申报》：哈尔滨息，宫长海部骑步兵二千，退哈南24里正黄旗四屯，与日军大队对峙中。反吉军正向该方集中兵力，14日早有反吉军千名，携炮数门，自阿城驶来。经过哈南13里益丰源，向靠山屯急进，有与宫长海部联络之势。（15日专电）

  • 1932年6月16日《申报》：北平息，老北风、三胜、项青山、李凤华等积极联络各路义勇军。项为辽西义勇军司令，三胜副之；李为辽南司令，老北风为副。项李等部主黑山县、沙岭、辽东县山北河、辽阳、黄泥洼一带，人数六七千，实力甚厚。（15日专电）

  • 1932年6月16日《申报》：哈尔滨息，齐克璐克山附近，13日日军与反黑军一队激战，克山间现有反黑军输送，闻系新征丁壮，归团长南某统率。（15日专电）

  • #抗战影像#伪满洲国时期，在我国东北地区某书店内，日本人正在挑选书籍。

  • 1932年6月16日《申报》：哈尔滨息，马占山编组所部为数十独立队，计划长期抵抗。（15日专电）

1932年06月14日

发表于 2021-06-14 更新于 2021-07-05 分类于 局部抗战(1931-1937)

  • 1932年6月14日讯：劳动大学护校委员会召开执行委员会，通过驳复教育部文及对外宣言，并派代表陈悲农等赴京请愿。

  • 1932年6月14日讯：国立编译馆成立，直隶教育部，掌理学术文化书籍及教育用书的编译与审查。辛树帜任馆长。

  • 1932年6月14日讯：第四师师长徐庭瑶由蚌埠赴正阳关指挥“剿共”，师部及直属部队随行。15日，第四师在正阳关集中，准备进攻六安、霍山、霍邱。

  • 1932年6月14日讯：国民政府主席林森到沪慰留陈铭枢和宋子文，并访孙科。孙称病未见。

  • 1932年6月14日讯：前外交部长陈友仁离上海赴法国。

  • 1932年6月14日讯：汪精卫、罗文幹、顾维钧等飞庐山晤蒋介石，商外交、财政及“剿共”事宜。15日下午，顾与罗返京，顾旋乘飞机到沪，对记者宣称：在庐山两度会议，“对东北失地，决以积极方法从速收回。对日外交，仍本一面抵抗、一面交涉之原则努力进行”。

  • 1932年6月14日讯：下午2时10分，广州地震。“全市房屋均微微摆动，悬空之物动荡不止”。

  • 1932年6月14日讯：行政院会议决议，慰留江苏省府主席顾祝同暨王柏龄等全体委员。

  • 1932年6月14日讯：克山县保安游击队总队长南廷芳，以黑龙江省“民众救国义勇军”第二军上校司令的职衔，会同“海中华”、“火龙”等绿林武装数千人，击溃日本守备队，毙敌数十人，攻入克山县，占领伪县公署，捣毁监狱，释放“犯人”六十余人，同时攻击了日军旅团部等军事机构，后因日援军到来，方撤出县城。

  • 1932年6月14日《申报》：山海关息，兴城锦西各路义勇军，大部向连山进击，12日晨郑部在连山北10余里之崔家屯，与日军接触。日军陆续增援，义勇军实力雄厚，急在侦炸，现义勇军倚山林之掩蔽，进退极活跃，仍在激烈恶战中。（13日专电）

  • #抗战影像#参与日本政府殖民伪满洲国的一处“开拓村”中日本殖民家庭合影。

  • 1932年6月14日《申报》：南京息，马占山部集中北德都北安一带，并编游击队数队，每夜出动，响日军松木旅团部防地袭击。日军极不安，日机连日出动，以该队昼伏夜出毫无效果。驻齐黑街道附近之马占山旧部徐宝珍部，10日全部反正，现与日田野旅团小全联队激战中。（13日专电）

  • 1932年6月14日《申报》：哈尔滨息，哈尔滨附近，昨夜有剧战，日军失利后，复谋反攻，阵地起于哈埠东5里之某点，而达哈埠南4里之处，双方各以全力接战，重炮声与机关枪声，此间可悉闻之。居民惶扰终夜有客来自上海者，谓此时哈埠与当日闸北恶战时上海租界相似。反满军初颇胜利，因“满洲国”军队于攻军进扑时，反正响应也。反满军声势顿盛，闻日兵死伤逾百，未几日军重新集合，开始反攻，其势颇锐。反满军虽接战，但至破晓后，气力渐竭，遂向后退。哈埠东9里之中东路轨道，与电报杆，悉为反满军所毁，修路车驶往该处，但为反满军所包围，路员见枪弹如雨，不敢前进，赶即开足速度驶回哈埠，故东面通常现已阻断。（13日路透社电）

  • 1932年6月14日讯：日本众议院通过久原等45人提出之关于“满洲国即时承认”之决议案。

1932年06月13日

  • 1932年6月13日讯：何香凝、柳亚子等为支援东北义勇军抗日，组建国难救护队，杨庶誉任队长，是日救护队由沪启程北上。

  • 1932年6月13日讯：蒋介石电邀顾维钧赴庐山，并派自用飞机抵京迎顾。罗文幹在京宴请顾维钧。

  • 1932年6月13日讯：蒋介石令豫、皖、赣、湘各省主席于15日齐集庐山会商“剿共”事宜。

  • 1932年6月13日讯：国民政府聘张继为西京筹备委员会委员长，居正、覃振、刘守中、杨虎城、李协、褚民谊、陈璧君、王陆一、何遂、戴愧生、石青阳、黄吉宸、李次温、李敬斋、贺耀组、邓宝珊、恩克巴图、陈果夫、焦易堂为委员。

  • 1932年6月13日《申报》：吉林息，11日上午1时半，在本地与敦化间之蛟河地方，突发现二百五十名之兵匪，袭击公安局，并夺取军械子弹，放火烧毁民房六十户，并袭击铁道守路之事务所，破坏电报电话铁路轨道等。日本某中队接此急电，即向该方面开拔，兵匪早已逃走，并架去妇女小孩约三十名，日军现在追击中。（12日电通社电）

  • #抗战影像#德国蔡司公司为“伪满洲国”制造的蔡司伊康相机，底部有“为满洲国（制造）”字样。

  • 1932年6月13日《申报》：北平息，义勇军第十路黄振兴部1400余名，6日晨在锦州西良村，与日军激战4小时，旋撤小刘庄一带休整，与马占山接洽，由马供给子弹，日内反攻锦州，该路骑兵千二百余名，9日晨在打虎山一带，同马占山部联合，与日军激战两日。（12日专电）

  • 1932年6月13日《申报》：北平息，吉林义勇军副军长郝振声率部由吉海吉敦各路攻吉林，前日下总攻令，各路均发生激战。义勇军第三路昨准备进攻沈阳。（12日专电）

  • 1932年6月13日讯：上海停战共同委员会讨论日军完全撤退问题，日方委员冈崎称再候三五日作正式答复。

1932年06月12日

发表于 2021-06-12 更新于 2021-07-05 分类于 局部抗战(1931-1937)

  • 1932年6月12日讯：北平大学校长沈尹默再电教育部请辞职。

  • 1932年6月12日讯：红军占领湖北广济，上官云相第四十七师开抵武穴。13日晚红军自动退出广济城。

  • 1932年6月12日讯：皖西地主武装两万余人，随第四师徐庭瑶部进犯霍邱。

  • 1932年6月12日讯：红四方面军发起的潢（川）光（山）战役开始。战役历时五天，至16日胜利结束，共歼敌新二十师、第七十五师、第七十六师共八个团和民团一部，毙、伤、俘敌近万人，缴获枪 支7000余支，商城以西、潢川和光山以南被敌侵占的广大地区悉行恢复，并扩大了部分新区。

  • 1932年6月12日讯：日军第十四师团平贺支队自海伦出发，对马占山部发起总攻。在距海伦20里之大榆树激战三小时。

  • 1932年6月12日讯：江苏省主席顾祝同暨全体委员因财政困难，库空如洗，所定救济办法又未能顺利进行，向行政院辞职。

  • 1932年6月12日讯：上海各界2000余人在市商会召开淞沪抗日阵亡将士及被难同胞追悼大会。王晓籁主祭，蔡廷锴等出席致祭。蔡致词称：“以后国难甚多，望大家一致团结应付。”

  • 1932年6月12日讯：顾维钧到京。13日，汪精卫在京召集各部长及顾维钧开谈话会，先由顾报告出关调查经过，然后讨论外交问题及国内财政问题。

  • 1932年6月12日《申报》：山海关息，前往兴城绥中之义勇军，因战略关系，顷向辽热边界药王寺及新台门一带集中。兴锦西方面之义勇军联络，向东进展，俾规复锦州等处。（10日专电）

  • 1932年6月12日《申报》：北平息，赵欣伯呈请伪执政，请建立国祠，供祭此次阵亡日满军士，溥仪已照准。（11日专电）

  • #抗战影像#伪满洲国幼年军校，教官与学生互相施以敬礼和持枪礼。

  • 1932年6月12日《申报》：北平息，马占山部月余修养，实力扩充，已进驻白奎堡。马在海伦，日内赴前方督师，进攻哈埠。马谈，日禁农民种高粱，为防义勇军。我军进攻减去障碍不少，不久可占哈埠。（11日专电）

  • 1932年6月12日《申报》：山海关息，兴绥一带义勇军郑桂林部，已与锦西义勇军取得联络，郑部一支队进袭兴城。10日拂晓，毁铁道数节，围攻车站日军驻所，歼敌二十余。战有两时余，锦州日军派来铁甲车应援，义勇军已获机枪两挺，步枪多枝，弹药甚众，并生擒日兵十余名，仍向辽热边境退去，是日由锦开榆伪满洲国军，迟到三时余。（11日专电）

  • 1932年6月12日讯：蒋介石电召何成濬、徐源泉、夏斗寅等赴庐山，指示“剿匪”机宜。何、徐、夏等于13日抵九江。

1932年06月11日

发表于 2021-06-11 更新于 2021-07-05 分类于 局部抗战(1931-1937)

  • 1932年6月11日讯：开滦赵各庄、马家沟二矿工人1.6万余人，因反对资方取消花红，要求增加工资，相约罢工。后因资方答应工人部分要求，罢工坚持两日后复工。

  • 1932年6月11日讯：汉口商会电复沪全国商联会等团体，响应废止内战，并主张：一、各军、师长以至诚发表消灭内战意见；二、请中央彻底革新政治，以杜战源。

  • 1932年6月11日讯：北平市商会及银行同业公会等四团体电沪，拥护废止内战大同盟运动，并建议在各省、市成立分会。

  • 1932年6月11日讯：宋子文在沪发表谈话，说明辞财长原因，谓“将来财难，必甚于今，军政支出将有增无减”，“在势惟有举债，然挖肉补疮，终将至肉无可挖”。“余心力已瘁，不能再肩财政重任”。

  • 1932年6月11日《申报》：山海关息，日军迭次攻击辽中、台安、盤山、海城一带义勇军无效，近电辽省警备旅王殿忠部及靖安游击队，包抄进攻，战事激烈。（10日专电）

  • #抗战影像#伪满洲国某地罂粟大丰收。

  • 1932年6月11日《申报》：哈尔滨息，中东路东段平靖未久，今日复发生战事。今晨军火车一列由此出发，铁甲车一辆紧随其后，以资保护。至一面坡止沿途均无阻碍，续进至乌吉密河附近时，突有反满军六百人向军火车猛烈攻击。是时适日铁甲车落后，故军火车危险异常。旋铁甲车赶到，以机关枪及步枪还击，剧战数小时后华军退走。是役华军若有任何战炮，定能将军火车炸毁，日方发表日兵死五人。（9日路透社电）

  • 1932年6月11日《申报》：北平息，兴城敌军仍在猛攻，义勇军敢死队长黄纪刚今晨阵亡，受伤兵士十一名，伤入口甚小，出口极大。据军事专家谈，确系达姆弹，三路义勇军长李果中决向日军提出严重抗议。（10日专电）

  • 1932年6月11日讯：立法院通过《大赦条例》，规定凡三年以下有期徒刑、拘役或专科罚金者均赦免之；犯外患罪者不在赦免之列，“反革命犯”赦后得移反省院。24日国民政府明令公布。
