1932年07月25日

发表于 2021-07-25 更新于 2021-08-15 分类于 局部抗战(1931-1937)

  • 1932年7月25日讯：伪满洲国协和会成立，溥仪为名誉总裁，本庄繁为名誉顾问，郑孝胥为会长。该会系日本关东军直接筹建的从思想上统治东北人民的“国民组织”。

  • 1932年7月25日讯：国民政府令：公布《修正蒙藏委员会组织法》；免蒙藏委员会委员石青阳本职；任命张笃伦、陈炳光为蒙藏委员会委员。

  • 1932年7月25日讯：西北问题研究会在沪举行成立大会，胡庶华主席致开会词，说明该会系用科学研究之结果去开发西北，纯为学术团体而非政治团体。大会通过简章，选举职员，并发表宣言。

  • 1932年7月25日讯：何键在湘省府纪念周发表演说，坚决反对中苏复交。

  • 1932年7月25日讯：邮政总局致电国际邮政公署，宣布封锁东北邮务情况，请国际邮联一致行动。

  • 1932年7月25日《申报》：北平息，义勇军郑桂林部伤兵八名，据谈，彼等均系乡民，因愤日军暴行，自动投入义勇军，所经大小战事，不下数十次，多系肉搏。日军兵器虽利，而胆小如鼠，常受上官督促，又不敢不进。故彼等均呼日军为坏种。（24日专电）

  • 1932年7月25日讯：何应钦在京中央纪念周作关于御侮与“剿匪”的报告，声称：“中国目前重要问题，为御侮与剿匪。外侮不御会亡国，赤匪不剿也会亡种。”

  • 1932年7月25日《申报》：哈尔滨息，现闻反满军一队，数约五百，攻击松花江佳木斯西北40里之日兵，又一面坡电称，一面坡为反满军所包围，即将开始攻击，今日阴雨，场地潮湿，故日飞机不能飞起云。（24日路透社电）

  • #抗战影像#伪满洲国皇宫兴运门，为日伪官吏进出伪满皇宫必经之门。图为溥仪在兴运门前参加伪满童子团团旗亲授仪式。

  • 1932年7月25日《申报》：北平息，汤玉麟24日电平，报告热境安谧，并表示誓死守土，愿与热河共存亡。（24日专电）

  • 1932年7月25日《申报》：北平息，外讯，日机数架，23日飞平泉凌源侦察，散发各色传单，语多荒谬，承德亦发现日机散发同样传单。（24日专电）

  • 1932年7月25日《申报》：北平息，王德林部与大刀队千余人，14日向敦化进攻，与义勇军联合，将日军包围痛击，多门师团闻警往援，双方转战三昼夜，日军始退。（24日专电）

1932年07月24日

发表于 2021-07-24 更新于 2021-08-15 分类于 局部抗战(1931-1937)

  • 1932年7月24日讯：日人在长春成立大同学院，是日开学。

  • 1932年7月24日讯：河南鹿邑县长亲带团丁下乡催缴烟款，鞭笞农民，激起众愤，鸣枪抗缴，数十村农民举行起义。

  • 1932年7月24日讯：安徽宿县石乡劣商陈廷芳、张炳怀包办烟税，索价苛重，农民数千人愤起焚毁陈等之房屋。第十二师派第六十八团前往镇压。

  • 1932年7月24日讯：军委会调第三十三师师长葛云龙为中将参议，遗缺由副师长冯兴贤暂代。

  • 1932年7月24日讯：西康旅京人士在京召开救省全体大会，决请国民政府明令讨伐达赖，并准康人组织自卫军。

  • 1932年7月24日讯：上海撤兵区域接管委员会结束，经办事宜摘要连同卷宗交上海市政府保管。

  • 1932年7月24日《申报》：南京息，日人挑衅攻热，外部除迭电颜代表提交国联暨分电驻美各重要使馆转告驻在国政府注意外，并已向日方提出严重抗议。大意谓东省日军尚未撤退，竟复挑衅进犯热河，实属有意扩大事态，违反国联决议案及国际公约，所有一切责任，应完全由日方担负云。（23日中央社电）

  • #抗战影像#伪满洲国“皇宫”莱薰门，为伪皇宫正门，专供溥仪、关东军司令官、和来访的外国元首级人物出入。

  • 1932年7月24日《申报》：东京讯，据天津来电，热河主席汤玉麟之第一第二两夫人，及小孩四名，于昨午后四时，由北平到天津意租界汤宅，同时由热河运到贵重品货车数辆。意租界工部局，疑其内容有紊乱治安之虞，昨夜11时半，搜索汤宅之结果，押手 枪两支，阿片一千包（时价廿五万元）即由公安局向工部局交涉，请其发还，结果工部局仅发还手 枪两支。（23日电通社电）

  • 1932年7月24日《申报》：天津息，东北民众抗日救国军第32路军驻津代表李新三，23日接驻北票代表拍来22日电云，19日午前一时，驻锦州日军高桥中佐，率一联队，急趋朝阳寺增援，途径义县北票间，被我32路军陈总司令清新所部，驻凌南大岭一带之程志远支队长探悉，急埋伏步骑兵二千三百名，待日军半部渡岭时，我军四面猛击，将敌截为数段。乃敌顽强抵抗，血肉相搏，非常激烈。正在短兵相接，敌将全部被扫时，不料敌军援队开到，炮火凶惨，威逼愈急。我因弹药不充，遂暂退却。同时檄调绥义等部，併取游击战略。是役也，计毙日军少佐川岛秀雄一名，兵12名，获步枪14支，马5匹。我军仅伤7名，亡3名。现凌南北票准备迎头痛击，日本迁移鲜农之政策，迄未能实现云。（23日专电）

  • 1932年7月24日讯：陈诚部周至柔、李明两师协同夹攻粤赣边红军，占南康。粤军余汉谋部攻占大庾。第十军徐源泉部黄新、刘培绪两旅攻占湖北潜江县城。

  • 1932年7月23日讯：上海各民众团体联合会召开紧急宣传会议，电促张学良效死战场，以谢国人，并电勉汤玉麟效第十九路军精神，扫除日寇。

  • 1932年7月23日讯：外交部就日攫夺东北盐政事，再次向日本政府提出抗议。

  • 1932年7月23日讯：蔡廷锴在厦门谈第十九路军“剿匪”计划，决定分三步进行：第一步集中兵力，于短期内克复龙岩；第二步由龙岩推进闽西之永定、上杭、连城、武平等处；第三步直捣长汀根据地。

  • 1932年7月23日《申报》：北平息，救国军孙玉田部，在绥中与三百日军激战半日，敌死伤三十八，缴械40余，余突围向绥中城内溃退。（22日专电）

  • 1932年7月23日《申报》：北平息，千五百名义勇军，昨夜围攻凤凰城，并开大炮数门轰击，日守备队受重创。（22日专电）

  • 1932年7月23日《申报》：天津息，汤玉麟之大佐与少佐（姓名不详）两副官，护送汤玉麟所有之贵重品，计满载八汽车，于今夜运送天津意（大利）界汤玉麟之私宅。（22日电通社电）

  • 1932年7月23日《申报》：东京讯，据天津来电，张学良之军队，向热移动，非常迅速。迄21日晨，已有三旅运送完毕，而目下运送中者，尚有四旅。又将平绥路宣化之步兵旅，急送石门镇，津浦路马厂之骑兵旅，及杨柳青之步兵旅等急速准备开往喜峰口。此等开拔部队除归清欠饷外，另给若干之开拔费，其先发队已抵热河。（22日电通社电）

  • 1932年7月23日《申报》：北平息，热河20日21日无冲突，北票尚在我军手中，石本失踪事，正在调查，日炸朝阳安，热当局已向日方交涉。据情势观测，或将不至扩大。（22日中央社电）

  • 1932年7月23日讯：邮政总局奉交通部令，封锁东北各邮务，邮件、汇兑均停寄发。同日，交通部长黄绍竑发表宣言，谓日本指使叛逆攫夺邮政，业务不能执行，被迫封锁东北邮务，以致影响公众交通，一切责任应由日本政府负之。

1932年07月22日

发表于 2021-07-22 更新于 2021-08-15 分类于 局部抗战(1931-1937)

  • 1932年7月22日讯：宋子文与上海银钱业续商币制改革事，决定组织“废两改元”研究会，由中央银行副总裁陈行为主席委员，任命贝淞荪、胡笔江、刘鸿生及西人凯末、麦照特、雷祺为委员。

  • 1932年7月22日讯：导淮委员会副委员长庄崧甫，因兵工导淮不能实行，又无经费而辞职，是日，国民政府令准，特派陈果夫为导淮委员会委员，并代理副委员长。

  • 1932年7月22日讯：红军击溃敌毛炳文、许克祥部10个团，攻克南丰、抚州，南昌大为震动。

  • 1932年7月22日讯：行政院通过教育部所提之整顿教育令：国立北平大学及国立北平师范大学近年来学潮迭起，办学困难，均应从事整理，除平大农、工、医各学院外，其余各学院及平师大一律停招新生；又国立暨南大学教育学院并入文学院，改为教育学系，法学院裁撤，学生转入中央大学肄业。中央大学商学院、医学院，改名国立上海商学院、国立上海医学院。27日教育部令三校遵行。

  • 1932年7月22日《申报》：北平息，何柱国今晨到平谒张（学良），报告榆关防务。（21日专电）

  • 1932年7月22日讯：下午1时，郑州骤起大风雨，夹冰雹巨如鸡卵，历四小时始止，行人被击伤者比比皆是，倒塌房屋数千间，田禾伤十之八九。贾鲁河上游水暴发，沿河房屋漂没，浮尸数十具，为近数十年来未有之奇灾。

  • 1932年7月22日《申报》：北平息，日军此次犯热，意在试探我方态度，及国际间情势，18日攻朝阳后，我力持镇静，各国莫不震骇，狡计卒未得逞。昨今两日，热边颇安靖，义县一带日军，无积极行动，事态渐缓和。（21日专电）

  • #抗战影像#婉容留影，她于1922年12月1日在北京紫禁城与溥仪结婚，后被册封为伪满洲国“皇后”。伪满垮台后，她在逃亡中于1946年病死在延吉。

  • 1932年7月22日《申报》：南京息，朱霄青谈，锦州日军派飞机轰炸朝阳，系意料中事，当不待言。惟石本事件有否，尚不可知，竟借口向热进攻，窥其用意，不过实行威吓手段，以逼热汤（玉麟），至其事件之如何扩大，余未敢下断云。（21日专电）

  • 1932年7月22日《申报》：天津息，攻热日军见东北军已有准备，诚恐徒受牺牲，反予调查团不良印象，适热河驻沈代表，请日军部停止军事行动。日军部队首肯，汤玉麟即派北票商会长邵子峰，20日到朝阳寺，与原田大尉接洽。原田令热军负责拯救石本，并消灭义勇军，形势暂趋缓和。（21日专电）

  • 1932年7月22日讯：汪精卫以日军进攻热河，电令张学良作自卫抵抗，并电促蒋介石回南京共商应付策略。蒋复电称：“剿匪紧张，暂难返京”，并称已令张学良“于受侵袭时尽力抵抗”。
