1932年07月09日

发表于 2021-07-09 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年7月9日讯：台湾公布《资本逃避防止法》。

  • 1932年7月9日讯：国联调查团委员在东京往晤日本陆相荒木，荒木谬称“满洲为日本生命所系，日本防务问题与满洲防务问题不能分开”，“日本一俟满洲国组织完备，当予承认”。

  • 1932年7月9日讯：国民党中央政治会议决议提高常委职权，在国难期间，由常委全权处理一切政务。

  • 1932年7月9日《申报》：北平息，日方在辽西一带收买大股土匪，掠劫焚杀，民不堪扰，纷逃关内。（8日专电）

  • #抗战影像#伪满洲国奉天省公署，原为辽宁省政府。

  • 1932年7月9日《申报》：北平息，三路义勇军7日午在富官屯大败伪组织军，伪军死二百余，获机枪6挺，枪三百余。（8日专电）

  • 1932年7月9日《申报》：北平息，桦川俄军三千人，7日沿松花江向依兰推进，该地日军一中队南退，俄军仍续进。（8日专电）

  • 1932年7月9日讯：朱德毛泽东指挥红一军团、季振同红五军团所属各军与粤军20个团在池江、梅关岭、大庾、南雄县水口圩展开争夺战，经过三天两夜战斗，于11日将粤军全部击溃，红军克水口圩，敌退南雄。

1932年07月08日

发表于 2021-07-08 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年7月8日讯：中国首次参加奥林匹克运动会代表队启程赴美。在上海码头举行数千人参加的欢送会，中华体育协进会董事王正廷授旗并致词。刘长春接旗致答词，表示为国争光的决心。于希渭因日伪阻挠未成行。

  • 1932年7月8日讯：中国教育电影协会在南京成立，通过会章34条，选举徐悲鸿、田汉等21人为执行委员，蔡元培、吴敬恒、汪精卫等七人为监察委员。

  • 1932年7月8日讯：粤二陈争端，经蔡廷锴调停，是日双方接受条件，停止战争。条件为：一、由谭启秀部赴琼接防；二、琼舰队全移厦“剿共”，陈济棠每月助海军费10万元，七个月为期。

  • 1932年7月8日讯：蒋介石新聘之美国顾问裘伟达上校抵沪，协助开办航空学校。

  • 1932年7月8日讯：国民政府任命郝梦龄为陆军第五十四师师长。

  • 1932年7月8日讯：蒋介石任命杨永泰为豫、鄂、皖三省“剿匪”总部秘书长，杨是日到职。

  • 1932年7月8日讯：废止内战大同盟会推举代表朱庆澜、查良钊、陈立廷三人赴粤制止陈济棠、陈策之争，是日乘“胡佛总统号”轮离沪。

  • 1932年7月8日《申报》：北平息，打虎山驻日步兵七百余，山炮4门，铁甲车1列，骑兵40余。黑山站日步兵20余，八道沟20余名，新立屯百余名。日军每日用自动甲车载兵数名，携自动火器，沿路巡察，每夜间各小站驻军，调集大战。（7日专电）

  • #抗战影像#伪满洲国协和会奉天青年训练所。

  • 1932年7月8日《申报》：北平息，日军炮轰辽阳村堡，村舍均为废墟，屠杀居民无算，并绑19名到靶山战札毙。（7日专电）

  • 1932年7月8日《申报》：山海关息，绥中一带乡民，受日军唆使帮匪大肆劫掠，不能安居，接踵来榆，投亲避难。数日来已有5千人以上，榆关当局已饬县府公安局三日内查清具报，并设警卡盘查，以防奸徒混入，而筹救济办法。（7日专电）

  • 1932年7月8日讯：汪精卫邀请各地学术专家胡适、陶孟和、丁文江、蒋梦麟等32人在京集会，讨论外交、内政、建设、教育等问题，外交侧重对日方针，建设侧重财政，教育侧重制度经费。13日闭会。

1932年07月07日

发表于 2021-07-07 更新于 2021-08-28 分类于 局部抗战(1931-1937)

  • 1932年7月7日讯：山东淄博煤矿工人因公司降低工资，群起反对，万余工人7日至9日次第罢工。

  • 1932年7月7日讯：国民政府令：国立北平师范大学校长李建勋辞职照准，任命李蒸为北平师范大学校长；任命郭汝栋为陆军第二十六师师长。

  • 1932年7月7日讯：牛兰夫妇继续在狱中绝食，坚持移沪审讯。

  • 1932年7月7日讯：季振同红五军团击溃乌径、新田之敌张枚新第四师。次日占领信丰城，张师几被全歼，退守水口待援。

  • 1932年7月7日讯：粤陈济棠攻琼军5日晨在榆林港偷渡，被“海瑞”舰察觉击退。是日晨，粤机投弹炸沉琼舰“飞鹰号”。

  • 1932年7月7日讯：财政部长宋子文在沪召集银行界会议，讨论废两改元问题，原则确定采用银元制度，以统一币制，旧铸银元照旧使用；一俟法定重量标准规定后即开始鼓铸新币。

  • 1932年7月7日《申报》：北平息，马占山现确在龙泉，准备总攻，日方传其暂退绥楞或铁骊不确。（6日专电）

  • #抗战影像#20世纪30年代，伪满洲国时期，我东北某地，日本移民妇女正用手纺车进行纺织。

  • 1932年7月7日《申报》：黑河息，丁超率两团部众集结宝清，在县城内北门内设司令部，城内外昼夜放哨，委前桦川张县长编练民壮丁营，每营百五十人，又警团学生三百，由张县长练为义勇军。（5日专电）

  • 1932年7月7日《申报》：黑河息，宫长海、姚秉乾等部自卫军，在五常南山河屯集结，宣称先取舒兰，后攻吉林。冯占海军亦中止攻新立屯，有移向舒兰势，开去榆树之日军村井船桥部，4日返哈。（5日专电）

  • 1932年7月7日讯：国联调查团团长李顿向日本内田外相转达国民政府所拟解决东北问题方案：一、承认满洲自治，中国保有宗主权；二、承认日本在满权益；三、日本从满洲撤军，改变军政状态，公布纯粹的文治制度。内田拒绝接受。

  • 1932年7月6日讯：上海教育界救国联合会通电全国，反对鸦片公卖。

  • 1932年7月6日讯：行政院议决设中央大学整理委员会，聘蔡元培为委员长，李四光为副，顾孟馀、周鲠生、俞大维、竺可桢、钱天鹤、张道藩、罗家伦、谭伯羽等为委员。

  • 1932年7月6日讯：教育部派易克嶷接收中大工学院，为院长顾毓琇拒绝，并表示“如强迫执行，仪器工具等如有失落，应由接收者负责”。

  • 1932年7月6日《申报》：北平息，北镇县义勇军四百余，2日晚联络黑山民团二百约人，向青堆子车站日军60余进攻，激战甚久，义勇军一度占青堆子车站，该路交通停4小时，后大批日军到，义勇军暂退。（5日专电）

  • #抗战影像#伪满洲“皇宫”的勤民楼，伪帝溥仪据“敬天法祖，勤政爱民”的祖训而将其命名。从1932年4月3日始直至伪满垮台，溥仪一直在此处理“政务”，举行典礼。

  • 1932年7月6日《申报》：黑河息，一日向海伦北方进出之日军骑兵部队，在通北附近，与马军骑兵独立大队1七百名相遇，激战甚久，吉自卫军退却。（4日专电）

  • 1932年7月6日《申报》：黑河息，吉自卫军以冯占海为总指挥，宫长海为副指挥，计划进取长春。冯占海军主力现集中榆树新立屯东23里之土桥子，拟再向新立屯日军驻屯处反攻。现冯军与日军村井船桥部队对峙中，宫长海率吉自卫军二千余，集中五常榆树间之四河城，与冯军姚秉乾赵文斌旅取联络推进式，向长春移动。四河城在榆树东方45里，为五榆间要隘。（4日专电）

  • 1932年7月6日讯：朱德红一方面军分三路向南雄进攻。余汉谋派张达师开翁源堵击，派张枚新师固守大余，并急电中央派兵增防赣州。

1932年07月05日

  • 1932年7月5日讯：保定第二师范学校因学潮多日未解决，是日保定驻军及公安局奉令前往接收该校，与学生发生冲突，学生被枪 杀六人，伤八人，被捕38人。

  • 1932年7月5日讯：行政院会议决议：任朱绍良为太湖“剿匪”总指挥，张寅为副指挥。16日，国民政府明令公布。

  • 1932年7月5日讯：江西各业公会以江西省政府值此民穷财尽之际，竟借口“清匪”善后，征特种物品产销捐，加重人民痛苦，呈请行政院电饬该省政府收回成命，速即撤销。

  • 1932年7月5日讯：沪停战共同委员会委员俞鸿钧访该委员会主席克宁翰，报告D区日军延不撤退情形，要求转向日方交涉。

  • 1932年7月5日《申报》：黑河息，二日榆关附近三十里之东西靠山屯有激战，日军追及吉自卫军，猛攻一时许，自卫军撤退榆树。（3日专电）

  • 1932年7月5日《申报》：黑河息，官方得报，李杜军一日攻富锦，伪吉军退桦川。（3日专电）
