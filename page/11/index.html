1932年11月24日

发表于 2021-11-24 更新于 2022-01-14 分类于 局部抗战(1931-1937)

  • 1932年11月24日讯：吉林抗日救国军王德林部进攻黑省珠河（今珠河县），与一面坡日军激战。

  • 1932年11月24日讯：日阁议决定，任命武藤信义为驻伪满大使。

  • 1932年11月24日讯：天津裕元纱厂工人因要求发放制服被开除四人，是晨开始罢工，又被开除12人，工人被迫复工。

  • 1932年11月24日讯：北平大学代理校长徐诵明电教育部辞职。

  • 1932年11月24日讯：翁文灏就任教育部长，但不辞地质调查所长职。

  • 1932年11月24日讯：皖省旅京同乡电国民政府反对米照捐。同日，宋子文电皖省政府，粮食照费商民不得抗缴，如有赴京请愿，定予申斥。

  • 1932年11月24日讯：南京农、工、商、学、妇各团体联名电请国联对日有效制裁，谓对于日本若仍持宽容态度，不予迅速有效制裁，则世界和平基础从此即破坏无余。

  • 1932年11月24日讯：刘文辉、邓锡侯、田颂尧在成都再度协商息争，谓川战发生，皆刘湘所操纵，今后当制止其野心，一切请命中央，谋川局善后。同日，刘湘分电潘文华、王缵绪、唐式遵、穆瀛洲等各督所部分路西进，期于月底攻下成都，完成统一。

  • 1932年11月24日《申报》：北平息，义勇军百余人，前日在北宁路青堆子，掘毁路轨十余丈，图颠覆伪奉山路车。适日军守备队乘甲车梭巡，至此开炮，与义勇军激战。义勇军遂向双台子撤退，伪奉山路车误点四小时，始到榆关，榆关谣言甚炽。（23日专电）

  • 1932年11月24日《申报》：北平息，前几日日机八架飞拜泉轰炸，投弹30余枚，东大营已成一片焦土，且散放传单。令民众将濮（炳珊）扣押之日军下枝少佐联络员，护送海伦或省垣，不准再供给濮部粮物，否则飞机多架，再来轰炸该地街市等恐吓语。（23日专电）

  • 1932年11月24日《申报》：天津息，关外青纱帐倒后，义勇军大部隐于深山，刻各江河封冻，活动较夏便利。日逆甚忧虑，在辽河鸭绿江松花江等江各要镇赶筑土垒，以防义勇军袭击。（23日专电）

  • #抗战影像#“一·二八事变”中，在上海街头一处工事的日本海军陆战队员，中间沙袋上架着一挺日制大正11年式轻机枪。

  • 1932年11月24日《申报》：北平息，苏炳文21日电平称，马主席前由讷河到雅鲁县，已与职及张副司令香阁会面，对黑省军事步骤完全商妥。马主席刻已离县返回讷河，职亦返抵海防。（23日专电）

  • 1932年11月24日《申报》：东京讯，据日内瓦来电，“满洲国”代表丁士源被拒绝入瑞士国境，后经矢田公使周旋，瑞士政府遂登许可入境，已于今晨11时由巴黎出发，晚9时抵日内瓦。（12日日联社电）

  • 1932年11月24日《申报》：东京讯，据日外交界讯，国联一般空气于日本逐渐不利，十九国大会之开幕又迫在眼前。日外部处此状态之下，愈觉有与国联冲突之危险，为缓和目前之危机，日外部除一方训令日内瓦各代表加紧抓作各大国恳其援助外，仍是脱不了虚声恫吓手段，以脱退国联而组织东洋联盟，而中日问题范围属东洋，应在东洋联盟解决等，并宣布要求俄国参加东洋联盟，以牵制英法意各国，企图挽救其喘死之运命。（23日华联社电）

1932年11月23日

发表于 2021-11-23 更新于 2022-01-14 分类于 局部抗战(1931-1937)

  • 1932年11月23日讯：抗日军李海青部收复吉省长岭、瞻榆（今通榆）等县。

  • 1932年11月23日讯：松江《松报》因登载调查仇货新闻，被国民党县党部以“故违法令，鼓动风潮”罪勒令停刊。

  • 1932年11月23日讯：刘珍年部第二旅约6000余人，由烟台分乘五轮，开往温州。

  • 1932年11月23日讯：上海市拥护国联盟约会发表告全国商人书，勉全国商人御侮救亡，提出五事勉商界共同进行：一、拥护国联盟约；二、保持领土完整；三、实施经济封锁；四、援助东北义勇军；五、制裁破坏盟约及世界和平之野心国家。

  • 1932年11月23日讯：国民党中央政治会议通过建设陪都西京、行都洛阳案，交行政院、军委会妥议办法进行，并通过保留行都中央党部及国民政府现有地址等案。

  • 1932年11月23日讯：国民政府为息川事，重申民国十七年整理川政之命令，交行政院详定实施办法，并令川军各将领暨行政专员“引咎互让，立止干戈”，依院决办法实行。

  • 1932年11月23日《申报》：北平息，日军令伪国强迫各县增兵，大县增四千，中县三千，小县二千，准备再东北成立10个师，由日军官训练三个月，预备进犯热河用。（22日专电）

  • 1932年11月23日《申报》：北平息，日军再满洲作战，使逆军在前线，日兵在后督战。伪军以与苏炳文宫长海袍泽关系，不肯拼战，日兵在后严重压迫，后退即以机枪扫射，伪军被日军击毙者，比战死者多。日对大部义勇军进攻，对小部义勇军实行分散，意图义勇军潜伏各村人民不能安居，纷逃关内，日人可享有其土地权，其计阴毒。（22日专电）

  • 1932年11月23日《申报》：沈阳息，辽东义勇军六十八人被捕于安东县，分禁两处。昨夜11时半，同时破狱脱出，日军警接讯，即时派警查询情形。仅见监房被冲破，并不能发现任何踪迹。日方疑为守监华人被义勇军收买内应，将华人巡捕在日宪兵队询讯中，又恐义勇军乘机攻日侨，守备队派兵守各关隘云。（22日专电）

  • 1932年11月23日《申报》：北平息，救国军总部参谋长谢珂，20日电平云，19日晚日军高波部队，以坦克车队为前锋，掩护其步马队兵千余，向莲花镇我黄团阵地进攻。同时日军黑由之助部队，由林家店，向我吕团进攻，激战一夜，日军不支，向兴凯山退却。我军仍固守拜泉，刻正由大黑岗子山，调来张旅增援，期一鼓歼灭日寇等语。（22日专电）

  • #抗战影像#“一·二八事变”中，两名日本陆军士兵正用担架运送一名负伤的同伴。

  • 1932年11月23日《申报》：华盛顿讯，（美国）国务院自日内瓦议会开始以后，因恐外界误会，美国对于满洲问题之态度将极端保持缄默。但消息灵通人士相信，国联会对于中国若保持有利态度，则列强均将宣言拒绝承认“满洲国”，至美国采取此种态度之意，怀之已久云。（22日哈瓦斯电）

  • 1932年11月23日《申报》：东京讯，伪组织傀儡丁士源由巴黎往日内瓦，被瑞士政府拒绝入境，目下徘徊巴黎郊外，进退维谷。乃电告关东军及东京日外交部周旋，因傀儡不能入日内瓦，故日外部焦急万分。（22日华联社电）

  • 1932年11月23日《申报》：天津息，东北国民救国军独立第七支队长付殿臣部，在苦战中。罗明星部攻吉长路大胜。（22日华联社专电）

1932年11月22日

发表于 2021-11-22 更新于 2022-01-14 分类于 局部抗战(1931-1937)

  • 1932年11月22日讯：河南灾民500余人乘车至长辛店站，要求换车至浦口，因无车皮，与路警发生冲突，捣毁车站玻璃门窗等，经站长及公安局劝导，并允将灾民送至郑州再转浦口，始平息。

  • 1932年11月22日讯：川军邓锡侯通电戴季陶、石青阳、张群及旅外川绅，请转恳中央严令各军停战。

  • 1932年11月22日讯：安徽旅沪同乡会代表李振亚等，控告国民政府救济水灾委员会办赈人员杨树诚、余绍武、查良钊、王范五等在皖北办赈贪污巨款案，是日，上海第一特区法院开审。

  • 1932年11月22日讯：苏省京沪民食调节协会致电行政院代院长宋子文，请速明令各省开放省界米禁，免除米谷捐税，并推代表赴省府请愿，要求立即撤销苏省米禁。

  • 1932年11月22日讯：第九路军孙连仲自20日起率五个团分三路进攻金溪，红一军团一部偷渡抚河袭临川，孙部侧背受胁，是日撤出临川。

  • 1932年11月22日讯：东北义勇军将领苏炳文、马占山、丁超、李杜、王德林、李海青等联名致电国联，声明东北民众誓必抗日，决不屈服，除非杀尽东北3000万人民，决不许傀儡组织存在，更不能抛弃主权，造成所谓共管局面，政府纵不能收复失地，人民则誓驱日寇，还我河山。

  • 1932年11月22日讯：国民党西南政务委员会决议反对续借美麦。

  • 1932年11月22日讯：立法院通过《行政执行法》。

  • 1932年11月22日《申报》：北平息，日人近在辽西各县，实行调查户口，复出大宗金钱，利用汉奸，在各地收编民团应募者每人月薪18元并发械弹给养服装。近迫伪政府分令各区，实行併村政策，限定三千亩为一寸，移植鲜民。中外杂居，广置电话材料，移民后在各村设电话，并实行设警察，期夺我警政权。民众痛朝鲜亡国之惨，深望国军出关。（21日专电）

  • 1932年11月22日《申报》：北平息，日机一大队共42架，19日由沈阳起飞，飞往北满。此为第一批，尚有二三两批，即起行。（21日专电）

  • #抗战影像#“一·二八事变”中，在上海的日本侨民正在欢迎一支日本陆军部队进入上海市区。

  • 1932年11月22日《申报》：哈尔滨息，据日方报告，日军对义勇军之进攻，现正在进行中。战争之范围，现已扩大，义勇军现集中拜泉，成半圆形之战线，日军分五路向拜泉进袭。此项战事，若日方获利，则该处之义勇军势必退出。由海伦进攻之日军，已遭遇最大之困难，该处作战最烈，双方死伤均重。由沙河集进攻之日军，闻已到达距拜泉三里之地点，该处现有义勇军五千人集中。闻日军行动遭遇最大之困难，在土地泞湿不良于行。在拜泉以北，义勇军正猛烈袭击日军，企图击破日军之包围阵势，宁古塔方面亦有战事，驻守宁古塔之日军，已为义勇军千人驱逐退离云。（20日路透社电）

  • 1932年11月22日《申报》：南京息，日对李顿报告意见，21日正式发表，内容荒谬绝伦，措辞蛮横无理，开国际外交文件未有之奇态。现国联已引起极大反感，美国亦已驳斥，外部以国联开幕伊始，虽政府某要人，1日已驳斥，但仍须痛驳，文已草就，22日发表。（21日中央社电）

  • 1932年11月22日讯：行政院会议，交通部长朱家骅报告处理招商局经过，并通过准刘珍年辞鲁省府委员职。

1932年11月21日

发表于 2021-11-21 更新于 2022-01-14 分类于 局部抗战(1931-1937)

  • 1932年11月21日讯：温州旅沪同乡会分电军委会和军政部，反对刘珍年调浙。

  • 1932年11月21日讯：刘文辉、邓锡侯、田颂尧会衔通电停战，共谋善后。22日，刘、邓、田继续会商，决定五项善后办法：一、刘、邓、田联名通电停战，三部将领通电赞成；二、田自动表示与邓、刘合作到底，不受他方利用；三、由邓担保开放成都北门，使城内田部扫数安全退出城外；四、由三部共谋整个和平办法，期在三数日内川省战争一概停止；五、最短期内召开全川将领会议，以谋军事、政治、交通诸重大问题之整个解决。

  • 1932年11月21日讯：北平商会召集各团体开会，反对续借美麦，电请中央停签合同。

  • 1932年11月21日讯：国民党中央开中委谈话会，推陈果夫、程天放、段锡朋、邵元冲、蔡元培五人为电影文化委员会委员。

  • 1932年11月21日讯：国联行政院开会，讨论李顿调查团报告书，日本代表松冈洋右和国民政府代表顾维钧相继发言，互相指责。23日，国联行政院继续开会，各国代表发言，均不承认“满洲国”，主张日本即速取消“满洲国”。24日，顾维钧发言再驳松冈九一八事变为日人自卫行为，“满洲国之成立，为当地人民自由志愿之行为”之谬说。26日，国联行政院将李顿报告书及本届会议记录移送十九国委员会讨论。

  • 1932年11月21日《申报》：齐齐哈尔息，（日军）松本某部从小蒿子、安达、海伦、克山、泰安镇五个方向开始向拜泉县城前进。昨日（19日）清晨，将拜泉县城完全包围，开始进攻。日本战车队之一队，从小蒿子泰安镇之中间地点，冲破义勇军防线。日机多架，飞翔泰安镇及克山上空，猛烈轰炸义勇军阵地。据昨午后日机之侦察，义勇军最后防线在拜泉城上，列炮数十尊，强硬抵抗，直至城破阵亡。最后消息，拜泉于今晨八时被日军攻陷，最先入城者为日军高波骑兵部队，拜泉现已被日军完全占领。（20日电通社电）

  • 1932年11月21日《申报》：北平息，外讯，连日日满联军向安达、卜奎、海伦、望奎一带输送，不下5个师团之多。仅安达即有万余人，战斗空气紧张。拜泉南义勇军邓文部积极补充，双方仅距20余里，时有小冲突。日机每日盘旋空中五六十架（次），时向义勇军防地投弹轰炸。（20日专电）

  • 1932年11月21日《申报》：北平息，安东外电，伪国现收买流氓土匪，编成八旅，旅长已内定，名单未发表，期以之解决东边各地义勇军。（20日专电）

  • 1932年11月21日《申报》：北平息，王德林16日电平云，副司令吴义成，13日与各将领计划，分三路进取吉林。吴任中路，取江密峰；刘旅任左路，取阿格什哈；张旅任右路，取高亮口。13日夜开始总攻，翌晚，敌不支，退江同守，我军猛进，敌不抵抗后退。晨9时将江密峰完全占领，敌刻退守距吉垣50里之阿什哈，右路高亮口敌不战而退，将该处占领，不久仍将向前推进，刻在苇河，已布置完竣，日内当有激战。（20日专电）

  • 1932年11月21日《申报》：北平息，绥中北乡为热孔道，连日发现日便衣队多次，义勇军派出干员，分批四处侦查，已拿获日便衣队多人，送回审办。（20日专电）

  • 1932年11月21日《申报》：北平息，热河来人谈，日军原在通辽百余人，现有正增兵一师团消息，日机连日运输炸弹及军用品甚多，极忙碌。11日，日机5架，轰炸开鲁县城，投弹6枚，落南门外，伤士兵2人，百姓死1人，牲畜5只。又在最前线道太影子投弹10余枚，炸伤士兵1人，马30余匹，炸弹坑深六尺，义勇军某部支队长刘剑人、包克刚等仍在康平瞻榆联络胡宝山部，对昌图待机而发，威胁敌军右侧。卫队长毕克宗训勉义勇军努力抗日。（20日专电）

1932年11月20日

发表于 2021-11-20 更新于 2022-01-14 分类于 局部抗战(1931-1937)

  • 1932年11月20日讯：顾维钧访国联行政院主席狄凡勒拉，盼速解决东北问题。下午，颜惠庆告各国记者，称“中国政府无意推翻李顿调查团报告书”，“中国政府将不至宣布不顾李顿调查团之劝告，采取一种直接违反李顿建议之方针”。
