1932年10月02日

发表于 2021-10-02 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1932年10月2日讯：旅京江西同乡千余人集会，反对江西省主席熊式辉强征产销税，增重江西人民负担。

  • 1932年10月2日讯：刘文辉部与刘湘部开战，刘湘急调鄂西“剿匪”部队回川。同日，蒋介石致电刘湘、刘文辉等令各饬所部，勿轻启衅端。

  • 1932年10月2日讯：韩复榘部与刘珍年部在胶东掖县县城炮战甚烈。何应钦再电促韩、刘切实停战，并电蒋介石请示处置办法。

  • 1932年10月2日《申报》：北平息，义勇军二百余人30日攻绥中县城，至距城八里某地，日军闻警赶来应战，双方激战竟日，均有伤亡。县城紧闭，铺商停止营业，因日军大炮威胁甚烈，义勇军暂退。（1日专电）

  • 1932年10月2日《申报》：北平息，义勇军孙国儒部第三四两支队队长孙德儒、孙助国，率众500人，27日夜偷渡半拉门河口，偷袭饶阳河白旗堡两车站，均被攻下。毙敌7名，获枪9枝，铁轨拆毁20余段，拂晓南北甲车均开至，两站义勇军今退原防，孙部死一伤三。（1日专电）

  • #抗战影像#一队行军中的日军背负着阵亡者的骨灰盒。

  • 1932年10月2日《申报》：哈尔滨息，东铁护路军苏炳文部已与李海青军连成一气，黑省伪国军队中约700余人，亦与李海青军有联络，闻定日内组成联军，分途攻入齐齐哈尔。伪黑省主席已请援于伪军政部，日内将有大战，齐齐哈尔以西之铁路、电信、电话依然不通。（1日华联社电）

  • 1932年10月2日《申报》：南京息，据美联社消息，李顿调查报告长350页，分10章，首述中国关内情形，次述满洲历史及引起九一八事变原因，第三章以下分述满洲九一八以后现状，末章调差团建议，大致主权归还中国，日本得经济开发权利。但未提及恢复九一八以前原状，主张组织新行政机关，由中国自由意志聘外国顾问，襄助治理。当地税收，以关税附税盐税邮政收入，归国民政府，其余归地方政府。关于军事方面，建议由中国与日本，会同使满洲不驻军队，永除冲突根源，至对于满洲案责任一层，虽无切实断定语，据闻曾表示满洲在旧政府统治下之紊乱，不足以为日本占据领土之适当理由。（1日专电）

  • 1932年10月2日讯：《国联调查团报告书》在日内瓦、南京、东京三地同时发表。《报告书》承认“九一八”为日方“预定精密计划”所造成，但认为满洲问题之解决，必须“遵守现行多方面之条约”，“承认日本在满洲利益”，并提出国际共管东三省，设立“自治政府”的荒谬主张。

  • 1932年10月1日讯：荷属东印度政府颁布限制华人教育的《野校条例》（又称《取缔私立学校条例》）。

  • 1932年10月1日讯：《女声》半月刊在上海出版。

  • 1932年10月1日讯：察哈尔省教育会、农会、商会等各团体派代表王润亭等到北平向宋哲元请愿，反对察省财厅提高营业税率和增加捐税。

  • 1932年10月1日讯：黑龙江省邓文部救国军攻克安达县城，将伪军千余名缴械。

  • 1932年10月1日讯：内政部通令全国各省、市筹款设仓，购粮囤积，以调剂农民经济。

  • 1932年10月1日《申报》：北平息，义勇军百余名，连夜袭击沈阳大东边门，并以巨炮向兵工厂轰击，兵工厂27日夜起火，旋扑灭，沈阳四门均堆沙袋电网，坦克车在郊外梭巡，城内人心极恐慌。（30日专电）

  • 1932年10月1日讯：立法院修正通过《统计法》及《导准委员会组织法》。

  • 1932年10月1日《申报》：北平息，榆关伪官吏连日派伪警勒索商民，逼令纳税，并强迫运货物出口，商民不敢抗。（30日专电）

  • 1932年10月1日讯：国民政府公布《民国二十一年湖北善后公债条例》，发行额300万元，年息八厘，10月1日起发行，至1939年6月止还清本息，以该省营业税收入为基金。

  • 1932年10月1日讯：林森由沪赴闽，调解闽省省防军第一旅旅长陈国辉被扣事。

  • 1932年10月1日《申报》：山海关息，沈阳来人谈，张逆海鹏自附逆媚日后，对所部渐失统驭力量，部队形虽团结，实已分化。瞻榆县被义勇军攻克后，张部遂有三团首起反正，与义勇军结合，增厚抗日实力。亟向四洮洮昂两路伸进，张部虽仍多属执迷不悟，但士气大挫，纷纷投顺。（30日专电）

  • 1932年10月1日讯：日籍伪警强占榆关东罗城门楼，进而强占天下第一关城关，击毙我哨兵一名，何柱国为自卫计，下令还击，毙日籍伪警一名。驻南关日守备队出动。经何柱国会同日守备队长落合及日宪兵队长同赴现场调查，东罗城始恢复原状。

  • 1932年10月1日《申报》：山海关息，义勇军连续收复突泉、洮安、泰来、开通等县，复攻洮南。洮南逆部较多，实约有六团，未能立时攻溃。义勇军现仍期图短期内击破洮城，外并施抚绥办法，促该部队自悟来归。（30日专电）

1932年09月30日

发表于 2021-09-30 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1932年9月：《海外月刊》在南京创刊，报道华侨事务为其主要内容。

  • 1932年9月：中国诗歌会在上海成立，“左联”领导下的新诗歌团体，由森堡（任钧）倡议，穆木天等人发起，以推起进新诗歌运动、致力于中国民族解放、保障诗歌权力为宗旨。

  • 1932年9月：陶行知在上海大场孟家木桥村创办“山海工学团”，开始新的乡村教育改革实验。宗旨是：工以养生，学以明生，团以保生。把工厂、学校、社会打成一片。

  • 1932年9月下旬：内政部统计全国人口总数为4.74787386亿人。

  • 1932年9月30日讯：张群电劝刘文辉、刘湘息争，听候中央秉公处理。西康民众驻京代表马泽昭呈请中央制止川战。同日，废止内战大同盟电请川军将领息争御侮。

  • 1932年9月30日讯：晚7时，英使馆职员梯莱将国联调查团报告书送达外交部。

  • 1932年9月30日讯：司法院令最高法院、司法行政部否认西南成立最高分院，咨西南政委会迅行撤销。

  • 1932年9月30日讯：国民政府令免甘肃宣慰使孙蔚如本职，另任为陆军第三十八军军长。

  • 1932年9月30日讯：蒋光鼐呈行政院报告扣押陈国辉经过及列举其虐民罪状，请示处理办法。行政院决定由该绥署组军事法庭会审严办。

  • 1932年9月30日讯：川军刘文辉与刘湘争夺地盘，有一触即发之势，是日，行政院决议严厉制止，派何应钦负责处理。

  • 1932年9月30日讯：行政院会议，何应钦报告韩复榘、刘珍年两军近况，称军委会决令刘军缩小防区，韩军后撤，派蒋伯诚赴前线监视，纠纷即可解决。

  • 1932年9月30日《申报》：北平息，沈讯，义勇军某部副官杨明武，11日率兵李仁来等三名，赴沈阳城东，被敌捕去。该队长闻讯，派某支队潜伏沈西，准备路劫，营救未遂，杨等遂被杀。16日日队长石田率队由防卡经过，被潜伏义勇军包围缴械，押回队部，24日将石田队长及伏谷士官长、士兵22名枪决。（29日专电）

  • 1932年9月29日讯：日军第十四师团在齐齐哈尔南围攻李海青抗日义勇军。
