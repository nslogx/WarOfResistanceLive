1932年12月12日

发表于 2021-12-12 更新于 2022-01-06 分类于 局部抗战(1931-1937)

  • 1932年12月12日讯：自政府明令将招商局收回国营后，该局股东起而组织法益维持会，研讨维护股东利益，是日该会在沪招待报界，反对政府以每套价银50两收回股票（按：依该会主席李次山报告，每股应得资产价值银600两以上），决派代表入京向三中全会请愿，并向监察、立法两院商议此次政府收回招商局手续问题。

  • 1932年12月12日讯：沪杭甬铁路各站职工因加薪不平等，经派代表赴总局请愿，未得圆满结果，是日举行罢工，要求当局迅予解决。京沪、沪杭甬铁路管理局局长陈兴汉向铁道部辞职。

  • 1932年12月12日讯：废止内战大同盟会总会常委王晓籁、杜月笙、林康侯等37人通电中央党部、行政院等，以刘湘无故枪 杀四川大学学生，封闭《新蜀报》，封闭川省裕通银行，要求中央予以严厉制裁，褫夺刘一切职位。

  • 1932年12月12日讯：下午，中国代表颜惠庆与苏联外交人民委员李维诺夫在日内瓦交换中苏复交照会，宣布中苏两国政府自即日起恢复正式外交关系，照常交换使领。

  • 1932年12月12日《申报》：山海关息，炮击榆关事件解决后，地方形势11日完全恢复，11时有日飞机七架，由关外列队飞来，分三组巡绕榆城，经半小时始向东飞去，榆关秦皇岛均安静无事。（11日专电）

  • #抗战影像#“一·二八事变”期间，以保护使馆和侨民名义被派遣到上海的一支美国海军陆战队，他们正在列队进入上海市区。

  • 1932年12月12日《申报》：北平息，日军对热边，除在锦朝路线上北营子南岭等处积极布置军事外，昨突在绥中增驻军队五百名，并利用前直鲁联军遗孽程国瑞为伪救国军总司令，召集散兵游勇等，沿六股河将向凌源进袭，程已在绥中着手组织伪部，一切动作，均听命日人。（11日专电）

  • 1932年12月12日《申报》：北平息，义勇军耿继周部二千余，由李升久率领，6日由新民东高台子进攻新民，晚与日军七百名激战数小时，日军开来甲车三辆，援军五百余，向我总攻。我军取包围势，猛攻二小时，日军不支，退至城垣固守，义勇军占领新民车站，刻仍激战中。（11日专电）

  • 1932年12月12日讯：国民党留粤中委邹鲁、邓泽如、李宗仁、刘芦隐等14人电三中全会，借口“职守羁身”，不出席会议，希望今后“执行第四次全国代表大会及一中全会之各项对外对内决议案，永远阻止独裁，协同剿共，实行抗日”。

1932年12月11日

发表于 2021-12-11 更新于 2022-01-06 分类于 局部抗战(1931-1937)

  • 1932年12月11日讯：中央红军在闽赣边战斗后，分成三路：红三、五两军团由黎川入建宁；红十二军由资溪入光泽；红十军回信江北岸。

  • 1932年12月11日讯：工农红军闽浙赣军团总指挥部通电，奉苏维埃中央革命军事委员会命令，闽浙赣新苏区正式宣布成立。方志敏任省苏维埃政府主席。辖区达20余县。

  • 1932年12月11日讯：蒋介石委任卫立煌兼鄂东“剿匪”总指挥。

  • 1932年12月11日讯：蒋介石向内政会议提出重新制定县、区、地自治法规，区或镇以下施行保甲制度案。

  • 1932年12月11日讯：中国驻英使馆在伦敦发表宣言指出，据正式统计，九一八以来，日军屠杀我国同胞达5.8248万人，上海一二八损失尚未包括在内。

  • 1932年12月11日《申报》：北平息，苏炳文、张殿九、谢珂等仍在赴莫斯科途中，平方接谢珂电称，预定下星期三四抵莫斯科，稍停留即转德美，再往日内瓦，向国联报告。苏炳文眷属等已到海参崴，日内转沪来平。（10日专电）

  • 1932年12月11日《申报》：北平息，冯占海率部西进时，所部步兵第一旅张纯玺部，及骑兵第一二两旅，被留吉西其塔木等处，计共官兵一万三千余人，前数日该部行经松花江北岸，甫将渡江，隔岸刘铁民、尹保衡及日蒙兵突开炮射击，我方还击，鏖战二昼夜。嗣扶余商会及各法团等，一再要求停战，并捐送我方毡鞋皮帽各二千件，我军始允所请。敌军伤亡甚众，我阵亡连长三、士兵六，伤20余。（10日专电）

  • 1932年12月11日《申报》：北平息，丁超、李杜两部均在依兰桦川沿江一带据守。（10日专电）

  • 1932年12月11日《申报》：北平息，辽河西方一带，义勇军老北风及三胜海联合军二千人，6日晨进攻辽中逆军王殿忠部，激战7小时，逆军不支，日军派五百名增援。我军用大刀长矛奋战，日逆军伤亡甚多，向辽河南溃退，我军追击，在辽河岸俘逆军三百，全部缴械，毙日逆军50余名。（10日专电）

  • #抗战影像#日本于侵华战争时期制作美化侵略战争的明信片，宣扬日本陆军士兵与中国儿童友好相处。

  • 1932年12月11日《申报》：北平息，8日晚日军开炮，榆关城内二弹落第九旅司令部门前，一落何柱国公馆，二落公安局旁，击毁房屋20余间。榆关戒严，城门关闭，仅开南门，商民许出城，不许入城。榆关车站水塔，被日军炮火击穿一巨孔，塌陷甚多，榆关段长英人高累派工今晨修复。（10日专电）

  • 1932年12月11日《申报》：北平息，今日下午1时何柱国与若河会晤，日允将甲车后撤，下午4时甲车一辆离榆东开，其一尚待榆关外，日军撤回原防，形势略缓和。（10日专电）

  • 1932年12月11日《申报》：北平息，秦皇岛海港，9日晨开到日本海军水上飞机母舰一艘，驱逐舰二艘，日兵数百名，往南沿日兵营驻防，秦皇岛车站，由何柱国旅曹团驻防。（10日专电）

  • 1932年12月11日讯：何香凝复函第十五师特别党部不出席三中全会，略称：现接中央及贵师特别党部来函，催促入京参加三中全会，“衮衮诸公，党 国名流，出席者大有人在，如能各出真诚，一致共趋国难，对于一二人之出席，不成问题，否则亦何补于事，凝以抱病之躯，无裨于事，不愿力疾入京，以增病苦”。

1932年12月10日

发表于 2021-12-10 更新于 2022-01-06 分类于 局部抗战(1931-1937)

  • 1932年12月10日讯：国民党北平市党部接中央党部密令，饬即“严捕共党负责分子解京法办”。是日，北师大教授马哲民被北平公安局逮捕，11日平大教授侯外庐被捕，13日北大教授许德珩亦以共产党嫌疑被捕。农学院进步学生18人被捕。

  • 1932年12月10日讯：训练总监李济深离沪赴港养病，致电蒋介石，称即日具呈国府，请辞本兼各职。

  • 1932年12月10日讯：蒋介石乘舰离汉赴京，出席国民党三中全会。12日午抵下关。

  • 1932年12月10日讯：第二次全国内政会议在南京开幕。下午，举行首次大会，黄绍竑主席，国民政府主席林森讲话，声称“此次内政会议实为今后政治修明之关键，其重要直与国民会议相仿佛”。

  • 1932年12月10日讯：何柱国与日守备队长落合及日军第五联队长谷仪一等在山海关南关谈判。日方以高压手段强迫何承认炮击事件“系出误会”，由中方赔礼道歉。何为缓兵之计，予以妥协。是日下午，日军退回原防。

  • 1932年12月10日讯：邓乃柏和张纯玺部进抵热河下洼镇，与先期到达的主力部队汇合，至此，东北义勇军第三路冯占海部，全部到达热河省东部，兵员达到4万人左右，总指挥部设在热河建平县下洼镇，其他部队分布在绥东、建平、乌丹城、赤峰等几个县。

  • 1932年12月10日讯：红36军独立师奉命西征，以期会合那里的李海青、邓文部义勇军，但行至泰来时，得知李、邓已开往热河，独立师只好回师东归。在此过程中，受“王明路线”影响，每到一个地方就打土豪、分田地，进行土地革命，逐步丧失了武器和粮食的主要来源，部分地主家庭出身的指战员纷纷离开部队。

  • 1932年12月10日讯：日军仍在东罗城外的威远城线构筑工事。何柱国赶往北平向张学良汇报。张学良主持召开军事秘密会议，并以海陆空军副总司令名义，令商震32军开赴滦河，宋哲元29军开赴喜峰口，王以哲军（后以徐庭瑶部代替）开赴古北口，万福麟和缪澂流部邻口以北支援。

  • 1932年12月10日《申报》：北平息，苏炳文秘书长贺圣达7日电到平称，苏等抵大乌黑后，同行官兵眷属暂留该处。苏偕张殿九、贺珂、金奎壁、郭竹书等及随从共10余人，继续前进。6日到赤塔，莫德惠派王曾思前往迎接，苏赴莫斯科，与莫会晤后，再定赴日内瓦与否。据苏俄驻平代表谈，苏炳文决赴日内瓦，向国联陈述日人暴行，再由欧陆返国。（9日专电）

  • 1932年12月10日《申报》：北平息，上月10日义勇军邓铁梅部蔡文辉、李福田、赵庆吉、刘紫宸分四路攻凤城，一度占领，毙敌松井大尉一名，日军二十余名，获日人永吉一名，鲜人金德生一名，及华工61名。据称，拟赴北井子，修筑由安东经过龙王庙、黄土坎、大孤山至庄河之汽车站，将日鲜人枪毙，华工解散。邓部防地领有黄土坎至北井子礁西间一带，势力甚雄厚。（9日专电）

  • 1932年12月10日《申报》：北平息，马占山仍在黑省东北部地方，部下尚有万余人，对日抵抗到底。（9日专电）

  • #抗战影像#日本移民居住的“生琉里”：日本青少年“义勇军”被移往中国东北后，即进入设在东北的训练所，接受军事、农业及其他技能的训练。日本在伪满洲国滨江省(今黑龙江省)某县设立了“天理村生琉里”移民村，当年移民45户二百多人。在这之后，又有第二批、第三批日本移民移居此地，形成日本移民的居住“团地”。

  • 1932年12月10日《申报》：山海关息，8日夜事件继续交涉，经过良好，日铁甲车将即开回关外。日对炮击责任之曲解，谓因误解而发生，秦皇岛安静无事。（9日专电）

  • 1932年12月10日《申报》：北平息，昨晚10时余，日铁甲车一列，突由下家屯开至榆关内车站，第二道扬旗外石河地方，向车站开炮三响，将车站旁水塔击毁。旋又向城内猛轰三炮，伤居民及房屋甚多，人心恐慌。各处枪声四起，我城内驻军，力持镇静，并妥为布置。一方由何柱国派参谋，往见日守备队长落合，询以日军此项举动用意，并请其命令日军停止举动。否则发生不幸事变，全由日方负责，落合诿称不知详情，允即饬令该日军停止炮击，至今晨一时始平静。（9日专电）

  • 1932年12月10日讯：废止内战大同盟总会常委会决议：一、推林康侯等三人为代表，向三中全会请愿制止内战，一致对外；二、普征会员，增厚力量；三、电请中央严厉制裁刘湘，通电全国勿与刘湘合作；四、实行与内战者不合作；五、联合旅沪贵州同乡设法制止黔乱。

  • 1932年12月10日讯：我义勇军第二军团在关门山设伏，居高临下，动用火炮轰击，毙伤日伪军不计其数，下午发动反攻，至晚间，俘获日本指挥官成泽直亮以下日伪军500余人，缴获其随身所用“马牌”手 枪一支（该枪后赠与东北救亡总会秘书长于炳然带往延安）。我军胜利突围。

  • 1932年12月10日讯：自本日至15日，刘湘、刘文辉两军于乐山、井研、仁寿等地血战五昼夜，双方伤亡均重。

1932年12月09日

  • 1932年12月9日讯：退入苏联境内之苏炳文及其随员征求苏联政府同意假道赴欧。上日，日驻苏代办天羽要求引渡苏炳文等，苏政府依据国际公法严辞拒绝。是日再声明凡随苏炳文入境之华人愿留苏境工作者悉准居住，代觅职业。

  • 1932年12月9日讯：驻津日领谒河北省府主席于学忠提出抗议，诬山海关我驻军枪击日军，并以同样内容通知驻津各国领事，混淆听闻。日驻华使馆武官永津致函北平军分会参谋长荣臻，诡称日装甲车赴山海关车站装水，忽被何柱国军所射击，“不得已而应战”。

  • 1932年12月9日讯：刘文辉急谋与田颂尧携手，令所部退出成都，转移新津。是晨田部占领成都。

  • 1932年12月9日讯：蒋介石以安徽人民抗缴米照捐，特电该省主席吴忠信制止，并称：“倘仍有此等情事，即以妨害政治，扰乱秩序论。”

  • 1932年12月9日讯：我山海关守军东北步兵独立第9旅旅长何柱国前往交涉，日方提出由何柱国创立一个包括滦东和热河的缓冲区，实行独立自治，否则即以武力占领长城，入关攻取平津。

  • 1932年12月9日讯：东路由凤凰城出动的日伪军在岫岩地区为邓铁梅部阻击在岫岩以东的龙王面地区，南路伪军则在岫岩以南逡巡不进，未能形成合围。北路日军两个中队及伪军，西路日军骑兵一个中队及伪军先后在大偏岭、关门山、磨盘沟、黄花店一带与我军接战，我初战不利，撤集关门山和磨盘沟。

  • 1932年12月9日《申报》：北平息，王德林四日电平称，职已与丁超、李杜联络一致，乌珠已为我军占领，日内即向滨江总攻，日军刻退守距离滨江百七十里之利里河子。哈埠已早恐慌状态，日军输送连日不绝，松花江已结冰，我军活动甚力，吉垣又增日军千余，谋向我军进击。（8日专电）

  • 1932年12月9日《申报》：南京息，忠勇抗日之苏炳文将军率部退入俄境后，曾电政府，请向苏俄政府交涉护送回国，闻外部已电令王曾思与俄政府交涉云。（8日中央社电）

1932年12月08日

发表于 2021-12-08 更新于 2022-01-06 分类于 局部抗战(1931-1937)

  • 1932年12月8日讯：夜10时，日关东军第四旅团第五联队铁甲车一列自绥中驶抵山海关车站东口，向车站开炮数发，将车站旁水塔击毁，伤看守夫役一人；旋向山海关城内开炮十余发，并投掷炸弹。守军第九旅旅长何柱国当与日驻榆守备队长落合严重交涉，允将日铁甲车退至车站静候交涉，至次晨2时始停止射击。

  • 1932年12月8日讯：由建设委员会、国防设计会、扬子江水道整委会合组之长江上游水力勘察团发现宜昌葛洲坝有巨大流水量，每秒为6.5万立方尺，向建委会建议筹设水电厂。

  • 1932年12月8日讯：国联大会第三日，爱尔兰、西班牙、捷克、瑞典四国代表提出议案，请国联否认九一八事件为日本自卫行动，不承认日本卵翼下之伪满洲国，并建议邀请美、苏加入十九国委员会参加协议调停。日使松冈反对，要求将该案撤销。郭泰祺郑重声明拒绝中日直接交涉，谓任何解决方案，必须以盟约及中国主权完整为基础。

  • 1932年12月8日讯：广州学生抗日联合会电国民政府请出兵援助苏炳文，并通电全国援助义勇军。

  • 1932年12月8日讯：陈诚电约蔡廷锴第十九路军进攻赣闽边中央红军。

  • 1932年12月8日讯：蒋介石为对鄂、豫、皖三省原红军根据地13县实行经济控制，令农村金融救济处迅筹设农民银行。

  • 1932年12月8日讯：日军侦知我义勇军第二军团海运械弹成功，纠结日伪军数千人四面围剿我在岫岩以北海城凤凰城交界山区的部队。

  • 1932年12月8日讯：苏联外交委员会委员李维诺夫在日内瓦和国民政府出席国际联盟代表团团长颜惠庆达成协议，两国拟恢复邦交。此时，退入苏联境内的苏炳文部突然受到苏联方面的热烈欢迎。

  • 1932年12月8日《申报》：南京息，复旦社讯，长江一带日货，上月进口达五六万吨，价值千万以上。以五金、疋头（注：旧指布和绸缎）、海味、毛绒、文具、燃煤等为大宗。据日商方面所传，12月1月两月，日商将在全华再倾销价值五千万元之过剩货品，现已由日清轮船公司加班专运。（7日专电）

  • 1932年12月8日《申报》：北平息，邓铁梅部蔡李赵各团，及武术队等部，上月12日进攻鸣城县，分四路进兵，与日逆军激战4小时。武术队猛攻南路，敌溃攒。毙日兵14人，伪自卫警2人，伤10余人，义勇军伤亡10余人。遂将鸣城占领，因无防守利器，复退原防。15日日逆军600余进攻，被邓部击退，16日晨日增援400余，共千余重进，攻极猛烈，正相持间，邓率千余人来援。邓铁梅亲身督战，敌不支，退鸣城，毙日人50余人，义勇军伤30余人，获枪械20余枝。20日，日方派日韩人各1，率叛逆62名，修筑由安东至龙王庙大孤山小庄河等处长途汽车路，被邓部将修路之日韩人掳获，解送司令部枪决，获筑路用具及粮食等物三汽车。（7日专电）

  • #抗战影像#“一·二八事变”中，一队日本陆军士兵正在检查刚刚占领的中国军队阵地。

  • 1932年12月8日《申报》：东京讯，陆军省今日接讯，马占山将军已入俄境，闻马于11月29日向满洲里俄领署领取护照，自称为商民，嗣于12月4日乔装苦力，携二仆入俄。又传马现谋取道新疆赴北平，苏炳文将军则将取道海参崴赴沪云。（7日路透社电）

  • 1932年12月8日《申报》：北平息，张殿九、谢珂等，均随苏炳文入俄，将枪械交俄国保存。苏及随员均停大乌里，归国路线未定。平当局派员慰问其在平家属，并电莫斯科，向俄方交涉保护苏等安全，苏归国路线，如由海参崴乘船，恐有问题。或经由俄境经蒙古边境西转热河，俄国驻86号站军队，严重警戒。（7日专电）

  • 1932年12月8日讯：锦州日本第八师团1列铁甲列车，以追击义勇军为名，开到榆关站东端长城缺口，突然向城内发炮38发，全城惊骇。
