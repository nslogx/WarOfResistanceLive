1932年06月11日

发表于 2021-06-11 更新于 2021-06-21 分类于 局部抗战(1931-1937)

  • 1932年6月11日讯：开滦赵各庄、马家沟二矿工人1.6万余人，因反对资方取消花红，要求增加工资，相约罢工。后因资方答应工人部分要求，罢工坚持两日后复工。

  • 1932年6月11日讯：汉口商会电复沪全国商联会等团体，响应废止内战，并主张：一、各军、师长以至诚发表消灭内战意见；二、请中央彻底革新政治，以杜战源。

  • 1932年6月11日讯：北平市商会及银行同业公会等四团体电沪，拥护废止内战大同盟运动，并建议在各省、市成立分会。

  • 1932年6月11日讯：宋子文在沪发表谈话，说明辞财长原因，谓“将来财难，必甚于今，军政支出将有增无减”，“在势惟有举债，然挖肉补疮，终将至肉无可挖”。“余心力已瘁，不能再肩财政重任”。

  • 1932年6月11日《申报》：山海关息，日军迭次攻击辽中、台安、盤山、海城一带义勇军无效，近电辽省警备旅王殿忠部及靖安游击队，包抄进攻，战事激烈。（10日专电）

  • #抗战影像#伪满洲国某地罂粟大丰收。

  • 1932年6月11日《申报》：哈尔滨息，中东路东段平靖未久，今日复发生战事。今晨军火车一列由此出发，铁甲车一辆紧随其后，以资保护。至一面坡止沿途均无阻碍，续进至乌吉密河附近时，突有反满军六百人向军火车猛烈攻击。是时适日铁甲车落后，故军火车危险异常。旋铁甲车赶到，以机关枪及步枪还击，剧战数小时后华军退走。是役华军若有任何战炮，定能将军火车炸毁，日方发表日兵死五人。（9日路透社电）

  • 1932年6月11日《申报》：北平息，兴城敌军仍在猛攻，义勇军敢死队长黄纪刚今晨阵亡，受伤兵士十一名，伤入口甚小，出口极大。据军事专家谈，确系达姆弹，三路义勇军长李果中决向日军提出严重抗议。（10日专电）

  • 1932年6月11日讯：立法院通过《大赦条例》，规定凡三年以下有期徒刑、拘役或专科罚金者均赦免之；犯外患罪者不在赦免之列，“反革命犯”赦后得移反省院。24日国民政府明令公布。

1932年06月10日

发表于 2021-06-10 更新于 2021-06-21 分类于 局部抗战(1931-1937)

  • 1932年6月10日讯：中国左翼作家联盟机关刊物《文学月报》在上海创刊，由姚蓬子主编。

  • 1932年6月10日讯：北平师大学生因反对李建勋长校举行总罢课。11日，师大学生集合准备赴南京索校长，警察百余将师大包围，学生与 警察发生冲突，至夜，学生以砖瓦、石子乱击警察。

  • 1932年6月10日讯：青岛各业工会等11个团体开会，响应废止内战大同盟运动，通过拥护通电。

  • 1932年6月10日讯：“剿匪”总部在汉口开运输会议，鄂民政厅长及各县代表参加，决在各处组织军运车船代办所。

  • 1932年6月10日讯：沪公共租界工部局宣告，1月28日起所宣布之戒严办法，自6月13日上午6时起终止。

  • 1932年6月10日讯：军事委员会通令申明职掌：“除关于绥靖、军令及重要情报事项由本会直接掌理外，其他军政、教育训练及国防事项，均由主管各部呈由本会作最高审核决定，交部执行。”

  • 1932年6月10日讯：行政院会议通过《中小学组织法》（草案）；决定8月中旬召集全国体育会议。

  • 1932年6月10日《申报》：哈尔滨息，昨日上午3时，日本满装军需品之军用列车由哈埠出发，当经过哈东乌吉仔密仔（译音）之际，突被六百之兵匪所袭击。当时列车被阻，日方接此急报后，即由铁甲车队一支队前往，与匪激战后，将其击退。（9日路透社电）

  • #抗战影像#伪满洲国时期，生活在我东北的白俄家庭母女。

  • 1932年6月10日《申报》：哈尔滨息，据日方官场消息，日方侦察机报告，哈尔滨西北德都境内，有中国步兵骑兵甚多，当日机飞过时，彼等出示“满洲国“旗。但实则此项军队，确为反满军，故日方已遣出爆炸机，前往轰散之。（8日路透社电）

  • 1932年6月10日《申报》：哈尔滨息，马占山、李海青两军，集合五千名，由沈鸿猷、李天德诸人分统，在海伦西北兴华镇整理中，已有北安镇送往通北，本人率轻骑南下，会李海青。（8日专电）

  • 1932年6月10日讯：外交部电令在意大利之莫德惠赴莫斯科，与苏联交换复交意见。24日，莫赴苏。

1932年06月09日

发表于 2021-06-09 更新于 2021-06-21 分类于 局部抗战(1931-1937)

  • 1932年6月9日讯:北平大学法、工、农、女四学院反对校长沈尹默，全体罢课。10日，平大各院校联合会招待报界，称沈尹默三日内如不辞职，决心武力驱逐。

  • 1932年6月9日讯：青海省府派马步芳为玉树宣慰使

  • 1932年6月9日讯：上海市公安局布告严禁谣言，称“近有不肖之徒，造作种种谣言，意图煽惑，倘再有人造谣滋事，一经查明，定当依法严办”。

  • 1932年6月9日讯：　粤空军总司令张惠长由香港抵沪，与前往欢迎者谈，“本人素主张空军不参加任何内战”。

  • 1932年6月9日讯：邹鲁在香港谈中苏复交问题，宣称中苏复交于国情上便利，决非联苏，复交后，政府仍抱防共之旨。

  • 1932年6月9日讯：第十九路军分三批入闽，第一批毛维寿师计1.2万余人，于7、8、9三日抵泉州。

  • 1932年6月9日讯：汪精卫返京。10日，在行政院会议上报告赴沪挽留宋子文、陈铭枢经过，称宋允打消辞意，陈须请假略事休养。

  • 1932年6月9日《申报》：南京息，外息，日俄对东北谅解协定决于中俄复交之前成立。政府息，中俄复交问题，中央不厌求详，最近一月来，当局公开会议，及私人谈论，不下数十次。对于应付方策，大致分两步骤：第一步先与苏俄订立双方不相侵犯条约；第二步再行正式恢复邦交。（8日专电）

  • #抗战影像#侵占我东北的日本制作的宣传照片，美化宣传伪满洲国内朝鲜、满族、日本、俄罗斯和蒙古族儿童友善相处。

  • 1932年6月9日《申报》：哈尔滨息，闻马占山现又活动，据日方消息，马部下五千人刻向南进发，以攻日军，闻马刻在克山东北之北安镇。又一日方消息，反满军获有弹药接济，颇为充足。据日人称，由绥芬河开往横道河子之火车，常运入弹药，供反日与反满军队之用云。（8日路透社电）

  • 1932年6月9日《申报》：北平息，调查团李顿、及德意代表随员何许端纳等，与我方顾、刘、颜等，日方吉田林出等，今晚6时离平，赴青岛视察，北宁路车务处长王奉瑞，科长周颂贤，随车照料，招待处分电韩复渠、沈鸿烈，请届时妥为保护。调查团副秘书长斐勒特刻，随员邓纳利多福等，今晨由大连到平，即谒李顿，报告途中情形。（8日专电）

  • 1932年6月9日讯：蒋介石自汉口到达庐山，准备召开鄂、豫、皖、赣、湘五省“剿匪”会议。同日，与何应钦等商赣、闽、粤“剿匪”计划。

1932年06月08日

发表于 2021-06-08 更新于 2021-06-21 分类于 局部抗战(1931-1937)

  • 1932年6月8日讯：北平大学校长沈尹默以工学院风潮扩大，联合各院长电教育部请辞。11日，教育部复电沈慰留，并令沈对学生“严厉制止，以肃校风”。

  • 1932年6月8日讯：浙江大学教授因积欠薪金三个月，全体请假。当晚该校当局发给全体教授一个月薪金。因学生学业关系，9日起全体教授一律授课。

  • 1932年6月8日讯：外交部就日本嗾使伪满派中东铁路理事长、理事、督办等情事发表声明，表示中国政府绝对不能承认，所有一切责任，应由日本负之。

  • 1932年6月8日讯：国联调查团离北平赴青岛视察。

  • 1932年6月8日《申报》：哈尔滨息，哈西四十里半拉城，五日晚为旧吉军攻入，缴去警队枪械。（6日专电）

  • #抗战影像#伪满洲国时期制作的纸牌。

  • 1932年6月8日《申报》：哈尔滨息，吉林伪长官署，在哈设军属特务部，办理军事调动事项，委王之佑为部长。（6日专电）

  • 1932年6月8日《申报》：长春息，扰乱朝鲜国境附件之大刀会救国军，及成正会等之联合军约三千人，最近占领安图县城，更似将俟机袭击敦化，故该方面之人心，皆甚恐慌。（7日电通社电）

  • 1932年6月8日讯：英、美、法、意四国大使访日首相斋藤，密商上海问题，表示反对在东京举行上海圆桌会议之预备会议。

1932年06月07日

发表于 2021-06-07 更新于 2021-06-21 分类于 局部抗战(1931-1937)

  • 1932年6月7日讯：鲁南股匪张黑脸2000余众经招抚后由鲁省府将其北调，是晚车抵两下店时下车逃往抱犊崮。

  • 1932年6月7日讯：美商上海电话公司工人约3000人，为反对开除工人，要求增加工资、改善待遇，举行罢工。10日，电话工人开会，被租界捕房驱散，并捕去代表四人；工人改在华界开会，又被国民党党部及公安局等干涉。22日，美商和市党部联合对工人进行镇压，工人忍痛复工。

  • 1932年6月7日讯：陇海路技师汤仲明发明以油炉代替汽炉开动汽车。实业部电拨巨款资助。

  • 1932年6月7日讯：伪满溥仪颁布国籍令：一、居住满洲华人非生长满洲者，被视作外国人，但可申请加入满洲国籍；二、各铁路或满洲机关雇员不入满洲籍者，将解雇；三、已入中国籍之在满洲俄人，在入满籍以前，亦以外国人看待。

  • 1932年6月7日讯：日陆军省发表战报，公布从九一八到1932年6月6日在华日军死伤4163名。

  • 1932年6月7日讯：下午5时，蒋介石离开南京赴汉口“督剿”红军。

  • 1932年6月7日讯：行政院会议决议停办劳动大学。该校师生极为愤慨，于11日召开全体师生大会，组织学生护校委员会护校。

  • 1932年6月7日讯：浙江戒严司令部通令中等以上学校学生不得擅自集会。

  • 1932年6月7日讯：上海地方协会成立，选举史量才为会长，杜月笙、王晓籁为副会长，并通过章程10条，第一条称：“本会由上海市民地方维持会发起，以协力图谋本市市民之福利，与各项地方事业之改进为宗旨。”

  • 1932年6月7日讯：张治中向军政部请辞第五军军长及第八十七师师长兼职。

  • 1932年6月7日讯：敌14师团第27旅团占领克山，并以第28旅团东西对进，准备进攻克东。

  • 1932年6月7日《申报》：北平息，调查团以所住北京饭店，对整理材料不便，拟借旧外交部房屋数间，为打字及翻译文件人员用。各委今晨一度会议，讨论整理材料各事，并决每晨会谈一次，分配一日内工作。今午法代表赴法使馆宴，德美两代表赴美使馆，意代表赴意使馆，李顿偕随员赴英使馆，旋即返北京饭店。（6日专电）

  • 1932年6月7日《申报》：北平息，吉自卫军磐石县攻敌，已抵烟筒山西，双方相距二里，桦甸我部，沿松花江进击，到额穆县属大平沟石夹沟一带，敌有不战而退势。（6日专电）

  • 1932年6月7日讯：红二十五军攻克正阳关，嗣又自动撤离，以霍丘为根据地。

  • 1932年6月7日《申报》：哈尔滨息，李海青军自安达沿铁路北退，在霍山子集合，有经望奎折向海伦，与李天德、沈鸿猷旅会合趋势。日机往爆炸不退，沈鸿猷部骑兵七百，将自兰西十间房，开至兰西东五站策应李军。包围洪家店之李海青军，3日晚退却。（6日专电）
