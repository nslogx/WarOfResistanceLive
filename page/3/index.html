1932年10月03日

发表于 2021-10-03 更新于 2021-10-13 分类于 局部抗战(1931-1937)

  • 1932年10月3日讯：郭汝栋部在阳新之龙港、咸宁之杨 林桥、通山之大畈与红独立第三师激战后，陷鄂南红军根据地龙港。次日，续陷燕厦。

  • 1932年10月3日讯：福建旅京同乡会决议：一、电蒋光鼐遵行政院命令，速将陈国辉枪毙；二、电中政会、国民政府、行政院及蒋介石，要求彻底改组闽省府。

  • 1932年10月3日讯：交通部通令各邮电机关，凡新闻纸类挂号须先验登记证，否则不准立卷；前已立卷而无登记证者，应一律取消。

  • 1932年10月3日讯：陈国辉部经第六十一师包围后，派代表到泉州向蔡廷锴请降，以不杀陈为条件。8日，蔡廷锴称陈部已大致解决，零星溃散者即可肃清。

  • 1932年10月3日讯：何应钦、顾孟馀在京召集川军代表，商议消弭川争办法。何、顾发言，望“一切纠纷均应诉之中央，听候中央处理解决，不得擅自用兵”。各代表表示接受，转电各将领知照。

  • 1932年10月3日讯：胡适在平对“路透社”记者称：彼对《国联调查团报告书》感觉满意，认为颇属公允，对报告书中所列解决中日问题之十项原则亦表同意。

  • 1932年10月3日讯：日军一部由齐齐哈尔以北渡江，遭东北民众救国军第一旅旅长张玉珽率富拉尔基步兵第一团一营击退，敌弃尸十二具。

  • 1932年10月3日《申报》：北平息，义勇军耿继周部千余人上月25日，在浑河浦附近，与日五百余名激战数小时，日军退沈阳。我军占领浑河浦，毙敌30余名，获步枪20余枝，炮1门，我方死五伤二，耿部准备向沈阳推进。（2日专电）

  • 1932年10月3日《申报》：北平息，锦绥义勇军张鸣五部一团，27日晨进攻锦州，日军死守，遂转攻女儿河车站，守站日军仅百余，被击溃，将车站占领，获军需品甚多，并夺获小米五十余麻包。该部与王显庭部联络后，共万余人，刻分散距锦城周围三四十里各处驻扎。锦城已成瓮中鳖，即可攻下。义勇军郑桂林部五百余人，上月30日攻绥中，战事颇烈，双方死亡甚重，已围攻三日，刻尚对峙。该部另分一部进攻兴城，亦在激战中。（2日专电）

  • 1932年10月3日《申报》：北平息，苏炳文部开抵富拉尔基，计吴玉青部二千余人，由嫩江下游渡江进攻昂昂溪，张殿九第一旅担任铁路正面，由嫩江桥直迫卜奎。一日拂晓，与日军冲突，张本人在富拉尔基指挥。苏炳文将赴伯克图指挥，马占山与苏约定，已于一日下令各路总攻击，决收复省垣。马现在拜泉附近某地点督战，所部各旅刻分路猛进，驻黑省垣昂昂溪平贺旅团上月29日奉武藤命令，撤回辽宁，日军有放弃黑龙江退守滨江计划。（2日专电）

  • 1932年10月3日《申报》：南京息，中央社记者二日晚晤政府某要员，叩以审阅（调查团）报告书节要后作何感想。据云，报告书中对我国政治不乏批评之处，我人应猛力自省。同时报告书中对我亦有奖饰之处，我人则不可因之色然而喜。（2日专电）

1932年10月02日

发表于 2021-10-02 更新于 2021-10-13 分类于 局部抗战(1931-1937)

  • 1932年10月2日讯：旅京江西同乡千余人集会，反对江西省主席熊式辉强征产销税，增重江西人民负担。

  • 1932年10月2日讯：刘文辉部与刘湘部开战，刘湘急调鄂西“剿匪”部队回川。同日，蒋介石致电刘湘、刘文辉等令各饬所部，勿轻启衅端。

  • 1932年10月2日讯：韩复榘部与刘珍年部在胶东掖县县城炮战甚烈。何应钦再电促韩、刘切实停战，并电蒋介石请示处置办法。

  • 1932年10月2日《申报》：北平息，义勇军二百余人30日攻绥中县城，至距城八里某地，日军闻警赶来应战，双方激战竟日，均有伤亡。县城紧闭，铺商停止营业，因日军大炮威胁甚烈，义勇军暂退。（1日专电）

  • 1932年10月2日《申报》：北平息，义勇军孙国儒部第三四两支队队长孙德儒、孙助国，率众500人，27日夜偷渡半拉门河口，偷袭饶阳河白旗堡两车站，均被攻下。毙敌7名，获枪9枝，铁轨拆毁20余段，拂晓南北甲车均开至，两站义勇军今退原防，孙部死一伤三。（1日专电）

  • #抗战影像#一队行军中的日军背负着阵亡者的骨灰盒。

  • 1932年10月2日《申报》：哈尔滨息，东铁护路军苏炳文部已与李海青军连成一气，黑省伪国军队中约700余人，亦与李海青军有联络，闻定日内组成联军，分途攻入齐齐哈尔。伪黑省主席已请援于伪军政部，日内将有大战，齐齐哈尔以西之铁路、电信、电话依然不通。（1日华联社电）

  • 1932年10月2日《申报》：南京息，据美联社消息，李顿调查报告长350页，分10章，首述中国关内情形，次述满洲历史及引起九一八事变原因，第三章以下分述满洲九一八以后现状，末章调差团建议，大致主权归还中国，日本得经济开发权利。但未提及恢复九一八以前原状，主张组织新行政机关，由中国自由意志聘外国顾问，襄助治理。当地税收，以关税附税盐税邮政收入，归国民政府，其余归地方政府。关于军事方面，建议由中国与日本，会同使满洲不驻军队，永除冲突根源，至对于满洲案责任一层，虽无切实断定语，据闻曾表示满洲在旧政府统治下之紊乱，不足以为日本占据领土之适当理由。（1日专电）

  • 1932年10月2日讯：《国联调查团报告书》在日内瓦、南京、东京三地同时发表。《报告书》承认“九一八”为日方“预定精密计划”所造成，但认为满洲问题之解决，必须“遵守现行多方面之条约”，“承认日本在满洲利益”，并提出国际共管东三省，设立“自治政府”的荒谬主张。

  • 1932年10月1日《申报》：山海关息，义勇军连续收复突泉、洮安、泰来、开通等县，复攻洮南。洮南逆部较多，实约有六团，未能立时攻溃。义勇军现仍期图短期内击破洮城，外并施抚绥办法，促该部队自悟来归。（30日专电）

  • 1932年9月：《海外月刊》在南京创刊，报道华侨事务为其主要内容。
