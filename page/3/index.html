1932年08月08日

发表于 2021-08-08 更新于 2021-08-18 分类于 局部抗战(1931-1937)

  • 1932年8月8日讯：松花江堤防冲毁，哈尔滨被水包围，灾民达20万。

  • 1932年8月8日讯：皖北灵璧县农民数千人由李小白领导，向尤集区公所索回已收之烟税，并捣毁区公所。9日，农民聚集不散，攻占村镇多处，尤集区长逃至县城请兵镇压。19日，县派警镇压，农民抗争暂告结束。

  • 1932年8月8日讯：武藤信义在东京就任关东军司令官兼驻伪满特派全权大使职，26日武藤抵沈阳。29日前关东军司令官本庄繁离沈阳回日本。

  • 1932年8月8日讯：中华苏维埃共和国中央革命军事委员会通令宣布：奉中央政府命令，特任毛泽东为红军第一方面军总政治委员。

  • 1932年8月8日讯：蒋介石召见武汉大学校长王世杰，嘱转电蔡元培挽劝汪精卫回京复职，并派武大教授周鲠生代表赴沪面劝。

  • 1932年8月8日《申报》：沈阳息，今晨4时，义勇军进攻牛心台，火车在满铁安奉路分线（即本溪湖牛心台间）牛心台附近出轨。护路日军20人与义勇军发生交战，日军闻讯，由本溪湖派守备队往援。（7日华联电）

  • 1932年8月8日讯：吴佩孚致函蒋介石，主张重整伦理纲常，略谓：“窃谓天灾不足患，而人祸堪忧。困难不足平，而心死是惧。”“今礼教尽废，国之所以不国也。所望政府鉴于天秩之不可沦亡，民彝之不可废弃，速定国是，明布宪章，重整伦理纲常，奉若天经地义，上以是教，下以是学，凡有不忠不孝，不友不弟，不信不义者，从严惩处之。”

  • 1932年8月8日《申报》：北平息，义勇军千余人，由双羊店松山猛攻锦州，已逼近东站，与日军激战，弹飞如雨。沟帮子、兴城日军日机，均往助战。锦站日甲车安置巨炮，与义勇军激战。南台驿发电所被义勇军破坏，沈城内仅有日军500余名，仍在三家子与义勇军激战。（7日专电）

  • 1932年8月8日讯：陈树人为表示与汪精卫同进退，请辞侨务委员会委员长职。

  • #抗战影像#伪满洲国国务院总务厅需用处。

  • 1932年8月8日讯：张学良复电汪精卫已电请中央罢免本职，略称：“自卫必先准备，准备非财莫举，良职责所在，凡有吁请，均为自卫所必需，若夫明知中央困难而故作要求，良虽至愚，亦曷敢出此”，“倘以为良如在职有碍于内政或外交之进行，自当立时引退”，“惟念我公党 国柱石，万不可飘然远引，置国难于不顾”，望即日复职，主持大政。

  • 1932年8月8日《申报》：山海关息，锦州日军今日对汤玉麟送哀的美敦书（注：“最后通牒”早年的译法，源自拉丁语中“最後一個”），要求汤玉麟限48小时内交还石本权四郎，否则进攻热河。（7日华联电）

  • 1932年8月8日讯：张学良电国民政府、军委会、行政院辞北平绥靖主任职，内称：“原思忍辱负重，尽力职责，奋其待罪之身，勉图方来之效，乃以识力短浅，事与愿违，匡济无力，寸功未立，长此素餐席禄，诚恐陨越贻羞。”

  • 1932年8月8日《申报》：北平息，政委会临时谈话会，张学良报告经过，态度消极，决电汪引咎辞职，以谢国人。并电汪，请以国事为重，勿轻言辞。张准备辞职后，军事交军委会，政治交政委会，同时由谈国恒电汤玉麟，请其安心，财政另筹办法，政委会亦电汪报告事件经过，七日亥刻始散。（7日专电）

  • 1932年8月8日讯：汪精卫再电国民党中央执行委员会坚辞行政院长职，指责张学良治下省份，国家税收悉被截留；兵额中央无权过问。中央责以防御，则请饷之电，来如雪片。所谓财者，平日已被吞尽，中央何从得财，以应其请；请而不遂，则一切责任归之中央。

  • 1932年8月8日讯：汪精卫在沪对记者发表谈话，促张学良下野，略谓：行政院院长人选，“于右任、戴传贤均可，蔡元培来更好”；继张者“以何应钦、朱培德为宜”。有询以冯玉祥、阎锡山如何？汪谓不可，“将予人以口实，增加纠纷”。

1932年08月07日

发表于 2021-08-07 更新于 2021-08-18 分类于 局部抗战(1931-1937)

  • 1932年8月7日讯：山西突降大雨，祁阳、阳曲等30多县遭百年来未有之奇灾。8日，汾河决堤，太原被淹，正太路被冲毁，火车停开。

  • 1932年8月7日讯：伪满洲国国务总理郑孝胥与日本关东军司令官本庄繁签订《满洲国政府铁路、港湾、航路、航空管理及铁路线的敷设、管理协定》，规定伪满将这些交通设施交给关东军，由关东军委托“满铁”经营。

  • 1932年8月7日讯：锦州日军向汤玉麟下最后通牒，限48小时内交还石本权四郎，否则进攻热河。

  • 1932年8月7日讯：海关总税务司梅乐和发表宣言，说明伪满洲国劫夺满洲海关经过。

  • 1932年8月7日讯：汕头商界反对国民政府举办营业税，组织反对营业税委员会，各业自动罢市。

  • 1932年8月7日讯：张群电中央请辞北平文化整委会副会长及代理故宫博物院理事长职。25日，张再电请辞。

  • 1932年8月7日讯：张学良令天津公安局枪决扰乱破坏天津治安之大汉奸刘学古。

  • 1932年8月7日讯：李济深再电蒋介石坚辞三省“剿匪”副司令职。

  • 1932年8月7日讯：蒋介石下令总攻鄂豫皖苏区。命令各路“进剿”军疾速进击，深入根据地中心。10日陈继承纵队向七里坪急进，卫立煌纵队进抵河口一带。

  • 1932年8月7日讯：蒋介石电张群转劝张学良，“以大局为重，宜忍隐处之。北方同袍尤不宜亟有抗辩，以免益陷僵局，更增纠纷”。

  • 1932年8月7日讯：罗文幹呈行政院请辞司法、外交两部长职，表示与汪精卫同进退。

  • 1932年8月7日讯：北平政委会开会，张学良决定辞职。张复电汪精卫，劝汪“以国事为重，勿轻言辞”，“本人军、政权将分交平军分会、政委会”。同日，张并电蒋介石请北来主持。

  • 1932年8月7日讯：蒋介石再电何应钦、朱培德促赴沪恳切挽汪回京。何夜车赴沪，朱8日晨赴沪。

  • 1932年8月7日《申报》：北平息，6日黑河黑省府电称，马占山尚健在，谣传不足信，马尚在某地督师。又龙江来客谈，马占山上月29日，与日军甘粕部，在海伦附近作战。马率800人经过日军密集阵地，被乱枪射击，马部遗弃尸体颇多。马乃率部退海伦河丰附近，其地卑湿，日军追击困难，故马得安全退走。(6日专电）

  • 1932年8月7日《申报》：北平息，通辽克复后，衙门营等旗下马家窝铺自卫团，均揭义旗，联合义勇军，一致抗日。占领连山及葫芦岛之义勇军，现拟沿女儿河，向锦州进攻，刻正待援军及械弹到来，然后出动。（6日专电）

  • #抗战影像#吉林边防军司令冯占海与其部下合影。

  • 1932年8月7日《申报》：北平息，伪陆军第一旅长王殿忠，2日在营口指挥逆军作战，被义勇军弹击穿其胸部，当抬往满铁医院，生命已陷绝望。（5日专电）*注：王殿忠后来伤愈，先后出任伪满洲国安东地区司令官、牡丹江第六军官区司令官、奉天第一军区司令官、伪满洲国治安部军事咨议官。光复后出任国民政府营口治安委员会委员兼市长，1946年被解放军逮捕，1950年12月定为反革命罪，次年被枪决。

  • 1932年8月7日《申报》：秦皇岛息，义勇军一部进攻黑山县城，驻大虎山日军大部出动驰援，双方已发生剧烈战事，炮声隆隆，大虎山车站清晰可闻。（5日专电）

  • 1932年8月7日《申报》：沈阳息，驻在鞍山西北约14、15华里之刘二堡义勇军，已攻鞍山数次，现总兵力有万余人。今晨结队又攻鞍山，在鞍山与刘二堡间，与日逆军发生激战。双方已激战至四五小时之久，日逆军乃不支而退，义勇军乘胜追击，毙连长以下百余名，伤者不计其数，但双方现在犹在交战中。（6日华联社电）

  • 1932年8月7日讯：国民党中执会召开临时常务会议，讨论汪精卫辞职事。一致议决由中执会急电慰留，并派何应钦即日赴沪会同居正代表中央挽留。

1932年08月06日

发表于 2021-08-06 更新于 2021-08-18 分类于 局部抗战(1931-1937)

  • 1932年8月6日讯：行政院长汪精卫致电张学良，望其辞职以谢国人，并称：“惟兄拥兵最多，军容最盛，而敌兵所扰，正在兄防地以内，故以实力言之，以职责言之，以地理上之便利言之，抵抗敌人，兄在职一日，断非他人所能越俎。”“今兄未闻出一兵、放一矢，乃欲藉抵抗之名以事聚敛，自一纸宣言捍御外侮以来，所责于财部者，即筹500万……昨日则又以每月筹助热河三百万责之行政院……以此相要挟，诚不解是何居心。”

  • 1932年8月6日讯：蒋介石接汪精卫辞职电，急电恳切劝挽，内称：“吾二人既均以共赴国难而来，现在无论有何困难，必须共负仔肩，勉度难关，决不可于国难益加严重之际遽萌退志，务望即日返京，照常主持院务。

  • 1932年8月6日讯：上海锄奸团成员爱国少年恽惠芳，因用炸弹警告奸商，被市公安局逮捕，沪市总工会、各同业公会等各团体纷纷发表宣言，要求释放。11日，恽惠芳被判徒刑两月，缓刑两年。

  • 1932年8月6日讯：辽宁民众自卫军第六路李春润部3日起进攻抚顺，是日占抚顺。

  • 1932年8月6日讯：蒋介石电请林森慰留汪精卫，并电何应钦、宋子文、朱培德、吴铁城共同挽劝。蒋表示与汪共进退。

  • 1932年8月6日《申报》：山海关息，义勇军取黍屯大虎山，日军往攻，炮火极烈。大虎山车站闻声不绝，沈阳亦紧张，日逆军队积极布防。（5日专电）

  • 1932年8月6日《申报》：大连息，义勇军300余名，4日夜9时半，火攻金山岭，与日守备队激战中。日军电大石桥告急，日方由大石桥派警官队，令原田大石桥警察署率领，开往前方助战。（5日华联社电）

  • #抗战影像#伪满洲国综合法衙，伪满最高法院、最高检察厅、新京高等法院及高等检察厅亦在此办公。

  • 1932年8月6日《申报》：北平息，葫芦岛日舰8艘，炮击郑桂林部，并有日陆军300余名协助。4日晨在激战中，义勇军为避免日军炮火，均散布附近高粱地内应战。锦西县一部义勇军约600名，4日开连山应战。（4日专电）

  • 1932年8月6日《申报》：北平息，日军2日夜退出通辽，义勇军3日完全占领该地，日军推手彰武县，据沈20里千金寨煤矿，亦被义勇军占领，义勇军杜芳洲通告锦州车站，限48小时内交还锦州，否则进攻，锦日军已开始作战准备。（4日专电）

  • 1932年8月6日讯：汪精卫以“外交、财政问题诸感棘手”，分别致电中执委会、林森、蒋介石、各院、部长，请辞行政院长职。致中执委会、林森电中称：“忝长行政以来，原期竭尽心力，以救国难，乃荏苒数月，事与愿违，再四思维，惟有呈请辞职。”致各院、部长电中称：“个人引退之原因，与行政院全体无关，在中央未选出继任人以前，敬请宋（子文）副院长依法代理院长。”

1932年08月05日

发表于 2021-08-05 更新于 2021-08-18 分类于 局部抗战(1931-1937)

  • 1932年8月5日讯：军委会准津浦路南段警备司令王均辞职，遗职委第二军军长蒋鼎文兼任。

  • 1932年8月5日讯：国民政府任命顾维钧继钱永铭为驻法公使。

  • 1932年8月5日讯：行政院会议决议：一、铁道部长顾孟馀辞职慰留；二、设立青海七呼图克图联合驻京办事处。

  • 1932年8月5日讯：山东潍县国民党县党部派军队包围胶济路坊子工厂，逮捕共产党人八名，将解往潍县，坊子厂全体工人卧轨阻止，只得改由旱路解出。

  • 1932年8月5日讯：鄂“绥靖”主任何成濬下令封锁洪湖革命根据地，“围剿”红军。

  • 1932年8月5日讯：江苏高等法院以牛兰夫妇自请提回看守所，是日派武装警察40名自鼓楼医院提回至江宁地方法院看守所收押候讯。

  • 1932年8月5日讯：国民政府各院、部、会以中央政费只发八成，要求财政部十足发放。宋子文表示财部发放政费，系根据国民政府命令，请体察财政困难情形，个人无权增加。

  • 1932年8月5日《申报》：沈阳息，3日被日军由海城击退之义勇军，退教军山，即在此处设置本部。企图再举，至4日上午2时半，果有义勇军约200名，四次向海城进攻，包围海城日野 炮队及附属地。日本平田部队及野 炮队即与之应战，激战2时半之久。此时义勇军在海城西北之大矢组堆栈放火，付之一炬。即侵入站内发炮，适赴长春之13号快车开到，知有事变，未停车而去。又平田部队，今晨来击退义勇军，并向教军山之义勇军本部，开始攻击。（4日电通社电）

  • 1932年8月5日《申报》：齐齐哈尔息，天下红所统率之义勇军5千名，又包围讷河，形势严重。黑龙江省长程志远得讯后，力请日军前往讨伐，因遭30年来未有之大水灾，军事行动极为困难。（4日电通社电）

  • #抗战影像#伪满时期，日军在对阵亡官兵举行慰灵式时，将处决的抗日人士的尸骸置于地上，作为“祭品”。

  • 1932年8月5日《申报》：山海关息，锦州日机5架，4日未刻绥中境北暴力轰炸，被炸村落有30余处。申刻有一架由绥中飞入榆关，先绕城一周，嗣在车站上空低飞巡绕逾10分钟，投下一信筒，落车站。有拾到者，内系绥中联队致驻榆守备队命令文件，当有日宪兵索去。（4日专电）

  • 1932年8月5日《申报》：大连息，辽西义勇军今晨3时进攻营口西方之田庄台，前锋队约有400名，继其后又有1000余人。日军接到日飞机之报告，随即令驱逐舰三艘开往田庄台，由海上炮击义勇军。现时沟帮子营口间之铁路北炸毁数段，火车均不通行。（4日华联社电）

  • 1932年8月5日讯：汪精卫由京赴沪访宋子文，商财政问题。

1932年08月04日

  • 1932年8月4日讯：上海锄奸团抵北平，警告平奸商勿贩卖日货。

  • 1932年8月4日讯：上海渔商公会致电国民政府，反对重征渔税。
