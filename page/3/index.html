1933年02月16日

发表于 2022-02-16 更新于 2022-02-26 分类于 局部抗战(1931-1937)

  • 1933年2月16日讯：西陲宣化使班禅额尔德尼抵绥远百灵庙，对蒙古王公谈称：“中华五族，宜化除畛域，一致抗日。”并派安钦活佛返京，取道印度入藏，与达赖商班禅回藏事。

  • 1933年2月16日讯：上海三友实业社总厂工人，因厂方不遵上海劳资仲裁委员会关于开工问题的调解和江苏高等法院勒令开工的判决，数千工人无以为生，是日推代表樊臻涌等40余人到京向国民党中央党部请愿。

  • 1933年2月16日讯：实业部江浙区渔业改进委员会在上海成立，实业部长陈公博兼任主席委员，林康侯、方椒伯、杜月笙等任委员。4月，该会开征渔业建设费，遭渔商强烈反对。11月21日，陈公博以经费不敷，无余资从事渔业改进，呈请行政院停办。计划中之闽粤、鲁冀两渔业改进委员会亦未成立。

  • 1933年2月16日讯：国民党中政会议决修订反省院组织办法，反省院仍隶属于司法行政部，院长不由高等法院院长兼任，而就中央执行委员会所交付之人员任用之。

  • 1933年2月16日讯：日军以九门口两次被义军攻入，为扫除侵略热河的牵制，调步骑800余在九门口外进攻义军郑桂林、王慎庐等部。

  • 1933年2月16日《申报》：北平息，日军今日在连山县城锦县绥中一带村屯，征集车辆驮子等交通器具，备战地运输用。同时在朝阳、兴城、绥中、凌南、凌源一带，用飞机散传单，威胁村民迁移。现该地居民，恐慌万状，纷纷逃避，啼哭之声，惨不忍闻。义勇军近来在日军后方活动极力，凌南凌源朝阳绥中一带，交通孔道，多被义勇军封锁。（15日专电）

  • 1933年2月16日《申报》：南京息，15日外电传来消息，称日军已定本月27日开始总攻热河云云。官方对此，认为系日本在国联外交失败后之一种企图，并不惊奇。且据东京电传，自此项消息传出后，日金融界顿呈极度不安之现象，东京大阪等处之证券交易均已关闭，足见此项消息，在日本已发生恶劣的影响。我国上下对日军犯热，早在意料之中，并已一致决心抵抗，故日军如实际进犯，中央决严令守土将士誓死抵御，不失寸土。（15日中央社电）

  • 1933年2月16日《申报》：北平息，绥中西方之马甸日军，被义勇军包围击退，义勇军昨午夜占领马甸，获日军械甚多，今晨向绥中车站进攻，日在绥中调来大队炮兵，预备迎击。（15日专电）

  • 1933年2月16日《申报》：北平息，据此间之日兵高级官员称，日方现准备再最短时间内向中国提出哀的美敦书（注：最后通牒的旧译）三件，内容系要求中国政府撤退热河所有之军队。但中国当局恐不能接受此种要求，日兵之军队至迟在本月27日即将入热，预期3月1日左右开始大规模之战事。因3月1日为“满洲国”第一周年纪念日也，该哀的美敦书三件，其一将由“满洲国”政府交热省主席汤玉麟，其二由关东军总司令武藤至张学良，其三则为东京政府至中国政府者，内容大致相同，皆谓热河为“满洲国”之一部分，故中国军队须全部由该地撤退云。（15日路透社电）

  • 1933年2月16日讯：黄炎培、穆藕初、朱庆澜、熊希龄、杜重远等发起组织东北热河后援协进会，本日在平成立。宋子文、张学良莅会发表演说。会议通过章程草案和工作计划大纲。称该会主要工作和目的为：一、集中民众抗日力量；二、使民众力量与抗日军队力量相结合；三、唤起国际的同情与援助。推选朱庆澜、丁文江、胡适、王克敏、熊希龄、周作民等45人为理事，会长朱庆澜、副会长周作民。决议通电全国人民 报告该会之成立，要求全国一致起来援助前方军需；并通电全国军政官兵请一致团结御侮。会后商定朱庆澜等翌日随宋子文赴热河视察，推动汤玉麟抗战。

1933年02月15日

发表于 2022-02-15 更新于 2022-02-26 分类于 局部抗战(1931-1937)

  • 1933年2月15日讯：广州市海珠桥落成。此桥于1929年由美国马克敦公司以银103.2万两承建。

  • 1933年2月15日讯：国民党中政会通过戴季陶等提议，设立建国奖学委员会，其条例规定：设总裁三人，考试院长为当然总裁，余二人由国府简派；奖学金来源为中央拨款、政府机关补助、社会团体或私人捐助。

  • 1933年2月15日讯：日关东军司令官为伪满“建国”一周年布告民众，宣称“建国期年，从来秕政，概行革除，日满国交，益加敦厚”；扶植伪满系“义之不容看过，情之不可坐视”。

  • 1933年2月15日讯：赣省党政会议为强拉民伕供“剿匪”军运，通过《铁肩队组织规程》，定人数5640人，分47队，每队120人，由各县挑选壮丁组织，限月底组成，熊式辉兼总队长，各队长由县长兼任。

  • 1933年2月15日讯：东北民众抗日救国自卫军邓铁梅所属李海山部600余人被优势日军包围于沙金沟里老平顶，与敌激战四昼夜，弹尽粮绝，日军传单劝降，而无一人屈服，全军殉国。

  • 1933年2月15日《申报》：临榆息，13日九门口外义勇军复活跃前所铁道13日晚被拆毁，榆敌全部进入阵地，西城门并架炮。四城门紧闭，同时并调坦克三辆，步骑兵八九十名，分往应援，现榆城原状仍未恢复，城内仅留三条胡同通过行人外，其余各街巷，均以铁丝网封锁。鼓楼下及南门上，并设炮位，形势紧张，人心极恐慌。（14日专电）

  • 1933年2月15日《申报》：北平息，义勇军王蕴萍部敢死队6日由沈家台化装至孟家屯，王亲督所部，两袭上齐台，日本及伪国新编支队死伤约百余，义勇军得军用品甚多。别动队曾一度攻锦，以日军防守严，未得手。迨王与李部兵力集中后，将再度攻锦。（14日专电）

  • 1933年2月15日《申报》：北平息，某方接热边驻军电告，逆军组织侦探队四支队，潜入朝阳凌南等地调查。现经查觉，该侦探等均携有伪溥仪像邮票为证，连日缉获甚多，询得口供，对敌方动作，完全吐露。（14日专电）

  • #抗战影像#1932年“一·二八事变”期间，一群即将派往战场与中国守军作战的日本海军陆战队员正在集结接受训话。

  • 1933年2月15日《申报》：北平息，南岭昨有敌军斥候队约二十人，向我 防线开枪射击，被击退。日军连日在朝阳寺车站附近，挖掘丈余深战壕沟，沟旁埋设地雷，防我义勇军包围抄袭。（14日专电）

  • 1933年2月15日《申报》：日内瓦讯，热河省城商会会长及教育会会长联名致电国际联合会，由中国代表团转述，现已送达秘书处，电文如下：1月以来吾辈所居地方，毫无防御，备受日军惨无人道之天空轰击，尤以在开鲁朝阳等地为甚。至目前为止，男女老幼被日机轰炸致死者九百人，物质损失更属不可胜数。此种在满洲热河所施之暴行，其目的实欲威逼吾人，使吾人不得已而加入满洲傀儡国。此则吾人所断不能承受者也，兹特代表热河省五百万中国人民向国际联合会呼吁，请求制止此种纯属破坏之行动云云。（14日哈瓦斯电）

1933年02月14日

  • 1933年2月14日讯：浙江镇海农民与城镇居民二三千人举行元宵赛会，因遭警察阻止，起而暴动，将公安局捣毁。翌日，县府紧急会议决定严禁迎赛集会，城厢戒严，并拘捕群众七人。

  • 1933年2月14日讯：日大藏省认可“满铁”增资3.6亿元，资本金达8亿元；新增资金充本年后新建事业经费。

  • 1933年2月14日讯：东北民众救国军苏炳文部入苏官兵2500余名由第十五旅旅长郑润成等率领，于是日、翌日及18日分三批由苏联鄂木斯克运送回国，27日抵新疆塔城，3月下旬陆续到迪化。

  • 1933年2月14日讯：段祺瑞在沪与日驻华公使有吉明会晤，要求日本缓和侵热军事。有吉表示侵热不能中止，对平、津可不积极行动。

  • 1933年2月14日讯：蒋介石委蔡廷锴任赣粤闽边区进剿军左路总指挥，闽省各“剿匪”部队均归其节制。16日，蔡在福州就职。

  • 1933年2月14日讯：行政院通过实业部所拟《创设硫酸铔厂招收商股办法大纲》，规定该厂资本1100万元，英、德或其他外国公司投资500万元，实业部投资300万元，中国商人投资300万元。每百元一股，利息与红利，官商股同。次日，实业部公布《大纲》。

  • 1933年2月14日《申报》：天津息，人民自卫会推代表六人，地方协会推代表四人，定15日赴前方慰劳将士，并视察情况，归来报告。此行携有咸菜二万斤，手套3700副，香烟500条，载重汽车一辆，电动自行车二辆，沪代表穆藕初黄任之随同前往。（13日专电）

  • 1933年2月14日《申报》：东京讯，长春传来“满洲国”之消息，谓丁超将军已在“满洲国”军政部军事法庭审讯完毕。因丁超当时举事，处不得已之环境，故特宣告无罪，准予释放，闻丁超不日即将赴富顺县视其老母。（13日路透社电）

  • 1933年2月14日《申报》：北平息，日军前次计诱义勇军蒙边骑兵军长韩色望至辽宁拘押，一面假借韩之名义，在热边收编蒙军骚扰，现韩氏已由辽宁逃抵开鲁，脱出樊笼。昨与刘震东等发出通电，决再振劲旅，誓与日寇拼命到底。（13日专电）

  • #抗战影像#1933年长城抗战期间，伪蒙军正在进入长城关内。

  • 1933年2月14日《申报》：北平息，进犯开鲁之日蒙匪军，经我击溃后，即退通辽。闻日方俟援军开到，即行三次进攻，此次日方进攻开鲁，以蒙匪为前锋，日兵督饬于后，蒙匪经我军痛击，纷纷向后逃窜，日方以机枪扫射阻止，蒙匪伤亡甚众。日方以蒙匪进攻不利，拟定第三次进攻开鲁时，以日兵为前锋，期向我军猛攻，我援队已陆续开到，大战即在目前。（13日专电）

  • 1933年2月14日《申报》：北平息，九门口昨晚10时，敌骑兵约百余人向柳河沟进犯，被我军迎头痛击，至今晨一时余始退却。永安堡有义勇军某部三百余人，埋伏九门口外萧家河，该骑兵中伏，被义勇军击毙廿余名，逃向万家屯，石河前线无事。（13日专电）

  • 1933年2月14日讯：冯玉祥致电胡汉民、邹鲁，指责国民政府“自榆关失陷以来，表面上虽有大军开赴前线之举，而实际上如兵站之设置，弹药之补充，军费之筹拨等等迄未筹办，是无异驱十万大军于绝境，此云抗日，真欺人之谈”；要求胡等“应时势之要求，顺人民之意向，奋起救亡”。

  • 1933年2月13日讯：热河全省民众联合会及地方各法团联电国民政府，以冯占海、李海青等各义军陆续入热，所有粮秣等项地方不堪负担，吁请政府“俯念边区劫重，筹集巨款，分别作储粮备荒及赶办急赈之用”，并要求对入热义军“从速补充编制，俾便向外发展”。

  • 1933年2月13日《申报》：北平息，日军攻开鲁之第六师团一部500余人，原担任攻开鲁前哨，昨晚日方复将第六师团调至后方，另以川田旅团一部，向前推进，并携机关枪大炮甚多。开鲁形势愈紧张，凌南朝阳两县人民，因日人拉夫，已逃避一空。（12日专电）

  • 1933年2月13日《申报》：北平息，苏炳文李杜王德林等部义勇军，退入俄境者，连同吉黑民众妇孺，共达一万八百五十人，每日给养需美金3300余元，总计费用达美金68万之巨，刻正与苏俄当局接洽，设法赶紧回国，至苏马李王诸人，决先赴欧洲。民众士兵则待政府将旅费汇到，即可取道外蒙，遣送归国云。（12日中央社电）

  • #抗战影像#1932年“一·二八事变”期间，在上海公共租界区内巡逻的意大利军队士兵。

  • 1933年2月13日《申报》：北平息，承德电，日军大部昨袭击开鲁，我崔旅仍在开鲁城内扼守，义勇军冯占海、王蕴萍等部向开鲁西方十二马架江密峰引退，将敌诱入深山中，突返击，毙敌约八百余，获军用品甚多。敌经此重创，开鲁敌未敢再进，敌机在开鲁一带侦查掷弹，终日不息，人民逃避山中，开鲁附近除兵士外，已无居民踪影。阜新清河门义勇军，亦与日军相战，惟不甚激烈。朝阳寺日甲车又开至南岭，形势更紧张。（12日专电）

  • 1933年2月13日讯：红军一、五军团及独立第四师围攻江西南丰。陈诚急令第一纵队各师速在宜黄集中，又令驻南城第二十四师许克祥部驰援，企图合围红军于南丰城下。红军在周恩来、朱德指挥下，在新丰街以南地区阻击第二十四师，并重创南丰守军毛炳文部。14日，红军撤退，移主力至东陂、蛟湖、霍源一带，待机行动。
