1932年09月01日

发表于 2021-09-01 更新于 2021-09-11 分类于 局部抗战(1931-1937)

  • 1932年9月1日讯：国际反帝国主义战争大会在苏联开会，各国代表2000余人签名发表宣言，反对列强瓜分中国。

  • 1932年9月1日讯：《论语》半月刊在上海创刊，林语堂、明耀玉等主编，上海时代图书公司出版。

  • 1932年9月1日讯：中国政治学会在南京中央大学成立，选举高一涵、周鲠生、刘师舜、杭立武、杨杏佛等22人为干事。

  • 1932年9月1日讯：上海各大学教授抗日救国会致电北平教育界，请就近调查出卖故宫古物真相，并致电故宫博物院院长易培基请宣布真相。同日，北大教授陈寅恪、顾颉刚、吴其昌等联名致函政府请勿迁移故宫古物。3日，张群函香港《工商日报》，声明该报8月24日所载蒋介石指使李石曾、易培基盗取故宫古物售与美国消息，“纯属无根”。4日，易培基函复上海各大学教授，谓处理故宫物品，系遵照政府命令办理，“确系无关文化历史，且不能永久保存之物，院中有案可查，并无丝毫古物”。

  • 1932年9月1日讯：“热察义勇军军事处”正式成立，通电全国誓死抗日。同日，辽南抗日义勇军大举进攻沈阳；吉林义勇军对长春取包围形势。

  • 1932年9月1日讯：南京警备司令部杀害共产党人仲继成、朱寿臣、陈正兴、陈正富、张长贵、何朵文、于四殷、逢斌、冯世仁、孙正兰、郑金礼、仲三、方茂清13人。

  • 1932年9月1日讯：蒋介石训令湖北省政府等机关，劝导各地逃亡地主还乡“筹办善后”，协助反 共，如9月内不归者，即将其田产另行分配。

  • 1932年9月1日讯：国民党粤中委召开联席会议，讨论对日政策，并致电国民党中执会和国民政府，请“迅定对日大计，由抵抗之宣言进为抵抗之实行，督促得力军队出师关外，收复失地”。

  • 1932年9月1日讯：军事委员会北平分会在北平“绥靖”公署旧址正式成立，蒋介石再电张学良，请以军委会委员资格主持。

  • 1932年9月1日《申报》：东京讯，昨日沈阳日军司令部电陆军省及参谋本部告急，谓现时高粱茂密，义勇军乘机四处进攻，其势甚凶，如不增援军力，不能维持满铁沿路之治安，日军接讯开紧急会议，讨论增兵事宜，谓义勇军攻沈阳放火烧飞机场，为绝好调兵机会，国民不必反对云。（31日华联社电）

  • 1932年9月1日讯：国民党中常会以“现值剿匪急进，中央委员中担负军事责任者颇不乏人，在此时期，势难分身与会”，决议三中全会延期举行。

  • 1932年9月1日《申报》：哈尔滨息，据俄报消息，红枪会第27队已占领距此西93里之萨尔图及距此西79里之安达站，并于3小时内，两次扣留由满洲里开来之客车。闻车客死伤各数人，余者现无音讯，齐齐哈尔已派兵前往驱逐之。（31日路透社电）

  • #抗战影像#东北义勇军在新民白旗堡袭击日军列车。

  • 1932年9月1日《申报》：北平息，于大任部现集中永吉四部之张家子、乌拉街等地，与王德林部会合29日晨进攻永吉。城内仅日军警数百名把守，备有飞机辅助，双方战事颇激烈，日内可下。（31日专电）

  • 1932年9月1日《申报》：北平息，义勇军仍据沈阳近郊，正待援进展，定日内联合各地义勇军，大举沈阳各要市区。日援军约千余人，30日由铁岭开沈，将向千金寨南台浑河等处袭击义勇军根据地。沈市谣言甚炽，时闻枪声，电灯未明，日警强迫商店开业，叛逆眷属纷逃避大连，沈城内汽车被征调一空。（31日专电）

  • 1932年9月1日清晨7时50分，中国海军第一舰队司令陈季良与“宁海”号巡洋舰全体官兵齐集舰尾甲板。8时整，国旗升上“宁海”号舰尾旗杆，标志着该舰正式编入中国海军第一舰队。

1932年08月31日

  • 1932年8月31日讯：洪湖苏区周老咀被徐源泉部攻占，9月3日徐部又占瞿家湾。

  • 1932年8月31日讯：北平军分会决议增加孙殿英、门致中、秦德纯、高桂滋、张焕相等14人为委员。

  • 1932年8月31日讯：李烈钧等以江西“清共”善后捐“扰害商民，迄无宁日”，特电蒋介石、宋子文、熊式辉请迅予撤销。

  • 1932年8月31日讯：国民党中央政治会议通过：一、发行江、浙两省二十一年度救济丝业公债300万元；二、鄂省府请发短期公债，议决交财政组审查。

  • 1932年8月31日讯：外交部长罗文幹偕常务次长刘崇杰由京飞浔见林森，旋飞汉口见蒋介石，商外交问题。

  • 1932年8月31日《申报》：哈尔滨息，红枪会三百余人，退攻木兰，在木兰临近收买胡匪之日军联络员（即侦探）青木某被红枪会枪毙，木兰完全在红枪会手中。（30日华联社电）

  • 1932年8月31日《申报》：北平息，29日袭击沈市义勇军，皆着绿色衣裤，约千余人，进攻大南边门，为天下好部，约五百余人，与日坦克车数次肉搏，义勇军破坏日坦克车三辆，双方伤亡甚众，义勇军攻入城内。在商埠大马路，与日军警巷战，日军警节节败退，沈城内中国警察，向日方倒戈一击，加入义勇军作战，日军警首尾被击，攻击大北边门者为王天培部，约五百余名，有迫击炮手榴弹等，战甚烈。攻击小东门者，为李文华部，约五百名，城内义勇军便衣队，传有五百名，事先混入，日方由长春铁岭赶调大批援军。（30日专电）

  • #抗战影像#“九·一八事变”中，正在入侵我东北某城的日本关东军部队。

  • 1932年8月31日《申报》：北平息，东北救国军指挥彭振国，因日军迭向热边推进，11日率第四路司令李向元部官兵二千余名，携子弹四百万发，手榴弹百二十余箱，无线电机十架，进驻凌南布防，前锋已到木头城、六家子一带，距离敌军防线仅二十华里。李部官兵与锦西大窑沟日军，业经接触，赵进修部七百余名，13日占梨树沟，击毙日人七名，获大枪五支，正向绥中追进中。（30日专电）

  • 1932年8月31日《申报》：北平息，攻沈义勇军29日下午3时，退出沈阳城。刻分守千金寨、南台驿、塔湾、十里河、浑河等处，义勇军全部约三千余，系各部集合。日援军正向千金寨进击，义勇军迎战甚力，并进攻皇姑屯。伪奉山路、沈海路、安奉路车均不通，鲜人乘机扰乱，华人被惨杀甚多。伪国军通告居民，一概不许外出，否则格杀。沈全市停业，人心惶惶，满洲银行及中国银行，均为义勇军便衣队袭击，自来水电灯电话邮政军不通。飞机场日机7架被焚，兵工厂炮弹损失，不计其数。（30日专电）

  • 1932年8月31日讯：国民党中央通令全国，于9月18日举行国难纪念，停止娱乐，各机关、学校、工厂、商店、住户于上午11时停止工作五分钟，对殉难同胞默念志哀。行政院亦于9月8日发出同样通令。

  • #抗战影像#《东方杂志》1932年一幅题为《义勇军之活动》的照片，感谢 抗战直播详解与纠错 指正，照片内容应为：““锦州大虎山顶我军在战壕内瞭望戒备”。

  • 1932年8月30日《申报》：东京讯，今晨11时半，日陆军部接到关东军第一次报告，谓昨夜8时半，义勇军由三面围攻沈阳城，日军高山、铃木两军曹以下负伤数人，伪国公安队死者数人。（29日华联电）

  • 1932年8月30日《申报》：北平息，外讯，义勇军今晨袭沈阳，沈市已陷大混乱状态，炮弹落兵工厂及飞行场，均起大火，正延烧中，巡警与义勇军联合一致抗日。（29日专电）

  • 1932年8月30日讯：赵尚志部在原东北军才鸿猷团和“绿林好”部队配合下攻破巴彦县城，伪自卫团营长被击毙，伪县长被俘，但因为与东北军旧部和绿林部队不和，不久即撤出巴彦县城，回到洼兴桥一带的根据地

  • 1932年8月29日讯：辽宁抗日义勇军第二十一路赵殿良等部28日夜袭击沈阳城，与日伪军激战，在飞机场毁日飞机库一所，击毁飞机12架，打死日军十余名，由于日军炮击，义勇军未入城，于是日中午撤退。

  • 1932年8月29日讯：驻沪日陆战队司令杉坂印发反 华宣言数百份，分发旅沪日侨，声称对血魂除奸团“不能极端忍耐”，希望“竭力取缔”；如“发生不幸事件，则在上海方面，海有第三舰队之精锐，陆有富于战斗力之陆战队，其实力较之一二八以前更为雄厚”。

  • 1932年8月29日《申报》：北平息，今日据华字报载称，吉林义勇军已组织铁血团，团中共有青年500人，以暗杀日本与“满洲国”重要官员为目的，华字报又称，东三省之水患，现殊妨碍义勇军之活动，但义勇军正在准备进攻吉林省城等处云。（28日路透社电）

  • #抗战影像#东北义勇军某部正在前线阵地，准备与日军作战。

  • 1932年8月29日《申报》：北平息，占领南岭日军约百余人，已向朝阳寺撤退，南岭仅有少数日军。义县由锦州开到日军三百名，义勇军福升山部千余人，在朝阳寺抗日，因弹缺，双方各死数十人。（28日专电）

  • 1932年8月29日《申报》：北平息，锦朝线日军联络完全断绝，兴城绥中义勇军实行联络救国军18路及25路，开始向锦州推进。（28日专电）

  • 1932年8月29日讯：外交部长罗文幹在外交部纪念周上演说，对日外相内田25日侵华演说痛加驳斥，并阐明国民政府对目前时局所持之外交方针，表示“中国绝对不因武力之压迫而放弃尺土寸地或主权之一部”；“解决东北之办法，苟以东省伪组织为前提者，中国绝不同意”；“解决东北之合理办法，必以不背国联规约、非战公约、九国条约与中国主权，又能巩固远东永久和平为必要条件”。
