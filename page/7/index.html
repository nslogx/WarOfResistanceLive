1932年04月13日

发表于 2021-04-13 更新于 2021-05-13 分类于 局部抗战(1931-1937)

  • 1932年4月13日讯：上海各团体电国联，反对英使蓝普森所提折衷办法。

  • 1932年4月13日讯：上海市民联合会等百余团体发表宣言，主张中西纳税人互相合作，研究解决今后租界之联防。

  • 1932年4月13日讯：上海各民众团体联合会成立，共有34个团体参加，推举各大学学生抗日救国会等15个团体为执行委员，主张暴日未撤退在华海陆空军以前，反对任何谈判；誓死反对中日问题进行局部解决；反对依赖国联。

  • 1932年4月13日讯：国民政府特派孔祥熙为考察各国实业特使。

  • 1932年4月13日讯：交通部订定招商局整理计划，取清年终双薪，革除分局包办制度，减裁职员。

  • 1932年4月13日讯：日兵车一列在哈尔滨郊区出轨，死伤百余人。

  • 1932年4月13日《申报》：北平息，秦皇岛电，本庄到锦，北宁路干支线，日军将另行配置，依田旅团留驻锦州以西，另以第十师团驻锦州以东，第二十师团一旅调回朝阳，伪路局力图恢复锦朝支线，俾作军政经济侵略之运用。（12日专电）

  • 1932年4月13日讯：国联调查团与原东北军政官吏举行第二次谈话会，并接见荣臻、王以哲询问沈变经过。

  • #抗战影像#几张伪满洲国宣传画

  • 1932年4月13日《申报》：北平息，此间华人得悉马占山已逃往俄国，初据东北消息，马已逃往大黑河，今传马因部下将士多起抗满伪政府，知大势已去，故乃潜入俄境，以图自保。（12日路透电）

  • 1932年4月13日《申报》：北平息，调查团与原任东北高级官吏，为交换意见，今日下午四时，在顺承王府开第一次会，调查团全体出席，华方张学良、万福麟、荣臻、米春霖、顾维钧等出席，详谈东北问题，七时散会，定13日开第二次谈话会，仍在顺承王府，日代表吉田亦参加。（12日专电）

  • 1932年4月13日讯：沪中日停战会议暂停，郭泰祺已通告各关系国。郭语记者，大会须俟国联解释日本撤兵时期再开。

  • 1932年4月12日讯：沪中日军事小组会续开，日方仍提浦东、南市中国驻军问题，我国代表以其无稽，加以辩驳，争论达二小时无结果。

  • 1932年4月12日讯：国难会议闭幕，通过请政府克日将张学良撤职查办，所部军队着军委会妥为处理，以便收复东北失地等案，并发出四电：一、慰勉颜惠庆；二、嘉慰华侨捐款救国；三、嘉慰上海民众；四、勖勉全国将士。会议闭幕，发出宣言称：“中国在此严重局面之下，非集中全国才力，共作长 …

  • 1932年4月12日《申报》：哈尔滨息，延吉战事转二道沟，日警署被焚，战事仍烈，咸镜北道韩人倡乱（注：原文如此，应为配合义勇军的暴动），与救国军呼应，日派大军往剿。（10日专电）

  • 1932年4月12日《申报》：北平息，国联调查团10日下午3时半，在北京饭店开全体会议，中日代表均列席，讨论条约问题，双方辩论颇多，其紧张为从前所未有。（11日专电）

  • 1932年4月12日《申报》：太仓11日专电云，日兵在岳王市勒令居民，供给鸡蛋牛肉及用品并迫各商店开市，改悬太阳旗，居民多避，日兵在市搜索，该处小麦，尽被日军作马料，田收已无望。

  • 1932年4月12日《申报》：哈尔滨息，传马占山已乘汽车转奇潜入俄境，将绕道来南，8日马曾有电委程志远为黑全省警备司令，代行职权，一般料马已不返黑垣。（10日专电）

1932年04月11日

发表于 2021-04-11 更新于 2021-05-13 分类于 局部抗战(1931-1937)

  • 1932年4月11日讯：河北省民生银行总行在天津成立。

  • 1932年4月11日讯：上海公共租界纳税华人会本年第一次代表大会召开，选出工部局华董虞洽卿等五人，华委六人及该会执行委员27人。

  • 1932年4月11日讯：国难会议决议，宪政未实施前提前设民意机关，定名为国民代表会。

  • 1932年4月11日讯：国难会议电请国联调查团主持公道，“望根据事实，为正确之报告，使日本强暴情形，得以明白昭著于世界，受正义与公理之裁判”。

  • 1932年4月11日讯：沪中日停战会议延期。军事小组晨赴引翔港视察，下午开会，讨论浦东及苏州河南之我军驻防问题，我方代表黄强以此系中国主权问题，拒绝讨论。

  • 1932年4月11日《申报》：南京息，京沪卫戍长官署特务员赵某，九日下午五时在京沪车站，捕获汉奸李松亭、江肇周二名，于身畔搜出密码电本等件，当晚解卫戍署研讯。（9日专电）

  • 1932年4月11日《申报》：哈尔滨息，自昨日拘获阴谋炸毁中东铁路桥梁之俄人30名后，警察即大事侦查，陶赖昭站与松加里第二站间之大桥初传查货炸药一百十磅。今悉共有三百磅之多，且有附件甚多，又闻附件房舍内亦查出大批食物，内有俄制之酒，该房舍已多时未驻兵士，现信阴谋者必用以为办事所。…

  • 1932年4月11日《申报》：常熟10日专电云，杨|林口有日舰四，10日上午11时，向太仓开放三炮，弹落陆渡桥西南三里处某村田内，未炸，上有大正六年字样。

  • 1932年4月11日讯：国联调查团在北平开始调查九一八事变之经过，晚张学良在怀仁堂宴请调查团，力述中国统一之必要。

  • 1932年4月10日讯：红军一、五军团占领福建龙岩城，张贞第四十九师第一四五旅杨逢年部逃适中、南靖方向。

  • 1932年4月10日讯：江西宁都县工农兵苏维埃第一次代表大会召开，13日闭幕。

  • 1932年4月10日讯：粤军余汉谋部入赣“剿匪”。

  • 1932年4月10日讯：广州《新闻报》刊登涉及日皇小品文字，刘纪文应日领要求勒令该报停版。

  • 1932年4月10日讯：上海国难会议会员张耀曾等人组织政党“民宪协进会”。

  • 1932年4月10日讯：国难会议开二、三次大会，讨论御侮及政制，并电慰东北义勇军。

  • 1932年4月10日讯：上海各团体救国联合会致函英使蓝普森，对中日停战会议上所提折衷办法表示反对。

  • 1932年4月10日讯：旅沪九省同乡会通电国民政府行政院、军事委员会、外交部，称“如日方不自动撤兵，我即当驱逐出境”，“苟政府当局一味避战求和，竟贸然签订丧权辱国条约，置土地人民于不顾，我旅沪各省民众为不愿为亡国之民，惟知誓死反对”。

  • 1932年4月10日讯：上海日军仍在前线积极备战，在吴淞建营房，杨 林口日舰炮击太仓。日机29架先后在闸北、浦东等处侦察示威。

  • 1932年4月10日讯：伪满洲国电外交部，拒绝顾维钧出关，外交部拒收退回。

  • 1932年4月10日《申报》：哈尔滨息，救国军7日晚推进至一面坡，熙洽军警备第一旅退珠河。（8日专电）

  • #抗战影像#伪满洲国《国民学校日语国民读本》。

  • 1932年4月10日《申报》：北平息，依兰电，马占山抵大黑河后行踪不明，有已渡江赴俄说，但未证实。马向外国记者表示，伪国内部分裂，决难合作，丁超否认与马有接洽。（9日专电）

  • 1932年4月10日《申报》：哈尔滨息，7日王德林之大刀队千名，攻占延吉附近之三道沟，商家均悬青天白日旗庆贺，王德林亲率所部三千，向该方驰进，朝鲜日军两联队，续向该方增加，延边形势益紧。（8日专电）

  • 1932年4月10日讯：国联调查团晨访张学良，晤荣臻，询九一八事变经过。同日，调查团李顿对外报记者发表声明，略称“中国代表顾维钧为国联代表之一员，反对华代表无异反对国联，华代表有赴东北必要”。

1932年04月09日

  • 1932年4月9日讯：江西石城县召开第一次工农兵代表大会，通过参加革命战争等八项决议案。12日闭幕。

  • 1932年4月9日讯：鄂清乡促进会成立，方本仁等七人为常委。

  • 1932年4月9日讯：格桑泽仁在西康巴安独立，刘文辉部进剿。

  • 1932年4月9日讯：国难会议电慰吉林自卫军。

  • 1932年4月9日讯：马占山7日潜赴黑河。是日电北平张学良、国民政府、国内各报馆，表示继续抗日，称“占山一息尚存，誓本以身许国之初衷，决不负期许之至意”，并称“所有军政各机关，即时成立，照常办公”。

  • 1932年4月9日讯：立法院通过1931年度总预算案，收入共计7.13亿元，支出共计8.93亿元。

  • 1932年4月9日讯：汪精卫在洛宴请国难会议会员，发表演说，说明在洛开会之要义，称“足以振励打破国难之精神，对日作长期之抵抗”。

  • 1932年4月9日讯：国联调查团抵北平，张学良等到车站欢迎。

  • 1932年4月9日讯：军事小组委员会继续会议，日方代表要求中方代表说明浦东及苏州河南有无我军驻扎问题。中方代表加以驳复，并称日方此项要求违反国联决议与停战协定，枝节横生，日方应负会议破裂之完全责任。

  • 1932年4月9日《申报》：北平息，伪国公布日货进口无税，辽宁纺纱厂被日收没。（8日专电）

  • 1932年4月9日《申报》：北平息，日本为贯彻文化侵略，将东北教育制度，全部取消，另效日本制度为四年制，高中取消，大学停办，到日本升大学。（8日专电）

  • 1932年4月9日《申报》：汉城息，据延吉来电，义勇军三百，今晨突然攻击二道沟，日警官35名极力应战。又据头道沟日领事分馆报告，该地市街正在火烧，领馆警官队前往二道沟，参加战斗。（8日日联社电）
