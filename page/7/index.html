1933年02月10日

发表于 2022-02-10 更新于 2022-03-12 分类于 局部抗战(1931-1937)

  • 1933年2月10日讯：国民党南京市党部决议请求中央解散中国民权保障同盟，并予宋庆龄、蔡元培等以警告。

  • 1933年2月10日讯：江西省成立经济委员会，以范争波任主席，金融界徐槐青等任常委。该会以筹措“剿匪”军费为主要任务。

  • 1933年2月10日讯：辽东民众自卫军第三方面军王凤阁部2000人攻占抚松县城。

  • 1933年2月10日讯：李延禄率救国游击军在宁安东南团山子击退日军守备队及伪军进攻，敌伤亡200余人。

  • 1933年2月10日《申报》：北平息，驻朝阳董福亭，电汤玉麟报告，南岭北票间，防务吃紧。北票驻有汤（部一）团，煤矿已停止开采，交通断绝，南岭我军已增加兵力。（9日专电）

  • 1933年2月10日《申报》：北平息，日在通辽召集不肖蒙民，拟由内蒙沿新辽河进攻开鲁，伪军张子青部，系地方警察改编，程国瑞部系当地民众，被日寇扰乱，无家可归者，均无战斗力。（9日专电）

  • 1933年2月10日《申报》：北平息，耿继周部克服朝阳寺，与敌连日激战，嗣因敌用全力猛烈压迫，耿部已退出朝阳寺，向北票方面集中。（9日专电）

  • #抗战影像#1932年“一·二八事变”期间，一队侵沪日本陆军士兵正在集结待命，准备赶往前线同中国守军作战。

  • 1933年2月10日《申报》：天津息，前方电，据谍报，在锦州等处编练伪军之丁强，查系李际春之化名，丁在锦西县招募游击队一团，已训练成熟，将开往热河作战。7日夜，突有七八十名反正，杀死伪军官数名，掳走伪军官十余名，及士兵五六十，结队赴热边，请求朱霁青收编为救国军，共同抗日报国，该部枪械齐全。（9日专电）

  • 1933年2月10日《申报》：北平息，热河岭南紧急，敌用飞机坦克掩护步兵，自岳王庙进攻大井牛营子。（9日专电）

  • 1933年2月10日讯：日关东军司令官武藤召集各兵团主任参谋会议，布置关东军热河作战要旨：派第六师团、骑兵第四旅团及伪军张海鹏部在热河东境作战；派第八师团、混成第十四旅团急速进兵热河南部及河北省边境，“构成把华北与热河真正割断的铜墙铁壁”，以压迫张学良的势力，使热省华军及义勇军陷于孤立无援，尔后席卷西部及西南部。除另有命令外，不要在河北省内实施作战。本作战由本月下旬开始，在结冰期间结束主要作战行动。

1933年02月09日

发表于 2022-02-09 更新于 2022-03-12 分类于 局部抗战(1931-1937)

  • 1933年2月9日讯：行政院令准云南靖边行政区改置屏边县。

  • 1933年2月9日讯：中国电影文化协会在沪成立，选出执委及候补执委黄子布（夏衍）、陈瑜（田汉）、洪深、聂耳、沈西苓等31人。协会发布宣言，指出“帝国主义的侵略与封建势力的压迫在今日已更见严重”，号召电影工作者“亲切地组织起来”，“认清过去的错误”，“探讨未来的光明”，开展电影文化运动。

  • 1933年2月9日讯：国民政府明令改组湖北省政府。原省府委员夏斗寅、朱怀冰、沈肇年、夏元瑮、李书城、孔庚、杨在春、陈达勋、晏勋甫均免本职；夏斗寅免省府主席兼职，朱、沈、夏、李分别免民政、财政、教育、建设厅长兼职；任命夏斗寅、李书城、贾士毅、李范一、程天放、范熙绩、杨在春、陈达勋为省府委员，夏斗寅兼主席，李书城、贾士毅、程天放、李范一分别兼民政、财政、教育、建设厅长。

  • 1933年2月9日讯：国联十九国特委会致函日本代表团，询问日方是否能接受李顿调查团报告书关于满洲地方于中国主权及行政完整之范围内，建立高度自治权之原则，作为拟议的调解基础之一。14日，日本复文仍未明确答复，仅称：“确信维持与承认满洲国之独立，为远东和平之惟一保障，而此全体问题，将终由中日两国依此基础解决。”

  • 1933年2月9日讯：外交部公布与英、美、法、荷、巴西公使及挪威代办互致照会，同意1930年4月1日与上述各国在南京所订上海公共租界内中国法院之协定，自本年4月1日起延长有效期三年。

  • 1933年2月9日讯：关东军完成了“热河经略计划”，指出“热河经略之目的在于使热河省名副其实地成为满洲国的领域”，并确定了各部队的作战方向和时间。

  • 1933年2月9日讯：日陆军省发表侵热声明，妄言“满洲国为保持主权威信，已决定肃清热境华军。日本军部根据《日满议定书》合同，则满军剿灭叛徒，此种行动已有英、法前例可援，断非日军之侵华战争”。

  • 1933年2月9日讯：胡汉民为刘煜生、王慰三被杀事件电林森、孙科，指出：“数年来，人民言论、出版、居住自由为军人剥夺净尽，纲纪坠毁，民无死所”，要求“为死者求昭雪，为生者求保障”。

  • 1933年2月9日讯：中国民权保障同盟电山东省政府主席韩复榘，要求释放因参加“国民党行动委员会”嫌疑被捕之袁春霆等30余人。又电交通部，要求释放被捕之北平邮务工会抗日会执委13人，惩办北平邮局邮务长巴立地。

  • 1933年2月9日《申报》：北平息，苏炳文部两旅陆续由北满开抵热河北部某地，军士稍息，即调往热东，参加抗日作战。苏部前敌指挥张玉挺前赴某地检阅该两旅毕，昨返平，今晨赴津，日内事毕赴热东抗日。（8日专电）

  • #抗战影像#伪满洲国时期，沦陷的东北某处伪政府门口，悬挂着伪满洲国国旗。

  • 1933年2月9日《申报》：北平息，开鲁义勇军冯占海部已与张玉挺部联合，即将大举进攻日军根据地通辽，连日开鲁东道、德营子、小姑家子战事甚烈，日军已由通辽加派黑田支队往援。（8日专电）

  • 1933年2月9日《申报》：北平息，7日晨敌骑步军500余，会同伪军千人，携大炮三门，坦克4辆，由新立屯犯我阜新，与该地义勇军孟昭炎、李海青等部激战3小时。敌派机5架飞阜新城轰炸，破坏甚重，绥东敌军刻集结打通路之章古台等地，一部与义勇军在十字店相持。（8日专电）

  • 1933年2月9日讯：国民党中常会为指导华北党务工作，决定于新乡设中央执行委员会华北临时办事处，由张继任主任，王法勤、张厉生、陈立夫、王陆一、赵丕廉、刘守中、白云梯、克兴额、傅汝霖、黄慕松、纪亮、苗培成等为委员。

1933年02月08日

发表于 2022-02-08 更新于 2022-03-12 分类于 局部抗战(1931-1937)

  • 1933年2月8日讯：前江西都督、国民政府参军马毓宝在上海病死。18日，国民政府令军政部照上将积劳病故例从优议恤。

  • 1933年2月8日讯：云南省成立民众救国会，以“协助政府筹备国防，募集救国基金”为宗旨。由胡蕴山、卢永衡、周惺甫等人任常委。

  • 1933年2月8日讯：天津地方协会举行成立会，推选熊希龄等九人为常务委员。该会以抗日后援为其主要任务。

  • 1933年2月8日讯：豫鄂皖三省“剿匪”总部参谋长曹浩森到南昌，向蒋介石报告三省“剿匪”军事。

  • 1933年2月8日讯：国民政府以与日尚未断交，令外交、财政两部研究续订中日关税协定问题。12日，财政部令海关总署作修改细则准备。

  • 1933年2月8日讯：国联裁军会议召开，中国代表颜惠庆出席，大会竟将原定颜惠庆之演说取消。颜当即离场，以示抗议。

  • 1933年2月8日讯：田颂尧到通江“督剿”红四方面军徐向前部，是日下令总攻。

  • 1933年2月8日《申报》：北平息，日兵车一列，载日兵五六十名，六日由东开抵榆关车站，下车后，分驻城内。同时城内日兵四五十名，当成原车东行，榆关城东五眼城一带，有敌人数百，构筑工事，苏家屯敌人亦构筑工事。榆关车站电灯昨晚八时许全部熄灭，约二小时。（7日专电）

  • 1933年2月8日讯：日军派飞机八架次轰炸冯占海的义勇军司令部所占地下洼镇，投弹九十余枚，正逢旧历正月十四，民众聚集，遭受惨重伤亡，下洼镇仅有400户人家，多数倒塌，死伤者举目可见。

  • #抗战影像#1932年“一·二八事变”期间，驻守在上海公共租界区的意大利军队士兵。

  • 1933年2月8日《申报》：北平息，汤玉麟五日电中央，4日开鲁东北之小姑家子附近，日军以4辆坦克为前锋，掩护其步兵，大举来犯。当与我军激战，约二小时，因值大雪，敌前进不顺，我军联合义勇军民团猛力反攻，敌受创甚剧，乃向巴古塔西方退却。（7日专电）

  • 1933年2月8日《申报》：北平息，逆军于芷山部，6日晨与义勇军王蕴平，在阜新县清河门南八里沟发生激战，同时日军骑兵五百余开到八里沟援助逆军于芷山。

  • 1933年2月8日讯：蒋介石筹设军事委员会委员长南昌行营，任钱大钧为行营办公厅主任。

1933年02月07日

  • 1933年2月7日讯：河北定县平民教育促进会发动农民举行游行示威，反对日本帝国主义侵略华北，参加人数达7000左右。

  • 1933年2月7日讯：立法院聘戴季陶、覃振、伍朝枢、王世杰为宪法起草委员会顾问。10日，立法院会议通过宪法起草委员会组织条例。3月初，又加聘胡适、张君劢为顾问。

  • 1933年2月7日讯：日军1000人纠合伪满军千余，由辽宁新立屯出发进犯热河阜新。

  • 1933年2月7日讯：川陕苏维埃政府在四川通江建立，张国焘任主席。

  • 1933年2月7日讯：湘鄂赣省苏维埃政府发第四号训令，提出“争取江西和邻近数省首先胜利”，训令“各级政府应以百分之百的精神，为成立新的红六军团而动员而努力”。

  • 1933年2月7日讯：蒋介石电令第二军军长蒋鼎文，将该军由湖北宜昌调往江西“剿共”。

  • 1933年2月7日《申报》：临榆息，绥中方面续到兵车多列，兵力在侦查中，榆关刻无续到敌部队，伪奉山客车今不通，榆城日军传有白俄军人掺杂其间，绥中以东情况未悉。（6日专电）

  • 1933年2月7日《申报》：北平息，义勇军郑桂林部自一日起，每夜向九门口敌军猛攻，前晚彻夜作战。昨战暂停，昨晚七时起仍继续作战，逆军张子清部被郑部包围，在李家堡以东已开始接触。（6日专电）

  • #抗战影像#1933年长城抗战期间，一架日军水上飞机正飞临长城上空进行军事侦察，可能是从秦皇岛水域停靠的日军水上飞机母舰上起飞。

  • 1933年2月7日《申报》：北平息，日人委叛逆张海鹏为热河军务督办，兼攻热第一路总指挥。（6日专电）

  • 1933年2月7日《申报》：北平息，义勇军在李家堡进攻甚力，日军第一警备队向万家屯高岭退却，同时医用又向兴城连山进攻甚烈，日急将锦西第八师团冈本支队赶向兴城增援外，昨复将秦皇岛海面日舰两艘调至葫芦岛，第二外遣舰队将全开葫芦岛，以策应各方。（6日专电）

  • 1933年2月7日讯：四川善后督办刘湘召杨森、李家钰、罗泽洲等在渝开军事会议，决定增调刘湘部十个团、杨森部四个团赴川北，由田颂尧指挥堵截红四方面军，并电复西南政务会同意加入西南国防委员会。

1933年02月06日

  • 1933年2月6日讯：伪满国务院通过《商租办法》，确认日本军民在东北享有居住、往来和拥有土地的一切权利。

  • 1933年2月6日讯：犹国才到达南京，向国民党中央报告黔省内战经过，并要求相当名义。

  • 1933年2月6日讯：贵州省府主席、第二十五军军长王家烈电西南政务会，同意加入西南国防委员会。7日，西南政务会推王为西南国防委员会委员。

  • 1933年2月6日讯：行政院及中央古物保管委员会将北平故宫古物首批2118箱启运南京。天安门至西车站一带戒严，并将北平市民众保存故宫古物协会主席周肇祥逮捕，至22日古物在浦口起卸时始予释放。

  • 1933年2月6日讯：锦西日军沿小凌河推进，凌南、凌源等地形势紧张。

  • 1933年2月6日讯：南昌各界“协剿会”为“剿匪”急需，作出征借本市房铺租一个月，征收商店特别捐三个月，以及摊派店员每人一元捐等决定。

  • 1933年2月6日《申报》：北平息，郑桂林部伤兵九名到平，谈该部一日三次总攻九门口日军，二日夜向九门口小山城总攻，激战甚烈。三日早，郑率部攻兴绥先头部队，与伪军张子清不接触，伤兵由九门口抬至石门寨，转乘柳江火车换北宁路车来平。（5日专电）

  • 1933年2月6日《申报》：热河息，5日午此间市面纷传，日机将来承德侦察，驻军司令部即在沿城高处，预装高射炮，严密防范，结果未见踪迹。南方某救国宣传团，连夜放映国难电影，观众逾万，团员演讲时，群众大受感动，狂呼打到日本帝国主义口号，抗日空气浓厚异常。（5日中央社电，图文无关）

  • #抗战影像#山海关沦陷后，日军第8师团继续攻占在山海关以北的长城要隘石门寨，图为第8师团所属日本部队官兵在石门寨附近的合影。

  • 1933年2月6日《申报》：临榆息，4日，九门口方面义勇军与敌有激战，榆关敌百余名往援，5日在相持中，晨有伤兵二十余到榆。（5日专电）

  • 1933年2月6日《申报》：北平息，汤玉麟电平，据称，日军三宅骑兵第八联队一部七百余人，携迫击炮四尊，大炮十门，3日开抵绥中，与北票逆军李际春联合，将大举进攻朝阳。金教寺义勇军耿继周部，仍与三坚正部混战中，闻日方将先实行第三路攻热计划，由朝阳进攻南岭，并以李际春为攻热司令，实行以华治华之阴谋云。（5日中央社电）

  • 1933年2月6日讯：蒋介石在南昌召见湖北绥靖主任何成濬、第四十四师师长萧之楚、第十四师师长周至柔、新编第三十七师师长郭炳生、总部参议马青苑等商“剿匪”军事。
