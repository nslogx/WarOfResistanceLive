1933年02月12日

发表于 2022-02-12 更新于 2022-03-14 分类于 局部抗战(1931-1937)

  • 1933年2月12日讯：浙江慈溪县三北乡农民千余人反对县基干队驻扎该乡，将基干队物件焚毁。县府增派基干队前往镇压，拘捕农民七人。

  • 1933年2月12日讯：上海全浙公会电外交、财政两部，主张中日关税协定期满失效，反对在日人武力侵略状态下与日本重订协定。

  • 1933年2月12日讯：全国艺术家捐助东北义勇军作品展览会在上海开幕，本日前往参观者达万人。至20日闭幕。

  • 1933年2月12日讯：上海回民举行追悼榆关阵亡军士大会，吴铁城、张之江、王晓籁以及段祺瑞等出席。为悼念营长安德馨（回族），大会决议捐购“安德馨号”飞机。

  • 1933年2月12日讯：南迁故宫古物首批2000余箱因事先未定妥存放地点，在南京浦口停搁。是日，国民党中政会决定分置河南洛阳、开封，由行政院电令豫省府主席刘峙妥觅地点。嗣因蒋介石不同意，遂将古物分存京、沪。至5月，故宫古物自北平分五批运走1.956万箱，运费达43万余元。

  • 1933年2月12日讯：陈诚在南昌就任赣粤闽边区进剿军中路总指挥，赣东各“剿匪”部队属之，所属原第十八军副军长罗卓英升任第五军军长，第十四师师长周至柔任第五军副军长，该师副师长霍揆彰升任师长，第十一师副师长萧乾升任师长。

  • 1933年2月12日《申报》：北平息，昨晨8时日机6架，由通辽飞开鲁郭家店等处轰炸，投下均系三百磅重磅炸弹，轰炸极残酷，各处起火，商民死伤枕藉，惨不忍睹。同时日军由忙牛硝进攻，另有日人率蒙匪三千余，由岔沟门进攻开鲁。我开鲁防线为义勇军冯占海部扼守，双方激战10小时，我军因敌方坦克大炮锐利，以血肉相搏，刻正在沉着应战中，开鲁我军已陷苦境，各地义勇军已往驰援。（11日专电）

  • #抗战影像#日军随军记者拍摄下毁于日军炮火的山海关南门。

  • 1933年2月12日《申报》：北平息，东北义勇军李春润部朱奎武团，日前在新宝、新县、南口、前黑牛桥一带，与敌激战三日，因弹尽粮绝，所部400余，将枪械藏匿，化装走散，余则被日兵缴械遣散，日本侵满全权大使武藤，自任总指挥，统率逆军四个梯队，蒙匪千余名，及日军五百余，昨晨9时由通辽向开鲁实行总攻击。（11日专电）

  • 1933年2月12日《申报》：北平息，承德10日下午7时电话，今日开鲁方面日军向我崔旅长防线猛攻，同时以飞机向附近村落掷弹，平民死伤356名，为从来未有之惨剧。现崔旅长一部正向西移动，对日伪军作大包围形势。（11日专电）

  • 1933年2月12日讯：张学良制定以“确保冀热并巩固平津为目的”的防御方针，成立华北军总司令部，由蒋介石兼任总司令，张学良任副总司令。是日发布华北军两个集团军、七个军团战斗序列及任务：第一集团军总司令张学良兼，辖第一军团总指挥于学忠，由第五十一军、第四十军组成，于天津附近集中，担任塘沽方面防务；第二军团总指挥商震，由第三十二军、第五十七军组成，于滦东附近集中，担任滦东方面作战；第三军团总指挥宋哲元，由第二十九军组成，于通县、三河附近集中，准备担任热河凌南方面作战；第四军团总指挥万福麟，由第五十三军组成，担任热河中路凌源、平泉、承德线之防守。第二集团军总司令张作相，副总司令汤玉麟，辖第五军团总指挥汤玉麟，由第五十五军、骑二军组成，担任热河北路开鲁、赤峰及中路南岭、北票线防守；第六军团总指挥张作相兼，由第四十一军、第六十三军等部组成，担任赤峰、围场线防务；挺进军总指挥刘翼飞，由热河境内五路义勇军组成，按原驻地分别配合正规军作战。另第七军团总指挥傅作义，直隶总司令部，由第五十九军、第六十一军组成，预定用于察东方面，暂于察省沽源集中待命。

1933年02月11日

发表于 2022-02-11 更新于 2022-03-14 分类于 局部抗战(1931-1937)

  • 1933年2月11日讯：伪满外交总长谢介石电令驻日内瓦伪代表卜朗逊（美人），与日本代表团协同动作。13日，卜将备忘录一件递交国联，为伪满所谓“独立自主权”作辩解。

  • 1933年2月11日讯：行政院令准广西古化县改名百寿县。

  • 1933年2月11日讯：中央研究院地质所研究员李捷、朱森、丘立我在桂林发现百万年前化石。

  • 1933年2月11日讯：财政部召开整理田赋会议，确定原则两条：一、附捐不得超过正税；二、正赋、附捐共同征收额不得超过田价1％，并以此为依据制定整理田赋附加办法11条。7月12日通令各省遵办。

  • 1933年2月11日讯：行政院令内政、财政、实业、交通各部及蒙藏委员会派员会商内外蒙通商办法。

  • 1933年2月11日讯：国民政府派代理行政院长兼财政部长宋子文、军政部长何应钦、外交部长罗文干、内政部长黄绍竑等至北平与张学良商讨保卫热河问题及为张军筹措军费，亦有传言实为逼迫张学良下野而来。

  • 1933年2月11日讯：代行政院长、财政部长宋子文由京飞平，与张学良等商华北财政，并拟发行公债2000万元作华北军政费用。宋迭与平、津银行界周作民、卞白眉、杨荫荪、许汉卿等人商洽，望平、津两地承销半数。银行界表示平、津经济力量有限，数目过多，实难负担。

  • 1933年2月11日《申报》：南京息，军部10日颁发去岁参加淞沪抗日作战之第十九路军参谋长黄强、参谋处长赵一肩、军需处长范其务、旅长张励、黄固、刘占雄、邓志才、李盛宗等陆海空军甲种一等奖章各一枚，又副官处长唐德煌、参谋蔡杰、叶季新等，各发陆海空军甲种二等奖章各一枚。（10日专电）

  • #抗战影像#1932年“一·二八事变期间，一队侵沪日本陆军士兵集结待命中，准备赶往前线同中国守军作战。

  • 1933年2月11日《申报》：北平息，热边义勇军司令李芷亭9日电称，日军1500名，今晨向我七里河子防地，用猛烈炮火进攻。我全军抵抗，旋第五军团刘震东部第三梯队司令解国忱，率队千余来援，激战甚烈，日亦增援数百名参战，刻形势极为紧张。（10日专电）

  • 1933年2月11日《申报》：北平息，石河东岸日军，时摇白旗，向我军挑衅。昨晚8时，日骑兵突向石河桥冲进，经我西岸步哨用机枪扫射后始退。石河前线一时顿形紧张，榆关车站共停甲车三辆。（10日专电）

  • 1933年2月11日讯：蒋介石严令各“剿匪”部队，除厉行纵的连坐法外，并遵行横的连坐法，规定同一战斗序列各部，必须密切联络，同进同退，否则杀无赦。

1933年02月10日

发表于 2022-02-10 更新于 2022-03-14 分类于 局部抗战(1931-1937)

  • 1933年2月10日讯：国民党南京市党部决议请求中央解散中国民权保障同盟，并予宋庆龄、蔡元培等以警告。

  • 1933年2月10日讯：江西省成立经济委员会，以范争波任主席，金融界徐槐青等任常委。该会以筹措“剿匪”军费为主要任务。

  • 1933年2月10日讯：辽东民众自卫军第三方面军王凤阁部2000人攻占抚松县城。

  • 1933年2月10日讯：李延禄率救国游击军在宁安东南团山子击退日军守备队及伪军进攻，敌伤亡200余人。

  • 1933年2月10日《申报》：北平息，驻朝阳董福亭，电汤玉麟报告，南岭北票间，防务吃紧。北票驻有汤（部一）团，煤矿已停止开采，交通断绝，南岭我军已增加兵力。（9日专电）

  • 1933年2月10日《申报》：北平息，日在通辽召集不肖蒙民，拟由内蒙沿新辽河进攻开鲁，伪军张子青部，系地方警察改编，程国瑞部系当地民众，被日寇扰乱，无家可归者，均无战斗力。（9日专电）

  • 1933年2月10日《申报》：北平息，耿继周部克服朝阳寺，与敌连日激战，嗣因敌用全力猛烈压迫，耿部已退出朝阳寺，向北票方面集中。（9日专电）

  • #抗战影像#1932年“一·二八事变”期间，一队侵沪日本陆军士兵正在集结待命，准备赶往前线同中国守军作战。

  • 1933年2月10日《申报》：天津息，前方电，据谍报，在锦州等处编练伪军之丁强，查系李际春之化名，丁在锦西县招募游击队一团，已训练成熟，将开往热河作战。7日夜，突有七八十名反正，杀死伪军官数名，掳走伪军官十余名，及士兵五六十，结队赴热边，请求朱霁青收编为救国军，共同抗日报国，该部枪械齐全。（9日专电）

  • 1933年2月10日《申报》：北平息，热河岭南紧急，敌用飞机坦克掩护步兵，自岳王庙进攻大井牛营子。（9日专电）

  • 1933年2月10日讯：日关东军司令官武藤召集各兵团主任参谋会议，布置关东军热河作战要旨：派第六师团、骑兵第四旅团及伪军张海鹏部在热河东境作战；派第八师团、混成第十四旅团急速进兵热河南部及河北省边境，“构成把华北与热河真正割断的铜墙铁壁”，以压迫张学良的势力，使热省华军及义勇军陷于孤立无援，尔后席卷西部及西南部。除另有命令外，不要在河北省内实施作战。本作战由本月下旬开始，在结冰期间结束主要作战行动。

1933年02月09日

发表于 2022-02-09 更新于 2022-03-14 分类于 局部抗战(1931-1937)

  • 1933年2月9日讯：行政院令准云南靖边行政区改置屏边县。

  • 1933年2月9日讯：中国电影文化协会在沪成立，选出执委及候补执委黄子布（夏衍）、陈瑜（田汉）、洪深、聂耳、沈西苓等31人。协会发布宣言，指出“帝国主义的侵略与封建势力的压迫在今日已更见严重”，号召电影工作者“亲切地组织起来”，“认清过去的错误”，“探讨未来的光明”，开展电影文化运动。

  • 1933年2月9日讯：国民政府明令改组湖北省政府。原省府委员夏斗寅、朱怀冰、沈肇年、夏元瑮、李书城、孔庚、杨在春、陈达勋、晏勋甫均免本职；夏斗寅免省府主席兼职，朱、沈、夏、李分别免民政、财政、教育、建设厅长兼职；任命夏斗寅、李书城、贾士毅、李范一、程天放、范熙绩、杨在春、陈达勋为省府委员，夏斗寅兼主席，李书城、贾士毅、程天放、李范一分别兼民政、财政、教育、建设厅长。

  • 1933年2月9日讯：国联十九国特委会致函日本代表团，询问日方是否能接受李顿调查团报告书关于满洲地方于中国主权及行政完整之范围内，建立高度自治权之原则，作为拟议的调解基础之一。14日，日本复文仍未明确答复，仅称：“确信维持与承认满洲国之独立，为远东和平之惟一保障，而此全体问题，将终由中日两国依此基础解决。”

  • 1933年2月9日讯：外交部公布与英、美、法、荷、巴西公使及挪威代办互致照会，同意1930年4月1日与上述各国在南京所订上海公共租界内中国法院之协定，自本年4月1日起延长有效期三年。

  • 1933年2月9日讯：关东军完成了“热河经略计划”，指出“热河经略之目的在于使热河省名副其实地成为满洲国的领域”，并确定了各部队的作战方向和时间。

  • 1933年2月9日讯：日陆军省发表侵热声明，妄言“满洲国为保持主权威信，已决定肃清热境华军。日本军部根据《日满议定书》合同，则满军剿灭叛徒，此种行动已有英、法前例可援，断非日军之侵华战争”。

  • 1933年2月9日讯：胡汉民为刘煜生、王慰三被杀事件电林森、孙科，指出：“数年来，人民言论、出版、居住自由为军人剥夺净尽，纲纪坠毁，民无死所”，要求“为死者求昭雪，为生者求保障”。

  • 1933年2月9日讯：中国民权保障同盟电山东省政府主席韩复榘，要求释放因参加“国民党行动委员会”嫌疑被捕之袁春霆等30余人。又电交通部，要求释放被捕之北平邮务工会抗日会执委13人，惩办北平邮局邮务长巴立地。

  • 1933年2月9日《申报》：北平息，苏炳文部两旅陆续由北满开抵热河北部某地，军士稍息，即调往热东，参加抗日作战。苏部前敌指挥张玉挺前赴某地检阅该两旅毕，昨返平，今晨赴津，日内事毕赴热东抗日。（8日专电）

  • #抗战影像#伪满洲国时期，沦陷的东北某处伪政府门口，悬挂着伪满洲国国旗。

  • 1933年2月9日《申报》：北平息，开鲁义勇军冯占海部已与张玉挺部联合，即将大举进攻日军根据地通辽，连日开鲁东道、德营子、小姑家子战事甚烈，日军已由通辽加派黑田支队往援。（8日专电）

  • 1933年2月9日《申报》：北平息，7日晨敌骑步军500余，会同伪军千人，携大炮三门，坦克4辆，由新立屯犯我阜新，与该地义勇军孟昭炎、李海青等部激战3小时。敌派机5架飞阜新城轰炸，破坏甚重，绥东敌军刻集结打通路之章古台等地，一部与义勇军在十字店相持。（8日专电）

  • 1933年2月9日讯：国民党中常会为指导华北党务工作，决定于新乡设中央执行委员会华北临时办事处，由张继任主任，王法勤、张厉生、陈立夫、王陆一、赵丕廉、刘守中、白云梯、克兴额、傅汝霖、黄慕松、纪亮、苗培成等为委员。

1933年02月08日

  • 1933年2月8日讯：前江西都督、国民政府参军马毓宝在上海病死。18日，国民政府令军政部照上将积劳病故例从优议恤。

  • 1933年2月8日讯：天津地方协会举行成立会，推选熊希龄等九人为常务委员。该会以抗日后援为其主要任务。

  • 1933年2月8日讯：豫鄂皖三省“剿匪”总部参谋长曹浩森到南昌，向蒋介石报告三省“剿匪”军事。

  • 1933年2月8日讯：国民政府以与日尚未断交，令外交、财政两部研究续订中日关税协定问题。12日，财政部令海关总署作修改细则准备。
