1933年01月29日

发表于 2022-01-29 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1933年1月29日讯：蒋介石到达南昌亲自坐镇指挥对中央苏区进行第四次“围剿”。

  • 1933年1月29日讯：热河省府主席汤玉麟电林森、蒋介石等，称：热河境内义军、溃军，连同正式军队已达20余万，要求速筹办法给予粮饷接济。31日及2月3日，又连电催促办理。3月1日，实业、财政、内政三部议决呈行政院通令各省、市政府，“鼓励粮商或商会将粮食运往热河销售，并由政府设法协助保护”。直至3月21日，实业、财政、内政三部始会函向行政院呈报。

  • 1933年1月29日讯：吉林自卫军瓦解后，尚余几支较大的部队，孙朝阳、陈子鄂、郭怀堂、刘化南、李华堂等部5000余人在下江地区坚持斗争。陈大凡等在绥滨、桦川组织抗日军1700人。

  • 1933年1月29日讯：根据中共宁安县委指示，在宁安一带活动的抗日游击队改编为“东北抗日救国游击军”，李延禄任总司令。

  • 1933年1月29日《申报》：北平息，日军在锦州第八师团司令部，召开攻热军事会议，列席者第八师团、第六师团、第廿师团、第九师团大佐以上人员，日参谋部梅津少将、松木大佐及武藤信义代表斋藤大佐等。决以日军五万，分向凌南开鲁及滦东进攻，谋取热河，并决定在锦州设总指挥部，由梅津常川驻守，担任指挥全责。刻锦州军车日夜向绥中输送，伪奉山路车全停。葫芦岛连山湾有日舰5艘，运来枪炮子弹等军用品甚多，正向锦绥等地输送中。（28日专电）

  • #抗战影像#在入侵山海关作战中，配属给日本陆军第5联队的第6装甲列车队2名士兵与列车炮合影。

  • 1933年1月29日《申报》：上海息，昨日为“一·二八”淞沪抗日周年纪念，本市各界，假小西门少年宣讲团举行纪念大会，决议要案四件，全市休业悬半旗，节食移助军饷，警备司令部市民联合会等机关，分别举行多场纪念活动。（28日专电）

  • 1933年1月29日《申报》：北平息，敌以野 炮队一排，28日晨掩护坦克车2辆，在我石河一带阵地巡视，发两炮向我示威。9时敌机2架，飞石门寨后方侦查，向附近村落投弹数枚而去。（28日专电）

  • 1933年1月29日讯：辽吉黑民众后援会会长朱庆澜通电全国，列举义军抗日业绩，吁请全国续作后援。

1933年01月28日

发表于 2022-01-28 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1933年1月28日讯：田颂尧就任川陕边区绥靖督办，孙震任总指挥，率部进驻阆中，决定以第四师师长王铭章任“进剿”军左纵队司令，指挥第四、五独立各师由广元向南江进攻；以第三师师长罗乃琼任右纵队司令，指挥第一、二、三师由阆中向巴中红四方面军徐向前部进攻。

  • 1933年1月28日讯：中国教育学会在上海成立，以“研究改进教育为宗旨”，选刘廷芳、刘湛恩等15人为理事。

  • 1933年1月28日讯：热河省府主席汤玉麟通电全国各报馆，表示“守土有责，抗日救国，贯彻始终”。

  • 1933年1月28日讯：外交部照会日驻华使馆，抗议日机轰炸开鲁。

  • 1933年1月28日讯：美国芝加哥群众600人高举反日旗帜，包围日本领事馆，抗议日本侵略中国。日领事逃出领馆躲避，警察前往弹压，数千群众用石头与警察搏斗，嗣经大批警察开到始散。群众受伤30人，被捕180余人。

  • 1933年1月28日讯：上海各界举行“一二八”纪念大会，通电全国一致抗日，捐款购机。全市休业一日，上海公安局及日海军陆战队均严密防范。同日，全国各大城市均举行集会，要求国民政府抗日。天津国立院校教职员联合会决定每月捐薪10％支援抗日，并派代表赴各地联络抗日工作。北平民众抗日救国总会在天桥召开市民大会，警察以“非法集会”罪名驱散，并捕去学生20多人。

  • 1933年1月28日讯：延吉各游击队在依兰沟组成延吉县抗日游击大队，朴东根任大队长，朴吉任政委，大队130人，分为三个中队，此后，王德泰率领从山林队中拉出的武装20余人也来到依兰沟，加强了延吉县抗日游击大队的力量。

  • 1933年1月28日讯：关东军司令官武藤信义下达了“关于进攻热河的作战准备命令”，命令第8、第6 师团迅速向热河边境集结，骑兵第4 旅团，混成第14旅团待命出动。此前军部还下令增派部队，充实关东军。

  • 1933年1月28日《申报》：北平息，此间官场消息称，占据榆关美国教会产业之日军，今已退出。（27日路透社电）

  • #抗战影像#“一·二八事变”期间，一名在上海公共租界区站岗执勤的英属印度殖民地军队士兵。

  • 1933年1月28日《申报》：莫斯科讯，日本屡传中俄缔结秘密盟约以抗日本之说，闻苏俄方面对于日本此种政策，渐形愤怒。据此间消息灵敏者云，苏俄虽有抗议，然日本仍进行其散播谣言之政策。再，日本陆相荒木近在上议院声称，日本已设置空军（注：应为陆军和海军航空队），其力量与俄之空军同，其故因斯大林最近演说预料俄日仇敌之可能性也云云。苏俄官场对于荒木此种言论，认为极不正当。（27日路透社电）

  • 1933年1月28日《申报》：东京讯，日内瓦来电，日本与国联之对立状态，依然不缓和，国联声称，非由日本让步，无折冲余地。日方亦要求国联之让步，在此对峙之下，仅由特鲁蒙与衫村时有晤谈，两者关系前途如何，始不能预测。（27日日联社电）

  • 1933年1月28日讯：日关东军司令官武藤下令准备进攻热河，令第十师团接管第六师团现行任务，并将第十四旅团于2月20日前返回第八师团原属；第十四师团接管独立守备队铁路保护任务；第六师团在2月24日前集兵力于所警备区域及奉天、四平街铁路沿线要地；第八师团在2月24日前将主力向饶阳河以西奉天省内各要地集结，准备尔后向承德前进；混成第十四旅团做好在2月24日以后开始行动的态势；骑兵第四旅团即日起受关东军司令官直辖，第六、十、十四师团各准备一部兵力于2月20日以后供军司令官使用。

  • 1933年1月27日讯：蒋介石派王法勤赴张家口邀冯玉祥赴京“共商抗日大计”，21日王抵平。是日偕黄少谷到张与冯多次晤谈。冯表示如中央有抗日决心，当即刻启程到南京供驱使，虽粉身碎骨亦所不辞，并嘱黄随王赴京向中央表明态度。30日，王、黄返平，2月8日抵京复命。

1933年01月26日

发表于 2022-01-26 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1933年1月26日讯：国民政府任命冯兴贤为第三十三师师长；俞大维为军政部兵工署署长。

  • 1933年1月26日讯：日步骑炮联合部队，以伪满蒙军为前驱，在飞机掩护下进犯开鲁。东北义勇军李海青等部奋起抵御，将其击退。

  • 1933年1月26日讯：日陆相荒木在众议院答辩时宣称：“张学良若不反省而与日军构衅，则日方亦已作相当准备。”2月2日，再次在众议院宣称：“关东军已决定与满洲国军队合作，肃清热河军九万人。”

  • 1933年1月26日《申报》：北平息，日军司令加藤率第一旅团步炮军千人，23日由锦州乘甲车两列抵朝阳寺，在车站设司令部，昨晨率随从数十人，向我阵地近处巡视一周，同时日机2架向我阵地侦察。（25日专电）

  • 1933年1月26日《申报》：通辽息，日军航空队北野大尉以下5名，搭乘轰炸机，于24日上午10时半出发通辽，飞往开鲁北方，攻击义勇军。但至晓未归，或系途中发生故障，安否可虑。（25日电通社电）

  • #抗战影像#日本陆军第5联队对东北抗日义勇军手段十分狠毒，落入他们手中的抗日义勇军被斩首后，头颅还被悬挂在树上以图恐吓中国老百姓放弃抗日的念头。

  • 1933年1月26日《申报》：北平息，北戴河昨发现日舰5艘，在海面停泊，用探照灯四射。（25日专电）

  • 1933年1月26日《申报》：北平息，日参谋次官小矶，连日在锦召集日伪军重要将领铃木、程国瑞、于芷山、李际春等协商攻热计划。决定日军第六、第七、第八、第十二四个师团为主力军，调驻朝鲜日兵第十五师团第二十师团为预备队，张海鹏、程国瑞、于芷山、李际春等逆部各抽派二旅，担任前锋。于芷山逆部两团开绥中，张海鹏骑兵二千向通辽集中，另通辽集有日伪军及蒙匪约一万五千余人。驻朝鲜日第十五师团一部昨到沈，并传对侵热军事已定，对锦朝线取守，先取热河开鲁、凌源两地，拟想朝阳包围。（25日专电）

  • 1933年1月26日讯：中共中央发出《中央给满洲各级党部及全体党员的信》，对“九一八”后东北形势作出估计，分析东北四种反日武装的性质和前途，提出“为使反日游击运动胜利”，“须要坚决的为夺取和巩固我们党在满洲反日游击运动及各种革命群众运动中领导权而斗争”，“在政治上和组织上发展和巩固我们党在满洲的组织，是目前我们党最要紧最主要的任务之一”，并指示组织抗日民主政府，组织抗日民族统一战线，发动东北人民武装抗日等具体任务。

1933年01月25日

发表于 2022-01-25 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1933年1月25日讯：新疆维吾尔族民众反对金树仁的斗争波及北疆，新编第三十六师马仲英部将领马全禄趁机在北疆集合暴动民众绕道天山进攻迪化（今乌鲁木齐）。金树仁遣团长邹某率兵数百人往堵。是日，暴动民众在达坂城乘旧历除夕，邹部戒备疏懈，实行夜袭，邹部逃脱者仅百余人。随后暴动民众直趋迪化。金令陈品修任南路总指挥应援，暴动民众入南山暂避其锋。

  • 1933年1月25日讯：闽浙赣新红十军成立，王如痴任军长兼政治委员。

  • 1933年1月25日讯：红军一、五军团围攻临川以来，因国民党军集主力于临川，为避实计，东乡一带红军转移资溪，翌日让出浒湾，28日放弃金溪黄狮渡等地，向南城、黎川转移。

  • 1933年1月25日讯：东北义勇军独立第八梯队王慎庐部会同东北民众救国军第四路郑桂林部联合进攻九门口，与日第八师团在九门口周围旋战近十日，曾一度占领九门口东、西城，击毙不少日伪军。

  • 1933年1月25日讯：蔡廷锴抵广州出席西南政务会，发表谈话称：“目下情势惟有一战乃可图存，苟再玩忽，非至亡国不止。”并表示一旦中央令下，即统率兵力北上抗日。

  • 1933年1月25日讯：国民党中央执行委员会电召冯玉祥到京“共谋决策”。是日，冯电复，以“内感风寒”辞不应召，并陈述抗日意见12条，主要内容为：组织统一指挥之军事机关，统筹抗日军事全盘计划；立即调遣精锐部队开赴前线；筹拨巨额军费；赶制各种器械弹药；派飞机协助作战；接济义勇军；恢复各种民众组织；令军队严守纪律等。29日，冯电于右任表示：“此时国家出路，惟武力抗争之一途，倘介石先生具此决心，弟当即日南下。”
