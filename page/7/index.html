1932年08月17日

发表于 2021-08-17 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年8月17日讯：山东武城县运河决口，淹没房屋甚多。

  • 1932年8月17日讯：交通部因各方反对该部前与马凯公司所订无线电合同，是日以“财政支绌，无力办理”为由，向该公司商请取消。

  • 1932年8月17日讯：驻沪日总领事村井和驻津日总领事太田就锄奸团的抗日活动，分别向各该市政府提出抗议，要求予以取缔。

  • 1932年8月17日讯：丁超、李杜、冯占海、王德林等派代表赴平，代表东北15万官兵，恳求张学良“顾念国难家仇，万勿遽萌退志，以资振奋军心，而利长期抗日”。

  • 1932年8月17日讯：华北军、师、旅长61人由宋哲元领衔，联电张学良劝勿辞职，略谓：“值此积极抗日之日，请顾念华北重大责任，勿因各方意见灰心言去，如必去，职等只有避位让贤。”

  • 1932年8月17日讯：外交部就日本任命武藤为伪满特命全权大使事发表宣言，指出日本政府“此项举动显然为正式承认伪满之初步，藉以达其最终吞并之目的”。

  • 1932年8月17日讯：国民党中央政治会议决议：一、北平绥靖公署暂行停设，改设军事委员会北平分会；二、《北平军分会暂行组织大纲》准予备案；三、任命王树翰、万福麟、张作相、张群、韩复榘、徐永昌、王树常、宋哲元、鲍文樾、于学忠、商震、荣臻、庞炳勋、沈鸿烈、汤玉麟、蒋伯诚、刘翼飞、萧振瀛为北平军分会委员，指定万福麟、荣臻、蒋伯诚为常务委员，蒋介石自兼委员长（19日，国民政府明令发表北平军分会委员名单）；四、免河北省政府主席王树常职，免平津卫戍司令于学忠职，任于学忠为河北省政府委员兼主席；任王树常为平津卫戍司令（9月11日就职）；免察哈尔省政府主席刘翼飞职，任宋哲元为察哈尔省政府委员兼主席。18日，国民政府发表冀、察省府主席任免令。

  • 1932年8月17日《申报》：北平息，吉林义勇军于大任部，在双阳与日军接触，王德林部连日与日军冲突。（16日专电）

  • 1932年8月17日《申报》：北平息，蒙边义勇军约三千人，15日抵义县，日军亦积极增兵，形势紧张。（16日专电）

  • #抗战影像#一队关东军在中国东北的一处院子里吃饭。

  • 1932年8月17日《申报》：北平息，义勇军千余猛攻高桥，日军不支，退出车站，兴城锦州日军因此失联络，锦州陷入孤立，危在旦夕。（16日专电）

  • 1932年8月17日《申报》：北平息，锦西朝阳救国军分12别动队，每队70人，进攻锦州，副司令系两江女生姚莹芳，已率部抵西关，刘玉海率众抵锦州，西城门毙日兵6名，秩序大乱。城门紧闭，别动队总指挥金铸山，率众往焚锦日机场，值日军正调机，遂冲突。别动队因急夺机，误触地雷，伤5人，因日甲车来援，炮火猛烈遂退出。（16日专电）

  • 1932年8月17日讯：汪精卫回京，出席国民党中执委会临时常务会议，报告辞职经过。汪表示此次辞职之本意，决非一般所谓消极主义，要求中央鉴其真诚，另行物色接替人选，“本人辞职后，仍担任中政会事务，不敢推辞”。吴敬恒、叶楚伧、居正等发言慰留。

1932年08月16日

发表于 2021-08-16 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年8月16日讯：鲁南滕、峄、邹、兖等县及苏北铜、邳、沛县蝗蝻成灾，秋禾树苗食尽。

  • 1932年8月16日讯：辽南抗日义勇军袭击鞍山制钢所。

  • 1932年8月16日讯：吉林义勇军破坏吉敦路，颠覆列车一列，克沈海路支线东丰县城。

  • 1932年8月16日讯：济南、苏州、平、津、嘉兴等地锄奸团警告各商店勿贩卖仇货。

  • 1932年8月16日讯：红一方面军发起乐安、宜黄战役。17日，攻克乐安城，20日占领宜黄城。第二十七师高树勋部四个团大部被歼。同时，闽西红军19日占领宁化，红十二军23日占领南丰。

  • 1932年8月16日讯：全国体育会议在南京开幕。21日闭幕。会议通过《国民体育实施方案》。发表宣言，强调普及全民体育。

  • 1932年8月16日讯：国民政府特派颜惠庆、顾维钧、郭泰祺为出席国联第十三届大会代表。

  • 1932年8月16日讯：行政院会议通过：李四光请辞中央大学整委会副委员长及代行中大校长职务，决议慰留。

  • 1932年8月16日讯：西南政委会决议，设立最高法院西南分院，为粤、桂、闽、滇、黔五省终审审判机关，派广东高等法院院长陆嗣曾兼管最高分院行政事务，并通过该分院组织暂行条例。18日，最高法院咨西南政委会，反对设立西南分院。

  • 1932年8月16日讯：蒋介石为杜绝挟嫌诬告之风，制订《控告官吏须知八条》，是日在豫、鄂、皖颁行。

  • 1932年8月16日《申报》：南京息，辽宁义勇军第四路总司令耿继周，派代表杨义杰、杨静来京，分呈中央国府军委会，报告抗日详情，请求援助。（15日专电）

  • #抗战影像#1932年，高志航与新婚的第三任妻子叶容然女士拍摄于上海，中立者为高志航与第二任妻子葛莉娅所生的中俄混血次女高友良。

  • 1932年8月16日《申报》：北平息，攻锦州打虎山义勇军，因子弹缺乏，暂停进攻，打通线义勇军刻守黑山。（15日专电）

  • 1932年8月16日《申报》：北平息，沈讯，辽南第二军区总攻满铁沿线，迭克强敌。惟日人利用汉奸，潜入境内，煽惑造谣。李代指挥10日令沿南满北宁两路中间第二军区内，施行肃清工作。当获汉奸于冠军等13名，13日在总部枪决。（15日专电）

  • 1932年8月16日讯：江苏高等法院续审牛兰案。牛兰夫妇对10日至12日三次口供笔录颇多修正，以高等法院笔录多处错误，拒绝签字。

  • 1932年8月16日《申报》：沈阳息，铁岭新城一带，有大批义勇军，围攻铁岭。沈日警接此急报，派警官50人，守备队若干名前往防御。烟台附近下午7时发现义勇军，准备明晨袭击烟台，日当局非常紧张。（14日日联社电）

1932年08月15日

发表于 2021-08-15 更新于 2021-09-16 分类于 局部抗战(1931-1937)

  • 1932年8月15日讯：张学良委任唐聚五为辽宁省政府主席兼辽宁民众自卫军总司令。20日，辽宁省政府正式成立，以裴焕星、杜枫廷、高惠民分别任民政、财政、实业各厅厅长。

  • 1932年8月15日讯：蒋介石将自序之《胡林翼军政语录》分发给豫、鄂、皖三省官吏。

  • 1932年8月15日讯：蒋介石乘飞机赴浔转庐山。张学良派参谋长鲍文樾携亲笔函至庐山谒蒋，报告华北军政诸事，并请示机宜。

  • 1932年8月15日讯：张学良召集所部各将领在平开会，各将领希张顾念国难当头，取消辞意。张训勉三点：一、努力为国，“不忘党 国福利”；二、勿蹈军阀割据覆辙，不以一人之去留危及国家；三、凡事三思而行，平心静气，态度安详。

  • 1932年8月15日《申报》：沈阳息，铁岭新城一带，有大批义勇军，围攻铁岭。沈日警接此急报，派警官50人，守备队若干名前往防御。烟台附近下午7时发现义勇军，准备明晨袭击烟台，日当局非常紧张。（14日日联社电）

  • 1932年8月15日《申报》：延吉息，昨晚义勇军数百袭击珲春，日军还击。经一小时，义勇军始退。（14日日联社电）

  • 1932年8月15日《申报》：北平息，马占山在大青山，前在海伦附近与日人作战，部队确受相当损失，马部尚有四旅，分驻木兰县附近，与丁超、李杜联成一气。（14日专电）

  • #抗战影像#一名日军在我东北漫天大雪中。

  • 1932年8月15日《申报》：北平息，峪岭口义勇军赵大中三千余人，联络兴城绥中义勇军郑桂林部，大举攻锦州。并派许少华在遵化玉田一带，招集数千人，继续东进，为各路应援。（14日专电）

  • 1932年8月15日《申报》：山海关息，汪张辞职声中，日军散布空气，谓将利用时机，于8月底9月初在榆关方面实行暴动。连日日军大形活跃，在南海架设电话，以备举事时日兵营与海面军舰联络之用。在北宁路榆关段内演放通信鸽，在连山、兴城、绥中、前所等车站构筑工事与炮台。锦州绥中日军官佐，接续来榆视察，络绎不绝，又日飞机13日飞关外永安堡掷弹8枚，炸毁民房三处。（14日专电）

  • 1932年8月15日讯：国民党中委谈话会对汪、张辞职拟定方案，汇送中常会决定：一、准张学良辞北平“绥靖”公署主任职（16日国民政府明令发表）；二、裁撤北平“绥靖”公署，改设军事委员会北平分会，委员18人，以万福麟、荣臻、蒋伯诚为常委；以军事委员会委员长兼任军分会委员长；三、再由中常委切实慰留行政院长及各部、会长。

1932年08月14日

  • 1932年8月14日讯：河北省立各院校联合会派代表谒见省教育厅长陈宝泉，请恢复二十一年教育经费预算，陈允提省政府会议讨论。

  • 1932年8月14日讯：红军贺龙部七、八两师分二路进攻湖北沙市，已抵土城，与川军王陵基部激战一昼夜后，向东北撤退。同日，贺龙红军一部入草市，逼近江陵。

  • 1932年8月14日讯：吴敬恒由汉乘机抵沪，携蒋函偕宋子文、何应钦、朱培德、朱家骅等晤汪，并代达蒋劝汪回任意。汪辞意坚决，但允日内返京。

  • 1932年8月14日《申报》：北平息，伪奉山路日军铁压道车一列，在中途倾覆，日少佐一、日兵七重伤。日兵在黎树沟门新台边门大窑庙一带，均有驻军。每处约一中队，义县兵力较厚，有窥朝阳势。近日时到凌南一带，散传单对中央及张实行反宣传，以离间热河民情。（13日专电）

  • 1932年8月14日《申报》：北平息，路讯，义勇军二百余，一度攻进沈阳，在小西关小南关附近，巷战多时，因众寡不敌，被伪游击队及日军击退。（13日专电）

  • 1932年8月14日《申报》：北平息，共锦义勇军昨夜用抽签法，组必死队，赤臂裹草，持大刀手 枪，扑入日军阵地，猛力肉搏后，一度占锦州车站，获日军坦克车一辆，机枪子弹甚多，必死队生还者寥寥无几，但日军伤亡亦多。（13日专电）

  • 1932年8月14日讯：蒋介石再次电促汪精卫复职，关于华北军政各事，表示愿遵汪意，即为解决；并称：“如仍坚持，当亲至沪面挽。”

1932年08月13日

  • 1932年8月13日讯：晚，张学良在北平再次召集各将领训话，宣布辞职经过及决定赴外国游历考察，并嘱各旅长“团结一致，维持地方，服从命令，拱卫国家”。

  • 1932年8月13日讯：教育部令取消北平华北学校立案，该校全体师生电教育部请收回成命。

  • 1932年8月13日讯：东北民众抗日救国军第二军区代理总指挥兼第一路司令李纯华等，分电汪精卫、张学良吁请复职。称：“陡闻政变，士气顿为沮丧，覆巢之下，必无完卵，值此时势危急之秋，团结御侮之不遑，岂容彼此诘难，互相诿卸。”

  • 1932年8月13日讯：中路军卫立煌部、刘峙部向鄂省新集、黄安、七里坪等处红军进攻，下午占领黄安城。次日第二纵队陈继承部占领七里坪。

  • 1932年8月13日讯：蒋介石请吴敬恒劝汪复职。吴敬恒自京抵汉，征求蒋介石意见，并请蒋即日返京，俾中枢负责有人。

  • 1932年8月13日《申报》：北平息，义勇军昨包围凤城后，日军派韩军二千往援，内外夹攻，正在肉搏，本溪包围已三日，西路军力雄厚，前进甚速，刻距城不足40里。（12日专电）

  • 1932年8月13日《申报》：北平息，朝锦线自义县迄南，全为义勇军占领，义县正围攻中，上齐台沈家台女儿河等，均为义勇军占领。（12日专电）

  • 1932年8月13日《申报》：沈阳息，今晨8时半，义勇军一队攻沈安路，时遇有安东开往沈阳之二百零三号火车，将过石桥子站，离沈阳75启罗米地点，被义勇军攻到，子弹中车窗甚多，旅客面如土色，甚形狼狈，火车开足速力走沈阳。（12日华联社电）
