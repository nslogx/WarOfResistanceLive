1932年06月24日

发表于 2021-06-24 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年6月24日讯：汉口商会全体执委赴鄂省府，要求停办营业牌照税，省府主席夏斗寅允停办。

  • 1932年6月24日讯：中央大学教费独立运动委员会推代表20余人赴行政院请愿，要求拨定庚款为该校经费独立基金。汪精卫手谕答复：“英庚款与英有换文规定用途，当查明办理，如无款可拨，政府必须设法维持中大教费。”该代表认为满意返校。

  • 1932年6月24日讯：行政院决议，北平师大校长李建勋辞职照准，任命李蒸为该校校长。

  • 1932年6月24日讯：全国商联会及上海银、钱两公会为东北关税被夺事发表对外宣言，略称：日本借自造傀儡伪满，“劫夺东北关税，匪特违反现有条约，且足酿成中国财政及政治之瓦解”，“为保障条约尊严，并顾全国际贸易与金融关系起见，应请各友邦速起设法制止日本施此下策”。

  • 1932年6月24日讯：中共临时中央在上海召开北方各省委代表联席会议，通过《革命危机的增长与北方党的任务》、《开展游击运动与创造北方苏区的决议》、《关于北方各省职工运动中几个重要任务的决议》。

  • 1932年6月24日讯：国民政府公布《大赦条例》。

  • 1932年6月24日讯：外交部为伪满将于7月1日起实行贴用日本代印之邮票事，特向日使提出严重抗议，指出日本此种行为“破坏中国邮务行政完整，实属违法已极”，“所有一切责任，应由日政府完全负担”。

  • 1932年6月24日《申报》：哈尔滨息，据此间俄报消息，逐渐西进之日军，已于星期二晚开抵满洲里。闻日军此举，由满洲里穿越边界而去。（23日路透社电）

  • #抗战影像#伪满洲国时期，奉天一处卖眼镜的小商贩。

  • 1932年6月24日《申报》：哈尔滨息，马占山部吴松林等部会合，20日向青岗进攻，与新黑军激战甚烈。日军大队驰往援，马军各团队旗帜，均书抗日救国字样。（22日专电）

  • 1932年6月24日《申报》：哈尔滨息，21日海伦东北三马家子日军将校侦查队，与黑军接触。海伦日军问讯，派骑兵大队往救。克东方面二十日仍在激战，黑军约千余名猛攻甚烈，日军平松、平贺两部联络，激战甚久，黑军退却。（22日专电）

  • 1932年6月24日讯：以博古为首的临时党中央在上海召开北方各省省委代表联席会议，继续推行王明的“左”倾冒险主义政策。参加会议的满洲省委代表反映，在东北应把工作的重点转移到组织和领导东北人民进行抗日武装斗争上来，但却被扣上“右倾机会主义”和“满洲特殊论”的帽子。满洲省委书记罗登贤被撤职，由魏抱一继任。

1932年06月23日

发表于 2021-06-23 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年6月23日讯：中华国民拒毒会就国民政府重颁禁烟令一事发表宣言，表示“疑信参半”，谓“证以当局以往言行之不一致，殊令人难以置信”，“政府果有禁烟诚意，宜于煌煌功令之外，更作事实上之进行”。

  • 1932年6月23日讯：上海废止内战大同盟筹备会电广东陈济棠和陈策，吁请悬崖勒马，另图和平解决；并电广州各团体婉劝力诤，联合阻止二陈互相残杀。

  • 1932年6月23日讯：财政部以伪中央银行发行纸币两亿元，呈请行政院速谋应付方法，并咨外交部向日抗议。

  • 1932年6月23日讯：行政院令冀、鲁、豫省政府及平、津市政府，筹划有效办法，救济自九一八以来由东北逃至华北各处之灾民，协同慈善机关及路局将灾民遣送还乡，或设法为之谋生。

  • 1932年6月23日讯：中华苏维埃临时中央政府为反对国民党对红军发动第四次“围剿”发表宣言，称：“现在国民党军阀……在帝国主义的指挥之下，正集其全力，实行进攻苏区与红军的冒险的行动”，“本政府号召全国的工农兵士及一切劳苦群众，一致的斗争起来，武装起来，扩大民族革命战争……反对帝国主义、国民党对苏区红军的四次大开战。”

  • 1932年6月23日《申报》：北平息，沈伪教育厅令各校组青年联盟团，专宣传承认伪国，并往各县村讲演，欺骗民众。东北各机关职员，多日人。因言语隔阂，日令中国职员每日学日文二小时。日人恐各机关职员反正，多换用女职员，已占三分之一以上，资格多系高小女中或日本女高毕业。（22日专电）

  • #抗战影像#1932年3月8日上午8点，伪满洲国“执政”溥仪与其妻子婉容出发，前往伪长春市政府。

  • 1932年6月23日《申报》：哈尔滨息，21日夜，约五百之义勇军一团，袭击庆城，攻破监狱，放出犯人约百名，经抢掠后退去，日军某某队与各方面之军队联络，向前进攻中。（22日电通电）

  • 1932年6月23日《申报》：北平息，辽东自卫军克复清源，于芷山部日内可肃清，自卫军人数约25万。（22日专电）

  • 1932年6月23日讯：外交部为日本嗾使伪满破坏中国海关行政完整，特向日本政府提出严重抗议，并分别致函《九国公约》签字国之驻华代表，请各政府对日政府准备正式承认“满洲国”事，加以严重之注意。

1932年06月22日

发表于 2021-06-22 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年6月22日讯：青岛大学学生于16日向校方提出取消学费、取缔不良教员、修改学则、制发校章四项要求，未得确切答复，是日一致罢课。24日，校方布告开除学生九人，全体学生赴校长杨振声宅请愿，要求收回成命，杨允俟校务会再讨论处置办法。

  • 1932年6月22日讯：南京各界在公共体育场举行淞沪抗日阵亡将士暨殉难同胞追悼大会，南京市市长石瑛主祭，到万余人。

  • 1932年6月22日讯：上海各团体救国联合会所属89团体，举行留别第十九路军将士大会。

  • 1932年6月22日讯：孙科由沪赴香港调停粤二陈纠纷。

  • 1932年6月22日讯：上海银、钱两业同业公会电请行政院、财政部、外交部，抗争东北关税。

  • 1932年6月22日讯：财长宋子文就伪满政府强劫牛庄、安东税款，移往满洲银行事，再次发表宣言表示反对。

  • 1932年6月22日讯：蒋介石电令鄂、赣、皖、豫省府及“剿共”部队，在苏区与白区交界地带，“一律仿湘办法，举办团防与剿共义勇军”，以扰乱苏区。

  • 1932年6月22日《申报》：哈尔滨息，日机20日至阿城东北三大家子，向冯占海军投弹数十枚。（21日专电）

  • #抗战影像#蒙古族为主的伪满洲国兴安军骑兵部队。

  • 1932年6月22日《申报》：北平息，哈埠来人谈，驻哈伪吉军警备一旅三营，于自卫军攻滨江时，作内应，并至日机场，将飞机6架悉烧毁，后即全队投自卫军。哈附近自卫军，时有攻哈势，日人极恐慌，将哈埠各胡同尽数安置栅栏门，以防自卫军。（21日专电）

  • 1932年6月22日《申报》：北平息，三路义勇军昨夜大败兴城日军，毙敌70余，伤23人，绥中仍酣战中。（21日专电）

  • 1932年6月22日讯：废止内战大同盟筹备会成立，并发表公告，声明全国商会联合会、上海市商会、上海银行同业公会、钱业同业公会等四团体，鉴于内忧外患之严重，拟组织废止内战大同盟会，决先行设立废止内战大同盟会筹备会于上海，即日起开始办公，并定于8月6日在上海举行发起人大会。

1932年06月21日

发表于 2021-06-21 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年6月21日讯：江苏省商联会呈行政院，请严厉制止苏省财政厅兴办特种营业税。

  • 1932年6月21日讯：豫、鲁、苏、皖边界商丘、睢县、宁陵、永城、曹县、夏邑、虞城、柘城、单县、亳县、鹿邑、考城等15县为“剿匪”清乡，在商丘召开15县联防会议，议决于7月1日正式成立15县联防委员会。

  • 1932年6月21日讯：蒋介石任命曹浩森为鄂、豫、皖三省“剿匪”总部参谋长。

  • 1932年6月21日讯：上海市商会呈请行政院免征淞沪国税，庶战区得稍苏息。同日，上海市政府布告减免战区捐税。

  • 1932年6月21日《申报》：沈阳息，今晨一时，义勇军包围攻击满铁沿线汤岗子站，将电报电话线全部切断，断绝与外部之联络，并继续包围攻击日本铁道守备队分遣队兵舍。复以一部袭击收容日本伤兵之玉泉馆，伤病兵即以身边武器起而应战。然已死伤数名，日本守备队现与辽阳、鞍山开到之应援队合力进攻，目下在交战中。（20日电通电）

  • #抗战影像#伪满洲国时期，生活在东北的朝鲜族儿童。

  • 1932年6月21日《申报》：锦州息，本日上午，老北风率部约600名，突然袭击泰安城，并在城内放火，火势甚炽。打虎山之日本守备队田中部队，闻讯驰往，现正与激战中。（19日电通社电）

  • 1932年6月21日《申报》：哈尔滨息，哈长线三姓屯红旗头屯，19日发现吉义勇军一队，与日军战一时许，向双城退去。19日义勇军与日军中村部队激战于双城东官所，双方战线长20余里，吉义勇军扼苏家窝铺、赵家铺子、狼窝海旺窝棚，竭力应战。嗣日军以飞机投弹，重炮轰射，占长岭子高地，义勇军遂向三道沟方面退却。（20日专电）

  • 1932年6月21日讯：上海停战共同委员会开会，俞鸿钧促日军速撤。日方委员冈崎答允最短期内撤退。

1932年06月20日

发表于 2021-06-20 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年6月20日讯：陕西举行泾惠渠落成放水典礼，中央派吴敬恒、褚民谊参加。

  • 1932年6月20日讯：北平市小学教员会召开执委会，议决：一、21日全体执委往访宋子文，面索协款；二、推葛济欧、吕流长二人为代表，持呈文于日内赴绥靖公署，要求张学良从速筹拨补助费。

  • 1932年6月20日讯：中央大学教授、学生举行经费独立运动联席会议，决定：一、以下周为本校经费独立运动周；二、推定代表赴国府请愿；三、电慰任鸿隽并促从速南下长校。21日，中央大学经费独立运动委员会教授和学生代表九人，赴行政院请愿，因汪精卫在平未返，无结果。

  • 1932年6月20日讯：上海各大学学生抗日救国联合会决议反对教育部停办劳动大学。

  • 1932年6月20日讯：兰州中等以上各学校教职员罢教事，经甘肃省政府主席邵力子调解，并发给一个月欠薪，各教职员即日复课。

  • 1932年6月20日讯：许世英电行政院请辞赈委会委员长职。

  • 1932年6月20日讯：陈济棠在国民党西南执行部纪念周报告粤海军历年走私漏税，为政治污点，又不能“剿匪”，故奉令将其改组。

  • 1932年6月20日讯：蒋作宾奉召赴庐山谒蒋介石。

  • 1932年6月20日讯：沪日陆战队声明，沪西丰田纱厂、同文书院、吴淞路华丰纱厂、平凉路公大纱厂四处日军必须长期驻防，决不撤退；第四暂驻区剩余日军亦暂不撤。

  • 1932年6月20日《申报》：哈尔滨息，黑义勇军徐子鹤部拟攻黑垣，现所部出动于齐克璐泰安镇附近，向省城活动，日军宇都部17日在呼兰河北与黑义勇军激战。义勇军退却，日军平贺部队渡过通肯河，向拜泉攻进，义勇军集结拜泉南方扼守。（19日专电）

  • #抗战影像#伪满洲国时期，在东北一处白俄生活区，正在举行东正教婚礼。

  • 1932年6月20日《申报》：哈尔滨息，宫长海义勇军，分两支取双城阿城县，16日已有向两县猛攻之势，双城魏县电哈乞援，日军兵车一列开往。16日晨宫长海、冯占海军已薄近双城，距城只10余里，情形紧张。（17日专电）

  • 1932年6月20日《申报》：沈阳息，今日上午8时，沈安线本溪湖北九里之牛心台，突被数百自卫军所袭击。牛心台车站被包围，站员及警官等努力防御对战，致警官死一站员伤一。及接警报，即由本溪湖之警官队前往征讨，目下正在对峙奋战中。（19日电通社电）

  • 1932年6月20日讯：财长宋子文发表宣言，对伪满强夺东北关税事予以指斥，略称：日政府假借伪满洲国名义干涉东三省海关行政，哈尔滨、牛庄、安东三处海关解交总税务司之税款，分别于3月28日、4月16日和4月19日被迫停止解出，并扩充其侵占行为于大连，构成直接违犯国际条约。
