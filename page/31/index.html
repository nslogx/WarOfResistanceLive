1931年12月14日

发表于 2020-12-14 更新于 2021-05-11 分类于 局部抗战(1931-1937)

  • 1931年12月14日讯：日本政府向国联致文抗议中国政府参加抗日宣传，略谓：中国政府教育部曾令大中小学讲授日本侵华史；政府令国民党组织领导抗日会；政府令抗日会筹款五万元援助马占山，此款由扣留之日货拍卖拨充。

  • 1931年12月14日讯：上海各校学生二万余人决定进京示威请愿，要求政府立即动员全国进行抗日，蔡元培电沪各大学校长劝阻无效。是日，示威团首批代表500人乘车离沪赴京。

  • 1931年12月14日讯：济南市学生请愿团在南京举行示威游行，行抵外交部，拟向顾维钧质问，因顾未到部，遂在部长办公楼上及部内各室墙壁上大书“反对秘密外交”等标语。

  • 1931年12月14日讯：特种教育委员会委员长蔡元培在国民政府总理纪念周报告该会任务，谓国难时期学生之爱国运动决不能荒废学业，荒废学业其害“几与丧失领土相等”；为集思广益解决国难时期教育上之种种特殊问题，故设立本委员会，待将来国难会成立后，本会即可取消。

  • 1931年12月14日讯：陈铭枢由南京抵沪与孙科晤谈蒋介石下野及粤中委进京等问题，陈当晚返京复命。孙科电胡汉民及粤各中委从速来沪。

  • 1931年12月14日《申报》：哈尔滨息，哈满线牙克石站发现白俄胡匪，苏炳文派杨营往剿，击毙匪首格拉耶夫，余已溃。苏炳文派铁甲车巡梭哈满线防匪，并派参谋长王而瞻率兵一团防满札。（13日专电）

  • 1931年12月14日《申报》：哈尔滨息，哈警备队今哗变一中队，往海伦投马。安广一带胡匪，经马占山派员收编为骑步兵各一团，该匪枪马均齐，今日在安广编妥开海伦。（12日专电）

  • 1931年12月14日《申报》：北平息，山海关到日军400余名，连日在兵营附近掘挖战壕，并在屋顶堆置沙袋，似备战，民心恐慌。（13日专电）

  • 1931年12月14日《申报》：哈尔滨息，马占山招编学生团，日人浅谣蔑为已与苏俄携手。哈男女学生赴海伦投军者极多。（13日专电）

  • 1931年12月14日《申报》：哈尔滨息，马占山11午后2时返海伦，车中语人，本人早有会见张氏之意。此次会见结果，虽不能发表，但本人决不变更初衷，致负民众期望。无论何事，均以国家主义为前提，个人利害早已置度外。前次与板垣会见，亦以个人人格国家利害，如毁堕人格及不利国家，非马某所为。12日专电

  • 1931年12月14日《申报》：哈尔滨息，俄因日侵东铁路权日甚，决于最近有所表示。海参崴俄军已准备向四站出发，并向民众征军费，每户征费一元。（13日专电）

1931年12月13日

发表于 2020-12-13 更新于 2021-05-11 分类于 局部抗战(1931-1937)

  • 1931年12月13日讯：中华苏维埃共和国中央执行委员会非常会议通过《处理反革命案件和建立司法机关的暂行程序》，同日，以第六号训令颁布。

  • 1931年12月13日讯：日本政友会总裁犬养毅组织新内阁，主要成员为：外务大臣芳泽谦吉、内务大臣中桥德五郎、大藏大臣高桥是清、陆军大臣荒木贞夫、海军大臣大角岑生、司法大臣铃木喜三郎。前陆军大臣南次郎及前海军大臣安保清种任军事参议官。14日，荒木声称，今后对华仍将继续执行前任南次郎政策。

  • 1931年12月13日讯：中华林学会在南京举行年会，决议：请实业部迅予成立林垦署；请政府颁布森林法及狩猎法；请政府明文规定各省林业经费至少应占省支预算的百分之五；建议导淮委员会于淮河流域建造大规模之水源涵养林。

  • 1931年12月13日讯：上海暨南大学校长郑洪年发表谈话，认为学生爱国运动“系总理恢复民族固有精神之遗训”，无可非议。

  • 1931年12月13日讯：上海民众反日救国联合会召开全市市民大会，决议：反对锦州设立中立区；反对共管天津；反对中立国调查团赴满调查；民众自动武装起来对日宣战；否认国联对满洲问题决议案。

  • 1931年12月13日《申报》：北平息，打虎山电，洮南治安归张海鹏部下团长李树田维持。市内警宪，均归其节制。张海鹏在洮散传单诋毁万福麟父子，但日人对张，仍派军多名，分驻蒙边督办公署，及漫铁公所，监视其行动。（12日专电）

  • 1931年12月13日《申报》：天津息，日兵近在山海关，积极作军事准备，最近四天内，由津开往武装士兵50余名，军火四百余箱。由秦皇岛运往军火三百余箱，武装士兵80余名。12午又有日兵三百二十名，军火百余箱，由津搭轮赴秦皇岛。（12日专电）

  • 1931年12月13日《申报》：北平息，马占山昨自海伦电平报告，齐克路平靖，日军未积极进攻，本人正与省府委员整理政务，本人日内赴齐克路视察。（12日专电）

  • 1931年12月13日《申报》：北平息，锦州电，驻新日军用现洋二万收买匪首老提子野郎二名，及蒙匪首战北小辫二名，所属股匪，约千七百余名，编为国民自卫军。人马粮秣，日需八百元，迫由当地人民供给。新民辽宁各处日人，制脚镣甚多，用途不详。（12日专电）

  • 1931年12月13日《申报》：北平息，本庄派关东司令干部人员廿一人至哈，名为哈尔滨军事联络员，实则监视张景惠。近张复媚日，将本庄派来人员皆留居公署。每得电令，皆交日人先阅，并同议如何答复。故日军虽未进兵哈埠，哈埠早在暴日掌中矣。（12日专电）

  • 1931年12月13日《申报》：沈阳息，闻新民屯附近之日兵已拆毁该处中国电报局。所有机器皆已拆去，该局已废。资新民屯电局为收发国内外电报之站，而不受日人检查。今此局既废，则沈阳电报必须由沈阳日本邮局或日人现所管理之中国电局发出，故各电皆将受日人检查。（12日路透社电）

  • 1931年12月13日《申报》：北平息，白旗堡站长，电北宁局长称，101次车由该站开行后，突来土匪8名，将住站工人衣服行李财物等件，抢劫一空。全体工人，冒险工作，衣食全无，极不安，请设法接济，否则无法工作云。该局已设法接济。（12日专电）

1931年12月12日

发表于 2020-12-12 更新于 2021-05-11 分类于 局部抗战(1931-1937)

  • 1931年12月12日讯：红二十二军陈毅部及红二十军刘铁超部攻克南康之唐江墟。

  • 1931年12月12日讯：国民政府公布《户籍法》。

  • 1931年12月12日讯：山西省府、教育厅停止办公，《民国日报》停刊，各校学生亦均停课，官方加派军警维持治安。太原各校学生与警备司令荣鸿胪谈判，荣允私人资助学生派代表入京请愿。

  • 1931年12月12日《申报》：天津息，驱日前线敢死队长张显如，由京率队员40余人，10日晚10时抵津，11日分组宣传，日内赴锦州。（11日专电）

  • 1931年12月12日讯：蒋介石在国民政府接见济南学生请愿团2000余人，声称“救国御侮，须内部团结，须全国青年一致拥护政府，始可收最后胜利”。同日，南京各校学生代表26人赴国民政府请愿，要求惩办外长顾维钧、宪兵司令谷正伦及南京警察厅长吴思豫。

  • 1931年12月12日讯：南京卫戍司令部布告声称，进京请愿团体中有共产党乘机活动，要求各团体“自加检束”，免被“利用”。

  • 1931年12月12日《申报》：南京息，宁·镇·澄·淞四路要塞司令部所辖之工兵队，第二期教育终了，刻举行第二次检阅，并邀各关系机关派员参加。（11日专电）

  • 1931年12月12日《申报》：巴黎讯，我国施总代表今日在会商辽案时，对于国际条约与公约不能适用于东三省之言论，严辞驳辩，拒绝同意。并声明锦州并无反常局势。（11日国民社电）

  • 1931年12月12日讯：张学良在北平发表宣言，略谓日军事当局诡称东北军对日军发生威胁，纯属造谣，欺蒙世界，并声明若锦州附近有任何严重事态发展，其责任将由日本完全负责。

  • 1931年12月11日讯：中华苏维埃共和国临时中央政府发表《为国民党政府出卖中华民族利益告全国民众书》，提出“国民党政府已经承认在锦州设立中立区，提议组织在天津的国际共管，承认一切以前的卖国密约”，这是“将满洲几万里的土地，数千万的民众断送给日本帝国主义践踏”，号召“民众 …

  • 1931年12月11日讯：中华苏维埃共和国临时中央政府机关报《红色中华》在江西瑞金创刊。周以栗主编，瞿秋白、王观澜、李一氓等参与领导和编辑，为中共在根据地创办的第一张刊期较长的中央级铅印报纸。

  • 1931年12月11日讯：特种教育委员会第一次会议决议，关于各地学生请愿事宜由该委员会负责办理，其他教育方面之重要设施，由该会决定原则，交教育部处理。

  • 1931年12月11日讯：太原23所学校学生2000余人至山西省府请愿，要求拨车赴京请愿。省府正开会，大门紧闭，不理学生。学生破门而入，直冲会议室，各省委员弃鞋遗帽逃散，学生将会议室内陈设捣毁，随后沿街示威游行，又将省教育厅及山西民国日报社捣毁。

  • 1931年12月11日《申报》：天津息，日舰13号小汽船，10日由塘沽运枪炮弹下午1时半抵津，卸入日兵营。（10日专电）

  • 1931年12月11日《申报》：北平息，锦州电，日军再南满沿线，招收吾国流氓及胡匪，编成队伍，假救国军名义，至吾方扰乱，由日方暗中接济军火，持红黄白各色旗帜，首领华日各一。华名张昌波，日名黄慕，预定在法库营口抚顺等处举事。（10日专电）

  • 1931年12月11日讯：国民政府令京沪卫戍司令陈铭枢彻查上海学潮及上海当局对学潮处置案。后陈呈报查处情形，略谓学生大多数以爱国为动机，但难保有少数危险分子，但学潮发生的原因，应归咎于市公安局及市党部处置乖方。

  • 1931年12月11日讯：国民政府文官处通电，略谓国家多难，内忧外患并至，国民政府愿与国内明达之士共摅荩筹，以济艰危，依国民党四全大会决议，在本月召集国难会议。

  • 1931年12月11日讯：北平八校赴京请愿团1500余人赴国民政府请愿，蒋介石对请愿各点逐一答复，允尽量接受，并表示日不撤兵，决不交涉。

  • 1931年12月11日《申报》：天津息，日兵在 新民巨流河间连日捕华人甚多，凡衣冠整齐、或携有官衔名片者，均诬为间谍，被杀32人，焚尸灭迹。（10日专电）

  • 1931年12月11日《申报》：巴黎讯，国联理事会今日下午四时45分召集最后公开大会，我国施总代表接受决议案。日总代表芳泽亦接受决议案，但仍声明决议案内第二节不能阻止日军之剿匪行动。最后此决议案遂由全体理事一致通过。（10日国民电）

  • 1931年12月11日讯：胡汉民在香港发表谈话，表示支持汪精卫关于组织民众团体与政府共商外交主张，认此种机关宜永久存留。胡并补充三点：一、该机关之代表必须真能代表民意，应以学、工、农、商为主；二、该机关应设沪，不应设宁；三、代表一旦不能代表民意时，应由其团体立即召回。

  • 1931年12月11日《申报》：里加讯，共产党职业团体，顷在莫斯科举行第八届大会，听取中国及日本代表之报告。该两代表宣称，日军占据满洲，为日本帝国主义之一种示威，中日两国民众对此应加反抗云云。大会乃决议全球劳动者发出宣言，请其组织示威运动，以反对日本帝国主义干涉满洲。（9日哈瓦斯社电）

  • 1931年12月10日《申报》：北平息，由沈来人谈南满客车，每开行时，均有日人一在站台上，用号筒高呼亡国奴上车，亡国奴上车。直至车开行后始止，令人闻之极愤慨。（9日专电）

  • 1931年12月10日讯：新编第十师奉令改番号为第八十五师，师长谢彬。
