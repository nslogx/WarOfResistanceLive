  • 1932年2月3日讯：上海市商会决定银、钱、米业是日开市，并组织粮食平价维持会。

  • 1932年2月3日讯：国民政府主席林森自洛阳通电全国各省、市政府称：“现值国难方殷，财政奇窘……自即日起，所有在国府及所属各机关服务人员，一律停止薪俸，每月仅酌发生活费若干，以维持个人生活。”

  • 1932年2月3日讯：上海地方维持会募集救国捐支援第十九路军抗日。自是日至5月31日，共募得大洋27万余元。

  • 1932年2月3日《申报》：上海本埠息，前晚本埠济生会救护队出发闸北战区，救护国民革命军陆军60师29旅1团1连一等79号列兵广东人郇有德伤兵一名，年约30左右。数弹射入腹部，当时欲车送医院疗治，无奈伤势过重，中途气绝身死。救护队职员凌有光，将尸体转送法租界同仁辅元分堂，请为殓葬。惟该堂收理……

  • 1932年2月3日《申报》：上海本埠息，市民联合会义勇军三百余名，昨由总指挥王屏南率领，于下午2时开赴闸北太阳庙平江公所，听候19路军收编，加入前线，分配工作。今日当续有2百名开往，该军事先曾向蔡廷楷接洽妥帖，予以国民救国军名称，至给养等由市民会自行给予。

  • 1932年2月3日《申报》：大陆报云，1日清晨，日炮舰突向浦东德士古煤油栈方面，开机关枪射击，一农民受伤，而德士古公司棚内所储煤油若干，悉遭焚去。据事后说明，日舰中人，因闻浦东某村有爆竹声，恐遭袭击，故开枪。现德士古公司已请美领事馆署，向日领事正式抗议。

  • #一二八淞沪抗战#1932年2月3日讯：因吴淞受到猛烈攻击，我十九路军以60师120旅接替78师156旅闸北防务，以156旅第五团增防吴淞。

  • 1932年2月3日《申报》：上海本埠息，闸北战事，经英美领事等调停，双方以三日为期，暂行停战，据司令部与市政府宣称，须至今日（3日）下午四五时许，始满三日之期，乃昨日日军，不守停战信约，于下午1时20分，复以大炮机枪等，向我进攻。市政府遂于昨日下午2时许，向英美日三领事，提出正式抗议。

  • 1932年2月3日《申报》：哈尔滨息，26旅王团，协张广喜赵维文支队，26旅孙营，31日晚8时，驰抵双城，与宮占海旅骑兵合力猛攻双城。日军据城顽抗，激战一小时，王团自南门攻入，日军不支，分两支溃走，一遁往东铁英家沟站，一遁至双城车站，据货仓抗拒，为我军奋勇攻破毙敌5百余名，俘百余，获步枪五…

  • 1932年2月3日讯：我自卫军以邢占清第26旅的两个团防守三棵树，以王瑞华第28旅一部防守高岗，以双城撤退的赵毅第22旅防守上号，以冯占海部迂回敌后。

  • 1932年2月3日《申报》：雅典讯，希腊社会党今日在譬莱斯开大会，通过一议案，反对日军轰击闸北，并请国联干涉中日争端。（2日路透电）

  • #一二八淞沪抗战#1932年2月3日中午，从日本海军“加贺”号和“风翔”号2艘航空母舰上起飞的12架舰载机空袭吴淞要塞，以重磅炸弹轰炸要塞炮台。归十九路军一五六旅指挥的第八十八师高射炮连，即以高射炮向敌机猛烈射击。这是本次事变中，日军飞机首次受到中国军队地面炮火的回击。

  • 1932年2月3日讯：茅盾、鲁迅、叶圣陶、郁达夫、丁玲、陈望道、冯雪峰、周扬、田汉、夏衍等43人联合发表《上海文化界告世界书》，愤怒斥责日军侵略，反对国民党的不抵抗主义。

  • 1932年2月3日《申报》：南京息，兹确悉昨夜日舰之炮轰，纯出于误会。据日官场宣称，昨夜有日水兵数名，登岸买零用物，华巡队于黑暗中向询口号未答，疑为匪徒，向天开枪数响。日水兵即逃回舰中，报告长官，谓华兵已进攻，故军舰乃发数炮，其中有数空炮，以视炮台有无回答。嗣见炮台无动静，乃停止轰…

  • #一二八淞沪抗战#1932年2月3日讯：敌海军四艘炮舰向我吴淞口炮台发炮，遭我军猛烈还击，敌一艘受重创，我炮台毁炮三门，但配属防御的156旅4团未有伤亡。（图片选自日方出版《昭和七年上海事变记念画册》）

  • 1932年2月3日讯：陈铭枢代表第十九路军发表谈话表示：“不论遇到如何侵犯我国土之强敌，决不畏惧，虽全数牺牲，亦决不离开京沪线上。”

  • #抗战影像#1932年2月3日，“一·二八淞沪抗战”中，日本海军第26驱逐队多艘驱逐舰于当天正在集火炮轰吴淞炮台要塞。

  • 1932年2月3日《申报》：南京息，此间军事当局对于一日晚日本炮舰轰击南京事，宣称并未训令狮子山炮台司令不予还击。报纸所传，实属非确。日舰所放之炮非实弹者，故不予还击，以免中其挑衅之计。且他国亦有军舰泊于江面，炮台司令自当出之实慎，以免惊扰友邦炮舰。（2日国民社电）

  • 1932年2月3日讯：上海市府就公共租界工部局容许日军以租界为攻击中国军队之根据地事，向工部局提出抗议。

  • 1932年2月3日《申报》：南京息，二日晨起至午后三时止，下关江面日舰，未有举动。我军仍积极布防，各军事机关戒备亦严，江边及各商埠重要街口，均安置电网沙袋，兴中门半开半掩。商民搬移什物携带妇孺入城避难者，江面轮渡，照常往来，京沪津浦车晨仍通行，乘客异常拥挤。（2日专电）

  • 1932年2月3日讯：上海市政府就日军残酷杀害华人，致函日总领事村井仓松提出严正抗议，要求释放被捕中国居民，严惩凶犯，以后对此项情事负责取缔等。

  • #一二八淞沪抗战#1932年2月3日讯：得到加强的日军陆战队恢复进攻，向我青云路、天通庵路、宝兴路、宝山路一带阵地猛烈轰击，我156旅第5团迫击炮连首当其中，被三炮击中，第3营8连、9连阵地激战后为敌所占，9连连长张福甫重伤，不久即殉国。但此后日军未再有进展。

  • 1932年2月3日讯：英、美、法、意、德五国公使照会中日两国政府，建议两国在沪停战撤兵，设立中立区，由中立国军警驻防。

1932年02月02日

发表于 2021-02-02 更新于 2021-07-02 分类于 局部抗战(1931-1937)

  • 1932年2月2日讯：沪“日清”、“大阪”等日轮华员、华工为反抗暴日侵沪，全体举行罢工。

  • 1932年2月2日讯：北平女界抗日会、平等抗日会、工界同盟、弱小民族同盟、青年抗日会等五团体，联电慰劳第十九路军。

  • 1932年2月2日讯：阎锡山电慰第十九路军抗日将士。

  • 1932年2月2日讯：中国国民救济会通电全国军界称：“本会愤倭焰之方张，痛国亡之无日，爰本救国之义，敢请我全国海陆空军界同胞，抱敌忾同仇之志，卫国救民之愿，一致奋起，自动开沪援应。”

  • 1932年2月2日讯：上海各医药学院抗日战地医事联合会成立，决派180人赴前线从事救护医治工作。全部医药费用由何香凝主持之国难战士慰劳救护会供给。

  • #一二八淞沪抗战#1932年2月2日讯：日本内阁决定正式派遣陆军。先行派遣上海混成旅团（后称混成第24旅团），旅团长下元熊弥少将，此后增派第九师团，师团长植田谦吉中将，并以独立战车第二中队等部加强了上海派遣混成旅团。

  • 1932年2月2日讯：下午1时后，沪日军战斗机数架飞闸北、真如、南市、浦东上空盘旋侦察，并在闸北、真如投弹多枚。3时许，日军在天通庵车站一带开炮轰击闸北，遭到第七十八师炮兵还击，双方炮战至夜12时始息。

  • #一二八淞沪抗战#1932年2月2日讯：日本海军中央部将长江一带第一遣外舰队之外的舰船，以“出云号”为旗舰（“出云号”2月6日抵达上海），由海军中将野村吉三郎为司令官，组成第三舰队，统一指挥投入战斗。

  • 1932年2月2日讯：下午2时50分，驻沪日总领事村井仓松电话通知上海市政府，谓日本政府对于1月31日在英总领事官舍会议所建议之避免两军冲突办法，不能同意。

  • #抗战影像#1932年2月，“一·二八”淞沪抗战期间，在上海某地作战的日军部队。左侧为一门大正11年式平射步兵炮，后侧为安装37毫米长身管坦克炮的法制NC-27型轻型坦克。

  • 1932年2月2日《申报》：南京息，陈济棠电京，请缨讨日，已令粤方十万健儿，加紧准备完毕，枕戈待命。空军将领张惠长亦电京，待命北上杀敌。（1日专电）

  • 1932年2月2日讯：第十九路军将领蒋光鼐、蔡廷锴、戴戟等通电全国，表示“十九路军将以纯洁之心，纯洁之血，贡于党 国，贡于全民”，“切望散处各方之中央委员政治领袖，发挥其拯救危亡抱负，致力应付存亡一发之危局”。

  • 1932年2月2日《申报》：南京息，中国抗日救国军铁血团一日上午十时赴沪，参加杀敌，沿途上海市民燃放爆竹，欢送至热烈。（1日专电）

  • 1932年2月2日讯：美国就上海事件提交中日政府之照会到达南京，内提出四条停战建议：一、中日两方须即停止敌对行动；二、双方军队退至原防；三、双方区域由中立国军队填驻；四、双方根据《国联盟约》及《凯洛格公约》开始交涉。
