1932年05月24日

发表于 2021-05-24 更新于 2021-08-07 分类于 局部抗战(1931-1937)

  • 1932年5月24日讯：河北省政府决议开采密云等四县金矿，筹组官商合办股份有限公司。

  • 1932年5月24日讯：川军第二十一军第三师师长王陵基续调12个团到宜昌“剿匪”。鄂绥署电王陵基，鄂西“剿匪”事宜由王全权指挥。是日，王陵基在宜昌下总攻击令。

  • 1932年5月24日讯：闽省政府代理主席方声涛由厦门赴同安，即在同设行营，指挥“剿匪”。闽党政军联席会议，决议推刘和鼎代理省防委员会主席。

  • 1932年5月24日讯：国民政府特派蒋介石为豫、鄂、皖三省“剿匪”总司令，李济深为副司令；特派章嘉呼图克图为蒙旗宣化使。6月6日，国民党中政会决议追认。

  • 1932年5月24日讯：平、津、济南、杭州、无锡、开封、洛阳等地邮工援助上海邮工罢工相继罢工。

  • 1932年5月24日讯：交通部招待新闻界，次长俞飞鹏声称：“工会对此次沪邮罢工应负责任。中央早已取消工会组织……不知何来邮务总工会之名目”；邮工“干涉国家行政制度，不能允许，所谓巩固邮基方案，根本不能提出，在此国难期中罢工，尤为绝大错误”。

  • 1932年5月24日讯：沪市府布告，劝邮工先行复工，听候中央解决。

  • 1932年5月24日讯：下午3时，国民党中常会讨论沪邮工潮事，决定交民运会依据《工会法》分别处理。

  • 1932年5月24日讯：行政院决议：邮政总局局长钱春祺免职，听候查办，任命黄乃枢为邮政总局局长。

  • 1932年5月24日讯：杨行、狮子林炮台日军于正午12时撤尽，由江苏保安队接收。

  • 1932年5月24日《申报》：哈尔滨息，今日哈埠闻枪炮之声，甚为清晰。因昨夜开始在呼海路附件之战事，今仍在进行中。反满军力攻“满洲国”之军，双方迄今尚未分胜负，距哈埠西约60里亦有战事，战区难民线纷拥入哈。距哈埠西15里之中东铁路，今日为反满军拆毁一段。中东铁路东段仍有不清消息传来，反满军在1386公里处轰击货车，重伤铁路华雇员一人，又匪众曾袭击铁路货栈数次。据日人所办俄文报纸载称，黑龙江当局出示，生擒马占山将军者赏十万元，得其尸者赏半数。（23日路透社电）

  • #抗战影像#“一二·八”事变中死去的两名中国军人，被安置在同一口棺材内。

  • 1932年5月24日讯：敌第14师团28旅团从呼兰出发，向马占山部队海伦攻击前进。第27旅团则从哈尔滨出发，在肇东一带扫荡作战。

  • 1932年5月24日《申报》：汉城讯，此间今日接讯，非正式军二千五百名协同匪队进攻珲春，情势危急。该处（伪）满洲国军队闻风退走，故日韩侨均已逃避朝鲜境。朝鲜总司令林氏现游于（伪）满洲，闻此警耗，赶回汉城，今夜可到，闻边界卫队已有奉命开往乱区者。（23日电路透社电）

  • 1932年5月24日《申报》：沈阳息，本庄关东军司令官，22日晚9时20分，由沈阳出发，乘火车往哈尔滨，指挥作战。（23日电通社电）

  • 1932年5月24日讯：上海各民众团体联合会通电全国，对否决弹劾汪精卫案提出：一、应由各团体环请立法院切实声明关于上海中日停战协定全部无效；二、应由各团体环请监察院继续提出弹劾，责成汪精卫引咎自劾，否则应处以法律相当惩戒。

  • 1932年5月24日讯：国民党中常会否决于右任弹劾汪精卫案。于右任、汪精卫均呈中执会辞职，中执会决议慰留。

1932年05月23日

发表于 2021-05-23 更新于 2021-08-07 分类于 局部抗战(1931-1937)

  • 1932年5月23日讯：马占山部才鸿猷旅在呼兰与日军血战，将日军压逼到松花江边，隔江猛烈射击哈尔滨道外日军指挥所。日关东军司令本庄繁飞哈尔滨督师。

  • 1932年5月23日讯：上海各团体救国联合会、东北义勇军后援会联电各省军政当局，请资助东北义勇军。

  • 1932年5月23日讯：西南外交协会通电反对上海停战协定，并望政府下大决心抗日，否则不对外而对内，甘为国人公敌，恐为全国共弃。

  • 1932年5月23日讯：外交部照会法使韦礼德，抗议上海法租界捕房将拘捕之韩人安昌浩引渡日本当局。

  • 1932年5月23日讯：汪精卫电令吴铁城劝导沪邮务员工即日复工，必要时“执行严厉之处置”。

  • 1932年5月23日讯：交通部部长陈铭枢致电国民党中央政治会议，请求处理邮工罢工办法，必要时“执行严厉处置”。

  • 1932年5月23日讯：上午，日军第九师团自真如撤退，下午2时半日海军第一、三两大队自闸北撤退。由北平到沪之保安队入驻接收。

  • 1932年5月23日讯：中监会开会讨论监察院提请弹劾汪精卫案，认为“理由不充分，本案不成立”。

  • 1932年5月23日讯：国民党中央政治会议讨论弹劾汪精卫案，认为“行政院依中政会决议案办理，手续并无不合，所请惩戒事应毋庸议”。蒋介石表示：“本案手续上办理既无错误，当然不成问题。”

  • 1932年5月23日《申报》：北平息，三路义勇军二万余名，连日在绥中与城北票一带，与日军激战，毙敌四百余名，敌准备退却。（22日专电）

  • #抗战影像#“一·二八”事变中，侵沪日本陆军炮兵阵地上，一门日制大正四年式150毫米重榴弹炮，正在瞄准中国军队阵地准备发射炮弹。

  • 1932年5月23日《申报》：沈阳息，国联调查团各委员自今日早晨起，行动自由，以慰连日之疲劳。各随员亦于今日参观当地之“满洲国建国纪念联合运动会”，但只顾维钧一人居于旅馆。（22日电通社电）

  • 1932年5月23日讯：受中共满洲省委指示，张甲洲与于九公、夏尚志等一起，在巴彦七马架（今镇东乡）小学校组织一支200余人的抗日武装队伍，任总指挥，开展武装斗争，但武装队伍受到伪县长程绍廉镇压，张甲洲率百余人突围，此后，在此基础上，张甲洲逐步收编抗日队伍达到700余人

  • 1932年5月23日《申报》：北平息，16日晚，张海鹏部百余人，将北镇城北范家屯村长，拘捕殴击，焚毁范某住宅。二十五路义勇军闻讯驰至，包围该村痛击，同时民团内应，将逆完全解决。张因部下纷纷反正，通令所属，准予任意抢掠，俾勾搅军心。（22日专电）

  • 1932年5月23日讯：日军第10师团占领依兰后，分兵而出，先后侵入和占领松花江、同江流域各县城，同时占领方正和通河，截断了前方自卫军的退路。

  • 1932年5月23日讯：上海战区善后委员会成立，吴铁城为委员长。

1932年05月22日

发表于 2021-05-22 更新于 2021-08-07 分类于 局部抗战(1931-1937)

  • 1932年5月22日讯：徐源泉返汉，就任鄂省清乡督办。

  • 1932年5月22日讯：上海《时事新报》工潮仍未解决，被开除工人推代表与该报经理熊少豪谈判，无结果。

  • 1932年5月22日讯：上海各团体救国联合会电监察院长于右任，对其弹劾汪精卫违法签订上海停战协定案表示支持。

  • 1932年5月22日讯：吴铁城在沪市府接见邮务职工代表张克昌等四人，劝邮工即日复工，然后再商办法。

  • 1932年5月22日讯：胡适、丁文江、蒋廷黻等创办《独立评论》周刊，胡适为总编辑。是日创刊号在北平出版。

  • 1932年5月22日讯：上海邮务工人大罢工。上海邮务工会、上海邮务职工会以该会等提出巩固邮基方案未被交通部接受，令沪市3500余邮工今起大罢工。《罢工宣言》略称：“本会等所拟巩固邮基方案，为救邮之唯一良箴，本会一再电催，交部乃迁延至今，竟未容纳，群情愤激，无由遏抑，认为非实行最后行动，不足以促当局之猛省。”23日，沪邮工罢工风潮扩大，沪设临时邮局，邮政总局局长钱春祺因邮务工潮被看管。

  • 1932年5月22日《申报》：哈尔滨息，反满军进攻松浦与哈尔滨，未能得手，现向呼兰方面退却。日军追逐其后，安达站与甜草岗之反满军，现亦在退却中，估计日人在哈尔滨附件战争中死伤逾三百。（21日路透社电）

  • #抗战影像#伪满洲国发行的明信片，主题是“哈尔滨的夜色”。

  • 1932年5月22日讯：自卫军左路军发生内讧，第二旅旅长刘万奎因物资分配和攻坚任务分配等事由对总指挥兼第一旅旅长马载舟怀恨在心，利用其在马桥河指挥部开会之际，将马载舟活活勒死，左路军随即分崩离析。

  • 1932年5月22日《申报》：南京息，回国参加十九路军与日作战之旅日华侨徐香进，曾于二月二十八日，在南翔被日机炸毙。翁泓兴、叶公正二人在战场染受重病，到京医治无效，先后身殁。刻侨委会已咨询军政部抚恤，该殉难之同志，均浙籍。（21日专电）

  • 1932年5月22日《申报》：北平息，沈电，日人对东北计划，传系采用四种步骤：1）分政，即分离各政权，使投降之官吏，亦不得悉其底蕴；2）裁官，即将投降之官吏，逐渐裁汰，而添用日本官吏，现正在进行此二步骤中；3）移民，先将朝鲜及日本人民逐渐移来，藉政治势力而收买侵占，以操土地所有权；4）逐民，移民既有根基，即将所有我国农民，逐于荒野未开之区。（20日中央社电）

  • 1932年5月21日讯：长江水位连日陡涨，是日达35尺。

  • 1932年5月21日讯：陕、甘霪雨、黑霜成灾，灾民达数十万，杨虎城电国民政府请急赈。

  • 1932年5月21日讯：国有七铁路工会联席会发表告全国铁路工友书，并电国民政府，要求以武力收复东北失地。

  • 1932年5月21日讯：上海市长吴铁城约邮务工会、职工会、邮务长、总局长等在市府谈话，谓储金汇业局归并及取消邮航津贴问题，涉及国家行政制度，不能随意变更，更不能以罢工要挟。

  • 1932年5月21日讯：何应钦令湘、粤、赣三省军队“会剿”红军彭德怀部。

  • 1932年5月21日讯：蒋介石令第十九路军开赴福建，参加“剿匪”战争。

  • 1932年5月21日讯：行政院决议：拨国币两万元汇法，遣送失业华工回国。又拨一万元汇驻荷兰领事馆接济失业华工；公布修正《沪撤兵区域接管委员会组织条例》。

  • 1932年5月21日《申报》：哈尔滨息，松浦阵线，战事未已。昨闻反满军渐后退，此间犹偶闻炮声，横道河子东面桥梁四座，昨日被毁。（20日路透社电）

  • #抗战影像#日本发行的宣扬日军士兵与伪满洲国百姓友善相处的明信片。

  • 1932年5月21日《申报》：哈尔滨息，李顿调查团因中东路西段反满军密布，恐有危险，兹已将原定明晨赴齐齐哈尔之行作罢。惟该团仍可由该区域觅得情报，因团中有专家10人将由哈尔滨乘飞机前往齐齐哈尔调查该处情形也。调查团已定星期六日由此遣返沈阳。（20日路透社电）

  • 1932年5月21日《申报》：哈尔滨息，此间顷得报告，谓齐齐哈尔至满沟之区域全部，为马占山占领，但马之主力军仍在克山及讷河一带。传有华军数大队，刻向中东路西段推进。闻李海青在满沟之司令部，被日机炸毁，参谋长李某及其他八人，均被压毙。（20日路透社电）

  • 1932年5月21日讯：真如日军撤退，由沪保卫团进驻。接管委员会预备会议决定本月23日上午11时接收真如。

  • 1932年5月21日讯：监察院长于右任弹劾行政院长汪精卫违法批准上海停战协定，不交立法院审查，呈中监会请予惩戒，内称：国府组织法规定，立法院有议决宣战媾和及其他重要国际事项职权，沪停战协定未闻送立法院议决，遽行签字，“设不严予惩处，则以后国家主权、疆土有此成案可援，皆将断送于协定二字之下”。

  • 1932年5月20日《申报》：南京息，据可靠方面消息，马占山之抗日军事行动，极称顺利，日军曾数度被窘。马现得华侨赠送飞机数架，参加作战，龙江之兵工厂已迁移黑河。闻马最近购置军械颇多，尚待证实。然马于未反正时，确由日方取得军械，马之军队约四万人，步炮骑兵俱全，尚有飞机一队，野 炮二十尊。文马之军队军容甚整，军械充足，且得民团及义勇军赞助，人数渐增。（19日路透社电）

  • 1932年5月20日讯：自卫军中路军在后援尽失的情况下决定仍前往哈尔滨，进抵阿城，料甸子地区，并于总司令部和先期到达的冯占海部完成联络，遂在此集结等待左路军的到来。

  • 1932年5月20日《申报》：接管委员会，昨晨派员赴江湾，接收江湾淞沪铁路以西之区域，该处日军共二百余人，于昨晨11时一刻，完全撤退，双方于11时零5分交替。我方5区5所长戴鸿恩，于昨晨率警，会同平保安队前往，午时已布置就署。消防保安两组，亦即恢复，并实行清查户口，教育局亦派员前往接收各学校。此外我方又派员于昨晨接管彭浦，并于昨晨10时，日方在北站交还俘虏。

  • 1932年5月20日讯：沪撤兵区域接管委员会召集有关各方举行联席会议，会商接管闸北铁路以北区域办法。

  • 1932年5月20日讯：《再生》月刊在北平创刊。张君劢、张东荪、罗隆基等创办。宣传“国家社会主义”，中国国家社会党成立后为其机关刊。

  • 1932年5月20日讯：河南鹿邑、柘城两县春荒，粮食告竭，死亡枕藉，惨不忍睹，鹿邑县设人市五处，幼女不值10元，幼童仅易1000文，孩提婴儿抛弃遍地。
