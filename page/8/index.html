1932年07月13日

发表于 2021-07-13 更新于 2021-08-17 分类于 局部抗战(1931-1937)

  • 1932年7月13日讯：东北军第九旅旅长何柱国就任临永警备司令，辖临榆、昌黎、抚宁、卢龙、迁安五县。

  • 1932年7月13日讯：豫、鄂、皖三省党政委员会成立，蒋介石兼任委员长，并派定委员九人：张难先、仇鳌、彭介石、萧萱、洪陆东、贺衷寒、张群、杨永泰、耿伯钊。张难先为监察处主任；洪陆东为党务指导处主任；张群为政务指导处主任。

  • 1932年7月13日讯：江苏高等法院向牛兰夫妇最后警告，准其于南京中央医院、鼓楼医院择一出外诊治，倘再拒绝，将强制执行。

  • 1932年7月13日《申报》：北平息，沈讯，沈南北边门外挖战壕，昼夜巡守，防义勇军袭击。举行私产收没调查，城内调查注册被收没者三千余户。凡来平者，均被收没。沈伪市署总务处长邵伸系民党，因日人利用毕，特拘禁之。哈公安局长高齐栋，招宴日岛本中佐致辞。日认为有侮辱日军语，当场拘捕。哈中小学7日一律罢课，推李某代表，向叛逆交涉，叛徒在东京设代表公署。（12日专电）

  • 1932年7月13日《申报》：北平息，马占山所部，在林甸与日骑兵联队相持，本人在庆城附近指挥。（12日专电）

  • #抗战影像#伪满洲国“皇宫”内的勤民殿，“皇帝”溥仪用来举行仪式和大典的正殿。

  • 1932年7月13日《申报》：哈尔滨息，闻日军现已占据横道河子，查该处前为“满洲国”军所据守，后被中国义勇军逐出。（11日路透电）

  • 1932年7月13日《申报》：北平息，驻临江徐达三部8日夜由下马蹬分股渡江，以平壤为进攻目的地，长白李奎五正准备出动中。（12日专电）

  • 1932年7月13日讯：宋庆龄、杨杏佛在沪发表声明，谓“前因牛兰夫妇绝食十日，本人等出于人道观念，并基于与关系当局事前之谅解，故愿以个人资格保释，俾到沪就医，经努力两日，未达目的，同时司法部长罗文幹因此呈辞，现本人等不愿再出为牛兰等作保，希望罗氏即可打消辞意”。18日，罗文幹、郑天锡打消辞意，到部视事。

1932年07月12日

发表于 2021-07-12 更新于 2021-08-17 分类于 局部抗战(1931-1937)

  • 1932年7月12日讯：行政院议决将统税署与印花烟酒税局合并为税务署，任谢祺为税务署署长。16日，该署在上海成立。

  • 1932年7月12日讯：朱德部红军集结信丰、南康、大余一带，并分出一部绕道南雄，袭击广东仁化，直逼韶关，图断绝南雄粤军与广州的联络。

  • 1932年7月12日讯：徐庭瑶第一纵队攻占皖西霍丘城。

  • 1932年7月12日讯：蒋介石在汉口三省“剿匪”总部召见湖北各县县长41人训话，强调县长职责最为重要，应抱城存与存决心，有好县长，可抵过一万兵，应在政治上力谋改进。

  • 1932年7月12日讯：驻日公使蒋作宾访日外相内田康哉，转达国民政府对于日本承认伪满洲国问题的意见。蒋去东京途经神户时对记者称：如日本承认伪组织，不惟证明日本违背《九国公约》信义，且将使其在世界之声望大受损伤。

  • 1932年7月12日讯：国联调查团与日外相内田康哉会谈，内田态度强硬，声言“满洲国家业已成立，无与中国政府直接交涉满洲问题的必要”。

  • 1932年7月12日讯：中华苏维埃共和国临时中央政府为争取释放牛兰夫妇发表宣言，谓“本政府已预备释放各苏区所羁留之帝国主义侦探——外国传教士，为南京政府释放牛兰夫妇之交换条件”，要求立即释放牛兰夫妇。

  • 1932年7月12日讯：牛兰夫妇经宋庆龄、蔡元培具保移沪就医问题，蔡得悉罗文幹、郑天锡因此案辞职，“恐因此引起政治纠纷”，特向高等法院退保并撤回保证书。宋庆龄亦只得连带退保。晚宋怫然去沪。

  • 1932年7月12日《申报》：北平息，沈讯，伪奉山路沿线日军约5千人，南满沿线及辽河两岸，每站仅日军数人。汉奸王殿忠受日人委为司令，所部万余人，配置各县。副司令李某，不忍献媚日人，率该部大半反正，盘踞各要地，待机发动。日人对来往旅客青年妇女，裸体检搜，羞辱自杀者甚众。（11日专电）

  • #抗战影像#伪满洲国“皇帝”溥仪“裁可”的部分奏折。

  • 1932年7月12日《申报》：北平息，姜荣耀王可大部义勇军二千余，被张海鹏部勾引日军田野击溃，死伤270余，余逃扶余。现集中扶余长岭二县，共万一千余名，义勇军眷属70余人，露宿野食待援。（11日专电）

  • 1932年7月12日《申报》：哈尔滨息，昨日自卫军二千人袭击哈尔滨西45里中东铁路之安达站，激战后，占据该地，齐齐哈尔日军闻报，即派兵前往，希图夺回失地。（11日路透社电）

  • 1932年7月12日讯：宋庆龄在京访汪精卫、罗文幹磋商营救牛兰夫妇。宋要求于人道上而不违背中国法律想一折衷办法。罗表示为保法律威信，当依法办理。同日，司法行政部长罗文幹、次长郑天锡因反对外籍律师为牛兰夫妇出庭辩护，并以牛兰保释“违背法治精神”，呈行政院辞职。

1932年07月11日

发表于 2021-07-11 更新于 2021-08-17 分类于 局部抗战(1931-1937)

  • 1932年7月11日讯：国民党中央政治会议通过财政部整理产区盐税暂行税率案，宋子文为此发表谈话称，产区盐税暂行税率案，其目的在于平均税率，取缔走私，增进税收。

  • 1932年7月11日讯：豫、鄂、皖三省“剿匪”总部决设党政委员会，是日公布该委员会组织条例。

  • 1932年7月11日《申报》：北平息，沈伪教厅迫各校实行日人教育计划，令各校学生组织联盟青年团，附属日侵略东北集团之协和会，专宣称承认伪国，欺骗民众。（10日专电）

  • #抗战影像#伪满洲国时期，在新京修建的帝政纪念塔，光复后被拆除。

  • 1932年7月11日《申报》：北平息，朝阳居民不堪日军及于芷山部骚扰，扶老携幼，逃避山城子镇，自卫军唐聚五部大刀会已将辉南县克复。（10日专电）

  • 1932年7月11日《申报》：北平息，日关东军拨飞机20架，每日飞机20架，每日飞各地侦义勇军行动。4日于芷山部二千余，携日炮兵三百，日机6架，猛攻朝阳镇义勇军，投燃烧弹，全镇大火。（10日专电）

  • 1932年7月11日讯：宋庆龄由沪到京探视牛兰夫妇，劝其进食。牛兰对送医院表示赞同。同日，上海中外各界人士在宋庆龄领导下组织“营救牛兰夫妇委员会”，并发表英文宣言称：“为人道正义及不可侵犯之政治自由权，应准牛兰夫妇之请求，将案移沪，或将其全部释放，此种请求，应立时应允。”

1932年07月10日

发表于 2021-07-10 更新于 2021-08-17 分类于 局部抗战(1931-1937)

  • 1932年7月10日讯：豫北六河沟煤矿工人罢工，丰乐镇驻军第十五旅第六 四三团派兵前往镇压，逮捕41人。

  • 1932年7月10日讯：谭启秀奉蔡廷锴命抵广州与陈济棠商收编琼州陆战队事，“中山”、“海瑞”、“福安”三舰及陆战队交蔡廷锴带闽“剿匪”，琼州由陈济棠派陈汉光旅接防。逃港各舰交回陈之第一集团军，海军欠饷由粤发给。

  • 1932年7月10日讯：孔荷宠红十六军在湖北通山与敌军谢彬部激战，歼敌两团，缴获甚多，并占通山县城。

  • 1932年7月10日讯：红军占领福建龙潭。

  • 1932年7月10日讯：杨耀钧部败退下江后，冯占海部更显孤立，遂乘青纱帐起，经五常、榆树、农安、长岭、瞻榆等县，败退热河地区，脱离了吉林抗日自卫军系统，后编为东北抗日义勇军第六军团。

  • 1932年7月10日《申报》：哈尔滨息，昨晚警察拘捕之滨江副税务司沃伦堡与其助理罗查夫二人，现已释放。但警察迄未宣布搜查此二人住宅并拘捕其人之理由，查此二人均系白俄。（8日路透电）

  • #抗战影像#伪满洲国时期，新京火车站站前广场上，“国都”建设纪念庆祝塔，后已被拆除。

  • 1932年7月10日《申报》：哈尔滨息，当道决计严治共产 党，除昨捕俄人17名外，今日又拘捕俄人15名，内有远东银行火油公司及其他苏俄机关之职员，警察称已查获许多煽乱文件。（8日路透电）

  • 1932年7月10日《申报》：北平息，马占山一日再庆城，3日视察拜泉龙门镇，行踪无定。马近派人到平沪各地，呼吁接济饷项，决抵抗到底。齐克日军前线部队在兴城镇，多门尚在卜奎。（9日专电）

  • 1932年7月10日讯：文化界鲁迅、柳亚子、茅盾、陈望道、丁玲、洪深、田汉、郁达夫等32人致电汪精卫等要求释放牛兰夫妇“以重人道”。同日，江苏高等法院允对牛兰夫妇以移送医院为“通融办法”。

  • 1932年7月10日讯：晨，南京水西门外大王庙军械火药库突然爆炸，附近民房延烧百余家，居民被烧死烧伤者甚多。
