1932年07月04日

发表于 2021-07-04 更新于 2021-08-08 分类于 局部抗战(1931-1937)

  • 1932年7月4日讯：浙江海宁2000余农妇因灾向米商索米，军警开枪镇压，伤妇孺五人。

  • 1932年7月4日讯：吉林抗日义勇军图取长春，以冯占海为总指挥，宫长海为副。冯军主力月初起与日军战于新立屯一带，次日占舒兰、五常。

  • 1932年7月4日讯：日本海军中将左近司继野村任第三舰队司令，是日左近司自佐世保军港乘“出云号”旗舰到沪。

  • 1932年7月4日讯：军政部长何应钦、训练总监李济深前往吴淞、江湾、闸北各处视察战区，详询当时作战情形及我军防御工作。

  • 1932年7月4日讯：国联调查团抵东京。团长李顿昨日在大阪发表声明，谓“余等之使命系搜集此次纷争之一切关系事实，报告国联，此种关系事实之中最重要者，为中日两国在纷争地域内所有之永久的权益”；“余等之调查，确信为中日两国之死活的权益所寄与”。

  • 1932年7月4日《申报》：黑河息，呼海路绥化日军30日拂晓遭马占山军骑兵大队猛攻，双方交绥于绥化西方6里之长发屯，战二小时，马军退走。（2日专电）

  • #抗战影像#伪满洲国时期，东北某处伪政府举办的庙会活动上，关东军士兵正在持枪警戒。

  • 1932年7月4日《申报》：哈尔滨息，日军官大川中尉及日兵二人又教练官二人，近与反满军接战而阵亡者，其尸身今日将由日骑兵送至榆树。（3日路透电）

  • 1932年7月4日《申报》：黑河息，一日日军中村、村井、船桥三队联络伪吉军刘宝麟总攻榆树新立屯弓棚子，飞机往来投弹，机枪扫射，炮发猛烈异常。冯占海、赵文斌、姚秉乾三支自卫军竭力抵抗，由辰迄酉，激战数小时，各军向蔡家沟方面分数支退却。（2日专电）

  • 1932年7月4日讯：杨耀钧、邢占清率直属部队2000余人从大杨树村突围，且战且走渡过牡丹江，邢占清部驻扎于勃利县，杨耀钧驻扎于八面通，刘化南由玉泉村突围经五常县渡过牡丹江至双台镇整顿，李华堂部退守驼腰子金厂。

1932年07月03日

发表于 2021-07-03 更新于 2021-08-08 分类于 局部抗战(1931-1937)

  • 1932年7月3日讯：朱德、毛泽东率红一军团一部击溃梅岭关守敌一个团，占领梅岭关要隘。

  • 1932年7月3日讯：旅沪日侨以公共租界工部局有通过华方收回越界筑路地段之可能，日侨居留民会等两团体召集紧急会议，决定除面促工部局日董冈本等表示反对外，并郑重发表反对宣言，声称工部局放弃越界筑路权，“我侨民顿失生命财产之保障”。

  • 1932年7月3日讯：国民党长沙市党部以中俄复交关系重大，令各区分部充分发表意见，何键以“我国既一意剿赤，自不能对俄复交”为由，电请中央“详加察核”。

  • 1932年7月3日《申报》：哈尔滨息，王德林之义勇军姚振上部三千名，在吉敦路马号韩冲沟三四道荒沟集中，将再攻敦化，日军长谷川部已向该方输送防堵。（2日专电）

  • 1932年7月3日《申报》：北平息，马占山电，克山县城18日夜我军与敌军激战，毙敌50余，伤10余。海伦天主堂镇东乡毙敌20余，绥化现毙敌20余，我民团指挥王凤鸣殉国，穆棱县六井地方，毙敌28名，获枪炮甚多，日军仍到处奸淫屠杀，强迫民众悬伪国旗。（2日专电）

  • #抗战影像#伪满洲国时期，生活在东北的朝鲜族儿童。

  • 1932年7月3日《申报》：北平息，马占山骑兵一旅，驻庆城指挥，马以青纱帐起，改游击方略，时派骑兵及便衣队，向呼伦及齐克路侧攻，各地自卫军纷起响应，各县民团纷纷接济子弹。（2日专电）

  • 1932年7月3日讯：吉林自卫军第5旅李辅亭部首先突围，但计划被泄露，几乎全部被歼，旅长李辅亭只身逃脱，张福泰营率残部逃往夹信镇。

  • 1932年7月3日讯：北平学生、士兵、市民及其他劳动者1000余人，在天桥举行集会，示威游行，反对国民政府对日妥协投降，镇压爱国学生运动，反对日本进攻华北。

1932年07月02日

发表于 2021-07-02 更新于 2021-08-08 分类于 局部抗战(1931-1937)

  • 1932年7月2日讯：安徽旅沪同乡会因安徽省政府实行特种营业税，联衔电请行政院转饬立即撤销。

  • 1932年7月2日讯：阎锡山在太原成立“造产救国社”，阎任委员长。

  • 1932年7月2日讯：中华国民拒毒会通电揭露国民政府对鸦片公卖“一向态度模棱，均采取明禁暗行之策略”，号召“各界同胞，亟起自救，继续抗争”。

  • 1932年7月2日讯：午后4时，教育部派易克嶷、周淦等接收中央大学，教员解聘，令学生三日内离校，听候甄别，如有违抗，将强迫执行。

  • 1932年7月2日讯：废止内战大同盟会筹备会在沪举行第四次会议，讨论制止广东内战办法，决推代表赴粤请愿停战，并邀请粤各团体加入。

  • 1932年7月2日讯：牛兰夫妇因国民政府不准聘用外籍律师进行辩护，又因不允其请求移回上海法院“管辖”，本日起绝食，以示抗议。

  • 1932年7月2日讯：红三军贺龙部围攻京山，15日在第十三师万耀煌部压迫下撤围。

  • 1932年7月2日讯：林彪红一军团在大余东北池江地区击溃由南康向大余集结之李振球第一师，敌退守大余。4日红一军团开始围攻大余，粤军李汉魂独立第三师、张枚新第四师等向南雄集中，企图夹击红一军团。

  • 1932年7月2日《申报》：哈尔滨息，6月28日满洲里（税）关为“满洲国”当道所夺，该关仅有一华人帮办，当为日人警察所拘，解至哈埠。今日抵此，犹在拘禁中。哈埠税关共有职员220人，但现仅有华人职员6人服务，余则藏匿。众信“满洲国”将任南满路码头股主任加藤为哈尔滨税务司。（1日路透社电）

  • #抗战影像#伪满洲国“皇帝”溥仪访问日本期间，与日本天皇裕仁同乘一辆马车。

  • 1932年7月2日《申报》：北平息，宽甸日军偷袭灭石河，为我义勇军包围，激战甚久，敌死亡三十余，获步枪三十余枝，机枪两挺，子弹千余粒，我方仅死二人（1日专电）

  • 1932年7月2日《申报》：哈尔滨息，吉义勇军冯占海、赵文斌部30日与日军船桥中村部队在榆树东南30里新立屯激战一日。日军以飞机重炮猛攻，双方肉搏甚厉，现无进退。一日日军增加，将联络伪吉军刘玉枢旅三面总攻，日军村井支队30日开榆树增援，榆树弓棚子刘家店均成战场，两架对峙中。（1日专电）

  • 1932年7月2日讯：晨，蒋介石在汉口接见张难先、方本仁等，下午接见鄂省政府委员及武昌县长。蒋要求各县县长“应抱城存与存决心，遇有匪警，不得弃城离职”。

1932年07月01日

发表于 2021-07-01 更新于 2021-08-08 分类于 局部抗战(1931-1937)

  • 1932年7月1日讯：日外务省训令驻长春日领照会伪满洲国当局：“满洲所有税关除大连关外，一律归满洲国管辖；大连税务司福本复职”，督促“满洲国”接受此项计划，不能有任何更动，倘“满洲国”拒绝接受，将蒙不利。

  • 1932年7月1日讯：山东官商合办之民生银行在济南开幕，总经理王向荣。

  • 1932年7月1日讯：西北各省霍乱蔓延，潼关、包头死十五六人。

  • 1932年7月1日讯：张学良在东北大学体育系毕业典礼上宣布刘长春和于希渭为运动员、宋君复为教练员代表中国参加第十届奥运会。

  • 1932年7月1日讯：中华苏维埃临时中央政府发行“革命战争短期公债”60万元，半年期，年利一分，1933年1月1日起还本付息。

  • 1932年7月1日讯：北平师大学生致电行政院，要求撤回解散中央大学令。

  • 1932年7月1日讯：南京中央大学代理校长段锡朋布告限学生三日内离校，听候重行甄别。学生会向各界发表紧急宣言，呼吁“全国人士一致主持正义”，“力争吾校之生存”。同日，该校教授代表向行政院索薪。

  • 1932年7月1日《申报》：哈尔滨息，日军司令部消息，反满军与“满洲国“第二旅刻在旧哈尔滨城交战，昨夜反满军四百人袭击第二旅，今日清晨双方犹在交绥中云。（30日路透社电）

  • 1932年7月1日《申报》：哈尔滨息，攻下榆树县之自卫军宫长海等各部，27日早8时，受日军中村船桥夹击，并有日军多架掷弹。在城外刘家店吕鹏子，激战一日，双方死伤甚重。至晚向三岔河方面退却，一部自卫军向舒兰续发，榆树陶赖昭小刘家鹏，27日午后自卫军与日军激战二时退却。（29日专电）

  • #抗战影像#伪满洲国时期，东北某地日本移民村里的铁作坊。在伪三江省桦南县，日本武装移民“千振乡”、“湖南营”里，设施齐全，俨然像生活在他们自己国家的土地上。

  • 1932年7月1日《申报》：北平息，马占山电称，今在前方指挥军事，海伦日军被前头部队包围，正激战中。（30日专电）

  • 1932年7月1日《申报》：北平息，哈电马占山部第三二团，28日占领肇东县，呼兰日军28日亦被马部包围，激战甚烈，日军伤亡颇众。日机一架，28日由哈飞宾县侦察，被宫长海部击落。（30日专电）

  • 1932年7月1日讯：行政院决议：任命李杜代理东北边防军驻吉林副司令长官，丁超代理吉林省政府主席；任命冯占海为哈绥警备司令，王德林为宁安警备司令；青岛大学应即解散，听候整理；交通部长陈铭枢呈请辞职，应毋庸议，给假三个月休养，陈请假期内，由黄绍竑兼代交通部长。

  • 1932年7月1日讯：何应钦由浔抵京，向汪精卫报告赣省“剿匪”近况，并称：决定分区“清剿”，政治、军事双方并进，标本兼施，稳扎稳打，逐步“肃清”。夜，汪精卫、何应钦、曾仲鸣、李济深、褚民谊等乘车赴沪，与宋子文商筹“剿匪”军费问题。

1932年06月30日

发表于 2021-06-30 更新于 2021-08-08 分类于 局部抗战(1931-1937)

  • 1932年6月：成通纺织公司在济南成立，纱锭一万枚，布机200台，苗杏村任董事长兼总经理，1933年5月建成投产。

  • 1932年6月：民族音乐家、作曲家刘天华逝世。

  • 1932年6月：中央苏区创办列宁师范学校，徐特立任校长。

  • 1932年6月下旬：红一方面军一、五军团自闽南回师赣南，经安远、定南、龙南、信丰、南康县境，向粤北之南雄水口地区推进。彭德怀红三军团移师崇义、新城。

  • 1932年6月30日讯：南京警备司令部昨今两日逮捕中大学生会主席骆纪常及学生陈克诚等。

  • 1932年6月30日讯：国民党中央常务会议决议，电请留粤各中委调解海军冲突，一致对外。

  • 1932年6月30日讯：皖西敌军分三路进犯红军，一入六安，一入霍山，一侵霍邱，其空军连日来向霍邱一带轰炸。

  • 1932年6月30日讯：蒋介石在三省“剿匪”总部召集旅长以上军官面示“剿匪”机宜，声称“要救国救党，御侮对外，须先肃清赤匪”，并表示“匪如一日不肃清，本人即一日不回京”。

  • 1932年6月30日讯：蒋介石决定分三路进犯鄂、豫、皖三省革命根据地红军，并任命各路司令官，中路军司令官蒋介石自兼，刘峙副，下辖六个纵队：第一纵队指挥官张钫，第二纵队陈继承，第三纵队马鸿逵，第四纵队张印相，第五纵队上官云相，第六纵队卫立煌，进犯平汉线红军；右路军司令官李济深兼，王均副，下辖三个纵队，第一纵队指挥官徐庭瑶，第二纵队王均兼，第三纵队梁冠英，预备队阮肇昌，进犯津浦线红军；左路军司令官何成濬，徐源泉副，下辖四个纵队，第一纵队司令万耀煌，第二纵队萧之楚，第三纵队张振汉，第四纵队刘培绪，进犯鄂中红军。此外，长江上游总指挥王陵基，进犯鄂西红军。

  • 1932年6月30日《申报》：北平息，伪丰山路女儿河南铁桥，被义勇军炸毁，沟帮子羊圈子间枕木路轨均破坏。（29日专电）

  • #抗战影像#正在接受检阅的伪满洲国军队。

  • 1932年6月30日《申报》：哈尔滨息，马占山军千名，自绥化方面向呼海线集结，马占山率部渡通肯河，在通北附近集中兵力，日军平松部队，拟向该方总攻。（28日专电）

  • 1932年6月30日《申报》：哈尔滨息，攻下榆树之自卫军宫长海等部，现以四千守城内，千名驻城外，在四郊挖散兵战壕。伪国军刘玉枢之第一旅，顷退榆树西方50里之五棵树待援。27日日军船桥部队由五棵树向榆树总攻，中村部队兹青山堡夹击，午刻战事甚烈。日飞机多架往投炸弹。（28日专电）

  • 1932年6月30日讯：黑龙江省主席马占山将其所属抗日军队重新整编为三个军，由邓文、吴松林、李海清分任一、二、三军军长。
