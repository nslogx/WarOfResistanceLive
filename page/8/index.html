1932年07月28日

发表于 2021-07-28 更新于 2021-09-01 分类于 局部抗战(1931-1937)

  • 1932年7月28日讯：上海市香业工人400人因要求改善待遇，资方屡加拒绝，最近各店资方更陆续开除工人百余名，于是日起宣布罢工。

  • 1932年7月28日讯：上海各团体救国联合会致电国民政府，略称：“日军已决定重新占领虹口越界筑路及八字桥一带之地面，北四川路一带人心浮动，纷纷迁避，如大祸之将至，且已运来便衣警察，准备遣浪人前往肇事，恳请迅令淞沪附近驻军火速驰赴闸北实力镇慑，以安人心，而保国土。”

  • 1932年7月28日讯：李济深向蒋介石请辞豫鄂皖三省“剿匪”副司令及右路军司令、驻蚌行营主任兼职。蒋电复慰留，准将“剿匪”指挥事宜着王均负责兼代。31日豫鄂皖三省“剿匪”总部驻蚌行营结束。

  • 1932年7月28日讯：日本阁议于26日通过派遣驻满特命全权大使兼任关东军司令官，为承认伪满之先声，是日外交部训令驻日公使蒋作宾对日政府提出抗议，并命顾维钧请国联调查团注意此事。

  • 1932年7月28日讯：国民政府训令各机关公务人员，对政府设施，如认为不妥，应用书面建议于长官，不得径自向外发表，违者交付惩戒。

  • 1932年7月28日《申报》：北平息，外讯，日军侵热，全系一种威胁手段，以汤在东北财产甚多，冀迫其屈服。汤以国家为重，决心抵抗，日图热乃缓。（27日专电）

  • 1932年7月28日《申报》：南京息，东北伪组织受日人唆使攫夺海关问题，我方对大连海关，根据条约保障，不患其不能就范。闻日内尚拟向日本施行最后办法。（27日专电）

  • #抗战影像#为满洲国“皇宫”怀远楼，溥仪在此设立家庙，供奉列祖列宗。

  • 1932年7月28日《申报》：哈尔滨息，据日方消息，日军与红枪会及反满军剧战两次，皆获胜利。星期晚七时石头河子发生恶战，至次晨六时止，日方自称死4人、伤22人，反满军则死150人，伤200人。昨日乌吉密河日军与红枪会交战终日，日方亦自称胜利，但未报告死伤人数。（27日路透社电）

  • 1932年7月28日《申报》：北平息，关外日方，沿北宁路布置严密，各站大小桥梁均筑坚固炮台，各要站均设防御工事，并有甲车梭巡防守，路警更好白俄人及朝鲜金洲人甚多。（27日专电）

  • 1932年7月28日讯：马占山东进欲联合李杜，但计划泄露，在庆城县（今庆安县）东山张河白石拉子山口时，遭到日军预伏部队袭击，为日军所击溃。少校连长于俊海率百余人向北突围，吸引了日军追击力量，马占山率卫队数十人向东奔入大山。

1932年07月27日

发表于 2021-07-27 更新于 2021-09-01 分类于 局部抗战(1931-1937)

  • 1932年7月27日讯：上海青年爱国组织“血魂锄奸团”，警告奸商如再买日货，决戕杀无遗。28日向贩卖日煤之永昌煤号投炸弹一枚。

  • 1932年7月27日讯：废两改元研究会在中央银行开第一次会议，讨论新币制度，意见不一，定30日续议。

  • 1932年7月27日讯：全国邮务职工代表会发表维护邮权宣言，声明对日本攫夺东北邮权，誓予反对，并要求国民政府对入关邮工，无条件分配各邮局服务。

  • 1932年7月27日讯：是日至29日，马占山军800人渡过海伦河，在安固镇附近遭日军田中大队伏击追击，主力被围罗圈甸子一带，大部官兵牺牲。日军误认被难之参议韩述彭为马占山，日关东军司令本庄繁向天皇报功。

  • 1932年7月27日讯：日驻长春领事馆改为总领事馆，并设置锦州领事馆。

  • 1932年7月27日讯：鄂豫皖红军为粉碎敌第四次“围剿”，将各部队化整为零，全面扰敌。是日蒋介石令三省“剿匪”部队照预定计划，节节清剿，并称“彼以化整为零之法四出我周围，而我须以整齐严肃之阵收抚民众”。

  • 1932年7月27日讯：蒋介石在汉口召开湖北党政会议谈话会，张难先等党政委员五人及湖北省委、省、市党部全体委员出席，决定由党政委员会、省府、省党部各推委员，分区赴全省各县调查。蒋介石训话，强调“须实地调查各县情况，以为实施指导之依据”。

  • 1932年7月27日讯：蒋介石派机飞京，迎汪精卫、宋子文、李济深、黄绍竑至汉口，共商财政、封锁东北海关及废两改元等问题。

  • 1932年7月27日《申报》：北平息，吉救国军王德林，现有步兵七旅，骑兵二团，共约三万五千人，枪 支多子弹缺，平均每人三十粒。王军部在东宁，各旅分驻敦化、宁安、穆棱等县境。王军除阻止日人修筑吉会路外，并与丁李取攻守联络。（26日专电）

  • 1932年7月27日《申报》：北平息，绥中讯，日人强迫割除铁路沿线庄稼，日军每与义勇军作战，先捕良民若干，作与义勇军作战死伤抵偿。日军部散传单，攻击义勇军，恫吓东北民众，倭兵过绥中七区强奸妇女甚众。（26日专电）

  • #抗战影像#伪满洲国时期新京特别市公署，伪满文教部、国都建设局亦在此办公。

  • 1932年7月27日《申报》：天津息，东北军第七旅长王以哲顷被任为热河自卫义勇军总指挥，由东北军第七、八、十六及骑兵第四、炮兵第六各旅，选拔兵士二千人，24日开往承德。（26日日联社电）

  • 1932年7月27日《申报》：北平息，东北归来邮工谈，日本因我方封锁东北邮务，各邮局一律停办，一切送信交通全断绝，日人乃率伪警，按户搜索邮务职工，强迫复工，并以升级加薪相诱，但均为祖国关系不为所动。（26日专电）

  • 1932年7月27日讯：国民党中央政治会议决议：设立惩戒委员会，审议政务官惩戒案件；准庄崧甫辞立法院委员职，慰留其导淮委员职；任命贾士毅为立法院委员。

1932年07月26日

发表于 2021-07-26 更新于 2021-09-01 分类于 局部抗战(1931-1937)

  • 1932年7月26日讯：日本政府任命武藤信义为驻伪满全权大使；任命林博太郎为南满铁路总裁；任命有吉明为驻华公使。

  • 1932年7月26日讯：北平小学联合会代表40余人为反对市政府非法撤免六个小学校长，赴社会局请愿无结果，就地绝食抗议，宣称“复职始复食”。

  • 1932年7月26日讯：江苏公安局奉省政府密令，逮捕镇江《江声日报》经理刘煜生，并勒令该报停刊。省府秘书长金体乾谈捕刘原委称：“江声副刊时有宣传阶级斗争文字。”

  • 1932年7月26日讯：华侨义勇军缅甸队130余人，由许笑影等率领，本日由京出发赴东北各地参加抗日工作。

  • 1932年7月26日讯：东北民众抗日救国会热河分会致电汪精卫，表示“决率全热八百万民众，为政府先驱，誓死抵抗，以保疆土”。

  • 1932年7月26日讯：旅京西康人民请愿代表马泽昭等到行政院、国民党中央党部、参谋本部等处请愿：一、请速决方针，电令刘文辉继续前进，乘胜收复西康失地；二、请中央电川、青出兵援助西康；三、接济军实；四、撤销达赖驻京办事处；五、准西康民众组织自卫军。

  • 1932年7月26日讯：行政院长汪精卫、教育部长朱家骅发布整顿教育令，以近来学风嚣张，学潮迭起，若不厉行整顿，“国民教育即可完全破产”。

  • 1932年7月26日讯：行政院会议决议：第十九路军总指挥蒋光鼐因病辞职照准，遗缺由第十九路军军长蔡廷锴升任，并暂兼代闽“绥靖”公署主任职。8月2日，国民政府任命正式发表。

  • 1932年7月26日讯：北平政务委员会开临时大会，到张学良、韩复榘、徐永昌、商震等，张学良报告最近军事、外交及热河情况，决议正式大会于本月29日举行。

  • 1932年7月26日讯：张甲洲所率武装向兰西镇一带进行第一次西征。一路上攻破多个土窑和城镇，在一个多月的时间里行程千里，受此影响，其队伍迅速扩大到1000多人。

  • 1932年7月26日《申报》：东京讯，据沈阳消息称，“满洲国”当局已完全接管辽宁省之邮局，吉黑两省之邮局，定8月1日接管。于是即将宣称满洲邮务之独立，用新邮票。沈阳区之邮务司波莱蒂闻已接南京之训令，命停闭满洲中国之邮局，即将邮务人员遣送入关，拒绝与“满洲国”调解之任何建议。（25日路透社电）

  • #抗战影像#伪满洲国时期，新京日本总领事馆，位于长春市上海路30号，后已被拆除。

  • 1932年7月26日《申报》：南京息，陈树人谈，海外华侨闻日军侵热，极端愤慨，迭电张学良，请积极抵抗，愿以物资精神，尽量援助，并拟组义勇军，回国从戎为杀敌前驱。（25日专电）

  • 1932年7月26日《申报》：北平息，热河平静，但日图热仍急，在锦州作军事准备，其计划第一步注重朝阳、建昌、赤峰，对热取大包围形势，并以飞机轰炸各要隘，白旗堡、沟帮子等地日军，已奉命调集锦州、绥中。（25日专电）

  • 1932年7月26日讯：颜惠庆就日本掠夺东北邮务权案，再次向国联提出报告。

  • 1932年7月25日讯：西北问题研究会在沪举行成立大会，胡庶华主席致开会词，说明该会系用科学研究之结果去开发西北，纯为学术团体而非政治团体。大会通过简章，选举职员，并发表宣言。

  • 1932年7月25日讯：何键在湘省府纪念周发表演说，坚决反对中苏复交。

  • 1932年7月25日讯：邮政总局致电国际邮政公署，宣布封锁东北邮务情况，请国际邮联一致行动。

  • 1932年7月25日《申报》：北平息，义勇军郑桂林部伤兵八名，据谈，彼等均系乡民，因愤日军暴行，自动投入义勇军，所经大小战事，不下数十次，多系肉搏。日军兵器虽利，而胆小如鼠，常受上官督促，又不敢不进。故彼等均呼日军为坏种。（24日专电）

  • 1932年7月25日讯：何应钦在京中央纪念周作关于御侮与“剿匪”的报告，声称：“中国目前重要问题，为御侮与剿匪。外侮不御会亡国，赤匪不剿也会亡种。”

  • 1932年7月25日《申报》：哈尔滨息，现闻反满军一队，数约五百，攻击松花江佳木斯西北40里之日兵，又一面坡电称，一面坡为反满军所包围，即将开始攻击，今日阴雨，场地潮湿，故日飞机不能飞起云。（24日路透社电）

  • 1932年7月25日《申报》：北平息，汤玉麟24日电平，报告热境安谧，并表示誓死守土，愿与热河共存亡。（24日专电）

  • 1932年7月25日《申报》：北平息，外讯，日机数架，23日飞平泉凌源侦察，散发各色传单，语多荒谬，承德亦发现日机散发同样传单。（24日专电）
