1932年01月26日

发表于 2021-01-26 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年1月26日讯：中德签订炼钢厂草约，中国向德借美金1600万至2000万元。

  • 1932年1月26日讯：依兰镇守使兼第二十四旅旅长李杜所部陈东山团协同冯占海团占据滨江县公电局、滨江镇守使署，与吉长镇守使兼第二十八旅旅长丁超等部反抗熙洽，27日，在哈东大败熙洽伪军。

  • 1932年1月26日讯：上海《民国日报》在工部局出面“劝令”下于本日被迫停刊。同日，北平公安局通知各报馆：“嗣后对日本皇室暨日军各项事务，须审慎登载，万勿贻人口实。”英文《北京导报》因“侮辱日本”，在日方一再要挟下于次日停刊。

  • 1932年1月26日讯：财政部长黄汉梁、内务部次长兼首都警察厅长陈群、外交部政务次长傅秉常、外交部常务次长甘介侯同日辞职。

  • 1932年1月26日讯：行政院第六次会议决议，国难会议展期至2月11日开幕。

  • 1932年1月26日讯：上海闸北一带、宝山路车站、天通庵路、江湾路及其他各要隘，均有军警戒备，构筑工事，预防日军入侵。

  • 1932年1月26日《申报》：北平息，兴城苦战三昼夜之义勇军，因受日军陆海空三路压迫，力竭弹罄，大部退铁道线外附近山谷，待机再举。绥中兴城间路电未修复，兴城仍危，绥中日军迫令县城住户，赶筑炮台，防义勇军袭击。（25日专电）

  • 1932年1月26日《申报》：东京讯，据北宁路沟帮子传来新闻消息，日本军事飞机1架由一下级士官及一中士驾驶者，今日为义勇军射落，机中二人皆被杀。查自满洲有事以来，日飞机曾被射击数次，并有1架被击毁，但机毁而驾驶人亦丧命者，则今日始有之。（25日路透社电）

  • 1932年1月26日《申报》：哈尔滨息，新、旧吉林政府两派军队之冲突，酝酿已久，曾有一、二次之小接触。昨晨则在孝陵南面数里开始恶战，新政府军队以全力进攻，辅以飞机数架，掷下炸弹多枚。旧政府军队初则抵抗颇力，继则被迫退至孝陵。孝陵司令要求败兵缴械，否则闭城不纳。败兵不允，遂向…

  • 1932年1月26日《申报》：哈尔滨息，23日午后1时半，日飞机2架飞阿城投10余弹，重要机关全毁。商民纷逃，秩序大乱，土匪乘机抢掠。被害者无数，23及24两日，逃难者来哈阿商民近2万，顷阿城东铁车站，待车来者有数万。（24日专电）

  • 1932年1月26日《申报》：哈尔滨息，23日午后1时，于琛澂逆军协同日重炮兵攻拉林站科伦站。冯占海宫傁子及任团合力御敌。日军发百余炮，并以飞机低空飞行，往来投弹。冯宫部队进驻克伦站、拉林站全市。23日悉为日炮火所毁。（24日专电）

  • 1932年1月26日《申报》：哈尔滨息，今晨9时，张作舟部新编独立支队宫傁子部队十一营，退入阿城，冯占海部退二层甸子。（24日专电）

  • 1932年1月26日《申报》：哈尔滨息，日飞机3架，今午前11时飞阿城县城，向城内东大街投8弹，7弹炸。商店被毁6家，死兵士商民7人，经兵士以高射机枪击退。（24日专电）

  • 1932年1月26日《申报》：哈尔滨息，于琛澂部匪军五千余，今早10时进至阿城南十八里白城子，先锋已抵阿城郊，今午当有激战。宫傁子新自熙洽方面反正，宣言效义勇军行为，杀敌救国，诚允委冯占海为总指挥，宫傁子为副指挥御敌，卫戍省府。丁超、邢占清态度暧昧，所部不动。丁仅令东…

  • 1932年1月26日讯：日本天皇裕仁召开军事会议，在参谋总长闲院宫（载仁亲王）的主持下，训令在上海的盐泽幸一“行使自卫权利”。日本海军省即以第1 水雷战队（旗舰“夕张”号巡洋舰率第22、第23、第30驱逐队共驱逐舰12艘）运载第2特别海军陆战队460余人开沪。

  • 1932年1月26日讯：日领村井仓松向上海市政府提出最后通牒，对21日所提要求，限48小时答复。27日，村井又口头通知上海市长吴铁城：所提要求限于次日下午6时以前，当得一满意之答复；并要求下令将凡有抗日字样之团体一律解散，否则日人将采取必要之手段，以实现其要求。

1932年01月22日

发表于 2021-01-22 更新于 2021-04-25 分类于 局部抗战(1931-1937)

  • 1932年1月22日讯：　中共湘鄂西中央分局为了贯彻《中央关于争取革命在一省与数省首先胜利的决议》，在夏曦领导下召开湘鄂西省第四次党代表大会，大会通过了一系列“左”倾错误决议，选出以夏曦为首的新湘鄂西省委。29日大会结束。

  • 1932年1月22日讯：驻汕头日领因《汕报》称日兵为兽，日人为倭，向市政府要求道歉及令该报停版。

  • 1932年1月22日讯：日军骑兵各一中队分别侵占长岭、农安两县。

  • 1932年1月22日讯：段祺瑞被聘为国难会议会员后，是日在沪发表谈话，略谓：“余以为处置国家大事不在夸大虚矫，而在能实践所言。国事至此，吾人惟有效越王勾践刻苦忍辱，以求最后之胜利。但屈辱非妥协之比，以后须在‘求己’二字上用五六年苦功夫，国事终有可为，决无用其悲观也。”

  • 1932年1月22日讯：国民政府举行会议，通过蒙藏委员会增加常委六人；决议照行政院所拟聘任国难会议会员。

  • 1932年1月22日讯：蒋介石、汪精卫、孙科、张继、李宗仁、冯玉祥等在南京励志社开谈话会，共商对日外交及财政等问题。

  • 1932年1月22日《申报》：北平息，前昨牛庄城黄沙坨八角台等处，皆有战事。前日义勇军人众，略站优势。昨晨起，多门师团主力部队，由海城大石桥营口三面进逼，又以大批飞机向黄沙坨方面掷弹助战，义勇军不支，沿辽河撤退，至达都牛绿地方。（21日专电）

  • 1932年1月22日讯：上海日本陆战队因《民国日报》刊载题为《日浪人藉陆战队掩护昨日在沪肆意横行》之文章，是日向该报社提出四项无理要求：一、主笔来队提出公文陈谢；二、揭载半张大地位之谢罪文；三、保证嗣后不再发生此种事情；四、罢免直接责任记者职位，并限23日上午5时前答复。

  • 1932年1月22日《申报》：东京讯，据日本陆军省发表，满洲事变发生以来，截至本月20日为止，日军死伤者共计九百八十名。（21日日联社电）

  • 1932年1月22日《申报》：北平息，高山子义勇军，昨晨突受铃木师团威胁，与牛庄城义勇军失联络。昨晨起，新立屯黑山北镇义县等处，日军以铃木旅团为主力，联络一气，纷向义勇军威胁。冀迫各处义勇军及步骑各部队向热撤退，至高原地带，因作战不易，19日改用大批飞机向义勇军阵地轰炸。（21日专电）

  • 1932年1月22日《申报》：北平息，张海鹏到沈后已受本庄秘令，率蒙匪攻热。驻朝阳热军骑兵旅与张树森旅，均奉命分途开边境布防，以阻日军由锦朝锦大两线前进。日村井旅团，向大虎山西赵家屯义勇军猛攻。高山子附近铁道，被义勇军拆毁，多门师团主力开该方夹击，现酣战中，新立屯日军向新邱进逼…

  • 1932年1月22日讯：上海市政府对日浪人烧毁三友实业社案，向驻沪日总领事署提出书面抗议，并要求：一、日本总领事向沪市长表示歉意；二、迅速逮捕及严惩纵火杀人之罪犯；三、充分赔偿被害者；四、切实保证嗣后不得有同样事件发生。
