1932年04月27日

发表于 2021-04-27 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年4月27日讯：李宗仁电吴奇伟回师入闽“剿匪”。

  • 1932年4月27日讯：行政院会议通过救济江、浙丝业办法：一、减免生丝出口税；二、增加人造丝入口税率；三、发行兑换券1000万元。

  • 1932年4月27日讯：宋庆龄在上海谈：接欧洲电，请其代表中国出席7月28日在日内瓦召开之国际非战及反对日本对中国之侵略大会，已复电愿任该会中央执委，但是否能代表中国出席，须俟牛兰夫妇之生命安危而定。

  • 1932年4月27日讯：第五军军长张治中、第一师师长胡宗南，由苏州到京向蒋介石报告前方情况。

  • 1932年4月27日讯：国联调查团第四次访本庄繁，询问九一八事变情况。攻击北大营之平田联队长及岛元大队长说明事变时沈阳城内之状况。

  • 1932年4月27日讯：中国代表张似旭与日本代表冈崎在沪英领署开会，整理中日上海停战有关协定文字。日使重光葵通知英使，日政府对折衷办法表示接受。

  • 1932年4月27日《申报》：北平息，辽阳团总指挥王金一及38路义勇军，拟调查团到达时攻辽阳，将进太子河桥，于芷山派部将义勇军包围，双方激战一昼夜，各伤亡20余人。因子弹不济，义勇军退海城界，与老北风联络，拟日内袭击营口海城辽阳各地。（26日专电）

  • 1932年4月27日《申报》：哈尔滨息，24日早日军村井旅团，自一面坡向围沙河逼进，救国军则三路包围一面坡。25日晨，救国军刘万魁部二千人，抄出日军后路，袭占珠河，日村井旅团陷于包围。（26日专电）

1932年04月26日

发表于 2021-04-26 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年4月26日讯：冀、晋、察、绥诸省以财政奇绌，定5月1日实行鸦片公卖，以充军费。

  • 1932年4月26日讯：日军三个混成旅开吉东总攻义军，义军已于25日克中东路西之兰西城。

  • 1932年4月26日讯：湖北“绥靖”公署划京山、天门、潜江、应城、沔阳、汉川、钟祥、宜城等八县为“特别剿匪区”，行政、公安均归徐源泉指挥。

  • 1932年4月26日讯：国民政府派刘绍先代理陆军第四十三师师长；任命林秉周为海军陆战队第二独立旅旅长。

  • 1932年4月26日讯：湖北省府会议议决劝销善后短期公债300万元，充“剿共”经费。

  • 1932年4月26日讯：国民党西南执行部、政委会联席会议决：一、唤起西南民众监督政府勿与日妥协；二、由一、四集团派劲旅于最短期内肃清赣、闽“匪”共，并电中央饬邻省友军“会剿”；三、陈济棠、李宗仁表示，在抗日“剿匪”事件未告段落前，暂不就中央所委新职，由陈、李将此情形报告中央。

  • #抗战影像#1932年4月26日，韩籍义士尹奉吉进入虹口公园实地考察，为日本“天长节”庆祝会上的刺杀行动作准备。当晚，尹奉吉在自己的住所给父母、妻子和两个儿子写下了遗书。

  • 1932年4月26日讯：蒋光鼐到京谒蒋介石等报告前方情况，并商洽关于日军撤退交涉之应付事宜。

  • 1932年4月26日讯：国联调查团第三次访本庄繁，征询九一八事变当时之满洲方面状况。

  • 1932年4月26日讯：英使蓝普森及郭泰祺返沪。郭答记者称，英使之折衷办法为友邦善意，吾人当然乐于接受，但以不违背前协定之精神为原则。

  • 1932年4月26日《申报》：北平息，开鲁附近热河第九路义勇军联合各部约八九千人，进攻通辽，日羽山支队及独立守备队步兵第七十联队开通辽。（25日专电）

  • 1932年4月26日《申报》：延吉息，此间总领事接电谓，昨日下午四时，延吉冷水泉子日警察分署，被义勇军围攻，激战甚烈，总领事即派警官队前往救援。（25日日联社电）

  • #抗战影像#1932年4月26日上午10点，在上海法租界霞飞路宝康里27号，韩籍义士尹奉吉，左手握手榴弹，右手持手 枪，胸前挂着誓词，在韩国独立运动旗帜下宣誓加入“韩人爱国团”，并接受韩国临时流亡政府代总统金九委派，准备在几天后于虹口公园日本“天长节”庆祝会上，刺杀参会的日本军政界高级官员。

  • 1932年4月26日《申报》：北平息，自卫军二千名昨晨占石头城子，当地与长春电报断绝。（25日专电）

  • 1932年4月26日讯：日军第10师团33旅团在哈尔滨登船，顺松花江而下，向南天门码头冯占海部一个营发起攻击。

1932年04月25日

发表于 2021-04-25 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年4月25日讯：西安各校学生2000余人在民乐园举行欢迎戴季陶大会，因戴发表反 共媚日演说，激怒学生，将戴乘坐之汽车烧毁。晚，公安局封闭学生抗日总会，逮捕总会职员两人。次日，在中共陕西省委领导下，学生举行驱戴游行示威，被省府派兵镇压，伤十余人，被捕100余人。

  • 1932年4月25日讯：马占山自黑河电溥仪，切劝勿为傀儡，指示“为今之计，欲绝处求生，惟有俟国联调查团到达长春于接见之时，将日人压迫我公及组织政府之非出己意情形，据实详述，并请求调查团保护我公出国”，即使因而牺牲，亦优于身处樊笼因循坐误。同日，并电郑孝胥，责其“以溥仪孤注一掷”。

  • 1932年4月25日讯：东北义勇军占领安达站，哈尔滨日军一旅团东下谋攻伊兰，李杜率部扼险防堵。

  • 1932年4月25日讯：湖北财政厅呈财政部，谓月收109万元，支出216万元，计差百万元，请将中央原有补助费50万元继续拨济。

  • 1932年4月25日讯：赣粤闽“剿匪”总司令部发表贺国光为该部参谋长，下设参谋、副官、军法、交通、军医、军需六处，以杨珏等分别为主任。

  • 1932年4月25日讯：国民党中央政治会议决议：特任居正兼中央公务员惩戒委员会委员长；内政部长冯玉祥辞职不就，特任黄绍竑为内政部长（5月3日国民政府明令公布）；特任陈树人为侨务委员会委员长。

  • 1932年4月25日讯：孙科在沪寓所对报界发表谈话，详细解释由其所拟之抗日救国纲领，征求各记者意见，谓今日中国欲求出路，惟在全国一致抗日；苟非政治易辙，全国团结抗日势无可能；主张速行宪政，开放党禁，联合美、苏共同对日。

  • 1932年4月25日讯：国联调查团第二次访本庄繁，询问九一八事变发生以来的经过。

  • 1932年4月25日《申报》：哈尔滨息，哈长线三岔河，23日午后三时，为李青山救国军攻占，熙洽之护路军溃退，23日午后三时，日飞机二往侦察。据云，三岔河站尚留有少数军队。（24日专电）

  • 1932年4月25日《申报》：哈尔滨息，22日黑东安达为救国军占领，联络各县民团，听马占山指挥，并树救国旗。（23日专电）

  • #抗战影像#伪满洲国童子军与到访伪都新京（长春）的日本童子军代表见面握手的留影。

  • 1932年4月25日讯：罗文幹、郭泰祺偕英使蓝普森晤蒋介石、汪精卫谈沪事。罗文幹告记者，政府对沪中日停战会议抱两原则：一、停战协定内绝对不能含有政治问题之条件；二、必须确定日军撤退地点与日期。

1932年04月24日

发表于 2021-04-24 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年4月24日讯：上海《时事新报》被迫离馆工人发表第二次宣言，要求：一、立即恢复4月2日以前之状态；二、反对填写志愿书；三、离馆期内工资照发；四、馆方向报界工会道歉。提出“反对破坏工运的《时事新报》资本家”等口号。

  • 1932年4月24日讯：李杜吉林自卫军占领黑龙江省珠河县石头河子；25日又被日军第八旅团村井支队攻陷。

  • 1932年4月24日讯：日关东军参谋石原莞尔针对马占山揭露日本在东北的阴谋，表明反满抗日态度，拟定对伪满的方针与“满洲平定方略”，拟于5月下旬乃至6月上旬开始对黑龙江讷河、海伦、黑河等地的“平定”行动。

  • 1932年4月24日讯：鄂省政府主席夏斗寅及省府委员欢宴党、政、军、商、学、新闻各界。夏报告施政方针，望各界援助，并望军界领袖切实“剿匪”；商界领袖繁荣市场，提倡国货，协助政府。

  • 1932年4月24日讯：黄绍竑抵京谒见蒋介石，报告对粤、赣联合防共事。

  • 1932年4月24日讯：最高法院在南京《中央日报》发表《牛兰夫妇罪状调查报告》，声称“牛兰夫妇确与湘、赣中国共产党有联系，并与近在上海枪毙之共产党员向忠发有关系”，并称最高法院已训令江苏高等法院依此报告起诉，“如法院证明被告确犯图谋推翻现政府罪，则应处以死刑”。

  • 1932年4月24日讯：上午，国联调查团在沈阳访日本关东军司令本庄繁，询问目下军事情况。

  • 1932年4月24日《申报》：哈尔滨息，救国军自卫军实行合并，王德林李杜分任正副总指挥，冯占海任参谋长，总司令部设绥芬河，李杜军大部向延吉输送，与救国军联成三角阵线，沿东铁西进。21日农安县为李青山救国军三路包围，与熙洽军激战于城南牛罗屯，长春日军22日开一联队往援，自卫军宫长海旅21日……

  • 1932年4月24日讯：孙科在沪对记者谈，已拟定目前抗日救国纲领草案，主张召开三中全会，促成宪政，彻底抗日。

  • 1932年4月24日《申报》：北平息，辽义勇军第十路七支队二中队，占柳河沟后，日机一架到该地侦察半小时而去，20日晨日探数名，被我义勇军击毙一名，九时炮声机枪大作，队长宋鹤峰、队副顾国戚，率部迎战，激战二小时，获步枪一支，子弹两箱，至七时未停。（23日专电）
