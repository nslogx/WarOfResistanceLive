1932年06月01日

发表于 2021-06-01 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年6月1日讯：韩复榘派第二十师师长孙桐萱为鲁北剿匪总指挥，民政厅长李树春为副总指挥。2日，韩在济南召集各军开剿匪会议。3日，孙、李赴鲁北指挥剿匪。

  • 1932年6月1日讯：江苏教育厅明令禁止小学校教职员罢教索薪，以“防止借口索薪，暗图掀动教潮”。

  • 1932年6月1日讯：国民政府令撤销第十九路军卫戍司令部，派蒋光鼐为驻闽“绥靖”公署主任。

  • 1932年6月1日讯：汉口20余商会向鄂总商会请愿，因水灾后营业无法维持，请减轻全市房租。

  • 1932年6月1日讯：北平大学工学院学生为驱逐压迫反帝学生运动的校长沈尹默和院长程干云，于本日举行罢课。中国共产主义青年团河北省委发表《援助工学院罢课宣言》，对驱程斗争表示援助与支持。

  • 1932年6月1日讯：中央公务员惩戒委员会成立，居正等11人在司法院就职，该会通告本日起实行惩戒职务。

  • 1932年6月1日讯：上海《申报》、《新闻报》、《时事新报》等报馆工人，为援助《时事新报》被迫离馆之工人，一致举行大罢工。

  • 1932年6月1日讯：川、鄂军总攻鄂西红军，刘湘增兵一团、飞机一架，出川助战。

  • 1932年6月1日讯：5月份东北关税受伪满压迫，未解中央，外交部向日提出抗议。

  • 1932年6月1日讯：马占山在海伦附近三门谢家接见由国联调查团团长李顿密派的美国记者海米斯和一名瑞士记者。马对其陈述日本制造伪满及江桥抗战情况，表示“唯一心愿就是把日寇打走，消灭伪组织——满洲国，收复我东北三省同胞安居乐业的国土”。

  • 1932年6月1日讯：河北省反帝国主义大同盟第一次全省代表大会在北平召开，该会宗旨为加紧反对帝国主义，进行与扩大民族革命战争，“打倒帝国主义走狗——国民党政府”，“建立民众自己的政权”，“争取中华民族的独立与解放”。

  • 1932年6月1日讯：敌28旅团占领海伦，控制了呼海铁路，第27旅团结束肇东地区的扫荡作战，从安达站转向克山，并令15旅团天野所部向墨尔根方向前进，准备墨尔根、黑河地区的作战。

  • 1932年6月1日《申报》：北平息，吉自卫军占阿城，破坏道路桥梁，日机往侦察。（31日专电）

  • 1932年6月1日《申报》：北平息，辽东义勇军保持原阵地，近接管十二县行政，于芷山军奉日令往剿，在新宾激战五昼夜。于芷山军耗子弹近万发，大败。于行踪不明，其两夫人已离省城，因部下纷纷反正，恐权险。（31日专电）

  • #抗战影像#伪满洲国“皇帝”溥仪曾经使用过的几座“龙椅”。

  • 1932年6月1日《申报》：沈阳息，日本平松部，今日清晨向海伦之马占山军，开始猛烈之炮击，海伦势将攻（沦）陷。（31日电通社电）

  • 1932年6月1日《申报》：哈尔滨息，30日午前7时，日本飞机队飞机数架袭海伦上空，猛烈投掷炸弹，致海伦全市顿成火海，焚毁极重。29日夜深更，由海伦出发沿呼海路南下之马占山军约骑兵三千名，及吴松林所部，30日行抵中途，闻海伦大火，折回扑救，终日未熄。（31日专电）

  • 1932年6月1日讯：颜惠庆将日军进攻北满详情报告国联，请从速履行12月10日保证日军退入铁路沿线之国联行政院决议。

1932年05月31日

发表于 2021-05-31 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年5月：清华大学自3月份起，庚款即停付，学生组织经费维护委员会，反对停付美庚款，几经交涉，才由财政部借垫100万元作为维持费。

  • 1932年5月下旬：中华苏维埃共和国临时中央政府电全国邮务罢工工人，希望“本着无产阶级的坚决精神并防止黄色领袖出卖罢工，以与敌人作坚决的斗争直至最后的胜利”。

  • 1932年5月31日讯：行政院决议，特派蒋光鼐为驻闽绥靖公署主任；决设邮政经济制度研究委员会，聘陈公博、吴铁城、林实等为该委员会委员。

  • 1932年5月31日讯：马占山部骑兵千余攻入安达县境，6月1日占领安达县城。

  • 1932年5月31日讯：南京、济南市商会分别致电上海全国商联会等，响应废止内战大同盟，京商会派濮仰山等三人参加，济银行公会已函沪商联会等加入。

  • 1932年5月31日讯：吴铁城赴京向蒋介石、汪精卫等人报告日军撤退经过及请示善后。同日，吴对记者谈，沪战区善后，农业区如吴淞、江湾、大场、庙行等地由政府及地方协力救济为主，工商业区如闸北一带应以恢复和平秩序及进行防疫为主。

  • 1932年5月31日讯：侵沪日陆军除宪兵外全撤，第九师团长植田返日。虹口越界筑路周围地区尚留海军陆战队未撤。

  • 1932年5月31日《申报》：哈尔滨息，闻哈尔滨西面复有激战，初以为马占山军在该处失利后，不致得有战事，不意日军今复在哈尔滨西约18里处遇劲敌。日飞机12架由天空轰炸反满军，敌（原文如此，应该指反满军）死伤颇多，但仍坚守阵地。（30日路透社电）

  • #抗战影像#伪满洲国发行的系列明信片，主题为“哈尔滨的夜色”。

  • 1932年5月31日《申报》：哈尔滨息，哈绥线客货车，30日仍抵返一面坡。29日自一面坡开出试通绥芬河客车，中途被阻折回。东铁俄局长要求熙洽之护路军护行车，派重兵分驻各站，并表示在旅客生命财产未得保障、及路方利益无丝毫损失前，不开行哈绥通车。（30日专电）

  • 1932年5月31日《申报》：大连息，来连中之调查团一行，今晨九时二十分，由大连复往沈阳。一行于中途鞍山下车，拟视察鞍山制铁所。（30日电通社电）

  • 1932年5月31日讯：我宪兵两连到沪维持治安，日方认为违反停战协定，双方发生争执，沪停战共同委员会为此举行会议调解。日方代表冈崎认此举为敌对行动。中方代表俞鸿钧驳复，称宪兵到沪并无敌对行为，系我主权，日方不能干涉。最后经共同委员会主席克宁翰转圜，中方答应以后军队调动须通知该委员会。

1932年05月30日

发表于 2021-05-30 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年5月30日讯：吉林自卫军占阿城。日机数架轰炸海伦，全城起火。马占山在海伦召开紧急会议，决定改变集中攻打哈尔滨的作战计划，采取出其不意、攻其不备战术。翌日率部退至海北。

  • 1932年5月30日讯：蒋介石电令徐庭瑶任蚌埠警备司令，驻蚌各军概归其指挥。是日徐在蚌召开警备会议，讨论整顿军纪，维持治安。

  • 1932年5月30日讯：皖省府常会决议，奉蒋介石27日电令，撤销皖南、北盐斤附加税及特税。

  • 1932年5月30日讯：国民党中央政治会议决议改革教育初步方案，交教育组审查。此方案由陈果夫提议，其内容专重造就农、工、医各项专门人材，各大学十年内停招文、法、艺术等科学生。

  • 1932年5月30日讯：江西苏区50万赤卫军检阅大会致电全国工农群众和工农红军，表示在中央临时政府领导下，驱逐日本帝国主义出中国，求得中国民族完全独立与解放。

  • 1932年5月30日讯：中共中央为纪念“五卅”发表宣言，号召全国工、农、兵、学及劳苦群众，“以民族的革命战争打倒日本帝国主义”。

  • 1932年5月30日讯：北平市商会、银行公会、钱业公会等电上海全国商联会及市商会，响应废止内战大同盟，一致赞同加入发起之列。

  • 1932年5月30日讯：国联调查团离大连返沈阳。

  • 1932年5月30日讯：沪撤兵区域接管委员会接收吴淞铁路机厂，机械损失千万元。

  • 1932年5月30日《申报》：北平息，吉林、伊通各地义勇军大联合，拟进攻日军。东北义勇军第二路，昨夜攻兴城，日田井少佐额部重伤，死二十余伤百余，并有逆部张某，率二千余名反正。（29日专电）

  • 1932年5月30日讯：因李杜在依兰失守后向哈尔滨推进的各路部队复电“前方军事，请兄等权益处理”，自卫军前方部队在敌占区无法完成补给，各部陷入军纪混乱状态，当地民众中流传“不怕皇军飞机大炮，就怕自卫军刁抢胡闹。”等等不满言论。

  • #抗战影像#伪满洲国“皇帝”和“皇后”与侵占我东北的关东军军官以及外国宾客的合影照片。

  • 1932年5月30日《申报》：北平息，义勇军数千人，进攻舒兰日军，县城料可收复。（29日专电）吉林息，据昨日下午10时，驻屯榆树之吉林军报告，海龙与赵戴生所指挥之七千联合义勇军，转向舒兰攻击，小山子被围，舒兰县城已不免有被占之势。（29日电通社电）

  • 1932年5月30日《申报》：哈尔滨息，马占山旧部石兰斌部炮兵85团树反伪国旗，28日向海伦移动，马占山本人顷在德都。（29日专电）

  • 1932年5月30日讯：本日为“五卅”运动七周年，上海防范甚严，杨树浦工人乘车至体育场拟开会，被军警阻止，捕去一名。北平学生游行被军警制止。

1932年05月29日

发表于 2021-05-29 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年5月29日讯：唐柯三在京招待记者报告调解康、藏纠纷经过，称：“康、藏纠纷，发生于大金、白利两方财产之争执，不意甘孜知事措置失当，激成变乱，以致藏番猖獗，迭陷甘瞻。余秉中央意旨，与藏方议订条件，国人不满意，以割地赔款见责，实太冤枉。”

  • 1932年5月29日讯：上海童子军战地服务团全体复员。

  • 1932年5月29日讯：上海引翔港三友实业社总厂日军撤退。

  • 1932年5月29日讯：上午5时，日军第十四师团平松支队进攻肇东李海青义勇军，旋占领肇东。

  • 1932年5月29日《申报》：鞍山息，今晨三时半，马贼袭击鞍山东面大孤山之日本警察派出所，日警负伤。后并袭击满铁制铁所、大孤山之采矿所，绑去该所主任等要员三人。（28日电通社电）

  • #抗战影像#可能正在训练中的一支伪满洲国陆军迫击炮部队。

  • 1932年5月29日《申报》：哈尔滨息，昨日正午有人在一面坡与乌吉密河间一零八三公里轨道中发现地雷一枚，即止将抵之日铁甲车前进。后由火车中日兵将地雷移去，复开车前发。一面坡与该站西十五里某地点间敌军甚为活动，故哈尔滨与西比利亚边界五站间之通车，现复停驶。据昨日开抵此间之汽船四艘报称，曾在距哈尔滨北二十里处受反满军来复枪猛烈之射击，但未伤一人。（28日路透社电）

  • 1932年5月29日《申报》：淞沪之役，我19路军及第5军将士血战匝月，先后阵亡者数千人，政府及民众追念忠烈，昨日上午11时20分，在苏州公共体育场（即五卅公园）举行淞沪抗日阵亡将士追悼大会。中央、国府暨各军政机关各民众团体，多派代表参加，共计到会军民约五万余人。在风雨凄迷中，举行隆重之祭典，与祭人员，在此庄严悲哀之空气中，多有泣下者。

  • 1932年5月29日讯：汪精卫召罗文幹、蒋作宾及外交委员会委员商外交问题，决定外长仍由罗继任；郭泰祺担任驻英公使，日内赴英履任；驻日公使仍由蒋作宾回任。

1932年05月28日

发表于 2021-05-28 更新于 2021-07-26 分类于 局部抗战(1931-1937)

  • 1932年5月28日讯：沪公安局公布闸北五区境内沪战损失情形：原有人口10.1万余，现仅800余；房屋7627所，被焚达6435所。

  • 1932年5月28日讯：上海广肇公所粤侨商业联合会电唐绍仪、邓泽如、萧佛成等，请斡旋粤局，“以定粤局而安人心”。

  • 1932年5月28日讯：香港第一届英帝国货品展览会开幕。

  • 1932年5月28日讯：国民政府令：陆军第八十七师师长楼景越免职，任命张治中为该师师长；任命王均为陆军第七师师长。

  • 1932年5月28日讯：上海出版业工会等35个工会因闻第十九路军将调闽，特派代表赴苏州向该军军长蔡廷锴请愿挽留，并表示如无结果，再往南京当局请愿。

  • 1932年5月28日讯：天津市商会召集各同业公会开会，一致赞成废止内战运动，并电上海全国商联会等称：“废止内战，本为全国一致之心理，矧在困难期间，尤有安内对外之必要，此项组织，敝会极端赞成。”

  • 1932年5月28日讯：广东各界在北较场追悼淞沪抗日阵亡将士大会，到会数万人。同日，第八十八师在武汉及汉阳驻地，分六处举行追悼淞沪抗日阵亡将士。

  • 1932年5月28日《申报》：苏州息，淞沪抗日阵亡将士追悼大会，定今日上午10时，在苏公共体育场举行。事前苏垣各民众团体暨19路军与第5军方面，筹备进行，殊为热烈。苏垣各机关各团体，均派员参加，并由童军从车站至会场，沿途粘贴淞沪抗日阵亡将士大会会场由此前进之标语，金阁内外各要道、案牌坊林立于途，白布黑字，弥见悲壮。

  • 1932年5月28日讯：淞沪抗日阵亡将士追悼大会在苏州举行，到会军民五万余人，主祭官居正。全国各地一律下半旗，停止娱乐一天，以志哀悼。

  • 1932年5月28日讯：立法院会议讨论释放政治犯案，决议：将此案交付法制委员会、军事委员会于审查大赦案时参考。

  • 1932年5月28日讯：沪撤兵区域接管委员会派人会同公安局分赴吴淞、殷行及引翔三地日兵暂驻区域恢复行政权。

  • 1932年5月28日《申报》：沈阳息，昨日辽中县城内公安队全部反正，即日占领县衙及各机关，拘捕伪县长，揭青天白日旗，在辽中日侨二十余名，日警三十一名，韩侨三百余名等大起恐慌，拍电请日领及伪国派兵营救。（27日华联社电）

  • 1932年5月28日讯：新疆增设巩留县，由伊宁县析置。

  • 1932年5月28日《申报》：哈尔滨息，据日方消息，近在呼兰及哈埠以西诸处未能前进之马占山军队，刻向北退走。闻马刻在大黑河附近，日方自称，现以骑兵与飞机追击退军。而驻齐齐哈尔之日军亦向北出发，会同追击云。就中东路线之火车而言，事态渐有进步，虽路线外现有战事，但哈埠与绥芬河间之交通，今午已恢复。（26日电路透社电）

  • 1932年5月28日《申报》：长春息，昨夜九时半，在宽城子西北一里地方，及长春南面之八里坡，均频闻枪声，守备队当派警察队出防，宪兵队亦临时召集，形势紧张。（27日电通社电）
