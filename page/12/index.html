1933年01月15日

发表于 2022-01-15 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1933年1月15日讯：江苏南通县平潮镇保卫团逼交保卫捐，将农民沈宏奎全家六人扣押，农民二三百人到区公所抗议，要求开释。桥东乡农民往援，被开枪打死四人，群众愤而捣毁区公所，将沈全家救出。县长陈栋被迫将肇事区、乡长等撤职讯办，并抚恤死难农民。

  • 1933年1月15日讯：北平佛教青年救国团发表告全国僧界书，指出僧界为中华民族之一部，当此民族存亡生死关头，应立即团结一致，努力抗日，宁作战场鬼，莫为亡国僧。

  • 1933年1月15日讯：美国新任总统罗斯福向各国发出美国不承认满洲国的通告，表达出对日本的强硬态度。此后，国联的态度也变得强硬起来。

  • 1933年1月15日讯：上海全浙公会电促蒋介石克期北上督师，并反对将刘珍年师调驻浙境，要求蒋率同北上。

  • 1933年1月15日《申报》：北平息，秦皇岛闻炮声二十余响，驻锦西日军第八师团连日对郑桂林部总攻三次，日军损失甚重。日军在角山筑炮台二座，秦皇岛共日兵舰三艘，巡逻舰四艘陆战队不时上陆，形势极严重。（14日专电）

  • #抗战影像#一队身着昭五式军服的日本陆军士兵在一辆野战炊事推车前合影。

  • 1933年1月15日《申报》：北平息，连日敌以大队陆空军，及伪军程国瑞、张壁部猛攻九门口，总计日兵死伤六、七百人，伪军死伤四、五百名，我方亦有巨大伤亡。九门口长城内外农村，悉被炸毁，民众炸毙颇众，敌尸已多运葫芦岛，再转运回国，敌在角山寺一带，筑防御工事，13日下午起，前方无战事，仅步哨小接触。（14日专电）

  • 1933年1月15日《申报》：临榆息，北戴河13日夜到日舰一艘，在海面游弋，并向铁路沿线探照，至14日晨始离海面，石河地区连日时有敌侦察兵发现，均被我哨兵击毙。（14日专电）

  • 1933年1月15日讯：日军纠合伪满军千余人，在坦克配合下，向河北境内石门寨进犯。

1933年01月14日

发表于 2022-01-14 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1933年1月14日讯：山东省府主席韩复榘对该省囚犯200余人已关押一二年以上者，分别情况，取保释放。

  • 1933年1月14日《申报》：北平息，平市国难救护队，派代表赴秦皇岛，与何柱国协商，该部赴秦担负救护工作，已得何同意，谢电平。队员即日出发赴北戴河，听候调用。平队接电后，即派该队队员吕兴文 、甘元、夏子州、何笑家、姜振东五人，携带大宗药品，今晚离平赴北戴河。（13日专电）

  • 1933年1月14日讯：被阻隔于宁安的原救国军一部重新整编，由吴义成任代理司令，周保中任总参谋长，所部整编为4 个路军和1个救国游击军。分别有吴义成、周保中、姚振山、柴世荣、李延禄等人指挥，总兵力达到万余人。

  • 1933年1月14日《申报》：北平息，关外义勇军郑桂林、朱霁青、盛瑜等部已取得联络，扰敌后方，颇收奇功。热河义勇军近又向万家屯一带活动，如日军由朝阳寺北进，决断其归路。（13日专电）

  • #抗战影像#山海关南城根的民房在榆城之战中被焚毁。

  • 1933年1月14日《申报》：北平息，日军入榆城后，将第九旅伤兵六名俘虏，用铁丝将六人手穿于一起，放炉火中燃烧，用硫磺弹将六人置于一处，加以轰炸。炸弹爆炸后，当时死亡四名，余二名幸得逃脱，往水门，中途又死一名。余第九旅机关枪连兵许耀武一名，今逃来平。（12日专电）

  • 1933年1月14日《申报》：北平息，秦皇岛形势仍紧张，日军昨深夜由兵舰运炮数门登陆，旋送日兵营，停泊秦皇岛日舰，除津田少将旗舰外，其驱逐舰等，时向榆关绥中海面游弋，石河前线无大变动。（13日专电）

  • 1933年1月14日讯：全球华侨总公会通电，提出“造成一个有组织有秩序之救亡运动……以为救国之有效准备”。

1933年01月13日

发表于 2022-01-13 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1933年1月13日讯：交通部令邮政总局将所有东北各邮局与外界所订合同，在失地未收复前暂时解除。

  • 1933年1月13日讯：监察委员高友唐弹劾前上海特区法院院长杨肇熉与审判厅长郑毓秀狼狈为奸，贪婪不法，要求政府将杨、郑及同案人书记官钮传椿、会计主任郑慧琛依法究办。15日，杨、郑登报声明否认有贪污不法行为。2月25日，监察院将该案移最高法院，杨、郑逃逸。

  • 1933年1月13日讯：日军第十师团饭冢支队从佳木斯出发进攻宝清，9日占宝清。吉林省府代主席、护路军总司令丁超所部第二十一旅旅长关庆禄率部投敌，余部被日军缴械。丁超在宝清藏匿。是日，丁遭日军搜出被俘。

  • 1933年1月13日讯：杨靖宇参加中共海龙中心县委扩大会议，帮助整顿海龙工农义勇军，成立红军第三十七军海龙游击队。

  • 1933年1月13日《申报》：北平息，日军对俘虏之义勇军，常施极刑，近在海龙县朝阳镇，俘义勇军四十余，囚一室内，饿死37名，余不知下落，日军在金川俘义勇军指使伪警犬前往咬死4人，同时在金川指使鲜人，以锯锯死义勇军2人。（12日专电）

  • 1933年1月13日《申报》：北平息，敌茂田部二千余人，昨夜由沈阳开至万家屯，即沿长城向九门口李家堡推进增援前所绥中等处，兵车山积，日决心攻夺九门口石门寨等要隘，连日积极增援，大战即在目前。（12日专电）

  • 1933年1月13日《申报》：北平息，九门口仍在激战中，秦埠昨澈夜闻迫击炮声，闻现在李家堡相持，我军某地援军开到，士气大振，九门口依有天险，可无恙。（12日专电）

  • 1933年1月13日《申报》：北平息，秦皇岛形势愈紧张，日军借口我军捕一奸谍问题，日舰陆战队今夜或有动作，我已严加防备。（12日专电）

  • 1933年1月13日《申报》：临榆息，12日晨日机6架，猛烈轰炸九门口，掩护歩骑炮联合部队，猛烈攻击。我军警戒部队，固守阵地，至敌进距阵地三百米附近，始开始射击，敌屡扑屡挫，伤亡累累。嗣后敌愈来愈众，火力益炽，两翼步兵涌进，势成包围，我军死守，终将当面之敌击退，遂自动撤回某阵地，日军大部在口外李家堡附近，占领阵地构筑工事，一部日军及伪警约二百余名，已推进至九门口，并无前进模样，双方对峙中。（12日专电）

  • 1933年1月13日讯：湘鄂西红二军团贺龙部一部由鄂入湘，是日占领桑植县城，并向慈利、大庸等县进展。湖北保安处长范熙绩到恩施率各县保安队会同陈渠珍部“进剿”。20日，何键派李觉率部赴常德、临澧“督剿”。

1933年01月12日

发表于 2022-01-12 更新于 2022-03-10 分类于 局部抗战(1931-1937)

  • 1933年1月12日讯：国民政府上日令行政院办理《流通国内米麦案》及《开放运米禁令并厉行积谷办法挽回利权调节民食案》。是日行政院电饬各省、市政府等，“省与省及县与县间，应绝对流通，不得阻留”。

  • 1933年1月12日讯：爱国志士刘崇武等上年11月在上海以炸弹、手 枪对付私贩日货之奸商，被上海公共租界警务处逮捕，送第一特区地方法院审理。是日刘崇武被判徒刑七年，潘鸿生、曹松寿、田水阳等亦均判刑。

  • 1933年1月12日讯：上年冬新疆鄯善暴动发生后，吐鲁番维吾尔族民众起而响应，在麻木提等人领导下秘密组织武装，是日起事进攻吐鲁番老城，省军守将马福明投降。马降后焚烧县府，杀戮汉人，并将金树仁派往进剿之熊发育诱杀。金树仁遣盛世才率部由哈密前往镇压，相继将鄯善、吐鲁番攻占，暴动民众退焉耆。新编第三十六师马仲英部将领马世明，利用民众武装于下旬在焉耆成立第三十六师“剿匪”总司令部，马自任总司令。

  • 1933年1月12日讯：国民党中央委员、国民政府委员薛笃弼以榆关失陷，华北垂危，政府不积极抗日，愤而电辞国府委员职，并于15日通告在上海、苏州执行律师职务。

  • 1933年1月12日讯：西南政务会是日起连日在广州开联席会议，参加者广东陈济棠、邹鲁、邓泽如、刘芦隐、刘纪文、林云陔，广西李宗仁、梁朝玑、马君武，福建李孝侯、赵一肩，云南张冲，贵州杨秋帆、甘嘉仪，四川张明九、但懋辛，湖南戴静园，冯玉祥代表王建屏，胡汉民代表胡木兰，热河义勇军代表何民魂等。会议作出：一、促中央履行三中全会决议，出兵抗日，收复国土；二、拟西南大联合，筹组西南国防委员会等项决定。

  • 1933年1月12日讯：日军攻九门口，继续向石门寨发动攻击，但为我军阻击，形成对峙，日军在山海关西遭遇何柱国部坚强阻击后，苦战后仍未能触及我军主阵地，遂派遣落合出面，由英国军舰舰长寻求和谈可能，为何柱国拒绝。

  • 1933年1月12日《申报》：北平息，泊秦皇岛日军舰9日晨开走，驱逐舰一艘，开榆关前所绥中一带海面游弋。（11日专电）

  • #抗战影像#1932年“一·二八事变”期间，驻守在上海公共租界区的葡萄牙水兵。

  • 1933年1月12日《申报》：北平息，伪沈阳靖安游击队某团，上周奉命由日军某中佐，及日兵20名统率，进攻邓铁梅部。抵凤城后，三区游击队，突向天空鸣枪，向义勇军传递信号。日军乃令靖安队返沈，拟予法办，靖安队乃秘密集议，将日人尽数消灭，携全副武装，尽投邓铁梅部，参加抗日工作。（11日专电）

  • 1933年1月12日《申报》：北平息，日军再度攻九门口，同事石门寨、李家堡亦发现敌踪，激战甚烈。我军陷苦境，经我援军赶到，迎头痛击，同时义勇军郑桂林部三千，由石河沟出动绕击李家堡之敌，敌溃退，集中于万家屯。我军遂转危为安，郑部刻在高岭与日军激战中。（11日专电）

  • 1933年1月12日讯：汪精卫在日内瓦发表宣言，略称：“中国对于暴日侵略，确立交涉及抵抗并行之方针”，“中国始终信任国联，听候解决，此为交涉之本旨也。惟在此期间，日本侵略不已，中国为领土主权人民生命财产计，断难坐受其侵凌，不能不奋起而为正当防卫，此为抵抗之本旨也。”
