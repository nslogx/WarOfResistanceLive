1932年06月27日

发表于 2021-06-27 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年6月27日讯：国民政府救济水灾委员会全体委员大会决定该会于7月1日起办理结束。

  • 1932年6月27日讯：青岛大学全体学生开会议决：一、否认学校当局将开除之九名学生改为准其休学一年的处置；二、驱逐校长、教务长；三、请教育部另选贤能；四、请各教授组织维持会；五、全体赴京请愿，并通电全国大学，请一致援助。

  • 1932年6月27日讯：中央大学师生全体会议决议：校长仍请于任鸿隽、翁文灏、竺可桢三人中择一任命；驱逐刘运筹、杨公达、黄仁浩、方光圻四教授；请政府彻查中大水灾捐款舞弊事，限朱家骅将挪用水灾捐款三日内送还会计组；通过要求行政院撤换教育部长朱家骅。11时整队赴行政院请愿。

  • 1932年6月27日讯：教育部电各大学、专门学校、各省、市教育厅、局指示暑期军事训练办法，凡受军事训练之学生，在暑期内应一律留校，连续训练三周。

  • 1932年6月27日讯：伪满正式接收安东、营口、哈尔滨、珲春及大连各海关，福本接受伪命，重行到关。

  • 1932年6月27日讯：中共苏区中央局作出《关于争取和完成江西及其临近省区革命首先胜利的决议》。

  • 1932年6月27日《申报》：哈尔滨息，齐克路克山站23日为携炮九门之马占山军1千五百名猛攻，与日军平松部队激战半日而退。（25日专电）

  • #抗战影像#伪满洲国与前苏联黑龙江边境地区，一名身穿防寒服执勤的日本关东军，正用军用望远镜密切关注着苏联方面的情况。

  • 1932年6月27日《申报》：哈尔滨息，吉自卫军冯占海宫长海各部，由青山堡进攻榆树，伪国军不敌，为攻下。张家店郑家附近县城要隘，均为攻下。榆树双城一带，电讯不通，24日午后，日军大队开去。晚间与吉自卫军发生激烈战事，吉自卫军刘玉枢旅往协攻，顷在激战中。（25日专电）

  • 1932年6月27日《申报》：哈尔滨息，李杜大刀会及自卫军24日攻占延寿县，设自卫军总指挥部，委任公安局长县长，与宾县冯占海军取联络，向方正推进。（25日专电）

  • 1932年6月27日讯：汪精卫在京中央纪念周报告，声称将五省红军消灭，方可并力御侮；财政当取决于政治，必须政治修明，财政始能充实；鸦片公卖不可随便举行。

1932年06月26日

发表于 2021-06-26 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年6月26日讯：钱塘江水大涨，杭州、海宁、萧山一带沿江滩地坍陷三万余亩，禾秧尽遭淹没。长沙因连日暴雨，全市殆受水浸。湘水续涨，长潭、长宝、潭衡各汽车路均被水淹停驶。

  • 1932年6月26日讯：中央研究院与陕西地质调查所订定勘查陕西油矿协定。中研院担任供给技术人才，地质所担任调查、测绘。

  • 1932年6月26日讯：北平青年群众代表大会在平召开。大会致电中华苏维埃临时中央政府，表示“我们更要进一步的建立红军，创造河北的新苏区，来积极完成拥护你们的战斗任务”；并另电东北义勇军称：“坚决号召河北省的劳苦青年自动武装起来，帮助你们与敌人作战。”

  • 1932年6月26日讯：河南省红军将平汉线花园附近铁轨拆断，火车 出轨。陆家山车站被捣毁，平汉车不通。

  • 1932年6月26日讯：第十九路军由参谋长黄强率领入漳州“剿共”，第六十师向南靖、龙岩推进。

  • 1932年6月26日讯：新任粤空军司令黄光锐续派飞机飞伶仃洋轰炸陈策各舰。各舰以高射炮还击，旋避入香港英界。

  • 1932年6月26日《申报》：沈阳息，野田军曹今早乘机出发，拟威吓在辽西一带之义勇军，因机件发生故障，今晨坠落于沈阳县月粉屯。机全毁，军曹亦惨死，军曹为长崎人士云。（25日电通社电）

  • 1932年6月26日《申报》：延吉息，23日义勇军在延吉附近与日军激战，当时日警官今井、加藤两人失踪。至24日在二道沟发现其死尸。（25日日联社电）

  • #抗战影像#伪满洲国境内，身穿昭五式军装的日军士兵，乘坐火车前往北方前线途中，正在列车上吃饭。

  • 1932年6月26日《申报》：哈尔滨息，22日敦化遭王德林部义勇军猛攻，日军往援。23日一日夜，义勇军退往蛟河。（24日专电）

  • 1932年6月26日《申报》：哈尔滨息，义勇军张大成向五常推进，23日抵小山子，与伪国军第五旅骑兵激战。（24日专电）

  • 1932年6月26日讯：伪满强占哈尔滨海关，北满各关均易帜。大连关日员因福本被免职而全体辞职，并声明自即日起，与中国政府脱离关系，投入“满洲国”海关。

1932年06月25日

发表于 2021-06-25 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年6月25日讯：连日大雨，长江水陡涨至36.9尺；湘水亦涨。

  • 1932年6月25日讯：上海虹口区怡昌、云成、祥成三丝厂工人1000余人因反对延长工时，要求增加工资，一律宣布罢工。26日虹口通纬、裕经、兴纶三丝厂工人加入罢工。其他各丝厂资方自动宣布停工，27日虹口各丝厂全部停顿。30日，闸北区15家丝厂工人全部参加虹口区丝厂工人大罢工。闸北区丝厂亦完全停顿。

  • 1932年6月25日讯：上海市商会电行政院反对江苏实行特种营业税。29日，该会再电行政院力争。

  • 1932年6月25日讯：教育部颁发《第一期实施义务教育办法大纲》，规定以1932年8月起至1935年7月为第一期，此期内全国各县、市设义务教育实验区，收容县、市区内失学儿童十分之一。同时颁发《短期义务教育实施办法》，收容10至16周岁失学儿童入短期小学班。

  • 1932年6月25日讯：国联十九国特委会决议，展缓讨论远东问题，待调查团报告书完成。国联十九国特委会决议，展缓讨论远东问题，待调查团报告书完成。

  • 1932年6月25日讯：孙科到香港访胡汉民。陈济棠军两路渡海攻琼崖，并派飞机在伶仃洋炸陈策之“中山”等舰。

  • 1932年6月25日讯：大连税务司日人福本因拒绝汇解关税至沪，经上海总税务司梅乐和于24日予以免职。是日，中国政府为日本嗾使伪满接收大连海关事向日本提出抗议。27日，日政府向中国政府抗议福本褫职事。

  • 1932年6月25日《申报》：哈尔滨息，“满洲国”兵一队从齐齐哈尔北进，行至距城18里处，为反满军包围。齐齐哈尔骑兵闻警往援，则见队长及其三百兵士，尸陈原野，盖全队已尽为反满军所杀死，不遗一人矣。中国义勇军之切齿于“满洲国”兵，于此可见。（24日路透社电）

  • 1932年6月25日《申报》：北平息，日军以陆空军猛攻通辽，南江岸自卫军总部，被日机掷弹四五十枚，房屋一部被毁，自卫军事前有准备，损失不大，城内重要街市，均被毁。唐聚五部死守城内，子弹缺，恐难持久。（24日专电）

  • #抗战影像#伪满洲国时期，一场暴雨过后，在积水中嬉戏的儿童。

  • 1932年6月25日《申报》：山海关息，大通线义勇军，22日攻入通辽，与驻军混战一昼夜，歼敌甚众，翌晨大虎山日军大队往援，义勇军恐势不敌，遂先退出，待机再发。沈阳义勇军散布四郊，将伺机再袭。（24日专电）

  • 1932年6月25日《申报》：哈尔滨息，21日午后八时，吉自卫军冯占海杨文麟部二千余，攻入榆树县东北青山堡镇。伪国吉军警备第一旅刘玉枢部，22日驰往堵御，自晨间发生猛烈战事，迄晚犹在激战中。青山堡距榆树60里，距长春320里，吉军攻入后，四郊设卡将久屯驻兵一支，骑兵向他方转去。（24日专电）

  • 1932年6月25日讯：国民党中央政治会议开会，汪精卫详细报告东北情形，对日人在东省练兵窥伺关内及在东省之各种侵略措置，陈述颇多。会议通过追认国民政府特派蒋光鼐为驻闽“绥靖”公署主任等多案。

1932年06月24日

发表于 2021-06-24 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年6月24日讯：汉口商会全体执委赴鄂省府，要求停办营业牌照税，省府主席夏斗寅允停办。

  • 1932年6月24日讯：中央大学教费独立运动委员会推代表20余人赴行政院请愿，要求拨定庚款为该校经费独立基金。汪精卫手谕答复：“英庚款与英有换文规定用途，当查明办理，如无款可拨，政府必须设法维持中大教费。”该代表认为满意返校。

  • 1932年6月24日讯：行政院决议，北平师大校长李建勋辞职照准，任命李蒸为该校校长。

  • 1932年6月24日讯：全国商联会及上海银、钱两公会为东北关税被夺事发表对外宣言，略称：日本借自造傀儡伪满，“劫夺东北关税，匪特违反现有条约，且足酿成中国财政及政治之瓦解”，“为保障条约尊严，并顾全国际贸易与金融关系起见，应请各友邦速起设法制止日本施此下策”。

  • 1932年6月24日讯：中共临时中央在上海召开北方各省委代表联席会议，通过《革命危机的增长与北方党的任务》、《开展游击运动与创造北方苏区的决议》、《关于北方各省职工运动中几个重要任务的决议》。

  • 1932年6月24日讯：国民政府公布《大赦条例》。

  • 1932年6月24日讯：外交部为伪满将于7月1日起实行贴用日本代印之邮票事，特向日使提出严重抗议，指出日本此种行为“破坏中国邮务行政完整，实属违法已极”，“所有一切责任，应由日政府完全负担”。

  • 1932年6月24日《申报》：哈尔滨息，据此间俄报消息，逐渐西进之日军，已于星期二晚开抵满洲里。闻日军此举，由满洲里穿越边界而去。（23日路透社电）

  • #抗战影像#伪满洲国时期，奉天一处卖眼镜的小商贩。

  • 1932年6月24日《申报》：哈尔滨息，马占山部吴松林等部会合，20日向青岗进攻，与新黑军激战甚烈。日军大队驰往援，马军各团队旗帜，均书抗日救国字样。（22日专电）

  • 1932年6月24日《申报》：哈尔滨息，21日海伦东北三马家子日军将校侦查队，与黑军接触。海伦日军问讯，派骑兵大队往救。克东方面二十日仍在激战，黑军约千余名猛攻甚烈，日军平松、平贺两部联络，激战甚久，黑军退却。（22日专电）

  • 1932年6月24日讯：以博古为首的临时党中央在上海召开北方各省省委代表联席会议，继续推行王明的“左”倾冒险主义政策。参加会议的满洲省委代表反映，在东北应把工作的重点转移到组织和领导东北人民进行抗日武装斗争上来，但却被扣上“右倾机会主义”和“满洲特殊论”的帽子。满洲省委书记罗登贤被撤职，由魏抱一继任。

1932年06月23日

发表于 2021-06-23 更新于 2021-08-21 分类于 局部抗战(1931-1937)

  • 1932年6月23日讯：中华国民拒毒会就国民政府重颁禁烟令一事发表宣言，表示“疑信参半”，谓“证以当局以往言行之不一致，殊令人难以置信”，“政府果有禁烟诚意，宜于煌煌功令之外，更作事实上之进行”。

  • 1932年6月23日讯：上海废止内战大同盟筹备会电广东陈济棠和陈策，吁请悬崖勒马，另图和平解决；并电广州各团体婉劝力诤，联合阻止二陈互相残杀。

  • 1932年6月23日讯：财政部以伪中央银行发行纸币两亿元，呈请行政院速谋应付方法，并咨外交部向日抗议。

  • 1932年6月23日讯：行政院令冀、鲁、豫省政府及平、津市政府，筹划有效办法，救济自九一八以来由东北逃至华北各处之灾民，协同慈善机关及路局将灾民遣送还乡，或设法为之谋生。

  • 1932年6月23日讯：中华苏维埃临时中央政府为反对国民党对红军发动第四次“围剿”发表宣言，称：“现在国民党军阀……在帝国主义的指挥之下，正集其全力，实行进攻苏区与红军的冒险的行动”，“本政府号召全国的工农兵士及一切劳苦群众，一致的斗争起来，武装起来，扩大民族革命战争……反对帝国主义、国民党对苏区红军的四次大开战。”

  • 1932年6月23日《申报》：北平息，沈伪教育厅令各校组青年联盟团，专宣传承认伪国，并往各县村讲演，欺骗民众。东北各机关职员，多日人。因言语隔阂，日令中国职员每日学日文二小时。日人恐各机关职员反正，多换用女职员，已占三分之一以上，资格多系高小女中或日本女高毕业。（22日专电）

  • #抗战影像#1932年3月8日上午8点，伪满洲国“执政”溥仪与其妻子婉容出发，前往伪长春市政府。

  • 1932年6月23日《申报》：哈尔滨息，21日夜，约五百之义勇军一团，袭击庆城，攻破监狱，放出犯人约百名，经抢掠后退去，日军某某队与各方面之军队联络，向前进攻中。（22日电通电）

  • 1932年6月23日《申报》：北平息，辽东自卫军克复清源，于芷山部日内可肃清，自卫军人数约25万。（22日专电）

  • 1932年6月23日讯：外交部为日本嗾使伪满破坏中国海关行政完整，特向日本政府提出严重抗议，并分别致函《九国公约》签字国之驻华代表，请各政府对日政府准备正式承认“满洲国”事，加以严重之注意。
