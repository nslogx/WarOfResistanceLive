1933年01月04日

发表于 2022-01-04 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1933年1月4日讯：江西黎川、资溪一带红军一、五军团主力，乘国军调动之际，向北进展，计划夺取金溪、临川，扩展苏区。是日，红军一部在金溪黄狮渡附近围歼第五师周浑元部第十三旅。该旅伤亡大半，旅长周士达被俘，残部于次日拂晓向南城溃逃。红军占金溪。

  • 1933年1月4日讯：日军发动榆关事件引起世界舆论的谴责，是日苏《真理报》载文指出：“日本帝国主义者以武力占据山海关，并非是偶而发生的所谓地方事件，乃日本帝国主义者侵略热河与华北之整个计划之一步骤。”并说：“此种侵略之结果，将使帝国主义者间之冲突，愈益严厉尖锐化。”

  • 1933年1月4日讯：驻日公使蒋作宾电告外交部称：本日日本外相内田康哉“向英、法、美、意、俄大使说明山海关事件经过，并声明不愿扩大，认为局部问题已训令前方官宪直接与张（学良）之代表交涉”。

  • 1933年1月4日讯：蒋介石致电张学良，指出：“此后倭必以真面目攻取平、津，我方不能不迅下决心，从速处置。”提出军分会及张本人“应即迁保定或张家口，一面与各公使馆交涉，声明北平驻军他移，以北平为文化区，不愿与倭军在北平附近冲突，并望各国互尊条约，保持平、津之和平”。

  • 1933年1月4日讯：日军五六百人在战车掩护下沿平榆大道进攻五里台附近阵地，被何柱国部第九旅第六二七团守军击退。同日，日机轰炸石河阵地。临永警备司令部移海阳镇，电北平军分会要求增援。

  • 1933年1月4日讯：国民党中政会讨论日军侵榆事件，由军政部长何应钦报告事件经过。会议仅决定“交付各常委会同军事当局负责处理”。

  • 1933年1月4日讯：外交部就榆关事件照会日驻华使馆，要求日政府迅饬日军退出榆关，严处肇事者，嗣后不得再有此种举动，至我方一切损失，保留要求赔偿之权。同日，该部发表宣言，指出日军侵榆为其预定计划，要求国联迅即以最有效方法予以制裁；并电令驻国联代表颜惠庆将日军侵榆情形报告国联，要求采有效措施。

  • 1933年1月4日讯：李延禄在穆棱县五河林宣布吉林救国军补充团改编为抗日游击总队。

  • 1933年1月4日讯：五六百名日军在战车掩护下，沿平榆大道进攻榆关城西的中国守军五里台防地，被严阵以待的独9旅627团官兵击退。

  • #抗战影像#“一·二八事变”期间，一队支援侵略上海作战的日本陆军预备役部队在上海某处码头上岸，其胸口布条上是其姓名。

  • #抗战影像#漫画家丰子恺在得知榆关（山海关）失陷后，当即画下画作《关山月》。

  • #抗战影像#日本陆军第8师团某部士兵，在攻陷山海关一处城墙后高声欢呼庆祝。

  • #抗战影像#榆关抗战中，被日本陆军第8野 炮联队8门三八式野 炮轰塌的山海关（榆关）城墙。

  • 1933年1月4日讯：红36军独立师在西荒四面楚歌的形势下，回师东归。在回师路上，与索伦族山林队“索利营”发生矛盾并激化，连遭索伦营的追打；到庆城克苏里大桥时，又遭曹荣、徐景阳等地方武装的伏击，部队被打散，牺牲49人。

  • 1933年1月4日《申报》：哈尔滨息，据中东路局消息，向中东路东段进攻义勇军之日军，已于本星期一晨占据绥芬河。（3日路透社电）

  • 1933年1月4日讯：榆关失陷后，城内外大火，燃烧3昼夜，到处残墙焦土，死尸狼藉。 北宁铁路3名警察不肯投降，日军强在其背上插上“欢迎大日本”旗帜，游街绕全城，然后押往南关枪决。未能逃出的妇女学生，皆被日军屠杀，百姓伤亡一千几百人。

1933年01月03日

发表于 2022-01-03 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1933年1月3日讯：伪满外交总长谢介石通电“警告”张学良，妄称榆关引起不幸事件，应由张学良负完全责任。

  • 1933年1月3日讯：马占山于上年底退入苏境，所部二万余人由军长邰斌山、邓文，司令檀自新等率领撤至热河。是日，外交部代电行政院要求对马部拨款购粮，解决给养。5日，热河省府主席汤玉麟亦电国府各院、部及蒋介石、张学良，要求速筹救济办法。

  • 1933年1月3日讯：孙科、吴铁城等在沪邀请各界名流200余人，发起建立中山文化教育馆。8日，开第一次筹委会，蔡元培、吴经熊、伍朝枢等15人参加，通过筹委会简章及办事细则，24日，经国民党中执会及教育部批准备案，并由国民政府每月补助事业费五万元。

  • 1933年1月3日讯：驻日公使蒋作宾自东京电蒋介石，报告日军发动榆关事件原因：“日军部久欲驱张，使反 动分子在华北另组政府，因欲与我公提携，迟迟未发。近因中俄复交，三中全会提议全国长期抗日，我公又无意出而负责，其对华感情日形恶化……荒木、松井等虽欲先用政治手腕，促我公与之妥协，而在满军人则以荒木计划尚嫌过迟，现又值国联开会期近，故即夺取榆关，压迫平津，使热河归其掌握。”望蒋“负起全责，速组健全政府，确定方针，或战或和，当机立断”。

  • 1933年1月3日讯：626团余部做激烈巷战，无人乞降，战至下午5时，一连连长赵壁连亦重伤，四门皆破，仅余十几人，在团长石世安率领下从北水门撤出，榆关失陷。我军阵亡400人，伤300余人，日军战报伤亡120人。

  • #抗战影像#1933年1月3日下午，日本陆军第5步兵联队部分官兵正在检查山海关城内东北军阵亡尸体数量，以便作成战斗详报中的战果数字。

  • 1933年1月3日讯：榆关失陷。上午，日军第八师团铃木旅团以飞机、坦克配合猛攻临榆县城。泊于南海之日舰两艘频繁向榆关城发炮。午，占南门及东南城角。下午2时，由东南城角攻入，坦克由南门冲入，城内发生巷战。何柱国部第九旅第六二六团守军伤亡逾半，一营营长安德馨及二、三、四、五连连长均阵亡，全营伤亡几尽。下午3时，守军撤出，临榆遂陷。城内商号毁于炮火者500户以上，民众死伤千余人。日方称日军死亡官兵80余人，伤200余人。

  • #抗战影像#1933年1月3日，攻陷山海关的日本陆军第5步兵联队乘马小队部分士兵在一车东北军独立第9旅战死烈士的尸体前合影。

  • #抗战影像#攻陷山海关后，日军士兵在牺牲的东北军第九旅626团烈士遗体前留影。

  • #抗战影像#山海关城内，死于战火的无辜平民尸体。

  • #抗战影像#1933年1月3日，在山海关西门附近殉国的东北军士兵和死难的平民遗体。

  • #抗战英烈#国民革命军东北军独立第九旅626团一营安德馨营长、王宏元连长、关景泉连长、刘虞宸连长、谢振藩连长 1933年1月3日上午8时，日军6架飞机在山海关（旧称榆关）投弹10余枚。9时许，又有1架日机从榆关飞至秦皇岛、南大寺、北戴河、留守营、昌黎一带，侦察我军动态。　　上午10时，日军先头部队突然在陆、海军重炮轰击和飞机轰炸掩护下，向榆关南门进攻。11时许，日军第八旅团主力加入进攻榆关的战斗。与此同时，停泊在南海的日本海军4艘军舰搭载海军陆战队员登陆，以舰炮掩护对榆关夹击，并出动10余架飞机低空轮番轰炸。 守卫榆关的东北军独立第九旅626团奋起还击，榆关南门和东南城角及西南水门一带战斗最为激烈，南门城楼及商民住宅多被毁坏。正午时分，南门及东南城角被大批日军攀登占领。我军预备队向南门增援对敌反攻，第11连自东门(即第一关城门)向东南角发起反冲锋，遂将日军击退。 午后2时，日军增强兵力，再次总攻榆关东南城角，集中炮火将城墙轰出豁口后，日军蜂拥而入，我军舍命相拼，屡堵屡仆，拼争异常激烈。接着，敌军沿城进攻，其坦克车队从南门闯入。我守军用机枪猛烈阻击，近距离后以手榴弹投杀。 日军在占领南门城楼后用机枪扫射，我军官兵伤亡惨重，626团一营三连连长关景泉身中数弹壮烈殉国。坚守东南城角及奎星楼（即现靖边楼）附近的626团一营二连连长刘虞宸与日军搏杀中英勇牺牲，一营四连连长王宏元也相继战死。 日军坦克从榆关南门冲入后，626团一营营长安德馨率领两个班奋勇反击。危难时刻，他大声向全营官兵喊道：“我安某一日在山海关，日本人一日决不能过去。日本人要过去，只有在我们的尸体上过去！”官兵们深受感动，无不奋勇当先和日军浴血奋战，直至战斗到最后一人。安德馨营长头部、肘部多处中弹，仍奋不顾身、视死如归，直至在山海关古清真寺附近英勇牺牲，兑现了自己与山海关共存亡的誓言。 随即，城东二里店、馒头山方面的敌军也迫近城下，东北城角和北、西门相继失守。午后3时，626团团长石世安忍痛下令余部由西水门撤退，退守西关。此时四面城墙，均已被日军占领，当我军撤退时，又遭敌军猛烈射击，626团一营五连连长谢振藩身负重伤后牺牲，残余部队撤至石河西岸防线。在榆关战斗中，我方坚守城池的东北军独立第九旅626团，阵亡官兵400余人、负伤300余人，驻军眷属遭日军杀害者亦有10多人。 安德馨营长、王宏元连长、关景泉连长、刘虞宸连长、谢振藩连长以及东北军626团所有牺牲的烈士们，今天是你们89周年祭日，山海关永远铭记你们！榆关抗战纪念碑永远铭记你们！民族永远铭记你们！

  • 1933年1月3日讯：今日10时，日军第8师团对榆关发起全面进攻，因众寡悬殊，不到2小时我军即伤亡过半，至下午2时，日军在东南部轰出巨大缺口，安德馨营长及以下二连连长、刘虞宸、三连连长关景泉、四连连长王宏元、五连连长谢振藩全部壮烈牺牲。一营伤亡殆尽。

  • #抗战影像#1933年1月，榆关抗战期间，正在接受西方记者采访的东北军独立第九旅旅长何柱国，在采访中告诫同胞们中华民族想要生存只有誓死抵抗这一条路。

  • 1933年1月3日讯：蒋介石由奉化到杭州，复电张学良，略谓：“无论倭寇行动如何变化，我军速入热河计划，万不可稍有变更，只要能达成此任务，则为缓寇计，不妨相机应付。”并表示商震部“调动与接济筹备，弟当负责”。

1933年01月02日

  • 1933年1月2日讯：晚，天津日驻屯军司令中村孝太郎就榆关事件电张学良提出“警告”，妄称榆关事件系中国进兵热河，宣言抗日所致。同日，驻平日使馆代办中山亦访张学良提出同样“警告”。

  • 1933年1月2日讯：是晚，日第八师团长西义一命铃木第四旅团增援榆关。

  • 1933年1月2日讯：北平邮局邮务长、意大利人巴立地勾结军警机关非法拘禁该局邮务工会抗日会执委13人，并封闭邮务工会。邮务工人强烈反对，电请中国民权保障同盟向当局要求惩办巴立地，释放被拘人员。

  • #抗战影像#在新民辽河铁桥上巡逻警备的日军。

  • #抗战影像#1933年初，山海关（榆关）战斗中，正在使用掷弹器抛射钩索准备攀爬城墙的日本陆军士兵。

  • #抗战影像#侵华日军炊事兵正在用野战炊事车烹饪米饭与味增汤。

  • 1933年1月2日讯：张学良密电蒋介石，认为日军发动榆关事件“并非即欲作真面目之战斗，仍为借此对我方军事部署加以试探”，希望“设法对榆关事件谋一缓和延宕办法”。同时提出“如日方不顾一切悍然来犯，缓敌之谋无效，则我亦不得不尽其全力以与周旋”，并表示自己“决无丝毫犹豫”。要求蒋“迅示机宜，并乞迅饬启宇（第三十二军军长商震）所部火速出动，其他军队速行集结”。

  • #抗战影像#1933年1月长城抗战期间，东北军独立第9旅旅长何柱国亲赴山海关前线督战。

  • 1933年1月2日讯：10时，日军炮击临榆县城，步兵爬城进攻。守军第九旅第六二六团官兵愤极，不顾“不准还击”之令，以石头、手榴弹回击，毙日军儿玉中尉等。同时日军3000余人于石河铁桥、南关、二里店、五眼城、吴家岭之线展开，将榆关城从东、南、西三面包围。何柱国遂下令还击。

  • 1933年1月2日讯：日军一名叫儿玉的中尉率70余人在南关民房上架设机枪与平射炮，向山海关南城墙上的中国守军射击，遭我军反击后，日军即图谋进攻。安德馨营长给一营全营战士作最后告白：“我安某人一日在山海关，日军就绝对不能从山海关进去，如果日军想进去，除非踩着我的尸体进去！”

  • 1933年1月2日讯：上午8时日方由前卫开来南关兵车三列，步炮兵3000余人，配备大炮20余门。

  • 1933年1月2日讯：晨2时，榆关日军向临永警备司令部提出：一、撤退南关中国驻军、警察及保安队；二、撤退城上中国守兵；三、南关归日方警戒；限即时答复，否则武力夺取。临永警备司令部允南关暂由日方警戒，南关稽查兵暂撤城内，俟天明调查真相后再交涉解决。日军得寸进尺，要求开放南门，门内及城上均归日军警戒，遭我拒绝。日军竟将南关公安分局局长扣留，缴去警察枪械。

1933年01月01日

  • 1933年1月1日讯：上海英美烟草公司工人罢工，9日允暂复工。
