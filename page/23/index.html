1932年01月20日

发表于 2021-01-20 更新于 2021-05-09 分类于 局部抗战(1931-1937)

  • 1932年1月20日讯：《中国日报》在南京创刊。康泽创办，社长顾希平，总编辑邬绳武，总经理唐忍安。

  • 1932年1月20日讯：福建长乐县农民因生活困苦举行暴动，捆捉县长陈希彭，打开监狱释放无辜农民，并布告列数其对农民剥削的罪恶。

  • 1932年1月20日讯：骑兵第一师第一旅士兵和下级军官在河南息县暴动，投入红军，旅长王春长当场被起义士兵打死。

  • 1932年1月20日讯：班禅率随员多人抵锡盟，张学良派张九卿前往欢迎，并以金表等贵重礼物数十种，分赠班禅及锡盟各王公，以示宣慰。

  • 1932年1月20日讯：上海市国难救济会成立，通过该会公约、会章和宣言，推举沈田莘为主席，王晓籁、史量才等25人为理事，并通过以经济实力援助东北义勇军案。

  • 1932年1月20日讯：国民政府特派吴铁城为国难会议秘书处主任，郑洪年为副主任；任命蔡增基为建设委员会秘书长；任命俞飞鹏为交通部常务次长。

  • 1932年1月20日讯：外交部就日军占领北宁路关外段阻止交通事，向日使提出严重抗议。

  • 1932年1月20日讯：何应钦电各军军事长官，说明中央因财政困难，决自本月起军费减为1600万元，以前积欠亦决设法发放。

  • 1932年1月20日讯：粤国民党中委唐绍仪、伍朝枢等21人通电拥护中央，否认扣留国税。

  • 1932年1月20日讯：国民政府为日机在吉林临时政府所在地宾县轰炸，照会国联请加制止。

  • 1932年1月20日《申报》：青岛息，英文泰晤士报对日侨暴动主持正论，连日大加抨击，日侨屡请更正，均被拒。该报主笔特函公安局，请派警保护，日领对市政抗议焚毁市党部捣毁民国日报事，已答复，谓肇事时，我国未获凶犯，坚不承认。（19日专电）

  • 1932年1月20日《申报》：北平息，锦西日军不熟地势，迭受围攻，16日义勇军又在庄家屯地方与近卫辎重大队苦战终日，截获粮秣子弹无数，该辎重大队几近全队覆没。（19日专电）

  • 1932年1月20日《申报》：北平息，榆关电，依田旅团主力，因连日在乱山中苦战被围，损失极重，已奉本庄令，昨起开始撤回锦州，改由王殿忠匪军，与义勇军作战。大虎山新立屯附近日军嘉村铃木两旅团主力，以蒙匪为前驱，又向义勇军开始袭击，我第8旅步兵两营，正与蒙匪接触，已入混战时期。（19日专电）

  • 1932年1月20日《申报》：沈阳息，关东大侠老北风所部绿林豪杰1500名，昨日下午进攻牛庄，旋将日军包围。同时牛庄城内义勇军亦起而响应，营口日军派兵往援，迄今仍在激战中，日兵死伤甚众。闻老北风并有分兵进攻营口计划，目下营口日兵已全数出防，并在埠内搜索义勇军，民间大受骚扰。又老北风别部在…

  • 1932年1月20日讯：上海市政府就日浪人烧毁三友实业社事，派秘书长俞鸿钧口头向日领村井仓松提出严重抗议，日领表示遗憾，并声明负责缉凶严办。

  • 1932年1月20日讯：晨2时20分，在沪日浪人32人烧毁中国三友实业社毛巾厂，并冲入附近华德路警亭，砍断电话线，杀死正在报警之华捕田阔生一人，刺伤二人。下午，上海日侨2000人在公共租界蓬莱路日侨俱乐部举行居留民大会，会后赴驻沪日领事馆及日本海军陆战队请愿，要求日政府增 …

1932年01月19日

发表于 2021-01-19 更新于 2021-05-09 分类于 局部抗战(1931-1937)

  • 1932年1月19日讯：日机向宾县大量投弹，轰炸吉林临时省政府。

  • 1932年1月19日讯：南京各界抗日会通电要求国民政府“对日绝交，自决图存”。

  • 1932年1月19日讯：安徽旅京同乡会及铁路协会等各团体，因皖人阚铎受伪命为奉山路局长，咸深愤激，决议开除其会籍。

  • 1932年1月19日讯：章太炎、张一麐、沈钧儒等联名通电，“请国民援救辽西”。

  • 1932年1月19日讯：国民政府令：任命邹鲁为国立中山大学校长。

  • 1932年1月19日讯：各军驻南京代表开会，议决请军政部维持军费每月1800万元，并第二次向军政部请愿索饷。

  • 1932年1月19日讯：行政院决议：派顾维钧参加国联满洲调查团。

  • 1932年1月19日讯：行政院会议决议裁员减政，各院、部、会经费自本月份起，六个月内暂按原额发五成。各省、市照中央办法，一律减缩。

  • 1932年1月19日讯：阎锡山电蒋介石、汪精卫、胡汉民，盼早日入京。

  • 1932年1月19日讯：孙科电促胡汉民北上入京，略称：“此次中央政制改革之后，行政院实对政治会议负责，但政治会议常委三人均未在京主持，对内对外党 国大计无从决定。”

  • 1932年1月19日《申报》：沈阳息，据今日日军当局宣称，满洲伪共和国之组建，正在急急筹备中，预定将于2月6日农历元旦宣布成立，又闻南满铁路公司刻正予以准备，与伪共和政府开始谈判，一面筹备与造新支线，以期席卷满蒙富源，且闻伪共和政府成立后，日人将代向各国游说承认。（18日国民电）

  • 1932年1月19日《申报》：哈尔滨息，长春日兵二百，携机关枪迫击炮，16日晚向陶赖昭推进。于琛澂逆军不忍同族相残，多不从命令逃散。马锡麟部逆军，16日一枝绕至陶赖昭，仍拟向二十四旅进攻。于琛澂收编之匪军宫呆子16日晨哗变，宣言歼灭卖国军，现与马锡麟部激战。（18日专电）

  • 1932年1月19日《申报》：沈阳息，松尾运输队断绝消息以后，混成队某旅组织搜索队，极力探索其下落，至昨日在锦西东方发现松尾少尉等三十名之尸体。（17日日联社电）

  • 1932年1月19日《申报》：北平息，东京政府因辽西义勇军，人数激增，日军屡挫，决定于朝鲜驻屯军全数，移至东北外，再加派内地师团，以厚兵力。至图热计划，拟俟该内地师团开到后，再发动，故沿大通线朝锦栈日军，均暂停进攻模样。（18日专电）

  • 1932年1月19日《申报》：北平息，日军由沈阳调到大部援军，分向大通锦朝两线推进，红螺山暖池一带日军，昨晚被我义勇军包围，死伤甚多.余今晨纷向锦州女儿河方面败退，拟与后方援军联络，再大举进攻。又锦朝支路战事仍烈，义勇军在红螺山向锦出动，扰乱日军侧翼，锦人心恐慌。（18日专电）

  • 1932年1月19日《申报》头版马占山将军香烟广告：孤军抗日当代大英雄。来函山积渴望已久之十枝装纸匣，爱国同胞一致赞赏之五十枝罐装。（17日专电）

  • 1932年1月19日讯：汪精卫、蒋介石再电促胡汉民入京，称：“此值国难严重时期，吾辈三人，与其天各一方，遇事不能即时商榷，诚不如同聚首都，随时献替，较于党 国有裨。”

1932年01月17日

发表于 2021-01-17 更新于 2021-05-09 分类于 局部抗战(1931-1937)

  • 1932年1月17日讯：晨1时50分，天津工业印刷局大火，延烧中华书局、丽生大药房等八家商店，焚房屋63间，损失约在50万元以上。

  • 1932年1月17日讯：中国著作者协会在上海成立，主要成员有陈望道、冯雪峰、楼适夷、丁玲等。

  • 1932年1月17日讯：南京中央大学教授为日军攻陷锦州发表告国民党及国人书，略谓：“四万万人之中华民国，断不能因国民党领袖不团结或疾病而被断送。同人等诚不信蒋、汪、胡三公不来，国事遂毫无办法”，国民党“应整个交还中国人民所付托之政权，俾中国人民自谋生路”。

  • 1932年1月17日讯：留日学生抗日救国会在中央大学召开全体会员大会，决议要求国民政府对日绝交，并以实力援助东北义勇军。

  • 1932年1月17日讯：上海30余民众团体在南市公共体育场召开市民大会，通过反对国民政府出卖东三省、反对政府压迫民众运动、反对政府停付公债本息等议案14项。会上有人散发共产党传单和高呼反对国民党口号。会后游行至上海市府及市党部，被警察驱散。

  • 1932年1月17日讯：孙洪伊等发起之宪政促进会成立，选孙洪伊等17人为理事，声称该会目的在“实现全民政治，反对一党专政”。

  • 1932年1月17日《申报》：北平息，榆关电，依田旅团15日晨以主力向义勇军压迫，越过辽宁省界，深入五顶山左近，经我步兵2团及义勇军四面包抄日军后路，肉搏5小时，日军损伤极重，仓促退锦西。16日拂晓，日军增援猛攻，与义勇军在新台门地方激战终日。我步兵1团与义勇军会合，另由大窑沟、暖池塘、红…

  • 1932年1月17日《申报》：哈尔滨息，日军由吉林开向舒兰，攻击张作舟部队，战况颇烈。日军已入城，日机连日赴榆树投弹，军民伤亡甚众。（15日专电）

1932年01月16日

发表于 2021-01-16 更新于 2021-05-09 分类于 局部抗战(1931-1937)

  • 1932年1月16日讯：连日来晋钞价格暴落。本日晋钞一元仅换现洋四分，持票购现金者甚多。山西省府通令各县15日起赋税等款，一律改收现洋。金融异常混乱，商民恐慌万状。

  • 1932年1月16日讯：英使蓝普森因日方将北宁路榆沈段划归南满路公司附带经营，有妨害英国在该路之债权，并破坏中英间之借款合同，向日方提严重抗议。

  • 1932年1月16日讯：上海国难协济会等70余团体召集各界代表大会，讨论民众自卫救国等要案。

  • 1932年1月16日讯：南京国民外交后援会电慰东北义勇军，望再接再厉，为国家留生气，为民族争殊光。

  • 1932年1月16日讯：广州学生赴京请愿代表团到京向国民政府请愿，要求明令各省军队克日开赴东北，收复失地。

  • 1932年1月16日讯：财政部电全国各税收机关，称“军政各费，急于星火”，着即将税收款项一律扫数解交国库，毋得贻误。

  • 1932年1月16日讯：中国海军“江宁”号、“海宁“号炮艇在江南造船所开工，工厂编号分别为658、659。

  • 1932年1月16日《申报》：哈尔滨息，13日榆树南秀水甸子吉军26旅宋团，被匪军马锡麟部围攻，25旅张作舟部千人，携迫击炮往援。激战数小时，匪军退，驻长春日飞机两架，13日飞往，助匪军反攻。25旅一部13日绕近匪军后方，在临兰县境发生激战。日铁甲汽车队往增援，飞机多架亦飞往。（15日专电）

  • 1932年1月16日《申报》：哈尔滨息，张作相旧部张作舟，13日在舒兰与吉林熙洽军已发生战事，义勇军参加战斗颇烈。日本飞机前往掷弹援助，死伤甚众熙洽代表金武宣来哈，与张景惠协商调解中。双城县亦闻枪炮声，传系张作相旧部苏德臣与熙洽军交战。（15日专电）
