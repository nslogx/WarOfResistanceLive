1932年01月15日

发表于 2021-01-15 更新于 2021-05-03 分类于 局部抗战(1931-1937)

  • 1932年1月15日讯：湖北天门县长刘赓飏率天门、应城、汉川三县地主武装及军队一团，进犯芦家口红军，全军覆没，刘被活捉。

  • 1932年1月15日讯：上海市长吴铁城奉国民政府令，与沪金融界代表会商财政问题。吴称，现中央军费每月减到1600万元，政费减到200万元，合计1800万元，每月仅收入700万元，不足1100万元，请金融界设法协助，以两个月为期。协商未获结果。

  • 1932年1月15日讯：国民政府令：京沪卫戍司令长官蒋光鼐未到任以前，着京沪卫戍司令长官公署参谋长邓世增暂行代理。

  • 1932年1月15日讯：驻美公使颜惠庆启程赴日内瓦，代施肇基出席国联理事会议。

  • 1932年1月15日讯：日军村井旅团占阜新，向新邱推进，为骑三旅及义勇军击退。

  • 1932年1月15日讯：行政院第四次会议决议组织国难会议筹备处，由李文范、陈公博、段锡朋、叶恭绰、罗文幹、马超俊、吴铁城负责办理，李文范任主任。

  • 1932年1月15日讯：于右任赴香港促胡汉民入京。

  • 1932年1月15日《申报》：青岛息，日侨14日午后1时，又在居留民团开会到数百人，会议内容未悉。闻15日仍继续开会，日报对日暴徒烧毁市党部捣毁民国日报事，诬我国学生所为，但欧美人均明真相。（14日专电）

  • 1932年1月15日《申报》：北平息，通辽到大部日军，携坦克车，将向开鲁进击，该地蒙匪猖獗。彰武附近被我拆毁铁道数里，新立屯日军大部到援，入混战状态，韦新告急，张树森旅一团，督义勇军一路驰往新邱，防堵锦朝线日军前进。（14日专电）

  • 1932年1月15日讯：东北民众反日救国会电国民党中央暨国民政府，陈述东北民众义勇军抗日情形，请予协助弹械。

  • 1932年1月15日《申报》：北平息，锦西方与我军鏖战之依田旅团主力部队，以多数飞机掩护，一度攻入锦西城内，正在纵火。顷其松尾辎重队突为义勇军包围，迎头痛击，俘获辎重弹药甚多。依田旅团主力退出锦西城，古贺联队亦退到锦补充，其队长古贺大佐确战死。我军及义勇军连日苦战，伤亡达四百余人，…

  • 1932年1月15日讯：江苏高邮筑堤工人因反对政府克扣救灾筑堤款项，剥削工人，举行罢工。

  • 1932年1月15日《申报》：北平息，北镇锦西前经义勇军一度克复，嗣日军大部步骑炮队及飞机援应。义勇军因子弹后援均缺被迫弃城，日军二次攻入锦西县城，放火屠戮，民众死者无算，城内民房多被焚毁。（14日专电）

  • 1932年1月15日《申报》：北平息，日方13日午由南满路运来朝鲜军五千余名，即转向北宁路新民方面进攻饶阳河方面之义勇军。14日晨饶阳河白旗堡均剧战。（14日专电）

  • 1932年1月15日《申报》：北平息，室师团主力军昨拂晓以空军炮兵掩护，向义县猛攻。我骑三旅及步19旅一部，会同义勇军死守，并在城南泥家子地方，筑坚固战壕，鏖战颇久。室师团又加派大批坦克车攻我两翼，日机及炮队并向城内轰炸，我军受巨大压迫，退守朝阳寺，依田旅团一部开至义县四郊驻扎，……

  • 1932年1月15日《申报》：北平息，日室师团由沟帮子派出生力军二千人，甲车两列，飞机八架。14日晨反攻打虎山，与义勇军在高山子一带接触，日机分在大通路乱掷弹，扰乱义勇军后方。打虎山站台房屋及门楼，均被炸毁。（14日专电）

  • 1932年1月15日讯：行政院副院长陈铭枢飞杭晤蒋介石，携孙科敦促蒋出山函，词意恳切，蒋为动容。

  • 1932年1月15日讯：中国共产党为反对日本帝国主义占领锦州，发出《中国共产党为反对日本帝国主义占领锦州号召民族的革命战争的宣言》，号召全中国人民进行民族革命战争。

  • 1932年1月15日讯：国民党中政会特务委员会在中央党部召开第一次会议，讨论对日外交问题。要求国联援用会章第十六款，对日施行经济制裁，由外交部电颜惠庆秉承办理；对日取不妥协态度，以保障领土主权为原则。

  • 1932年1月14日讯：上海农、工、商、学各界举行联席会议，通过一系列抗日主张，决定17日开市民大会，并实行罢课、罢市、罢工、罢税、罢岗、罢操。

  • 1932年1月14日讯：旅京华侨抗日救国会召开救国大会，通过请政府克日调遣大军收复东北失地、对日绝交宣战、宣布对日外交方针等项要求。

  • 1932年1月14日讯：伍朝枢电林森请辞司法院长职。

  • 1932年1月14日讯：张学良在北平召集华北各将领商震、宋哲元等会议，讨论华北治安、财政及各军缩编减费等问题。

  • 1932年1月14日讯：外交部发表复美国公使照会，称中国政府本主权独立及领土、行政完整之原则，绝无与日本订立任何条约之意。望美国政府继续增进国际公约之效力，以保各国际公约之尊严。

  • 1932年1月14日《申报》：青岛息，日水兵600名，12日晚12时，武装登岸，分布日领署及居留民团等处。日侨13日午后3时，仍在民团开会，讨论继续暴动。民国日报、国民通讯社，内部被毁殆尽，不能发刊。（13日专电）

  • 1932年1月14日《申报》：北平息，日军图由锦朝线进犯热河，被我骑兵旅及义勇军，在辽热交界各地阻击后，日军受创颇巨。第一路经通辽大道入开平，二路由彰武顺大道入绥东，三路由黑山经新立屯入阜新，期联成一气。10日已开始行动，其一路由南满路四洮路输送厚兵，进击通辽。打通线我义勇军在万人以上…

  • 1932年1月14日《申报》：锦西电，应援锦西日军之户波支队，11日早7时入锦西城，与足立支队及古贺骑兵联队合队。城中各处，一时火起，约一千义勇军乘机来袭，日军遂被包围，在火焰之中，再陷于苦战。（13日日联社电）

  • 1932年1月14日《申报》：北平息，锦西城内12日忽起火，城外战事转激，义勇军弹尽援绝，难持久。大虎山战事未停，室师团恐后路被断，12日续发后援部队。（13日专电）

  • 1932年1月14日《申报》：天津息，近数日间关外各地义勇军，均与日军作殊死战，敌因地理不熟，受创甚巨。自万家屯到绥中各站日军撤退锦州，山海关日军因兵力单薄，未敢出关接防。我义勇军视死如归，可惜弹药不足。（13日专电）

  • 1932年1月14日《申报》：北平息，打虎山12日被义勇军第四路耿继周千余人克复，日军室师团死伤百数十人，余向沟帮子溃逃。北宁沿线遗弃枪械马匹甚多。现绕阳河、厉家窝铺、打虎山等处全入义勇军第四路势力范围，沈锦间交通已不通。（13日专电）

  • 1932年1月14日讯：外交部照会日驻华公使，就日驻汕头军舰连日向中国军队驻所挑衅；汉口日海军在汉口越界构筑防御工事；青岛日侨聚众滋事，焚毁青岛市党部等情事提出严重抗议。

  • 1932年1月13日讯：上海各民众团体抗日救国联合会成立，出席有沪杭路抗日会、上海革命青年会、上海海员工会等50余团体代表，大会通过电慰东北抗日将士及义勇军等案。

  • 1932年1月13日讯：华北人民抗日救亡会成立，发表抗日宣言，略谓：日本长驱西进，国势日蹙，应唤醒全国上下，共同致力于消弭内战，共御外侮之运动。

  • 1932年1月13日讯：国民政府以财政困难，每月挪用公债偿付本息基金1400万元。上海江海关二五附税国库券基金保管委员会、银钱业两公会、沪市商会，均电国民政府表示反对。同日，北平、天津银行公会分电沪银业公会，请一致主张维持债权基金。

  • 1932年1月13日讯：北平大学七院长徐诵明、虞振镛、程子云、王之相、杨仲子、夏元瑮、白鹏飞，因教育经费困难总辞职。校长沈尹默亦电教育部辞职。

  • 1932年1月13日讯：湘省主席何键电中央索军政欠款，请速汇10—12月补助费60万元，并拨还省库垫用军费500余万元。

  • 1932年1月13日讯：行政院通令各部、会，国家财政困难，“一切应采用紧缩政策”。财政部长黄汉梁、次长林康侯因财政困难，无法解决，分别向国民政府提出辞职。

  • 1932年1月13日《申报》：青岛息，12晚9时半，日暴徒用火酒火油焚烧市党部全部。第四分驻所办公室捣毁，沿马路放枪。（12日专电）

  • 1932年1月13日讯：熊希龄、马相伯、章太炎、张一麐、沈钧儒等代表中华民国国难救济会通电国民政府主席林森、行政院长孙科及蒋介石、汪精卫、何应钦、胡汉民等，略谓：“事至今日，诸公倘犹认救国全责可由一党负之，则请诸公捐除一切，负起国防责任，联合全民总动员收复失地，以延国命。 …

  • 1932年1月13日《申报》：青岛息，12晚7时半，日国粹会员数百余人，由日本神社出发，沿中山路狂呼，无若旁人，驰赴居留民团，有准备暴动模样。欧美街侨民因情势严重，12晚假万国总会开会，讨论预防办法。（12日专电）

  • 1932年1月13日讯：蒋介石由奉化抵杭州，14日在杭对记者发表谈话，声称“汪、胡如能推诚入京，余虽身在诟谇之中，为党为国，也无不乐从其后”，“惟熟审政治之环境，以及最近之事实，实鲜余个人负责之余地，故不得不仍以在野之身，尽个人职责”。

  • 1932年1月13日《申报》：北平息，锦西日军为我义勇军耿继周部及其他部队，重重包围，室师团主力援军虽到，无法突入。日兵被杀极多。锦州日机悉数向红螺山出发轰炸。（12日专电）

  • 1932年1月13日《申报》：北平息，打虎山义勇军连战连胜，10日日兵车一列出轨，损伤颇巨。新民日军全数出动，沈阳11日有兵车13列，开往锦州、打虎山等处。（12日专电）

  • 1932年1月13日《申报》：北平息，日军陷锦后，大部遇义县南朝民军三千余众，10日在朝阳寺与日军激战。我民军首领毕景山、张梦麟率部与日军血战5小时，因日机胁迫，9日退骆驼沟北，与张树森旅已取联络，尚在激战中。敌方伤亡甚众，惟弹药将尽，无法接济。（12日专电）

  • 1932年1月13日讯：孙科、冯玉祥等自沪至南京，开始组织国民党中政会特务委员会，在中政会党务委员未到京前，负责处理“中央各紧急政务”。

  • 1932年1月13日讯：张学良电促蒋介石、汪精卫、胡汉民入京，略谓：“人望不可以屡辜，时会不可以再逸”，“宜及此政本未摇，余势犹在之际，集全党领袖于一堂，奋其智勇，以定安攘之策，则桑榆之效，或尚可收，沦胥之祸，其犹得免。若更分崩离析，或貌合神乖，信用一失，断难再复。”
