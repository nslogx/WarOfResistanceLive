1932年05月22日

发表于 2021-05-22 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年5月22日讯：徐源泉返汉，就任鄂省清乡督办。

  • 1932年5月22日讯：上海《时事新报》工潮仍未解决，被开除工人推代表与该报经理熊少豪谈判，无结果。

  • 1932年5月22日讯：上海各团体救国联合会电监察院长于右任，对其弹劾汪精卫违法签订上海停战协定案表示支持。

  • 1932年5月22日讯：吴铁城在沪市府接见邮务职工代表张克昌等四人，劝邮工即日复工，然后再商办法。

  • 1932年5月22日讯：胡适、丁文江、蒋廷黻等创办《独立评论》周刊，胡适为总编辑。是日创刊号在北平出版。

  • 1932年5月22日讯：上海邮务工人大罢工。上海邮务工会、上海邮务职工会以该会等提出巩固邮基方案未被交通部接受，令沪市3500余邮工今起大罢工。《罢工宣言》略称：“本会等所拟巩固邮基方案，为救邮之唯一良箴，本会一再电催，交部乃迁延至今，竟未容纳，群情愤激，无由遏抑，认为非实行最后行动，不足以促当局之猛省。”23日，沪邮工罢工风潮扩大，沪设临时邮局，邮政总局局长钱春祺因邮务工潮被看管。

  • 1932年5月22日《申报》：哈尔滨息，反满军进攻松浦与哈尔滨，未能得手，现向呼兰方面退却。日军追逐其后，安达站与甜草岗之反满军，现亦在退却中，估计日人在哈尔滨附件战争中死伤逾三百。（21日路透社电）

  • #抗战影像#伪满洲国发行的明信片，主题是“哈尔滨的夜色”。

  • 1932年5月22日讯：自卫军左路军发生内讧，第二旅旅长刘万奎因物资分配和攻坚任务分配等事由对总指挥兼第一旅旅长马载舟怀恨在心，利用其在马桥河指挥部开会之际，将马载舟活活勒死，左路军随即分崩离析。

  • 1932年5月22日《申报》：南京息，回国参加十九路军与日作战之旅日华侨徐香进，曾于二月二十八日，在南翔被日机炸毙。翁泓兴、叶公正二人在战场染受重病，到京医治无效，先后身殁。刻侨委会已咨询军政部抚恤，该殉难之同志，均浙籍。（21日专电）

  • 1932年5月22日《申报》：北平息，沈电，日人对东北计划，传系采用四种步骤：1）分政，即分离各政权，使投降之官吏，亦不得悉其底蕴；2）裁官，即将投降之官吏，逐渐裁汰，而添用日本官吏，现正在进行此二步骤中；3）移民，先将朝鲜及日本人民逐渐移来，藉政治势力而收买侵占，以操土地所有权；4）逐民，移民既有根基，即将所有我国农民，逐于荒野未开之区。（20日中央社电）

1932年05月21日

发表于 2021-05-21 更新于 2021-09-09 分类于 局部抗战(1931-1937)

  • 1932年5月21日讯：长江水位连日陡涨，是日达35尺。

  • 1932年5月21日讯：陕、甘霪雨、黑霜成灾，灾民达数十万，杨虎城电国民政府请急赈。

  • 1932年5月21日讯：国有七铁路工会联席会发表告全国铁路工友书，并电国民政府，要求以武力收复东北失地。

  • 1932年5月21日讯：上海市长吴铁城约邮务工会、职工会、邮务长、总局长等在市府谈话，谓储金汇业局归并及取消邮航津贴问题，涉及国家行政制度，不能随意变更，更不能以罢工要挟。

  • 1932年5月21日讯：何应钦令湘、粤、赣三省军队“会剿”红军彭德怀部。

  • 1932年5月21日讯：蒋介石令第十九路军开赴福建，参加“剿匪”战争。

  • 1932年5月21日讯：行政院决议：拨国币两万元汇法，遣送失业华工回国。又拨一万元汇驻荷兰领事馆接济失业华工；公布修正《沪撤兵区域接管委员会组织条例》。

  • 1932年5月21日《申报》：哈尔滨息，松浦阵线，战事未已。昨闻反满军渐后退，此间犹偶闻炮声，横道河子东面桥梁四座，昨日被毁。（20日路透社电）

  • #抗战影像#日本发行的宣扬日军士兵与伪满洲国百姓友善相处的明信片。

  • 1932年5月21日《申报》：哈尔滨息，李顿调查团因中东路西段反满军密布，恐有危险，兹已将原定明晨赴齐齐哈尔之行作罢。惟该团仍可由该区域觅得情报，因团中有专家10人将由哈尔滨乘飞机前往齐齐哈尔调查该处情形也。调查团已定星期六日由此遣返沈阳。（20日路透社电）

  • 1932年5月21日《申报》：哈尔滨息，此间顷得报告，谓齐齐哈尔至满沟之区域全部，为马占山占领，但马之主力军仍在克山及讷河一带。传有华军数大队，刻向中东路西段推进。闻李海青在满沟之司令部，被日机炸毁，参谋长李某及其他八人，均被压毙。（20日路透社电）

  • 1932年5月21日讯：真如日军撤退，由沪保卫团进驻。接管委员会预备会议决定本月23日上午11时接收真如。

  • 1932年5月21日讯：监察院长于右任弹劾行政院长汪精卫违法批准上海停战协定，不交立法院审查，呈中监会请予惩戒，内称：国府组织法规定，立法院有议决宣战媾和及其他重要国际事项职权，沪停战协定未闻送立法院议决，遽行签字，“设不严予惩处，则以后国家主权、疆土有此成案可援，皆将断送于协定二字之下”。

  • 1932年5月20日讯：沪邮务工会因所提归并汇业局、维持旧邮资、停止邮航津贴、改善邮务管理四项要求，为交通部批驳，本日开会决议采取直接行动。

  • 1932年5月20日讯：国联调查团长李顿请苏联政府签证护照，准团员由中东路取道西伯利亚铁路至海兰泡渡江至黑河访马占山。苏外交部门以严守不干涉政策拒绝。

  • 1932年5月20日讯：上官云相自浔乘飞机到京，向蒋介石报告在赣“剿共”情况。

  • 1932年5月20日讯：上海停战共同委员会日方委员冈崎正式通知中方委员俞鸿钧、温应星，决定于本月23日上午11时将杨行、狮子林炮台、炮台湾营房以及三官塘火药库方面之日军完全撤退。

  • 1932年5月20日《申报》：北平息，伪警组织，设总队一，内分三小队，下又分五分队。大队计二百人，中有日鲜十之九，华人约四十人。总队长为日人松山，分队长皆日鲜人，华人最高仅充班长。（19日专电）

  • 1932年5月20日《申报》：秦皇岛息，路透社今日得报官场消息，驻山海关之何柱国旅长，曾因日人无故炮击山海关，提出抗议。但日人迄未说明其炮击之理由，山海关现尚宁静。（19日路透社电）山海关息，榆关今日无事，沈变后临榆县党务工作，无形中限于停顿中。17日有徒手日兵擅入党部内，搜去宣传品一束。（19日专电）

  • #抗战影像#伪满洲国明信片，主题是“哈尔滨的夜色”。

  • 1932年5月20日《申报》：南京息，据可靠方面消息，马占山之抗日军事行动，极称顺利，日军曾数度被窘。马现得华侨赠送飞机数架，参加作战，龙江之兵工厂已迁移黑河。闻马最近购置军械颇多，尚待证实。然马于未反正时，确由日方取得军械，马之军队约四万人，步炮骑兵俱全，尚有飞机一队，野 炮二十尊。文马之军队军容甚整，军械充足，且得民团及义勇军赞助，人数渐增。（19日路透社电）

  • 1932年5月20日讯：自卫军中路军在后援尽失的情况下决定仍前往哈尔滨，进抵阿城，料甸子地区，并于总司令部和先期到达的冯占海部完成联络，遂在此集结等待左路军的到来。

  • 1932年5月20日《申报》：接管委员会，昨晨派员赴江湾，接收江湾淞沪铁路以西之区域，该处日军共二百余人，于昨晨11时一刻，完全撤退，双方于11时零5分交替。我方5区5所长戴鸿恩，于昨晨率警，会同平保安队前往，午时已布置就署。消防保安两组，亦即恢复，并实行清查户口，教育局亦派员前往接收各学校。此外我方又派员于昨晨接管彭浦，并于昨晨10时，日方在北站交还俘虏。

  • 1932年5月20日讯：沪撤兵区域接管委员会召集有关各方举行联席会议，会商接管闸北铁路以北区域办法。

  • 1932年5月20日讯：《再生》月刊在北平创刊。张君劢、张东荪、罗隆基等创办。宣传“国家社会主义”，中国国家社会党成立后为其机关刊。

  • 1932年5月20日讯：河南鹿邑、柘城两县春荒，粮食告竭，死亡枕藉，惨不忍睹，鹿邑县设人市五处，幼女不值10元，幼童仅易1000文，孩提婴儿抛弃遍地。

  • 1932年5月19日讯：行政院会议，陈铭枢、陈公博相继报告在沪与孙科接洽情形；决议设立全国水利委员会。

  • 1932年5月19日讯：考试院副院长钮永建对《申报》记者发表关于考试问题的谈话，称：“俟国难问题解决，当厉行考试制度，拔取真才。”

  • 1932年5月19日讯：马占山旧部柴鸿猷率部向克山进攻，与日军激战一天多，予敌较大打击。

  • 1932年5月19日讯：江湾日军于上午11时许完全撤退，由我方自北平调沪之保安队第三中队接防。彭浦、庙行亦均由我方派警进驻。江湾日军撤退区域，仅余瓦砾。

  • 1932年5月19日《申报》：北平息，榆关电，驻榆日守备队松下，今下午访问何柱国谈二小时。内容如下：1）以前误会设法接触；2）盼报纸对榆事勿扩大；3）长城内如伪警与我警冲突时，双方解除武装，再交涉；4）长城外属关东军，如发生事件，驻榆守备队不负责；5）榆关治安中日双方共同维持。（18日专电）

  • #抗战影像#日本大石田合同运送株式会社在伪满洲国发行的股票。

  • 1932年5月19日《申报》：哈尔滨息，日广濑师团，今晨八时占领松花江下流之依兰，该团司令部即移入城内。（18日路电通社电）

  • 1932年5月19日《申报》：东京讯，李杜军队为沿松花江而下之日军所迫，决定放弃依兰，而向东省与西比利亚边界附近之富锦退走。昨晨退出时，将日侨35名杀死，中村旅团入城后，发现被杀日侨之尸身。日本军事当道，以为日军之占据此城，乃一重要胜利。（18日路透社电）

  • 1932年5月19日讯：中华民国国难救济会通电全国，否认上海停战协定，略称：“协定第二条规定我国军队在常态恢复未决定办法以前，暂驻现在地位，等于设定暂时不驻军队之区域”；“协定未经立法院议决，在我现行国法上未具备有效条件，不得认为已生效力，我国家殊无受其拘束之理由。”

  • 1932年5月18日《申报》：东京讯，据哈尔滨访电称，“满洲国”当局与李顿调查团已因马占山问题，发生冲突。调查团拟往晤马，询其意见并采取渠所能供给之任何证据，而“满洲国”当局则反对调查团前往晤马，访电又称，“满洲国”当局指顾维钧博士作政治活动，扬言拟加逮捕。（17日路透社电）
