1932年11月10日

发表于 2021-11-10 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1932年11月10日讯：罗文幹派谢冠生飞汉，向蒋介石报告国联最近主张成立国际委员会，解决中日纠纷，请示应付机宜。同日，外交委员会研讨国联国际委员会讨论中日问题时应取之方针。

  • 1932年11月10日讯：北新书局因出版《小猪八戒》一书，激起沪市回民公愤，除遵照书业公会决定登报向全市回民道歉外，是日并自动宣布停业。

  • 1932年11月10日讯：东北民众救国军在富拉尔基以西腰库勒歼日军原冈轻机枪队，后被迫退至碾子山。

  • 1932年11月10日讯：全国各界救国团体联合会电国民政府反对续购美麦，称“若再续贷美麦，则国内粮食价格将更形惨落，已呈破产之农村经济，必将陷于万劫不复之途”。

  • 1932年11月10日讯：张学良飞汉晤蒋介石，面商东北、华北问题，并协议海军接防烟台、龙口。12日飞杭，16日复飞汉见蒋。

  • 1932年11月10日讯：何应钦加派毛炳文部陶峙岳、许克祥两师到闽“会剿”红军，陶师前锋逼近光泽。

  • 1932年11月10日讯：刘湘、刘文辉两军主力在泸州、内江一带决战。

  • 1932年11月10日讯：金日成领导的安图游击队和汪清抗日游击队、宁安抗日游击队合并，扩编为汪清抗日游击队，梁成龙任大队长，金日成任大队政委。

  • 1932年11月10日《申报》：北平息，唐聚五通电，请息止内战，使国难早除。（九日专电）

  • 1932年11月10日《申报》：北平息，唐聚五部暂退濛江一带后，近来日方节节压迫，士气极激昂。总司令部及附属各机关，暂设濛江，从事联络友军，再图进展。其辽东海龙金川抚松等县，双方尚有激战，唐氏亲在濛江指挥督战。（9日专电）

  • 1932年11月10日《申报》：北平息，辽吉黑民众后援会军息，顷据吉林特务专员电称，日方于上月26日派遣护路军500名，经王德林部吴义成率领义勇军千余名，在某地（电码不明）设伏截击，用手榴弹击中敌车汽油，当时爆发，日军逃逸，复被伏兵包围激战。经日全部歼灭，是役计获敌机枪九挺，步枪九百五十余枝，山炮二门，迫击炮四门，子弹十二箱。本月四日王部已占领横道河子，日逆两军伤亡二百七十余名，王部死伤七十余名，刻向淇河进发等语，特闻。（9日专电）

  • 1932年11月10日《申报》：山海关息，锦州北亮蓬山附近义勇军，前曾一度袭锦，现据守待机。5日，日机复往轰炸附近之杂木林子村歪脖树庄，均被焚毁，义勇军士气仍极兴奋，誓死抗敌。（9日专电）

  • 1932年11月10日《申报》：北平息，马占山4日电平称，讷河县城，1日午突来敌机三架盘旋数周。翌日复来大批敌机，向民房投重量炸弹，计20余枚，并施放毒气弹，意存屠杀净尽。查日军此种残忍手段，违反国际公法，实属惨无人道，务请迅向中外宣布，俾明真相。（8日专电）

  • 1932年11月10日《申报》：北平息，辽吉黑民众后援会军息，顷据哈尔滨专员电称，安达站某部（电码不明）“满洲国”军六千五百名，因痛日军残暴压迫，已于本月6日全部反正。刻与苏炳文部联合，向日军进攻，日军恐慌，有后退模样。北满商业全停，日军仅统辖中东路东段以女儿河为止，西段以富拉尔基为止。日方因兴安玲华军阵地强固，且满军又多反正，故嫩江桥之进攻暂停。李杜、丁超刻在吉北黑东建设新政府，并自发行纸币等语，特闻。（9日专电）

1932年11月09日

发表于 2021-11-09 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1932年11月9日讯：东北抗日救国军苏炳文部在齐满路连日与日军激战。

  • 1932年11月9日讯：张发奎由香港乘意轮“干德华地号”赴德国。

  • 1932年11月9日讯：刘文辉电蒋介石，请制止刘湘进逼，略称“川战突起，辉遵奉中央迭令，始终力避冲突，让防已达十数县，辉部十余万众，今已局促一隅，再退无地。刘湘近且躬赴前方指挥战事，泸富尤在必争”，“刘湘处心积虑，不至兵连祸结不止”。

  • 1932年11月9日讯：闽省府召集党、政、军及银行界代表开联席会议，讨论东省财政救济办法，决组财经委员会，推詹调元、陈培锟、何公敢等为委员。

  • 1932年11月9日讯：内政部规定禁止蓄奴养婢办法，不论以买卖、赠与或慈善关系而蓄养者，均予禁止，违者以“使人为奴隶罪”送司法机关办理。

  • 1932年11月9日讯：行政院令上海市府查封北新书局，令南京市府转饬《南华文艺》停刊，并批示华北及上海回教请愿代表知照。

  • 1932年11月9日《申报》：哈尔滨息，据可靠消息，富拉尔基方面之义勇军，势力极为雄厚。闻义勇军中有张毓庭（译音）部下之正式军队四千、义勇军三千，此外尚有来历不明之军队一千名。彼等皆臂有白色标志，似为蒙古军队，或布加人云。西屯（译音）附近之中东路轨，为义勇军拆毁，今晨该地有货车一列出轨，倾覆但尚无人员死伤。今晚交通即可恢复，按西屯在哈尔滨南60里云。（7日路透社电）

  • 1932年11月9日《申报》：北平息，驻安达县城内伪军第三旅第52团段自新部，受黑军郑文之忠告，3日反正，占领安达，该团日顾问北部大尉闻讯逃窜。（8日专电）

  • 1932年11月9日《申报》：北平息，东边自卫军王凤阁函平报告，实行反攻后，2日克复海龙城，日甲车倾覆，伤亡无算。（8日专电）

  • #抗战影像#在我东北某地，日本殖民开拓团员正在用机器为收获的稻谷脱粒。

  • 1932年11月9日《申报》：北平息，据濮炳珊5日电称，日飞机三架，由卜奎飞向安达、宁年、克山侦察，遇飓风，一机跌落，全机被焚，驾驶员三人毙命。连日狂风严寒，日军不敢冒寒动作，我军正严阵以待。（8日专电）

  • 1932年11月9日《申报》：北平息，苏炳文6日电报告，我部一、二两旅一万人，沿泌淋河上游，向碾子山、朱家岗、腰库勒等处推进，包围富拉尔基。当在朱家岗、腰库勒，与敌中山支队二千余，激战一夜之久，敌死亡甚重，我军略损失。敌军向麻菇溪退却，我军尾随追击，并向富拉尔基推进。（8日专电）

  • 1932年11月9日《申报》：天津息，市整委刘不同，决心出关，领导义勇军杀敌，8日晚宴亲友朋客告别。（8日专电）

  • 1932年11月8日讯：行政院发布保护宗教通令，内称“以后各种刊物，对于任何宗教，不得稍存侮视”。

  • 1932年11月8日讯：康、藏纠纷经年，血战已达半载，是日西康代表康军旅长邓蟠村与藏方代表琼让代本在西康正式签订《康藏停战协定》，规定双方防地以金沙江为界，不得互相侵犯，“所有历年康、藏一切悬案，听候中央与达赖解决”。

  • 1932年11月8日讯：在朱德、周恩来指挥下，红一方面军克光泽。

  • 1932年11月8日讯：阎锡山通令山西各军警机关及各县政府“缉拿”共产党人。同日，国民党在上海破坏中共设立之“互济会”机关，并捕共产党人韩葆春等二人。

  • 1932年11月8日讯：法使韦礼敦到京，与外长罗文幹会商中法越边商约问题。同日，罗文幹宴越南回国请愿实行《中法越南专约》之华侨代表黄安、许亦鲜等，席间商谈《中法越南专约》问题。罗允请法使转促法政府依约实行。

  • 1932年11月8日讯：行政院会议决议将招商局收归国营。9日国民党中央政治会议通过。

  • 1932年11月8日《申报》：北平息，濮炳珊军三千，在泰安镇东五里，与日军黑田耘村两部激战5小时，敌大溃，获野 炮迫击炮各五门，弹药九箱，即准备攻泰安。（7日专电）

  • 1932年11月8日《申报》：北平息，沪各民众团体捐助关外义勇军棉衣数万套，由义勇军代表领收，已运至关外过半数，为日军探悉，在白庙子图劫掠运输之物，被义勇军击退，棉衣无损失。（7日专电）

  • #抗战影像#在雪地里运送军需品的日军辎重队。

  • 1932年11月8日《申报》：北平息，义勇军百余名，5日夜攻双羊店，将路轨掘毁，拟倾覆伪奉山路车，为日方察觉，当派铁甲车攻击义勇军，激战数十分钟，义勇军向大凌河引退。（7日专电）

  • 1932年11月8日《申报》：北平息，龙门镇马占山行辕电称，马前赴讷河嫩江杨家宅各地，与各军师旅长商军事方略，刻转前方，在拉哈附近指挥徐松两旅及南廷芳部，猛攻拉哈残敌，士气极壮，才鸿猷部攻海伦，形势顺利。（7日专电）

  • 1932年11月8日讯：宋子文由京飞汉口，9日与戴季陶等晤蒋介石，商内政、外交及鲁、川内争解决办法。

1932年11月07日

发表于 2021-11-07 更新于 2022-02-27 分类于 局部抗战(1931-1937)

  • 1932年11月7日讯：翁文灏函宋子文辞教育部长职。9日，朱家骅兼理教育部部务。

  • 1932年11月7日讯：国民党湖北省执委会电请国民党中央依法严办陈独秀。

  • 1932年11月7日讯：为防止共产党纪念苏联十月革命十五周年和中华苏维埃政府成立一周年，军政部通令各省、市严予防范。南京、上海、北平严密戒备。北平、上海等市共产党人张贴“打倒国民党，加入共产党”、“庆祝红军胜利”、“拥护苏维埃政府”等革命标语，散发《中华苏维埃告工人书》、《苏联十月革命宣传大纲》等革命传单。上海租界有工人、学生集会，被捕探逮捕六人。

  • 1932年11月7日讯：国民党中委谈话会讨论处分刊登侮辱回教文字案，佥主查封上海北新书局，将登载讽刺回教徒文章之《南华文艺》停刊，依法惩办作者，并通令全国，此后严禁刊布侮辱任何宗教之文字。

  • 1932年11月7日讯：何应钦电令刘珍年调鄂中“围剿”红军。韩复榘军开始向潍河以西撤退。8日，沈鸿烈所部东北海军“海琛”、“楚豫”、“镇海”等舰接防烟台、龙口，并布告安民。

  • 1932年11月7日讯：中华苏维埃共和国临时中央政府为成立周年纪念发表宣言，号召全国工、农、兵、学及一切劳苦群众，驱逐日本及其他帝国主义出中国，粉碎四次大“围攻”，推翻国民党和帝国主义在中国的统治，彻底争取中华民族的真正独立和解放。

  • 1932年11月7日《申报》：北平息，救国军部参谋处4日电平云：1）东路濮炳珊3日晨率宋徐两部，向杨屯出动，与敌骑兵支队激战甚烈，互有伤亡。3日晚我先头部队进抵十里堡，向宁年推进。2）南廷芳率部攻进拉哈，沿铁路向西进攻。3）我部已进至富拉尔基附近地点，右路李忠义部侧攻安达，敌甚恐慌。（6日专电）

  • 1932年11月7日《申报》：北平息，锦西电称，东北民众救国军三十二路二十二支队部杨雪门队长，于3日夜12时，攻打锦西，血战一昼夜，将锦西北门攻破。日军用飞机6架，在空中掷炸弹24枚，同时日以一部将我军包围，幸我第一支队陈琪部由南门攻入，与我军会合夹击，近身肉搏，敌不支溃退。是役计毙敌19名，获弹药无算，我军伤亡20余名，仍在血战中。（6日专电）

  • #抗战影像#“一·二八事变”中，一辆日本陆军的八九式中型坦克在上海街头横冲直撞，准备冲向中国守军的防线。

  • 1932年11月7日《申报》：北平息，救国军董荣久部第二支队司令侯璧峰，6日拂晓率部千八百余名，及第三旅曹振国部千五百余名，进攻锦西虹螺岘，与日军五百余名激战，肉搏六时许，卒被我军克复。敌伤亡颇众，我阵亡少校营附赵宝珍一名，兵三名，负伤十名，获军用品甚众。（6日专电）

  • 1932年11月7日《申报》：北平息，吉救国军王德林部集中横道河子，日军派飞机20余架掩护步兵攻击，激战中日军被攻下七架（注：原文如此，存疑），双方死亡均重。日军溃退，王派所部沿吉敦线向吉林进攻，前锋已达距吉林省城四十里之江蜜蜂地方，双方仍相持中。吉林已降大雪，王部衣弹两缺，作战艰难。吉敦路前被王部破坏甚多，日方正赶修，王部拟俟日军修复后，再大举破坏。（6日专电）

  • 1932年11月7日《申报》：北平息，救国军耿继周部千余人，30日晨进攻白旗堡，激战数小时。日伪军溃退，当占白旗堡，一日向饶阳河进攻，至小白旗，与日伪援军相遇，激战数小时。敌溃退，该部追击至饶阳附近，有日伪援军千余增援，我军未再追击，刻正准备进攻饶阳。（6日专电）
