1932年02月10日

发表于 2021-02-10 更新于 2021-08-02 分类于 局部抗战(1931-1937)

  • 1932年2月上旬：新加坡华侨成立“救济上海伤兵难民筹赈委员会”，中华总商会负责人李俊承任主席。

  • 1932年2月10日讯：香港东华医院筹款赈济一二八淞沪战役中的难民。

  • 1932年2月10日讯：陈独秀主持“托派”常委会议，起草通过《政治决议案》。

  • 1932年2月10日讯：中共河南省委书记肖云鹄上年在开封被捕，是日在洛阳就义。

  • 1932年2月10日讯：第十九路军将领蒋光鼐、蔡廷锴、戴戟通电海内外同胞，请援助抗日。

  • 1932年2月10日讯：第十九路军通电全国，响应财长宋子文2月7日关于“停止借用国税，悉数解部，平均分配”的通电。

  • 1932年2月10日讯：上海各团体救国联合会代表市商会等81个团体及300万民众，向公共租界工部局提出抗议：一、公共租界所驻军队应限于中立国，所有日军应扫数驱除；二、日军不得利用租界登陆，亦不能退避租界。

  • 1932年2月10日讯：沪前线战事沉寂。下午1时，日舰以重炮轰吴淞炮台，第十九路军还炮相击，至4时始息。日机两度在闸北投弹。入晚宝山路口有激战，战一个半小时日军被击退。

  • 1932年2月10日《申报》：香港息，粤空军第二中队长丁纪徐请缨援沪已准，定十日晨率战机九架出发，各要人准备到场欢送。（9日专电）

  • 1932年2月10日《申报》：上海息，自日寇犯沪以来，市国术馆因处于战区之内，所有各员，皆担任临时救护工作。兹闻该馆主持人员，拟召集本市国术团体，组织大刀队及长枪队，协助军队与敌肉搏，以贯彻锻炼国术之初衷，闻长枪辅以大刀，其功效益当显著云。

  • 1932年2月10日讯：军政部长何应钦派陆军步兵学校校长王俊同驻沪日使馆武官田代皖一郎少将在沪密淡中日停战。王电何称：“田代对于双方撤退，及我派警察维持中间地区治安问题，无甚反对意，但恐实行困难。盖以济南、天津两处成案为例，疑我无法防止便衣队与反 动分子暗中活跃惹事之故。” …

  • 1932年2月10日讯：日军在汇山码头屠杀华工百余人，斩首级运往日本，以示侵沪“胜利”。对此，沪市商会派代表请公共租界工部局制止。

  • #抗战影像#1932年“一·二八事变”中，作战中的日本特别海军陆战队

  • #参战装备#荷兰哈以哈HIH75毫米步兵炮（二）：出口给中国军队的型号被称为M30型哈以哈75毫米步兵炮。该炮采用横锲式炮闩，炮弹为半固定分装式，有四种可变装药，最大装药炮口时初速为230米/秒 ，最大射程可达3.7公里。机动方式可以采用一匹骡马进行拖曳，或分解为四部分由骡马驮运，八部分由人力背运。

  • 1932年2月10日讯：粤空军将领张惠长、黄光锐等通电援沪，第二中队长丁纪徐率飞机一队共七架自广州出发。

  • 1932年2月10日讯：何应钦在报请蒋介石同意的情况下，派军政部次长陈仪和陆军步兵学校校长王俊同日军第九师团参谋长（原日本驻沪使馆武官）田代皖一郎少将谈判，意图谋和。

1932年02月08日

发表于 2021-02-08 更新于 2021-08-02 分类于 局部抗战(1931-1937)

  • 1932年2月8日讯：马占山往哈尔滨秘密会见日军师团长多门，提出黑龙江省不设日本顾问的自治问题。多门请示本庄繁，得到“只要不打仗，诸事都好办”的承诺。

  • 1932年2月8日讯：吉林自卫军总司令李杜通电全国，报告因作战失利，由哈尔滨退守宾县经过，并谓已在宾县与护路军通力合作，组织联合军司令部，整饬部属，再图规复。

  • 1932年2月8日讯：第十九路军驻沪办事处招待报界，对民众各团体纷加慰劳，并予以种种物质之援助，向各界表示谢忱。

  • 1932年2月8日讯：上海租界纳税华人会致函工部局，要求制止日军非刑吊打华人。

  • 1932年2月8日讯：日军久留米旅团自拂晓起倾全力总攻吴淞，截止下午3时，冲锋达十余次，均被第十九路军第一五六旅击败。闸北日海军陆战队向克明路、宝兴路猛攻，遭我伏兵袭击，向横浜桥方面败退。八字桥方面敌进攻未遂，向北四川路方面败退。

  • 1932年2月8日讯：上海各大学教授抗日救国会电盼北方各大学各团体切实督促当地各将领自动抗日，北以援马（占山），南与第十九路军遥相呼应，既可表示举国一致之决心，亦可制止政府犹存两可之态度。

  • #一二八淞沪抗战#1932年2月8日讯：日军在吴淞遭受重创的消息传到东京后，根据日本天皇批准的敕令，日军参谋总长载仁急令陆军第九师团（师团长植田谦吉）火速增援上海

  • 1932年2月8日讯：上海文化界戈公振、陈望道、丁玲、郑伯奇、王亚南、叶圣陶、胡愈之、郁达夫等组织中国著作家抗日会。9日举行第一次执行委员会，推举戈公振任主席，陈望道为秘书长。

  • 1932年2月8日《申报》：天津息，北宁路空车现奉令集中丰台，东北铁甲车队亦奉令赴平训练。六日晚至七日午，有四个中队，共四列甲车，过津赴平。（7日专电）

  • 1932年2月8日讯：日外务省提议，在上海、武汉、天津、广州、青岛各通商口岸，划不驻兵区，向各国探询意见。外长罗文幹发表谈话驳斥日政府此种谬论为“剥夺中国全部生存之自卫权，及独立国一切法律上应享之权利与保障”。

  • 1932年2月8日《申报》：沈阳息，日军司令于占据哈尔滨后，即派兵在城外四周设哨兵线。始终抗日之丁超，现已往呼兰，马占山将军仍在海伦，中东路南端客车，即往来于长春与哈尔滨之间者，昨已照常行驶。（7日路透社电）

  • 1932年2月8日讯：军政部长何应钦致电上海市长吴铁城等，要求从速设法停止战争，称：“此次淞沪事件，弟曾迭电商酌适可而止，盖期早得收束，为国家多留一分元气也。”“目前沪事交涉，如诸同志坚持强硬并依赖国际或列强之帮助，势必纡缓迁延，牺牲我十九路军净尽而后已，不但丧师，抑且失 …

  • #参战装备#日本“能登吕”号水上飞机母舰：1924年由川崎造船所由油料舰改装竣工，排水量12786吨,航速12节,武备120毫米炮和80毫米炮各2门，搭载8架水上飞机,舰员324人。参与一二八事变及抗战初对广东及长江地区作战,1944年末遭美军轰炸重创后作为预备舰,日本投降后由英军接收1947年被凿沉于马六甲海峡。

  • 1932年2月8日讯：国民政府令免李文范内政部长职，特任冯玉祥为内政部长；免叶恭绰铁道部长职，特任汪兆铭暂兼铁道部长；任命陈继承为洛阳卫戍司令。

  • #抗战影像#1932年“一·二八”淞沪抗战中，一处中国军队炮兵阵地，炮手正在操作荷兰造哈依哈HIH 75毫米步兵榴弹炮，向日军准备开炮。

  • 1932年2月8日讯：上海市府通告各国驻沪总领事，请严饬公共租界工部局采取有效办法，制止日军利用租界为攻击中国军队之根据地，并郑重声明：“中国军队为自卫起见，对于利用租界为根据地之日本军队施以进攻时，各国侨民之生命财产受有损失情事，中国政府概不负责。”

  • #一二八淞沪抗战#1932年2月8日讯：日军以炮舰6艘，飞机二十余架向我156旅4团2营阵地猛烈轰击，并以步兵千余人发起冲锋，我军苦战三小时，将敌击退。

  • 1932年2月8日讯：国民党中央执行委员会及国民政府致电慰勉守沪将士，称：“旬日以来，陆军、空军及要塞方面，迭告胜利，敌受重创，寸土尺地，并无失陷，吾将士为国家作正当防卫，为世界维持和平，允为全国、全球所矜式。”

1932年02月07日

发表于 2021-02-07 更新于 2021-08-02 分类于 局部抗战(1931-1937)

  • 1932年2月7日讯：日机轰炸吉林宾县（今属黑龙江省）。

  • 1932年2月7日讯：上海北苏州路招商内河轮船局私进大批日煤，被煤业公会查获。

  • 1932年2月7日讯：闽、赣两省工人代表大会在中央苏区全总执行局召开。中共苏区中央局代表周恩来、临时中央政府代表项英、中央 军委代表叶剑英等先后在大会上致词，周恩来作政治报告。大会选出袁国珍等15人为江西职工联合会执行委员，林松善等13人为福建职工联合会执行委员。13日大会闭幕。

  • 1932年2月7日讯：财政部长宋子文通电苏、鄂、湘、浙、皖、赣、鲁、闽、豫等省当局暨各“绥靖”主任、各总指挥、军、师长等，要求“停止借用国税，悉数解部，平均分配”。

  • 1932年2月7日讯：国难会议会员陶希圣电洛阳林森、汪精卫，主张停开国难会议，谓“国难会议非由民选，不足以集中群力，应迅速召集以普选所产生之国民代表大会，解决国是”。

  • 1932年2月7日讯：第十九路军将领蒋光鼐等通电对海内外同胞给予的精神或物质援助表示感谢。

  • 1932年2月7日讯：磐石县汉族、朝鲜族群众，在中共磐石中心县委领导下分别在8处举行纪念“二·七”大会和反日大会。大会无情地揭露了“保民会”的反 动本质和敌人挑拨离间汉族、朝鲜族群众团结反日的阴谋。并公开处决了一批日本走狗。有两处大会遭到日伪军警的镇压，数名反日群众被捕。

  • 1932年2月7日讯：上海市商会发布公告，劝告各界援款抚恤前敌阵亡将士家属，以慰英魂而励士气。

  • 1932年2月7日《申报》：上海本埠息，前日旁晚5时许，有避难妇人三口一约四旬，两皆二十余岁，行经杨树浦平凉路，被日军所见立用刺刀将该三妇，逐一刺死，并将尸体贮入麻袋，携之而去。

  • 1932年2月7日讯：湘省各界在长沙召开抗日示威大会，到百余团体10万人，通过武力收复失地、慰劳沪军、请海外侨胞助饷等七案。

  • 1932年2月7日《申报》：南京息，空军五日在沪作战，第6队飞机员朱达先带伤下降，适该队副队长黄毓全见事机紧迫，即腾身上机，起飞应战。然该机已受重伤，未及审查，起升不及百尺，即下坠，人机并殉于难，航署已电汇千元抚恤。（6日专电）

  • 1932年2月7日讯：冯玉祥、李济深、朱培德电促在沪粤中委孙科、胡汉民等赴洛“力戡大难，使一般同志有所矜式”。

  • 1932年2月7日《大阪每日新闻》报纸号外关于（第一次）上海事变的报道，包括日军出动重型轰炸机轰炸宝山路中国守军阵地，加贺号航母轰炸机编队轰炸闸北，一千名中国守军撤出青云路柳荣路，在上海中山路作战的日军神川某队，日军对吴淞炮台发起总攻，发生在上海商务印书馆附近的激战等。

  • 1932年2月7日讯：　汪精卫电复上海地方维持会会长史量才4日电称：“政府对日方针，在外交上确保中国主权，尊重国际信义；在军事上严戒挑衅行动，力谋正当防卫。十九路军为正当防卫而战，将士奋勇，克尽厥职，政府爱护不暇，岂有听其孤军失援之理。”

  • #抗战影像#1932年“一·二八”淞沪抗战中，日军攻下一处中国军队阵地后，发现一具阵亡中国军人的尸体。

  • #参战装备#美制达格拉斯O-2MC型侦察轰炸机：O-2型为美国在两次大战间使用最久之多功能双座双翼侦巡机。中国1929年购入38架O-2MC-2/3型，85架O-2MC-4/5型,称为达机，曾用于一二八抗战。1935年，又增购22架O-2MC-6型。武备2挺7.7毫米机枪和100公斤炸弹，该机抗战初期被用于执行夜间轰炸任务。

  • 1932年2月7日讯：行政院长汪精卫由滁州南下，在浦口发表谈话，声称：“余去年在沪，即主对日一面抵抗，一面交涉，此主张至今未变。”

  • 1932年2月7日《申报》：上海本埠息，日军昨在其各处根据地，以机枪步枪，进攻我军阵地，间以大炮轰击，入晚较烈，均经我军击退，日本飞机数架，时向闸北等处掷弹，经我空军，驾起飞机6架，由闸北追至真如，卒将敌机一架击落，余均惊遁。吴淞亦被敌机袭击，为我军开高射炮击退，炮台无恙。

  • 1932年2月7日讯：第五军张治中第八十七师第二六一旅宋希濂部集中昆山，顾祝同部第八十八师俞济时部移驻南翔，准备援沪。

  • #一二八淞沪抗战#1932年2月7日讯：日军海军陆战队和混成旅团分3路向张华浜、蕴藻浜、吴淞镇进攻，在蕴藻浜车站遭我156旅4团8连连长赵全声巧妙奇袭，敌军陷于混乱，遭我军杀伤数百人。张华滨、吴淞镇阵地遭日军猛烈轰击，致整排人被埋于废墟中的惨事，但我军士气仍然高昂，死战不退，力保各处阵地不失。

  • 1932年2月7日讯：日军改变战略，移其主力攻吴淞、江湾。混成第二十四旅团主力由张华浜进攻吴淞，黄浦江日舰开炮协助，猛攻两次，均被第一五六旅翁照垣部击退。另一部协同特别陆战队于午前9时起进攻八字桥，激战六七小时，亦被击退。闸北炮击终日不息。

1932年02月06日

  • 1932年2月6日讯：上午10时许，日军向闸北横浜桥、青云路、中山路一带进攻，以天通庵路至中山路阵地战斗最烈，至12时许被我军击退，敌转而向我左翼移动，猛攻八字桥，经守军第六十师第一一九旅第二团回击，于午后6时开始撤退。吴淞方面战争沉寂。

  • #抗战英烈# 滕久寿滕久寿（1899—1932），贵州省都江县人。父亲滕子清于清朝末在都江厅任职。滕久寿“少雄武，有节概”，常以“精忠报国自劢”。民国8年（1919年）毕业于贵州陆军讲武学堂炮兵科，历任黔军排、连、营、团长等职务。民国15年到广州，投奔国民革命军，先后任中央军校潮州分校教官，潮州警备司令部参谋处长，以后又调任国民革命军第十七军二师及第十军二十九师参谋长，民国18年被调到第十九路军吴淞要塞司令部任参谋长。民国21年1月28日夜，日本海军陆战队借口向上海闸北阵地发起了全线攻击，并集中火力轰击杨子江的第一门户吴淞要塞。当时要塞司令临阵辞职，对敌人没有任何反抗。在紧急时刻，滕久寿奉命督战，登上炮台，率领全体炮兵奋勇还击，屡次击败日军的凶猛进攻。开战后的第7天，2月4日上午10时左右，敌舰13艘，飞机20架，向要塞炮台轮番轰击。吴淞全镇变成火海，炮台内到处是一、二丈深的弹坑。滕久寿巍然坚守岗位，指挥炮兵奋力还击。突然，弹片击中左膀，鲜血染红衣服，随身护兵请参谋长暂时退避，滕久寿坚决的说：“我辈军人，负有保国卫民之责，速还炮杀敌，后退者枪毙！”话未说完，左腋又中敌弹，炸去了右手，接着，弹片又穿透胸腹，倒在血泊中壮烈牺牲，时年33岁。战火中，士兵将其遗体用棉絮包裹好后，就地掩埋。同年3月中旬，遗体安葬在上海永安公墓。滕久寿奋勇抗日，为国捐躯，上海各界爱国人士和全国人民同志钦佩。十九路军领导人蔡廷锴领衔组成治丧委员会，濡墨挥毫，写下“血洒松沪”4字，宋庆龄也发表演说，赞扬十九路军和滕久寿将军奋勇抗敌的爱国精神，上海各报报道了滕久寿将军的英勇壮举，大夏大学教授王蘧常撰写《滕将军传》，上海人民和十九路军官兵的抗战热情更由此大为激发。1984年6月26日，北京市人民政府批准原国民革命军第十九路军吴淞要塞司令部参谋长滕久寿将军为革命烈士。同年7月6日，中华人民共和国民政部为滕久寿正式颁发了《革命烈士证明书》，执证人为滕久寿将军的次子滕树威。
