1932年07月23日

发表于 2021-07-23 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年7月23日讯：华侨140余人去旧金山谋生，被美国当局驱逐回国。

  • 1932年7月23日讯：女共产党员区梦觉（即周爱霞）及女友莫琼兰，在沪被跟踪的广州公安局侦缉队员扣留，寄押在上海公安局，是日押回广州。

  • 1932年7月23日讯：上海各民众团体联合会召开紧急宣传会议，电促张学良效死战场，以谢国人，并电勉汤玉麟效第十九路军精神，扫除日寇。

  • 1932年7月23日讯：外交部就日攫夺东北盐政事，再次向日本政府提出抗议。

  • 1932年7月23日讯：蔡廷锴在厦门谈第十九路军“剿匪”计划，决定分三步进行：第一步集中兵力，于短期内克复龙岩；第二步由龙岩推进闽西之永定、上杭、连城、武平等处；第三步直捣长汀根据地。

  • 1932年7月23日《申报》：北平息，华北各校师生联合一致，抵抗日进攻热河，华北学总会将推代表谒张，请抗日，大学教授会电林汪蒋等，积极抗日。（22日专电）

  • 1932年7月23日《申报》：北平息，救国军孙玉田部，在绥中与三百日军激战半日，敌死伤三十八，缴械40余，余突围向绥中城内溃退。（22日专电）

  • 1932年7月23日《申报》：北平息，千五百名义勇军，昨夜围攻凤凰城，并开大炮数门轰击，日守备队受重创。（22日专电）

  • 1932年7月23日《申报》：天津息，汤玉麟之大佐与少佐（姓名不详）两副官，护送汤玉麟所有之贵重品，计满载八汽车，于今夜运送天津意（大利）界汤玉麟之私宅。（22日电通社电）

  • #抗战影像#青年赴东北援助抗日宣传会

  • 1932年7月23日《申报》：东京讯，据天津来电，张学良之军队，向热移动，非常迅速。迄21日晨，已有三旅运送完毕，而目下运送中者，尚有四旅。又将平绥路宣化之步兵旅，急送石门镇，津浦路马厂之骑兵旅，及杨柳青之步兵旅等急速准备开往喜峰口。此等开拔部队除归清欠饷外，另给若干之开拔费，其先发队已抵热河。（22日电通社电）

  • 1932年7月23日《申报》：北平息，热河20日21日无冲突，北票尚在我军手中，石本失踪事，正在调查，日炸朝阳安，热当局已向日方交涉。据情势观测，或将不至扩大。（22日中央社电）

  • 1932年7月23日讯：邮政总局奉交通部令，封锁东北各邮务，邮件、汇兑均停寄发。同日，交通部长黄绍竑发表宣言，谓日本指使叛逆攫夺邮政，业务不能执行，被迫封锁东北邮务，以致影响公众交通，一切责任应由日本政府负之。

1932年07月22日

发表于 2021-07-22 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年7月22日讯：宋子文与上海银钱业续商币制改革事，决定组织“废两改元”研究会，由中央银行副总裁陈行为主席委员，任命贝淞荪、胡笔江、刘鸿生及西人凯末、麦照特、雷祺为委员。

  • 1932年7月22日讯：导淮委员会副委员长庄崧甫，因兵工导淮不能实行，又无经费而辞职，是日，国民政府令准，特派陈果夫为导淮委员会委员，并代理副委员长。

  • 1932年7月22日讯：红军击溃敌毛炳文、许克祥部10个团，攻克南丰、抚州，南昌大为震动。

  • 1932年7月22日讯：行政院通过教育部所提之整顿教育令：国立北平大学及国立北平师范大学近年来学潮迭起，办学困难，均应从事整理，除平大农、工、医各学院外，其余各学院及平师大一律停招新生；又国立暨南大学教育学院并入文学院，改为教育学系，法学院裁撤，学生转入中央大学肄业。中央大学商学院、医学院，改名国立上海商学院、国立上海医学院。27日教育部令三校遵行。

  • 1932年7月22日《申报》：北平息，何柱国今晨到平谒张（学良），报告榆关防务。（21日专电）

  • 1932年7月22日讯：下午1时，郑州骤起大风雨，夹冰雹巨如鸡卵，历四小时始止，行人被击伤者比比皆是，倒塌房屋数千间，田禾伤十之八九。贾鲁河上游水暴发，沿河房屋漂没，浮尸数十具，为近数十年来未有之奇灾。

  • 1932年7月22日《申报》：北平息，日军此次犯热，意在试探我方态度，及国际间情势，18日攻朝阳后，我力持镇静，各国莫不震骇，狡计卒未得逞。昨今两日，热边颇安靖，义县一带日军，无积极行动，事态渐缓和。（21日专电）

  • #抗战影像#婉容留影，她于1922年12月1日在北京紫禁城与溥仪结婚，后被册封为伪满洲国“皇后”。伪满垮台后，她在逃亡中于1946年病死在延吉。

  • 1932年7月22日《申报》：南京息，朱霄青谈，锦州日军派飞机轰炸朝阳，系意料中事，当不待言。惟石本事件有否，尚不可知，竟借口向热进攻，窥其用意，不过实行威吓手段，以逼热汤（玉麟），至其事件之如何扩大，余未敢下断云。（21日专电）

  • 1932年7月22日《申报》：天津息，攻热日军见东北军已有准备，诚恐徒受牺牲，反予调查团不良印象，适热河驻沈代表，请日军部停止军事行动。日军部队首肯，汤玉麟即派北票商会长邵子峰，20日到朝阳寺，与原田大尉接洽。原田令热军负责拯救石本，并消灭义勇军，形势暂趋缓和。（21日专电）

  • 1932年7月22日讯：汪精卫以日军进攻热河，电令张学良作自卫抵抗，并电促蒋介石回南京共商应付策略。蒋复电称：“剿匪紧张，暂难返京”，并称已令张学良“于受侵袭时尽力抵抗”。

1932年07月21日

发表于 2021-07-21 更新于 2021-07-24 分类于 局部抗战(1931-1937)

  • 1932年7月21日讯：广州大风雨，全市成泽国，坍屋极多，溺毙压死者千余人。

  • 1932年7月21日讯：美兰德出任澳门第一百十三任总督。

  • 1932年7月21日讯：晚，汉口《大同报》被警察捣毁，并捕去三人。国民党湖北省党部以“特别事故”为名，令该报于22日停刊。

  • 1932年7月21日讯：国民政府公布《铁道法》。

  • 1932年7月21日讯：日军分五路包围吉林自卫军：一由敦化沿牡丹江南进；二由敦化沿牡丹江南北两路东进；三由延吉北进；四由珲春向西北进；五由中东路海林站南进。自卫军亦分五路迎击。

  • 1932年7月21日讯：蒋介石划豫、鄂、皖区域为鄂中、鄂东、皖西、豫南四个“剿匪”区，本日派刘秉粹、张 酉葳、石毓阳、向兆余分任视察。

  • 1932年7月21日讯：上海各团体救国联合会发表宣言，督促国民政府出兵收复东北失地，实行总动员，争取最后胜利，并电促张学良出兵，“决国家存亡于一旦，定个人功罪于千秋”。

  • 1932年7月21日《申报》：北平息，日军三百余，17日由义县乘甲车两列，向朝阳前进，日机大肆轰炸，损伤极重。日方谓石本失踪，纯系故意捏造借为进兵口实。（20日专电）

  • #抗战影像#侵占我东北之日本发行的明信片，宣扬务农，建设伪满洲国农业。

  • 1932年7月21日《申报》：南京息，政府接热河电，18日下午二时，日机5架，到朝阳轰炸，落弹30余枚，机枪扫射半小时，死伤人马数十，于二时30分飞回。又据报，敌机5架，于二时飞到朝阳轰炸，又射击，约30分钟飞去。炸后情形如下：1）旅部落二弹，未伤人；2）迫击炮连落5、6枚，死伤人员5、6人，马20余匹；3）电报局附近落5枚，有未炸3枚，弹形如迫击炮弹；4）各商号落弹未详，总计掷弹约30余枚。（20日专电）

  • 1932年7月21日《申报》：北平息，日机18日在朝阳炸毙居民二十余，19日日机6架，在热边凌源一带侦察，大屯口方面，昨有日军一联队前往袭击，热河方面昨有日军一联队前往袭击，热河方面今均有电报告近况。（20日专电）

  • 1932年7月21日讯：行政院以日军窥热，急电热河省主席汤玉麟抵抗，电促张学良加派大军助汤，并决定：一、向日提出抗议；二、电知国联。

1932年07月20日

  • 1932年7月20日讯：天津商民救国会致电热河省主席汤玉麟请对攻热日军妥加防御，矢志抵抗。

  • 1932年7月20日讯：上海各民众团体救国联合会以日军“袭热河，攻榆关，窥平津”致电国民政府，质问“有无收复失地准备”，并称“诸公秉持国政，败坏于前，岂仍因循坐误，使敌寇纵骑关内，以沦我华北，涂炭全国”。

  • 1932年7月20日讯：废止内战大同盟在沪举行第八次筹备会议，秘书处报告截止是日加入发起之团体203个，个人493名。代表大会展期至8月27日在上海举行。

  • 1932年7月20日讯：中华苏维埃共和国临时中央政府自瑞金用无线电向南京政府发出抗议，要求释放牛兰夫妇，愿以释放苏区所有西方教士为交换条件，并表示牛兰为中国革命之友，愿为牛兰夫妇辩护。

  • 1932年7月20日讯：教育部呈行政院整顿各大学办法数项：一、确定经费；二、裁并各大学重复院系；三、规定延聘教授标准；四、严格限制招收及甄别学生；五、慎重任命校长。

  • 1932年7月20日讯：日军“鉴于当前内外诸般情势，不宜立即对于热河方面进行武力解决”，是日退出热河朝阳寺。

  • 1932年7月20日讯：国民党中央制定《保障言论自由法》，凡12条，其中规定“宣传共产主义或谋破坏团体之刊物没收”。

  • 1932年7月20日《申报》：哈尔滨息，伪国所铸新币，目下暂由“中央银行”运送二百万元于哈尔滨，以为流通北满之用，至于流通北满市场之旧纸币，其换算率，定为金币纸百元，换新铸币百二十五元。（19日电通社电）

  • 1932年7月20日《申报》：东京讯，日军出动热河之部队已在前线开火，形势顿形重大。（14日路透社电）

  • 1932年7月20日《申报》：锦州息，17日被义勇军捕去之满铁联络员石本权四郎，本日由在北票之热河军宪兵队，电锦州日军司令部，谓关于石本之踪迹，当于三四日中，由义勇军取去，交与日本，惟日军对此电，不肯置信。（19日电通社电）

  • 1932年7月20日讯：国民政府任命沈光汉为陆军第六十师师长，毛维寿为陆军第六十一师师长，区寿年为陆军第七十八师师长。
