1932年03月28日

发表于 2021-03-28 更新于 2021-03-29 分类于 局部抗战(1931-1937)

  • 1932年3月28日讯：伪满洲国宣布关税、盐税独立。通令大连、营口、安东、哈尔滨、松花江、满洲里、绥芬河、珲春等海关，自4月1日起归伪满洲国财政部管辖。

  • 1932年3月28日讯：陈独秀发表《农民在中国革命中的作用及其前途》一文。

  • 1932年3月28日讯：东北民众自卫军约3000名攻克吉林农安县城。

  • 1932年3月28日讯：国民政府令：内政部长冯玉祥未到任前，着政务次长彭学沛暂代部务。

  • 1932年3月28日讯：汪精卫、罗文幹分别宴请国联调查团。汪致词略称：中国无排外之意，对于和各国订立的条约，无不尊重维持。中国人民排日是由于日本对中国侵略行为所促成。“中国人民对于现在时局所抱的希望及志愿，为领土与主权之完整”，对东北傀儡政府的出现，“决不能容忍”。“至于 …

  • 1932年3月28日讯：日机三架飞杭州市低空侦察。

  • 1932年3月28日讯：中日军事小组委员会续开会，日方仍坚持军队众多，须暂退至吴淞、江湾、闸北、真如四区。中国代表指出以上四区非原则第二项规定之撤兵地点，仍坚持照1月28日以前原防。

  • 1932年3月28日《申报》：哈尔滨息，自卫军赵毅旅24日攻入一面坡，熙洽军及日军退守珠河。（25日专电）

  • 1932年3月28日《申报》：哈尔滨息，24日夜，土肥原、多门、李桂林在哈特务机关内，邀自卫军代表王之佑，谈和平条件。闻自卫军仍持各军回驻原防，发饷三月，各司令旅长复原职等条件（25日专电）

  • 1932年3月28日《申报》：哈尔滨息，宮占海自卫军25日午后3时，与日军长谷部，在宾州激战，日机3架助攻，宫军为避威胁，退县城外。（26日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”初期，居留在上海的武装日本侨民正在配合日本海军陆战队投入上海街头作战。

  • 1932年3月28日《申报》：杭州息，调查团美、德、法三代表，17日晨8时35分赴京，共乘汽车几辆，1号麦考伊、魏文彬，2号克劳特、王广圻，3号希尼、朱凤千，余乘随员招待等。两辆装行李。（27日专电）

  • 1932年3月28日《申报》：各报馆上海童子军战地服务团第四批队员76人，已于27日抵前方，所经各地均由战地服务童子军迎接。该团总指挥汪刚亦到前方随时指挥，又悉前方工作之童子军，先后已到一百五六十人，并于即日由某处唐处长、周秘书莅临训话。

  • 1932年3月28日讯：中日停战会议讨论修改后之《停战协定新草案》，中方代表郭泰祺提出日军应在一定期限内完全撤退，恢复1月28日以前原状。日方反对。反复讨论无结果。

1932年03月27日

发表于 2021-03-27 更新于 2021-03-29 分类于 局部抗战(1931-1937)

  • 1932年3月27日讯：杨虎城通电声讨东北叛逆，表示“分属军人，一致誓保疆土”。

  • 1932年3月27日讯：国民政府下令嘉奖赣州“剿匪”将士，第十二师第三十四旅旅长马昆晋级，并传令嘉奖该旅官兵；第十八军军长陈诚“调度有方”，第十一师师长罗卓英、第十四师师长周至柔“指挥得力”，均予嘉奖。

  • 1932年3月27日讯：沪失业工人激增至16万余人，何香凝除自捐洋1500元救济失业工人外，并函沪市银行公会等商业团体尽量捐助。

  • 1932年3月27日讯：上海复业委员会决议，定4月1日忍痛开市。

  • 1932年3月27日讯：粤救国抗日联合会电林森、汪精卫、蒋介石，表示“拒绝一切丧权辱国条约，粤同胞誓为后盾”。

  • 1932年3月27日《申报》：哈尔滨息，闻旧吉军领袖已请日方撤兵，彼等准备无条件屈服，但日当局拟继续进攻，且坚欲丁超李杜即来哈尔滨。（26日路透电）

  • 1932年3月27日《申报》：东京讯，报载长春消息，据称（伪）满洲国政府已决定采用金本位以期改善对外贸易，并取得国际信用。闻东三省金矿或将归（伪）国家经营而以金矿所得，成立必要之金准备云。（25日路透社电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，被日军航空队轰炸为废墟的上海大场镇。

  • 1932年3月27日《申报》：北平息，哈电，苑崇谷率部七千名攻占黑垣，长春大混乱，救国军满布四郊，日军疲于奔命，苑军与昂昂溪苏炳文旅联合，扼洮昂线，切断日军来路。（26日专电）

  • 1932年3月27日《申报》：松江息，国联调查团美、德、意三国代表，26日上午10:05抵松，商学各界列队到车站欢迎，各团体代表杨仲和等登车致欢迎辞，面呈声请书，红十字分会周学文、美牧师步惠连鲍恩亦登车访谒，松社并有说帖呈递，约11时许开车赴杭。（26日专电）

  • 1932年3月27日讯：中日停战会议休会。沪西曹家渡一带苏州河日军向河南税警团哨兵开枪射击，经守军抵抗，相持半小时始息。

  • 1932年3月26日讯：中日停战会议续开，停战协定草案已大部议妥，会议空气和缓。决定组织由参加会议各友邦代表在内之共同委员会，其职权规定为证明双方履行撤兵，不干涉撤退区域之行政。

1932年03月25日

发表于 2021-03-25 更新于 2021-03-29 分类于 局部抗战(1931-1937)

  • 1932年3月25日讯：平津院校教联会发表宣言，要求国民政府清偿积欠，实行教育费独立计划。

  • 1932年3月25日讯：安徽省府常会决议：安徽大学校长何鲁辞职照准，聘程演生继任。

  • 1932年3月25日讯：吉林自卫军两度攻克宾县，中东路形势严重，日军积极备战。

  • 1932年3月25日讯：汪精卫电请蔡元培留居南京，支持其政权。蔡婉函拒绝。

  • 1932年3月25日讯：冯玉祥因抗日主张得不到蒋介石支持，以养病为名，自徐州赴泰山隐居。是日，冯对记者称：已三次请辞内政部长职；对日必须抵抗，切盼全国团结御侮。

  • 1932年3月25日讯：上海市教育局公布各学校因日寇侵沪所受损失：受害学校共228所，财产损失达1000万元。

  • 1932年3月25日讯：沪社会局训令市民联合会、各路商界联合会，劝告各业自25日起一律开市。

  • 1932年3月25日讯：川军刘湘部范绍增师出发援沪。

  • 1932年3月25日讯：日海军第一外遣队司令盐泽抵汉口。

  • 1932年3月25日讯：下午，中日军事小组委员会在英领署开会，就日军人数及撤退时暂驻地点等问题加以研究。日方代表极为蛮横，无结果而散。

  • 1932年3月25日讯：沪日侨开居留民大会，议决主张开辟闸北为中立区，请求白川大将、植田中将不得撤兵。

  • 1932年3月25日讯：日军攻太仓，江湾日军筑防线三道，并在沪新建营房。

  • 1932年3月25日《申报》：北平息，榆关电，义勇军13路军联合17路，进攻绥中。19日晚占绥中车站，歼敌甚巨。翌晨退出。22日晚再占绥中，石司令足部受伤，是役歼敌四十余，我军死伤30余。22日晨日军追击，我方死战，日军溃退。（24日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”期间，在江湾地区作战的一队日本陆军士兵，正在法制雷诺NC-27型坦克引导下发起攻击。

  • 1932年3月25日《申报》：南京息，外部以近在上海停战期内，日机仍不时飞翔苏杭各地侦察，24日再次向日方提严重抗议，并保留要求损失赔偿权，同时电颜代表转告国联。（24日专电）

  • 1932年3月25日讯：中日停战会议在上海举行，讨论日军撤退程序问题，因日本代表态度强硬，主张日军退至真如狮子林线，我方代表坚决反对，会议几乎破裂。经英、美两使调停，决定由中国代表黄强和日本代表田代另组军事小组委员会，研究撤兵程序问题。

  • 1932年3月25日讯：傅作义请辞绥远省政府主席。
