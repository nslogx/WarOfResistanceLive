1933年03月12日

发表于 2022-03-12 分类于 局部抗战(1931-1937)

  • 1933年3月12日讯：日军第八师团川原第十六旅团增加重炮、飞机向古北口再次进攻，主力指向我龙儿峪阵地，同时向右翼延伸包抄。午时，我军通讯设备遭日机炸毁，联络中断。下午3时后，龙儿峪阵地守军第一四五团在日军重炮火力下伤亡惨重，潮河北岸高地之第一四九团亦受日军包围，在日军源源增加，我军后援不继下，被迫后撤至古北口西南10里之南天门阵地。翌日晨，第二十五师撤密云休整，由暂二师接防。

  • 1933年3 月12日讯：国民党政府明令准予免去张学良本兼各职，由何应钦兼代北平军分会委员长，全权指挥华北军事。何应钦遂以北平军分会的名义令防守石门寨的何柱国部撤至滦河西岸，破坏滦河铁桥。

  • 1933年3月12日《申报》号外：长沙息，湖南公路局抗日汽车队，12日北上，担任支援热河抗战运输任务。（12日专电）

  • 1933年3月12日讯：日军在喜峰口遭我军沉重打击后，未敢继续进攻，下午始利用空中优势以轰炸机四架对我喜峰口、澈河桥阵地轮番轰炸，并驱伪蒙鲜军约一团由董家口向郙家峪窜扰。

  • 1933年3月12日《申报》号外：北平息，古北口今无激战，中央军师长关麟征，昨在前方指挥作战时被敌掷弹筒榴弹炸伤。今返平，入协和医院治疗。（12日专电）

  • 1933年3月12日讯：汤玉麟自丰宁电在津原热省民政厅长李树春转电何应钦、朱庆澜，饰词解释退出承德经过，并称所部在丰宁、隆化集结。21日，李树春在平谒何、朱，为汤疏解。

  • 1933年3月12日《申报》号外：北平息，宋哲元到喜峰口前线督战后，士气大振。宋严令不许放枪，迨敌人逼近，我军用大刀出击，砍杀敌人二千余，我军因受炮火，损失亦巨。（12日专电，图文无关）

  • 1933年3月12日讯：桂第四集团军派往兴安、全县、灌阳、龙胜等地镇压瑶民起义之部队，遭瑶民顽强抵抗，复派第七军军长廖磊前往督师。廖于是日将行营移兴安。至此，参加镇压起义之官兵达四万余人。同日，湘军第二十八军军长刘建绪在衡阳召保安团长等开“剿瑶”会议，决定派兵分途“围剿”。

  • #抗战影像#1933年3月12日，日军侵占古北口后欢呼庆祝。

  • 1933年3月12日讯：中山文化教育馆在南京成立，以林森、蒋介石、汪精卫、胡汉民、孙科等29人为理事，蔡元培、戴季陶等八人为常务理事，孙科为理事长。

  • 1933年3月12日《申报》：北平息，孙殿英由前方拍来无线电，报告10日激战结果，已在锥子山打出一条血路，倘后方能充分接济，全军愿作殊死战，全部牺牲，均所不计。（11日专电）

  • #长城抗战#1933年3月12日讯：古北口日军增加重炮和飞机对我发起全面进攻，主攻方向指向145团，至十二时，所有电话总机和无线电报机均被毁，各团失去联络，各自独立为战，至下午3时，除河西镇的150团尚完整外，各团均已残破，代理师长杜聿明撤退至南天门收容各部，古北口失守。

  • #抗战影像#1933年3月12日，日军击溃国军25师进占古北口关城。

  • 1933年3月12日讯：蒋介石由石家庄到保定坐镇，罗文幹同行。

  • 1933年3月12日《申报》：北平息，昨古北口外战事极剧烈，敌军排炮队竟日向我青石梁阵地轰击，我军战壕防御工事，悉被敌军炮火所毁。我军王师所部营长阵亡5人，连排长士兵伤亡极众。另有敌轰炸机10余架，昨日上下午两次飞我三间房偏桥镇古北口内一带轰炸。偏桥镇三间房等地多处起火，古北口内至石匣镇一带长途汽车道多被敌机投下重磅炸弹破坏。今晨长途电话电报均不通，足证前方战事激烈。（11日专电）

  • 1933年3月12日讯：国民政府明令准免张学良北平政务委员会常务委员兼代军事委员会北平分会委员长职；派军政部长何应钦兼代执行军事委员会北平分会委员长职权。同日，张离平飞沪，何到会接任。何对东北军官员表示：“一切照旧，望各安心。”

  • 1933年3月12日《申报》：北平息，喜峰口电，进攻喜峰口日军，自9日晨至10日晚，继续猛攻冲击，扼守口门之我军，奋起抵抗，11日晨9时，日军第七三十四两旅团与伪军联合步炮空装甲车坦克车，同时冲锋，至距我阵地仅四五十米达之远。我军大刀队以白刃抵御，拼杀数小时，始将敌砍退。我军特务营长王宝良阵亡，同时敌骑兵由董家口攻入，经我军协同民团截击，鏖战三小时，敌始后退。（11日专电）

  • #长城抗战#1933年3月12日讯：今日长城喜峰口上沉寂，日军仅以4架投弹20余枚，造成我军轻微伤亡。董家口有敌来犯，为我击退，遂成对峙。

  • 1933年3月12日《申报》：北平息，我王之均团在古北口外8日起与敌激战四日，未得一顿饱餐，幸得我后方某救国团体接济食物，士气大振。该团9日子弹一度断绝，士兵遂抛尽手榴弹后以大刀和刺刀应战，皆脱去大衣，奋勇前进，故损失颇重。据传王团长阵亡说不确，现该团已由友军换防，士气仍旺，留在古北口外西山与敌对峙，今晨与敌激战。（11日专电，图文无关）

  • #抗战影像#1933年3月12日拂晓，日军野炮第八联队抵达古北口附近建立炮兵阵地后，猛烈轰击中国守军阵地。

1933年03月11日

发表于 2022-03-11 更新于 2022-03-12 分类于 局部抗战(1931-1937)

  • 1933年3月11日讯：交通部上海国际电台与莫斯科直达线路正式开放。

  • 1933年3月11日讯：国民政府公布《县参议会组织法》、《县参议员选举法》、《市参议会组织法》、《市参议员选举法》，均自12日起施行；又公布《公务员任用法》及《公务员任用法施行条例》，4月1日起施行。

  • 1933年3月11日讯：下午6时，上海申新纺织一厂工人与搜身巡丁发生冲突，被巡丁开枪击伤15人，混乱中坠河及被扎伤者30余人。全厂9000余工人自动怠工。翌日，国民党上海市党部、公安局、总工会等派员与厂长严裕昆及工人代表等商定，将巡丁头目撤职惩办，受伤工人由厂方给予医药费及家属抚恤金，停工养伤期间工资照给。惨案指使者该厂协理王云程未受任何追究，凶手也早逃逸。工人对此项解决办法虽不满意，但在国民党当局压力下被迫复工。

  • 1933年3月11日讯：阎锡山到石家庄见蒋介石，商由山西调部分军队担任察哈尔防务，交北平军分会指挥调遣。翌日，阎返太原。

  • #长城抗战#1933年3月11日讯：喜峰口我军夜袭三家子、小喜峰口、狼洞子及白台子日军炮兵阵地得手，“只准用大刀砍、手榴弹炸，非到万不得已的情况，不得用轻机枪和步枪射击，以歼灭敌人为第一。”砍杀日军千余人，我军刀刃大多为之卷刃，出现缺口，亦牺牲团附胡鲁重，营长苏东元，两名连长及以下数百名官兵。

  • 1933年3月11日讯：日军第八师团川原第十六旅团在飞机大炮掩护下再次进攻古北口，以主力部队向我龙儿峪、将军楼两阵地猛攻。我守军奋勇抵抗，伤亡甚重，第二十五师师长关麟徵亲率特务连赴前线阵地指挥，中途遭日军狙击负伤，由第七十三旅旅长杜聿明代师长。是役除关麟徵负伤外，“第一四九团团长王润波壮烈殉职，其余官兵伤亡尤多”。

  • #长城抗战#1933年3月11日讯：古北口25师发动猛烈反击，关麟征亲率149团攻击将军楼阵地，两军短兵相接，战斗极为惨烈，我军击退日军，恢复了和145团的联系。但关麟征师长却因士兵不会使用手榴弹而被误伤，149团团长王润波牺牲。又因112师擅自撤退，只能以150团推进至河西镇占领阵地。

  • 1933年3月11日讯：晨，日军在喜峰口全线炮击。复攻喜峰口正面西侧高地，我官兵拼死迎击，毙敌百余名，至下午3时30分，西侧高地弃守。宋哲元手谕全军：“无论如何要拼命保阵地”，“国家存亡，本军存亡，在此一战。”下午4时，赵登禹令第二一七团团长刘景山率部反击，经两小时肉搏冲锋，将西侧高地夺回。是日夜，第二十九军赵登禹旅再次派队绕敌后，占领日军炮兵阵地，卸毁日军大炮18门，烧毁辎重粮秣，砍毙日军官兵数百名，在日本国内引起震惊。我军阵亡中校团附胡重鲁、营长苏东元及两名连长；受伤团附一人，营连长九人；“士兵死伤亦极伙”。

  • 1933年3月11日《申报》：天津息，唐山丰润之间，突发现女子救国军四百余名，服装整齐，纪律严明，身负宝剑一口，匣子枪一支。据彼声称，均为自愿抗日救国之同志，即出喜峰口到前线杀敌云。经过各地仅要求供给宿食，此外秋毫无犯，故受欢迎。（11日专电，图文无关）

  • 1933年3月11日《申报》：天津息，孙殿英部因弹药粮秣断绝，无法接济，9日由围场开始向多伦退却。孙与撤退时电津云，8日子刻在围场以东，刘旅奋勇抄袭敌背，续以大队全线反攻，金于两副军长及刘旅长督战，血肉相搏，万分激烈。我吴营长相陆被俘，张营长诚吾阵亡，刘营长慎修、刁营长松亭受伤，连长阵亡六名，排长三十余名，士兵阵亡二百余名，连排长受伤者俟查明再告。俘敌三十余名，毙敌四百余，获敌六年式山炮两门，机枪两挺，至步枪马匹，获得及损失者，查明再达。现弟向后稍退，我军刻在整顿追击中。（10日专电）

  • 1933年3月11日《申报》：北平息，喜峰口电，昨晨宋哲元所部赵旅王团接万部喜峰口防务之际，敌人乘机向我进攻，以装甲车20余辆，步骑联合，步队四五千人，向我阵地猛冲，我大刀队肉搏终日，敌势大挫，双方各有伤亡，迄昨夜仍相持中。（10日专电）

  • 1933年3月11日《申报》：北平息，敌逆军今开始总攻古北口外青石梁我军阵地，飞机40余架，坦克10余辆，猛力向我压迫，并飞我后方阵地掷炸弹，战况极烈，我军奋勇抵抗。（10日专电。）

  • #抗战影像#图为入侵长城古北口行军中的日军第十六旅团步兵第三十二联队。

  • 1933年3月11日《申报》：北平息，古北口电话，今晨拂晓，日军及伪军联合大部突向我青石梁阵地猛攻，敌坦克车装甲车10数辆，向我阵地乱冲。我用机枪射击，午前10时敌军略退，午后2时，敌再进攻青石梁至老虎山黄土坡之间，发生全线激战。王以哲军长、张何两师长均亲临阵地督战，后方援军陆续增加。（10日专电，图为水彩画创作《古北口抗战 》）

  • #长城抗战#1933年3月11日讯：古北口日军向我军一线阵地发动猛烈攻击，首先突破我112师右翼634团，逼迫后撤，随即夹攻左翼635团，我军伤亡甚重，635团团长白玉麟率第二营死战冲锋，夺回高地，但激战中白玉麟团长壮烈牺牲。此后112师纷向后撤，日军乘胜猛烈攻击25师右翼龙儿峪的145团。

  • 1933年3月11日讯：北平息，张学良10日晚通电下野，，内称：“此次蒋公北来，会商之下，益觉余今日之引咎辞职，即所以效忠党 国、巩固中央之最善方法，故毅然下野，以谢国人。”并表示“惟眷念多年袍泽，东北之健儿”，期望“中央俯察彼等劳苦”，“倘遇报国之机，加以使用，俾得为收复东北之效命，遂其志愿，免于飘泊，于愿斯足”。电文400余字，部下请中央维持。（11日上午3时电）

  • 1933年3月11日《申报》：北平息，宋哲元10日电平报告，谓9日晨，宋部与万部在喜峰口换防之际，日军及逆军万余乘机来犯，日钢甲车30余辆向我猛攻。经宋部冯治安师赵登禹旅与敌肉搏一昼夜，10日日机4架掩护进攻，被我军击退，迄下午4时，尚在相持中。两军死伤均重，赵旅长受伤，裹伤再战，士气大振。（11日专电，图为29军在喜峰口的阵地）

  • #长城抗战#1933年3月11日讯：喜峰口当面敌军复来，因敌我器械差距较大，我军坚守一日，伤亡甚重，遂决定以王治邦旅固守，以赵登禹、佟泽光各率两团夜袭当面日军。

1933年03月10日

发表于 2022-03-10 更新于 2022-03-12 分类于 局部抗战(1931-1937)

  • 1933年3月10日讯：上海中华国货介绍总所成立。

  • 1933年3月10日讯：世界动力学会分会在南京成立，由实业、交通、铁道三部筹组。

  • 1933年3月10日讯：上海各业开始实行银元本位制，银钱业取消洋厘行市。中央、中国、交通三银行合组之兑换管理会开始办公。同日，海关税收亦改收银元。

  • 1933年3月10日讯：天津北洋火柴公司借口受外货压迫，捐税过重，未经管辖机关允可宣告停业。工人群起反对，派代表向市政当局请愿。21日，社会局制定调解方案，规定每月工作20天，照原工资三分之二发薪，假日不发工资等。工人被迫接受，于24日复工。

  • 1933年3月10日讯：在辽西地区活动的田霖、英若愚、贾秉彝三支联合部队共3000余人突袭占领阜新县城

  • 1933年3月10日讯：国民政府任命马麟兼青海省政府主席。任命郭任远为浙江大学校长，原任程天放免职。

  • 1933年3月10日讯：我救国军各路攻城部队集结于三岔口城外，以突袭方式攻入城内，杀伤日伪军100余人，敌一度动摇撤退，但在敌反扑下且日军绥芬河驻军来援，被迫撤出三岔口城。此后，日军全县搜捕，杀害抗日群众200余人。

  • 1933年3月10日讯：中共中央就第四次反围剿问题向鄂豫皖省委发出军事指令，指出：“目前国民党对鄂豫皖苏区的围剿并没有完结”，“摆在我们面前的革命任务就是努力的继续与加强与国民党军队作斗争，以便保持现有的和恢复以前的苏区，并且在这个基础上扩大苏区。”16日，再致鄂豫皖省委信。

  • 1933年3月10日讯：多伦我军撤向张家口。撤退过程中，孙殿英部因补给不足，军纪极坏，沿途骚扰不堪，且有降敌谣言。后北平军分会发欠款40万元和面粉四万袋，指定在沽源、独石口和镇岭口布防。
