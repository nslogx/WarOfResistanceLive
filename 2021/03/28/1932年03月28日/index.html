1932年03月28日

发表于 2021-03-28 更新于 2021-07-05 分类于 局部抗战(1931-1937) 阅读次数：

  • 1932年3月28日讯：伪满洲国宣布关税、盐税独立。通令大连、营口、安东、哈尔滨、松花江、满洲里、绥芬河、珲春等海关，自4月1日起归伪满洲国财政部管辖。

  • 1932年3月28日讯：陈独秀发表《农民在中国革命中的作用及其前途》一文。

  • 1932年3月28日讯：东北民众自卫军约3000名攻克吉林农安县城。

  • 1932年3月28日讯：国民政府令：内政部长冯玉祥未到任前，着政务次长彭学沛暂代部务。

  • 1932年3月28日讯：汪精卫、罗文幹分别宴请国联调查团。汪致词略称：中国无排外之意，对于和各国订立的条约，无不尊重维持。中国人民排日是由于日本对中国侵略行为所促成。“中国人民对于现在时局所抱的希望及志愿，为领土与主权之完整”，对东北傀儡政府的出现，“决不能容忍”。“至于 …

  • 1932年3月28日讯：日机三架飞杭州市低空侦察。

  • 1932年3月28日讯：中日军事小组委员会续开会，日方仍坚持军队众多，须暂退至吴淞、江湾、闸北、真如四区。中国代表指出以上四区非原则第二项规定之撤兵地点，仍坚持照1月28日以前原防。

  • 1932年3月28日《申报》：哈尔滨息，自卫军赵毅旅24日攻入一面坡，熙洽军及日军退守珠河。（25日专电）

  • 1932年3月28日《申报》：哈尔滨息，24日夜，土肥原、多门、李桂林在哈特务机关内，邀自卫军代表王之佑，谈和平条件。闻自卫军仍持各军回驻原防，发饷三月，各司令旅长复原职等条件（25日专电）

  • 1932年3月28日《申报》：哈尔滨息，宮占海自卫军25日午后3时，与日军长谷部，在宾州激战，日机3架助攻，宫军为避威胁，退县城外。（26日专电）

  • #抗战影像# 1932年“一·二八淞沪抗战”初期，居留在上海的武装日本侨民正在配合日本海军陆战队投入上海街头作战。

  • 1932年3月28日《申报》：杭州息，调查团美、德、法三代表，17日晨8时35分赴京，共乘汽车几辆，1号麦考伊、魏文彬，2号克劳特、王广圻，3号希尼、朱凤千，余乘随员招待等。两辆装行李。（27日专电）

  • 1932年3月28日《申报》：各报馆上海童子军战地服务团第四批队员76人，已于27日抵前方，所经各地均由战地服务童子军迎接。该团总指挥汪刚亦到前方随时指挥，又悉前方工作之童子军，先后已到一百五六十人，并于即日由某处唐处长、周秘书莅临训话。

  • 1932年3月28日讯：中日停战会议讨论修改后之《停战协定新草案》，中方代表郭泰祺提出日军应在一定期限内完全撤退，恢复1月28日以前原状。日方反对。反复讨论无结果。
