1932年05月05日

发表于 2021-05-05 更新于 2021-05-21 分类于 局部抗战(1931-1937) 阅读次数：

  • 1932年5月5日讯：粤海军将领陈鼎、金彦文及“中山”等20余舰长通电指责陈济棠拥兵自固，对海军蓄意剪除，表示竭诚拥护原海军总司令陈策。为避陈济棠暴力压迫，将舰队移驻琼崖唐家湾。

  • 1932年5月5日讯：日驻华公使重光葵上午在病床签署停战协定后，下午施行手术，将被炸受伤之右足截断。

  • 1932年5月5日讯：孙科在沪寓所接见记者，答复于右任3日之驳议，仍主开放党禁，速行宪政。

  • 1932年5月5日讯：天津市工联会电国民党中央，要求以武力收回淞沪及东北失地，反对签订上海停战屈辱条件。

  • 1932年5月5日讯：国联调查团李顿等五委员在长春晤溥仪，并接见熙洽与驹井。

  • 1932年5月5日《申报》：东京讯，中东路东段依田旅团主力已代驻海林之村井旅团，现开始向牡丹江进发。日军今日与反满洲国军队四千名交战，又据长春消息，义勇军一大队攻击距长春东32里吉林路线之夏九台（译音）杀死路警两名。据沈阳消息，驻海伦东南之满洲国军，已加入反满洲国之军队，占据通化等若…

  • #抗战影像#驻扎伪满洲国之关东军奉天独立守备队岛本大队部分人员合影旧照。

  • 1932年5月5日《申报》：北平息，义勇军炸毁呼海路铁桥数处，阻日军前进，通化一部日侨逃出，与津日副领事，仍被围通化。（4日专电）

  • 1932年5月5日《申报》：依兰息，我军冯占海部占领宾州，先头部队进抵蜚克图，获重炮一门，小枪四百余枝。杨旅现又收服珠河，获重炮二，小枪一百余枝。刘万魁部占领湧河，毙敌甚众，尚在追击中。（3日专电）

  • 1932年5月5日讯：《中日上海停战及日方撤军协定》由中国代表郭泰祺与日本代表重光葵等在沪签订，共五条及附件三号，规定自是日起中日双方军队在上海周围停止一切敌对行动；日军撤至公共租界暨虹口方面之越界筑路，一如1月28日事变之前；组织共同委员会证明双方撤退，并协助撤退之日本军队与接管之中国警察间移交事宜。

  • 1932年5月5日讯：晨1时余，津浦路第九次车行至连镇以南被匪劫，夺去押车警察手 枪二支，旅客银钱搜去甚多。
