1932年05月28日

发表于 2021-05-28 更新于 2021-06-29 分类于 局部抗战(1931-1937) 阅读次数：

  • 1932年5月28日讯：沪公安局公布闸北五区境内沪战损失情形：原有人口10.1万余，现仅800余；房屋7627所，被焚达6435所。

  • 1932年5月28日讯：上海广肇公所粤侨商业联合会电唐绍仪、邓泽如、萧佛成等，请斡旋粤局，“以定粤局而安人心”。

  • 1932年5月28日讯：香港第一届英帝国货品展览会开幕。

  • 1932年5月28日讯：国民政府令：陆军第八十七师师长楼景越免职，任命张治中为该师师长；任命王均为陆军第七师师长。

  • 1932年5月28日讯：上海出版业工会等35个工会因闻第十九路军将调闽，特派代表赴苏州向该军军长蔡廷锴请愿挽留，并表示如无结果，再往南京当局请愿。

  • 1932年5月28日讯：天津市商会召集各同业公会开会，一致赞成废止内战运动，并电上海全国商联会等称：“废止内战，本为全国一致之心理，矧在困难期间，尤有安内对外之必要，此项组织，敝会极端赞成。”

  • 1932年5月28日讯：广东各界在北较场追悼淞沪抗日阵亡将士大会，到会数万人。同日，第八十八师在武汉及汉阳驻地，分六处举行追悼淞沪抗日阵亡将士。

  • 1932年5月28日《申报》：苏州息，淞沪抗日阵亡将士追悼大会，定今日上午10时，在苏公共体育场举行。事前苏垣各民众团体暨19路军与第5军方面，筹备进行，殊为热烈。苏垣各机关各团体，均派员参加，并由童军从车站至会场，沿途粘贴淞沪抗日阵亡将士大会会场由此前进之标语，金阁内外各要道、案牌坊林立于途，白布黑字，弥见悲壮。

  • 1932年5月28日讯：淞沪抗日阵亡将士追悼大会在苏州举行，到会军民五万余人，主祭官居正。全国各地一律下半旗，停止娱乐一天，以志哀悼。

  • 1932年5月28日讯：立法院会议讨论释放政治犯案，决议：将此案交付法制委员会、军事委员会于审查大赦案时参考。

  • 1932年5月28日讯：沪撤兵区域接管委员会派人会同公安局分赴吴淞、殷行及引翔三地日兵暂驻区域恢复行政权。

  • 1932年5月28日《申报》：沈阳息，昨日辽中县城内公安队全部反正，即日占领县衙及各机关，拘捕伪县长，揭青天白日旗，在辽中日侨二十余名，日警三十一名，韩侨三百余名等大起恐慌，拍电请日领及伪国派兵营救。（27日华联社电）

  • 1932年5月28日讯：新疆增设巩留县，由伊宁县析置。

  • 1932年5月28日《申报》：哈尔滨息，据日方消息，近在呼兰及哈埠以西诸处未能前进之马占山军队，刻向北退走。闻马刻在大黑河附近，日方自称，现以骑兵与飞机追击退军。而驻齐齐哈尔之日军亦向北出发，会同追击云。就中东路线之火车而言，事态渐有进步，虽路线外现有战事，但哈埠与绥芬河间之交通，今午已恢复。（26日电路透社电）

  • #抗战影像#侵占我东北之日本制作的伪满洲国铁路建设前后铁路总线路对比数据的宣传画，美化掩饰其侵略我东北进行殖民统治的实质。

  • 1932年5月28日《申报》：长春息，昨夜九时半，在宽城子西北一里地方，及长春南面之八里坡，均频闻枪声，守备队当派警察队出防，宪兵队亦临时召集，形势紧张。（27日电通社电）

  • 1932年5月28日讯：韩独立党员尹奉吉由沪解往日本，12月19日在日本金泽就义。

  • 1932年5月28日讯：蒋介石、汪精卫联名发表通电，称“救国必先剿共”，对于共产党“必须以有效的方法抵制它们，必须不顾一切代价去应付它们”。

  • 1932年5月28日讯：萧佛成、邹鲁等16人电国民党中央，略谓“此次停战协定未送立法院审查，乃行政院及中政会既违法于先，而中政会在职常委又自行袒庇于后，况此丧权辱国之协定乃由违法而签订，则尤难曲恕，伏望中央不畏强御，执法以绳”。
