1932年05月08日

发表于 2021-05-08 更新于 2021-07-10 分类于 局部抗战(1931-1937) 阅读次数：

  • 1932年5月8日讯：上海光华大学文学院长王造时发表《对于训政与宪政的意见》一文，驳斥汪精卫、于右任等人不同意结束训政的言论。指出“像国民党近几年来的干法，对外丧权辱国，对内压迫人民……到了万不得已的时候，推翻国民党的政权，也未始不是拥护中华民国之一法”。

  • 1932年5月8日讯：红军第三军团彭德怀部占领湖南桂东。

  • 1932年5月8日讯：苏家埠战役结束。红四方面军3月21日发起苏家埠战役，是日苏家埠、韩摆渡之守军全部投降。该战役历时48天，歼敌三万余，俘皖西“剿匪”总指挥厉式鼎及旅长五名，团长11名及以下官兵两万余人。

  • 1932年5月8日讯：川军师长王陵基、范绍增与何成濬、徐源泉、夏斗寅等商定，由川军派十二个团在鄂西“剿共”。

  • 1932年5月8日讯：何应钦电汪精卫、蒋介石称：在赣“剿匪”交通不便，请中央迅拨巨款，兴筑公路及铁路。

  • 1932年5月8日讯：平、津、济邮务工作会代表在天津开联席会议，决议：于6月12日在北平召开华北邮工联席会；反对邮资加价；平、津、济邮务工会共发宣言，反对上海丧权辱国停战协定。

  • 1932年5月8日讯：国联调查团访伪满交通总长丁鉴修，提出25项有关铁道之质询。旋赴伪立法院，听取伪院长赵欣伯说明参加“新国家”之动机及伪立法院组织之内容。

  • 1932年5月8日讯：上海各团体救国联合会电国联，“坚决否认中日停战协定，因其足以破坏中国领土、行政之完整”。

  • 1932年5月8日讯：国民党广州市党部通电反对上海停战协定，列举协定五大缺点：一、不提东北；二、淞沪被占领土不得驻兵与《辛丑条约》天津50里内不得驻兵相同；三、规定日军驻地模糊；四、无我军保护淞沪路明文；五、共同委员会无强制日人履约权。

  • 1932年5月8日讯：浏河、嘉定、南翔前线日军陆续撤退，9日撤尽，南京警察厅长吴思豫派干警500名前往接收。

  • #抗战影像#伪满洲国国境警察队，也称伪满洲国靖线警察队，正在接受其长官检阅。

  • 1932年5月8日《申报》：北平息，日关东军奉命决以全力消灭东北义勇军，连日运往绥中大批军需品子弹，日机迭飞各要隘，侦查义勇军根据地，并威胁各地驻军，不得与义勇军通声气，各驻军均不理。（7日专电）

  • 1932年5月8日《申报》：安东息，义勇军百二十人进攻缉安，居民纷纷避难，城内大混乱，日警察队亦离城避难。（7日日联社电）

  • 1932年5月8日讯：我吉林自卫军冯占海部攻克宾县，歼灭伪军2000余人，残敌逃回哈市，哈市一时风声鹤唳，极为动荡。
