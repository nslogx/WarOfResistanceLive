1932年02月02日

发表于 2021-02-02 更新于 2021-07-23 分类于 局部抗战(1931-1937) 阅读次数：

  • 1932年2月2日讯：沪“日清”、“大阪”等日轮华员、华工为反抗暴日侵沪，全体举行罢工。

  • 1932年2月2日讯：北平女界抗日会、平等抗日会、工界同盟、弱小民族同盟、青年抗日会等五团体，联电慰劳第十九路军。

  • 1932年2月2日讯：阎锡山电慰第十九路军抗日将士。

  • 1932年2月2日讯：中国国民救济会通电全国军界称：“本会愤倭焰之方张，痛国亡之无日，爰本救国之义，敢请我全国海陆空军界同胞，抱敌忾同仇之志，卫国救民之愿，一致奋起，自动开沪援应。”

  • 1932年2月2日讯：上海各医药学院抗日战地医事联合会成立，决派180人赴前线从事救护医治工作。全部医药费用由何香凝主持之国难战士慰劳救护会供给。

  • #一二八淞沪抗战#1932年2月2日讯：日本内阁决定正式派遣陆军。先行派遣上海混成旅团（后称混成第24旅团），旅团长下元熊弥少将，此后增派第九师团，师团长植田谦吉中将，并以独立战车第二中队等部加强了上海派遣混成旅团。

  • 1932年2月2日讯：下午1时后，沪日军战斗机数架飞闸北、真如、南市、浦东上空盘旋侦察，并在闸北、真如投弹多枚。3时许，日军在天通庵车站一带开炮轰击闸北，遭到第七十八师炮兵还击，双方炮战至夜12时始息。

  • #一二八淞沪抗战#1932年2月2日讯：日本海军中央部将长江一带第一遣外舰队之外的舰船，以“出云号”为旗舰（“出云号”2月6日抵达上海），由海军中将野村吉三郎为司令官，组成第三舰队，统一指挥投入战斗。

  • 1932年2月2日讯：下午2时50分，驻沪日总领事村井仓松电话通知上海市政府，谓日本政府对于1月31日在英总领事官舍会议所建议之避免两军冲突办法，不能同意。

  • #抗战影像#1932年2月，“一·二八”淞沪抗战期间，在上海某地作战的日军部队。左侧为一门大正11年式平射步兵炮，后侧为安装37毫米长身管坦克炮的法制NC-27型轻型坦克。

  • 1932年2月2日《申报》：南京息，陈济棠电京，请缨讨日，已令粤方十万健儿，加紧准备完毕，枕戈待命。空军将领张惠长亦电京，待命北上杀敌。（1日专电）

  • 1932年2月2日讯：第十九路军将领蒋光鼐、蔡廷锴、戴戟等通电全国，表示“十九路军将以纯洁之心，纯洁之血，贡于党 国，贡于全民”，“切望散处各方之中央委员政治领袖，发挥其拯救危亡抱负，致力应付存亡一发之危局”。

  • 1932年2月2日《申报》：南京息，中国抗日救国军铁血团一日上午十时赴沪，参加杀敌，沿途上海市民燃放爆竹，欢送至热烈。（1日专电）

  • 1932年2月2日讯：美国就上海事件提交中日政府之照会到达南京，内提出四条停战建议：一、中日两方须即停止敌对行动；二、双方军队退至原防；三、双方区域由中立国军队填驻；四、双方根据《国联盟约》及《凯洛格公约》开始交涉。

  • 1932年2月2日《申报》：哈尔滨息，双城战事31日午后1时已停，日军死伤甚众，残部退双城内，我军宮占海旅骑兵，已将城周包围。今双城激战，我军获辎重极多，得坦克二，机关枪八，大枪百余枝，赵谷旅退哈休息，25、24两旅，午后奉令开双城增援。（31日专电）

  • 1932年2月2日《申报》：南京息，11时20分，停泊下关日舰，突向我城内开炮，机枪迫击炮大炮齐发，探照灯四面探照，我军奉命严阵以待，尚未还击。（2日专电）

  • 1932年2月2日讯：上海市政府为日军违约进攻事致美、英各国总领事通告书，称：“日军已向我方驻在闸北之军队复行攻击，且用飞机任意轰炸该处”，为此，“除向日本总领事提出抗议外，相应声明并函达贵总领事，请烦查照，主持公道”。

  • 1932年2月2日《申报》：南京息，11时甫过，下关与火车站间之日陆战队枪击中国巡队，日军舰即发20余炮，轰击狮子山炮台，有数弹击中，炮台未回炮，以待命令。电灯三时皆熄，飞行场以探照灯照耀空中，以防日飞机由空中轰击。华军即占守沿江各阵地，预备抵抗，但日兵未登岸。旋中日兵互以机关枪…

  • 1932年2月2日讯：日军占领双城后，掌握哈长铁路，利用火车增调大量军队，配合飞机、坦克、装甲车，迫近哈尔滨。

  • 1932年2月2日讯：沪各大学义勇军500余名和救护队300余名奉第十九路军翁照垣旅长之命集中闸北，是日下午第一批出发，次日上午悉数开赴前线。同日，沪市民联合会义勇军300余名，在闸北太阳庙平江公所集合，听候第十九路军收编，加入前线工作。
