1932年02月04日

发表于 2021-02-04 更新于 2021-02-26 分类于 局部抗战(1931-1937) 阅读次数：

  • 1932年2月4日讯：国民党天津市党部答应宝成纱厂工人春节放假三天，并发三日工资。8日，该厂工人又罢工，仍要求发给十日工资，并每日增加工资五分。经调解，厂方答应发给八日工资，自本月16日起每日加给工资三分。

  • 1932年2月4日讯：上海银钱业今起实施同业汇划制。

  • 1932年2月4日讯：彭德怀红三军团发起赣州战役，围攻赣州国民党军。

  • 1932年2月4日讯：徐永昌电行政院请辞晋省府主席及委员职。

  • 1932年2月4日讯：国民政府特任李济深为军事委员会办公厅主任。6日，军事委员会在洛阳正式成立。

  • 1932年2月4日讯：上海肠业等150个同业公会急电国民政府、军政部，要求速派军援沪。上海地方维持会会长史量才等亦电国民政府，为第十九路军请援，略称：“上海三百万市民现几濒于绝境，无上海即无全国，置十九路军而不援，岂特弃我三百万市民，试问全国失此经济中心，今后将何以自立。”

  • 1932年2月4日讯：南京中央研究院、中央大学、金陵大学、中国科学社、江宁律师公会等联名通电世界各国民众，宣布日军暴行，吁请予以制裁。

  • 1932年2月4日讯：上海日海陆空军继续总攻，炮轰宝山路一带，并由新民路、虬江路、宝通路、天通庵路、青云路全线攻击，均被第十九路军击退。日舰十余艘于上午11时起再攻吴淞，亦被击退。敌海军遣外第一舰队司令盐泽幸一因此被免职调回日本，海军中将野村吉三郎继任。

  • #一二八淞沪抗战#1932年2月4日，日本海军“能登吕”号水上飞机母舰派出十四式三号水上侦察机3架，“加贺”号海空母舰派出三式一型舰上战斗机3架，联合空袭十九路军位于天通庵路与宝山路一带阵地。

  • 1932年2月4日《申报》：上海本埠息，日飞机昨日上午，又在沪西一带抛掷炸弹。晨九时后，有日机三架，飞行空中，窥测沪西曹家渡一带，约十分钟后，即连掷数弹。一弹落于六区公安局前，该地适有一小孩，半个头颅被炸去，脑浆迸裂，立时毙命，其状甚惨。又有一弹，入租界白利南路，租界当局，拟与之交涉。

  • 1932年2月4日《申报》：上海本埠息，昨日上午12时许，日军派陆战队，在虹口花园及天通庵车站方面，用大炮进攻闸北向我军阵地轰击，计开炮一百余发，同时并有军用飞机多架，在空中投掷炸弹数十枚。我军炮兵，立即还炮五十余发，迫击炮一百余发。激战至下午5时许。炮火始稍停，我全线官兵，均沉着应战…

  • 1932年2月4日讯：日军在飞机、坦克掩护下分三路大举进攻哈尔滨市区，李杜亲临前线指挥，马占山速派苑崇谷旅前往增援，行至何家沟附近，遭日军袭击，伤亡惨重。

  • 1932年2月4日《申报》：香港息，粤救国筹欵会二日决议，各机关职员捐月薪十之一，承商捐饷十之二，业主捐租一月，各商号捐资本额百之一，接济十九路军。（3日专电）

  • 1932年2月4日讯：何应钦致电吴铁城转孙科、顾孟馀及在沪中委，请在沪共同筹措巨款，以报国难。

  • 1932年2月4日讯：国民政府军事委员会根据徐州军事会议决定，通电划分全国为四个防卫区，第一防卫区为黄河以北，以张学良为司令长官；第二防卫区为黄河以南、长江以北，以蒋介石为司令长官；第三防卫区为长江以南及浙、闽两省，以何应钦为司令长官；第四防卫区为两广，以陈济棠为司令长官。

  • #抗战影像#“一·二八”抗战中，一队整装待发的十九路军盒子炮手｜枪队。

  • 1932年2月4日讯：上海绸缎业、棉布业等160个同业公会急电国民政府、行政院、外交部和军政部，对五国所提在上海划中立区的主张表示誓死反对，指出此主张为“巧立名目，断送国土”。

  • 1932年2月4日《申报》：哈尔滨息，前二十三旅长李札林等，在吉召集旧部反正，熙洽二日早逃长春，依多门。（2日专电）

  • 1932年2月4日讯：日军对哈尔滨发起总攻，我军官兵奋起抗战，战斗一时胶着，但日军火力占优，而我军仓促应战，连基本的工事都尚未完备，敌强我弱之下，战事极为不利。

  • 1932年2月4日讯：上海市商会致电国民政府、行政院、外交部，反对于公共租界之外另设中立区，谓“为避免战祸计，只须租界当局能以实力保持，万不可于原有中立区域之外，再设置所谓中立区域”。

  • 1932年2月4日《申报》：南京息，今日午后中日双方当局在下关日军舰开会，商妥双方不得无故开火，因此人心为之安定，中国出席会议者，为外交部能操日语之员三人，军政部代表一人，日方代表为驻宁日总领事与日海军司令。（3日路透社电）

  • 1932年2月4日讯：外交部分别复照英、美、法、德、意五国，接受关于停止中日冲突，在上海划中立区的照会。日本拒绝调停，并反对第三国干涉满洲事件。

  • #一二八淞沪抗战#1932年2月4日讯：我吴淞炮台与敌猛烈对射，激战竟日，吴淞露天炮台被敌狂轰滥炸全部摧毁，要塞官兵伤亡惨重，要塞滕参谋长殉国，阻敌登陆的156旅4团1营1个排在进入阵地时已伤亡过半，但在我军猛烈抵抗下，日军始终不能登陆。

  • 1932年2月4日讯：沪商务印书馆及东方图书馆被日机轰炸，付之一炬。是日该馆董事会决议停业。
